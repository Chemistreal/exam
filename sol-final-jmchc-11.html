문제 1수득률정답 ④

사고과정

한계 반응물 판별: A/2 = 3.0 < B/1 = 4.0 → A가 한계.

이론 C = 6.0×(3/2) = 9.0몰.

수득율 = 8.1/9.0 = 90%.

→ ④

수득율 = 실제/이론. 이론량은 반드시 한계 반응물 기준으로 계산. A/2와 B/1을 비교해 작은 쪽이 한계.
문제 2수득률정답 ③

사고과정

4Al + 3O2 → 2Al2O3.

Al 160/27 = 5.93몰 → 이론 Al2O3 = 2.96몰 = 2.96×102 ≈ 302g.

수득률 = 260/302 ≈ 86%.

→ ③

Al:Al2O3 = 4:2 = 2:1. 몰수로 이론 질량을 구한 뒤 실제와 비교한다.
문제 3평형상수정답 ②

사고과정

①(K는 T 의존)·③(상전이 중 온도 일정)·④(촉매는 K 불변)는 옳다.

② 증기압은 온도에만 의존하고 대기압과 무관. → ②

증기압 = 액체와 평형인 증기의 압력으로 온도만의 함수. 외부 대기압을 바꿔도 증기압 자체는 변하지 않는다.
문제 4삼중점정답 ①

사고과정

① 25°C < 임계점 31°C라 충분히 가압하면 액화 가능(거짓).

②(1atm<삼중점 5.1atm이라 승화)·③(35°C>임계점이라 액체 불가)·④(같은 온도서 액체 증기압>고체)는 옳다. → ①

임계온도 아래면 가압으로 액화 가능. 25°C는 임계점(31°C)보다 낮으니 액체 CO2를 만들 수 있다(소화기 내부처럼).
문제 5압력정답 ①

사고과정

가압은 밀도 큰(부피 작은) 상을 선호. ②③④는 모두 더 조밀한 상으로 가는 변화라 가압에 유리.

① 고체→기체는 가장 성긴 상으로 가는 변화라 가압 시 가능성 최저. → ①

르샤틀리에: 압력↑면 부피가 작은 쪽으로. 고체→기체는 부피가 폭증하는 방향이라 가압에 가장 불리하다.
문제 6분별증류정답 ②

사고과정

② 삼중점(0.01°C·0.006atm)에서 3상 공존(참).

① 에탄올-물은 공비혼합물이라 완전 분리 불가. ③ CaCl2(i=3)가 NaCl(i=2)보다 효과적. ④ 0~4°C선 밀도 증가. → ②

삼중점은 3상이 공존하는 유일한 온도·압력. 물의 밀도 이상(4°C 최대)과 공비혼합물은 단골 함정.
문제 7상평형도정답 ④

사고과정

①(고체-액체선 양의 기울기)·②(상온 1atm서 기체)·③(1atm<삼중점 5.1atm이라 액체 없음)는 옳다.

④ 상평형도는 순수 CO2(1atm) 기준. 대기 중 CO2 분압은 ~0.0004atm이라 −80°C서도 응결(눈)되지 않는다. → ④

−80°C 승화점은 순수 CO2가 1기압일 때. 실제 대기의 CO2 분압은 매우 낮아 훨씬 더 차가워야 응결한다.
문제 8상평형도정답 ③

사고과정

①(녹는점 119°C>95°C)·②(고체1·2·액체·기체로 삼중점 3개)·④(1atm서 119°C 녹음)는 옳다.

③ 상온(25°C)은 삼중점(95°C)보다 한참 낮아 증기압이 10⁻⁴atm(0.076torr) 미만 → 1torr보다 작다. → ③

다형 물질은 삼중점이 여러 개. 상온이 녹는점(119°C)보다 훨씬 낮으면 고체의 증기압은 매우 작다.

②(해양 광합성에 CO2 용해 중요)·③(O2 무극성이라 난용)·④(O2 축적 후 육상 진출)는 옳다. → ①

문제 10용해도정답 ①

사고과정

각 1.5g(0.5L).

25°C 용해 한계: A 2.4×0.5=1.2g, B 1.2×0.5=0.6g.

석출: A 1.5−1.2 = 0.3g, B 1.5−0.6 = 0.9g.

문제 16이온농도정답 ①

주어진 것 — Zn(OH)2 의 용해도곱 Ksp = 4.5×10−17 이고, pH 가 3, 5, 7, 9 인 네 수용액이 있다.

각 용액에 Zn(OH)2 를 포화시켰을 때 [Zn2+] 가 가장 큰 용액의 pH 를 찾는 문제다.

1단계 — 용해 평형을 쓴다.

Zn(OH)2(s) ⇌ Zn2+ + 2OH− 이고 Ksp = [Zn2+][OH−]2 = 4.5×10−17 이다.

2단계 — 구하려는 [Zn2+] 로 정리한다.

[Zn2+] = Ksp/[OH−]2 이다.

이 식에서 [OH−] 는 용액의 pH 가 정해 주는 값이므로, [Zn2+] 는 오직 [OH−] 가 얼마나 작은가로 결정된다.

3단계 — 각 pH 의 [OH−] 를 구한다.

pOH = 14 − pH 이므로 pH 3 → [OH−] = 10−11 M, pH 5 → 10−9 M, pH 7 → 10−7 M, pH 9 → 10−5 M 이다.

4단계 — 네 경우를 모두 대입한다.

pH 3 이면 4.5×10−17/(10−11)2 = 4.5×10−17/10−22 = 4.5×105 이다.

pH 5 이면 4.5×10−17/10−18 = 45 이다.

pH 7 이면 4.5×10−17/10−14 = 4.5×10−3 이다.

pH 9 이면 4.5×10−17/10−10 = 4.5×10−7 이다.

5단계 — 규칙을 확인한다.

pH 가 2 낮아지면 [OH−] 는 102 배 작아지고 [OH−]2 은 104 배 작아지므로 [Zn2+] 는 104 배 커진다.

네 값이 정확히 104 배씩 벌어지는 것이 그 결과다.

결론 — 가장 산성인 pH 3 에서 [Zn2+] 가 가장 크므로 답은 ① 이다.

다만 pH 3 에서 나온 4.5×105 M 은 실제로 존재할 수 없는 농도이며, 그 산성도에서는 Zn(OH)2 가 남김없이 녹아 버린다는 뜻으로 읽는다.

네 보기의 상대적 크기를 비교하는 것이 이 문제가 묻는 바다.

문제 17이온수정답 ④

주어진 것 — AlCl3, H2SO4, FeCl3, KMnO4 네 물질이며, 물에서 해리될 때 가장 적은 개수의 이온을 내놓는 것을 찾는다.

1단계 — 세는 규칙을 정한다.

SO42− 나 MnO4− 같은 다원자 이온은 원자로 쪼개지 않고 통째로 이온 1개로 센다.

따라서 화학식 1개가 내놓는 이온 수는 양이온 개수와 음이온 개수의 합이다.

2단계 — 네 물질의 해리식을 각각 쓴다.

AlCl3 → Al3+ + 3Cl− 이므로 1 + 3 = 4개다.

H2SO4 → 2H+ + SO42− 이므로 2 + 1 = 3개다.

FeCl3 → Fe3+ + 3Cl− 이므로 1 + 3 = 4개다.

KMnO4 → K+ + MnO4− 이므로 1 + 1 = 2개다.

3단계 — 비교한다.

4개, 3개, 4개, 2개이므로 가장 적은 것은 KMnO4

다. 결론 — ④

다. MnO4− 는 Mn 과 O 사이가 공유 결합으로 묶인 하나의 이온이라 물에서 그대로 남으며, 이 이온이 보라색을 띠는 것이 KMnO4 수용액이 보라색인 이유다.

문제 18용해도곱상수정답 ③

AgCl ⇌ Ag+ + Cl−.

Ksp = s·s = s2 → s = (Ksp)1/2.

→ ③

문제 19용해도곱상수정답 ③

사고과정

Ksp = (3s)3(2s)2 = 27s3·4s2 = 108s5 → s = (Ksp/108)1/5.

→ ③

계수가 농도의 지수이자 곱하는 수가 된다: (3s)3·(2s)2 = 27·4·s5 = 108s5. 총 이온수 5라 5제곱근.

화학량론이 달라 몰용해도 s를 직접 계산: Sn(OH)2(4s3) ≈ 9×10−10, CdS(s2) = 10−14, Al(OH)3(27s4) ≈ 5×10−9, Pb3(PO4)2(108s5) ≈ 6×10−12.

→ ③

Ksp가 작다고 용해도가 작은 게 아니다. 화학량론이 다르면 반드시 s로 환산해 비교(Al(OH)3는 작은 Ksp에도 s 최대).

문제 22앙금생성정답 ③

주어진 것 — 25 °C 에서 AgBr 의 용해도곱 Ksp = 7.7×10−13 이며, 답은 g/L 단위로 요구된다.

1단계 — 용해 평형을 쓴다.

AgBr(s) ⇌ Ag+ + Br− 이다.

녹은 몰 농도를 s 라 하면 [Ag+] = [Br−] = s 이므로 Ksp = s2 이다.

2단계 — 몰 용해도를 구한다.

s = √(7.7×10−13) 이다.

지수를 짝수로 만들어 7.7×10−13 = 77×10−14 로 고치면 s = √77 × 10−7 = 8.775×10−7 mol/L 이다.

3단계 — g/L 로 바꾸기 위해 화학식량이 필요하다.

문제지에 원자량이 주어져 있지 않으므로 표준 원자량(Ag 107.87, Br 79.90)을 쓴다.

AgBr 의 화학식량은 107.87 + 79.90 = 187.77 g/mol 이다.

4단계 — 곱한다.

8.775×10−7 mol/L × 187.77 g/mol = 1.648×10−4 g/L 이다.

결론 — 1.65×10−4 g/L 이므로 ③ 이다.

보기 ① 8.8×10−7 은 단위가 mol/L 일 때의 값이며, g/L 로 묻는 문제이므로 화학식량을 곱하는 단계를 반드시 거쳐야 한다.

문제 28해리도정답 ③

주어진 것 — 약산의 농도 C = 0.1 M, 해리 상수 Ka = 1.0×10−5 이며, 백분율로 나타낸 해리도를 구한다.

1단계 — 평형을 쓴다.

HA ⇌ H+ + A− 에서 해리된 양을 x 라 하면 Ka = x2/(C − x)

다. 2단계 — 약산 근사를 쓴다.

Ka 가 작아 x ≪ C 이므로 C − x ≈ C 로 두면 Ka ≈ x2/C

다. 3단계 — x 를 구한다.

x = √(Ka·C) = √(1.0×10−5 × 0.1) = √(1.0×10−6) = 1.0×10−3 M 이다.

여기서 10−5 × 10−1 = 10−6 이며, 지수는 더한다.

4단계 — 근사가 타당한지 확인한다.

x/C = 1.0×10−3/0.1 = 0.01 로 5% 보다 작으므로 2단계의 근사를 그대로 써도 된다.

5단계 — 해리도를 구한다.

α = (해리된 농도)/(초기 농도) × 100% = (1.0×10−3/0.1) × 100% = 1.0×10−2 × 100% = 1%

다. 결론 — ③ 이다.

같은 산이라도 농도를 묽히면 α = √(Ka/C) 에 따라 해리도가 커진다는 오스트발트 희석률과도 맞는다.

문제 29해리백분율정답 ②

3단계 — 정의에 대입한다.

문제 32평형상수정답 ③

주어진 것 — HA 와 HB 는 모두 약산이고 해리 상수는 각각 Ka(HA), Ka(HB) 이며 pKa(HA) < pKa(HB)

다. 대상 반응은 HA + B− ⇌ A− + HB 이고, 이 반응의 평형 상수 K 에 관해 옳은 것을 고른다.

1단계 — 두 해리 평형을 쓴다.

HA ⇌ H+ + A− 의 상수는 Ka(HA) 이고, HB ⇌ H+ + B− 의 상수는 Ka(HB)

다. 2단계 — 대상 반응을 두 식으로 조립한다.

첫 식은 그대로 두고 둘째 식은 뒤집어(B− + H+ ⇌ HB) 더하면 H+ 가 소거되어 HA + B− ⇌ A− + HB 가 된다.

평형 상수는 반응을 뒤집으면 역수가 되고 반응을 더하면 곱해지므로 K = Ka(HA) × 1/Ka(HB) = Ka(HA)/Ka(HB)

다. 곱이 아니라 몫이므로 ②와 ④의 식은 성립하지 않는다.

3단계 — K 의 크기를 판정한다.

pKa = −log Ka 이므로 pKa 가 작을수록 Ka 는 크다.

pKa(HA) < pKa(HB) 에서 Ka(HA) > Ka(HB) 이고, 따라서 K = Ka(HA)/Ka(HB) > 1 이다.

4단계 — 보기를 하나씩 판정한다.

①의 K < 1 은 부등호가 반대이므로 틀렸다.

②의 K = Ka(HA)×Ka(HB) 는 조립 규칙을 어겼으므로 틀렸다.

③의 K > 1 은 3단계와 같으므로 옳다.

④는 ②와 같은 곱이므로(곱셈은 순서를 바꿔도 값이 같다) 마찬가지로 틀렸다.

결론 — ③ 이다.

산·염기 반응은 언제나 센 산과 센 염기가 약한 산과 약한 염기로 바뀌는 쪽으로 치우치며, 여기서는 센 산 HA 가 약한 산 HB 로 바뀌는 방향이라 정반응이 유리하다.

확인 필요 보기 ②(K = Ka(HA)×Ka(HB))와 ④(K = Ka(HB)×Ka(HA))는 곱셈의 교환 법칙에 따라 완전히 같은 식이다. 서로 구별되지 않는 두 선지가 함께 놓여 있어 변별력이 없으므로, 다음 회차에서는 한쪽을 K = Ka(HA)/Ka(HB) 나 K = Ka(HB)/Ka(HA) 로 바꾸는 것을 검토할 필요가 있다. 정답 ③ 자체에는 문제가 없다.

문제 57중화적정정답 ①

주어진 것 — 농도가 모두 0.10 M 인 약염기 A, B, C 를 각각 센 산으로 적정한 세 개의 적정 곡선이다.

가로축은 넣어 준 0.1 M 적정액의 부피이고, 세 곡선 모두 50 mL 부근에서 pH 가 수직으로 떨어진다 — 그 지점이 당량점이다.

묻는 것은 당량점에서 pH 가 가장 큰 것이다.

1단계 — 적정 전(0 mL) pH 를 읽는다.

세로축과 만나는 점을 세로축 눈금에 대고 읽으면 A 가 약 11.6 으로 가장 높고, B 가 약 10.5, C 가 약 9.5 로 가장 낮다.

2단계 — 초기 pH 로 염기의 세기를 비교한다.

세 용액의 농도가 0.10 M 로 같으므로 적정 전 pH 가 높을수록 Kb 가 크다.

수로 확인하면, A 는 pOH = 14 − 11.6 = 2.4 이므로 [OH−] = 10−2·4 = 4.0×10−3 M 이고 Kb = (4.0×10−3)2/0.10 = 1.6×10−4

다. B 는 pOH = 3.5 이므로 [OH−] = 3.2×10−4 M 이고 Kb = (3.2×10−4)2/0.10 = 1.0×10−6

다. C 는 pOH = 4.5 이므로 [OH−] = 3.2×10−5 M 이고 Kb = (3.2×10−5)2/0.10 = 1.0×10−8

다. 따라서 염기의 세기는 A > B > C

다. 3단계 — 당량점에 무엇이 남는지 본다.

약염기 B 를 센 산 HX 로 꼭 당량만큼 중화하면 염기는 모두 짝산 BH+ 로 바뀌고, 용액에는 BH+ 와 반응에 참여하지 않는 구경꾼 이온 X− 만 남는다.

BH+ 는 약산이므로 당량점 용액은 산성이고 pH 는 7 보다 작다.

이 판단은 그래프의 모양이 아니라 당량점에 남는 화학종만으로 나온다.

이 도표는 개형이라 당량점 부근의 눈금이 정밀하지 않으므로, 50 mL 눈금선에서는 세 곡선의 pH 가 A > B > C 순이라는 것만 읽어 둔다.

4단계 — 짝산의 세기를 정한다.

Ka(BH+) × Kb(B) = Kw = 1.0×10−14 이므로 Ka = Kw/Kb 이고, Kb 가 클수록 짝산의 Ka 는 작다.

A 의 짝산은 Ka = 1.0×10−14/1.6×10−4 = 6.3×10−11, B 의 짝산은 1.0×10−14/1.0×10−6 = 1.0×10−8, C 의 짝산은 1.0×10−14/1.0×10−8 = 1.0×10−6

다. 즉 짝산의 세기는 C 의 짝산 > B 의 짝산 > A 의 짝산으로, 염기의 세기와 정확히 반대다.

5단계 — 당량점 pH 를 계산한다.

당량점이 50 mL 이고 적정액이 0.1 M 이므로 넣어 준 산은 0.1 mol/L × 0.050 L = 5.0×10−3 mol 이고, 처음 들어 있던 염기도 같은 5.0×10−3 mol 이다.

염기 용액이 0.10 M 이었으므로 그 부피는 5.0×10−3/0.10 = 0.050 L = 50 mL

다. 당량점에서 전체 부피는 50 + 50 = 100 mL 이므로 짝산의 농도는 C′ = 5.0×10−3 mol / 0.100 L = 0.050 M 이고, 세 적정이 모두 같다.

짝산만 있는 용액이므로 [H+] = √(Ka × C′)

다. A 의 짝산은 √(6.3×10−11 × 0.050) = √(3.2×10−12) = 1.8×10−6 M 로 pH 5.75, B 의 짝산은 √(1.0×10−8 × 0.050) = √(5.0×10−10) = 2.2×10−5 M 로 pH 4.65, C 의 짝산은 √(1.0×10−6 × 0.050) = √(5.0×10−8) = 2.2×10−4 M 로 pH 3.65

다. 세 값이 모두 7 보다 작아 3단계의 결론과 맞고, 크기 순서는 A > B > C

다. 이 수치는 그래프에서 읽은 초기 pH 로 역산한 Kb 를 넣은 것이라 개형으로 그린 곡선의 당량점 높이와 자릿수까지 맞지는 않으며, 순서를 확인하는 용도로 쓴다.

결론 — 당량점 pH 가 가장 큰 것은 A 이므로 답은 ① 이다.

요약하면 가장 센 약염기가 가장 약한 짝산을 남기고, 그 짝산이 물을 가장 덜 산성으로 만들어 당량점이 중성에 가장 가깝다.
