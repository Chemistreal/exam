문항별 사고과정

문제 1수득률정답 ④

사고과정

한계 반응물 판별: A/2 = 3.0 < B/1 = 4.0 → A가 한계. 이론 C = 6.0×(3/2) = 9.0몰.

수득율 = 8.1/9.0 = 90%. → ④

수득율 = 실제/이론. 이론량은 반드시 한계 반응물 기준으로 계산. A/2와 B/1을 비교해 작은 쪽이 한계.
문제 2수득률정답 ③

사고과정

4Al + 3O2 → 2Al2O3. Al 160/27 = 5.93몰 → 이론 Al2O3 = 2.96몰 = 2.96×102 ≈ 302g.

수득률 = 260/302 ≈ 86%. → ③

Al:Al2O3 = 4:2 = 2:1. 몰수로 이론 질량을 구한 뒤 실제와 비교한다.
문제 3평형상수정답 ②

사고과정

①(K는 T 의존)·③(상전이 중 온도 일정)·④(촉매는 K 불변)는 옳다.

② 증기압은 온도에만 의존하고 대기압과 무관. → ②

증기압 = 액체와 평형인 증기의 압력으로 온도만의 함수. 외부 대기압을 바꿔도 증기압 자체는 변하지 않는다.
문제 4삼중점정답 ①

사고과정

① 25°C < 임계점 31°C라 충분히 가압하면 액화 가능(거짓).

②(1atm<삼중점 5.1atm이라 승화)·③(35°C>임계점이라 액체 불가)·④(같은 온도서 액체 증기압>고체)는 옳다. → ①

임계온도 아래면 가압으로 액화 가능. 25°C는 임계점(31°C)보다 낮으니 액체 CO2를 만들 수 있다(소화기 내부처럼).
문제 5압력정답 ①

사고과정

가압은 밀도 큰(부피 작은) 상을 선호. ②③④는 모두 더 조밀한 상으로 가는 변화라 가압에 유리.

① 고체→기체는 가장 성긴 상으로 가는 변화라 가압 시 가능성 최저. → ①

르샤틀리에: 압력↑면 부피가 작은 쪽으로. 고체→기체는 부피가 폭증하는 방향이라 가압에 가장 불리하다.
문제 6분별증류정답 ②

사고과정

② 삼중점(0.01°C·0.006atm)에서 3상 공존(참).

① 에탄올-물은 공비혼합물이라 완전 분리 불가. ③ CaCl2(i=3)가 NaCl(i=2)보다 효과적. ④ 0~4°C선 밀도 증가. → ②

삼중점은 3상이 공존하는 유일한 온도·압력. 물의 밀도 이상(4°C 최대)과 공비혼합물은 단골 함정.
문제 7상평형도정답 ④

사고과정

①(고체-액체선 양의 기울기)·②(상온 1atm서 기체)·③(1atm<삼중점 5.1atm이라 액체 없음)는 옳다.

④ 상평형도는 순수 CO2(1atm) 기준. 대기 중 CO2 분압은 ~0.0004atm이라 −80°C서도 응결(눈)되지 않는다. → ④

−80°C 승화점은 순수 CO2가 1기압일 때. 실제 대기의 CO2 분압은 매우 낮아 훨씬 더 차가워야 응결한다.
문제 8상평형도정답 ③

사고과정

①(녹는점 119°C>95°C)·②(고체1·2·액체·기체로 삼중점 3개)·④(1atm서 119°C 녹음)는 옳다.

③ 상온(25°C)은 삼중점(95°C)보다 한참 낮아 증기압이 10⁻⁴atm(0.076torr) 미만 → 1torr보다 작다. → ③

다형 물질은 삼중점이 여러 개. 상온이 녹는점(119°C)보다 훨씬 낮으면 고체의 증기압은 매우 작다.
문제 9기체의용해도정답 ①

사고과정

① 태초의 광합성은 바다(해양 남세균·조류)에서 일어났다(지상 식물은 훨씬 후). 거짓.

②(해양 광합성에 CO2 용해 중요)·③(O2 무극성이라 난용)·④(O2 축적 후 육상 진출)는 옳다. → ①

생명·산소의 역사: 바다 광합성 → 대기 산소 축적 → 오존층 형성 → 육상 진출. 광합성의 시작은 물속이었다.
문제 10용해도정답 ①

사고과정

각 1.5g(0.5L). 25°C 용해 한계: A 2.4×0.5=1.2g, B 1.2×0.5=0.6g. 석출: A 1.5−1.2 = 0.3g, B 1.5−0.6 = 0.9g.

총 1.2g 중 A 0.3/1.2 = 25%, B 75%. → ①

석출량 = 녹아있던 양 − 냉각 온도의 용해 한계. 용해도가 작은 B가 더 많이 석출된다.
문제 11유유상종정답 ③

사고과정

에탄올(−OH로 수소결합, 물과 섞임) > 클로로폼(극성, 약간 녹음) > 에테인(무극성, 거의 안 녹음). → ③

"비슷한 것끼리 녹는다": 수소결합>극성>무극성 순으로 물에 잘 녹는다. 에탄올은 물과 무한히 섞인다.
문제 12이온분위기정답 ②

사고과정

KHT → K⁺ + HT⁻. A(최대 증가)=MgSO4(2+2− 이온세기 최대). B=NaCl. C(일정)=글루코오스(비전해질). D(감소)=KCl(공통이온 K⁺). → ②

전하 큰 무관 염(MgSO4)은 이온세기를 높여 용해도↑(염 효과). 비전해질은 무영향. 공통이온(KCl의 K⁺)은 용해도↓.
문제 13양적관계정답 ②

사고과정

수화물 x g 중 CuSO4 = 0.64x, 결정수 = 0.36x(용매에 더해짐). 포화: 0.64x/(100+0.36x) = 0.2 → 0.568x = 20 → x ≈ 35g. → ②

수화물이 녹으면 결정수가 용매 물에 합쳐진다. 이 추가 물을 분모에 넣지 않으면 답이 틀린다(흔한 함정).
문제 14용해도정답 ①

사고과정

① HCl이 CO3²⁻를 소모(CO2↑) → CaCO3 용해도 증가(참).

② SO4²⁻는 공통이온이라 BaSO4 용해도 감소. ③ Ksp는 온도만의 함수라 불변(용해도만 감소). → ①

용해도곱 상수 Ksp는 온도로만 변한다. 공통이온은 용해도를 낮추지만 Ksp는 그대로. 약산 음이온은 산으로 제거해 용해도를 높인다.
문제 15용해도정답 ②

사고과정

Ra는 2족(Ba와 유사). 염화물·질산염은 가용, Ra(OH)2도 가용(Ba(OH)2처럼). 탄산염 RaCO3만 난용(CaCO3·BaCO3처럼). → ②

용해도 규칙: 질산염·대부분 염화물은 가용, 2족 탄산염은 난용. 2족 수산화물은 아래로 갈수록 용해도 증가.
문제 16이온농도정답 ①

사고과정

[Zn²⁺] = Ksp/[OH⁻]². [OH⁻]가 작을수록(pH 낮을수록) [Zn²⁺] 최대. pH 3이 가장 산성. → ①

수산화물은 산성일수록 잘 녹는다(OH⁻가 적어 평형이 용해 쪽으로). pH가 2 낮아지면 [Zn²⁺]는 10⁴배 커진다.
문제 17이온수정답 ④

사고과정

AlCl3→4개, FeCl3→4개, H2SO4→3개. KMnO4 → K⁺ + MnO4⁻ = 2개로 최소. → ④

MnO4⁻는 다원자 이온이라 통째로 하나. 해리 이온 수는 화학식의 양이온·음이온 개수 합.
문제 18용해도곱상수정답 ③

사고과정

AgCl ⇌ Ag⁺ + Cl⁻. Ksp = s·s = s² → s = (Ksp)1/2. → ③

1:1 염은 Ksp=s². 화학량론에 따라 지수가 달라지니(다음 문제 참고) 계수를 꼭 반영한다.
문제 19용해도곱상수정답 ③

사고과정

Ca3(PO4)2 ⇌ 3Ca²⁺ + 2PO4³⁻. Ksp = (3s)³(2s)² = 27s³·4s² = 108s⁵ → s = (Ksp/108)1/5. → ③

계수가 농도의 지수이자 곱하는 수가 된다: (3s)³·(2s)² = 27·4·s⁵ = 108s⁵. 총 이온수 5라 5제곱근.
문제 20용해도곱상수정답 ③

사고과정

화학량론이 달라 몰용해도 s를 직접 계산: Sn(OH)2(4s³) ≈ 9×10⁻¹⁰, CdS(s²) = 10⁻¹⁴, Al(OH)3(27s⁴) ≈ 5×10⁻⁹, Pb3(PO4)2(108s⁵) ≈ 6×10⁻¹². → ③

Ksp가 작다고 용해도가 작은 게 아니다. 화학량론이 다르면 반드시 s로 환산해 비교(Al(OH)3는 작은 Ksp에도 s 최대).
문제 21앙금생성정답 ③

사고과정

첨가 후 [Ag⁺] ≈ (0.010×0.05)/100 = 5×10⁻⁶ M. 각 Q와 Ksp 비교:

AgCl Q=5×10⁻⁷ > 10⁻¹⁰✓, AgBr Q=2.5×10⁻⁹ > 4×10⁻¹³✓, Ag2CrO4 Q=(5×10⁻⁶)²×0.020 = 5×10⁻¹³ < 2×10⁻¹²✗. → AgCl+AgBr. → ③

침전 여부는 이온곱 Q와 Ksp를 비교: Q>Ksp면 침전. Ag2CrO4만 Q<Ksp라 안 생긴다([Ag⁺]이 제곱으로 들어감).
문제 22앙금생성정답 ③

사고과정

s = √(7.7×10⁻¹³) = 8.77×10⁻⁷ mol/L. g/L = 8.77×10⁻⁷ × 188 = 1.65×10⁻⁴ g/L. → ③

몰용해도(mol/L)를 구한 뒤 화학식량을 곱해 g/L로. 단위 변환을 빠뜨리지 말 것.
문제 23양적관계정답 ③

사고과정

[SO4²⁻] = (1×0.050)/0.5 = 0.1M. 침전 시작점서 Q=Ksp: [Ba²⁺] = Ksp/[SO4²⁻] = 10⁻¹⁰/0.1 = 1×10⁻⁹ M. → ③

침전이 "막 시작"하는 순간은 Q=Ksp인 임계점. 이때 아직 침전이 없어 희석된 [Ba²⁺]가 그대로 답.
문제 24앙금생성정답 ②

사고과정

A·D는 순수 포화: [Ba²⁺] = √Ksp = 1×10⁻⁵. B·C는 [SO4²⁻]=0.1 공통이온: [Ba²⁺] = 10⁻¹⁰/0.1 = 1×10⁻⁹.

② A=D=10⁻⁵ 동일(참). ①A가 더 많음. ③공통이온은 낮춤. ④고체량 무관, B=C. → ②

D는 Ba²⁺·SO4²⁻를 똑같이 넣어 거의 다 침전 → 순수 포화(A와 동일). 공통이온(B·C)은 용해도를 낮춘다. 고체 양은 [Ba²⁺]와 무관.
문제 25용해도곱상수정답 ③

사고과정

당량점 전 [Ag⁺]=Ksp/[X⁻]. 왼쪽: pAg⁺ 높을수록(=[Ag⁺] 낮을수록) [X⁻] 큼 → A>B>C. 오른쪽: 같은 [X⁻]라 pAg⁺ 높을수록 Ksp 작음 → 가<나<다. → ③

pAg⁺ = −log[Ag⁺]. 당량점 전 곡선 위치가 위(높은 pAg⁺)일수록 [Ag⁺]가 작고, 이는 음이온 농도가 크거나 Ksp가 작음을 뜻한다.
문제 26다양성자산정답 ①

사고과정

다양성자산은 Ka1>Ka2>Ka3(단계마다 약해짐). 1차 해리하는 H3Y가 가장 강한 산. → ①

음전하가 늘수록 H⁺를 떼기 어렵다. 그래서 첫 번째 양성자가 가장 쉽게 떨어진다(Ka1 최대).
문제 27물의자동이온화정답 ③

사고과정

[H⁺] ≈ 10⁻⁴(HBr). 물에서 나온 H⁺ = [OH⁻](물 자체이온화는 1:1) = Kw/[H⁺] = 10⁻¹⁴/10⁻⁴ = 10⁻¹⁰ M. → ③

산성 용액에서도 물은 H⁺와 OH⁻를 같은 양 만든다. 물 유래 H⁺ = [OH⁻]. 산이 누른 만큼 물의 기여는 작아진다.
문제 28해리도정답 ③

사고과정

[H⁺] = √(Ka·C) = √(10⁻⁵×0.1) = 10⁻³ M. 해리도 = 10⁻³/0.1 × 100 = 1%. → ③

약산 근사: [H⁺]≈√(KaC). 해리도 = [H⁺]/초기 농도. 농도가 묽어지면 해리도는 커진다(오스트발트 희석률).
문제 29해리백분율정답 ②

사고과정

[H⁺] = 10⁻³ M = 해리된 HA. 해리율 = 10⁻³/0.50 × 100 = 0.20%. → ②

pH로 [H⁺](=해리량)를 구하고 초기 농도로 나눈다. 진한 용액(0.50M)이라 해리율이 작다.
문제 30희석정답 ②

사고과정
