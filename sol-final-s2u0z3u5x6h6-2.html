문제 1원자모형정답 ③

수소(H) 원자살을 불균일한 자기장에 통과시키면 원자살이 위·아래 두 가지 방향으로 나누어져 검출판에 두 개의 자국을 남긴다.

다음 <보기>의 원자들을 기체 상태의 원자살로 만들어 같은 장치에 통과시켰을 때, 두… 해설 1) 원자살이 두 갈래로 갈라지는 것은 원자가 알짜 스핀 자기 모멘트를 가질 때, 즉 홀전자가 있을 때이다(Stern-Gerlach 실험).

2) Na: [Ne]3s¹ → 홀전자 1개 → 두 갈래로 갈라짐.

3) Ca: [Ar]4s² → 3s·4s가 모두 채워짐, 홀전자 0개 → 갈라지지 않음.

4) Cd: [Kr]4d¹⁰5s² → 홀전자 0개 → 갈라지지 않음.

5) Ag: [Kr]4d¹⁰5s¹ → 홀전자 1개 → 두 갈래로 갈라짐.

6) 개념 근거: 홀전자 1개의 스핀 양자수는 ms = +½, -½ 두 가지만 가능하므로 자기장 속에서 정확히 두 방향으로 갈라진다(공간 양자화).

함정 Cd, Ag를 전이금속이라는 이유만으로 d 오비탈에 홀전자가 있다고 착각하기 쉽다.

둘 다 d¹⁰으로 꽉 차 있어 s 오비탈 전자 수만 따져야 한다.

원본에서 바뀐 부분 보기 원소를 Li, Mg, Zn, Au → 같은 족의 Na, Ca, Cd, Ag로 바꾸고 정답 위치를 ②에서 ③으로 옮김.

문제 2몰과개수정답 ②

300 mL의 생수가 포함하는 원자의 총 개수는? (물의 밀도 = 1.00 g/mL, H₂O의 화학식량 = 18, 아보가드로수 = 6.02×10²³) 해설 1) 물의 질량: 300 mL × 1.00 g/mL = 300 g 2) 물의 몰수: 300 g ÷ 18 g/mol = 16.7 mol 3) H₂O 1개에는 원자가 3개(H 2개 + O 1개) 있으므로 원자의 몰수 = 16.7 × 3 = 50.0 mol 4) 원자 개수 = 50.0 mol × 6.02×10²³ /mol = 3.01×10²⁵ ≈ 3.0×10²⁵ 5) 개념 근거: 몰은 "화학식 단위"의 개수이므로, 원자 수를 구하려면 분자당 원자 수를 반드시 곱해야 한다.

함정 ③은 물 "분자" 수(1.0×10²⁵), ④는 H 원자만 센 값(2.0×10²⁵)이다.

발문의 밑줄 친 "원자"를 놓치면 바로 오답이 된다.

원본에서 바뀐 부분 부피를 500 mL → 300 mL로 바꾸고, 오답 선택지를 분자 수·H 원자 수 등 전형적 실수값으로 재설계하며 정답 위치를 ④에서 ②로 옮김.

문제 3몰과질량정답 ②

액체 질소의 밀도는 0.807 g/cm³ 이다.

액체 질소에서 분자들이 고르게 분포되어 있다고 가정할 때 가장 가까운 질소 분자 중심 사이의 거리와 가장 가까운 값은? (N의 원자량 = 14.0, 아보가드로수 =… 해설 1) N₂의 몰질량 = 28.0 g/mol 2) 몰부피 = 28.0 g/mol ÷ 0.807 g/cm³ = 34.7 cm³/mol 3) 분자 1개가 차지하는 부피 = 34.7 cm³/mol ÷ 6.02×10²³ /mol = 5.77×10⁻²³ cm³ 4) 분자를 한 변이 d인 정육면체 안에 하나씩 넣었다고 보면 d = (5.77×10⁻²³)^(1/3) = 3.86×10⁻⁸ cm 5) 단위 환산: 3.86×10⁻⁸ cm = 3.86×10⁻¹⁰ m = 0.386 nm ≈ 0.4 nm 6) 개념 근거: 응축상에서는 분자가 거의 맞닿아 있으므로 "1분자당 부피의 세제곱근"이 곧 최근접 중심 간 거리의 좋은 근사이다.

함정 세제곱근을 잊거나, cm → nm 환산(1 cm = 10⁷ nm)에서 자릿수를 틀리면 ①이나 ④가 나온다.

③은 거리를 지름으로 착각해 2배 한 값이다.

원본에서 바뀐 부분 물질을 액체 수소(0.069 g/cm³) → 액체 질소(0.807 g/cm³)로 바꾸고 선택지를 자릿수·2배 실수형으로 재설계, 정답 위치를 ③에서 ②로 옮김.

문제 4열화학정답 ②

다음 열화학 자료를 이용하여 계산한 NaCl(s)의 격자 에너지(lattice energy)(kJ/mol)로 가장 가까운 값은? 해설 1) 격자 에너지는 Na⁺(g) + Cl⁻(g) → NaCl(s) 의 ΔH이다(값이 음수).

2) Born-Haber 순환: ΔH_f = ΔH_승화 + ½D(Cl-Cl) + IE + EA + U 3) 대입: -411 = 108 + (244 ÷ 2) + 496 + (-349) + U 4) 괄호 합: 108 + 122 + 496 - 349 = 377 5) U = -411 - 377 = -788 kJ/mol 6) 개념 근거: 헤스 법칙에 따라 상태함수인 엔탈피는 경로에 무관하므로, 원소 → 기체 이온 → 결정의 경로 합이 직접 생성 경로와 같다.

함정 (3)은 Cl₂ 1몰이 Cl 2몰로 쪼개지는 값이므로 반드시 ½을 곱해야 한다.

그대로 244를 쓰면 ①(-910), 승화열을 빠뜨리면 ③(-680), 이항 부호를 반대로 하면 ④(-34)가 된다.

원본에서 바뀐 부분 화합물을 KF → 같은 1족·17족 조합인 NaCl로 바꾸고 5개 열화학 자료값을 모두 교체, 정답 위치를 ③에서 ②로 옮김.

문제 5엔탈피정답 ②

KBr(s)을 물에 녹일 때 용해열은 19.9 kJ/mol이고, KBr(s)의 격자에너지(lattice energy)는 671.0 kJ/mol이다.

다음 반응의 엔탈피 변화는? 해설 1) 주어진 두 과정을 반응식으로 쓴다.

(가) KBr(s) → K⁺(g) + Br⁻(g)　ΔH = +671.0 kJ (격자에너지, 결정을 기체 이온으로 떼어내는 값) (나) KBr(s) → K⁺(aq) + Br⁻(aq)　ΔH = +19.9 kJ (용해열) 2) 구하려는 수화 과정 = (나) - (가) 3) ΔH° = 19.9 - 671.0 = -651.1 kJ 4) 개념 근거: ΔH_용해 = ΔH_격자(분리) + ΔH_수화 이므로 ΔH_수화 = ΔH_용해 - ΔH_격자이며, 헤스 법칙으로 경로를 조합한 것이다.

함정 두 값을 그대로 더해 690.9(①)를 고르기 쉽다.

격자에너지가 "양수 671.0"으로 주어진 것은 결정 → 기체 이온 방향임을 뜻하므로, 수화 과정에서는 빼야 한다.

수화는 강한 발열이므로 부호는 반드시 음수다.

원본에서 바뀐 부분 물질을 KCl → 같은 알칼리 할로젠화물 KBr로 바꾸고 용해열(19.9)·격자에너지(671.0)를 교체, 정답 위치를 ③에서 ②로 옮김.

문제 6분자간인력정답 ①

다음 <보기>의 자료는 이온결합 화합물의 격자에너지와 관련된 것이다.

다음 중 x와 가장 가까운 값은? 해설 1) A에서 변의 중앙 음이온 4개까지의 거리 = r, 전하곱 = (+2)(-1) = -2 → 기여 = 4 × (-2)/r = -8/r 2) A에서 꼭짓점 양이온 4개까지의 거리 = √2 r (정사각형의 대각선), 전하곱 = (+2)(+1) = +2 → 기여 = 4 × (+2)/(√2 r) = +8/(√2 r) = +5.66/r 3) ΔU = (e²/4πε₀)[-8/r + 5.66/r] = (e²/4πε₀r)(-2.34) 4) 따라서 x = -8 + 8/√2 = -2.343 ≈ -2.3 5) 개념 근거: 이온 결정의 격자에너지는 인력(반대 전하, 가까움)이 척력(같은 전하, 멀리)을 이기기 때문에 음수가 되며, 이 부분합이 마델룽 상수의 첫 근사이다.

함정 꼭짓점까지의 거리를 r로 착각하면 -8 + 8 = 0이 되어 ②를 고르게 되고, 인력 항을 빼먹고 꼭짓점과의 척력만 더하면 +8/√2 = +5.7이 되어 ④를 고르게 된다.

인력과 척력의 부호를 반대로 잡으면 +2.3(③)이 나온다.

대각선 거리는 √2 r 임을 반드시 확인해야 한다.

원본에서 바뀐 부분 중심 A의 전하를 1가 → 2가 양이온으로 바꾸고(격자 구조·거리 관계는 동일), 그림을 좌표·전하 표로 재작성했으며, 오답을 대각선 거리 착각(0)·부호 반대(+2.3)·척력만 계산(+5.7) 값으로 재설계하여 정답 위치는 원본과 같은 ①로 두었다.

문제 7고체정답 ③

이온결합 화합물 RbI, NaF, BaSe 및 MgO를 격자 에너지가 감소하는 순서대로 바르게 나열한 것은? 해설 1) 개념 근거: 격자 에너지는 U ∝ (z₊·z₋)/(r₊ + r₋) 이므로, 먼저 이온 전하의 곱이 크고, 전하가 같으면 이온 간 거리가 짧을수록 크다.

2) 전하의 곱: MgO, BaSe는 (2)(2) = 4 / NaF, RbI는 (1)(1) = 1 → 2가 이온 쌍 두 개가 무조건 위쪽에 온다.

3) 2가끼리 비교: MgO(Mg²⁺ 72 pm + O²⁻ 140 pm = 212 pm) < BaSe(Ba²⁺ 135 pm + Se²⁻ 198 pm = 333 pm) → 거리가 짧은 MgO가 더 크다.

4) 1가끼리 비교: NaF(102 + 133 = 235 pm) < RbI(152 + 220 = 372 pm) → NaF가 더 크다.

5) z₊z₋/(r₊+r₋) 값: MgO 0.0189 > BaSe 0.0120 > NaF 0.00426 > RbI 0.00269 6) 실측 격자 에너지도 MgO 3795 > BaSe 약 2900 > NaF 923 > RbI 617 kJ/mol 로 같은 순서이다.

함정 이온 크기(주기율표 위치)만 보고 정렬하면 BaSe를 NaF 아래로 내리게 된다.

전하의 곱이 거리보다 훨씬 지배적인 인자이므로 전하부터 따져야 한다.

원본에서 바뀐 부분 화합물을 KBr·LiCl·SrSe·ZnS → 같은 전하 조합의 RbI·NaF·BaSe·MgO로 바꾸고 정답 위치를 ④에서 ③으로 옮김.

문제 8전기음성도정답 ②

LiF를 Li²⁺와 F²⁻로 구성된 이온 결정이 아니라 Li⁺와 F⁻로 구성된 이온 결정으로 생각하는 이유로 타당하지 않은 것은? 해설 1) 개념 근거: 이온 결정의 생성 여부는 보른-하버 순환에서 (이온화 에너지 + 전자 부착 에너지)의 손실을 격자 에너지가 갚아 주는지로 결정된다.

2) ①은 타당: F는 [He]2s²2p⁵ → F⁻가 [Ne]로 옥텟을 완성한다.

전자를 하나 더 받은 F²⁻는 새 껍질 3s에 전자가 들어가야 하므로 몹시 불안정하다.

3) ③은 타당: Li의 제1 이온화 에너지는 520 kJ/mol이지만, 제2 이온화 에너지는 1s 껍질을 깨야 하므로 7298 kJ/mol로 14배가량 뛴다.

4) ④는 타당: 이미 음전하를 띤 F⁻에 전자를 더 넣으려면 정전기적 반발을 이겨야 하므로 제2 전자 친화 과정은 강한 흡열이다.

5) ②는 타당하지 않음: 격자 에너지는 U ∝ (z₊·z₋)/(r₊+r₋)이므로 전하가 2배씩 커진 Li²⁺F²⁻의 격자 에너지는 오히려 약 4배 크다.

즉 격자 안정화만 보면 Li²⁺F²⁻가 유리하며, 그런데도 만들어지지 않는 이유는 ③·④의 에너지 손실이 그 4배를 넘기 때문이다.

함정 "실제로 존재하지 않으니 모든 면에서 불리할 것"이라고 뭉뚱그리기 쉽다.

격자 에너지 항목만은 2가 쪽이 유리하다는 점이 이 문제의 핵심이다.

원본에서 바뀐 부분 물질을 NaCl → LiF로 바꾸고, 각 선택지를 그 물질에 맞게 다시 쓰면서 정답 위치를 ③에서 ②로 옮김.

문제 9원소의기원정답 ①

어떤 별의 대기를 분석하였더니 대부분을 차지하는 수소와 헬륨의 질량비가 대략 2:1이었다.

4) 전개액을 바꾸어도 "Q가 P보다 극성이 크다"는 순서 자체는 변하지 않으므로 두 반점의 상하 순서는 유지된다(둘 다 올라가되 Q의 증가폭이 클 뿐이다) → ㄹ 틀림.

5) 개념 근거: 크로마토그래피의 분리는 고정상 흡착과 이동상 용해의 경쟁이다.

극성 고정상(순상)에서는 극성이 작을수록 R_f가 크다.

함정 "이동 거리가 길다 = 극성이 크다"로 반대로 외우면 ㄱ/ㄴ을 뒤집게 된다.

또 전개액 극성을 높이면 Q가 크게 올라가는 것은 맞지만, P도 함께 올라가므로 순서가 역전되지는 않는다(ㄹ).
