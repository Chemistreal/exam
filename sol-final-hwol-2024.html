다음 화학 반응식 중에서 산화-환원 반응이 아닌 것은? (반응식은 렌더 누락)
①
②
③
④

사고과정

선택지 반응식이 원본서 렌더 누락. 산화수 변화가 없는 반응(중화·침전·복분해 등)이 비산화환원. 원본 풀이 기준 ④. → ④

산화-환원은 원자의 산화수가 변하는 반응. 모든 원소의 산화수가 그대로면 비산화환원(예: 중화, 침전).
문제 2반응식 균형(계수 합)정답 ④
구연산(H3C6H5O7)을 베이킹소다(NaHCO3)와 섞으면 기체가 발생한다. 균형 반응식의 계수의 합 a+b+c+d는?
① 4
② 6
③ 8
④ 10

사고과정

H3C6H5O7 + 3NaHCO3 → Na3C6H5O7 + 3CO2 + 3H2O. 계수 1·3·3·3 합 = 10. → ④

구연산은 −COOH 3개라 NaHCO3 3분자와 반응. 각 −COOH가 HCO3⁻와 만나 CO2·H2O를 1개씩 낸다.
문제 3방사 분포 함수(s 오비탈)정답 ③
수소 원자의 s 오비탈 방사 방향 확률 밀도 함수에 대해 옳은 것은? (① 방향 의존 / ② 2s 마디 2개 / ③ 3s 봉우리 3개 / ④ 핵에 가장 가까운 봉우리가 최대)
① 방향에 따라 다르다.
② 2s 방사 마디는 2개이다.
③ 3s 봉우리는 3개이다.
④ 핵에 가장 가까운 봉우리가 가장 크다.

사고과정

③ ns 방사 분포 봉우리는 n개 → 3s는 3개. 옳음. → ③

① s는 구대칭(방향 무관). ② 2s 방사 마디 = n−ℓ−1 = 1개. ④ 최외곽 봉우리가 가장 큼(핵 근처 아님).

방사 방향 확률 밀도(4πr²R²): ns 봉우리 n개, 방사 마디 n−1개. 전자가 가장 많이 발견되는 곳은 가장 바깥 봉우리.
문제 4실험식 결정(포스젠)정답 ②
포스젠(C·O·Cl) 98.8 g에 탄소 12.0 g, 산소 16.0 g이 존재한다. 실험식은? (원자량 C 12·O 16·Cl 35.5)
① CO2Cl6
② COCl2
③ C2O2Cl4
④ COCl

사고과정

Cl = 98.8 − 12.0 − 16.0 = 70.8 g. 몰: C = 12/12 = 1, O = 16/16 = 1, Cl = 70.8/35.5 = 2. C:O:Cl = 1:1:2 → COCl2. → ②

질량 차로 Cl 질량을 구한 뒤 각 원자량으로 나눠 몰비. 최소 정수비가 실험식이다.
문제 5알칼리 금속 반응(부당한 것)정답 ④
알칼리 금속 반응식 중 타당하지 않은 것은? (① 2Na+H2→2NaH / ② 4Li+O2→2Li2O / ③ 2Na+2H2O→2NaOH+H2 / ④ Cs+Cl2→CsCl2)
① 2Na+H2→2NaH
② 4Li+O2→2Li2O
③ 2Na+2H2O→2NaOH+H2
④ Cs+Cl2→CsCl2

사고과정

④ Cs는 1족이라 +1 이온 → 염화물은 CsCl. CsCl2는 Cs²⁺를 요구해 불가능. 부당. → ④

①(수소화물)·②(Li₂O)·③(물과 반응)은 타당.

알칼리 금속은 항상 +1 이온. 할로젠과는 1:1(MX) 화합물을 만든다(CsCl2 같은 +2 화합물 없음).
문제 6전이 금속 전자배치정답 ②
전이 금속(이온)의 바닥상태 전자배치로 옳은 것은? (① Cr=[Ar]4s²3d⁴ / ② Zn²⁺=[Ar]3d¹⁰ / ③ Fe³⁺=[Ar]4s²3d³ / ④ Cu⁺=[Ar]4s¹3d⁹)
① Cr [Ar]4s²3d⁴
② Zn²⁺ [Ar]3d¹⁰
③ Fe³⁺ [Ar]4s²3d³
④ Cu⁺ [Ar]4s¹3d⁹

사고과정

② Zn²⁺: Zn([Ar]3d¹⁰4s²)이 4s² 잃음 → [Ar]3d¹⁰. 옳음. → ②

① Cr=[Ar]4s¹3d⁵(반쯤 채움). ③ Fe³⁺=[Ar]3d⁵. ④ Cu⁺=[Ar]3d¹⁰.

전이 금속 이온은 4s 전자를 먼저 잃는다. Cr·Cu는 반쯤·꽉 채운 d의 안정성으로 4s¹ 배치를 가진다.
문제 7유효 핵전하(관련 적은 것)정답 ④
'유효 핵전하'와 관련이 가장 적은 것은? (① 순차 이온화E 증가 / ② 같은 주기 반지름 감소 / ③ 같은 주기 제1이온화E 증가 / ④ 같은 족 반지름 증가)
① 순차적 이온화 에너지는 점차 증가한다.
② 같은 주기 원자번호↑일수록 반지름↓.
③ 같은 주기 원자번호↑일수록 제1이온화E↑.
④ 같은 족 원자번호↑일수록 반지름↑.

사고과정

④ 같은 족 반지름 증가는 전자껍질(주양자수) 증가가 주원인. 유효 핵전하는 족 아래로 거의 일정 → 관련 가장 적음. → ④

①·②·③은 같은 주기에서 유효 핵전하 증가의 직접 결과.

같은 주기: 껍질 같고 Z_eff 증가 → 반지름↓·이온화E↑. 같은 족: 껍질 수가 늘어 반지름↑(Z_eff 변화는 부차적).

브로민이 ⁷⁹Br:⁸¹Br = 1:1로 존재할 때 Br2의 평균 분자량에 가장 가까운 값은?
① 159
② 160

문제 9쌍극자 모멘트 비교정답 ②
H2S, H2O, CO2의 쌍극자 모멘트 크기를 옳게 비교한 것은?
① H2S>H2O>CO2
② H2O>H2S>CO2
③ H2O>CO2>H2S
④ CO2>H2O>H2S

사고과정

CO2는 직선형이라 쌍극자 0(무극성). H2O·H2S는 굽은 형이나 O가 S보다 전기음성도 커 H2O가 큼. → H2O > H2S > CO2 → ②

대칭 직선형(CO2)은 결합 쌍극자가 상쇄돼 0. 굽은 분자는 전기음성도 차가 클수록 쌍극자가 크다.
문제 10혼성 오비탈(다른 것)정답 ③
원자가 결합 이론으로 설명할 때 중심 원자의 혼성 오비탈 종류가 다른 것은?
① CH4
② H2O
③ SF4
④ NH3

사고과정

CH4·H2O·NH3는 모두 전자 영역 4개 → sp³. SF4는 결합 4 + 고립쌍 1 = 5영역 → sp³d(다름). → ③

중심 원자의 전자 영역 수가 혼성을 결정: 4개 sp³, 5개 sp³d, 6개 sp³d². 고립쌍도 영역에 포함된다.
문제 11무극성 분자 짝정답 ①

② CO2, SO2
③ PCl3, PCl5

문제 12결합각 순서정답 ③
결합각을 순서대로 바르게 나열한 것은? (가. N2H2의 ∠H-N-N / 나. PCl6⁻의 ∠Cl-P-Cl / 다. ICl2⁻의 ∠Cl-I-Cl)

② 가<다<나
③ 나<가<다
④ 다<나<가

문제 13혼성 오비탈(스로비드)정답 ①
코로나 치료제 분자의 탄소 A~D의 혼성 오비탈을 바르게 표기한 것은? (A: CF3 탄소 / B: 카보닐 탄소 / C: 고리 탄소 / D: 나이트릴(C≡N) 탄소)
① A sp³·B sp²·C sp³·D sp
② A sp²·B sp³·C sp³·D sp³
③ A sp³·B sp²·C sp³·D sp³
④ A sp³·B sp²·C sp·D sp²

사고과정

A(CF3, 단일결합 4개) sp³, B(C=O 카보닐) sp², C(단일결합 탄소) sp³, D(C≡N 나이트릴) sp. → ①

혼성은 σ결합+고립쌍 수로 결정: 단일결합만(4개)이면 sp³, 이중결합 포함이면 sp², 삼중결합(나이트릴)이면 sp.
문제 14N-O 결합 길이정답 ①
N-O 결합 길이를 순서대로 바르게 나열한 것은?
① NO⁺ < N2O4 < NO3⁻
② NO⁺ < NO3⁻ < N2O4
③ NO3⁻ < NO⁺ < N2O4
④ N2O4 < NO⁺ < NO3⁻

사고과정

결합차수: NO⁺(N≡O⁺, 3) > N2O4(~1.5) > NO3⁻(~1.33). 결합차수 클수록 짧음 → 길이 NO⁺ < N2O4 < NO3⁻. → ①

결합 길이는 결합차수에 반비례. NO⁺는 삼중결합, 공명 화학종은 결합차수가 분산돼 더 길다.
문제 15염소 불균등화정답 ④
염기성 용액에 염소 기체가 용해될 때 일어나는 산화-환원 반응식의 균형을 맞출 때 a+b+c+d는?
① 9
② 11
③ 13
④ 15

사고과정

Cl2의 불균등화(뜨거운 염기): 3Cl2 + 6OH⁻ → 5Cl⁻ + ClO3⁻ + 3H2O. 계수 3·6·5·1 합 = 15. → ④

불균등화는 한 원소가 동시에 산화·환원. 염소는 0가에서 −1(Cl⁻)과 +5(ClO3⁻)로 나뉜다.
문제 16적정·반당량점 pKb정답 ②
0.100M 약염기 50.0 mL를 0.100M HCl로 적정해 HCl 25.0 mL 가했을 때 pH가 10.0이었다. 이 약염기의 pKb는?
① 1
② 4
③ 7
④ 10

사고과정

HCl 2.5 mmol = 염기 5.0 mmol의 절반 → 반당량점([B]=[BH⁺]). 여기서 pOH = pKb. pH 10.0 → pOH 4.0 = pKb. → ②

반당량점에서 짝산·짝염기 농도가 같아 pOH=pKb(헨더슨-하셀바흐). 약염기 적정의 핵심 지점.
문제 17한계 반응물(A+3B→2C)정답 ③
A + 3B → 2C. A를 a mol, B를 b mol 반응시켜 완결됐을 때 옳은 설명은? (④ A가 한계면 남은 B는 (b−a) mol)
① B 한계 관련
② B 한계 시 C양
③ A 한계 관련 (옳음)
④ A 한계면 남은 B=(b−a)

사고과정

④ A가 한계면 A(a)가 다 반응, B 소모 = 3a(1:3), 남은 B = b−3a(b−a 아님). 틀림. 옳은 설명은 ③. → ③

계수비 1:3:2를 정확히 적용. A 1몰당 B 3몰 소모·C 2몰 생성. 잔여 B는 b−3a다.
문제 18용액 혼합 농도정답 ③
용질이 같은 0.10M 수용액 20.0 mL와 0.20M 수용액 30.0 mL를 섞은 혼합 수용액의 농도(M)는?

같은 용질 혼합은 총 몰수를 총 부피로 나눈다(가법). 부피 가산 가정.
문제 19과망가니즈산 적정정답 ①
산성에서 MnO4⁻이 Fe²⁺를 Fe³⁺로 산화. 0.10M Fe²⁺ 20.0 mL의 Fe²⁺를 모두 산화시키는 데 필요한 0.10M MnO4⁻의 부피(mL)는?

② 8
③ 12
④ 16

문제 20산화-환원 식별정답 ②
산화-환원 반응이 아닌 것은? (① Zn+염산→H2 / ② 식초+베이킹소다→CO2 / ③ 철 녹 / ④ 광합성)
① 아연을 염산에 넣으면 H2 발생.
② 식초에 베이킹소다 넣으면 CO2 발생.

② 식초(CH3COOH)+베이킹소다(NaHCO3)는 산-염기 반응(산화수 불변) → 비산화환원. → ②

①(Zn 산화·H 환원)·③(Fe 산화)·④(C 환원·O 산화)은 모두 산화-환원.

기체 발생이 곧 산화환원은 아니다. 약산+탄산수소염은 전자 이동 없는 중화·분해 반응이다.
문제 21연소 분석(알 수 있는 것)정답 ②
C·H 화합물 x g을 완전 연소해 H2O y g, CO2 z g을 얻었다. 알 수 있는 것은? (가. 반응한 O2 질량 / 나. 탄소 질량 백분율 / 다. 화합물 1몰의 탄소 원자 수)
① 가
② 가, 나
③ 나, 다
④ 가, 나, 다

사고과정

가 O2 질량 = (y+z)−x(질량 보존). 나 C 질량 = (12/44)z → 백분율 = /x. 둘 다 가능.

다 화합물 1몰당 C 수는 분자식(몰질량) 필요한데 질량만으론 못 구함(실험식 비율만 가능). → 가, 나 → ②

질량 자료로 실험식·질량%는 구하나 분자식은 몰질량이 따로 있어야 확정. x는 질량이지 몰수가 아니다.
문제 22완충용액 식별정답 ④
두 수용액을 같은 부피로 섞을 때 완충용액으로 가장 적당한 것은?
① 0.10M NH3 + 0.10M HCl
② 0.10M NH4⁺ + 0.10M KOH
③ 0.20M NH3 + 0.10M KOH
④ 0.20M NH3 + 0.10M HCl

약산 HA(Ka=1.0×10⁻⁵)·짝염기 A⁻ 완충 용액 중 pH=5.0인 것은? (가. 0.1M HA 20mL+0.1M NaA 20mL / 나. 0.2M HA 20mL+0.1M NaOH 20mL / 다. 0.4M NaA 10mL+0.1M HCl 20mL)
① 가, 나
② 가, 다
③ 나, 다
④ 가, 나, 다

사고과정

pH = pKa + log([A⁻]/[HA]), pKa=5.0이라 [A⁻]=[HA]면 pH 5.0. 가 2.0:2.0. 나 4.0−2.0=2.0 HA : 2.0 A⁻. 다 4.0−2.0=2.0 A⁻ : 2.0 HA. 셋 다 동일량. → ④

강염기는 HA를 A⁻로, 강산은 A⁻를 HA로 전환. 절반씩 전환하거나 등량 혼합하면 [A⁻]=[HA]가 된다.
문제 46치환 효과(산·염기 세기)정답 ③
H2O2(물의 H 하나가 OH로 치환)·하이드라진 H2NNH2(암모니아 H 하나가 NH2로 치환). 옳은 것은?
① pKa(H2O)>pKa1(H2O2), pKb(NH3)>pKb1(하이드라진)
② pKa(H2O)<pKa1(H2O2), pKb(NH3)>pKb1
③ pKa(H2O)>pKa1(H2O2), pKb(NH3)<pKb1
④ pKa(H2O)<pKa1(H2O2), pKb(NH3)<pKb1

사고과정

H2O2는 인접 O가 짝염기를 안정화 → H2O보다 강산(pKa↓) → pKa(H2O) > pKa1(H2O2).

하이드라진은 두 번째 NH2가 전자 밀도를 끌어 NH3보다 약염기(pKb↑) → pKb(NH3) < pKb1(하이드라진). → ③

전기음성 치환기(OH·NH2)는 인접 결합의 전자를 끌어당김. 산성은 강해지고(짝염기 안정), 염기성은 약해진다(고립쌍 밀도↓).
문제 47농도차 전지정답 ①
농도차 전지 [A: Cu+1.0M CuSO4 / B: Cu+0.01M CuSO4], Cu²⁺+2e⁻⇌Cu. 옳은 것은? (가. A서 환원 / 나. 초기 기전력 (0.34−0.0592×…) / 다. 진행 중 기전력 불변)
① 가
② 가, 나
③ 나, 다
④ 가, 나, 다

사고과정

가 진한 쪽 A(1.0M)가 환원극(환원). 옳음. → ①

나 농도차 전지는 E°=0(같은 전극)이라 0.34 항이 없음. 기전력 = (0.0592/2)log(1.0/0.01) = 0.0592 V. 다 진행되며 농도가 같아져 기전력 감소.

농도차 전지: 진한 쪽=환원극, 묽은 쪽=산화극. 표준 전위는 상쇄(E°=0)되고 농도 비만 기전력을 만든다.
문제 48전기분해(패러데이)정답 ①
황산구리 수용액 전기분해((+)극 O2, (−)극 Cu). 0.965A로 200초 전기분해 시 각 전극 생성물 질량(g)은? (Cu 63.5, O 16, F=96500)
① Cu 0.0635, O 0.016
② Cu 0.0635, O 0.032
③ Cu 0.1270, O 0.032
④ Cu 0.1270, O 0.064

사고과정

Q = 0.965×200 = 193 C → 전자 = 193/96500 = 0.002 mol. (−)극 Cu²⁺+2e⁻→Cu: Cu = 0.002/2 = 0.001 mol → 0.0635 g.

(+)극 2H2O→O2+4H⁺+4e⁻: O2 = 0.002/4 = 0.0005 mol → 0.0005×32 = 0.016 g. → ①

전하량 Q=It → 전자 몰수 Q/F. 반쪽 반응의 전자 계수로 나눠 생성물 몰수(Cu는 ÷2, O2는 ÷4).
문제 49평형 이동(피스톤)정답 ①
정압 피스톤 내 발열 평형 반응(반응물 기체 몰수가 더 많음)에서 평형이 역반응 쪽으로 이동하는 변화는? (가. 온도↑ / 나. NO 첨가 / 다. Ar 첨가 / 라. 부피 절반으로 압축)
① 가, 다
② 가, 라
③ 나, 다
④ 나, 라

사고과정

가 발열이라 온도↑ → 역반응. 다 정압서 Ar 첨가 → 부피↑·분압↓ → 기체 몰수 많은 반응물쪽(역반응). → ①

나 반응물 NO 첨가 → 정반응. 라 압축(압력↑) → 몰수 적은 생성물쪽(정반응).

정압에서 불활성 기체 첨가는 부피를 늘려 분압을 낮추므로 몰수 많은 쪽으로 이동. 정적이면 영향 없다(주의).
문제 50염 가수분해 pH정답 ③
0.01M 락트산 소듐(CH3CH(OH)COONa) 수용액의 pH는? (락트산 Ka=1×10⁻⁴)
① 3
② 6
③ 8
④ 11

사고과정

약산의 짝염기 A⁻ 가수분해: Kb = Kw/Ka = 10⁻¹⁴/10⁻⁴ = 10⁻¹⁰. [OH⁻] = √(10⁻¹⁰×0.01) = 10⁻⁶ → pOH 6 → pH 8. → ③

강염기+약산의 염은 염기성. 짝염기의 Kb로 [OH⁻]=√(Kb·C)를 구한 뒤 pH로 환산한다.
문제 51금속 결정(구리)정답 ②
구리 금속(ABC 3층 밀집 배열)에 대해 옳은 것은? (가. 면심 입방 / 나. 가장 가까운 이웃 8 / 다. 단위 세포당 원자 2 / 라. 입방계 최대 채움 밀집 충진)

② 가, 라
③ 나, 다

구리는 FCC(입방 최밀): 가 면심 입방. 라 입방계 최대 채움(74%). 옳음. → ②

나 배위수 12(8 아님). 다 단위 세포당 원자 4개(2 아님).

문제 52착이온([Co(en)3]³⁺)정답 ④
착이온 [Co(en)3]³⁺(en=에틸렌다이아민)에 대해 옳은 것은? (가. 배위수 3 / 나. 킬레이트 리간드 / 다. 거울상이성질체 존재)
① 가
② 나
③ 가, 다
④ 나, 다

사고과정

en은 두 자리(N 2개) 리간드. 나 킬레이트 리간드 맞음. 다 tris-킬레이트 팔면체라 Δ·Λ 거울상이성질체 존재. → ④

문제 53반도체정답 ②
반도체 설명 중 옳은 것은? (가. p형 주된 운반체는 전자 / 나. Si에 P 도핑하면 p형 / 다. p-n 접합은 정류기로 사용)
① 가
② 다
③ 가, 나
④ 나, 다

사고과정

다 p-n 접합은 한 방향만 전류 → 정류기(다이오드). 옳음. → ②

문제 54기하 이성질체·산화수정답 ②
팔면체 K[Co(NH3)2Cl4]의 기하 이성질체 개수와 중심 금속 Co의 산화수가 바르게 짝지어진 것은?
① 2, +2
② 2, +3
③ 3, +2
④ 3, +3

사고과정

산화수: K(+1), 착이온 −1, Cl⁻ 4개(−4), NH3 중성 → Co = +3. MA2B4 팔면체는 시스·트랜스 2개. → ②

문제 55라울 법칙(기-액)정답 ①
순수 A·B의 증기압이 600·200 torr. 혼합 용액과 평형인 증기에서 A의 몰분율이 0.5이면, 액체 혼합물에서 A의 몰분율은? (이상 용액·이상 기체)
① 0.25
② 0.40
③ 0.50
④ 0.75

사고과정

yA = PA/P전체 = 600x/(600x+200(1−x)) = 600x/(400x+200) = 0.5 → 600x = 200x+100 → 400x = 100 → xA = 0.25. → ①

라울 법칙: PA=xA(액)·PA°. 증기 몰분율 y는 분압비. 증기압 큰 A가 증기에 농축돼 y>x가 된다.

① −790
② −870
③ −1120
④ −1200

사고과정

ΔH = 150 + 740 + 1450 + 160 + 2(−330) + (−2960) = 150+2190+160−660−2960 = −1120 kJ/mol. → ③

문제 57전위 조합(ΔG)정답 ④
Cu²⁺+2e⁻→Cu E°=0.34V, Cu²⁺+e⁻→Cu⁺ E°=0.16V일 때, Cu⁺+e⁻→Cu의 E°(=a V)는?
① −0.18
② +0.18
③ +0.50
④ +0.52

사고과정

ΔG로 결합(전위는 직접 더하면 안 됨): −1F·a = −2F(0.34) − (−1F(0.16)) → a = 2(0.34) − 0.16 = 0.52 V. → ④

전자 수가 다른 반쪽 반응은 E°를 직접 더할 수 없고, ΔG°=−nFE°로 환산해 더한 뒤 다시 전위로 푼다.

문제 59약산 해리율·pH정답 ④
