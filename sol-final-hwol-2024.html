문제 1산화환원판단정답 ④

사고과정

산화수가 변하는지 본다.

① 은 연소, ② 는 K 가 Br2 에 전자를 주는 반응, ③ 은 P 가 +5 로 오르는 반응이라 모두 산화-환원이다.

④ 는 Zn(OH)2 가 가라앉는 앙금 생성으로 이온이 자리만 바꿀 뿐 산화수가 그대로다.

→ ④

문제 2계수맞추기정답 ④

사고과정

H3C6H5O7 + 3NaHCO3 → Na3C6H5O7 + 3CO2 + 3H2O.

계수 1·3·3·3 합 = 10.

→ ④

구연산은 −COOH 3개라 NaHCO3 3분자와 반응. 각 −COOH가 HCO3-와 만나 CO2·H2O를 1개씩 낸다.
문제 3오비탈정답 ③

사고과정

③ ns 방사 분포 봉우리는 n개 → 3s는 3개. 옳음. → ③

① s는 구대칭(방향 무관). ② 2s 방사 마디 = n−ℓ−1 = 1개. ④ 최외곽 봉우리가 가장 큼(핵 근처 아님).

방사 방향 확률 밀도(4πr²R²): ns 봉우리 n개, 방사 마디 n−1개. 전자가 가장 많이 발견되는 곳은 가장 바깥 봉우리.
문제 4실험식정답 ②

사고과정

Cl = 98.8 − 12.0 − 16.0 = 70.8

g. 몰: C = 12/12 = 1, O = 16/16 = 1, Cl = 70.8/35.5 = 2.

C:O:Cl = 1:1:2 → COCl2.

→ ②

질량 차로 Cl 질량을 구한 뒤 각 원자량으로 나눠 몰비. 최소 정수비가 실험식이다.
문제 5알칼리금속정답 ④

사고과정

④ Cs는 1족이라 +1 이온 → 염화물은 CsCl. CsCl2는 Cs²⁺를 요구해 불가능. 부당. → ④

①(수소화물)·②(Li₂O)·③(물과 반응)은 타당.

알칼리 금속은 항상 +1 이온. 할로젠과는 1:1(MX) 화합물을 만든다(CsCl2 같은 +2 화합물 없음).
문제 6전자배치정답 ②

사고과정

② Zn²⁺: Zn([Ar]3d¹⁰4s²)이 4s² 잃음 → [Ar]3d¹⁰. 옳음. → ②

① Cr=[Ar]4s¹3d⁵(반쯤 채움). ③ Fe³⁺=[Ar]3d⁵. ④ Cu⁺=[Ar]3d¹⁰.

전이 금속 이온은 4s 전자를 먼저 잃는다. Cr·Cu는 반쯤·꽉 채운 d의 안정성으로 4s¹ 배치를 가진다.
문제 7유효핵전하정답 ④

①·②·③은 같은 주기에서 유효 핵전하 증가의 직접 결과.

같은 주기: 껍질 같고 Z_eff 증가 → 반지름↓·이온화E↑. 같은 족: 껍질 수가 늘어 반지름↑(Z_eff 변화는 부차적).

문제 9쌍극자모멘트정답 ②

사고과정

CO2는 직선형이라 쌍극자 0(무극성).

H2O·H2S는 굽은 형이나 O가 S보다 전기음성도 커 H2O가 큼.

→ H2O > H2S > CO2

→ ②

대칭 직선형(CO2)은 결합 쌍극자가 상쇄돼 0. 굽은 분자는 전기음성도 차가 클수록 쌍극자가 크다.
문제 10혼성오비탈정답 ③

사고과정

CH4·H2O·NH3는 모두 전자 영역 4개 → sp3.

SF4는 결합 4 + 고립쌍 1 = 5영역 → sp3d(다름).

→ ③

중심 원자의 전자 영역 수가 혼성을 결정: 4개 sp3, 5개 sp3d, 6개 sp3d2. 고립쌍도 영역에 포함된다.
문제 11분자의극성정답 ①

사고과정

① XeF4(평면 사각)·SiF4(정사면체) 모두 대칭 → 무극성. → ①

② SO2(굽은형, 극성). ③ PCl3(삼각뿔, 극성). ④ SF4(시소형, 극성).

대칭 구조(직선·평면 사각·정사면체·삼각쌍뿔)는 결합 쌍극자가 상쇄돼 무극성. 고립쌍으로 비대칭이면 극성.

문제 13혼성오비탈정답 ①

문제 14결합길이정답 ①

결합 길이는 결합차수에 반비례. NO+는 삼중결합, 공명 화학종은 결합차수가 분산돼 더 길다.
문제 15산화환원계수맞추기정답 ④

불균등화는 한 원소가 동시에 산화·환원. 염소는 0가에서 −1(Cl-)과 +5(ClO3-)로 나뉜다.
