반응 지수 Q와 평형 예측

076 · 화학 평형읽는 데 약 7분
‹ 파이널로
이번 진단에서 반응 지수 Q · 평형 방향 예측이 보강으로 잡혔어. 이 1강을 끝까지 읽고 직접 해보기까지. 현재 상태가 어느 쪽으로 갈지 예측하는 도구야. "Q<K면 정반응, Q>K면 역반응, Q=K면 평형"이 핵심이야.

자, K는 평형에서의 값이었지(074~075). 그런데 아직 평형이 아닌 상태에서 "이 반응이 앞으로 어느 쪽으로 갈까?"를 알고 싶을 때가 있어. 그때 쓰는 게 반응 지수 Q야. K와 똑같은 식인데, 평형이 아닌 임의의 순간 농도로 계산한 값이지. 이 Q를 K와 비교하면, 반응이 정반응으로 갈지 역반응으로 갈지 예측할 수 있어. 오늘은 Q의 정의와, Q·K 비교로 방향을 판단하는 법을 잡을 거야.

01반응 지수 Q · K와 같은 식, 임의의 순간

반응 지수(Q)는 K와 완전히 같은 식이야(생성물/반응물, 계수가 지수). 차이는 딱 하나, 평형이 아닌 임의의 순간 농도로 계산한다는 거지. K가 "평형에서의 값"이라면, Q는 "지금 이 순간의 값"이야.

Q = K와 똑같은 식(생성물/반응물, 계수가 지수)을 임의의 순간 농도로 계산한 값. K는 평형에서의 값, Q는 현재 상태의 값이야. 그래서 Q와 K를 비교하면 현재 상태가 평형에서 얼마나 벗어나 있는지, 어느 쪽으로 가야 평형이 되는지를 알 수 있어.
02Q와 K 비교 · 방향 예측

Q를 K와 비교해서 반응 방향을 판단해. 직관은 단순해. Q가 K가 되려고 반응이 움직이는 거야.

비교현재 상태반응 방향
Q < K생성물이 부족정반응(→, 오른쪽)
Q = K평형변화 없음
Q > K생성물이 과잉역반응(←, 왼쪽)

Q < K면 아직 생성물이 평형보다 부족하다는 뜻이라, 생성물을 더 만들려고 정반응이 진행돼. Q > K면 생성물이 평형보다 많아서, 되돌리려고 역반응이 진행되고. Q = K면 이미 평형이라 변화가 없어. Q를 K에 맞추는 방향으로 움직인다고 보면 돼.

Q < K → 정반응  |  Q = K → 평형  |  Q > K → 역반응
03예제 · 방향 판단
예제 어떤 반응의 K = 16인데, 지금 농도로 Q를 계산했더니 Q = 4였어. Q(4) < K(16)이니 생성물이 부족한 상태야. 그래서 정반응이 진행되어 생성물이 늘고 Q가 커지다가, Q = K = 16이 되면 평형에 도달해. 반대로 Q = 30이었다면 Q > K라 역반응이 일어나 Q가 줄어 16에 맞춰지지.
함정 · Q와 K 비교 방향을 거꾸로
방향을 헷갈리기 쉬워. Q < K면 생성물이 부족하니 더 만들어야 해서 정반응(오른쪽), Q > K면 생성물이 많으니 되돌려야 해서 역반응(왼쪽)이야. "작으면(Q<K) 오른쪽으로 키우고, 크면(Q>K) 왼쪽으로 줄인다"로 기억해. Q가 K를 향해 움직인다는 직관을 잡으면 안 헷갈려. 그리고 Q와 K는 같은 식이라는 점도 기억해(농도만 평형이냐 아니냐 차이).
04한 장 정리와 다음 연결

오늘 들고 갈 한 문장.

"Q는 임의 순간의 K식 값 · Q<K 정반응, Q>K 역반응 · Q는 K를 향해 움직인다."

반응 지수 Q는 K와 같은 식을 임의의 순간 농도로 계산한 값이야. Q<K면 생성물 부족이라 정반응, Q>K면 생성물 과잉이라 역반응, Q=K면 평형이지. 반응은 Q가 K에 맞춰지는 방향으로 진행돼.

이걸로 073~076, 즉 평형의 기본(동적 평형·K·Q)이 다 갖춰졌어. 다음 강(077 르샤틀리에 원리)부터 후반부에서는 평형에 자극(농도·압력·온도 변화)을 줬을 때 평형이 어떻게 이동하는지를 다뤄. 평형을 흔들면 그 흔듦을 줄이는 방향으로 스스로 이동하거든. 오늘의 Q·K 비교가 그 이동을 이해하는 바탕이야. 평형의 기본을 들고, 평형 이동으로 넘어가자.

✓확인 문제

방금 배운 것으로 풀 수 있는 3문항입니다. 답을 고르면 해설이 열립니다 — 먼저 스스로 고르고 나서 보세요.

1. 반응 초기에 생성물만 넣고 시작하면 Q 와 K 의 관계는?
정답 ③

분모에 반응물이 없어 Q 가 무한히 크므로 반응은 되돌아간다. → ③

자주 걸리는 자리 Q 가 크면 정반응이 잘 간다고 여긴다. Q 가 크다는 것은 생성물이 이미 많다는 뜻이다.
2. 298 K의 수용액에서 일어나는 반응 A(aq) ⇌ B(aq)의 표준 자유 에너지 변화는 ΔG° = +5.40 kJ/mol이다. 어느 순간 이 용액에서 [A] = 1.0 M, [B] = 1.0×10⁻² M이어서 반응 지수는 Q = [B]/[A] = 1.0×10⁻²이었다. 이 순간의 ΔG 값과 반응이 저절로 진행되는 방향을 옳게 짝지은 것은? (R = 8.314 J/(mol·K), ln 10 = 2.303)
정답 ③

ΔG = ΔG° + RT ln Q이다. RT = 8.314 × 298 = 2.478×10³ J/mol = 2.478 kJ/mol, ln Q = ln(1.0×10⁻²) = −2 × 2.303 = −4.606이므로 RT ln Q = 2.478 × (−4.606) = −11.41 kJ/mol. 따라서 ΔG = +5.40 + (−11.41) = −6.01 ≈ −6.0 kJ/mol. ΔG < 0이므로 이 순간에는 정반응이 자발적이다. ΔG°가 양수여도 Q가 K보다 작으면(여기서 K = exp(−ΔG°/RT) = 0.113 > Q = 0.010) 정반응이 진행된다.

자주 걸리는 자리 ΔG°의 부호만 보고 진행 방향을 판단하거나, RT ln Q 항의 부호를 잘못 붙인다.
3. 일정한 온도 T에서 X(g) ⇌ Y(g) + Z(g) 반응이 평형에 도달했을 때 농도를 측정하니 [X] = 0.20 M, [Y] = 0.30 M, [Z] = 0.40 M이었다. 같은 온도 T에서 이번에는 [X] = 0.10 M, [Y] = 0.50 M, [Z] = 0.60 M이 되도록 세 기체를 넣었다. 이 새로운 계에서 일어나는 변화로 옳은 것은?
정답 ①

먼저 첫 번째 평형 자료에서 평형상수를 구한다. K = [Y][Z]/[X] = (0.30 × 0.40)/0.20 = 0.120/0.20 = 0.60. 다음으로 새 조건의 반응지수를 구한다. Q = (0.50 × 0.60)/0.10 = 0.300/0.10 = 3.0. Q(3.0) > K(0.60)이므로 생성물이 과잉이며, 계는 Q를 K까지 낮추는 방향, 즉 역반응 쪽으로 진행하여 Y와 Z가 줄고 X가 늘어난다.

자주 걸리는 자리 Q와 K의 대소는 맞게 비교하고도 '큰 쪽으로 더 간다'며 진행 방향을 반대로 잡는 것.
