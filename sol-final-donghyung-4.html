문제 1반데르발스식정답 ④

사고과정

반데르발스 상수 b 는 분자 자체가 차지하는 부피를 보정하는 값이라 분자가 클수록 크다.

보기 중 가장 큰 것은 벤젠(C₆H₆)이다.

→ ④

문제 2분자의구조정답 ②

사고과정

① 넷 다 비공유 전자쌍이 있어 굽은형이다(옳음).

② H₂S 의 결합각은 약 92° 로 H₂O(104.5°)보다 작다 → 틀림.

③ OF₂ 의 O 는 +2, H₂O 의 O 는 −2 다(옳음).

④ 수소 결합을 하는 H₂O 가 가장 높다(옳음).

→ ②

문제 3PV=nRT정답 ③

사고과정

C₂H₃Cl 125 g ÷ 62.5 = 2 mol.

T = PV/nR = (1 × 100)/(2 × 0.082) ≈ 610 K, 곧 약 337 °C 다.

→ ③

문제 4결합에너지정답 ②

사고과정

두 분자는 C₆H₁₂ 로 같으므로 연소 생성물도 같다.

차이는 결합에서만 온다 — 헥센은 C−C 4개와 C=C 1개(4×348+615 = 2007), 사이클로헥세인은 C−C 6개(6×348 = 2088)다.

차이는 81 kJ.

→ ②

문제 5이온반지름정답 ①

사고과정

Te²⁻·I⁻ 는 전자 54개(Xe 배치), Rb⁺·Sr²⁺ 는 36개(Kr 배치)라 뒤엣것이 훨씬 작다.

각 짝 안에서는 양성자가 많을수록 작으므로 Sr²⁺ < Rb⁺, I⁻ < Te²⁻ 다.

→ ①

문제 6분자의모양정답 ①

사고과정

COCl₂ 평면삼각, XeO₃ 삼각뿔, SF₆ 팔면체, XeF₄ 평면사각, ICl₂⁻·CO₂·NO₂⁺ 직선이다.

직선형이 셋으로 가장 많다.

→ ①

문제 7완충용액의pH정답 ③

사고과정

산과 짝염기의 농도가 같으면 pH = pKa 다.

보기의 pKa 는 HF 3.2, HClO 7.5, HClO₂ 2.0, HBrO₂ 약 4 이므로 가장 작은 것은 HClO₂ 쪽이다.

→ ③

문제 8혼합물정답 ④

사고과정

순물질과 혼합물은 **분자 종류가 몇 가지인가**로 가른다.

Ⅰ 은 같은 이원자 분자 둘, Ⅱ 도 같은 이원자 분자 둘, Ⅲ 은 같은 화합물 분자 둘이라 모두 순물질이다.

Ⅳ 만 서로 다른 두 분자가 섞여 있어 혼합물이다.

→ ④

문제 9원소분석장치정답 ③

사고과정

실험식 CH₃ 의 식량은 15 이므로 30 g 은 CH₃ 단위 2몰, 곧 탄소 2몰이다.

연소하면 CO₂ 2몰이 나오고 2NaOH + CO₂ → Na₂CO₃ + H₂O 이므로 Na₂CO₃ 도 2몰, 2 × 106 = 212 g.

→ ③

문제 10압력정답 ③

사고과정

열린관에서 기체 쪽 수은이 더 내려가 있으면 기체가 대기압보다 세다.

P = 760 + 380 = 1140 mmHg = 1.5 기압이다.

온도를 올려도 열린관이라 기둥이 다시 균형을 잡아 압력은 그대로다.

→ ③

문제 11화학법칙정답 ①

사고과정

ㄴ 부피비 2:1:2 로 기체 반응의 법칙을, ㄷ 좌우 질량이 같아 질량 보존을, ㄹ 물의 조성이 일정해 일정 성분비를 설명한다.

ㄱ 배수 비례는 같은 두 원소가 **여러 화합물**을 만들 때의 법칙이라 이 식 하나로는 설명할 수 없다.

→ ①

문제 12몰과양적관계정답 ②

사고과정

수증기 22.4 L 는 546 K·1기압에서 n = 22.4/(0.082×546) = 0.5 mol 이다.

물 0.5 mol = 9 g 을 빼면 BaCl₂ 는 52 g, 곧 52/208 = 0.25 mol 이다.

x = 0.5/0.25 = 2.

→ ②

문제 13완충용액①·③ 복수정답

사고과정

완충 용액에서 산(NH₄⁺)과 짝염기(NH₃)의 농도가 같으면 헨더슨-하셀바흐 식의 로그 항이 0 이 되어 pH 가 곧 pKa 다.

→ ①

문제 14분자오비탈정답 ②

사고과정

N₂ 는 원자가 전자가 10 개이고 결합 차수가 3 이다.

전자를 더하면 반결합성 π* 에 들어가 차수가 줄고, 빼면 결합성에서 빠져 역시 준다.

N₂⁻ 은 2.5, N₂²⁻ 은 2, N₂⁺ 은 2.5, N₂ 는 3 이다.

가장 작은 것은 N₂²⁻ 다.

→ ②

문제 15분자의극성정답 ③

사고과정

BF₃ 는 평면삼각, BeCl₂ 는 직선, SF₄ 는 시소꼴, SeO₃ 는 평면삼각이다.

대칭이 깨진 SF₄ 만 쌍극자 모멘트가 0 이 아니다.

→ ③

문제 16에너지준위정답 ①

사고과정

수소는 전자가 하나뿐이라 전자 사이 반발이 없다.

그래서 에너지가 오직 주양자수 n 에만 좌우되고, 같은 n 이면 s·p·d·f 가 모두 같다.

→ ①

문제 17반응의자발성정답 ④

사고과정

XeF₆(g) → XeF₄(s) + F₂(g) 로 보면 ΔH = (−251 + 0) − (−294) = +43 kJ, ΔS = (146 + 203) − 300 = +49 J/K 다.

둘 다 양수이므로 높은 온도에서만 자발적이고, 뒤집히는 온도는 43000/49 ≈ 878 K ≈ 605 °C 다.

보기 중 그보다 높은 것은 1000 °C 뿐이다.

→ ④

문제 18전자배치정답 ②

사고과정

탄소는 2s²2p² 다.

2p 의 전자 2개는 훈트 규칙에 따라 서로 다른 오비탈에 같은 방향으로 하나씩 들어간다.

→ ②

문제 19평형상수정답 ④

사고과정

목표 반응을 아는 평형의 합으로 쪼갠다.

H₃A ⇄ H₂A⁻ + H⁺ 는 Ka₁ 이고, A³⁻ + H⁺ ⇄ HA²⁻ 는 셋째 해리를 뒤집은 것이라 1/Ka₃ 다.

더했으므로 K = Ka₁/Ka₃ = 10⁻³/10⁻⁸ = 10⁵ 이다.

보기가 Kb₁ 으로 적혀 있는데 Kb₁ = Kw/Ka₃ 이므로 Ka₁ × Kb₁ / Kw 가 곧 Ka₁/Ka₃ 다.

→ ④

문제 20용액의총괄성정답 ③

사고과정

어는점은 실제로 녹아 있는 입자의 몰랄농도가 클수록 낮다.

① 포도당 90 g = 0.5 mol → 0.5.

② Ag₂CO₃ 는 난용성이라 거의 녹지 않아 입자를 거의 내지 못한다.

③ HA 0.3 mol 에 해리도 0.8 이면 0.3 × 1.8 = 0.54.

④ 순수한 물은 0.

→ ③

문제 21산의세기③·④ 복수정답

사고과정

① 네 반응 모두 질소의 산화수가 바뀐다(옳음).

② 산화수는 N₂ 의 0 부터 HNO₃ 의 +5 까지다(옳음).

③ NO 와 NO₂ 는 홀전자가 있어 옥텟을 만족하지 못한다 → 틀림.

④ 산소가 더 붙은 HNO₃ 가 더 세므로 pKa 가 작다(옳음).

→ ③

문제 22pH정답 ②

사고과정

Al(H₂O)₆³⁺ 는 약산이고 Ka = 1.4×10⁻⁵, 농도는 7.1 mmol/L = 7.1×10⁻³ M 이다.

[H⁺] = √(1.4×10⁻⁵ × 7.1×10⁻³) ≈ 3.2×10⁻⁴ 이므로 pH ≈ 3.5.

→ ②

문제 23고체의구조정답 ④

사고과정

① Mg²⁺ 의 수화 이온이 약산이라 약산성을 띤다(옳음).

③ Mg 이 Cl 보다 전기음성도가 작다(옳음).

④ 화학식이 MgCl₂ 이므로 Mg 하나에 Cl 이 둘이다.

결정에서 배위수는 그 반대로 Mg²⁺ 쪽이 Cl⁻ 쪽의 2배여야 한다 → 틀림.

→ ④

문제 24몰농도정답 ②

사고과정

몰분율 0.2 이면 NaOH 2몰에 물 8몰이다.

질량 = 2×40 + 8×18 = 224 g, 부피 = 224/1.12 = 200 mL.

몰농도 = 2/0.2 = 10 M.

→ ②

문제 25크로마토그래피정답 ②

사고과정

얼마나 멀리 가느냐의 **순서**를 정하는 것은 고정상이다 — 고정상과 친한 것이 아래, 안 친한 것이 위다.

그래서 전개용매를 바꿔도 A·B·C 의 차례는 그대로다.

용매가 바꾸는 것은 **간격**이다.

물:에탄올을 7:3 에서 3:7 로 바꾸면 극성이 작아져 간격이 좁아진다.

→ ②

문제 26분자의모양정답 ②

사고과정

비공유 전자쌍은 XeCl₂ 가 Xe 3 + Cl 6 = 9개, SF₆ 는 S 0 + F 18 = 18개, H₂CO₃·HNO₃ 는 그보다 적다.

→ ②

문제 27중화반응정답 ②

사고과정

아세트산 0.2×35 = 7.0 mmol, NaOH 0.1×45 = 4.5 mmol 이므로 산 2.5 와 짝염기 4.5 가 남는 완충이다.

pH = pKa + log(4.5/2.5) = 4.74 + 0.26 ≈ 5.

→ ②

문제 28엔탈피정답 ④

사고과정

CH₄ + H₂ 로 C₄H₈ 를 만든다고 보면 가장 많은 열은 반응물이 가장 많이 든 조건에서 난다.

각 보기의 몰수를 견주면 CH₄ 78 g(약 4.9몰)과 H₂ 2몰을 넣은 ③ 이 아니라, 연소열의 합이 가장 큰 조건을 골라야 한다 — CH₄ 1몰과 H₂ 4몰인 ①·② 를 견주면 ② 가 더 많다.

→ ④

문제 29분자간인력정답 ④

① 아세트알데하이드는 극성이지만 수소 결합을 못 하고, ② 에탄올은 −OH 로 수소 결합을 하며, ③ 다이메틸에터는 −OH 가 없어 무극성에 가깝다.

④ 아세트산은 −COOH 로 수소 결합을 하면서 극성도 커 인력이 가장 세다.

→ ④

문제 34운동에너지정답 ②

사고과정

평균 운동에너지는 온도에만 좌우되므로 300 K → 1200 K 이면 4배다.

속력은 √(T/M) 에 비례하는데 T 는 4배, M 은 16 → 64 로 4배이므로 서로 지워져 그대로 v 다.

문제 35pH정답 ③

사고과정

Mg²⁺ 12 mmol 과 OH⁻ 12 mmol 이 만나 Mg(OH)₂ 가 생기며 Mg²⁺ 6 mmol 이 남는다(0.06 M).

[OH⁻] = √(1.8×10⁻¹¹/0.06) ≈ 1.7×10⁻⁵ 이므로 pOH ≈ 4.8, pH ≈ 9.

→ ③

문제 36용액의농도정답 ④

사고과정

용액 110 g(밀도 1.1 이므로 100 mL), NaOH 0.25 mol 이다.

몰농도 = 0.25/0.1 = 2.5, 몰랄농도 = 0.25/0.1 kg = 2.5, % 농도 = 10/110 × 100 ≈ 9.1 이다.
