문제 1화학평형정답 ②

즉시 재도전 화학평형 · 르샤틀리에원리 ← KMChC 2025 제2차 · 일반 14번 르샤틀리에원리 · 난이도 재도전 평형 상수 K 는 평형에서 (생성물의 농도 항)/(반응물의 농도 항) 이므로, K 의 크기는 평형에 도달했을 때 어느 쪽이더 많은지만 알려 준다.

· (가) K = 3.5×1010 >> 1 : 생성물 쪽이 압도적으로 많아 거의 완결되는 반응처럼 보인다.

·(나) K = 1.2 ≈ 1 : 반응물과 생성물이 비슷한 양으로 함께 존재한다.

· (다) K = 4.0×10−8 << 1 : 분모(반응물)가분자(생성물)보다 훨씬 커야 하므로 평형에서 반응물이 훨씬 많다.

2번이 옳다.

1번 : K 는 평형에서의 '양'만 말할 뿐'얼마나 빨리 그 상태에 이르는가'와는 무관하다.

도달 속도는 활성화 에너지와 반응 메커니즘이 정한다.

K 가 아주큰데도 몹시 느린 반응이 있다.

3번 : K 가 1 보다 크다는 것은 생성물이 조금 더 많다는 뜻일 뿐이며, 가역 반응이므로 반응물이 0 이 되는 일은 없다.

K = 1.2 는 오히려 양쪽이 비슷하다는 뜻이다.

4번 : 역반응의 평형 상수는 정반응의 역수이므로 1/(3.5×1010) ≈ 2.9×10−11 로 매우 작다.

오개념 평형 상수는 평형에서 생성물과 반응물의 비를 말할 뿐 반응이 일어나는 속도와는 아무 관계가 없고, 역반응의 평형 상수는 정반응의 역수이다.

그때 왜 틀렸나 약산을 강염기로 적정할 때 전도도가 어떻게 꺾이는지 이온의 종류 변화로 따지지 못함.

문제 2평형상수정답 ②

즉시 재도전 화학평형 · 평형상수 ← 기출동형 1회 46번 평형상수 · 난이도 재도전 B가 1.00 mol 생겼으므로 반응한 A는 1.00 × (1/2) = 0.50 mol.

평형에서 A = 2.00 - 0.50 = 1.50 mol.

부피 5.00L로 나누면 [A] = 0.300 mol/L, [B] = 0.200 mol/L.

Kc = [B]2/[A] = (0.200)2 ÷ 0.300 = 0.0400 ÷ 0.300 =0.133.

오개념 몰수를 그대로 평형 상수에 대입하는 것, 반응한 A를 B의 몰수와 같다고 보는 것, 그리고 계수 2를 지수로 반영하지 않는 것.

그때 왜 틀렸나 오스트발트 희석률(묽히면 해리도가 커진다)을 강염기에도 적용.

그것은 약전해질에서만 뜻이 있다.

문제 3용해도정답 ②

즉시 재도전 화학평형 · 용해도 ← 기출동형 4회 39번 용해도 · 난이도 재도전 몰 용해도 s를 각 염의 화학량론에 맞게 Ksp 식에 대입해야 한다.

(가) MA: Ksp = s × s = s2 = 1.6×10−9 → s =√(1.6×10−9) = 4.0×10−5

M. (검산: (4.0×10−5)2 = 1.6×10−9 ○) (나) MB2: Ksp = s × (2s)2 = 4s3 =3.2×10−11 → s3 = 8.0×10−12 → s = 2.0×10−4

M. (검산: 4 × (2.0×10−4)3 = 4 × 8.0×10−12 = 3.2×10−11 ○)(다) M2C: Ksp = (2s)2 × s = 4s3 = 1.08×10−10 → s3 = 2.7×10−11 → s = 3.0×10−4

M. (검산: 4 × (3.0×10−4)3= 4 × 2.7×10−11 = 1.08×10−10 ○) 따라서 (다) 3.0×10−4 > (나) 2.0×10−4 > (가) 4.0×10−5 이다.

Ksp의 크기순서는 (가) > (다) > (나)로 몰 용해도 순서와 완전히 반대이다.

Ksp를 직접 비교해도 되는 것은 이온 개수 유형이같은 염들끼리뿐이다.

오개념 화학식 유형이 달라도 Ksp가 큰 염이 더 잘 녹는다고 보고, Ksp 값만 크기순으로 늘어놓는다.

그때 왜 틀렸나 공통이온이 있어도 순수한 물에서처럼 √Ksp 로 셈함.

문제 4화학평형정답 ④

즉시 재도전 화학평형 · 평형이동 ← 기출동형 4회 44번 평형이동 · 난이도 재도전 (가) 부피가 일정한 채 Ar만 넣으면 전체 압력은 올라가지만 SO2·O2·SO3의 몰수와 부피가 그대로여서 각각의 분압(농도)이 전혀 변하지 않는다.

Q = K가 유지되므로 평형은 이동하지 않는다.

→ 증가하지 않음 (나) 전체 압력을 일정하게 유지하며 Ar을 넣으려면 용기가 팽창해야 한다.

부피가 커지면 반응에 참여하는 기체들의 분압이 모두 낮아지고, 평형은 기체 몰수가 많은 쪽(왼쪽, 2 + 1 = 3몰 쪽)으로 이동한다.

→ SO3 감소 (다) 정반응이 발열(ΔH < 0)이므로 온도를 낮추면 열을 내놓는 정반응 쪽으로 이동한다.

→ SO3 증가 (라) 부피를 절반으로 줄이면 모든 분압이 2배가 되고, 평형은 기체 몰수가 적은 쪽(오른쪽, 2몰 쪽)으로 이동한다.

→ SO3 증가 따라서 (다)와 (라)이다.

(검산:52 Kp = P(SO3)2 / [P(SO2)2·P(O2)]에서 압축으로 모든 분압이 2배가 되면 분자는 22 = 4배, 분모는 22 × 2 = 8배가 되므로 Q는 처음의 4/8 = 1/2배, 즉 Q = K/2 < K가 되어 정반응이 진행한다.) 오개념 '압력을 올리면 몰수가 적은 쪽으로 이동한다'를 통째로 외워, 비활성 기체를 넣어 전체 압력만 올라간 경우와 부피를 줄여 분압이 올라간 경우를 구별하지 못한다.

그때 왜 틀렸나 부피를 줄이면 압력이 는다고만 여김.

고체가 함께 있는 평형에서는 다시 Kp 로 되돌아간다.

문제 5계수맞추기정답 ③

즉시 재도전 산화환원 · 계수맞추기 ← 기출동형 1회 4번 계수맞추기 · 난이도 재도전 환원 반쪽: Cr2O72− + 14H+ + 6e− → 2Cr3+ + 7H2O (Cr이 +6 → +3, Cr 2개이므로 6e−).

산화 반쪽: H2S → S +2H+ + 2e− (S가 -2 → 0).

전자를 6개로 맞추려면 산화 반쪽에 3을 곱한다: 3H2S → 3S + 6H+ + 6e−.

두 식을 더하면 Cr2O72− + 14H+ + 3H2S → 2Cr3+ + 7H2O + 3S + 6H+ 이고, 양쪽의 H+ 6개를 상쇄하면 Cr2O72− + 3H2S +8H+ → 2Cr3+ + 3S + 7H2O.

검산: 전하 -2 + 8 = +6 = 2(+3), H 6 + 8 = 14 = 7×2, O 7 = 7.

따라서 H+의 계수는 8이다.

오개념 환원 반쪽에 쓴 H+ 14개를 그대로 최종 계수로 쓰거나, 산화 반쪽에서 생기는 H+와 상쇄하는 과정을 빠뜨리는 것.

그때 왜 틀렸나 염기성 조건에서도 H+ 를 그대로 남겨 둠.

산성에서 맞춘 뒤 양쪽에 OH− 를 더해 H+ 를 물로 바꿔야한다.

문제 6산화환원정답 ①

즉시 재도전 산화환원 · 화학전지 ← 기출동형 1회 53번 화학전지 · 난이도 재도전 농도 차이를 줄이는 방향, 즉 묽은 쪽에서 M(s) → M2+ + 2e−(산화로 농도 증가), 진한 쪽에서 M2+ + 2e− → M(s)(환원으로 농도 감소)이 자발적이다.

이때 Q = [M2+](묽은 쪽)/[M2+](진한 쪽) = 0.0010/0.10 = 1.0 × 10−2.

E = 0- (0.0592/2) × log(1.0 × 10−2) = -(0.0296) × (-2) = 0.0592

V. M2+의 전하가 2+이므로 n = 2이다.

오개념 E° = 0이면 기전력도 0이라고 보는 것, 그리고 진한 쪽에서 산화가 일어난다고 방향을 뒤바꾸는 것.

그때 왜 틀렸나 기울기에서 ΔH 를 구할 때 R 을 곱하지 않거나, J 를 kJ 로 고치지 않음.

문제 7전지정답 ③

즉시 재도전 산화환원 · 전지 ← 기출동형 4회 54번 전지 · 난이도 재도전 [E°(전지)] 표준 환원 전위가 큰 쪽이 환원 전극(+극), 작은 쪽이 산화 전극(-극)이다.

E°(전지) = E°(환원 전극) - E°(산화 전극) = (+0.80) - (-0.76) = +1.56

V. 전체 반응을 만들 때 Ag 반쪽 반응에 2를 곱했지만, 전위는 세기 성질(intensive property)이므로 계수를 곱해도 값이 변하지 않는다.

여전히 +0.80 V이다.

[ΔG°] 전체 반응에서 이동한 전자는 Zn → Zn2+ 기준으로 2 mol이므로 n = 2이다.

ΔG° = -nFE° = -2 × 96500 C/mol × 1.56 V = -301080J = -301 kJ.

검산: 96500 × 1.56 = 150540, 150540 × 2 = 301080 J = 301.08 kJ ○ E°(전지) > 0이므로 ΔG° < 0이고, 자발적인 전지 반응이라는 결론과 일치한다.

오개념 반쪽 반응에 계수를 곱하면 표준 전위도 그만큼 커진다고 생각하고, ΔG° = -nFE°의 n을 반쪽 반응 하나의전자 수로 잡는다.

그때 왜 틀렸나 네른스트 식에서 Q 를 세울 때 계수를 지수로 올리지 않거나 n 을 1 로 둠.

문제 8원자모형정답 ③

즉시 재도전 원자모형 · 에너지준위 ← 기출동형 1회 9번 에너지준위 · 난이도 재도전 He+는 Z = 2이므로 Z2 = 4.

ΔE = 13.6 × 4 × (1/22 - 1/32) = 54.4 × (0.2500 - 0.1111) = 54.4 × 0.13889 =7.556 eV.

λ = hc/ΔE = 1.240 × 103 eV·nm ÷ 7.556 eV = 164 nm.

오개념 Z2 인자를 빠뜨려 수소 원자의 값을 그대로 쓰거나, Z를 잘못 거듭제곱하는 것.

문제 9방사성붕괴정답 ③

즉시 재도전 원자모형 · 방사성붕괴 ← 기출동형 1회 60번 방사성붕괴 · 난이도 재도전 12.5 % = 1/8 = (1/2)3이므로 24일은 반감기 3번에 해당하고 반감기는 24 ÷ 3 = 8.0일이다.

남은 비율이 0.050이되려면 (1/2)를 t/8.0번 거듭제곱한 값이 0.050이어야 하므로 t/8.0 = log(1/0.050) ÷ log 2 = log 20 ÷ log 2 = (1+ 0.301) ÷ 0.301 = 4.32.

따라서 t = 8.0 × 4.32 = 34.6일.

오개념 반감기를 24일 자체로 보거나, 남은 비율이 반감기의 정수배에서만 계산된다고 보아 6.25 %(4번)나 3.125%(5번)에 해당하는 시간으로 근사해 버리는 것.

그때 왜 틀렸나 중성자와 양성자 중 어느 쪽이 남는지 보지 않고 붕괴 방식을 고름.

양성자가 많으면 양전자 방출·전자 포획, 중성자가 많으면 β− 방출이다.

문제 10분자오비탈정답 ①

즉시 재도전 원자모형 · 분자오비탈 ← 기출동형 4회 14번 분자오비탈 · 난이도 재도전 O 원자의 원자가 전자는 6개이므로 O2의 원자가 전자는 12개이다.

위 순서대로 채우면 σ2s2 σ*2s2 σ2p2 π2p4π*2p2 가 되고, 마지막 2개는 에너지가 같은 두 π* 오비탈에 훈트 규칙에 따라 하나씩 홀로 들어간다.

결합 차수 =(결합성 전자 - 반결합성 전자)/2 O2+ (전자 11개) : (8 - 3)/2 = 2.5, π*에 홀전자 1개 → 상자기성 O2 (12개) : (8 -4)/2 = 2.0, 홀전자 2개 → 상자기성 O2− (13개) : (8 - 5)/2 = 1.5, 홀전자 1개 → 상자기성 O22− (14개) : (8 - 6)/2 =1.0, π*가 모두 채워져 홀전자 0개 → 반자기성 결합 차수가 작을수록 결합이 약하고 길어지므로 O22−의 결합이 가장 길다.

실제 측정값도 O2+ 112 pm < O2 121 pm < O2− 128 pm < O22− 149 pm로 결합 차수 순서와 일치한다.따라서 1번이 옳다.

오개념 전자를 더하거나 빼는 자리가 반결합성 오비탈(π*)이라는 점이 핵심이다.

반결합성 전자를 빼면 결합 차수가 오히려 커지고, 더하면 작아진다.

그때 왜 틀렸나 전자가 많을수록 결합이 세다고 여김.

더한 전자가 반결합성에 들어가면 오히려 약해진다.
