문제 2분자량정답 ③

사고과정

①(M=ρRT/P)·②(삼투압은 몰농도=mol/L 사용, g/L에서 직접)·④(그레이엄 법칙)는 충분.

③ 어는점 내림은 몰랄농도(mol/kg 용매)가 필요한데, g/L(용액)은 밀도 없이 몰랄로 환산 불가. → ③

삼투압은 몰농도(부피 기준), 어는점 내림은 몰랄농도(질량 기준). g/L 용액 농도는 밀도 없이 몰랄로 못 바꾼다. 결정적 차이.
문제 3총괄성정답 ②

사고과정

①(삼투)·③④(어는점 내림)는 총괄성. ② 호수가 표면부터 어는 건 물의 밀도 이상(4°C서 최대밀도)이라 차가운 물이 위에 머무는 현상 → 총괄성 아님. → ②

총괄성 = 용질 입자 수가 좌우하는 성질(어는점·끓는점·삼투·증기압). 물이 표면부터 어는 건 순수 물의 밀도-온도 관계다.
문제 4몰농도정답 ①

사고과정

삼투압 π = MRT에서 M은 몰농도(mol/L).

→ ①

삼투압은 부피 기준 몰농도를 쓴다(어는점 내림의 몰랄농도와 대비). 같은 총괄성이라도 사용 농도 단위가 다르다.
문제 5삼투압정답 ③

사고과정

NaCl은 i=2라 입자 농도가 2배 → 삼투압이 더 큼 → 물이 글루코오스(묽음)에서 NaCl쪽으로 이동.

→ NaCl 수위 상승, 글루코오스 수위 하강.

→ ③

물은 입자 농도가 높은(삼투압 큰) 쪽으로 간다. NaCl이 i=2라 같은 몰랄이어도 입자가 2배라 그쪽이 올라간다.
문제 6삼투압정답 ③

사고과정

가한 압력이 삼투압과 같아지는 농도가 한계: 7.5 = iMRT = 2×M×0.0821×300 → M = 7.5/49.3 ≈ 0.15 M. → ③

역삼투로 물을 뽑으려면 압력 > 삼투압이어야 한다. 한계 농도는 삼투압=가한 압력인 지점. NaCl은 i=2.
문제 7농도전환정답 ②

사고과정

5.8% NaCl ≈ 58g/L → 58/58.5 ≈ 1몰.

NaCl i=2라 유효 입자 농도 ≈ 2 osmol/L.

포도당(i=1)으로 같으려면 2 M 필요.

→ ②

삼투압은 입자 농도(i×M)에 비례. NaCl 1M은 입자 2M에 해당하니 포도당 2M과 같은 삼투압을 낸다.
문제 8삼투압정답 ②

사고과정

증기압 순: 물 > 포도당(i=1) > NaCl(i=2).

NaCl이 입자 2배라 증기압 최저 → 수은을 가장 적게 누름(수은 높이 최대).

수은 높이로 A=포도당, B=물, C=소금.

→ ②

용질 입자가 많을수록 증기압이 낮아진다(라울). NaCl은 i=2라 같은 몰랄이어도 포도당보다 증기압을 더 낮춘다.
문제 9기체상수정답 ③

사고과정

(가) 속도(m/s)는 SI 에너지 단위라 R=8.314 J/K·mol(b).

(나) 압력 atm·농도 mol/L면 R=0.082 L·atm/K·mol(a).

→ ③

단위를 맞추는 게 핵심. 역학·에너지(J)는 8.314, 기체 압력(atm·L)은 0.082를 쓴다.
문제 10결합에너지정답 ④

주어진 것: 기체 반응 세 가지다.

ㄱ은 2H2(g) + O2(g) → 2H2O(g), ㄴ은 H2(g) + Cl2(g) → 2HCl(g), ㄷ은 3H2(g) + N2(g) → 2NH3(g)이다.

이 중 발열 반응을 모두 고른다.

문항에는 열량 값이 주어져 있지 않으므로 표준 결합에너지 자료값(kJ/mol: H–H 436, O=O 498, Cl–Cl 242, N≡N 945, O–H 463, H–Cl 431, N–H 391)으로 판정한다.

쓰는 법칙: ΔH = (끊는 결합에너지의 합) − (만드는 결합에너지의 합)이다.

이 값이 음수면 발열이다.

계산 ㄱ: 끊기는 2 × 436 + 498 = 872 + 498 = 1370이고, 만들기는 물 2분자의 O–H 4개로 4 × 463 = 1852이다.

ΔH = 1370 − 1852 = −482 kJ이다.

계산 ㄴ: 끊기는 436 + 242 = 678이고, 만들기는 2 × 431 = 862이다.

ΔH = 678 − 862 = −184 kJ이다.

계산 ㄷ: 끊기는 3 × 436 + 945 = 1308 + 945 = 2253이고, 만들기는 NH3 2분자의 N–H 6개로 6 × 391 = 2346이다.

ΔH = 2253 − 2346 = −93 kJ이다.

결론: 세 반응 모두 ΔH < 0인 발열 반응이므로 답은 ④ ㄱ, ㄴ, ㄷ이다.

원소 상태의 기체에서 안정한 화합물이 만들어지는 반응은 끊는 결합보다 만드는 결합이 강해 열을 내놓는 것이 보통이다.

문제 11Q=c m T정답 ④

사고과정

총 발열 = 0.752×26.4 = 19.85kJ.

물 흡수 = 1000×4.18×3.60 = 15.05kJ.

열량계 흡수 = 19.85 − 15.05 = 4.80kJ.

열용량 = 4.80/3.60 = 1.33 kJ/°C.

→ ④

총 발열 = 물 흡수 + 열량계 흡수. 열량계 몫을 ΔT로 나누면 열용량. 표준물질(벤조산)로 열량계를 보정하는 방법.
확인 필요 2026-09-05 확인: 선지 ①(15.87 kJ/°C)이 지문 수치로 재현되지 않는다. 물 몫 15.05도, 4.18을 그대로 뺀 15.67도 아니다. 주어진 값 두셋의 사칙연산을 전수로 훑어도 오차 0.02 이내로 맞는 식이 없다. 또 ②5.52·③4.81을 재현하려면 총발열이 19.86이어야 하는데 그 값으로는 ④가 1.34가 되어 선지 1.33과 어긋난다 — 오답들과 정답이 서로 다른 반올림 기준으로 만들어졌다. 정답 ④(1.33)는 지문 값 그대로의 계산과 일치하므로 키는 유효하다.
문제 12중화엔탈피정답 ④

사고과정

HA 몰수 = NaOH = 1.0×0.005 = 0.005몰.

용액 25g.

발열 = 25×4×3.0 = 300J.

ΔH = −300/0.005 = −60000 J/mol = 60 kJ/mol.

→ ④

종말점 NaOH 몰수 = HA 몰수. 발열량을 몰수로 나눠 몰당 엔탈피로. 강산-강염기 중화열(~57kJ)에 가깝다.
확인 필요 2026-09-05 확인: 지문은 「적정 반응의 엔탈피 변화(ΔH°)는?」인데 중화는 발열이라 ΔH° = −60 kJ/mol 이다. 선지는 ①0.3 ②0.6 ③30 ④60 으로 전부 양수다. 정답 키 ④를 유지하려면 지문을 「방출된 열량의 크기」나 「|ΔH°|」로 고쳐야 한다. 답지 해설도 −60000 J/mol 을 60 kJ/mol 로 적으며 마지막에 음부호를 떨어뜨린다.

문제 16격자에너지정답 ③

주어진 것: KCl(s)의 용해열 17.2 kJ/mol과 KCl(s)의 격자에너지 701.2 kJ/mol이다.

구하는 것은 K+(g) + Cl−(g) → K+(aq) + Cl−(aq)의 ΔH°, 곧 수화 엔탈피다.

쓰는 법칙: 헤스의 법칙이다.

세 과정을 하나의 엔탈피 순환으로 잇는다.

1단계: 격자에너지는 이온 결정을 기체 이온으로 떼어내는 데 드는 에너지이므로 KCl(s) → K+(g) + Cl−(g), ΔH = +701.2 kJ/mol이다.

2단계: 용해열은 KCl(s) → K+(aq) + Cl−(aq), ΔH = +17.2 kJ/mol이다.

값이 양수이므로 KCl이 녹을 때 용액은 차가워진다.

3단계: 고체에서 수용액으로 가는 경로는 '고체 → 기체 이온' 다음에 '기체 이온 → 수용액'을 거치는 것과 같다.

구하는 값을 x라 하면 17.2 = 701.2 + x이다.

계산: x = 17.2 − 701.2 = −684.0 kJ/mol이다.

결론: 답은 ③ −684 kJ이다.

격자를 깨는 데 든 +701.2 kJ을 수화가 내놓는 −684.0 kJ이 거의 다 돌려주기 때문에 실제로 측정되는 용해열은 +17.2 kJ밖에 되지 않는다.
