문제 1정밀도정확도정답 ②

사고과정

참값 = 12.5 mmol/0.25M = 50.0 mL. 정밀도(분산 작음): A(49.0~49.1, 폭 0.2) 최고. 정확도(참값 근접): B(평균 50.0) 최고. → ②

정밀도는 측정값끼리의 일치도(재현성), 정확도는 참값과의 근접도. 둘은 독립적이라 정밀해도 부정확할 수 있다(A).
문제 2계수맞추기정답 ④

사고과정

ㄴ·ㄷ·ㄹ 모두 균형식의 양적 관계로 가능. ㄱ 몰비가 안 맞아도 반응은 일어남(과량이 남을 뿐). → ④

균형식은 정량적 계산(한계 시약·수율·생성물 비)의 토대. 반응 발생 여부와는 무관하다.
문제 3산화수정답 ④

사고과정

금속 수소화물에서 H는 −1.

LiAlH4: Li(+1)+Al(+3)+4H = 0 → H = −1(+1 아님).

→ ④

①·③(금속 수소화물 H=−1)·②(HCl H=+1)는 옳음. H는 보통 +1이나, 자신보다 전기음성도 낮은 금속과 결합하면 −1(수소화물). LiAlH4는 강한 환원제로 H−를 공급한다.
문제 4계수맞추기정답 ④

사고과정

반쪽 반응으로 가른다.

환원 쪽은 MnO4− + 8H+ + 5e− → Mn2+ + 4H2O 이고, 산화 쪽은 2Br− → Br2 + 2e−

다. 주고받는 전자를 최소공배수 10 으로 맞추면 환원 쪽에 2 를, 산화 쪽에 5 를 곱한다.

H+ 는 8 × 2 = 16 이다.

→ ④

문제 5기체정답 ②

사고과정

같은 n·V·T: 부분압(P=nRT/V 동일)·평균 운동에너지((3/2)kT, T만 의존) 동일. 질량(4 vs 20 g)·평균 속력(∝√(1/M)) 다름. → 2개 → ②

평균 운동에너지는 분자량과 무관(온도만). 평균 속력은 √(T/M)이라 가벼운 He이 더 빠르다.
문제 6원자반지름정답 ②

사고과정

Mg(3주기 2족, 가장 왼쪽)가 최대.

Si는 같은 주기지만 오른쪽이라 작고, O·C는 2주기라 작음.

→ ②

반지름은 주기 아래로·족 왼쪽으로 커진다. 3주기 금속 Mg가 2주기 비금속(C·O)이나 같은 주기 Si보다 크다.
문제 7DNA정답 ②

사고과정

DNA는 C·H·O·N·P(인산 골격)로 구성.

황(S)은 DNA에 없음(일부 단백질에 존재).

→ ②

핵산(DNA·RNA)의 특징 원소는 인(P). 황은 단백질(시스테인·메싸이오닌)에 들어가는 원소다.
문제 8발열반응정답 ④

사고과정

셋 다 안정한 화합물이 만들어지는 결합 형성 반응이다.

ㄱ 은 물 생성(연소), ㄴ 은 HCl 생성, ㄷ 은 암모니아 합성으로 ΔH 가 −92 kJ

다. 결합이 새로 생기며 에너지를 내놓으므로 모두 발열이다.

→ ④

문제 9수소원자정답 ③

사고과정

바닥상태 이온화에너지 = RH = 2.2×10−18

J. 최대 파장 = 최소 에너지: λ = hc/E = (6.6×10−34×3×108)/(2.2×10−18) ≈ 9.0×10−8 m = 90 nm.

→ ③

이온화에 필요한 최소 에너지가 곧 이온화에너지. 에너지가 최소면 파장(hc/E)은 최대가 된다.
문제 10쌍극자모멘트정답 ④

사고과정

q = μ/d = (0.1×3.3×10−30)/(110×10−12) = 3.0×10−21

C. CO는 :C≡O:(C 형식전하 −1)라 이례적으로 C가 음(−)단.

→ ④

CO는 산소가 더 전기음성적인데도 쌍극자가 매우 작고 음의 끝이 탄소를 향한다(형식전하·고립쌍 효과). 부분 전하 ≈ 전자 전하의 약 2%.
문제 11홀전자정답 ③

사고과정

홀전자(알짜 스핀)가 있어야 두 줄로 갈라짐. H(1s¹)·Ag([Kr]4d¹⁰5s¹) 홀전자 1개 → 분리. Zn([Ar]3d¹⁰4s²) 모두 짝지음 → 안 갈라짐. → ③

홀전자의 스핀 자기모멘트가 자기장과 상호작용해 빔이 둘로 갈라진다. 모든 전자가 짝지은 원자는 갈라지지 않는다.
문제 12일정답 ①

사고과정

일정 압력에서 계가 주위에 한 일은 w = −PΔV 이고, ΔV 는 사실상 기체 몰수 변화가 정한다.

② 는 수용액끼리, ③ 은 고체→액체라 기체가 없고, ④ 는 기체 2 몰에서 2 몰이라 변화가 없다.

① 만 액체가 기체로 바뀌어 기체 몰수가 0 에서 1 로 는다.

→ ①

문제 13온실효과정답 ①

사고과정

온실기체는 진동 시 쌍극자 변화로 적외선을 흡수.

H2는 등핵 이원자라 쌍극자가 없어 IR 흡수 불가 → 온실기체 아님.

→ ①

IR 흡수는 진동 중 쌍극자 모멘트가 변해야 가능. 등핵 분자(H2·N2·O2)는 대칭 신축에서 쌍극자가 변하지 않는다.
문제 14헤스법칙정답 ②

사고과정

헤스 법칙으로 두 식을 더한다.

P4 + 6Cl2 → 4PCl3 (−2439 kJ) 와 4PCl5 → P4 + 10Cl2 (+3438 kJ) 를 더하면 P4 가 지워지고 4PCl5 → 4PCl3 + 4Cl2, ΔH = 999 kJ 가 된다.

목표 식은 PCl5 한 몰이므로 4 로 나눠 약 250 kJ 다.

→ ②

문제 15연소열정답 ③

사고과정

이미 가장 산화된(산소 많은) 화합물이 연소열 최소.

아세트산 CH3CO2H는 O 2개로 가장 산화돼 방출 열량 최소.

→ ③

연소는 완전 산화(CO2·H2O). 출발 물질이 이미 산화돼 있으면 방출할 에너지가 적게 남는다(C2H6가 최대 방출).
문제 16중화열정답 ④

사고과정

반응 몰수 = 1.0×0.005 L = 0.005몰.

q = m·c·ΔT = 25.0×4×3.0 = 300

J. ΔH = 300/0.005 = 60000 J/mol = 60 kJ/mol(발열).

→ ④

총 부피(20+5=25 mL)의 질량으로 q를 구하고, 반응한 몰수로 나눠 몰당 엔탈피로 환산한다.
문제 17실제기체정답 ③

사고과정

중간~고압에서 분자간 인력이 강할수록 Z<1로 더 떨어짐.

CO2가 가장 크고 편극성·임계온도 높아 인력 최강 → Z 최소.

→ ③

Z=PV/RT. 인력 지배 시 Z<1(실제 부피가 이상보다 작음). 이상 기체는 항상 Z=1.
문제 18PV=nRT정답 ①

사고과정

P = 570/760 = 0.75 atm.

n = PV/RT = (0.75×1)/(0.0821×300) = 0.0305몰.

질량 = 0.0305×16 ≈ 0.50 g.

→ ①

부분압만으로 그 기체의 몰수를 구한다(혼합기체라도 각 기체는 자기 분압을 따름). torr는 760으로 나눠 atm으로.
문제 19평균자유행로정답 ①

사고과정

충돌빈도 z 는 평균 속력과 밀도에, 평균자유행로 λ 는 밀도에만 매인다.

ㄱ 은 옳다(온도↑ → 속력↑ → z↑).

ㄴ 은 틀리다 — 같은 온도에서 압력을 높이면 부피가 줄어 밀도가 올라 z 가 는다.

ㄷ 은 옳다(밀도 두 배 → λ 반).

ㄹ 은 틀리다 — 부피가 같으면 밀도가 그대로라 λ 도 그대로다.

→ ①

문제 20전자배치전원정답

사고과정

원본 채점표에서 삭제처리(무효)된 문항.

마델룽(n+l) 규칙은 채움 순서일 뿐, 특정 원자(특히 무거운 Au)의 실제 궤도 에너지는 다르다.

Au([Xe]4f145d106s1)에서 채워진 내부 4d는 5s보다 에너지가 낮아 마델룽 순서와 어긋난다.

단일한 에너지 순서로 확정할 수 없어 출제 오류로 처리됨.

→ 삭제처리 마델룽 규칙은 다전자 원자의 일반적 채움 순서.

특정 원자의 실제 궤도 에너지는 핵전하·차폐·상대론 효과로 달라져 보편적 서열과 불일치할 수 있다.

문제 21양자수정답 ③

사고과정

ms=+1/2 고정이라 각 오비탈당 1개 → 3개.

→ ③

ml=0은 3s(1개)·3pz(1개)·3dz2(1개)로 부껍질마다 하나씩. 스핀까지 지정하면 오비탈당 전자 1개로 제한된다.

문제 23분자오비탈정답 ①

사고과정

NO⁻(12 e⁻): π*2p에 전자 2개 → 훈트 규칙으로 홀전자 2개 → 상자성(①). 결합차수 2.

② NO⁺(3)>NO⁻(2) 결합E. ③ NO(2.5)>NO⁻(2) → NO⁻ 결합 더 김. ④ 최고 점유는 π*(반결합성). → ①

결합차수=(결합성−반결합성)/2. NO+(3)>NO(2.5)>NO⁻(2)로 갈수록 결합 약·길어짐. π*의 홀전자가 상자성을 만든다.
문제 24혼성오비탈정답 ③

사고과정

③ 에터 산소는 결합 2개 + 고립쌍 2개 = 4영역 → sp³(sp 아님). 틀림. → ③

문제 25공명구조정답 ①

문제 28입자수정답 ②
