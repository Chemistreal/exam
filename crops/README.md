# 오답노트 · 원문 문제 이미지 슬롯

성적표 PDF의 **오답 정리 노트**에서 각 틀린 문항 자리에 원문 문제 이미지를 자동으로 넣기 위한 폴더입니다.
이미지는 **관리자(권리 보유자)가 직접** 준비·업로드합니다.

## 파일 규칙

```
crops/<시험id>/<문항번호>.png
```

- `<시험id>` : `final.html` 의 시험 id (예: `jmchc-1`, `hwol-2015`, `kmchc-2024-1`, `sanyeom-60` …)
- `<문항번호>` : 1 ~ 60 (해당 시험의 문항 번호)
- 형식 : **PNG** (권장, 폭 800px 내외면 인쇄 화질 충분)

예)
```
crops/jmchc-1/11.png     ← JMChC 1회 11번 문제 크롭
crops/jmchc-1/13.png
crops/kmchc-2024-1/7.png
```

## 동작

- 학생이 그 문항을 틀렸고, 해당 크롭 이미지 파일이 있으면 → 오답노트에 원문이 그대로 표시됩니다.
- 파일이 없으면 → 이미지 없이 "문제지 N번을 보고 다시 풀어보세요" 안내만 나옵니다(오류 없음).
- 한 번 올려두면 그 시험을 응시한 **모든 학생 리포트에 자동 재사용**됩니다.

## 만드는 법(예)

1. 문제지 PDF를 열고 해당 문항 영역을 캡처/크롭.
2. `crops/<시험id>/<문항번호>.png` 경로로 저장.
3. GitHub 저장소에 커밋·푸시하면 즉시 반영.
