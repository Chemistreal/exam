문제 1수득률정답 ①

사고과정

A/2 = 1.0 < B/1 = 2.0 → A가 한계.

이론 C = 2.0×(3/2) = 3.0몰.

수득율 = 2/3 ≈ 66%.

→ ①

한계 반응물(A) 기준으로 이론량을 구한다. 수득율 = 실제/이론.

수득률 = 150/302 ≈ 50%.

→ ①

문제 3평형상수정답 ②

사고과정

② K는 온도 의존(참). ① 증기압은 온도만 의존(대기압 무관). ③ 상전이 중 온도 일정. ④ 촉매는 K 불변. → ②

평형상수는 오직 온도로만 변한다. 증기압도 온도만의 함수. 상전이 중에는 흡수·방출 열이 상변화에 쓰여 온도가 일정.
문제 4삼중점정답 ③

사고과정

③ 35°C > 임계점 31°C라 액체 불가(참). ① 1atm<삼중점이라 액체 없음. ② 승화는 고체→기체. ④ 같은 온도서 액체 증기압이 더 큼. → ③

임계온도(31°C) 위에서는 아무리 가압해도 액체가 안 된다. 1atm은 삼중점 압력(5.1atm)보다 낮아 고체↔기체만.
문제 5압력정답 ②

사고과정

물은 얼음(고체)이 액체보다 덜 조밀(이상). 가압은 부피 작은 상을 선호하므로 액체가 유리 → ② 액체→고체(부피 증가)가 가장 불리. → ②

물의 특이성: 얼음이 물에 뜬다(덜 조밀). 그래서 가압하면 얼음이 녹는다(고체-액체선 음의 기울기). 일반 물질과 정반대.
문제 6분별증류정답 ③

사고과정

③ CaCl2(i=3)가 NaCl(i=2)보다 어는점을 더 낮춰 효과적(참).

① 공비혼합물이라 완전 분리 불가. ② 삼중점서 3상 공존 가능. ④ 녹는점서 얼음→물로 밀도 증가(항상 감소 아님). → ③

제설제는 입자 수가 많을수록 효과적. CaCl2는 한 분자가 3개 이온으로 나뉘어 NaCl보다 우수하다.
문제 7상평형도정답 ②

사고과정

② 상온·1atm서 CO2는 기체(참). ① 고체-액체선 양의 기울기(녹는점↑). ③ 1atm<삼중점이라 액체 없음. ④ 80°C>임계점이라 액체 불가. → ②

CO2는 일반 물질이라 가압 시 녹는점이 오른다(물과 반대). 임계온도 위에서는 액체가 존재하지 못한다.
문제 8상평형도정답 ③

사고과정

③ 119°C는 녹는점이고 끓는점은 더 높으므로 증기압 < 1atm(참). ① 녹는점은 정확히 119°C. ② 삼중점 3개. ④ 정상녹는점 119°C > 95°C. → ③

정상녹는점(증기압이 1atm 만나는 고체-액체 전이)이 119°C라면 끓는점은 그보다 높다. 따라서 녹는점 온도에서 증기압은 1atm 미만.
문제 9기체의용해도정답 ③

사고과정

③ 태초 광합성은 남세균(시아노박테리아)이 했고, 지상 식물은 산소→오존층 형성 후 등장(참).

① O2·N2는 무극성이라 난용. ② CO2는 물에 녹아(탄산) 수중 광합성 가능. ④ 광합성 부산물은 이산화탄소가 아니라 산소. → ③

산소의 역사: 바다 광합성으로 산소(부산물)가 대기에 쌓인 뒤 오존층이 생기고 생물이 육지로 올라왔다. ④는 부산물을 CO2로 잘못 적은 함정.
문제 10용해도정답 ③

사고과정

80°C 포화(0.5L): A 5.0×0.5=2.5g, B 3.0×0.5=1.5g.

25°C 한계: A 1.5g, B 0.5g.

석출 A = 2.5−1.5 = 1.0g, B = 1.5−0.5 = 1.0g → 50:50.

→ ③

두 물질을 80°C서 각각 포화시킨 뒤 냉각한다. 석출량 = 80°C 용해량 − 25°C 용해 한계. 우연히 둘 다 1.0g 석출.
문제 11유유상종정답 ④

사고과정

CH2F2(극성, 잘 녹음) > CO2(물과 반응해 탄산, 어느 정도 녹음) > C2H6(무극성, 거의 안 녹음).

→ ④

극성·물과의 상호작용이 클수록 잘 녹는다. CH2F2는 굽은 극성 분자, CO2는 무극성이나 물과 반응, 에테인은 무극성.
확인 필요 ③ CH₃CH₂OCH₂CH₃ > CHCl₃ > C₂H₆ 는 실제 용해도 자료로도 성립하는 배열이다. 20 °C에서 다이에틸에터는 약 6.9 g/100 mL, 클로로폼은 약 0.8 g/100 mL, 에테인은 약 0.006 g/100 mL가 물에 녹으므로 ③의 부등호 방향이 자료와 일치한다. 정답률이 9 %로 무작위 선택(25 %)보다도 낮은 것은 응시자가 ③에 몰렸을 가능성을 시사한다. 복수정답 여부를 검토해 주시기 바란다.
문제 12이온분위기정답 ②

사고과정

A=MgSO4(이온세기 최대, 용해도↑). B=NaCl. C=글루코오스(비전해질, 일정). D=KCl(공통이온 K⁺, 감소). → ②

전하 큰 무관 염(MgSO4)은 염 효과로 용해도↑, 비전해질은 무영향, 공통이온(KCl)은 용해도↓.
문제 13양적관계정답 ④

사고과정

수화물 x g 중 CuSO4 = 0.64x, 결정수 = 0.36x. 포화: 0.64x/(1300+0.36x) = 0.2 → 0.568x = 260 → x ≈ 458 ≈ 450g. → ④

결정수가 용매에 합쳐지는 걸 분모에 반영. 물의 양만 100→1300g으로 커진 같은 유형 문제.
문제 14용해도정답 ③

문제 16이온농도정답 ①

문제 17이온수정답 ①

문제 18용해도곱상수정답 ①

→ ①

문제 19용해도곱상수정답 ②

문제 20용해도곱상수정답 ②

몰용해도 환산: Sn(OH)2(4s3)≈9×10−10, CdS(s2)=10−14, Al(OH)3(27s4)≈5×10−9, Pb3(PO4)2(108s5)≈6×10−12.

문제 23양적관계정답 ①

사고과정

[SO4²⁻] = (1×0.050)/500 = 1×10⁻⁴M. 침전 시작점서 Q=Ksp: [Ba²⁺] = 10⁻¹⁰/10⁻⁴ = 1×10⁻⁶ M. → ①

총 부피가 500L(11회는 500mL)라 [SO4²⁻]가 훨씬 묽어 [Ba²⁺] 임계값이 10⁻⁶로 커진다.
문제 24앙금생성정답 ②

사고과정

A·D는 순수 포화 [Ba²⁺]=√Ksp=10⁻⁵. B·C는 공통이온([SO4²⁻]=0.1) [Ba²⁺]=10⁻⁹.

② A=D=10⁻⁵(참). ①A가 더 많음. ③공통이온은 낮춤. ④고체량 무관, B=C. → ②

D는 Ba²⁺·SO4²⁻ 동량이라 거의 다 침전 → 순수 포화(A와 동일). 공통이온은 용해도를 낮추고 고체 양은 무관.
문제 25용해도곱상수정답 ③

사고과정

당량점 전 [Ag+]=Ksp/[X−].

왼쪽: pAg+ 높을수록 [X−] 큼 → A>B>C.

오른쪽: 같은 [X−]라 pAg+ 높을수록 Ksp 작음 → 가<나<다.

→ ③

곡선이 위(높은 pAg+)일수록 당량점 전 [Ag+]가 작고, 이는 음이온 농도가 크거나 Ksp가 작음을 뜻한다.
문제 26다양성자산정답 ③

사고과정

Ka1>Ka2>Ka3. 양성자를 줄 수 있는 종 중 Ka3가 가장 작은 HY²⁻이 가장 약한 산. (Y³⁻는 양성자가 없어 산이 아니라 염기) → ③

"가장 약한 산"은 마지막 양성자를 떼는 HY²⁻(Ka3 최소). Y³⁻는 줄 H⁺가 없으니 산 자체가 아니라 함정.
문제 27물의자동이온화정답 ②

사고과정

HBr 10−10은 무시할 정도라 용액은 사실상 중성.

물 유래 H+ = [OH−] ≈ 10−7 M.

→ ②

산이 10−7보다 훨씬 묽으면 물이 지배해 거의 중성. 물 자체이온화 H+는 [OH−]와 같아 ≈10−7.
문제 28해리도정답 ④

사고과정

[H+] ≈ √(Ka·C) = √(10−3×0.1) = 10−2

M. 해리도 = 10−2/0.1 × 100 = 10%.

→ ④

Ka가 10−3로 커서 해리도가 10%까지 올라간다(약산 근사가 슬슬 한계에 가까워지는 지점).
문제 29해리백분율정답 ③

사고과정

[H+] = 10−2 M = 해리된 HA.

해리율 = 10−2/0.50 × 100 = 2.0%.

→ ③

pH로 [H+](=해리량)를 구하고 초기 농도로 나눈다. pH가 2.0(11회는 3.0)이라 해리율이 10배 큼.
문제 30희석정답 ③

사고과정

HCl은 강산이라 완전 해리.
