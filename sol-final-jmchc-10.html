문제 1어는점내림정답 ②

사고과정

몰랄 = (0.494/329.25)/0.1 = 0.015m. i = 0.112/(1.86×0.015) ≈ 4 → 입자 4개.

K3Fe(CN)6 → 3K⁺ + Fe(CN)6³⁻ (3+1=4). 착이온은 그대로 유지. → ②

반트호프 i로 해리 입자 수를 센다. 배위권 안의 CN⁻은 착이온 Fe(CN)6³⁻에 묶여 따로 떨어지지 않는다.
문제 2분자량정답 ③

사고과정

①(M=ρRT/P)·②(삼투압은 몰농도=mol/L 사용, g/L에서 직접)·④(그레이엄 법칙)는 충분.

③ 어는점 내림은 몰랄농도(mol/kg 용매)가 필요한데, g/L(용액)은 밀도 없이 몰랄로 환산 불가. → ③

삼투압은 몰농도(부피 기준), 어는점 내림은 몰랄농도(질량 기준). g/L 용액 농도는 밀도 없이 몰랄로 못 바꾼다. 결정적 차이.
문제 3총괄성정답 ②

사고과정

①(삼투)·③④(어는점 내림)는 총괄성. ② 호수가 표면부터 어는 건 물의 밀도 이상(4°C서 최대밀도)이라 차가운 물이 위에 머무는 현상 → 총괄성 아님. → ②

총괄성 = 용질 입자 수가 좌우하는 성질(어는점·끓는점·삼투·증기압). 물이 표면부터 어는 건 순수 물의 밀도-온도 관계다.
문제 4몰농도정답 ①

사고과정

삼투압 π = MRT에서 M은 몰농도(mol/L).

→ ①

삼투압은 부피 기준 몰농도를 쓴다(어는점 내림의 몰랄농도와 대비). 같은 총괄성이라도 사용 농도 단위가 다르다.
문제 5삼투압정답 ③

사고과정

NaCl은 i=2라 입자 농도가 2배 → 삼투압이 더 큼 → 물이 글루코오스(묽음)에서 NaCl쪽으로 이동.

→ NaCl 수위 상승, 글루코오스 수위 하강.

→ ③

물은 입자 농도가 높은(삼투압 큰) 쪽으로 간다. NaCl이 i=2라 같은 몰랄이어도 입자가 2배라 그쪽이 올라간다.
문제 6삼투압정답 ③

사고과정

가한 압력이 삼투압과 같아지는 농도가 한계: 7.5 = iMRT = 2×M×0.0821×300 → M = 7.5/49.3 ≈ 0.15 M. → ③

역삼투로 물을 뽑으려면 압력 > 삼투압이어야 한다. 한계 농도는 삼투압=가한 압력인 지점. NaCl은 i=2.
문제 7농도전환정답 ②

사고과정

5.8% NaCl ≈ 58g/L → 58/58.5 ≈ 1몰.

NaCl i=2라 유효 입자 농도 ≈ 2 osmol/L.

포도당(i=1)으로 같으려면 2 M 필요.

→ ②

삼투압은 입자 농도(i×M)에 비례. NaCl 1M은 입자 2M에 해당하니 포도당 2M과 같은 삼투압을 낸다.
문제 8삼투압정답 ②

사고과정

증기압 순: 물 > 포도당(i=1) > NaCl(i=2).

NaCl이 입자 2배라 증기압 최저 → 수은을 가장 적게 누름(수은 높이 최대).

수은 높이로 A=포도당, B=물, C=소금.

→ ②

용질 입자가 많을수록 증기압이 낮아진다(라울). NaCl은 i=2라 같은 몰랄이어도 포도당보다 증기압을 더 낮춘다.
문제 9기체상수정답 ③

사고과정

(가) 속도(m/s)는 SI 에너지 단위라 R=8.314 J/K·mol(b).

(나) 압력 atm·농도 mol/L면 R=0.082 L·atm/K·mol(a).

→ ③

단위를 맞추는 게 핵심. 역학·에너지(J)는 8.314, 기체 압력(atm·L)은 0.082를 쓴다.
문제 10결합에너지정답 ④

사고과정

ㄱ(물 생성)·ㄴ(HCl 생성)·ㄷ(암모니아 합성, 하버법) 모두 안정한 결합을 형성하며 에너지를 방출 → 발열.

→ ④

원소에서 안정한 화합물이 생성되는 반응은 대개 발열. 세 반응 모두 강한 결합을 만들며 열을 낸다.
문제 11Q=c m T정답 ④

사고과정

총 발열 = 0.752×26.4 = 19.85kJ.

물 흡수 = 1000×4.18×3.60 = 15.05kJ.

열량계 흡수 = 19.85 − 15.05 = 4.80kJ.

열용량 = 4.80/3.60 = 1.33 kJ/°C.

→ ④

총 발열 = 물 흡수 + 열량계 흡수. 열량계 몫을 ΔT로 나누면 열용량. 표준물질(벤조산)로 열량계를 보정하는 방법.
문제 12중화엔탈피정답 ④

사고과정

HA 몰수 = NaOH = 1.0×0.005 = 0.005몰.

용액 25g.

발열 = 25×4×3.0 = 300J.

ΔH = −300/0.005 = −60000 J/mol = 60 kJ/mol.

→ ④

종말점 NaOH 몰수 = HA 몰수. 발열량을 몰수로 나눠 몰당 엔탈피로. 강산-강염기 중화열(~57kJ)에 가깝다.

문제 15표준증발엔탈피정답 ③

문제 22표준생성엔탈피정답 ①

표준 생성 반응의 조건: 표준상태 원소들 → 화합물 1몰. 흑연(O2·F2·Xe기체)이 표준상태이고 다이아몬드·O3·SO2는 아니다.

생성열로 반응열 구하기: 생성물 − 반응물(H2는 0). 수증기 개질은 흡열이라 고온이 필요하다(수소 생산 공정).
문제 25결합에너지정답 ①

사고과정

ΔH = 651 − 755 = −104 kJ/mol.

→ ①

CH4의 C−H 4개 중 1개만 바뀐다. 변하지 않는 결합은 빼고 끊는/만드는 결합만 센다.
문제 26생성엔탈피정답 ③

사고과정

먼저 결합에너지로 ΔHrxn = [413+242] − [339+432] = 655 − 771 = −116kJ.

생성열식: −116 = [ΔHf(C3H7Cl) + (−92)] − [(−104)] → ΔHf = −116 + 92 − 104 = −128 kJ/mol. → ③

두 방법을 잇는다: 결합에너지로 ΔHrxn을 구하고, 그걸 생성열 식에 넣어 미지 생성열을 역산한다.

→ ③

문제 29수소결합정답 ④
