문제 1몰과양적관계정답 ③

사고과정

50 kg 중 H 는 7.78% = 3.89 kg, O 는 62.22% = 31.11 kg 이 물로 있다.

O 로 세면 31110/16 ≈ 1944 mol, 곧 물 1944 mol.

분자 수 = 1944 × 6.02×10²³ ≈ 1.2×10²⁷.

→ ③

문제 2분자수정답 ②

사고과정

1×10⁸ Pa = 1000 기압, V = 1 mL = 0.001 L, T = 300 K.

n = PV/RT = (1000×0.001)/(0.082×300) ≈ 0.041 mol.

분자 수 ≈ 0.041 × 6.02×10²³ ≈ 2.5×10²².

→ ②

① ⁶₃Li⁴⁺ 은 전자가 3개뿐인 리튬이 4개를 잃은 꼴이라 있을 수 없다.

②·③·④ 는 질량수·원자번호·전하가 모두 맞는다.

문제 4원소분석장치정답 ①

사고과정

리비히 장치는 들어오는 공기의 수분을 먼저 없애고(염화칼슘), 산화구리(CuO)로 완전 연소시킨 뒤, 생긴 물을 흡수하고(실리카겔), 마지막에 CO₂ 를 흡수한다(수산화나트륨).

→ ①

문제 5질소산화물정답 ②

사고과정

질소산화물을 암모니아로 환원해 질소를 얻는 반응(SCR)이다.

NOₓ 의 산소와 NH₃ 의 수소가 만나 물이 되고 질소만 남는다.

→ ②

문제 6계수맞추기정답 ④

사고과정

Cl 은 +5 → −1 로 6전자를 얻고, S 는 +4 → +6 으로 2전자를 잃으므로 SO₂ 가 3개 필요하다(a=3, b=3).

염기성이므로 ClO₃⁻ + 3SO₂ + 6OH⁻ → 3SO₄²⁻ + Cl⁻ + 3H₂O 로 맞춰진다.

3 + 3 + 3 = 9.

→ ④

문제 7헤스법칙정답 ④

사고과정

목표는 2ICl(g) → I₂(s) + Cl₂(g) 다.

2×(ICl→I+Cl) = 422, 2I→I₂(g) = −150, 2Cl→Cl₂ = −243, I₂(g)→I₂(s) = −65.

합하면 422 − 150 − 243 − 65 = −36 kJ.

→ ④

문제 8선스펙트럼정답 ①

사고과정

(a) n=1→2 는 위로 올라가는 전이라 빛을 흡수한다.

파장은 에너지 차가 작을수록 길다.

n=1→2 의 차는 10.2 eV, n=2→∞ 의 차는 3.4 eV 이므로 (b) 가 더 길다.

→ ①

C 396, CH₄ 896, C₈H₁₈ 5472/8 = 684, C₇H₈ 3864/7 = 552.

CH₄ 가 가장 크다.

→ ②

문제 10양자수정답 ③

사고과정

CO 가 CO₂ 로 산화되므로 환원되는 것은 Fe 다.

Fe₃O₄(평균 +8/3) → FeO(+2) 로 전자를 얻는데, 그 전자가 들어가는 자리는 3d 이므로 n=3, l=2 이고 곱은 6.

→ ③

문제 11시그마파이결합정답 ④

사고과정

HO−C≡C−CH=CH−CH₂−C≡C−NH₂ 에서 ㄱ σ 는 뼈대 결합과 O−H·C−H·N−H 를 더해 15개다(참).

ㄴ π 는 삼중 둘(2+2)과 이중 하나(1)로 5개다(참).

ㄷ sp² 탄소끼리의 σ 는 C=C 자리 하나뿐이다(거짓).

ㄹ 삼중 결합에 걸린 탄소 4개가 sp 다(참).

→ ④

문제 12혼성오비탈정답 ①

사고과정

DNA 염기의 인은 인산 골격에서 산소 4개와 결합해 sp³ 이다.

표시된 P 를 sp³d 라 한 ① 이 틀렸다.

고리의 C·N 은 이중 결합이면 sp², 아니면 sp³ 로 맞다.

→ ①

문제 13분자의모양정답 ①

사고과정

XeO₃ 는 Xe 둘레에 결합 3개와 비공유 전자쌍 1개, 곧 전자 영역 4개다.

사면체 배열에서 하나가 비공유이므로 모양은 삼각뿔이다.

→ ①

문제 14분자의극성정답 ③

사고과정

쌍극자 모멘트가 있으려면 결합 쌍극자가 상쇄되지 않아야 한다.

XeF₄(평면 사각)·PF₅(삼각쌍뿔)·SF₄·SF₆·BrF₄⁻·ClF₄⁻ 는 대칭이라 0 이고, XeO₃(삼각뿔)와 PF₃(삼각뿔)는 비공유 전자쌍 때문에 대칭이 깨져 0 이 아니다.

→ ③

문제 15용액의농도정답 ①

사고과정

용액 1 L 를 잡으면 HCl 은 12.0 mol = 438 g 이고, 이것이 전체 질량의 37% 다.

용액 질량 = 438/0.37 ≈ 1184 g.

밀도 = 1184 g / 1000 mL ≈ 1.2 g/mL.

→ ①

문제 16원자결정정답 ①

사고과정

SiO₂ 는 원자(그물) 결정이라 녹으려면 공유 결합 자체를 끊어야 한다.

이온 결정(KCl)·수소 결합(H₂O)·분산력(CF₄)보다 훨씬 세다.

→ ①

문제 17결합에너지정답 ③

사고과정

① 결합 길이는 차수가 클수록 짧으므로 C≡C < C≡O < C=C 순으로 커진다(제시된 순서가 틀림).

② 전기음성도 차는 H−I 가 가장 작다.

③ 제2이온화에너지는 원자가전자를 하나 잃은 뒤의 값이라 N < F < O 순이 맞다.

④ 반지름은 Na⁺ < O < O²⁻ 다.

→ ③

문제 18용해도정답 ②

사고과정

25 °C 로 낮출 때 A 는 5.2 → 2.4 로 2.8 g/L, B 는 3.0 → 1.2 로 1.8 g/L 가 나온다(고체 C).

다시 10 °C 로 낮추면 A 는 2.4 → 0.5 로 1.9, B 는 1.2 → 0.1 로 1.1 이 더 나온다(고체 D).

D 에서 A 의 비율 = 1.9/(1.9+1.1) ≈ 63.3%, B ≈ 36.7%.

→ ②

문제 19확산전원정답

사고과정

구멍이 생긴 직후에는 아직 빠져나간 양이 적으므로 처음 몰수가 그대로다.

부피가 같으므로 몰수는 압력에 비례한다 — (나)와 (다)가 2기압, (가)는 1기압이다.

다만 (가)는 바깥(2기압 헬륨)이 더 높아 오히려 들어오고, 가벼운 기체일수록 빨리 오간다.

분자 수가 가장 많아지는 것은 (가) 쪽이다.

→ ①

문제 33반응속도상수정답 ③

사고과정

실험 1→2 에서 [A] 2배에 속도 2배이므로 A 는 1차, 2→3 에서 [B] 2배에 속도 4배이므로 B 는 2차, 1→4 에서 [C] 2배에 속도 1/2 이므로 C 는 −1차다.

전체 차수 = 1+2−1 = 2 이므로 k 의 단위는 L·mol⁻¹·s⁻¹ 이고, 값은 8.0×10⁻⁴/(0.1×0.1²×0.1⁻¹) = 8.0×10⁻².

→ ③

문제 36방사성붕괴정답 ④
