문제 1DNA정답 ②

사고과정

천연고무(아이소프렌 1종)·테플론(테트라플루오로에틸렌 1종)·셀룰로오스(글루코스 1종)는 단일 단위체.

핵산은 4종류 뉴클레오타이드(A·T/U·G·C)로 구성 → 3종 이상. → ②

대부분의 합성·천연 고분자는 한 종류 단위체. 핵산·단백질만 여러 종류 단위체(염기·아미노산)로 정보를 담는다.
문제 2수소결합정답 ②

사고과정

세기: 이온-쌍극자(Li+-H2O) > 수소결합(H2O-H2O) > 쌍극자-쌍극자(CHCl3) > 분산력(CH4).

두 번째로 강함 = H2O⋯H2O(수소결합).

→ ②

분자간 힘 위계: 이온-쌍극자 > 수소결합 > 쌍극자-쌍극자 > 분산력. 1위는 Li+(이온)이 낀 ③.
문제 3수소결합정답 ②

사고과정

아세트산(−COOH)은 이합체(dimer)로 수소결합 2개를 형성 → 끓는점 최고(118°C).

에탄올(78°C, −OH 1개) > 아세트알데하이드(20°C, 케톤형) > 다이메틸에터(−24°C, 에터). → ②

카복실산은 −COOH끼리 두 줄의 수소결합으로 이합체를 만들어, 같은 크기 알코올보다도 끓는점이 훨씬 높다.
문제 4분산력정답 ③

사고과정

①②④ H2O·NH3·HF는 수소결합으로 끓는점이 이상하게 높아 최저가 아니다(순서가 깨짐).

③ 비활성기체는 수소결합이 없어 분자량↑(분산력↑)에 따라 단조 증가: He < Ne < Ar < Kr < Xe. → ③

2주기 H 화합물(H2O·NH3·HF)은 수소결합으로 끓는점이 튄다. 분산력만 작용하는 비활성기체만 깔끔히 단조 증가.
문제 5이온결합정답 ②

사고과정

He(분산력, 최저) < C2H6(분산력) < C2H5OH(수소결합) < KBr(이온결합, 최고).

→ ②

결합 세기: 이온(KBr) ≫ 수소결합(에탄올) > 분산력(He·에테인). 분산력은 분자량이 큰 에테인이 He보다 강하다.
문제 6수소결합정답 ②

사고과정

에틸에테르(35°C)·아세톤(56°C)은 수소결합 없음(에터·케톤).

메탄올(65°C)·에탄올(78°C)은 −OH 수소결합.

에틸에테르 < 아세톤 < 메탄올 < 에탄올.

→ ②

수소결합 유무로 먼저 두 그룹을 나누고, 그 안에서 분자량·극성으로 세분한다. 알코올끼리는 메탄올 < 에탄올.
문제 7수소결합정답 ③

사고과정

C6H6(무극성, 80°C) < C6H5Cl(극성, 132°C) < C6H5Br(더 무거움, 156°C) < C6H5OH(−OH 수소결합, 182°C).

→ ③

벤젠 고리에 −OH가 붙은 페놀만 수소결합으로 끓는점이 가장 높다. 할로젠은 Cl < Br 순(분산력↑).
문제 8HF의특징정답 ④

사고과정

가(수소결합으로 끓는점 최고)·나(F−H⋯F 수소결합)·다(약산, HCl·HBr·HI는 강산)·라(SiO2 + 4HF → SiF4, 유리 부식) 모두 참. → ④

HF는 할로젠화수소 중 유일하게 약산이면서 끓는점은 가장 높다(수소결합 때문). 유리를 녹이는 특이 성질도 있다.

사고과정

HF의 수소결합 에너지는 약 10~40 kJ/mol(수소결합 중 가장 강함).

보기 중 10에 가장 가깝다.

→ ④

수소결합은 보통 10~40 kJ/mol로, 공유결합(수백 kJ/mol)보다 약하지만 분산력(수 kJ/mol)보다 강하다.

문제 12탈출속도정답 ②

사고과정

a 같은 온도면 평균 운동에너지 동일(3/2 kT, 질량 무관). H2>He>N2>O2는 속도 순서. c 평균속도 ∝ √T이라 T 2배면 √2배(2배 아님).

b 옳음: 분포의 꼬리 때문에 온도가 낮아도 매우 빠른 분자가 일부 존재 → 어떤 기체든 탈출속도 분자가 있을 수 있음. 따라서 틀린 것은 a·c → ②

같은 온도 = 같은 평균 KE. 맥스웰 분포는 꼬리가 있어 어떤 기체든 극히 빠른 분자가 일부 존재한다(b가 옳은 이유).
문제 13이상기체정답 ②

사고과정

PV=nRT라 같은 T·P·V면 몰수(분자수) 동일(a ✓). b 몰질량 다름(N2 28 vs NH3 17) → 질량 다름. d 평균속력 ∝ 1/√M → 다름.

c 분자당 공유 전자쌍: N2(삼중결합 3쌍) = NH3(N−H 3개) → 분자수 같으니 총 공유결합 수 동일. → ②

N≡N의 삼중결합은 공유 전자쌍 3개, NH3의 N−H 3개도 3쌍. 우연히 분자당 공유결합 수가 같아진다.
문제 14분자량정답 ③

주어진 것 25 °C에서 He의 평균분자속도가 1300 m/s이다.

두 기체가 같은 온도에 있다는 점이 풀이의 출발점이다.

쓰는 법칙 기체 분자 운동론에서 분자 하나의 평균 운동에너지는 (3/2)kT로 온도에만 의존한다.

따라서 같은 온도에서는 (1/2)Mv2이 두 기체에서 같고, 이로부터 v ∝ 1/√M 이 나온다.

몰질량 표준 원자량(H 1.008, He 4.003)으로 M(H2) = 2.016 g/mol, M(He) = 4.003 g/mol이다.

계산 v(H2)/v(He) = √(M(He)/M(H2)) = √(4.003/2.016) = √1.986 = 1.409이다.

따라서 v(H2) = 1300 × 1.409 = 1832 m/s이다.

몰질량을 2와 4로 어림하면 1300 × √2 = 1300 × 1.4142 = 1838.5 m/s가 된다.

결론 보기 중 이 값에 해당하는 것은 1838 m/s이므로 답은 ③이다.

온도 25 °C는 두 기체에 똑같이 적용되므로 계산식에는 직접 들어가지 않는다.

문제 15분자량정답 ②

주어진 것 동일 조건(같은 온도·압력)에서 기체 A의 확산 속도가 질소보다 1.3배 빠르다.

쓰는 법칙 그레이엄의 확산 법칙에 따라 같은 온도에서 확산 속도는 몰질량의 제곱근에 반비례한다.

즉 v ∝ 1/√M 이다.

식 세우기 v(A)/v(N2) = √(M(N2)/M(A)) = 1.3이다.

계산 표준 원자량(N 14.01)으로 M(N2) = 28.02 g/mol이다.

양변을 제곱하면 M(N2)/M(A) = 1.69이고, M(A) = 28.02 / 1.69 = 16.6 g/mol이다.

보기 대조 표준 원자량으로 계산한 몰질량은 헬륨 4.00, 메테인(CH4) 16.04, 아르곤 39.95, 이산화탄소 44.01이다.

16.6에 맞는 것은 메테인뿐이다.

되짚어 보면 CH4의 확산 속도 비는 √(28.02/16.04) = √1.747 = 1.32로 문제의 1.3배와 일치한다.

결론 답은 ②이다.

문제 16온도정답 ②

주어진 것 100 K, 2 L 용기의 산소 기체 평균속력이 v이다.

구할 것은 400 K, 1 L 용기의 수소 기체 평균속력이며, 둘 다 이상기체로 가정한다.

쓰는 법칙 이상기체의 평균속력은 √(8RT/πM)이므로 v ∝ √(T/M)이다.

이 식에는 부피도 압력도 기체의 양도 들어가지 않는다.

따라서 2 L와 1 L라는 용기 크기는 답을 바꾸지 않는다.

몰질량 표준 원자량(H 1.008, O 16.00)으로 M(O2) = 32.00 g/mol, M(H2) = 2.016 g/mol이다.

계산 v(H2)/v(O2) = √[(T2/M2)/(T1/M1)] = √[(400/2.016)/(100/32.00)] = √(198.4/3.125) = √63.5 = 7.97이다.

몰질량을 2와 32로 어림하면 √[(400/2)/(100/32)] = √(200 × 32/100) = √64 = 8이 된다.

나누어 보기 온도가 4배로 오르므로 √4 = 2배, 몰질량이 1/16로 줄므로 √16 = 4배이고, 두 효과를 곱하면 8배이다.

결론 답은 ② 8v이다.

문제 20평균자유행로정답 ①

사고과정

ㄱ 부피 일정 + T↑ → 속도↑ → 충돌 잦아짐(z↑). ㄷ T 일정 + P 2배 → 부피 반감 → 밀도 2배 → λ 반감.

ㄴ P↑(부피↓) → 밀도↑ → z 증가(불변 아님). ㄹ λ는 수밀도에만 의존(온도 무관) → 부피·분자수 같으면 불변. → ①

평균자유행로 λ ∝ 1/(수밀도)로 온도와 무관. 충돌빈도 z는 속도(온도)·밀도 둘 다에 의존한다.
문제 21반데르발스식정답 ①

사고과정

인력 보정 +a/V²(압력을 올려줌), 분자 부피 보정 −b(부피를 줄여줌). → (P + a/V²)(V − b) = RT. → ①

문제 36입자수정답 ④

주어진 것 NaCl 결정에서 Na+와 Cl−가 각각 면심입방구조를 이룬다는 사실이다.

구할 것은 단위 세포 안에 존재하는 이온의 총 개수이다.

세는 법 단위 세포의 경계에 걸친 입자는 여러 세포가 나누어 가지므로 몫으로 센다.

꼭짓점은 8개 세포가 공유하므로 1/8, 면심은 2개 세포가 공유하므로 1/2, 모서리는 4개 세포가 공유하므로 1/4, 세포 내부에 온전히 들어 있으면 1이다.

Cl− 세기 Cl−를 꼭짓점과 면 중심에 놓으면 꼭짓점 8 × 1/8 = 1개, 면심 6 × 1/2 = 3개이므로 합 4개이다.

이것이 면심입방구조 하나가 갖는 입자 수 4개이다.

Na+ 세기 Na+는 같은 세포의 모서리와 중심에 들어간다.

모서리 12 × 1/4 = 3개, 세포 중심 1 × 1 = 1개이므로 합 4개이다.

Na+ 역시 4개로, 두 이온이 각각 면심입방구조를 이룬다는 지문과 맞는다.

합 4 + 4 = 8개이다.

단위 세포당 화학식 단위 NaCl은 4개이고, 이온의 총 개수는 그 두 배인 8개이다.

결론 답은 ④이다.

몰랄농도 = 용질 몰수 / 용매 kg. 용액 100g 기준: NaCl 13g·물 87g. NaCl 몰수 = 13/58.5 = 0.2222몰, 물 = 0.087kg.

몰랄농도 = 0.2222 / 0.087 = 2.55 mol/kg → ③. (밀도 1.10은 미끼·몰랄농도엔 불필요)

몰랄농도는 질량%만으로 구해진다(용매 질량을 질량%로 얻음). 밀도는 몰농도 환산에만 필요하니 여기선 함정. 몰농도로 풀면 2.44(②)가 나오게 만든 오답 유도.
문제 53몰농도의특징정답 ④

사고과정

몰분율·질량%·몰랄농도는 질량/몰수 기준이라 온도 무관.

몰 농도는 부피 기준(mol/L)이라 부피가 온도 따라 팽창·수축 → 온도 의존.

→ ④

부피가 들어간 농도(몰농도)만 온도에 변한다. 질량·몰수 기준 농도는 온도가 변해도 일정하다.
문제 54농도계산정답 ①

사고과정

CuS 몰수 = 0.019/95.5 ≈ 2.0×10⁻⁴ mol = Cu²⁺ 몰수. 농도 = 2.0×10⁻⁴/2.0L = 1.0×10⁻⁴ M = 0.10 mM. → ①

난용성 CuS로 Cu²⁺를 정량하는 침전 분석. CuS 1몰 = Cu²⁺ 1몰이므로 질량/몰질량/부피로 농도를 구한다.
문제 55농도계산정답 ②

사고과정

CoCl2 + 2NaOH → Co(OH)2 + 2NaCl.

CoCl2 3mmol, NaOH 4mmol → NaOH 한계(3몰 필요는 6mmol).

Co(OH)2 = 4/2 = 2mmol → 0.002×93 = 186mg ≈ 200mg.

→ ②

계수비(1:2)로 한계 반응물을 판별. NaOH가 부족하면 생성물은 NaOH 기준으로 결정된다.
문제 56농도계산정답 ②

사고과정

S2O32− = 0.020×0.030 = 0.6mmol → I3− = 0.6/2 = 0.3mmol → Cu²⁺ = 0.3×2 = 0.6mmol = CuCO3.

CuCO3 = 0.6mmol×125 = 0.075g. 질량% = 0.075/0.50×100 = 15%. → ②

적정은 거꾸로 추적: 티오황산 몰수 → I3− → Cu²⁺. 계수비(2:1:2)를 차례로 적용한다(아이오딘 적정의 전형).
문제 57증기압력내림정답 ①

사고과정

NaCl은 이온화로 입자가 2배(유효 2M) → 증기압이 더 낮다.

포도당은 1배(1M) → 증기압 높다.

물이 증기압 높은 B(포도당) → 낮은 A(NaCl)로 이동 → A 수면 상승.

→ ①

증기압 내림은 입자 수(총괄성)에 비례. NaCl은 같은 몰농도라도 입자가 2배라 증기압이 더 낮아 물을 끌어온다.
문제 58증기압력정답 ①

사고과정

라울 법칙: P = x·300 + (1−x)·45 = 180 → 255x = 135 → x(메탄올) = 0.529.

메탄올:프로페인올 = 0.529:0.471 ≈ 53:47. → ①

이상용액 전체 증기압 = Σ(몰분율×순수 증기압). 미지수 x로 식을 세워 풀면 조성이 나온다.
문제 59실제용액①·② 복수정답

사고과정

곡선이 이상 직선 위 → 라울 법칙 양의 편차. ① 물-에탄올이 양의 편차 대표 예. ② 약한 A−B 결합 형성 → 흡열 용해. 둘 다 옳음.

③ 양의 편차(음 아님). ④ 양의 편차는 A−B 인력이 더 약함. → 복수정답 ①, ②

양의 편차: A−B 인력 < A−A·B−B → 분자가 더 잘 증발(증기압↑) + 흡열 용해 + 부피 팽창. 물-에탄올이 대표적.
문제 60어는점내림정답 ③

사고과정

어는점 내림 ∝ i×m: ① 0, ② 1×0.60 = 0.60, ③ 2×0.50 = 1.00(KF→K++F−), ④ 4×0.245 = 0.98(FeI3→Fe3++3I−).

i×m이 최대인 KF(1.00)가 어는점 최저.

→ ③

어는점 내림은 입자 농도(i×m)가 클수록 크다. 반트호프 인자 i(KF=2, FeI3=4)와 몰랄농도를 곱해 비교한다.
