이 식은 완충 용액의 pH가 짝염기/짝산의 "비"로만 결정된다는 것을 보여 줍니다.

단계 2) 해리도를 구합니다.

[H+] = Cα ⇒ 10−3 = 1.0 × α ⇒ α = 10−3 α = 0.001로 충분히 작으므로 근사가 타당합니다.

단계 3) Ka를 구합니다.

[A−]/[HA] = 10−2 = 0.01 단계 7) 문제가 묻는 것은 [HA]/[A−]이므로 역수를 취합니다.

해리도가 이미 1인 강전해질에는적용할 여지가 없지만, α = 0.01인 약염기에는 그대로 적용됩니다.

6) 물질 수지: 처음 넣어 준 B의 총량은 어디로가든 보존되므로 [BOH] + [B+] = 0.1 M 입니다.

단계 1) pH = 11 ⇒ pOH = 14 - 11 = 3 ⇒ [OH−] = 10−3 = 0.001 M 단계 2) 넣어 준 BOH가 0.1 M인데 생긴 OH−는 0.001 M뿐이므로 해리도 α = 0.01(1 %), BOH는 약염기입니다.BOH(aq) ⇌ B+(aq) + OH−(aq) (일부만 해리, 역반응 존재) 단계 3) 평형 농도를 정리합니다.

[B+] = [OH−] = 1.0×10−3 M, [BOH] = 0.1 - 0.001 = 0.099 M 단계 4) 염기 해리 상수도 구해 둡니다.

Kb = [B+][OH−]/[BOH] = (1.0×10−3)2/0.099 = 1.0×10−6/0.099 ≈ 1.0×10−5 암모니아(Kb = 1.8×10−5)와 비슷한 수준의 전형적인 약염기입니다.

46 단계 5) 세 농도의 합을 계산합니다.

[BOH] + [B+] + [OH−] = 0.099 + 0.001 + 0.001 = 0.101 M 0.2 M과는 전혀 다릅니다.

따라서 ③이 틀린 설명입니다.

① 물의 자동이온화에 의해 만들어진 H+ 농도와 OH− 농도는 같다 ⇒ 옳음.

H2O ⇌ H+ + OH− 는 1 : 1 반응이므로물에서 유래한 두 이온의 양은 언제나 같습니다.

여기서는 둘 다 [H+] = Kw/[OH−] = 1.0×10−14/1.0×10−3 =1.0×10−11 M 입니다.

② 용액을 묽히면 해리도가 커진다 ⇒ 옳음.

BOH는 α = 0.01인 약염기이므로 오스트발트희석률이 그대로 적용됩니다.

묽히면 [OH−]는 줄지만 해리도는 커집니다.

③ [BOH] + [B+] + [OH−] = 0.2 M 이다⇒ 틀림(정답).

물질 수지에서 [BOH] + [B+] = 0.1 M 이고 여기에 [OH−] = 0.001 M을 더하면 0.101 M 입니다.

0.2M이 나오려면 완전 해리(α = 1)여야 하는데, pH가 11이라는 것은 그렇지 않다는 증거입니다.

④ HCl을 소량 첨가하여도 [H+]×[OH−] 는 일정하다 ⇒ 옳음.

[H+][OH−]는 정의상 Kw이고 Kw는 온도만의 함수입니다.

HCl을 넣으면 [H+]가 커지고 [OH−]가 그만큼 작아져 곱은 25 °C에서 항상 1.0×10−14로 유지됩니다.

③ 세 농도의 합은 0.101 M이지 0.2 M이 아닙니다.
