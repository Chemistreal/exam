문제 1수소원자정답 ④

사고과정

① 먼저 "개수로 가장 많은 원자"가 무엇인지 정한다. 질량으로 따지면 우리 몸의 약 65%가 산소이지만, 그건 질량 기준이다. 묻는 것은 원자 개수다.

② 몸의 대부분은 물(H2O)이고, 물 한 분자마다 수소 원자가 2개씩 들어 있다. 분자 수도 많고 분자당 H도 2개이므로, 개수로 압도적으로 많은 원자는 수소(H)다.

③ 수소의 거의 전부는 가장 흔한 동위원소 1H(경수소)다. 질량수 1 = 양성자 1 + 중성자 0 이므로 중성자가 없다. 중성 원자이므로 전자는 1개.

④ 따라서 1H이 가진 입자는 양성자와 전자뿐. → ④

함정: "모든 원자는 양성자·중성자·전자를 가진다"고 외워 ③을 고르기 쉽다. 하지만 수소의 대부분인 1H은 중성자가 없는 유일한 핵이다. "개수로 가장 많은 = 수소 = 중성자 없음"이 핵심.
문제 2원자,이온정답 ④

사고과정

쓸 관계식 두 개를 먼저 떠올린다. 전하 = 양성자수 − 전자수, 질량수 = 양성자수 + 중성자수.

(가) 1행: 양성자 20, 전하 +2. 전자수 = 양성자 − 전하 = 20 − 2 = 18.

(나) 2행: 양성자 23, 전자 20. 전하 = 23 − 20 = +3 → 더할 값은 3.

(다) 3행: 5626Fe2+은 질량수 56, 원자번호(양성자) 26. 중성자 = 56 − 26 = 30. (이온이어도 핵은 그대로 — +2는 전자가 2개 빠진 것일 뿐 중성자수와 무관하다.)

합 = 18 + 3 + 30 = 51. → ④

실수 포인트: (나)에서 전하 부호(+)에 끌려 다른 값을 넣지 말 것. 이온 56Fe2+의 중성자를 "전하 때문에 바뀐다"고 착각하면 (다)를 틀린다.
문제 3원자의크기정답 ②

사고과정

각 단위의 정의를 m로 환산한다. 1 Å = 10−10 m, 1 pm = 10−12 m.

1 Å를 pm으로: 10−10 ÷ 10−12 = 102 → 1 Å = 100 pm = 102 pm. → ②

기억법: 0.1 nm = 1 Å = 100 pm. 원자 반지름·결합 길이가 대개 1~3 Å = 100~300 pm 범위라는 감각을 함께 익혀두면 좋다.
문제 4원자핵의크기정답 ②

사고과정

두 척도의 대표값을 떠올린다. 원자 반지름 ≈ 1 Å = 10−10 m, 원자핵 반지름 ≈ 수 fm = 10−15 m(페르미 단위).

비율 ≈ 10−10 ÷ 10−15 = 105. → ②

의미: 핵은 원자 크기의 10만분의 1. 원자는 사실상 텅 빈 공간이다. 핵을 야구공이라 하면 원자는 수 km 규모 — 러더퍼드 α입자 산란 실험이 보여준 "작고 무거운 핵"과 직결된다.
문제 5원자의크기정답 ③

사고과정

① 하루 성장 길이 = 1 mm = 10−3 m.

② 원자 한 층의 두께 ≈ 원자 지름 ≈ 1 Å = 10−10 m (문제 3의 척도 활용).

③ 하루에 쌓이는 층 수 = 10−3 ÷ 10−10 = 107 층.

④ 하루 = 24 × 3600 = 86400 s ≈ 8.6 × 104 s.

⑤ 매 초 층 수 = 107 ÷ (8.6 × 104) ≈ 116 ≈ 102 → 약 100개. → ③

자릿수(order of magnitude) 추정 문제. 보기가 1·10·100·1000으로 자릿수만 다르므로 정밀 계산 없이 지수만 맞추면 된다: 107/104.9 ≈ 102.
문제 6녹는점정답 ③

사고과정

① 열량 공식 Q = m·c·ΔT를 쓴다. 구할 것은 올라간 온도 ΔT.

② ΔT = Q ÷ (m·c) = 2280 ÷ (36 × 0.70) = 2280 ÷ 25.2 ≈ 90.5°C.

③ 시작이 25°C였으므로 녹는점 = 25 + 90.5 ≈ 115°C. → ③

"녹기 직전까지"이므로 이 열은 모두 온도를 올리는 데(현열) 쓰였고, 녹이는 데(잠열, 융해열)는 아직 쓰이지 않았다. 그래서 단순 Q=mcΔT로 충분하다.
문제 7화학변화정답 ②

사고과정

"새로운 물질이 생기는 변화(화학변화)"인지를 각 보기에서 따진다.

① 도시가스 연소 → 새로운 물질(CO2, H2O) 생성. 화학변화 관련.

② 빛의 흡수·반사는 물질의 종류가 바뀌지 않는 물리 현상(광학). 화학변화와 무관. → ②

③ 잘 구워진 색은 마이야르 반응 등 화학변화의 결과물이므로 화학변화와 관련. ④ 냄새는 가열로 생성된 화합물을 맡는 것이라 역시 관련.

"직접 관련 없는 것"을 고르는 부정형 문항. ②만 물질 변화가 없는 순수 물리 현상이다.
문제 8태양에너지정답 ②

사고과정

각 현상의 에너지가 결국 태양에서 오는지 추적한다.

① 호흡 에너지는 음식 → 광합성 → 태양. ③ 수력은 물의 증발·순환 → 태양. ④ 화력은 화석연료 → 고대 생물 → 고대 태양. 모두 태양 기원.

② 우라늄-235의 핵붕괴는 핵 자체의 에너지(핵에너지)로, 태양과 무관하다. → ②

지구 에너지의 거의 전부는 태양에서 오지만, 예외가 핵에너지와 지열(지구 내부 방사성 붕괴)이다. ②는 그 예외에 해당.
문제 9원자의표기정답 ④

사고과정

표기 질량수원자번호원소에서, 아래첨자(원자번호)가 그 원소의 양성자수와 맞는지 확인한다.

① Li는 원자번호 3 ✓ ② C는 6 ✓ ③ P는 15 ✓.

④ 구리(Cu)의 원자번호는 29인데 표기는 ₃₀로 되어 있다. 따라서 틀린 표기. → ④ (올바른 표기는 6329Cu)

주기율표에서 Cu(29), Zn(30) 순서를 기억하면 즉시 잡힌다. 원자번호=양성자수는 원소의 정체성이므로 절대 바뀌지 않는다.
문제 10원자의구조정답 ①

사고과정

원소의 정의: 원소는 양성자수(원자번호)로 결정된다.

① 양성자수가 바뀌면 원자번호가 바뀌므로 항상 다른 원소. 참 → ①

② 중성자수만 다르면 동위원소 — 같은 원소. 거짓.

③ 전자수만 다르면 이온 — 같은 원소. 거짓.

④ 양성자 2개 이상 + 중성자 0인 핵은 양성자 간 반발을 묶어줄 중성자가 없어 결합하지 못한다(예: 양성자 2개의 "²He"는 존재하지 않음). 거짓.

①·②·③을 한 줄로: 원소=양성자, 동위원소=중성자 차이, 이온=전자 차이. 헷갈리면 이 대응만 떠올리면 된다.
문제 11원자량정답 ①

사고과정

개별 원자 하나하나는 정수에 가까운 질량수를 갖는 특정 동위원소다: 12C(질량 ≈ 12) 또는 13C(질량 ≈ 13).

12.011은 이들이 자연 비율로 섞였을 때의 평균값일 뿐, 어떤 개별 원자도 12.011이라는 질량을 갖지 않는다.

따라서 단 하나의 원자가 12.011을 가질 확률은 0%. → ①

"평균은 실제 한 개의 값이 아니다"라는 개념. 학생 평균 키가 165.3 cm여도 정확히 165.3 cm인 학생이 없을 수 있는 것과 같다.
문제 12질량비정답 ③

사고과정

① 원자량을 A = a, B = b로 둔다. A2B의 질량비는 2a : b = 60 : 40 = 3 : 2 → a/b = 3/4.

② 편하게 a = 3, b = 4로 잡는다.

③ AB2의 질량비 = a : 2b = 3 : 8.

④ 백분율로 = 3/11 : 8/11 ≈ 27 : 73. → ③

핵심은 "원자량 비는 화합물이 바뀌어도 그대로"라는 점. A2B에서 원자량 비(3:4)를 뽑아낸 뒤, 그것을 AB2의 개수비에 다시 적용한다.
문제 13동위원소정답 ①

사고과정

① 113A의 존재비를 x로 두면 115A는 1−x. 평균 원자량 식을 세운다.

② 112.9x + 114.9(1−x) = 114.8

③ 정리: 114.9 − 2x = 114.8 → 2x = 0.1 → x = 0.05.

④ 따라서 113A : 115A = 5 : 95. → ①

평균값 114.8이 무거운 쪽 114.9에 거의 붙어 있다 → 무거운 동위원소가 압도적으로 많다는 감각을 먼저 가지면, 5:95(가벼운 쪽이 적음)가 자연스럽다.
문제 14동위원소정답 ③

사고과정

① 평균 원자량 = (35×3 + 37×1)/4 = 142/4 = 35.5. 참.

② Cl2는 두 원자의 조합이라 35+35=70, 35+37=72, 37+37=74 → 피크 3개. 참.

③ 각 피크 확률: 70 → (3/4)2=9/16, 72 → 2(3/4)(1/4)=6/16, 74 → (1/4)2=1/16. 가장 큰 피크는 70(³⁵Cl–³⁵Cl)이지 71이 아니다. → ③ (틀림)

④ 몰 분자량 = 2 × 35.5 = 71 g/mol. 참.

함정: ④의 "71 g"(평균 기반 몰질량)과 ③의 "질량 스펙트럼 피크 71"을 혼동하게 만든다. 스펙트럼은 개별 동위원소 조합의 정수 질량(70·72·74)으로 찍히지, 평균 71에는 피크가 없다.
문제 15동위원소정답 ③

사고과정

가 AB 조합은 (14,16)=30, (14,17)=31, (15,16)=31, (15,17)=32. 조합은 4개지만 질량은 30·31·32 세 종류(31 중복). → 거짓.

나 B의 모든 동위원소는 양성자수가 같다(원소를 정의). 따라서 어떤 B2든 양성자 수는 2×(B의 원자번호)로 동일. → 참.

다 A의 평균 원자량 = 14.0×0.4 + 15.0×0.6 = 14.6. A2 평균 = 29.2 ≠ 29.0. → 거짓.

라 가장 무거운 B2 = 17B–17B = 34. → 참.

옳은 것은 나, 라. → ③

문제 16몰=질량/분자량정답 ④

사고과정

① 물 70 kg = 70000 g. 물 1몰 = 18 g이므로 몰수 = 70000/18 ≈ 3.9×103 mol.

② 분자 수 = 3.9×103 × 6.0×1023 ≈ 2.3×1027개.

③ 물 1분자에 원자 3개(H2O) → 원자 수 = 3 × 2.3×1027 ≈ 7×1027 ≈ 1028. → ④

실수 방지: "분자 수"가 아니라 "원자 수"를 물었으므로 ×3을 빼먹지 말 것. 그 한 단계가 ③(1027)과 ④(1028)를 가른다.
문제 17몰=질량/분자량정답 ③

사고과정

① 1.0 L = 1000 cm3, 밀도 1.0 g/cm3 → 질량 1000 g. 몰수 = 1000/18 ≈ 55.6 mol.

② 분자 수 = 55.6 × 6.0×1023 ≈ 3.3×1025개.

③ 원자 수 = 3 × 3.3×1025 ≈ 1.0×1026. → ③

②(3.3×1025)는 "분자 수"의 답이다. 물은 분자라는 점을 이용해 원자 수로 바꾸려면 ×3. 함정 보기 ②를 피하는 게 포인트.
문제 18몰=질량/분자량정답 ③

사고과정

① 몸속 물 = 50 kg × 0.7 = 35 kg = 35000 g. 몰수 = 35000/18 ≈ 1.9×103 mol.

② 분자 수 = 1.9×103 × 6.0×1023 ≈ 1.2×1027 ≈ 1027. → ③

문제 23PV=nRT정답 ④

문제 24PV=nRT정답 ④

사고과정

풍선 크기는 안쪽 압력과 바깥 압력의 균형으로 정해진다. 높이 올라가면 바깥 대기압이 낮아진다 — 즉 풍선을 누르던 힘이 약해진다.

압력은 "기체 분자가 벽을 때리는 충돌"이다. 고도가 높을수록 바깥 공기가 희박해 풍선 밖 공기가 벽을 때리는 빈도가 줄어든다 → 안쪽 기체가 밀어내 풍선이 커진다. → ④

①은 고도가 높으면 오히려 온도가 낮아져 틀리고, ②·③도 팽창의 직접 원인이 아니다.

"왜 커지나"의 본질은 바깥 압력 감소. 압력을 분자 충돌 빈도의 언어로 바꾼 것이 ④다.

문제 26PV=nRT정답 ①

문제 45ICE식정답 ③

사고과정

① 초기 기체는 O2 5몰뿐(흑연은 고체). 같은 T·V에서 압력 20%↑ → 최종 기체 = 5 × 1.2 = 6몰.

문제 46PV=nRT정답 ②

문제 49ICE식정답 ②

사고과정

① 질량 보존: A=2→C=3이면 반응한 B = 3−2 = 1. A=4→C=6이면 B = 2. 즉 반응 질량비 A:B = 2:1 → 몰질량비 MA = 2MB(계수 1:1 기준).

② 마지막 행 A=8, B=8: A:B=2:1이라 A 8g엔 B 4g만 필요 → B 4g 남고 A 한계. C = 8+4 = 12g, 남은 B = 4g.

③ 분압비 = 몰수비: (4/MB) : (12/MC) = 1:2 → MC = 1.5 MB.

④ 질량 보존 MA + MB = c·MC → 3MB = c·1.5MB → c = 2. → ②

질량비(2:1)로 몰질량 관계를, 잔여 B와 C의 분압비로 또 다른 관계를 얻어 연립한다. 표의 세 단계가 각각 "A한계 → 전이 → B한계"를 보여주는 게 설계 의도.
