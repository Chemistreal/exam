문제 1전지전위정답 ①

사고과정

전지는 산화형 1개(환원될 것)+환원형 1개(산화될 것)가 필요하고 E°cell>0이어야 함. ① MnO2(산화형, 1.23)+Li(환원형, −3.04) → E°cell=4.27V>0.

② Cd²⁺ 환원·Cu 산화면 E°cell=−0.74V<0. ③④ 산화형만 둘이라 산화될 게 없음. → ①

전지는 자발적 산화환원이 일어나야 한다. 한쪽은 산화형(환원전극), 한쪽은 환원형(산화전극)이어야 짝이 맞다.
문제 2전류의방향정답 ②

사고과정

Zn 산화전극(−)·Cu 환원전극(+).

전자는 Zn→Cu, 전류는 반대로 Cu→Zn(1).

음이온은 산화전극(Zn) 쪽으로 이동 → b.

→ ②

전류는 전자와 반대 방향(+극 Cu에서 나옴). 염다리·다공성판의 음이온은 양전하가 쌓이는 산화전극으로 간다.
문제 3전지전위정답 ③

사고과정

역방향 전지(Ag 산화·Cu 환원): E° = 0.337−0.799 = −0.462V. 반응 2Ag+Cu²⁺→2Ag⁺+Cu, Q=[Ag⁺]²/[Cu²⁺]=(0.01)²/0.01=10⁻².

E = −0.462 − (0.0592/2)log10⁻² = −0.462 + 0.0592 = −0.403V. → ③

전지 표기 방향이 바뀌면 E° 부호도 반대. 네른스트로 농도 보정(n=2, Q에 농도 대입).
문제 4표준환원전위정답 ①

사고과정

Q = [M2+]/[Ag+]2 = 0.01/0.12 = 1 → logQ=0 → E = E°cell = 0.46V.

E°cell = 0.80 − E°(M) = 0.46 → E°(M) = 0.34V.

→ ①

농도항이 상쇄돼 Q=1이면 측정 전위=표준 전위. E°cell=E°(환원)−E°(산화)로 미지값 역산.
문제 5에너지정답 ③

사고과정

가 전기 변환량은 ΔH 전부가 아니라 효율(카르노 등)로 제한돼 훨씬 작다. 다 연료전지는 터빈 없이 전기화학적으로 직접 전기 생산. → ③

나(에너지 보존·대체에너지 활용)는 옳다.

열기관은 ΔH 전부를 일로 못 바꾼다(카르노 한계). 연료전지의 강점은 터빈 없이 직접 전기를 만드는 것.
문제 6납축전지정답 ③

사고과정

나 황산(H₂SO₄) 소모로 용액 밀도↓. 다 환원전극서 PbO2→PbSO4. 가 H⁺ 소모로 pH는 올라감(낮아짐 아님). → ③

방전은 황산을 소비해 물을 만든다 → 밀도↓·pH↑. 충전 시 반대로 회복(밀도계로 충전 상태 측정).
문제 7반쪽반응정답 ④

사고과정

전자 수가 달라 전위를 직접 더할 수 없음 → ΔG(=−nFE)로 결합.

(Cu2++e−→Cu+) = (Cu2++2e−→Cu) − (Cu++e−→Cu).

−1·a = −2(0.34) + 1(0.52) → −a = −0.16 → a = +0.16V.

→ ④

전위는 세기 성질이라 단순 합산 불가. ΔG는 크기 성질이라 더할 수 있다(n 곱해서).
문제 8리튬공기전지정답 ④

사고과정

방전 2Li+O2→Li2O2(O2 흡수), 충전은 역(O2 방출). ④ 충전 시 O2를 대기로 방출해 전지 질량 감소(동일 아님). → ④

①(Li 산화전극)·②(Li 산화돼 질량↓)·③(Li2O2 분해로 질량↓)은 옳다.

공기전지는 O2가 드나들어 질량이 변한다. 방전 시 흡수해 무거워지고 충전 시 방출해 가벼워진다.
문제 9에너지정답 ②

사고과정

①(N/m²·m³=J)·③(J/K·K=J)·④(V·C=J)는 모두 에너지(J). ② 힘×속도 = N·m/s = W(일률). → ②

일률(W)=에너지/시간. 힘×속도만 시간이 들어가 단위가 다르다.
문제 10전기분해정답 ②

사고과정

② H2:O2 부피비 2:1 = 몰비(같은 부피=같은 분자수, 아보가드로). 옳음.

① 질량비 = (2×2):(1×32) = 1:8. ③ (−)극은 환원(물→H2). ④ (+)극은 산화(물→O2). → ②

부피비=몰비(아보가드로). 음극은 환원(H2), 양극은 산화(O2). 질량비는 몰질량을 곱해야.
문제 11소금물의전기분해정답 ③

사고과정

③ 음극서 OH⁻ 생성·양극은 Cl2(H⁺ 안 생김) → 용액 염기성 → pH 올라감(낮아짐 아님). → ③

①(고농도→Cl2)·②(항상 H2)·④(저농도→O2)는 옳다.

음극 환원은 항상 OH⁻를 만든다. 양극서 Cl2가 나오면 H⁺가 안 생겨 OH⁻가 쌓여 pH가 오른다.

문제 13온도에따른 변화정답 ②

사고과정

② 온도↑면 분포가 넓어지며 봉우리 높이가 낮아짐 → 최빈속도 분자 수 감소(증가 아님). → ②

①(최빈속도 오른쪽 이동)·③(평균속도↑)·④(분포 넓어짐)는 옳다.

고온서 봉우리는 오른쪽으로 가며 낮고 넓어진다. 최빈속도 값은 커지나 그 속도의 분자 수는 줄어든다.
문제 14반응속도정답 ①

사고과정

온도↑ → k 증가(아레니우스) → 속도(=k[A])도 증가.

둘 다 증가.

→ ①

k는 온도의 함수라 온도가 오르면 커지고, 속도식에 k가 들어가니 속도도 함께 증가한다.
문제 15초기속도법정답 ④

사고과정

BrO3− 2배→2배(1차), Br− 3배→3배(1차), H+ 2배→4배(2차).

속도 = k[BrO3−][Br−][H+]2.

k 식은 분모에 [H+]2가 들어가야(④).

③은 [H+]1만 써서 틀림.

→ ④

속도식이 [H+]2면 k 계산식 분모도 [H+]2여야 한다. 차수와 k 식의 일관성을 확인.
문제 16초기속도법정답 ②

사고과정

OCl− 반→반(1차), OH− 반→2배(−1차), I− 2배→2배(1차).

속도 = [I−][OCl−][OH−]−1.

[OH−]만 변하는 쌍 필요: (6)(7)(I−·OCl− 같고 OH−만 0.10↔0.20).

(5)(6)은 OH− 같아 불가.

→ ②

특정 농도의 차수를 구하려면 그 농도만 바꾸고 나머지를 고정한 실험 쌍이 필요. (6)(7)이 OH−만 다르다.
문제 17초기속도법정답 ③

사고과정

실1→2: [A] 반→속도 반(A 1차).

실2→3: [B] 2배→속도 2배(B 1차).

속도 = k[A][B].

→ ③

B 계수가 3이어도 차수는 실험으로 결정(1차). 속도식은 화학량론이 아니라 데이터에서.
문제 18초기속도법정답 ②

사고과정

총 부피 일정이라 농도∝저장용액 부피.

Br− 1차·BrO3− 1차.

H3O+: (0.7)n=0.5 → n≈2.

속도 = k[Br−][BrO3−][H3O+]2.

→ ②

전체 부피를 일정하게 맞추면 각 시약 부피가 곧 농도에 비례. 비정수 배수는 로그로 차수를 구한다.
문제 19단일단계반응정답 ①

단일반응이라 속도 = k[CH3OH][OH⁻]. pH 13: [OH⁻]=10⁻¹, pH 14: [OH⁻]=10⁰. 비 = 0.1:1 = 1:10. → ①

단일반응은 화학량론=차수. OH⁻ 1차라 [OH⁻] 10배면 속도 10배.

문제 27열역학정답 ④

문제 28평형상수정답 ④

사고과정

정·역 속도상수의 비가 평형상수. K가 온도에 의존하므로 그 비도 온도에 따라 변한다.
문제 29활성화에너지정답 ④

사고과정
