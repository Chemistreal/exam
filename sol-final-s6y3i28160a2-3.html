문제 1평형상수정답 ④

H₃PO₄의 산 해리상수(Ka1, Ka2, Ka3)와 물의 이온곱상수(Kw)를 이용하여 다음 반응의 평형상수를 나타낸 것으로 옳은 것은? H₃PO₄(aq) + 2OH⁻(aq) ⇌ HPO₄²⁻(aq) + 2H₂O(l) ① Ka1 × Ka2 / Kw ② Ka1 × Ka3 / Kw² ③ Ka2 × Ka3 / Kw² ④ Ka1 × Ka2 / Kw² ■ 무엇을 묻는 문제인가 목표 반응식을 이미 알고 있는 몇 개의 기본 반응식의 "합"으로 분해한 뒤, 헤스의 법칙과 같은 원리를 평형상수에 적용하는 문제입니다.

반응식을 더하면 평형상수는 곱해지고, 반응식을 뒤집으면 평형상수는 역수가 된다는 규칙만 정확히 쓰면 되는 전형적인 조합 문항입니다.

1) 평형상수의 조합 규칙 반응식을 더한다 ⇒ 평형상수를 곱한다 반응식을 뒤집는다 ⇒ 평형상수를 역수(1/K)로 바꾼다 반응식에 n을 곱한다 ⇒ 평형상수를 n제곱한다 2) 인산의 단계별 산 해리 H₃PO₄ ⇌ H₂PO₄⁻ + H⁺ , Ka1 H₂PO₄⁻ ⇌ HPO₄²⁻ + H⁺ , Ka2 HPO₄²⁻ ⇌ PO₄³⁻ + H⁺ , Ka3 3) 물의 자동이온화 H₂O(l) ⇌ H⁺(aq) + OH⁻(aq) , Kw 따라서 그 역반응 H⁺(aq) + OH⁻(aq) ⇌ H₂O(l) 의 평형상수는 1/Kw 입니다.

4) 짝산·짝염기 관계: Ka × Kb = Kw.

단계 1) 목표 반응식을 씁니다.

H₃PO₄(aq) + 2OH⁻(aq) ⇌ HPO₄²⁻(aq) + 2H₂O(l) 단계 2) H₃PO₄에서 HPO₄²⁻로 가려면 양성자 두 개를 떼야 하므로 Ka1과 Ka2 단계를 더합니다.

H₃PO₄ ⇌ H₂PO₄⁻ + H⁺ , Ka1 H₂PO₄⁻ ⇌ HPO₄²⁻ + H⁺ , Ka2 합: H₃PO₄ ⇌ HPO₄²⁻ + 2H⁺ , K = Ka1 × Ka2 단계 3) 떨어져 나온 H⁺ 두 개를 OH⁻ 두 개로 중화시켜 물로 만듭니다.

H⁺ + OH⁻ ⇌ H₂O , K = 1/Kw 이 반응이 2번 필요하므로: 2H⁺ + 2OH⁻ ⇌ 2H₂O , K = (1/Kw)² = 1/Kw² 단계 4) 두 반응식을 더하면 H⁺가 양변에서 소거되어 목표 반응식이 됩니다.

H₃PO₄ + 2OH⁻ ⇌ HPO₄²⁻ + 2H₂O 단계 5) 평형상수는 곱해집니다.

K = (Ka1 × Ka2) × (1/Kw²) = Ka1 × Ka2 / Kw² 단계 6) 염기 해리상수로 검산합니다.

이 반응은 HPO₄²⁻의 1단계 가수분해(Kb = Kw/Ka2)와 H₂PO₄⁻의 가수분해(Kb = Kw/Ka1)를 각각 뒤집어 더한 것과 같으므로 K = 1 / ((Kw/Ka2) × (Kw/Ka1)) = Ka1 × Ka2 / Kw² 로 같은 결과가 나옵니다.

① Ka1 × Ka2 / Kw ⇒ 틀림.

Ka 두 개는 맞지만 물이 2몰 생기므로 Kw가 제곱이어야 합니다.

중화가 두 번 일어났다는 사실을 놓친 선지입니다.

② Ka1 × Ka3 / Kw² ⇒ 틀림.

Ka3는 HPO₄²⁻ → PO₄³⁻ 단계로, 여기서는 HPO₄²⁻에서 멈추므로 등장하지 않습니다.

첫 단계와 마지막 단계를 붙여 쓴 잘못된 조합입니다.

③ Ka2 × Ka3 / Kw² ⇒ 틀림.

출발 물질을 H₂PO₄⁻로 잘못 보았을 때 나오는 값입니다.

이 반응은 H₃PO₄에서 출발하므로 Ka1부터 세야 합니다.

④ Ka1 × Ka2 / Kw² ⇒ 옳음.

H₃PO₄ → H₂PO₄⁻ → HPO₄²⁻ 두 단계(Ka1 × Ka2)에 중화 두 번(1/Kw²)을 곱한 값입니다.

④ K = Ka1 × Ka2 / Kw² 입니다.

문제 2평형상수정답 ①

다음은 다양성자 산(H₂A)의 해리와 관련된 화학반응식과 평형상수를 나타낸 것이다.

25 °C에서 Ka1 = 10⁻³, Ka2 = 10⁻⁶이라고 할 때 다음 반응의 평형상수 값과 가장 가까운 것은? A²⁻(aq) + 2H₂O(l) ⇌ H₂A(aq) + 2OH⁻(aq) ① 10⁻¹⁹ ② 10⁻⁹ ③ 10⁹ ④ 10¹⁹ ■ 무엇을 묻는 문제인가 헤스 법칙의 평형 상수 버전, 즉 "반응식을 더하면 평형 상수는 곱하고, 뒤집으면 역수, 계수를 n배 하면 n제곱"이라는 규칙을 다양성자산에 적용하는 문제입니다.

특히 2가 짝염기 A²⁻가 물에서 두 단계로 가수분해되는 과정을 Ka와 Kw로부터 조립해 낼 수 있는지가 핵심입니다.

1) 평형 상수의 조작 규칙 (가) 반응을 뒤집으면 K → 1/K (나) 반응식 전체에 n을 곱하면 K → K^n (다) 두 반응을 더하면 K → K₁ × K₂ 이 규칙들은 K가 농도의 곱/나눗셈 꼴이라는 정의에서 곧바로 나옵니다.

2) 주어진 산 해리 반응 1번식: H₂A + H₂O ⇌ H₃O⁺ + HA⁻, Ka1 = 10⁻³ 2번식: HA⁻ + H₂O ⇌ H₃O⁺ + A²⁻, Ka2 = 10⁻⁶ Ka1 > Ka2인 이유는 이미 음전하를 띤 HA⁻에서 다시 H⁺를 떼어내려면 정전기적 인력을 이겨야 하기 때문입니다.

보통 Ka1/Ka2는 10⁴~10⁵ 정도 차이가 납니다.

3) 물의 자체 이온화 3번식: 2H₂O ⇌ H₃O⁺ + OH⁻, Kw = 10⁻¹⁴ (25 °C) 4) 짝산-짝염기 관계: 어떤 산의 Ka와 그 짝염기의 Kb 사이에는 Ka × Kb = Kw가 성립합니다.

이때 주의할 점은 짝을 정확히 맞추는 것입니다.

A²⁻의 짝산은 HA⁻이므로 A²⁻의 Kb는 Ka2가 아니라 Kw/Ka2입니다.

마찬가지로 HA⁻의 염기 해리 상수는 Kw/Ka1입니다.

5) 구하려는 반응은 A²⁻가 물에서 두 번 연달아 양성자를 받아 H₂A가 되는 반응이므로, 가수분해 두 단계를 이어 붙이면 됩니다.

[방법 1: 염기 해리 상수를 이어 붙이기] 단계 1) 1단계 가수분해를 씁니다.

A²⁻의 짝산은 HA⁻이므로 대응하는 Ka는 Ka2입니다.

A²⁻ + H₂O ⇌ HA⁻ + OH⁻, Kb1 = Kw/Ka2 = 10⁻¹⁴/10⁻⁶ = 10⁻⁸ 단계 2) 2단계 가수분해를 씁니다.

HA⁻의 짝산은 H₂A이므로 대응하는 Ka는 Ka1입니다.

HA⁻ + H₂O ⇌ H₂A + OH⁻, Kb2 = Kw/Ka1 = 10⁻¹⁴/10⁻³ = 10⁻¹¹ 단계 3) 두 식을 더하면 HA⁻가 양변에서 지워지고 구하려는 식이 됩니다.

A²⁻ + 2H₂O ⇌ H₂A + 2OH⁻ 단계 4) 더했으므로 평형 상수는 곱합니다.

K = Kb1 × Kb2 = 10⁻⁸ × 10⁻¹¹ = 10⁻¹⁹ [방법 2: 주어진 세 식을 조합하기] 단계 1) 구하려는 식은 [(3번식 × 2) - 1번식 - 2번식]으로 만들 수 있습니다.

단계 2) 3번식 × 2 : 4H₂O ⇌ 2H₃O⁺ + 2OH⁻, K = (10⁻¹⁴)² = 10⁻²⁸ 단계 3) 1번식을 뺀다 = 1번식을 뒤집어 더한다 : H₃O⁺ + HA⁻ ⇌ H₂A + H₂O, K = 1/10⁻³ = 10³ 단계 4) 2번식을 뺀다 = 2번식을 뒤집어 더한다 : H₃O⁺ + A²⁻ ⇌ HA⁻ + H₂O, K = 1/10⁻⁶ = 10⁶ 단계 5) 세 식을 모두 더하면 양변에서 H₃O⁺ 2개, HA⁻ 1개, H₂O 2개가 지워지고 A²⁻ + 2H₂O ⇌ H₂A + 2OH⁻ 가 남습니다.

단계 6) 평형 상수는 세 값의 곱입니다.

K = 10⁻²⁸ × 10³ × 10⁶ = 10⁻²⁸⁺³⁺⁶ = 10⁻¹⁹ 두 방법 모두 K = 10⁻¹⁹로 일치합니다.

① 10⁻¹⁹ ⇒ 옳음.

K = (Kw)²/(Ka1 × Ka2) = (10⁻¹⁴)²/(10⁻³ × 10⁻⁶) = 10⁻²⁸/10⁻⁹ = 10⁻¹⁹입니다.

② 10⁻⁹ ⇒ 틀림.

Kw를 제곱하지 않고 한 번만 쓰면(10⁻¹⁴/10⁻⁹ = 10⁻⁵) 나오는 값도 아니고, Ka1 × Ka2 = 10⁻⁹를 그대로 답으로 옮겼을 때 나오는 값입니다.

구하려는 반응은 산 해리가 아니라 그 역방향의 가수분해라는 점을 놓친 경우입니다.

③ 10⁹ ⇒ 틀림.

1/(Ka1 × Ka2) = 10⁹, 즉 H₂A + 2H₂O 대신 H₂A ⇌ ...

를 단순히 뒤집기만 하고 Kw² 항을 빠뜨렸을 때 나옵니다.

물이 반응물로 2 mol 들어가면서 OH⁻가 생긴다는 사실을 반영하지 않았습니다.

④ 10¹⁹ ⇒ 틀림.

부호가 반대입니다.

K가 1보다 훨씬 크다는 것은 A²⁻가 물에서 거의 완전히 H₂A로 바뀐다는 뜻인데, Ka2 = 10⁻⁶ 정도의 약산의 짝염기가 그렇게 강한 염기일 수는 없습니다.

지수의 부호만 봐도 걸러낼 수 있습니다.

① K = (Kw)²/(Ka1 × Ka2) = 10⁻²⁸/10⁻⁹ = 10⁻¹⁹입니다.

문제 3생성엔탈피정답 ④

다음 중 <보기>의 반응 중 흡열 반응을 모두 고른 것은? <보 기> ㄱ.

H₂(g) + I₂(s) → 2HI(g) ㄴ.

2C(s, 흑연) + H₂(g) → C₂H₂(g) ㄷ.

C(s, 흑연) + O₂(g) → CO₂(g) ① ㄱ ② ㄴ ③ ㄱ, ㄴ, ㄷ ④ ㄱ, ㄴ ■ 무엇을 묻는 문제인가 세 반응 모두 홑원소 물질에서 화합물 1종을 만드는 "생성 반응"입니다.

즉 표준 생성 엔탈피의 부호를 판단하는 문제입니다.

숫자를 외우지 않아도, 생성물이 안정한 분자인지 아닌지로 부호를 추론할 수 있어야 합니다.

1) 표준 생성 엔탈피 ΔHf°는 25 °C, 1 bar에서 가장 안정한 홑원소 물질로부터 화합물 1몰을 만들 때의 엔탈피 변화입니다.

홑원소 물질(H₂, O₂, 흑연 C, 고체 I₂ 등)의 ΔHf°는 정의상 0 입니다.

아이오딘의 표준 상태는 기체가 아니라 고체이고, 탄소의 표준 상태는 다이아몬드가 아니라 흑연이라는 점을 반드시 확인해야 합니다.

2) 반응엔탈피 ΔH = (생성물의 ΔHf° 합) - (반응물의 ΔHf° 합) 입니다.

반응물이 모두 홑원소 물질이면 ΔH = 생성물의 ΔHf° 합이 그대로 됩니다.

3) ΔH > 0 이면 흡열, ΔH < 0 이면 발열입니다.

4) 대부분의 화합물은 ΔHf°가 음수입니다.

일반적으로 무극성 공유 결합보다 극성 공유 결합이 더 강해서, 홑원소 물질의 결합을 끊고 화합물의 결합을 만들면 에너지가 남아 방출되기 때문입니다.

5) 예외가 나오는 대표적인 경우 ― 결합 세기 차이가 작은데 홑원소 쪽에 상변화(승화·기화) 비용이 얹히는 경우(HI), 삼중 결합처럼 결합 자체는 강해도 흑연을 낱개 탄소로 떼어내는 값이 훨씬 큰 불포화 탄화수소(C₂H₂, 아세틸렌), 그리고 옥텟이 깨진 라디칼(NO, NO₂)입니다.

6) 참고값 ― HI(g) +26.5 kJ/mol, C₂H₂(g) +227.4 kJ/mol, CO₂(g) -393.5 kJ/mol.

단계 1) ㄱ.

H₂(g) + I₂(s) → 2HI(g) ΔH = 2 × ΔHf°(HI) = 2 × (+26.5) = +53.0 kJ → 흡열 H-I 결합은 할로젠화 수소 중 가장 약하고, 게다가 반응물 쪽 I₂는 고체이므로 승화 에너지까지 치러야 합니다.

그래서 생성 반응이 흡열이 됩니다.

(만약 I₂(g)에서 출발한다면 발열이 되므로 상태 표기가 결정적입니다.) 단계 2) ㄴ.

2C(s, 흑연) + H₂(g) → C₂H₂(g) ΔH = +227.4 kJ → 흡열 아세틸렌은 C≡C 삼중 결합을 가진 불포화 탄화수소로 에너지가 높습니다.

흑연은 매우 안정한 그물 구조라 탄소 원자를 떼어내는 데 큰 에너지가 들고, 그 비용을 삼중 결합 형성으로 다 회수하지 못합니다.

아세틸렌이 연소할 때 엄청난 열을 내는 이유도 처음부터 에너지가 높기 때문입니다.

단계 3) ㄷ.

C(s, 흑연) + O₂(g) → CO₂(g) ΔH = -393.5 kJ → 발열 탄소의 완전 연소로, 대표적인 강한 발열 반응입니다.

단계 4) 흡열 반응은 ㄱ과 ㄴ 두 개입니다.

① ㄱ ⇒ 틀림.

ㄱ이 흡열인 것은 맞지만 ㄴ도 흡열이므로 답이 될 수 없습니다.

② ㄴ ⇒ 틀림.

ㄴ이 흡열인 것은 맞지만 ㄱ을 빠뜨렸습니다.

I₂가 고체 상태라는 점을 놓치고 ㄱ을 발열로 판단하면 이 선지를 고르게 됩니다.

③ ㄱ, ㄴ, ㄷ ⇒ 틀림.

ㄷ은 탄소의 연소로 ΔHf°(CO₂) = -393.5 kJ/mol인 강한 발열 반응입니다.

④ ㄱ, ㄴ ⇒ 옳음(정답).

HI(+26.5)와 C₂H₂(+227.4) 모두 ΔHf°가 양수이므로 두 생성 반응 다 흡열입니다.

④ ㄱ(ΔH = +53.0 kJ)과 ㄴ(ΔH = +227.4 kJ)이 흡열 반응입니다.

문제 4연소엔탈피정답 ②

② 글루코즈 쪽 수위가 올라간 그림 ⇒ 틀림.

문제 16삼투압정답 ①

물만 통과시키는 반투막(semipermeable membrane)으로 U자관이 두 칸으로 나뉘어 있다.

U자관의 왼쪽에는 0.20 M 설탕(sucrose) 용액 10 mL를, 오른쪽에는 0.15 M 염화 소듐 용액 10 mL를 넣었다.

평형에 도달한 후 U자관의 모습을 가장 잘 나타낸 것은 어느 것인가? ■ 무엇을 묻는 문제인가 총괄성은 용질의 종류가 아니라 녹아 있는 입자의 총 몰농도로 결정된다는 원리를 전해질과 비전해질의 비교로 묻는 문항이다.

총괄성(colligative property)은 녹아 있는 용질 입자의 수에만 의존하고 용질의 정체에는 무관한 성질이다.

증기 압력 내림, 끓는점 오름, 어는점 내림, 삼투압의 네 가지가 여기에 속한다.

삼투(osmosis)는 반투막을 사이에 두고 용매 분자만 묽은 용액 쪽에서 진한 용액 쪽으로 이동하는 현상이고, 삼투압(Π)은 이 이동을 막기 위해 진한 용액 쪽에 걸어야 하는 최소 압력이다.

계산식은 반트호프 식 Π = iMRT다.

M은 몰농도(mol/L), R = 0.08206 L·atm/(mol·K), T는 절대 온도이며, 기체 상태 방정식 PV = nRT와 형태가 같다.

반트호프 인자 i는 용질 1개가 용액에서 만드는 입자 수다.

설탕·포도당·요소는 1, NaCl·KBr은 2, CaCl₂·K₂SO₄는 3, AlCl₃는 4, Al₂(SO₄)₃는 5다.

실제 값은 이온쌍(ion pairing) 때문에 이론값보다 조금 작다.

같은 논리가 다른 총괄성에도 그대로 적용된다.

끓는점 오름 ΔT_b = i K_b m, 어는점 내림 ΔT_f = i K_f m이며 여기서는 몰랄 농도 m(mol/kg)을 쓴다.

적용 조건은 묽은 이상 용액이다.

농도가 진해지면 이온 간 상호작용 때문에 실측값이 계산값보다 작아진다.

삼투압은 네 총괄성 중 측정 감도가 압도적으로 크다.

0.010 M 용액도 25 °C에서 0.245 atm = 186 mmHg를 내므로, 어는점 내림으로는 잡히지 않는 고분자·단백질의 몰질량 측정에 삼투압을 쓴다.

생리 식염수 0.9% NaCl은 9.0 g/L ÷ 58.44 g/mol = 0.154 M, 입자 농도 0.308 mol/L로 혈액과 같은 등장액이다.

이 문항의 0.15 M NaCl이 바로 그 값이며, 적혈구를 저장액에 넣으면 물이 들어와 터지고 고장액에 넣으면 쭈그러든다.

역삼투(reverse osmosis)는 삼투압보다 큰 압력을 진한 쪽에 걸어 물을 거꾸로 짜내는 조작으로, 해수 담수화의 원리다.

시험 포인트 1: 총괄성 크기 비교 문항이 나오면 무조건 iM(또는 im)을 먼저 계산해 나열한다.

시험 포인트 2: 이동하는 것은 물이고 이동하지 않는 것은 용질이라는 원칙을 그림 문항에서 항상 확인한다.

구분 왼쪽 설탕 용액 오른쪽 NaCl 용액 몰농도 0.20 M 0.15 M 반트호프 인자 i 1 2 입자(삼투) 몰농도 0.20 M 0.30 M 25 °C 삼투압 4.89 atm 7.34 atm 물의 출입 빠져나감(액면 하강) 들어옴(액면 상승) STEP 1.

(반투막이 무엇을 통과시키는지 확정) ― 이 막은 물만 통과시킨다.

설탕 분자도, Na⁺도, Cl⁻도 넘어가지 못한다.

따라서 양쪽 칸의 용질 몰수는 처음 값 그대로 보존되고 오직 물만 이동한다.

STEP 2.

이동량까지 따지면 이렇다.

① ◎ 정답 오른쪽(NaCl) 칸의 액면이 올라가고 왼쪽(sucrose) 칸이 그만큼 내려가, 두 액면이 처음 높이를 사이에 두고 위아래로 갈라진 그림이다.

설탕은 비전해질이라 삼투 몰농도가 0.20 osmol L⁻¹이지만 NaCl은 i = 2이므로 0.15 × 2 = 0.30 osmol L⁻¹이 되어, 물은 삼투 몰농도가 낮은 왼쪽에서 높은 오른쪽으로 이동한다.

총괄성은 용질의 종류가 아니라 용액 속 입자의 총 농도가 결정하므로, NaCl이 Na⁺와 Cl⁻ 두 입자로 해리된다는 사실을 넣는 순간 대소가 뒤집힌다.

왼쪽이 완전히 비면 설탕 농도가 무한대가 되어야 하므로 물리적으로도 불가능하다.

④ ✕ (C)를 좌우로 뒤집은 그림으로, 오른쪽(NaCl) 칸이 바닥까지 비고 왼쪽(sucrose) 칸이 가득 찬 모습이다.

문제 17이온화에너지정답 ①

Li²⁺의 이온화에너지는 H의 이온화에너지의 9배이다.

Li²⁺의 전자를 떼어내기 위해 필요한 빛의 최대 파장 값과 가장 가까운 것은? (단, 수소원자의 에너지 준위는 En = -RH/n² 으로 RH = 2.2×10⁻¹⁸ J 이고 n은 자연수이다.) ① 10 nm ② 50 nm ③ 90 nm ④ 130 nm ■ 무엇을 묻는 문제인가 보어 모형의 에너지 준위식으로 이온화에너지를 구하고, 그 에너지를 광자의 파장으로 환산하는 문제입니다.

"최대 파장"이라는 표현이 왜 "최소 에너지 = 이온화에너지 정확히"를 뜻하는지 이해하는 것이 핵심입니다.

1) 전자가 하나뿐인 수소 유사 이온(H, He⁺, Li²⁺, Be³⁺ …)의 에너지 준위는 En = -Z²RH/n² 입니다.

Z는 원자번호(핵전하)이고 RH = 2.2×10⁻¹⁸ J 입니다.

Li²⁺는 Z = 3 이므로 Z² = 9, 즉 수소의 9배가 되어 문제의 조건과 정확히 맞아떨어집니다.

2) 이온화에너지는 바닥상태(n = 1)의 전자를 완전히 떼어내는(n = ∞) 데 필요한 에너지입니다.

ΔE = E∞ - E₁ = 0 - (-Z²RH) = Z²RH 수소라면 ΔE = RH = 2.2×10⁻¹⁸ J 입니다.

3) 광자 1개의 에너지는 E = hν = hc/λ 이므로 λ = hc/E 입니다.

파장과 에너지는 반비례합니다.

4) 따라서 이온화를 일으킬 수 있는 광자 중 "가장 긴 파장"은 곧 "가장 작은 에너지", 즉 이온화에너지와 정확히 같은 에너지를 가진 광자입니다.

이보다 파장이 길면 에너지가 부족해 이온화가 일어나지 않습니다(광전 효과의 문턱 개념과 같습니다).

5) 사용 상수 ― h = 6.63×10⁻³⁴ J·s, c = 3.00×10⁸ m/s, 1 nm = 10⁻⁹ m.

단계 1) Li²⁺의 이온화에너지를 구합니다.

E = 9 × RH = 9 × 2.2×10⁻¹⁸ J = 1.98×10⁻¹⁷ J 단계 2) 최대 파장 조건을 세웁니다.

최대 파장 = 최소 에너지 = 이온화에너지이므로 λ(최대) = hc/E 단계 3) 숫자를 대입합니다.

λ = (6.63×10⁻³⁴ J·s × 3.00×10⁸ m/s) / (9 × 2.2×10⁻¹⁸ J) = (1.989×10⁻²⁵ J·m) / (1.98×10⁻¹⁷ J) = 1.00×10⁻⁸ m 단계 4) 단위를 nm로 바꿉니다.

1.00×10⁻⁸ m = 10.0 nm 단계 5) 선지 중 가장 가까운 값은 10 nm 입니다.

참고로 수소 원자였다면 λ = hc/RH ≈ 90 nm 가 되므로, 9배 곱하는 것을 잊으면 선지 ③에 걸리게 설계되어 있습니다.

① 10 nm ⇒ 옳음(정답).

Z² = 9 를 반영한 정확한 계산 결과 10.0 nm 입니다.

② 50 nm ⇒ 틀림.

적정으로 실제 반응한 몰수를 구하고, 온도 상승으로부터 방출된 열량을 구한 다음, 그 열량을 반응 몰수로 나누어 1 mol당 값으로 바꾸는 것이 핵심입니다.

대부분의 실수는 마지막 단계, 즉 mmol 단위로 구한 몰수를 mol로 바꾸는 곳에서 나옵니다.

2) 몰수 계산에서 mol과 L 대신 mmol과 mL를 함께 쓰면 편합니다.

몰수(mmol) = 몰농도(M) × 부피(mL)로 바로 계산됩니다.

3) 열량 공식 Q = c × m × ΔT 입니다.

비열 c는 "물질 1 g의 온도를 1 °C 올리는 데 필요한 열량"으로 정의되므로, 질량 m(g)과 온도 변화 ΔT(°C)를 곱하면 그대로 열량이 됩니다.

산의 부피와 염기의 부피를 더한 뒤 밀도를 곱해야 합니다.

산만, 또는 염기만 넣으면 틀립니다.

6) 중화엔탈피는 "물 1 mol이 생성될 때" 또는 "H⁺ 1 mol이 중화될 때"의 엔탈피 변화입니다.

n(KOH) = 0.1 M × 10 mL = 1 mmol → OH⁻ 1 mmol 단계 2) 당량점이므로 반응한 산의 몰수도 같습니다.

크기로는 240 kJ/mol 입니다.

③ 120 kJ/mol ⇒ 틀림.

반응 좌표 그래프에서 반응물 높이에서 산꼭대기까지의 수직 거리입니다.

산꼭대기(전이상태)는 정반응이든 역반응이든 하나로 같습니다.

이것이 핵심입니다.

3) 반응엔탈피 ΔH는 생성물의 에너지에서 반응물의 에너지를 뺀 값, 즉 그래프에서 시작점과 끝점의 높이 차이입니다.

4) 세 양의 관계는 그림 하나로 나옵니다.

전이상태의 높이를 두 가지 방법으로 표현하면 (반응물 높이) + Ea(정) = (전이상태 높이) = (생성물 높이) + Ea(역) 양변을 정리하면 (생성물 높이) - (반응물 높이) = Ea(정) - Ea(역) 즉 ΔH = Ea(정) - Ea(역) 입니다.

5) 부호의 의미: Ea(정) > Ea(역)이면 생성물이 반응물보다 위에 있어 ΔH > 0, 즉 흡열반응입니다.

반대로 Ea(정) < Ea(역)이면 발열반응입니다.

산을 올라간 높이보다 내려온 높이가 작으면 결국 출발점보다 높은 곳에 도착한다는 상식과 같습니다.

6) 주의할 점: 활성화에너지는 반응 속도를 결정하고 반응엔탈피는 열역학적 안정성을 결정합니다.

Ea가 크다고 흡열인 것도 아니고, 흡열이라고 반응이 느린 것도 아닙니다.

이 문제에서는 두 Ea가 모두 주어졌기 때문에 비로소 ΔH를 알 수 있는 것입니다.

Ea(정반응) = 85 kJ, Ea(역반응) = 30 kJ 단계 2) 관계식에 대입합니다.

ΔHrxn = Ea(정) - Ea(역) = 85 kJ - 30 kJ = +55 kJ 단계 3) 그림으로 검증합니다.

반응물 X의 높이를 0이라고 두면 전이상태는 0 + 85 = 85입니다.

생성물 Y는 전이상태에서 30만큼 내려온 자리이므로 85 - 30 = 55입니다.

따라서 Y는 X보다 55 kJ 높고 ΔH = +55 kJ, 흡열반응입니다.

단계 4) 역반응의 반응엔탈피는 부호만 바뀐 -55 kJ이며, 이 값이 선지 ①로 준비된 함정입니다.

① -55 kJ ⇒ 틀림.

부호를 반대로 계산한 값(30 - 85)입니다.

이 값은 역반응의 반응엔탈피에 해당합니다.

정반응이 +55 kJ이면 역반응은 정확히 -55 kJ입니다.

② 55 kJ ⇒ 옳음.

85 - 30 = 55 이며, 올라간 높이보다 내려온 높이가 작아서 흡열이라는 그림과 일치합니다.

③ -30 kJ ⇒ 틀림.

역반응 활성화에너지에 그냥 음수 부호를 붙인 값입니다.

Ea(역)는 전이상태에서 생성물까지의 거리이지 반응물과 생성물의 높이 차가 아닙니다.

④ 30 kJ ⇒ 틀림.

역반응 활성화에너지를 그대로 쓴 값으로, 활성화에너지와 반응엔탈피를 구분하지 못한 경우입니다.

② ΔHrxn = Ea(정) - Ea(역) = 85 - 30 = +55 kJ 인 흡열반응입니다.

2) 공유 결합(그물) 결정(다이아몬드 C): 탄소 원자 하나하나가 sp³ 혼성으로 이웃 네 개와 강한 공유 결합을 이루어 결정 전체가 하나의 거대 분자입니다.

자연계에서 가장 단단하고 녹는점이 3500 °C를 넘습니다.

자유 전자가 없어 전기는 통하지 않지만, 격자 진동(포논)이 매우 잘 전달되어 열전도율은 금속보다도 높습니다.

3) 이온 결정(염화 포타슘 KCl): K⁺과 Cl⁻이 정전기적 인력으로 붙어 있습니다.

고체 상태에서는 이온이 못 움직여 전기가 통하지 않지만, 물에 녹으면 이온으로 흩어져 수용액이 전류를 흘립니다.

망치로 치면 같은 부호의 이온끼리 마주 보게 되어 서로 밀어내면서 결정면을 따라 쫙 갈라집니다(쪼개짐, 취성).

4) 분자 결정(황 S₈): 분자 안쪽은 공유 결합이지만 분자와 분자 사이는 약한 분산력뿐입니다.

그래서 녹는점이 매우 낮고(약 115 °C) 무르며, 물에 녹지 않아 수용액이 전류를 흘리지 않습니다.

단계 1) 후보를 결합 종류로 나눕니다.

아연 = 금속 결정, 다이아몬드 = 공유 결합 결정, 염화 포타슘 = 이온 결정, 황 = 분자 결정.

단계 2) 가장 결정적인 단서인 전기 전도성부터 봅니다.

물에 넣었을 때 용액이 전류를 흘리려면 물에 녹아 이온을 내놓아야 합니다.

네 물질 중 그런 물질은 염화 포타슘뿐입니다(아연 · 다이아몬드 · 황은 모두 물에 녹지 않습니다).

따라서 B = 염화 포타슘.

동시에 B가 "여러 조각으로 깨졌다"는 이온 결정의 쪼개짐 성질과도 딱 맞습니다.

단계 3) A는 망치로 치니 평평하게 펴졌습니다.

이 전성 · 연성은 금속만의 성질이므로 A = 아연.

단계 4) C는 형태 변화가 거의 없었습니다.

아주 단단하다는 뜻이므로 C = 다이아몬드.

단계 5) 남은 D = 황.

검산해 봅니다.

열을 잘 전달한 A(아연, 자유 전자)와 C(다이아몬드, 격자 진동)는 실제로 열전도율이 높고, B(KCl)와 D(S)는 낮습니다.

녹는점은 황 약 115 °C < 아연 420 °C < 염화 포타슘 770 °C < 다이아몬드 3500 °C 이상이므로 "D가 가장 먼저 녹았다"도 정확히 일치합니다.

모든 단서가 모순 없이 들어맞습니다.

① A-황, B-다이아몬드, C-아연, D-염화 포타슘 ⇒ 틀림.

다이아몬드를 물에 넣어도 녹지 않아 전류가 흐를 수 없고, 황(A)은 두드리면 가루로 부서질 뿐 펴지지 않습니다.

② A-아연, B-황, C-다이아몬드, D-염화 포타슘 ⇒ 틀림.

A와 C는 맞지만 황(B)은 물에 녹지 않아 전기 전도성 조건을 만족하지 못하고, 염화 포타슘(D, 770 °C)이 황보다 먼저 녹을 수도 없습니다.

③ A-황, B-염화 포타슘, C-다이아몬드, D-아연 ⇒ 틀림.

B와 C는 맞지만, 황(A)은 두드리면 펴지지 않고 아연(D)은 열을 아주 잘 전달하므로 "D는 열을 잘 전달하지 않았다"에 어긋납니다.

④ A-아연, B-염화 포타슘, C-다이아몬드, D-황 ⇒ 옳음.

전성(아연), 수용액 전도성과 쪼개짐(염화 포타슘), 최고의 경도(다이아몬드), 가장 낮은 녹는점(황)이 모두 맞아떨어집니다.

④ A = 아연, B = 염화 포타슘, C = 다이아몬드, D = 황입니다.

문제 22화학결합정답 ④

다음 중 공명 구조를 가지지 않는 물질은 무엇인가? ① SO₂ ② NO₂ ③ CO₃²⁻ ④ CO ■ 무엇을 묻는 문제인가 공명(resonance)이 언제 나타나는지를 아는지 묻습니다.

공명은 "루이스 구조를 하나로 딱 정할 수 없어서 여러 개를 그려야 하는 경우"에 나타납니다.

따라서 이 문제는 각 화학종의 루이스 구조를 그려 보고 "이중결합의 위치를 옮겨 그릴 수 있는가"를 확인하는 문제입니다.

1) 공명 구조란 원자의 위치는 그대로 두고 전자(주로 π 전자와 비공유 전자쌍)의 배치만 다르게 그린 여러 개의 루이스 구조를 말합니다.

실제 분자는 그중 어느 하나가 아니라 이들이 겹쳐진 하나의 상태(공명 혼성체)입니다.

2) 공명이 생기려면 이중결합(또는 홀전자, 형식 전하)을 옮겨 놓을 "다른 자리"가 있어야 합니다.

중심 원자에 같은 종류의 원자가 둘 이상 붙어 있는 경우가 대표적입니다.

3) 공명이 있으면 결합 길이가 균등해지고 결합 차수가 정수가 아닌 값이 됩니다.

또 전자가 넓게 퍼져(비편재화) 에너지가 낮아지므로 분자가 더 안정해집니다.

4) 각 화학종의 총 원자가 전자 수를 세는 법도 필요합니다.

음이온이면 전하만큼 더하고 양이온이면 뺍니다.

5) 이핵 이원자 분자처럼 원자가 둘뿐이면 이중결합을 "옮길 자리"가 없으므로 공명이 생기기 어렵습니다.

단계 1) SO₂를 봅니다.

원자가 전자 6 + 6×2 = 18개입니다.

굽은형 구조로 S를 중심으로 O가 둘 붙어 있고, 중심 S에는 비공유 전자쌍 1개가 있습니다.

한쪽 O와 이중결합, 다른 쪽 O와 단일결합을 그리면 되는데, 어느 쪽을 이중결합으로 잡을지 고를 수 없으므로 두 가지 공명 구조가 존재합니다.

S-O 결합 차수는 1.5로 두 결합이 똑같습니다.

단계 2) NO₂를 봅니다.

원자가 전자 5 + 6×2 = 17개로 홀수이므로 홀전자를 갖는 라디칼입니다.

여기서도 한쪽 O와 이중결합, 다른 쪽과 단일결합을 그릴 수 있으므로 두 가지 공명 구조가 있습니다.

N-O 결합 두 개는 실제로 같은 길이입니다.

단계 3) CO₃²⁻를 봅니다.

원자가 전자 4 + 6×3 + 2 = 24개입니다.

평면 삼각형 구조에서 C가 세 개의 O 중 하나와 이중결합을 이루는데, 어느 O를 골라도 되므로 공명 구조가 3개입니다.

C-O 결합 차수는 4/3 ≈ 1.33으로 세 결합이 모두 같습니다.

단계 4) CO를 봅니다.

원자가 전자 4 + 6 = 10개입니다.

두 원자가 옥텟을 모두 만족하려면 삼중결합 하나뿐이며, 이때 형식 전하는 C가 -1, O가 +1 입니다.

원자가 둘밖에 없어 결합을 옮겨 그릴 자리가 없고, 결합 차수 3인 구조 하나로 확정됩니다.

즉 공명 구조를 갖지 않습니다.

단계 5) 따라서 답은 CO 입니다.

① SO₂ ⇒ 공명 있음.

이중결합 자리를 좌우 두 산소에 각각 놓은 두 개의 공명 구조를 그릴 수 있고, 실제 두 S-O 결합 길이는 143 pm로 동일합니다.

② NO₂ ⇒ 공명 있음.

홀전자를 가진 라디칼이지만 이중결합의 위치를 바꾼 두 공명 구조가 존재하며, 두 N-O 결합이 등가입니다.

③ CO₃²⁻ ⇒ 공명 있음.

세 개의 등가 공명 구조를 가지며, 이것이 탄산 이온이 안정한 중요한 이유입니다.

④ CO ⇒ 공명 없음(정답).

원자가 두 개뿐이고 삼중결합 구조 하나로 결정되므로 전자를 옮겨 그릴 다른 배치가 없습니다.

실제로 C-O 결합 길이 113 pm, 결합 에너지 1072 kJ/mol로 알려진 가장 강한 결합 중 하나입니다.

④ CO는 삼중결합 구조 하나로 확정되므로 공명 구조를 갖지 않습니다.

문제 23평형농도정답 ②

다음 반응의 평형상수는 10⁻⁵이다.

A₂(aq) + 2B₂(aq) ⇌ 2AB₂(aq) A₂, B₂, AB₂를 각각 1.0몰씩 넣어 1.0 L 수용액을 만들었다.

이후 평형에 도달하였을 때 AB₂의 몰농도와 가장 가까운 값은 무엇인가? ① 3 mM ② 8 mM ③ 30 mM ④ 80 mM ■ 무엇을 묻는 문제인가 평형상수가 아주 작은 반응에서 "지금 상태가 평형에서 얼마나 벗어나 있는가"를 반응지수 Q로 판정하고, 평형으로 가는 방향을 정한 뒤 실제 평형 농도를 계산하는 문제입니다.

그냥 ICE 표를 세우면 3차 방정식이 나와 손으로 풀 수 없게 설계되어 있어서, "평형 상태는 도달 경로와 무관하다"는 성질을 이용해 계산이 쉬운 출발점을 새로 잡을 수 있는지가 진짜 관문입니다.

1) 평형상수 K는 평형에서의 (생성물 농도의 곱)/(반응물 농도의 곱)이며, 각 농도는 반응식의 계수만큼 거듭제곱합니다.

이 반응에서는 K = [AB₂]²/([A₂][B₂]²) 입니다.

2) 반응지수 Q는 K와 완전히 같은 꼴의 식이지만 평형이 아닌 임의의 순간 농도를 넣은 값입니다.

Q < K 이면 정반응, Q > K 이면 역반응, Q = K 이면 평형입니다.

3) K는 온도만의 함수입니다.

농도를 어떻게 넣든, 어느 방향에서 접근하든 같은 온도라면 최종 평형은 하나의 상태로 수렴합니다.

따라서 "일단 한쪽으로 100 % 진행시켜 놓고, 거기서 다시 평형으로 되돌아오는 과정"을 상상해도 답은 같습니다.

이것이 이 문제의 핵심 도구입니다.

4) K가 10⁻⁵처럼 매우 작으면 평형은 반응물 쪽에 크게 치우칩니다.

이때 변화량 y는 초기 농도에 비해 무시할 만큼 작으므로 (초기값 - y) ≈ 초기값 으로 근사할 수 있습니다.

보통 변화량이 초기 농도의 5 % 이하이면 이 근사는 안전합니다.

5) 단위: 1 mM = 10⁻³ M 입니다.

단계 1) 처음 상태의 Q를 구합니다.

1.0 L에 각각 1.0몰씩 넣었으므로 모든 농도가 1.0 M입니다.

Q = (1.0)²/((1.0)×(1.0)²) = 1 Q = 1 이고 K = 10⁻⁵ 이므로 Q > K, 즉 역반응 쪽으로 진행합니다.

단계 2) 계산을 쉽게 하기 위해 먼저 역반응을 끝까지 보냅니다.

2AB₂ → A₂ + 2B₂ 로 AB₂ 1.0 M이 모두 소모되면 A₂는 1.0/2 = 0.5 M 증가하고 B₂는 1.0 M 증가합니다.

가상의 출발점: [A₂] = 1.5 M, [B₂] = 2.0 M, [AB₂] = 0 단계 3) 이 출발점에서 다시 정반응으로 y만큼 진행해 평형에 도달한다고 놓습니다.

[A₂] = 1.5 - y, [B₂] = 2.0 - 2y, [AB₂] = 2y 단계 4) K가 10⁻⁵로 매우 작으므로 y는 아주 작습니다.

1.5 - y ≈ 1.5, 2.0 - 2y ≈ 2.0 으로 근사합니다.

K = (2y)²/(1.5 × (2.0)²) = 4y²/6 = (2/3)y² = 10⁻⁵ 단계 5) y를 구합니다.

y² = (3/2) × 10⁻⁵ = 15×10⁻⁶ y = √(15×10⁻⁶) = 3.87×10⁻³ 단계 6) 구하는 값은 [AB₂] = 2y 입니다.

[AB₂] = 2 × 3.87×10⁻³ = 7.75×10⁻³ M = 7.75 mM ≈ 8 mM 단계 7) 근사 검증: y = 0.0039 는 1.5의 0.26 %, 2y = 0.0077 은 2.0의 0.39 % 이므로 5 % 기준을 충분히 만족합니다.

참고로 처음 상태에서 바로 ICE 표를 세워 [A₂] = 1+x, [B₂] = 1+2x, [AB₂] = 1-2x 로 놓고 (1-2x)²/((1+x)(1+2x)²) = 10⁻⁵ 을 정확히 풀면 x = 0.4961 이 나오고, [AB₂] = 1 - 2x = 0.0077 M 으로 위 결과와 일치합니다.

① 3 mM ⇒ 틀림.

y = 3.87×10⁻³ 을 그대로 답으로 쓴 경우입니다.

구해야 할 것은 y가 아니라 AB₂의 농도 2y입니다.

② 8 mM ⇒ 옳음.

7.75 mM 이므로 가장 가깝습니다.

③ 30 mM ⇒ 틀림.

근사를 (1.5)(2.0)² = 6 이 아니라 1.5 정도로 잘못 잡거나, 제곱근을 빠뜨렸을 때 나오는 자릿수입니다.

④ 80 mM ⇒ 틀림.

K = 10⁻⁵ 이 아니라 10⁻³ 정도로 착각하면 이 근처가 됩니다.

K가 10⁻⁵이면 생성물 농도는 1 % 수준을 넘기 어렵습니다.

② 역반응이 완결된 상태(1.5 M, 2.0 M, 0)에서 다시 평형에 접근시키면 [AB₂] = 2y = 7.75 mM ≈ 8 mM 입니다.

문제 24화학평형정답 ②

다음은 암모니아 합성에 대한 하버-보슈법이다.

N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 이 반응의 평형상수(Kp)는 300 °C에서 4.34×10⁻³이고 600 °C에서 2.25×10⁻⁶이다.

1기압, 600 °C에서 피스톤 안에 N₂ 0.1몰, H₂ 0.3몰, NH₃ 0.01몰이 존재한다면 위의 반응은 어느 쪽으로 진행되는가? ① 정반응 ② 역반응 ③ 평형 ④ 정지됨 ■ 무엇을 묻는 문제인가 지금 용기 안의 조성이 평형 조성인지, 아니라면 어느 쪽으로 움직여야 평형에 도달하는지를 판단하는 문제입니다.

도구는 딱 하나, 반응 지수 Q와 평형상수 K의 비교입니다.

몰수만 주어졌으므로 몰수 → 몰분율 → 부분압력으로 한 번 갈아타는 과정이 반드시 필요하고, 어느 온도의 K와 비교해야 하는지도 확인해야 합니다.

1) 평형상수(Kp)의 정의: N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 에서 Kp = P(NH₃)² / (P(N₂) × P(H₂)³) 생성물 압력을 분자에, 반응물 압력을 분모에 두고 각각 계수만큼 거듭제곱합니다.

2) 반응 지수(Q): 평형상수와 똑같은 꼴의 식에 "지금 이 순간"의 압력을 그대로 대입한 값입니다.

Q는 언제든 계산할 수 있고, K는 평형에 도달했을 때의 Q 값입니다.

3) 판정 규칙 Q < K ⇒ 생성물이 아직 모자란 상태 ⇒ 정반응(오른쪽)으로 진행 Q = K ⇒ 평형 상태 ⇒ 겉보기 변화 없음 Q > K ⇒ 생성물이 넘치는 상태 ⇒ 역반응(왼쪽)으로 진행 4) 돌턴의 부분압력 법칙: P(성분) = 몰분율 × 전체압력.

전체압력이 1기압이면 부분압력의 수치는 몰분율의 수치와 같아집니다.

5) K는 온도의 함수입니다.

이 반응은 발열이므로 온도가 높아지면 K가 급격히 작아집니다.

반드시 문제에 지정된 온도의 K와 비교해야 합니다.

6) 평형은 "멈춤"이 아닙니다.

정반응 속도 = 역반응 속도인 동적 평형입니다.

단계 1) 전체 몰수를 구합니다.

n(전체) = 0.1 + 0.3 + 0.01 = 0.41 mol 단계 2) 몰분율을 구합니다.

χ(N₂) = 0.1 / 0.41 = 0.244 χ(H₂) = 0.3 / 0.41 = 0.732 χ(NH₃) = 0.01 / 0.41 = 0.0244 단계 3) 전체압력이 1기압이므로 부분압력은 몰분율과 같은 수치입니다.

P(N₂) = 0.244 atm, P(H₂) = 0.732 atm, P(NH₃) = 0.0244 atm 단계 4) 반응 지수 Q를 계산합니다.

Q = P(NH₃)² / (P(N₂) × P(H₂)³) = (0.0244)² / (0.244 × 0.732³) = (5.95×10⁻⁴) / (0.244 × 0.392) = (5.95×10⁻⁴) / (9.56×10⁻²) = 6.23×10⁻³ 단계 5) 600 °C에서의 Kp와 비교합니다.

Q = 6.23×10⁻³ , Kp = 2.25×10⁻⁶ ⇒ Q > Kp (약 2800배) 단계 6) Q > K 이므로 Q가 작아지는 방향, 즉 NH₃가 분해되는 역반응 쪽으로 반응이 진행됩니다.

① 정반응 ⇒ 틀림.

정반응이 일어나려면 NH₃가 부족해 Q < K여야 합니다.

여기서는 Q가 Kp보다 세 자릿수나 큽니다.

300 °C의 Kp(4.34×10⁻³)와 착각해도 Q가 여전히 더 크므로 정반응이 될 수 없습니다.

② 역반응 ⇒ 옳음.

Q(6.23×10⁻³)가 Kp(2.25×10⁻⁶)보다 훨씬 크므로 NH₃가 과잉이며, 분해되는 쪽으로 진행됩니다.

③ 평형 ⇒ 틀림.

평형이려면 Q = Kp여야 하는데 두 값의 차이가 약 2800배입니다.

④ 정지됨 ⇒ 틀림.

화학 평형은 정반응과 역반응이 같은 속도로 계속 일어나는 동적 평형이므로 반응이 "정지"하는 상태 자체가 존재하지 않습니다.

② Q = 6.23×10⁻³ > Kp = 2.25×10⁻⁶ 이므로 역반응 쪽으로 진행됩니다.

2017년까지 시중에 판매된 워셔액은 메탄올을 주성분으로 하고 있었다.

25 °C에서 물(H₂O)의 밀도는 1.0 g/mL, 에탄올(C₂H₅OH)의 밀도는 0.79 g/mL이다.

다음의 세 가지 방법으로 만든 워셔액의 어는점이 높은 것부터 낮아지는 순서대로 옳게 배열한 것은? A : 물과 에탄올을 3:1의 부피비로 섞는다.

B : 물과 에탄올을 3:1의 질량비로 섞는다.

C : 물과 에탄올을 3:1의 몰비로 섞는다.

① C, B, A ② A, B, C ③ C, A, B ④ B, A, C ■ 무엇을 묻는 문제인가 같은 "3 : 1"이라는 말이 부피비, 질량비, 몰비로 쓰일 때 실제 몰랄농도가 얼마나 달라지는지를 계산해 비교하는 문제입니다.

총괄성(어는점 내림)의 크기는 몰랄농도가 결정하므로, 세 조건을 모두 같은 잣대(물 1000 g당 에탄올의 몰수)로 환산하는 것이 요령입니다.

이번에는 배열 방향이 "어는점이 높은 것부터"라는 점을 반드시 확인해야 합니다.

1) 어는점 내림 ΔTf = Kf × m 입니다.

여기서 m은 몰랄농도(용매 1 kg당 용질의 몰수)이고 Kf는 용매의 어는점 내림 상수로 물은 1.86 °C·kg/mol 입니다.

즉 용질 입자가 많이 들어 있을수록 어는점이 더 많이 내려갑니다.

2) 어는점 내림이 생기는 이유: 용질이 들어가면 용액 속 용매의 몰분율이 낮아져 액체 상태의 화학 퍼텐셜이 내려갑니다.

고체(순수 얼음)의 퍼텐셜은 그대로이므로 두 곡선이 만나는 온도가 더 낮은 쪽으로 밀립니다.

그래서 총괄성은 용질의 종류가 아니라 개수에만 의존합니다.

3) 계산의 핵심 도구는 세 관계식입니다.

질량 = 부피 × 밀도, 몰수 = 질량 / 몰질량, 몰랄농도 = 용질 몰수 / 용매 질량(kg) 몰질량은 물 18 g/mol, 에탄올(C₂H₅OH) 46 g/mol 입니다.

4) 비교만 하면 되므로 "물 1000 g(= 1 kg) 기준으로 에탄올이 몇 g 들어가는가"를 계산하면 그대로 몰랄농도의 대소가 됩니다.

에탄올의 몰질량은 세 경우 모두 같으므로 질량 비교만으로 충분합니다.

5) 어는점 순서와 몰랄농도 순서는 반대입니다.

몰랄농도가 클수록 어는점 내림이 크고, 따라서 어는점 자체는 더 낮습니다.

어는점이 높은 것부터 배열하라는 것은 결국 몰랄농도가 작은 것부터 배열하라는 뜻입니다.

단계 1) A(부피비 3 : 1)를 계산합니다.

물 1000 mL를 기준으로 잡으면 물의 질량 = 1000 mL × 1.0 g/mL = 1000 g 에탄올의 부피 = 1000 mL ÷ 3 = 333.3 mL 에탄올의 질량 = 333.3 mL × 0.79 g/mL = 263.3 g 에탄올의 몰수 = 263.3 / 46 = 5.72 mol → m(A) = 5.72 mol/kg 단계 2) B(질량비 3 : 1)를 계산합니다.

물 1000 g을 기준으로 잡으면 에탄올의 질량 = 1000 g ÷ 3 = 333.3 g 에탄올의 몰수 = 333.3 / 46 = 7.25 mol → m(B) = 7.25 mol/kg 단계 3) C(몰비 3 : 1)를 계산합니다.

물 1000 g의 몰수부터 구합니다.

물의 몰수 = 1000 / 18 = 55.6 mol 에탄올의 몰수 = 55.6 ÷ 3 = 18.52 mol → m(C) = 18.52 mol/kg 참고로 이때 에탄올의 질량은 18.52 × 46 = 852 g 으로, 물 1000 g에 육박합니다.

단계 4) 몰랄농도를 비교합니다.

m(C) 18.52 > m(B) 7.25 > m(A) 5.72 단계 5) 어는점 내림 ΔTf = Kf × m 도 같은 순서이므로 내림 폭은 C > B > A 이고, 어는점 자체는 그 반대로 A가 가장 높고 C가 가장 낮습니다.

따라서 높은 것부터 배열하면 A, B, C 입니다.

단계 6) 수치로 확인하면 ΔTf(A) = 1.86 × 5.72 ≈ 10.6 °C, ΔTf(B) = 1.86 × 7.25 ≈ 13.5 °C, ΔTf(C) = 1.86 × 18.52 ≈ 34.4 °C 만큼 내려가므로 어는점은 A > B > C 순으로 높습니다.

① C, B, A ⇒ 틀림.

몰랄농도가 큰 것부터 늘어놓은 배열, 곧 어는점이 낮은 것부터의 순서입니다.

문제가 요구한 방향과 정반대입니다.

② A, B, C ⇒ 옳음.

물 1000 g당 에탄올이 A 263 g < B 333 g < C 852 g 이므로 어는점은 A가 가장 높고 C가 가장 낮습니다.

③ C, A, B ⇒ 틀림.

방향도 반대이고 A와 B의 대소도 뒤집혀 있습니다.

④ B, A, C ⇒ 틀림.

A와 B의 순서만 바꿔 놓았을 뿐 가장 진한 C를 마지막(가장 낮은 어는점)에 두어 얼핏 맞아 보이지만, A와 B의 대소가 틀렸습니다.

에탄올의 밀도가 1보다 작아(0.79) 부피 333.3 mL가 질량으로는 263.3 g밖에 안 되므로 부피비 조건 A가 질량비 조건 B보다 묽고, 따라서 어는점은 A가 더 높습니다.

② 물 1 kg당 에탄올 몰수가 A(5.72 mol) < B(7.25 mol) < C(18.52 mol) 이므로 어는점이 높은 순서는 A, B, C 입니다.

문제 27깁스자유에너지정답 ②

다음은 물과 사염화탄소의 층분리에 대한 그림이다.

다음 반응의 자발성에 대한 설명으로 옳은 것은? ① 높은 온도에서 자발적이다.

② 낮은 온도에서 자발적이다.

③ 항상 자발적이다.

④ 항상 비자발적이다.

■ 무엇을 묻는 문제인가 그림이 나타내는 변화(섞여 있던 상태 → 두 층으로 갈라진 상태)에 대해 ΔH의 부호와 ΔS의 부호를 각각 판정하고, ΔG = ΔH - TΔS에 넣어 온도 조건을 결론짓는 문제입니다.

계산은 한 줄도 없지만 자발성 판정의 네 가지 경우를 정확히 외우고 있는지, 그리고 "섞이지 않는다"는 현상을 열역학 언어로 번역할 수 있는지를 동시에 봅니다.

1) 깁스 자유에너지 ΔG = ΔH - TΔS 이고, 일정 온도·압력에서 ΔG < 0이면 자발적, ΔG > 0이면 비자발적, ΔG = 0이면 평형입니다.

2) 부호 조합에 따른 네 가지 경우를 반드시 구분해야 합니다.

- ΔH < 0, ΔS > 0 → ΔG는 항상 음수 → 모든 온도에서 자발적 - ΔH > 0, ΔS < 0 → ΔG는 항상 양수 → 모든 온도에서 비자발적 - ΔH < 0, ΔS < 0 → 낮은 온도에서 자발적 (엔탈피가 이기는 저온 영역) - ΔH > 0, ΔS > 0 → 높은 온도에서 자발적 (엔트로피가 이기는 고온 영역) 핵심은 T가 곱해져 있는 쪽은 엔트로피 항뿐이라는 점입니다.

온도가 높아질수록 -TΔS 항의 영향력이 커지므로, 고온에서는 엔트로피가, 저온에서는 엔탈피가 승부를 결정합니다.

3) 엔트로피의 방향 판정: 섞여 있는 상태(용액)는 배열 가능한 경우의 수가 많아 엔트로피가 크고, 두 층으로 깔끔히 갈라진 상태는 경우의 수가 적어 엔트로피가 작습니다.

따라서 혼합은 ΔS > 0, 층분리는 ΔS < 0 입니다.

4) 엔탈피의 방향 판정: 용해 엔탈피는 (용매-용매 인력을 끊는 흡열) + (용질-용질 인력을 끊는 흡열) + (용매-용질 인력을 만드는 발열)의 합입니다.

물은 수소결합으로 강하게 묶여 있고 사염화탄소는 무극성이라 물과 사이에 만들 수 있는 인력이 약한 분산력뿐입니다.

끊는 데 드는 에너지 > 새로 얻는 에너지이므로 물과 CCl₄의 혼합은 흡열(ΔH > 0)이고, 그 역과정인 층분리는 발열(ΔH < 0)입니다.

단계 1) 그림의 화살표 방향을 확인합니다.

왼쪽은 균일하게 섞인 상태, 오른쪽은 두 층으로 나뉜 상태이므로 대상 반응은 "혼합 → 층분리"입니다.

단계 2) 엔트로피 변화를 판정합니다.

무질서한 상태에서 정돈된 상태로 갔으므로 ΔS < 0 입니다.

단계 3) 엔탈피 변화를 판정합니다.

물-CCl₄ 혼합이 흡열이므로 그 역과정인 층분리는 발열, 즉 ΔH < 0 입니다.

단계 4) ΔG = ΔH - TΔS 에 부호를 넣습니다.

ΔH < 0 이므로 첫 항은 자발성에 유리합니다.

ΔS < 0 이므로 -TΔS = -(T)(음수) = 양수가 되어 자발성에 불리하고, 그 크기는 T에 비례합니다.

단계 5) 따라서 T가 작을 때는 |ΔH| > |TΔS| 가 되어 ΔG < 0 (자발적), T가 클 때는 |TΔS| > |ΔH| 가 되어 ΔG > 0 (비자발적)입니다.

두 항이 같아지는 T = ΔH/ΔS 가 경계 온도가 됩니다.

① 높은 온도에서 자발적이다 ⇒ 틀림.

이것은 ΔH > 0, ΔS > 0 인 경우입니다.

층분리가 아니라 반대로 잘 섞이는 흡열적 용해에 해당하는 설명입니다.

② 낮은 온도에서 자발적이다 ⇒ 옳음.

ΔH < 0, ΔS < 0 조합이므로 저온에서 엔탈피 항이 승리해 ΔG < 0 이 됩니다.

③ 항상 자발적이다 ⇒ 틀림.

ΔH < 0, ΔS > 0 일 때만 가능한 결론인데 여기서는 ΔS < 0 이므로 성립하지 않습니다.

④ 항상 비자발적이다 ⇒ 틀림.

ΔH > 0, ΔS < 0 일 때의 결론입니다.

층분리는 실제로 상온에서 일어나므로 최소한 상온에서는 자발적이며, "항상 비자발적"은 관찰 사실과도 어긋납니다.

② 층분리는 발열(ΔH < 0)이면서 엔트로피가 감소(ΔS < 0)하는 변화이므로 낮은 온도에서 자발적입니다.

문제 28상평형정답 ③

다음 자료를 활용하여 메탄올의 정상 끓는점을 계산한 값과 가장 유사한 것은? 물질 ΔHf°(kJ/mol) ΔS°(J/mol·K) CH₃OH(l) -240 125 CH₃OH(g) -200 240 ① 250 K ② 300 K ③ 350 K ④ 400 K ■ 무엇을 묻는 문제인가 "끓는점이란 무엇인가"를 열역학의 언어로 다시 정의할 수 있는지 묻는 문제입니다.

끓는점은 액체와 기체가 평형을 이루는 온도이고, 평형이란 곧 ΔG = 0 인 상태입니다.

이 한 문장을 T = ΔH/ΔS 로 옮길 수 있으면 나머지는 헤스 법칙을 쓴 뺄셈 두 번입니다.

단위 환산(kJ ↔ J)이 유일한 함정입니다.

1) 깁스 자유에너지 ΔG = ΔH - TΔS 입니다.

ΔG < 0 이면 자발적, ΔG = 0 이면 평형, ΔG > 0 이면 비자발적입니다.

2) 정상 끓는점은 1기압에서 액체와 기체가 공존하며 평형을 이루는 온도입니다.

기화 과정 CH₃OH(l) → CH₃OH(g) 에 대해 ΔG = 0 이 되는 온도가 바로 정상 끓는점이므로 0 = ΔH - TΔS → T = ΔH / ΔS 3) 헤스 법칙과 표준 생성엔탈피: ΔH° = (생성물의 ΔHf° 합) - (반응물의 ΔHf° 합) 입니다.

표준 엔트로피도 마찬가지로 ΔS° = (생성물의 S° 합) - (반응물의 S° 합) 으로 구합니다.

다만 엔트로피는 절대값이 존재하므로(열역학 제3법칙) 생성 엔트로피가 아니라 절대 엔트로피를 그대로 빼면 됩니다.

4) 기화는 언제나 ΔH > 0(분자간 힘을 끊어야 하므로 흡열)이고 ΔS > 0(기체가 훨씬 무질서)입니다.

따라서 T = ΔH/ΔS 는 항상 양수로 나오며, 이 온도보다 높으면 -TΔS 항이 이겨 기화가 자발적, 낮으면 응축이 자발적입니다.

5) 단위 통일이 필수입니다.

ΔH는 kJ/mol, ΔS는 J/mol·K 로 주어지므로 1000배 차이를 반드시 맞춰 주어야 합니다.

이것을 놓치면 T가 0.348 K 같은 터무니없는 값이 됩니다.

단계 1) 대상 반응을 씁니다.

CH₃OH(l) → CH₃OH(g) 단계 2) 기화 엔탈피를 구합니다.

ΔH = ΔHf°(기체) - ΔHf°(액체) = (-200) - (-240) = +40 kJ/mol 흡열이라는 예상과 부호가 맞습니다.

단계 3) 기화 엔트로피를 구합니다.

ΔS = S°(기체) - S°(액체) = 240 - 125 = +115 J/mol·K 기체가 되면서 엔트로피가 늘어난다는 예상과 맞습니다.

단계 4) 평형 조건 ΔG = 0 을 적용합니다.

0 = ΔH - TΔS → T = ΔH / ΔS 단계 5) 단위를 맞추어 대입합니다.

T = 40 kJ/mol ÷ 0.115 kJ/mol·K = 40000 J/mol ÷ 115 J/mol·K = 347.8 K 단계 6) 보기와 대조하면 347.8 K에 가장 가까운 값은 350 K이므로 ③입니다.

참고로 메탄올의 실제 정상 끓는점은 337.8 K(64.7 °C)로, 표준 상태 값(298 K 기준)을 그대로 외삽한 계산치와 10 K 정도 차이가 나는 것은 자연스러운 오차입니다.

① 250 K ⇒ 틀림.

-23 °C에서 메탄올이 끓는다는 뜻인데, ΔH/ΔS 계산과 맞지 않습니다.

ΔS를 240 + 125 처럼 더하거나 ΔH를 잘못 잡으면 이 근처로 흘러갑니다.

② 300 K ⇒ 틀림.

실온에서 끓는다는 뜻이며 347.8 K와 거리가 있습니다.

상온 298 K를 습관적으로 고른 경우입니다.

③ 350 K ⇒ 옳음.

T = 40000/115 = 347.8 K 이므로 보기 중 가장 가깝습니다.

④ 400 K ⇒ 틀림.

ΔH를 -200과 -240의 합처럼 잘못 처리하거나 ΔS를 100 정도로 반올림하면 나오는 값입니다.

347.8 K와의 차이가 50 K 이상이므로 350 K가 더 가깝습니다.

③ 평형 조건 ΔG = 0 에서 T = ΔH/ΔS = 40000 J/mol ÷ 115 J/mol·K = 348 K 이므로 350 K가 가장 유사합니다.

문제 29원자반지름정답 ②

다음 중 원자 반지름이 가장 큰 것은? ① S ② Na ③ O ④ B ■ 무엇을 묻는 문제인가 주기율표에서 원자 반지름이 어느 방향으로 커지고 작아지는지를 아는지 확인하는 기본 문제입니다.

계산이 필요 없고 원소의 위치만 정확히 떠올리면 되지만, "왜" 그런 경향이 나타나는지를 유효 핵전하와 전자 껍질 수로 설명할 수 있어야 응용 문제까지 대응할 수 있습니다.

1) 같은 족(세로줄)에서 아래로 내려가면 주 양자수 n이 커져 전자 껍질이 하나씩 추가됩니다.

가장 바깥 전자가 핵에서 멀어지므로 원자 반지름이 커집니다.

2) 같은 주기(가로줄)에서 오른쪽으로 갈수록 껍질 수는 그대로인데 양성자 수만 늘어납니다.

같은 껍질의 전자들끼리는 가려막기가 약하므로 유효 핵전하 Zeff가 커지고, 핵과 최외각 전자 사이의 인력이 강해져 반지름이 작아집니다.

3) 정리하면 원자 반지름은 주기율표의 왼쪽 아래로 갈수록 크고, 오른쪽 위로 갈수록 작습니다.

4) 각 원소의 위치 ― B(2주기 13족), O(2주기 16족), Na(3주기 1족), S(3주기 16족).

단계 1) 주기부터 나눕니다.

B와 O는 2주기(전자 껍질 2개), Na와 S는 3주기(전자 껍질 3개)입니다.

껍질이 하나 더 많은 3주기 원소들이 기본적으로 더 큽니다.

단계 2) 3주기 안에서 비교합니다.

Na(원자번호 11)가 S(16)보다 훨씬 왼쪽에 있으므로 유효 핵전하가 작고 반지름이 큽니다.

단계 3) 2주기 안에서 비교합니다.

B(5)가 O(8)보다 왼쪽이므로 B가 더 큽니다.

단계 4) 남은 후보는 Na와 B 입니다.

Na는 3주기 1족으로 주기율표의 가장 왼쪽 아래에 있고 B는 2주기 13족이므로, 껍질 수와 족 위치 모두 Na가 유리합니다.

단계 5) 실제 원자 반지름을 보아도 일치합니다.

Na 약 186 pm, S 약 104 pm, B 약 85 pm, O 약 73 pm 로 Na가 가장 큽니다.

① S ⇒ 틀림.

3주기라 껍질은 많지만 16족으로 오른쪽에 치우쳐 유효 핵전하가 커서 반지름이 작습니다(약 104 pm).

② Na ⇒ 옳음(정답).

주어진 넷 중 주기율표의 가장 왼쪽 아래에 있으므로 반지름이 가장 큽니다(약 186 pm).

③ O ⇒ 틀림.

2주기이면서 오른쪽에 있어 이 중 가장 작은 축입니다(약 73 pm).

④ B ⇒ 틀림.

2주기라 껍질이 하나 적어 Na보다 작습니다(약 85 pm).

② Na가 주기율표에서 가장 왼쪽 아래에 있어 원자 반지름이 가장 큽니다.

문제 30원자반지름정답 ③

다음 원소들의 원자 반지름을 비교한 것으로 옳은 것은? Zn, C, F, K ① Zn < K < F < C ② Zn < F < K < C ③ F < C < Zn < K ④ F < C < K < Zn ■ 무엇을 묻는 문제인가 원자 반지름의 주기적 경향을 "같은 주기 안에서의 비교"와 "다른 주기 사이의 비교" 두 단계로 나누어 적용할 수 있는지 묻는 문제입니다.

주어진 네 원소가 2주기 둘(C, F)과 4주기 둘(K, Zn)로 깔끔하게 나뉘어 있다는 점을 알아채는 순간 문제가 절반은 풀립니다.

여기에 전이 금속 Zn을 끼워 넣어 "4주기라고 무조건 크지는 않다"는 감각까지 확인하고 있습니다.

1) 원자 반지름을 지배하는 두 요인은 (가) 전자가 들어 있는 가장 바깥 껍질의 주양자수 n과 (나) 그 전자가 실제로 느끼는 유효 핵전하 Zeff입니다.

n이 커지면 전자 구름의 평균 거리가 멀어져 반지름이 커지고, Zeff가 커지면 핵이 전자를 더 세게 끌어당겨 반지름이 작아집니다.

2) 유효 핵전하는 Zeff = Z - S로 정의합니다.

Z는 양성자 수, S는 다른 전자들이 핵전하를 가려 주는 정도(가리움 상수)입니다.

같은 주기에서 오른쪽으로 한 칸 가면 양성자는 1개 늘지만 새로 들어간 전자는 같은 껍질에 있어 가리움 효과가 작습니다.

그래서 Zeff가 계속 커지고 반지름은 작아집니다.

3) 같은 족에서 아래로 가면 껍질이 하나 통째로 늘어나므로 n 증가 효과가 Zeff 증가 효과를 압도해 반지름이 커집니다.

4) 결론적으로 원자 반지름은 주기율표에서 왼쪽 아래로 갈수록 커집니다.

5) 전이 금속의 특이점: 4주기 전이 원소는 3d 오비탈을 채워 갑니다.

3d 전자는 4s 전자보다 안쪽에 분포하면서도 가리움 능력이 완전하지 않아, d 블록을 지나는 동안 4s 전자가 느끼는 Zeff가 서서히 커집니다.

그 결과 K에서 Zn까지 가면서 반지름이 꾸준히 줄어듭니다.

실제 금속 반지름은 K 227 pm, Ca 197 pm, Zn 134 pm 정도입니다.

단계 1) 주기를 나눕니다.

C(Z=6)와 F(Z=9)는 2주기, K(Z=19)와 Zn(Z=30)은 4주기입니다.

단계 2) 2주기 안에서 비교합니다.

C와 F 모두 최외각이 2껍질인데 F가 양성자를 3개 더 가지므로 Zeff가 훨씬 큽니다.

따라서 F < C입니다.

(공유결합 반지름 F 64 pm < C 77 pm) 단계 3) 4주기 안에서 비교합니다.

K와 Zn 모두 최외각이 4s인데 Zn은 양성자가 11개나 더 많고, 그 사이에 채워진 3d 전자의 가리움이 불완전하므로 Zeff가 훨씬 큽니다.

따라서 Zn < K입니다.

(Zn 134 pm < K 227 pm) 단계 4) 두 주기를 잇습니다.

2주기 원소는 최외각이 L껍질(n=2), 4주기 원소는 최외각이 N껍질(n=4)입니다.

껍질이 두 층이나 차이 나므로 아무리 작은 4주기 원소라도 2주기 원소보다 큽니다.

즉 C < Zn입니다.

단계 5) 이어 붙이면 F < C < Zn < K가 됩니다.

① Zn < K < F < C ⇒ 틀림.

Zn < K는 맞지만, 4주기인 K가 2주기인 F보다 작다는 부분이 껍질 수를 무시한 결정적 오류입니다.

② Zn < F < K < C ⇒ 틀림.

2주기와 4주기가 뒤섞여 있습니다.

F < C는 맞았지만 두 주기 사이 순서가 완전히 어긋났습니다.

③ F < C < Zn < K ⇒ 옳음.

2주기(F < C) → 4주기(Zn < K) 순서가 모두 맞고, 껍질 수가 큰 4주기가 통째로 뒤에 오는 배열입니다.

④ F < C < K < Zn ⇒ 틀림.

앞부분은 맞지만 4주기 안에서 K < Zn으로 뒤집혔습니다.

전이 금속을 지나며 Zeff가 커져 반지름이 줄어든다는 점을 놓친 선지입니다.

③ 껍질 수로 먼저 크게 나눈 뒤 주기 안에서 유효 핵전하로 비교하면 F < C < Zn < K입니다.
