표준 생성 엔탈피

068 · 열화학읽는 데 약 10분
‹ 파이널로
이번 진단에서 표준 생성 엔탈피가 보강으로 잡혔어. 이 1강을 끝까지 읽고 직접 해보기까지. 어떤 반응이든 ΔH를 계산하는 기준값이야. "원소의 생성 엔탈피=0"과 "ΔH = 생성물 − 반응물(생성 엔탈피로)"이 핵심이야.

자, 앞 강의 헤스 법칙은 강력하지만, 매번 반응식을 조합하는 게 번거롭지. 그래서 더 깔끔한 방법이 있어. 모든 물질에 대해 "원소에서 그 물질을 만들 때의 에너지"를 미리 정리해 두는 거야. 이게 표준 생성 엔탈피지. 이 값을 표로 가지고 있으면, 어떤 반응이든 ΔH = 생성물 − 반응물 한 줄로 계산할 수 있어. 헤스 법칙을 가장 실용적으로 쓰는 방법이야. 오늘은 생성 엔탈피의 정의(특히 원소는 0)와 계산법을 잡을 거야.

01표준 생성 엔탈피 · 원소에서 1몰 만들기

표준 생성 엔탈피(ΔHf°)는 표준 상태(보통 25°C, 1기압)에서, 가장 안정한 원소(홑원소 물질)로부터 그 물질 1몰을 만들 때의 엔탈피 변화야. 말하자면 "이 물질을 원소에서 빚어낼 때 드나든 에너지"지.

예를 들어 물의 생성 엔탈피는 H₂ + ½O₂ → H₂O의 ΔH야(수소와 산소라는 원소에서 물 1몰을 만드는 것). 이 값이 음수면 그 물질은 원소보다 에너지가 낮은(안정한) 상태로 만들어진 거지.

표준 생성 엔탈피 ΔHf° = 가장 안정한 원소들로부터 그 물질 1몰을 만들 때의 ΔH. 각 물질의 "원소 기준 에너지 위치"를 나타내는 값이야. 이걸 표로 정리해 두면 모든 반응의 ΔH를 계산할 수 있어.
02원소의 생성 엔탈피 = 0 · 기준점

핵심 약속이 하나 있어. 가장 안정한 홑원소 물질의 표준 생성 엔탈피는 0이야. 원소를 원소로부터 만든다는 건 아무것도 안 하는 거니까, 변화가 0인 거지. 이게 모든 생성 엔탈피의 기준점이야.

물질ΔHf°이유
O₂(g), H₂(g), N₂(g)0가장 안정한 원소
C(흑연)0탄소의 가장 안정한 형태
H₂O, CO₂, CH₄ …0이 아님화합물(원소에서 만들어짐)
함정 · 어떤 형태의 원소가 0인가
"가장 안정한" 형태의 원소만 0이야. 산소는 O₂가 0이지 오존(O₃)은 0이 아니고, 탄소는 흑연이 0이지 다이아몬드는 0이 아니야(흑연이 더 안정). 같은 원소라도 가장 안정한 형태만 기준(0)이라는 걸 주의해. 화합물은 당연히 0이 아니고. "가장 안정한 홑원소 물질 = 0"을 정확히 기억해.
03생성 엔탈피로 ΔH 계산 · 생성물 − 반응물

생성 엔탈피 표가 있으면 어떤 반응의 ΔH든 한 줄로 계산돼. 각 물질의 생성 엔탈피에 계수를 곱해, 생성물 합에서 반응물 합을 빼면 끝이야.

ΔH = Σ(생성물 ΔHf°) − Σ(반응물 ΔHf°)  (각 계수 곱해서)

이게 성립하는 건 헤스 법칙 덕분이야(067). 반응물을 원소로 분해했다가(역방향, 반응물 생성 엔탈피의 −) 다시 생성물로 조립하는(생성물 생성 엔탈피의 +) 경로로 본 거지. 그래서 "생성물 − 반응물"이 돼. 결합 에너지의 "반응물 − 생성물"과 방향이 반대니 주의(066).

04계산 예제 · 메테인 연소

메테인 연소의 ΔH를 생성 엔탈피로 구해보자.

CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l)
ΔHf°: CH₄ = −75, CO₂ = −394, H₂O(l) = −286, O₂ = 0 (kJ/mol)

공식에 넣어. 생성물 합: ΔHf(CO₂) + 2·ΔHf(H₂O) = (−394) + 2(−286) = −394 − 572 = −966. 반응물 합: ΔHf(CH₄) + 2·ΔHf(O₂) = (−75) + 0 = −75. 따라서

ΔH = (−966) − (−75) = −891 kJ (발열)

메테인 1몰이 연소하면 약 891 kJ을 방출해(발열). 산소는 원소라 생성 엔탈피가 0이라 빠지지. 표의 값만 대입하면 복잡한 반응의 ΔH도 한 번에 나와. 이게 생성 엔탈피의 위력이야.

예제 · 생성 엔탈피 표로 한 번에 CH₄ + 2O₂ → CO₂ + 2H₂O(l) 의 ΔH 를 구해 봐. (ΔHf°: CH₄ −75, CO₂ −394, H₂O(l) −286 kJ/mol) ΔH = Σ(생성물) − Σ(반응물), 그리고 홑원소 물질은 0 이야(O₂ 가 0인 게 그 이유). ① 생성물: (−394) + 2(−286) = −966 ② 반응물: (−75) + 2(0) = −75 ③ ΔH = −966 − (−75) = −891 kJ. 066에서 결합 에너지로 어림한 값(−890 쯤)과 거의 같지 — 길이 달라도 답이 같다는 게 헤스 법칙(067)이야.
05한 장 정리와 다음 연결

오늘 들고 갈 한 문장.

"생성 엔탈피 = 원소에서 1몰 만들 때 ΔH(원소는 0) · ΔH = 생성물 − 반응물."

표준 생성 엔탈피는 원소에서 물질 1몰을 만들 때의 ΔH이고, 가장 안정한 홑원소 물질은 0이야. 이 값들로 ΔH = Σ(생성물) − Σ(반응물)로 어떤 반응이든 계산돼(메테인 연소 −891 kJ). 결합 에너지(반응물−생성물)와 방향이 반대니 주의.

이걸로 064~068, 즉 열화학의 핵심 도구(발열·흡열, ΔH, 결합 에너지, 헤스 법칙, 생성 엔탈피)가 다 갖춰졌어. 다음 강(069 비열·열량 측정)부터 후반부에서는 실제로 열량을 어떻게 재는지(비열·열량계), 상태 변화의 에너지, 그리고 반응이 일어나는 방향을 정하는 엔트로피·자유 에너지를 다뤄. 오늘의 ΔH 계산을 들고, 열량 측정과 반응의 방향으로 넘어가자.

✓확인 문제

방금 배운 것으로 풀 수 있는 3문항입니다. 답을 고르면 해설이 열립니다 — 먼저 스스로 고르고 나서 보세요.

1. 다음 자료를 이용하여 ½Br₂(l) + ½Cl₂(g) → BrCl(g)의 표준 생성 엔탈피 ΔH_f°를 구하면? 25°C에서 브로민의 표준 상태는 액체, 염소의 표준 상태는 기체이다.
· Br₂(l) → Br₂(g), ΔH = +30.9 kJ/mol
· 기체 상태 결합 해리 에너지: Br−Br 193 kJ/mol, Cl−Cl 242 kJ/mol, Br−Cl 219 kJ/mol
정답 ①

헤스 법칙으로 경로를 나눈다. ① ½Br₂(l) → ½Br₂(g): +½(30.9) = +15.45 kJ. ② ½Br₂(g) → Br(g): +½(193) = +96.5 kJ. ③ ½Cl₂(g) → Cl(g): +½(242) = +121 kJ. ④ Br(g) + Cl(g) → BrCl(g): −219 kJ. 합 = 15.45 + 96.5 + 121 − 219 = +13.95 ≈ +14 kJ/mol (문헌값 +14.6 kJ/mol과 일치).

자주 걸리는 자리 표준 상태가 액체인 Br₂의 기화 단계를 빠뜨리거나, 기화 엔탈피를 절반이 아니라 전부 더한다.
2. 표준 생성 엔탈피(ΔH°f)는 표준 상태(25°C, 1기압)에서 가장 안정한 형태의 원소에 대해 0으로 정의한다. 다음 중 25°C, 1기압에서 ΔH°f가 0인 물질은?
정답 ③

원소라도 '표준 상태에서 가장 안정한 형태'여야 ΔH°f = 0이다. 수은은 25°C, 1기압에서 액체가 가장 안정한 형태이므로 Hg(l)의 ΔH°f = 0이다. 탄소의 기준 형태는 흑연이므로 다이아몬드는 0이 아니고(약 +1.9 kJ/mol), 구리의 기준 형태는 고체이므로 Cu(g)는 고체를 승화시켜야 얻어져 0이 아니며(크게 양의 값), 산소의 기준 형태는 O₂(g)이므로 O₃(g)도 0이 아니다(약 +143 kJ/mol).

자주 걸리는 자리 '원소이면 ΔH°f = 0'이라고 외워, 상태(상)와 동소체까지 기준 형태여야 한다는 조건을 빠뜨린다.
3. 다음 평균 결합 에너지(kJ/mol)를 이용하여 N₂H₄(g) + O₂(g) → N₂(g) + 2H₂O(g)의 ΔH를 어림한 값은? (N₂H₄에는 N−N 결합 1개와 N−H 결합 4개가 있다.)
N−N 163, N−H 391, O=O 498, N≡N 946, O−H 463
정답 ④

ΔH ≈ (끊는 결합 에너지의 합) − (만드는 결합 에너지의 합)이다. 끊는 결합: N₂H₄의 N−N 163 + N−H 4개 4 × 391 = 1564, 합 1727. 여기에 O=O 498을 더해 2225. 만드는 결합: N≡N 946, H₂O 2개에 들어 있는 O−H 4개 4 × 463 = 1852, 합 2798. ΔH ≈ 2225 − 2798 = −573 kJ. → ④ 음수이므로 발열이고, 하이드라진이 연료로 쓰이는 것과 맞는다. 평균 결합 에너지로 얻은 어림값이라 실측값과 수십 kJ 차이는 날 수 있다.

자주 걸리는 자리 ΔH는 (끊는 결합) − (만드는 결합)이다. 순서를 바꾸면 부호가 뒤집히고, 계수를 빠뜨리면 결합 개수가 모자란다.

검수된 동형문제에서 골랐습니다 (사람이 확인한 2,490문항).

직접 해보기 (숙제)
오답 났던 문제를 생성 엔탈피로 풀어봐. ① 원소(가장 안정한 형태)는 0 ② ΔH = Σ(생성물 ΔHf°) − Σ(반응물 ΔHf°), 계수 곱하기 ③ 결합 에너지(반응물−생성물)와 방향 반대인 것 주의. 그리고 입으로 말해. "원소는 0이고, 생성 엔탈피로는 생성물에서 반응물을 뺀다." 한 바퀴 돌리면 이 계산은 네 거다.
