문제 1분자운동속도정답 ③

사고과정

기체 분자의 평균 운동에너지는 온도만으로 정해진다는 것을 짚는다.

E_k = (3/2)kT 이므로 온도가 같으면 분자량이 달라도 평균 운동에너지는 같다.

분포가 오른쪽으로 넓어진 것은 분자량이 작아 속도가 빠르기 때문이지 에너지가 커서가 아니다.

→ ③

문제 2열량계정답 ④

사고과정

가열 곡선의 평평한 구간이 융해이고, 그 구간에 들어간 열이 융해열이다.

분당 100 J 로 80분~128분, 곧 48분이 융해 구간이니 융해열은 4.8 kJ/mol 이다.

27°C 에서 다 녹이려면 데우는 열까지 128분치 12.8 kJ 이 든다 — 8 kJ 이 아니다.

→ ④

문제 3헤스법칙정답 ①

사고과정

연소열이 주어졌으니 ΔH = (반응물 연소열 합) − (생성물 연소열 합) 으로 간다.

(−3268) + 3×(−286) − (−3754) = −372 kJ/mol 이다.

가장 가까운 값을 고른다.

→ ①

문제 4표준전위정답 ①

사고과정

두 반쪽 반응을 빼서 Mg(OH)2 의 용해 반응과 그 표준 전위를 만든다.

E° = −2.69 − (−2.36) = −0.33 V 이고 log K = nE°/0.0592 이다.

log K = 2×(−0.33)/0.0592 ≈ −11.15 이니 K ≈ 7×10−12 다.

→ ①

문제 5농도환산정답 ③

사고과정

40 wt% 용액의 몰농도를 먼저 구한다.

100 g 속 40 g 은 0.24 mol 이고 부피는 100/1.43 = 70 mL 이니 3.43 M 이다.

3.43 M × x = 0.1 mol 에서 x ≈ 29 mL, 가장 가까운 값은 30 mL 다.

→ ③

문제 6분출속도정답 ②

사고과정

같은 온도면 평균 운동에너지가 같으므로 v ∝ √(1/M) 이다.

v_A/v_N2 = 1.3 이면 M_A : M_N2 = 1 : 1.69 이다.

M_A = 28/1.69 ≈ 16.6 이니 메테인(16)이다.

→ ②

문제 7수득률정답 ③

사고과정

두 단계를 차례로 셈해 이론적 생성량을 구한다.

C 50 mol 과 O2 30 mol 로 CO 50 mol 이 생기고, Fe2O3 20 mol 중 16.7 mol 만 CO 50 mol 과 반응한다.

이론값 33.3 mol 에 실제 20 mol 이니 수득률은 60% 다.

→ ③

문제 8깁스자유에너지정답 ④

사고과정

주어진 반응식을 더하고 빼서 (가)·(나)를 만든다.

(가) 는 ΔG = −14 − (−21) = +7 kJ/mol, (나) 는 ΔG = −30 − (−62) = +32 kJ/mol 이다.

둘 다 ΔG > 0 이라 생체에서 에너지를 얻는 데 쓸 수 없다.

→ ④

문제 9원소의존재비정답 ④

사고과정

지각과 인체 모두 무게로 가장 많은 것은 산소다.

지각은 규산염이 대부분이라 두 번째가 규소(28%)다.

인체는 유기물이 대부분이라 두 번째가 탄소(18%)다.

→ ④

문제 10산화환원의정의정답 ④

사고과정

각 반응에서 원소의 산화수가 바뀌는지 본다.

①②③ 은 홑원소가 화합물이 되거나 그 반대라 산화수가 바뀐다.

④ 는 HClO4 와 NH3 가 붙어 염이 될 뿐 어느 원소의 산화수도 그대로다.

→ ④

문제 11방향족정답 ③

사고과정

멜라민 C3H6N6 을 놓고 보기를 하나씩 본다.

질소의 무게 %는 84/126 = 66.7% 이고, 고리에 π 전자 6개(4n+2)라 방향족이며, 고리 질소의 비공유 전자쌍이 염기성을 낸다.

요소가 멜라민이 되는 이 반응에서는 어느 원소의 산화수도 바뀌지 않는다.

→ ③

문제 12끓는점정답 ③

사고과정

끓는점을 묻는 것은 분자 사이 인력을 묻는 것이다.

에탄올은 수소 결합, 아세톤은 쌍극자 인력, 다이에틸에터는 분산력이 주로 작용한다.

따라서 에탄올 > 아세톤 > 다이에틸에터 순이다.

→ ③

문제 13분자의구조정답 ②

사고과정

중심 원자의 입체수를 세어 모양을 정한다.

SF4 는 시소형, XeF4 는 평면사각형, SO42−·CH4·MnO4−·NH4+ 는 정사면체다.

정사면체끼리 묶인 것을 고른다.

→ ②

문제 14방사성붕괴정답 ①

사고과정

각 변환에서 양성자수와 중성자수가 어떻게 바뀌는지 본다.

α 붕괴는 둘 다 2씩 줄고, 양전자 방출·전자 포획은 양성자가 1 줄고 중성자가 1 는다.

γ 선 방출은 에너지만 내보내므로 양성자수도 중성자수도 그대로다 — (가) 는 γ 가 아니다.

→ ①

문제 15분자의극성정답 ④

사고과정

각 분자의 쌍극자 벡터 합을 견준다.

CCl4 는 대칭이라 0 이고, CF2Cl2 는 F 와 Cl 이 서로 반대로 끌어 상쇄가 크다.

F 와 H 가 반대쪽에서 끌어당기는 CF2CH2 가 가장 크고 CCl2H2 가 그다음이다.

→ ④

문제 16혼성오비탈정답 ④

사고과정

각 화학종에서 질소의 입체수를 센다.

NH3 는 결합 3 + 고립쌍 1 로 sp3, NO2− 는 결합 2 + 고립쌍 1 로 sp2, N2 는 sp

다. 셋이 모두 다르니 같은 것이 없다.

→ ④

문제 17몰농도정답 ①

사고과정

얻은 CuS 의 질량을 몰수로 바꾼다.

CuS 의 화학식량은 95.5 이니 0.019 g 은 2.0×10−4 mol 이다.

폐수 2.0 L 로 나누면 1.0×10−4 M = 0.10 mM 이다.

→ ①

문제 18평형상수정답 ③

사고과정

평형 상수식에 주어진 농도를 넣는다.

K = [Cr2O72−]/([CrO42−]2[H+]2) = 0.1/(0.12[H+]2) = 3.0×1014 이다.

[H+]2 = 3.3×10−14 에서 [H+] = 1.8×10−7, pH ≈ 6.7 이다.

→ ③

문제 19염의액성정답 ②

사고과정

각 염이 물에서 가수분해하는지 본다.

NH4Cl 은 약염기의 짝산이라 산성, NaCl 은 어느 쪽도 가수분해하지 않아 중성이다.

CH3COONa 는 약산의 짝염기라 염기성이니 pH 는 다 > 나 > 가 순이다.

→ ②

문제 20르샤틀리에원리정답 ④

사고과정

르샤틀리에로 하나씩 본다.

CaCO3 는 고체라 평형 상수식에 안 들어가고, 촉매는 평형을 옮기지 않는다.

정반응이 흡열이니 온도를 높이면 CaO 가 늘고, 질소를 넣어도 CO2 의 부분압은 그대로다.

→ ④

문제 21주기적성질정답 ②

사고과정

2주기의 주기적 경향을 짚는다.

오른쪽으로 갈수록 유효 핵전하가 커져 전기음성도도 1차 이온화 에너지도 대체로 커진다.

13족·16족에서 잠깐 내려앉을 뿐 줄어드는 경향은 아니다.

→ ②

문제 22산화환원계수맞추기정답 ④

사고과정

반쪽 반응으로 나눠 전자 수를 맞춘다.

Cl 은 1 오르고 Mn 은 5 내리니 Cl− 10 개와 MnO4− 2 개가 짝이 된다.

염기성이므로 산소는 OH− 로 맞춘다 — OH− 의 계수는 16 이다.

→ ④

문제 23반응의자발성정답 ④

사고과정

높은 온도를 쓰는 까닭이 평형 때문인지 속도 때문인지 가른다.

①②③ 은 흡열이라 온도를 높여야 평형이 생성물 쪽으로 간다.

암모니아 합성은 발열이라 온도를 높이면 평형은 되레 불리해진다 — 속도를 얻으려고 높이는 것이다.

→ ④

문제 25전자기파정답 ③

사고과정

전자기파의 에너지 순서와 일으키는 운동을 짝짓는다.

에너지가 큰 쪽부터 이온화 → 전자 들뜸 → 진동 → 회전 → 핵스핀 들뜸 순이다.

그림의 A~D 를 이 순서대로 읽는다.

→ ③

문제 26물질파정답 ①

사고과정

λ = h/(mv) 를 두 물음에 각각 넣는다.

속도가 빠르면 λ 가 짧아지고, λ 가 짧을수록 해상도가 좋아진다.

야구공은 질량이 엄청나게 커서 λ 가 X선보다 훨씬 짧다 — 둘 다 옳다.

→ ①

문제 27결합차수정답 ①

사고과정

분자 오비탈로 결합 차수를 견준다.

N2 는 3 → N2+ 는 2.5 로 줄고, NO 는 2.5 → NO+ 는 3 으로 늘며, O2 는 2 → O2+ 는 2.5 로 는다.

전자를 뺐을 때 결합이 약해지는 것은 가 뿐이다.

→ ①

문제 28선스펙트럼정답 ④

사고과정

선 스펙트럼의 각 선이 어느 전이인지 맞춘다.

가시광선 계열은 모두 n=2 로 떨어지는 전이이고, 파장이 짧을수록 위에서 떨어진 것이다.

이온화는 n=∞ 에서 오는 가장 큰 에너지라 어느 선보다 파장이 짧다.

→ ④

문제 29수소결합정답 ①

사고과정

수소 화합물의 끓는점 경향을 짚는다.

같은 족에서는 분자량이 클수록 분산력이 커져 끓는점이 오르므로 GeH4 가 SiH4 보다 크다.

HF·H2O·NH3 만 수소 결합으로 튀어 오른다.

→ ①

문제 30이온화에너지정답 ④

구리 745, 철 762 kJ/mol 로 큰 차이가 없다.

청동기가 먼저인 까닭은 산화물의 안정성 — Fe2O3 가 CuO 보다 환원하기 어렵기 때문이다.

→ ④

문제 31순차이온화에너지정답 ③

사고과정

원자번호 1·2·3 의 전자 배치를 놓고 본다.

Li 은 2s 전자 하나가 안쪽 껍질에 가려져 1차 이온화 에너지가 가장 작고, Li 의 3차는 수소꼴 Li2+ 이라 Z2=9 배다.

He 은 1s 가 짝을 이뤄 홀전자가 없으니 상자기성이 아니다 — 셋 다 자석이 되지는 않는다.

→ ③

문제 32염의액성정답 ③

사고과정

강산과 약산의 염이 1:1 로 만난다.

H+ + CN− → HCN 으로 거의 다 넘어가고 HCN 은 약산이라 조금만 되돌아간다.

구경꾼 Na+·Cl− 를 빼면 HCN 이 가장 많고 용액은 산성이다.

→ ③

문제 33연소반응정답 ②

사고과정

CnH2n 의 완전 연소식을 세운다.

CnH2n + (3n/2)O2 → nCO2 + nH2O 에서 알켄 : 물의 질량비는 14n : 18n = 7 : 9

다. 8.4 g × 9/7 = 10.8 g 이니 물은 0.6 mol 이다.

→ ②

문제 40압력평형상수정답 ④

부피를 줄이면 압력이 올라 분자 수가 적은 P4 쪽으로 가니 P2 는 되레 줄어든다.

문제 49반응속도정답 ③

사고과정

압력으로 잰 속도를 PV = nRT 로 몰수 속도로 바꾼다.

P = 3×10−2 kPa = 2.96×10−4 atm, V = 0.3 L, T = 298 K 을 넣는다.

n = 2.96×10−4 × 0.3 / (0.082 × 298) ≈ 3.6×10−6 mol 이니 3×10−6 mol/s 다.

→ ③
