문제 1주기율표(옳은 것)정답 ④
주기율표와 관련된 설명 중 옳은 것은?
① 한 종류의 원소에서 다른 원소로의 변환은 불가능하다.
② 단원자 비활성 기체들은 주기율표에 포함되지 않는다.
③ 원자 질량에 따라 구분한 주기율표는 자연과학의 법칙이자 화학의 기초이다.
④ 주기적 성질의 발견은 축적된 관찰 결과를 연관관계 가진 지식체계로 탄생시켰다.

사고과정

④ 주기율표는 관찰된 규칙성을 체계화한 지식체계(옳음). ① 핵반응으로 원소 변환 가능. ② 비활성 기체도 18족에 포함. ③ 현대 주기율표는 원자번호 기준이며 "법칙"이 아님. → ④

현대 주기율표는 원자번호 순. 주기율은 자연법칙이라기보다 관찰된 경향을 정리한 체계다.
문제 2단분자층 질량 추정정답 ③
가로·세로 1m인 평평한 표면에 물 분자를 한 겹으로 최대한 많이 깔았을 때, 한 층 전체 질량에 가장 가까운 값은?
① 1 kg
② 1 g
③ 1 mg
④ 1 μg

사고과정

물 분자 지름 ~0.3 nm → 분자당 면적 ~10⁻¹⁹ m². 1m²에 ~10¹⁹개 → ~2×10⁻⁵몰 → 질량 ~2×10⁻⁵×18 ≈ 3×10⁻⁴ g ≈ 1 mg. → ③

차수(order of magnitude) 추정 문제. 분자 크기로 면적당 개수를 잡고 몰질량을 곱해 자릿수를 맞춘다.
문제 3극성 순서정답 ①
각 분자들의 극성이 증가하는 순으로 바르게 나열한 것은?
① CS2 < SO2 < HF < CH2O
② CS2 < SO2 < CH2O < HF
③ SO2 < CS2 < CH2O < HF
④ SO2 < CS2 < HF < CH2O

사고과정

CS2(직선 대칭, 무극성 μ=0) < SO2(굽음, ~1.6 D) < HF(~1.8 D) < CH2O(~2.3 D). → ①

쌍극자 모멘트로 극성 비교. CS2는 직선형이라 결합 쌍극자가 상쇄돼 무극성이다.
문제 4산화물·염 형성정답 ④
NaOH 수용액과 반응하여 염을 형성하지 않는 산화물은?
① Al2O3
② SiO2
③ P4O10
④ MgO

사고과정

NaOH(염기)는 산성·양쪽성 산화물과 반응. Al2O3(양쪽성)·SiO2·P4O10(산성)은 반응. ④ MgO는 염기성 산화물이라 NaOH와 반응 안 함. → ④

금속 산화물 중 1·2족(MgO)은 염기성, 비금속 산화물(SiO2·P4O10)은 산성, Al2O3는 양쪽성.
문제 5브뢴스테드 산정답 ④
다음 반응에서 물이 브뢴스테드-로리 산으로 작용한 것은?
① HCO3⁻ + H2O → CO3²⁻ + H3O⁺
② 2Na + 2H2O → 2NaOH + H2
③ Cu²⁺ + 6H2O → Cu(H2O)6²⁺
④ NH3 + H2O → NH4⁺ + OH⁻

사고과정

④ H2O → OH⁻로 양성자(H⁺)를 줌 → 브뢴스테드 산. ① H2O→H3O⁺(양성자 받음=염기). ②redox·③착물형성(루이스). → ④

브뢴스테드 산=양성자 주개. 물이 OH⁻가 되면 산, H3O⁺가 되면 염기로 작용한 것이다.
문제 6양자수 유효성정답 ②
실제 원자에 적용될 수 있는 양자수 모음은? [n, l, ml, ms]
① [1, 0, +1/2, +1/2]
② [3, 0, 0, −1/2]
③ [2, 2, 1, +1/2]
④ [3, 2, 1, 1]

사고과정

② n=3·l=0·ml=0·ms=−1/2 모두 유효. ① ml은 정수라야(+1/2 불가). ③ l은 0~n−1이라 n=2서 l=2 불가. ④ ms는 ±1/2(1 불가). → ②

규칙: l = 0~n−1, ml = −l~+l(정수), ms = ±1/2. 하나라도 어기면 불가능한 양자수 조합.
문제 7평면 분자정답 ③
모든 원자가 한 평면에 존재하는 분자/이온을 모두 고른 것은? (가. BH3 / 나. CO3²⁻ / 다. NH3 / 라. XeF4)
① 가, 나
② 가, 라
③ 가, 나, 라
④ 나, 다, 라

사고과정

가 BH3(평면삼각형)·나 CO3²⁻(평면삼각형)·라 XeF4(평면사각형) 모두 평면. 다 NH3는 고립쌍 때문에 삼각뿔(비평면). → ③

중심 원자에 고립쌍이 없으면(BH3·CO3²⁻) 평면, XeF4는 고립쌍 2개가 위아래라 평면사각형. NH3는 고립쌍 1개로 입체.
문제 8발열 과정정답 ④
발열 과정만 모두 모은 것은? (가. 수증기 응결 / 나. 식물의 광합성 / 다. 화학 결합의 생성 / 라. 철의 산화)
① 가, 나
② 나, 다
③ 가, 나, 라
④ 가, 다, 라

사고과정

발열: 가 응결(기체→액체)·다 결합 생성·라 철 산화(녹슮). 나 광합성은 빛 에너지 흡수 → 흡열. → ④

결합 생성은 항상 발열, 분해는 흡열. 응결·산화는 열 방출, 광합성은 에너지 저장(흡열).
문제 9조밀쌓임 틈새 자리정답 ①
입방조밀채움(ccp) 결정에서 적층축을 따라 표시된 틈새형 자리 A(a층-c층 사이)·B(c층-b층 사이)·C(b층-a층 사이)를 바르게 짝지은 것은?
① 사면체·팔면체·사면체
② 사면체·입방체·사면체
③ 팔면체·사면체·팔면체
④ 팔면체·입방체·팔면체

사고과정

조밀쌓임에서 적층 방향을 따라 틈새는 사면체-팔면체-사면체로 교대로 나타남(층 사이마다 팔면체 1세트·사면체 2세트). A·C는 사면체, B는 팔면체. → ①

조밀쌓임에는 사면체 구멍(원자 4개 둘러쌈)과 팔면체 구멍(6개)이 있고, 적층축을 따라 T-O-T 순으로 배열된다.
문제 10반데르발스 a값정답 ①
반데르발스식의 보정상수 a값이 작은 것부터 나열한 것은? (가. He / 나. Ne / 다. Ar / 라. Kr)
① (가) < (나) < (다) < (라)
② (라) < (다) < (나) < (가)
③ (다) < (나) < (가) < (라)
④ (라) < (가) < (나) < (다)

사고과정

a는 분자 간 인력(분산력)을 보정. 원자 크기·분극률 클수록 a 큼: He<Ne<Ar<Kr. → ①

반데르발스 a는 인력, b는 분자 자체 부피를 보정. 무거운 비활성 기체일수록 분산력이 커 a가 크다.
문제 11분출 분리정답 ①
고압 N2/H2 혼합 기체(농도 동일)를 작은 구멍이 있는 장치로 통과시킬 때, 분출구 A와 잔류측 B의 농도 비교가 옳은 것은?
① A: [N2]<[H2], B: [N2]>[H2]
② A: [N2]<[H2], B: [N2]=[H2]
③ A: [N2]>[H2], B: [N2]<[H2]
④ A: [N2]>[H2], B: [N2]=[H2]

사고과정

작은 구멍으로 가벼운 H2가 더 빨리 분출 → A는 H2 농축([N2]<[H2]). 잔류 기체(B)는 H2 빠져 N2 농축([N2]>[H2]). → ①

분출(effusion) 분리: 가벼운 기체가 먼저 빠져나가 분출 측은 가벼운 성분이, 잔류 측은 무거운 성분이 농축된다.
문제 12Al2Cl6 구조정답 ④
고체 AlCl3이 180℃에서 승화해 옥텟을 만족하는 Al2Cl6가 된다. 이 분자의 구조로 옳은 것은?
① (말단 Cl만)
② (한쪽 다리)
③ (직선 배열)
④ 다리 Cl 2개·말단 Cl 4개

사고과정

④ Al2Cl6는 다리 Cl 2개·말단 Cl 4개로, 두 AlCl4 사면체가 모서리를 공유. 각 Al이 결합 4개로 옥텟 만족. → ④

Al은 전자 부족이라 단량체 AlCl3는 옥텟 미달. 이량체화로 Cl이 다리를 놓아 각 Al이 4결합(옥텟)을 완성한다.
문제 13산의 세기(틀린 비교)정답 ③
산의 세기 비교가 잘못된 것은?
① H2SeO4 > H2SeO3
② H2SO4 > HSO4⁻
③ H2S > H2Se
④ H2SO4 > H2SeO4

사고과정

③ 이성분 수소화물은 족 따라 내려갈수록 H−X 결합 약해져 H2Se > H2S → "H2S>H2Se"는 틀림. → ③

①산소 많을수록 강함·②1차>2차 이온화·④중심 원자 전기음성도 클수록(S>Se) 강함은 모두 옳음.

옥소산은 산소 수·중심 전기음성도로, 이성분 수소화물(H2S·H2Se)은 결합 세기로 산도를 비교. 후자는 아래로 갈수록 강하다.
문제 14결정 실험식정답 ①
A는 정육면체 꼭짓점, B는 각 면 중심, C는 정육면체 중심에 위치한 결정의 실험식은?

문제 15준금속 공통 성질정답 ④
B·Si·Ge·As·Sb의 공통 성질을 모두 옳게 모은 것은? (가. 상온 1기압서 고체 / 나. 금속·비금속 모두와 화합물 형성 / 다. 산화물이 산성·염기성 모두 작용)
① 가
② 나, 다

문제 16평형 농도 계산정답 ③
평형 상수 9, X2+Y2⇌2XY. X2·Y2·XY를 각 1.0몰씩 10.0 L에 넣고 평형 도달. 평형 XY 농도(M)는?
① 0.14
② 0.16
③ 0.18
④ 0.20

사고과정

초기 각 0.1 M. Q = 0.1²/(0.1×0.1) = 1 < 9 → 정반응. (0.1+2x)/(0.1−x) = √9 = 3 → x = 0.04.

[XY] = 0.1 + 2(0.04) = 0.18 M. → ③

Q와 K를 비교해 진행 방향을 정하고 ICE 표 작성. K가 완전제곱이면 제곱근을 취해 1차식으로 푼다.
문제 17반감기·β붕괴정답 ③
⁹⁰Sr(반감기 28년, β붕괴)의 0.10 mg이 1.25×10⁻² mg 남을 때까지 걸리는 시간과 생성 원소를 바르게 연결한 것은?
① 56년 –
② 56년 –
③ 84년 – Y
④ 84년 –

사고과정

0.10/0.0125 = 8 = 2³ → 3반감기 = 84년. β붕괴는 중성자→양성자라 Z 증가: Sr(38) → Y(이트륨, 39). → ③

남은 비율 = (1/2)ⁿ로 n(반감기 횟수)을 구하고 ×28년. β⁻ 붕괴는 원자번호가 1 증가(질량수 불변).
문제 18적정 실험 기구정답 ④
진한 염산을 희석·표준화하는 실험에서 A~D에 적절한 기구는? (A: 진한 염산 4.0 mL 취함 / B: 500 mL 정확히 맞춤 / C: 25 mL + 지시약 / D: NaOH 표준액 넣어 적정)
① 눈금 실린더–부피 플라스크–삼각 플라스크–피펫
② 뷰렛–삼각 플라스크–부피 플라스크–피펫
③ 눈금 실린더–삼각 플라스크–부피 플라스크–뷰렛
④ 피펫–부피 플라스크–삼각 플라스크–뷰렛

사고과정

A 정밀 소량 → 피펫, B 정확한 500 mL → 부피 플라스크, C 적정 대상 담음 → 삼각 플라스크, D 적정액 적가 → 뷰렛. → ④

정확한 부피 취하기=피펫, 정확한 부피 맞추기=부피 플라스크, 적정액 떨어뜨리기=뷰렛, 반응 용기=삼각 플라스크.
문제 19탄산염·산 반응정답 ④
CaCO3 + 묽은 HCl → CaCl2 + 기체. 옳은 것은? (가. CaCO3는 염기로 작용 / 나. 발생 기체는 CO2 / 다. 발열반응)
① 가, 나
② 가, 다
③ 나, 다
④ 가, 나, 다

사고과정

CaCO3 + 2HCl → CaCl2 + H2O + CO2. 가 산을 중화(염기 작용)·나 CO2 발생·다 발열. 모두 옳음. → ④

탄산염+산 → 염+물+CO2(발열). 탄산칼슘이 양성자를 받아 산을 중화하므로 염기로 작용한다.
문제 20약산 pH·pKa정답 ③
0.1M 아세트산의 이온화도가 약 0.01이다. pH를 x, pKa를 y라 할 때 x+y에 가장 가까운 값은?
① 3
② 5
③ 8
④ 9

사고과정

[H⁺] = αC = 0.01×0.1 = 10⁻³ → pH = 3(x). Ka = α²C = (0.01)²×0.1 = 10⁻⁵ → pKa = 5(y).

x + y = 3 + 5 = 8. → ③

이온화도 α가 작으면 [H⁺]≈αC, Ka≈α²C. pKa=−logKa로 환산한다.
문제 21거울상 이성질체 수정답 ②
거울상 이성질체를 갖는 화학종의 총 개수는? (CHFClBr, cis-ClHC=CHCl, cis-Co(en)2Cl2, Pt(en)Cl2) (en = H2NCH2CH2NH2)
① 1
② 2
③ 3
④ 4

0.02M HA(pKa=8.0) 10mL를 0.02M NaOH로 적정. 당량점에서 페놀프탈레인(pKa=9.4) 중 색을 띠는 비율은? (log4=0.60)
① 20%
② 33%
③ 66%
④ 80%

사고과정

당량점: [A⁻]=0.01, Kb=10⁻⁶, [OH⁻]=√(10⁻⁶×0.01)=10⁻⁴ → pH=10. 페놀프탈레인 [In⁻]/[HIn] = 10^(10−9.4) = 10^0.6 = 4.

색 띠는 비율 = 4/(4+1) = 80%. → ④

먼저 당량점 pH(약산의 짝염기 가수분해)를 구하고, 그 pH에서 지시약의 [In⁻]/[HIn]을 헨더슨식으로 계산한다.
문제 44질량%→몰농도정답 ③
질량비 70% HClO4(화학식량 100) 수용액(밀도 1.67 g/mL)의 몰농도에 가장 가까운 값은?
① 10.0 M
② 11.0 M
③ 11.7 M
④ 12.5 M

사고과정

M = (밀도×질량분율×1000)/화학식량 = (1.67×0.70×1000)/100 = 11.69 ≈ 11.7 M. → ③

몰농도 = (밀도 g/mL × 질량% × 1000)/몰질량. 1 L(=1000 mL) 기준으로 용질 질량·몰수를 계산한 것.
문제 45철의 부식 속도정답 ②
(a) pH 7 증류수, (b) pH 4 묽은 HCl, (c) pH 10 묽은 NaOH에 철 막대를 담갔을 때 옳은 것은?
① (a)에서 녹이 가장 빠르게 생성된다.
② (b)에서 녹이 가장 빠르게 생성된다.
③ (c)에서 녹이 가장 빠르게 생성된다.
④ 세 용액에서 비슷하게 진행된다.

② 철의 부식은 산성(b, pH 4)에서 가장 빠름(H⁺가 산화 촉진). 염기성(c)은 부동태화로 느림. → ②

금속 부식은 산성 환경에서 가속(H⁺ 환원이 부반응). 염기성에선 산화막이 형성돼 부식이 억제되는 경향.
문제 46결합 에너지 최대정답 ①
이원자 분자 중 결합 에너지가 가장 큰 것은?

② N2
③ O2
④ H2

CO(~1072 kJ/mol)는 삼중결합에 추가 안정화로 N2(945)보다도 큼. O2(이중·498)·H2(단일·436)는 작음. → ①

문제 47NH3 연소 에너지정답 ②
질소 산화물 생성 엔탈피는 양의 값이고 NO+½O2→NO2는 발열. NH3 1몰당 연소 에너지 절댓값이 큰 것부터 배열한 것은? (가. N2 생성 / 나. NO 생성 / 다. NO2 생성)
① 가>나>다
② 가>다>나
③ 나>다>가
④ 다>나>가

사고과정

가장 안정한 N2(가) 생성이 최대 발열. NO·NO2는 생성 엔탈피가 양(흡열성)이라 덜 발열. NO+½O2→NO2 발열이라 NO2(다)>NO(나). → 가>다>나 → ②

연소 생성물이 안정할수록(생성 엔탈피 낮을수록) 더 많은 열 방출. N2가 가장 안정, NO가 가장 불안정.
문제 48헨리 법칙(용해량)정답 ②
A(산소 0.3atm·헬륨 0.7atm·수용액 0.5L)와 B(산소 0.9atm·헬륨 1.1atm·수용액 1.0L)의 용해 평형. 용해된 산소 몰수 x:y는?
① 1:12
② 1:6
③ 1:3
④ 1:2

사고과정

헨리 법칙: 용해 농도 ∝ 산소 분압. 용해 몰수 = 농도×부피 ∝ 분압×부피. x ∝ 0.3×0.5 = 0.15, y ∝ 0.9×1.0 = 0.90.

x:y = 0.15:0.90 = 1:6. → ②

헨리 법칙은 각 기체의 분압에만 의존(He 무관). 용해 "양"을 물으면 농도에 용액 부피를 곱해야 한다.
문제 49연료 연소열(질량당)정답 ①
사슬형 포화탄화수소 A·B(A가 B보다 끓는점 낮음, C−C 348·C−H 412 kJ/mol)를 같은 질량으로 완전 연소시킬 때 더 많은 열을 방출하는 것은?
① A
② B
③ 같다
④ 알 수 없다

사고과정

A가 끓는점 낮음 → 더 작은 분자 → H:C 비가 높음(C−H 결합 비율↑). 수소가 많을수록 질량당 연소열이 크므로 같은 질량서 A가 더 많은 열 방출. → ①

탄화수소는 H가 많을수록(작은 알케인일수록) 단위 질량당 연소 에너지가 크다. 끓는점으로 분자 크기를 가늠한다.
문제 50VSEPR 결합각정답 ③
VSEPR로 예측한 O−Xe−O 결합각이 큰 것부터 배열한 것은? (가. XeO3 / 나. XeO4 / 다. XeO6⁴⁻)
① 가>나>다
② 가>다>나
③ 나>가>다
④ 나>다>가

사고과정

XeO4(사면체, 고립쌍 없음, 109.5°) > XeO3(삼각뿔, 고립쌍 1개로 압축 ~103°) > XeO6⁴⁻(팔면체, 90°). → 나>가>다 → ③

고립쌍은 결합각을 압축. 같은 영역 수라도 고립쌍이 있으면 각이 작아지고, 팔면체(90°)가 사면체(109.5°)보다 작다.
문제 51아레니우스·역반응 Ea정답 ③
온도 10 K 증가 시 속도가 2배가 되는 단일 단계 반응 A+B→C+D(ΔH°정반응=−20 kJ/mol)에서, 역반응의 활성화 에너지에 가장 가까운 것은? (ln2=0.7)
① 10 kJ/mol
② 40 kJ/mol
③ 70 kJ/mol
④ 120 kJ/mol

사고과정

아레니우스: ln2 = (Ea/R)(10)/(300×310) → Ea,정 ≈ 8.3×0.7×9300 ≈ 53 kJ/mol.

ΔH = Ea,정 − Ea,역 → Ea,역 = 53 − (−20) = 73 ≈ 70 kJ/mol. → ③

10 K당 2배 규칙으로 정반응 Ea를 아레니우스식에서 구하고, ΔH=Ea정−Ea역로 역반응 장벽을 계산. 발열이라 역반응 장벽이 더 높다.
문제 52중화 적정·전도도정답 ①
1.0 L의 1.0M HCl을 1.0M NaOH로 적정할 때 전기 전도도 변화를 올바르게 나타낸 것은?
① 감소→(당량점 최소, 0 아님)→증가
② 일정
③ 증가→감소
④ 0까지 급감→증가

사고과정

이동도 큰 H⁺가 이동도 작은 Na⁺로 치환 → 전도도 감소. 당량점(V=1.0 L, NaCl 존재라 0 아님)서 최소. 이후 과량 OH⁻로 증가. → ①

④는 최소가 0까지 떨어져 틀림(NaCl이 전류를 통함).

강산-강염기 적정의 전도도는 V자형이되 바닥이 0이 아니다(염이 남음). H⁺·OH⁻는 특별히 이동도가 커 전도도를 크게 좌우한다.
문제 53NH3 완충 pH정답 ④
0.40M NH3와 0.20M NH4Cl로 구성된 완충 용액의 pH에 가장 가까운 값은? (NH3 pKb=4.75, log2=0.30)
① 5.05
② 8.95
③ 9.25
④ 9.55

사고과정

pKa(NH4⁺) = 14 − 4.75 = 9.25. pH = 9.25 + log(0.40/0.20) = 9.25 + log2 = 9.25 + 0.30 = 9.55. → ④

염기성 완충은 pKa(짝산)=14−pKb로 변환 후 헨더슨식 적용. 염기:짝산 비가 클수록 pH가 pKa보다 높아진다.
문제 54약산 농도 역산정답 ③
폼산(HCOOH) 용액의 pH가 2.00이었다. 이 용액의 농도에 가장 가까운 값은? (Ka=1.8×10⁻⁴)
① 0.05M
② 0.10M
③ 0.50M
④ 1.00M

사고과정

[H⁺]=[HCOO⁻]=10⁻². Ka = (10⁻²)²/[HCOOH] = 1.8×10⁻⁴ → [HCOOH] = 10⁻⁴/(1.8×10⁻⁴) ≈ 0.56.

농도 = 0.56 + 0.01 ≈ 0.5 M. → ③

약산은 [H⁺]²/(C−[H⁺]) = Ka. pH로 [H⁺]를 구한 뒤 Ka 식을 농도 C에 대해 푼다.
문제 55한계 반응물·피스톤정답 ②
4NH3(g)+5O2(g)→4NO(g)+6H2O(g). 자유 피스톤 용기(PNH₃=0.4·PO₂=0.6 기압, 대기압 1기압)서 반응 완결 후 옳은 것은? (가. 피스톤 위치 처음보다 높음 / 나. 전체 압력 1기압 / 다. O2 부분압 0.1기압)

③ 나, 다

NH3 한계(0.4 ↔ O2 0.5 소모, O2 0.1 잔류). 생성 NO 0.4·H2O 0.6 → 총 몰 1.0→1.1.

나 자유 피스톤이라 1기압 유지. 가 몰↑로 부피↑→피스톤 상승. 다 O2 분압 = (0.1/1.1)×1 = 0.09≠0.1. → ②

문제 56리튬전지 산화수정답 ①

문제 57속도식 해석(옳은 개수)정답 ①
초기 속도 자료([1] A 0.012·B 0.012·v 2.07×10⁻⁴ / [2] A 0.012·B 0.024·v 4.14×10⁻⁴ / [3] A 0.024·B 0.012·v 8.28×10⁻⁴)에서 옳은 것의 개수는? (가. A 1차 / 나. B 1차 / 다. 단일 단계 / 라. k=1.2 M⁻²s⁻¹)
① 1개
② 2개
③ 3개
④ 모두

사고과정

[1]·[2]: B 2배에 속도 2배 → B 1차(나 옳음). [1]·[3]: A 2배에 속도 4배 → A 2차(가 틀림). v = k[A]²[B].

다 속도식만으로 단일 단계 단정 불가. 라 k = 2.07×10⁻⁴/((0.012)²×0.012) ≈ 120(1.2 아님). 옳은 건 나 1개. → ①

차수는 한 농도만 바꾼 실험 쌍으로 판정. 속도식이 단순해도 단일 단계임을 보장하진 않으며, k는 자료로 직접 계산해 검증한다.
문제 58세기·크기 성질의 곱정답 ③

①(S×T)·②(P×V)·④(표면장력×면적)은 모두 에너지(크기 성질). ③ 화학퍼텐셜(세기)×밀도(세기) = 세기 성질로 다름. → ③

문제 60평형 이동 (전원정답)전원정답
A(g)⇌B(g)+C(g)(정반응 흡열). 압력-시간 그래프서 t1에 전체 압력 (가), t2에 온도 (나), t3에 A 일부 제거 시 B 농도 (다). (가),(나),(다)로 옳은 것은?
① 감소·감소·감소
② 증가·감소·감소
③ 감소·증가·감소
④ 감소·감소·증가

사고과정

원본 채점표에서 전원정답(모두정답)으로 처리된 문항. 의도된 해석: 정반응이 기체 몰수↑(1→2)이라 t1 A↓·B·C↑는 압력 감소(가), t2 역반응 쪽 이동은 흡열의 반대라 온도 감소(나), t3 A 제거는 역반응 유도라 B 감소(다) → ①에 해당하나, 출제 오류로 ①②③④ 모두 정답.

기체 몰수가 느는 정반응은 감압 시 촉진. 흡열 정반응은 냉각 시 역행. 다만 이 문항은 공식적으로 전원정답 처리되었다.
