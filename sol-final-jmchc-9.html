문제 1어는점내림정답 ③

사고과정

어는점 ∝ EG 몰랄농도(EG몰/물kg).

A(부피비): (1.11/62)×1000 ≈ 17.9m.

B(질량비): 1000/62 ≈ 16.1m.

C(몰비): 1000/18 ≈ 55.6m.

몰랄농도 C > A > B → 어는점 낮은 순 C, A, B.

→ ③

어는점 내림은 용질 몰랄농도에 비례. 몰비 1:1이면 가벼운 물이 적어 EG 농도가 가장 높다(어는점 최저).
문제 2어는점내림정답 ②

사고과정

몰랄 = (1.0/233)/0.025 = 0.172m. i = ΔTf/(Kf·m) = 0.62/(1.86×0.172) ≈ 2. → ②

i=2면 [Co(NH3)4Cl2]Cl 구조(착이온 + Cl− 1개). 배위권 안 Cl 2개는 해리되지 않는다(착화학의 핵심).
문제 3삼투압정답 ④

사고과정

①②③은 옳다(평형·반투막 압력·농도 균일화 경향).

④ 삼투에서 이동하는 건 용매(물)이고, 묽은 쪽→진한 쪽으로 간다. 용질은 반투막을 못 지난다. → ④

삼투 = 용매가 반투막을 통과해 농도를 맞추려는 현상. 용질은 막힌다. "용질이 이동"은 항상 함정.
문제 4어는점내림정답 ④

사고과정

비극성 벤젠에서는 이온화합물도 해리되지 않는다(i=1).

셋 다 0.2m·i=1 → 어는점 내림 동일.

→ ④

반트호프 인자 i는 용매에 따라 달라진다. 물에선 NaCl이 i=2지만, 비극성 용매에선 분자로 존재해 i=1. 결정적 함정.
문제 5삼투압정답 ④

사고과정

(i) 물만 통과 → 삼투로 물이 b(묽음)→a(진함) → a↑ b↓.

(ii) 둘 다 통과 → 농도·수위 모두 균일화 → a·b 같음.

→ ④

반투막(물만)이면 삼투로 한쪽이 올라가고, 완전 투과막이면 그냥 섞여 평평해진다.
문제 6역삼투정답 ④

사고과정

삼투압을 넘어야 한다: π = iMRT = 2×5×0.0821×298 ≈ 245 ≈ 250 기압. → ④

역삼투는 자연 삼투압보다 큰 압력을 가해 거꾸로 물을 짜내는 방식. NaCl은 i=2라 농도의 2배로 계산.
문제 7어는점내림정답 ③

사고과정

설탕(i=1) vs NaCl(i=2). ①(어는점 내림 있음)·②(설탕 끓는점이 NaCl보다 낮음)·④(증기압 내림)는 옳다.

③ 설탕은 i가 작아 어는점 내림이 작다 → 어는점이 NaCl보다 높다("낮다"는 거짓). → ③

총괄성은 입자 수(i×m)에 비례. NaCl(i=2)이 설탕(i=1)보다 어는점을 더 많이 내린다(설탕 어는점이 더 높음).
문제 8삼투압정답 ③

사고과정

M = (질량·R·T)/(π·V), π ∝ h이라 M ∝ (질량×T)/(h×V).

M↑: 가(h↓)·나(T↑)·다(질량↑). 라(V↑)는 M을 줄인다. → ③

분자량 공식의 분자·분모를 보고 각 변수가 M을 키우는지 줄이는지 판단. 부피(라)는 분모라 크게 측정하면 M이 작아진다.
문제 9분자량정답 ②

사고과정

M = (질량·RT)/(πV) = (20.0×0.0821×298)/(0.021×1.00) ≈ 489/0.021 ≈ 23,000 g/mol. → ②

삼투압은 작은 농도도 큰 압력을 내 거대분자(단백질) 몰질량 측정에 유용하다. M = mRT/(πV).
문제 10흡열반응정답 ④

사고과정

①(연소)·②(응축)·③(응고)는 모두 발열.

승화(고체→기체)는 결합을 끊어 에너지를 흡수 → 흡열.

→ ④

상태가 흩어지는 방향(융해·기화·승화)은 흡열, 모이는 방향(응고·액화·응결)은 발열. 연소도 발열.
문제 11온실기체정답 ①

사고과정

온실기체는 적외선을 흡수해야 하고, 그러려면 진동 중 쌍극자 모멘트 변화가 있어야 한다.

H2는 등핵 이원자라 쌍극자가 없어 적외선을 흡수하지 못한다.

→ ①

CO·H2O·CH4는 적외선 활성. 등핵 이원자(H2·N2·O2)는 쌍극자 변화가 없어 온실기체가 아니다.
문제 12반응열정답 ③

사고과정

HCl 0.172몰, Ba(OH)2 0.0862몰 → 정확히 2:1 양론비.

반응 단위 = 0.0862.

Q = 0.0862×112.4kJ = 9690J.

ΔT = 9690/(400×4.18) = 5.8°C → 최종 = 25 + 5.8 = 30.8°C.

→ ③

발열 반응이라 온도 상승. ΔH는 반응식 기준(2H2O당 112.4kJ)이라 Ba(OH)2 몰수로 곱한다.
문제 13Q=CmT정답 ④

사고과정

NaOH 4g = 0.1몰.

용해: 100×4.2×3 = 1260J → 12600J/mol.

용해+중화: 100×4.2×5 = 2100J → 21000J/mol.

중화 = 21000 − 12600 = 8400J/mol(발열) → ΔH = −8400.

→ ④

고체 NaOH는 녹으면서도 열을 낸다. 중화열만 뽑으려면 (용해+중화) 실험에서 (용해) 실험을 빼야 한다. 발열이라 음수.
문제 14발열량정답 ④

사고과정

a(CH4 55.6 > CH3OH 22.7)·c(에탄올 29.7 > 메탄올 22.7 kJ/g)는 옳다.

b H2는 143 kJ/g로 CH4보다 높다("CH4>H2"는 거짓). d 동면 동물·낙타는 지방(에너지 밀도 최고)을 비축한다. → ④

g당 발열량은 수소 > 지방 > 탄수화물 순. 낙타 혹·곰의 비축 에너지는 탄수화물이 아니라 지방이다.
문제 15양적관계정답 ②

사고과정

1kg Al = 1000/27 ≈ 37몰. 반응 1번에 Al 2몰 → 37/2 ≈ 18.5 반응단위. 에너지 = 18.5×1676 ≈ 31,000 ≈ 3×10⁴ kJ. → ②

반응식 계수(2Al)에 주의. 알루미늄 제련이 막대한 에너지를 쓰는 이유(재활용이 중요한 까닭).
문제 16엔탈피정답 ②

사고과정

원소(N2+O2)를 0 기준: 2NO2 = +68(최고), 원소 = 0(중간), N2O4 = −20(최저).

A = NO2, B = N2+O2, C = N2O4(l).

→ ②

생성열이 양수면 원소보다 높고, 음수면 낮다. NO2(+)는 위, N2O4(−)는 아래, 원소는 가운데.
문제 17표준생성열정답 ①

사고과정

이온화 에너지 = 기체 원자에서 전자 떼기 → 라(B→B++e−).

표준생성열 = 원소에서 화합물 1몰 생성 → 마(원소→NOF).

→ ①

다=전자친화도, 나=승화열, 바=연소열. 정의(어느 출발물→어느 생성물)로 종류를 구분한다.
문제 18헤스법칙정답 ④

계수 조합 (1)×ΔH1 + (−1)×ΔH2 + (−6)×ΔH3 + (10)×ΔH4:

−1230 + 2970 + 480 − 2900 = −680 kJ. → ④

헤스 법칙: 목표식의 각 물질이 맞도록 주어진 식을 정수배·역방향으로 더한다. PCl3가 중간체로 상쇄되도록 계수를 잡는다.
문제 19결합에너지정답 ①

사고과정

½N2+½O2→NO, ΔH = (끊은 결합)−(생긴 결합): 90 = [½(941)+½(499)] − D(NO) = 720 − D(NO).

D(NO) = 720 − 90 = 630 kJ/mol. → ①

ΔH = Σ(반응물 결합) − Σ(생성물 결합). N≡N·O=O 반쪽씩 끊고 N=O 하나 만든다.
문제 20결합에너지정답 ③

사고과정

E = hc/λ × NA = (6.6×10⁻³⁴×3×10⁸/239×10⁻⁹) × 6.0×10²³ ≈ 8.3×10⁻¹⁹ × 6.0×10²³ ≈ 5.0×10⁵ J/mol = 500 kJ/mol. → ③

광자 1개 에너지 E=hc/λ에 아보가드로 수를 곱해 1몰 에너지로. 파장이 짧을수록 광자 에너지가 크다.
문제 21연소엔탈피정답 ①

연소열 이용: ΔH = Σ연소열(반응물) − Σ연소열(생성물) = [−3268 + 3(−286)] − (−3754) = −4126 + 3754 = −372 ≈ −400. → ①

문제 23생성엔탈피정답 ④

ΔHf = (Ge 승화 + 2×F2 결합 끊기) − (4×Ge−F 결합 만들기):

[375 + 2×158] − [4×465] = 691 − 1860 = −1169 kJ/mol. → ④

생성 경로: 고체 Ge 승화 → F2 2개 분해 → Ge−F 4개 형성. 결합 형성(방출)이 더 커서 발열(음수).
문제 24에탄올의연소정답 ④

사고과정

가(연소=발열)·나(H2O 기체/액체에 따라 엔탈피 다름)·다(H가 O와 결합해 물 형성 = 산화)·라(0°C선 물이 액체, 기체 몰수 3O2→2CO2로 감소)는 모두 옳다. → ④

고전적 산화 정의(산소와 결합)로 보면 H도 산화된다. 0°C에선 H2O가 기체가 아니라 기체 부피 비교는 O2 vs CO2만.
문제 25반응엔탈피정답 ①

사고과정

끊기(반응물): 4×400(C−H) + 2×500(O=O) = 2600. 만들기(생성물): 2×700(C=O) + 4×450(O−H) = 3200.

ΔH = 끊기 − 만들기 = 2600 − 3200 = −600 kJ/mol. → ①

ΔH = Σ(끊는 결합) − Σ(만드는 결합). 끊기는 흡열(+), 만들기는 발열(−). 결합 개수를 정확히 세는 게 핵심.
문제 26반응엔탈피정답 ①

사고과정

끊기: H−H 436 + C≡C 812 + 2×C−H 828 = 2076.

만들기: C=C 620 + 4×C−H 1656 = 2276.

ΔH = 2076 − 2276 = −200 kJ.

→ ①

아세틸렌(삼중결합)에 H2를 첨가해 에틸렌(이중결합)으로. 삼중→이중 + C−H 2개 추가 형성을 추적한다.
문제 27결합에너지정답 ②

반응물(C3H8+5O2): 2×356 + 8×416 + 5×498 = 6530.

생성물(3CO2+4H2O): 6×803 + 8×467 = 8554.

차이 = 8554 − 6530 = 2024 kJ.

→ ②

6530(반응물 합)·8554(생성물 합)는 함정 보기. 문제가 "차이"를 물으니 빼야 한다. 이 차이가 곧 |ΔH|.
문제 28연소엔탈피정답 ③

사고과정

이미 가장 많이 산화된 아세트산이 더 탈 여지가 적어 연소열 최소.

→ ③

분자에 산소가 많을수록(이미 산화됨) 연소로 방출할 에너지가 적다. 가장 환원된 C2H6이 연소열 최대.
문제 29클라우지우스-클라페롱식정답 ①

사고과정
