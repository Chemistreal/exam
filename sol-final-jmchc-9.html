문제 1부동액 어는점 비교정답 ③
물(18, 1.00 g/mL)과 EG(에틸렌글리콜, 62, 1.11 g/mL)로 부동액을 만든다. A(1:1 부피비), B(1:1 질량비), C(1:1 몰비)로 만든 부동액의 어는점을 낮은 순서부터 옳게 배열한 것은?
① A, B, C
② B, A, C
③ C, A, B
④ C, B, A

사고과정

어는점 ∝ EG 몰랄농도(EG몰/물kg). A(부피비): (1.11/62)×1000 ≈ 17.9m. B(질량비): 1000/62 ≈ 16.1m. C(몰비): 1000/18 ≈ 55.6m.

몰랄농도 C > A > B → 어는점 낮은 순 C, A, B. → ③

어는점 내림은 용질 몰랄농도에 비례. 몰비 1:1이면 가벼운 물이 적어 EG 농도가 가장 높다(어는점 최저).
문제 2착화합물 이온 수정답 ②
물의 Kf = 1.86 ℃/m. 물 25.0g에 Co(NH3)4Cl3(233) 1.0g을 녹인 용액의 어는점이 −0.62℃다. 이 화합물 1몰을 녹일 때 생성되는 이온의 몰 수는?
① 1
② 2
③ 3
④ 4

사고과정

몰랄 = (1.0/233)/0.025 = 0.172m. i = ΔTf/(Kf·m) = 0.62/(1.86×0.172) ≈ 2. → ②

i=2면 [Co(NH3)4Cl2]Cl 구조(착이온 + Cl− 1개). 배위권 안 Cl 2개는 해리되지 않는다(착화학의 핵심).
문제 3삼투 현상정답 ④
삼투 현상에 대한 설명으로 옳지 않은 것은?
① 평형 과정으로 볼 수 있다.
② 삼투 현상이 생기면 반투막에 압력이 미친다.
③ 두 용액의 농도가 같아지려는 경향으로 일어난다.
④ 용질 분자는 진한 용액에서 묽은 용액으로 이동한다.

사고과정

①②③은 옳다(평형·반투막 압력·농도 균일화 경향).

④ 삼투에서 이동하는 건 용매(물)이고, 묽은 쪽→진한 쪽으로 간다. 용질은 반투막을 못 지난다. → ④

삼투 = 용매가 반투막을 통과해 농도를 맞추려는 현상. 용질은 막힌다. "용질이 이동"은 항상 함정.
문제 4비극성 용매 · 어는점정답 ④
화합물이 비극성 용매인 벤젠(C6H6)에 녹는다고 가정하면, 용액의 어는점이 가장 낮은 화합물은? (m은 몰랄농도)
① 0.2 m 글루코스
② 0.2 m NaCl
③ 0.2 m MgCl2
④ 모두 같다

사고과정

비극성 벤젠에서는 이온화합물도 해리되지 않는다(i=1). 셋 다 0.2m·i=1 → 어는점 내림 동일. → ④

반트호프 인자 i는 용매에 따라 달라진다. 물에선 NaCl이 i=2지만, 비극성 용매에선 분자로 존재해 i=1. 결정적 함정.
문제 5반투막 수위 변화정답 ④
반투막으로 분리된 a쪽(1.0M 포도당)과 b쪽(물). (i) 물만 통과 / (ii) 물·포도당 모두 통과할 때 충분한 시간 후 수위 변화는? (증발 무시)
(i)(ii)
①a↑ b↓a↑ b↓
②a·b 같음a↓ b↑
③a↓ b↑a·b 같음
④a↑ b↓a·b 같음

사고과정

(i) 물만 통과 → 삼투로 물이 b(묽음)→a(진함) → a↑ b↓. (ii) 둘 다 통과 → 농도·수위 모두 균일화 → a·b 같음. → ④

반투막(물만)이면 삼투로 한쪽이 올라가고, 완전 투과막이면 그냥 섞여 평평해진다.
문제 6역삼투 압력정답 ④
역삼투(reverse osmosis)로 바닷물(5M NaCl로 가정)을 마실 물로 바꾸는 데 필요한 압력은?
① 5 기압
② 10 기압
③ 100 기압
④ 250 기압

사고과정

삼투압을 넘어야 한다: π = iMRT = 2×5×0.0821×298 ≈ 245 ≈ 250 기압. → ④

역삼투는 자연 삼투압보다 큰 압력을 가해 거꾸로 물을 짜내는 방식. NaCl은 i=2라 농도의 2배로 계산.
문제 7설탕 vs NaCl 수용액정답 ③
1 M 설탕 수용액에 관한 설명 중 옳지 않은 것은?
① 어는점이 0℃보다 낮다.
② 끓는점이 1 M NaCl 수용액보다 낮다.
③ 어는점이 1 M NaCl 수용액보다 낮다.
④ 100℃에서 증기압이 760 mmHg 보다 낮다.

사고과정

설탕(i=1) vs NaCl(i=2). ①(어는점 내림 있음)·②(설탕 끓는점이 NaCl보다 낮음)·④(증기압 내림)는 옳다.

③ 설탕은 i가 작아 어는점 내림이 작다 → 어는점이 NaCl보다 높다("낮다"는 거짓). → ③

총괄성은 입자 수(i×m)에 비례. NaCl(i=2)이 설탕(i=1)보다 어는점을 더 많이 내린다(설탕 어는점이 더 높음).
문제 8삼투압 분자량 측정 오차정답 ③
삼투압으로 용질 A의 분자량을 측정할 때, 분자량이 크게 측정되는 오차 원인을 모두 고른 것은? (가. h 작게 측정 / 나. 온도 높게 측정 / 다. 용질 질량 크게 측정 / 라. 용액 부피 크게 측정)
① 가, 다
② 나, 다
③ 가, 나, 다
④ 가, 다, 라

사고과정

M = (질량·R·T)/(π·V), π ∝ h이라 M ∝ (질량×T)/(h×V).

M↑: 가(h↓)·나(T↑)·다(질량↑). 라(V↑)는 M을 줄인다. → ③

분자량 공식의 분자·분모를 보고 각 변수가 M을 키우는지 줄이는지 판단. 부피(라)는 분모라 크게 측정하면 M이 작아진다.
문제 9삼투압 · 단백질 몰질량정답 ②
20.0g 단백질이 녹은 1.00L 수용액의 25℃ 삼투압이 0.021 기압이다. 단백질의 몰질량은?
① 120,000 g/mol
② 23,000 g/mol
③ 12,000 g/mol
④ 2,300 g/mol

사고과정

M = (질량·RT)/(πV) = (20.0×0.0821×298)/(0.021×1.00) ≈ 489/0.021 ≈ 23,000 g/mol. → ②

삼투압은 작은 농도도 큰 압력을 내 거대분자(단백질) 몰질량 측정에 유용하다. M = mRT/(πV).
문제 10흡열 과정정답 ④
다음 중 흡열과정은?
① 가솔린의 연소
② 에어컨디션용 냉매의 응축
③ 물이 어는 현상
④ 아이오딘의 승화

문제 11온실효과 기체정답 ①
다음 분자들 중 온실효과(greenhouse effect)를 유발할 수 있는 기체가 아닌 것은?
① H2
② CO
③ H2O
④ CH4

사고과정

온실기체는 적외선을 흡수해야 하고, 그러려면 진동 중 쌍극자 모멘트 변화가 있어야 한다. H2는 등핵 이원자라 쌍극자가 없어 적외선을 흡수하지 못한다. → ①

CO·H2O·CH4는 적외선 활성. 등핵 이원자(H2·N2·O2)는 쌍극자 변화가 없어 온실기체가 아니다.
문제 12열량계 · 중화 온도정답 ③
커피컵 열량계에서 0.862M HCl 200mL와 0.431M Ba(OH)2 200mL를 혼합했다(초기 25℃). 혼합 용액의 최종 온도는? (밀도 1.0 g/mL, 비열 4.18 J/g·℃, 2HCl+Ba(OH)2→2H2O+BaCl2, ΔH°=−112.4 kJ)
① 13.4℃
② 19.2℃
③ 30.8℃
④ 36.6℃

사고과정

HCl 0.172몰, Ba(OH)2 0.0862몰 → 정확히 2:1 양론비. 반응 단위 = 0.0862. Q = 0.0862×112.4kJ = 9690J.

ΔT = 9690/(400×4.18) = 5.8℃ → 최종 = 25 + 5.8 = 30.8℃. → ③

발열 반응이라 온도 상승. ΔH는 반응식 기준(2H2O당 112.4kJ)이라 Ba(OH)2 몰수로 곱한다.
문제 13중화 엔탈피 측정정답 ④
단열 보온병에서 (고체 NaOH 4g + 물 100mL → 3℃ 상승), (고체 NaOH 4g + 1M HCl 100mL → 5℃ 상승). NaOH 1몰 당 중화 엔탈피(J/mol)에 가장 가까운 값은? (물 비열 4.2 J/g·℃, 용액 100g 가정)
① +840
② −840
③ +8400
④ −8400

NaOH 4g = 0.1몰. 용해: 100×4.2×3 = 1260J → 12600J/mol. 용해+중화: 100×4.2×5 = 2100J → 21000J/mol.

중화 = 21000 − 12600 = 8400J/mol(발열) → ΔH = −8400. → ④

고체 NaOH는 녹으면서도 열을 낸다. 중화열만 뽑으려면 (용해+중화) 실험에서 (용해) 실험을 빼야 한다. 발열이라 음수.

1그램 당 발열량에 관련된 다음 중 옳지 않은 것은? (a. CH4>CH3OH / b. CH4>H2 / c. C2H5OH>CH3OH / d. 동면 동물·낙타는 탄수화물 비축)
① a, b
② b, c
③ c, d
④ b, d

문제 15알루미늄 제련 에너지정답 ②

문제 19결합 해리에너지정답 ①
NO 분자 생성에 90kJ/mol이 필요하다(흡열). NO의 결합 해리에너지는? (N2 941, O2 499 kJ/mol)
① 630 kJ/mol
② 675 kJ/mol
③ 765 kJ/mol
④ 810 kJ/mol

사고과정

½N2+½O2→NO, ΔH = (끊은 결합)−(생긴 결합): 90 = [½(941)+½(499)] − D(NO) = 720 − D(NO).

D(NO) = 720 − 90 = 630 kJ/mol. → ①

ΔH = Σ(반응물 결합) − Σ(생성물 결합). N≡N·O=O 반쪽씩 끊고 N=O 하나 만든다.
문제 20광자 에너지 · 결합에너지정답 ③
산소 분자의 결합을 끊기 위해 필요한 파장은 239nm이다. 산소 분자의 결합에너지(kJ/mol)에 가장 가까운 값은?
① 250
② 360
③ 500
④ 600

사고과정

E = hc/λ × NA = (6.6×10⁻³⁴×3×10⁸/239×10⁻⁹) × 6.0×10²³ ≈ 8.3×10⁻¹⁹ × 6.0×10²³ ≈ 5.0×10⁵ J/mol = 500 kJ/mol. → ③

광자 1개 에너지 E=hc/λ에 아보가드로 수를 곱해 1몰 에너지로. 파장이 짧을수록 광자 에너지가 크다.
문제 21연소열 · 수소화 ΔH정답 ①
벤젠 수소화 C6H6(l) + 3H2(g) → C6H12(l)의 반응 엔탈피에 가장 가까운 값은? (연소 엔탈피 C6H6 −3268, C6H12 −3754, H2 −286 kJ/mol)
① −400 kJ/mol
② −200 kJ/mol
③ +200 kJ/mol
④ +400 kJ/mol

사고과정

전환 온도 = ΔH/ΔS = 175.9/0.285 ≈ 618K(345℃). 이보다 높은 400℃(673K)서 비자발적. → ④

ΔH<0·ΔS<0이면 저온서 자발, 고온서 비자발. 전환 온도 T=ΔH/ΔS를 기준으로 갈린다.
문제 43흑연·다이아몬드 안정성정답 ③
C(s, 다이아몬드) → C(s, 흑연), ΔG° = −3.0 kJ/mol. 옳은 것을 모두 고른 것은? (가. 다이아몬드가 열역학적으로 더 안정 / 나. 다이아몬드가 자유에너지 더 큼 / 다. 다이아몬드→흑연은 자발적)
① 가, 나
② 가, 다
③ 나, 다
④ 가, 나, 다

사고과정

ΔG<0이라 다이아몬드→흑연 자발적 → 흑연이 더 안정. 가(다이아몬드 안정)는 거짓.

나(다이아몬드 자유에너지 더 큼)·다(자발적)는 옳다. → ③

ΔG<0인 방향의 생성물(흑연)이 더 안정(자유에너지 낮음). 다이아몬드가 흑연이 되는 건 자발적이지만 속도가 극도로 느리다.
문제 44평형 농도 계산정답 ②
A + B ⇌ 2C의 평형 상수가 144이다. A·B 각각 0.4몰을 용액 2L에 넣어 평형에 도달했을 때 C의 농도에 가장 가까운 값은?
① 0.1 M
② 0.4 M
③ 0.7 M
④ 1.0 M

사고과정

초기 [A]=[B]=0.2M. 평형 [A]=[B]=0.2−x, [C]=2x. K = (2x)²/(0.2−x)² = 144 → √144 = 12.

2x/(0.2−x) = 12 → 14x = 2.4 → x = 0.171. [C] = 2x = 0.34 ≈ 0.4 M. → ②

K가 완전제곱(144=12²)이고 식도 제곱 형태라 양변에 √를 씌우면 1차식으로 간단해진다.
문제 45평형 이동 · HI정답 ④
300K에서 H2(g) + I2(g) ⇌ 2HI(g), K = 9.0. 10.0L 용기에 H2·I2·HI 각 1.0mol을 넣었다. 평형 HI 농도는?
① 0.12 M
② 0.14 M
③ 0.16 M
④ 0.18 M

사고과정

초기 각 0.1M. Q = 0.1²/(0.1×0.1) = 1 < K = 9 → 정반응 진행. [HI]=0.1+2x, [H2]=[I2]=0.1−x.

(0.1+2x)/(0.1−x) = 3 → 5x = 0.2 → x = 0.04. [HI] = 0.1 + 0.08 = 0.18 M. → ④

먼저 Q와 K를 비교해 진행 방향을 정한다. Q<K면 정반응(생성물↑). 제곱근으로 1차식 변환.
문제 46평형식 세우기정답 ①
N2O4 ⇌ 2NO2, Kc = 8. 1L 용기에 2몰 N2O4를 넣어 평형에 도달했을 때 NO2의 몰 수 X를 구하는 올바른 식은?
① 8 = X²/(2 − X/2)
② 8 = X/(2 − X/2)
③ 8 = 4X²/(2 − X)
④ 8 = X²/(2 − X)

사고과정

NO2 X몰 생성 → N2O4 X/2몰 소모 → 평형 N2O4 = 2−X/2. 1L이라 농도=몰수.

Kc = [NO2]²/[N2O4] = X²/(2−X/2) = 8. → ①

계수비 1:2라 NO2 X몰당 N2O4는 X/2몰만 소모된다. 이 X/2를 빼먹는 게 흔한 실수(④가 함정).
문제 47평형식 (전원정답)전원정답
N2(g) + O2(g) ⇌ 2NO(g), Kp = 1×10⁻³¹. 초기 PN₂=0.8, PO₂=0.2 atm일 때 평형 PNO를 구하는 식으로 옳은 것은? (①~④ 보기 생략)

사고과정

엄밀한 식: NO가 PNO만큼 생기면 N2·O2는 각각 PNO/2씩 소모 → Kp = (PNO)²/[(0.8−PNO/2)(0.2−PNO/2)].

보기는 모두 분모에 PNO/2가 아닌 PNO를 써서 양론적으로 불완전. 다만 Kp=10⁻³¹로 극소라 PNO가 무시되어(분모 ≈ 0.8×0.2) 수치 차이가 없으므로 전원정답 처리됨(④ 형태가 가장 근접).

평형이 거의 안 일어나는(K 극소) 경우 소모량이 무시돼 초기 분압을 그대로 쓴다. 양론 계수(1/2)를 엄밀히 반영하면 보기와 어긋나 무효처리.
문제 48Kp · 분압 계산정답 ④
CH4(g) + H2O(g) ⇌ CO(g) + 3H2(g), Kp = 2.0. 평형에서 H2·H2O·CH4의 분압이 각각 0.20 atm이면 CO의 분압은?
① 0.20 atm
② 1.0 atm
③ 2.0 atm
④ 10 atm

사고과정

Kp = (PCO·PH₂³)/(PCH₄·PH₂O) = (PCO×0.008)/(0.04) = 0.2·PCO = 2.0.

PCO = 2.0/0.2 = 10 atm. → ④

H2는 계수 3이라 분압을 세제곱(0.20³=0.008)해야 한다. 계수를 지수로 빠뜨리지 말 것.
문제 49평형상수 조합정답 ④
(1) Ca(OH)2(s) ⇌ Ca²⁺ + 2OH⁻, K1 = 6.5×10⁻⁶. (2) Ca(OH)2(s) + 2H⁺ ⇌ Ca²⁺ + 2H2O의 평형 상수 K2에 가장 가까운 값은? (Kw = 10⁻¹⁴)
① 1×10⁻⁸
② 1×10²
③ 1×10¹²
④ 1×10²²

사고과정

(2) = (1) + 2×(H⁺ + OH⁻ → H2O, K=1/Kw). K2 = K1 × (1/Kw)² = 6.5×10⁻⁶ × 10²⁸ = 6.5×10²² ≈ 1×10²². → ④

반응식을 더하면 K는 곱한다. 산을 넣어 OH⁻를 물로 만들면 (1/Kw)²=10²⁸배 커져 용해도가 폭증한다.
문제 50반트호프 · ΔS° 구하기정답 ④
평형상수 K를 온도에 따라 측정해 ln K vs 1/T 직선(y절편 ≈ 6.0)을 얻었다. 표준 반응 엔트로피 ΔS°(J/K·mol)에 가장 가까운 값은? (ΔH°·ΔS° 일정 가정)
① 0.20
② 6.0
③ 30
④ 50

사고과정

반트호프: ln K = −ΔH°/R·(1/T) + ΔS°/R. y절편 = ΔS°/R. 절편 6.0 → ΔS° = 6.0 × 8.314 ≈ 50 J/K·mol. → ④

ln K-1/T 그래프: 기울기 = −ΔH°/R(엔탈피), y절편 = ΔS°/R(엔트로피). 절편을 읽어 R을 곱한다.
문제 51반응지수 Q · 평형상수 K정답 ②
반응지수(Q)와 평형상수(K)에 관한 내용 중 옳지 않은 것은?
① Q=K인 상태는 평형 상태이다.
② Q>K일 때, 정반응이 우세하게 일어난다.
③ 반응 초기에 반응물만 존재할 때 Q 값은 0이다.
④ 높은 온도일수록 Q값이 K값과 같아지는 데 걸리는 시간이 줄어든다.

사고과정

①(Q=K=평형)·③(생성물 0이면 Q=0)·④(고온→빠른 평형 도달)는 옳다.

② Q>K면 생성물이 과해 역반응이 우세(정반응 아님). → ②

Q<K면 정반응, Q>K면 역반응으로 진행해 Q를 K에 맞춘다. 부등호 방향이 진행 방향을 결정한다.
문제 52기화 평형상수 · 온도정답 ②
물의 기화 H2O(l) ⇌ H2O(g)의 평형 상수 K의 온도 의존도를 올바르게 그린 것은? (A 일정 / B 증가 / C 감소 / D U자형)
① A
② B
③ C
④ D

사고과정

기화는 흡열(ΔH>0). 흡열 반응은 온도↑면 평형이 정방향으로 이동 → K 증가. → ②

흡열 반응의 K는 온도와 함께 증가(반트호프). 온도가 오르면 증기압(=기화 K)이 커지는 것과 같은 이치.
문제 53Q-K 진행 방향정답 ②
440℃에서 H2+I2⇌2HI 평형 그래프(평형 [HI]≈4, [H2]≈[I2]≈2). 동일 조건에서 H2 1몰, I2 1몰, HI 4몰을 넣었을 때 진행 방향은?
① 정반응
② 역반응
③ 평형
④ 알 수 없다

사고과정

그래프 평형값으로 K = [HI]²/([H2][I2]) = 16/(2×2) = 4. 새 조건 Q = 16/(1×1) = 16.

Q(16) > K(4) → 역반응. → ②

먼저 그래프에서 K를 읽고, 새 조건의 Q와 비교한다. Q>K면 생성물 과잉이라 역반응.
문제 54해리 평형 분석정답 ④
1000℃에서 P4(g) ⇌ 2P2(g), K = 0.5. P4를 빈 용기에 넣어 평형에 이르렀을 때 압력이 6기압이다. 옳지 않은 것은?
① 반응 초기 P4의 압력은 6기압보다 작았다.
② 평형에서 P4의 부분 압력은 4.5기압이다.
③ 평형에서 P4의 14.3%가 분해되었다.
④ 반응 용기의 부피가 감소하면 더 많은 P2(g)가 만들어진다.

사고과정

P4 분해량 y: 4y²/(6−2y) = 0.5 → y = 0.75. 초기 P4 = 5.25기압, 평형 P4 = 4.5, P2 = 1.5. 분해율 0.75/5.25 = 14.3%. ①②③ 옳음.

④ 부피 감소(압력↑)면 기체 적은 P4쪽(1몰)으로 이동 → P2 감소. → ④

P4⇌2P2는 1→2몰이라 압축하면 역방향(P4). 분해율↓. 르샤틀리에로 기체 몰수 적은 쪽으로 간다.
문제 55평형 이동(가열·압축)정답 ①
3A(g) + 2B(s) ⇌ 2C(g) + 4D(s), ΔH° = +38.5 kJ/mol. (a) 일정부피 가열, (b) 일정온도 부피 감소 시 평형 이동 방향은?
(a)(b)
①오른쪽오른쪽
②오른쪽왼쪽
③왼쪽오른쪽
④왼쪽왼쪽

사고과정

(a) 흡열(ΔH>0) 가열 → 정방향(오른쪽). (b) B·D는 고체라 무관, 기체는 3A→2C. 부피↓(압력↑)면 기체 적은 생성물(C)쪽(오른쪽). → ①

고체(B·D)는 압력 효과에서 빼고 기체 몰수만 비교(3 vs 2). 흡열은 가열하면 정방향, 압축은 기체 적은 쪽으로.
문제 56Q-K 진행 방향(2)정답 ①
2A ⇌ 2B + C, K(300K)=1.6×10⁴. 300K에서 A 0.0010몰, B 5.0몰, C 0.10몰을 포함하는 1L 용액의 진행 방향은?
① 역반응
② 정반응
③ 평형
④ 정지됨

사고과정

Q = [B]²[C]/[A]² = (5.0)²(0.10)/(0.0010)² = 2.5/10⁻⁶ = 2.5×10⁶.

Q(2.5×10⁶) > K(1.6×10⁴) → 역반응. → ①

생성물(B·C) 농도가 높고 반응물(A)이 극소라 Q가 K를 훌쩍 넘는다 → 역반응으로 A를 만든다.

문제 60착물 형성 평형 (전원정답)전원정답
Ag⁺ + 2NH3 ⇌ Ag(NH3)2⁺, Kf = 1.7×10⁷. 은 이온의 99%를 Ag(NH3)2⁺로 바꾸는 데 필요한 암모니아 농도에 가장 가까운 것은? (①~④ 보기 생략)

사고과정

99% 착물화: [착물]/[Ag⁺] = 99 = Kf·[NH3]². [NH3]² = 99/(1.7×10⁷) = 5.8×10⁻⁶ → [NH3] ≈ 2.4×10⁻³ M(①에 근접).

단 "필요한 농도"가 평형 자유 NH3인지, 착물에 소모된 2NH3까지 포함한 총 첨가량(미지의 [Ag⁺]에 의존)인지 모호해 전원정답 처리됨.

평형 자유 농도와 총 투입량을 구분해야 한다. 착물 1몰당 NH3 2몰이 소모되므로, 총량은 초기 Ag⁺ 농도가 있어야 정해진다.
