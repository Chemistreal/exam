난이도 중 다음은 암모니아 합성에 대한 하버-보슈법이다.

1) 평형상수(Kp)의 정의: N2(g) + 3H2(g) ⇌ 2NH3(g) 에서 Kp = P(NH3)2 / (P(N2) × P(H2)3) 생성물 압력을 분자에, 반응물 압력을 분모에 두고 각각 계수만큼 거듭제곱합니다.

2) 반응 지수(Q): 평형상수와 똑같은 꼴의 식에 "지금 이 순간"의 압력을 그대로 대입한 값입니다.

Q는 언제든 계산할 수 있고, K는 평형에 도달했을 때의 Q 값입니다.

3) 판정 규칙 Q < K ⇒ 생성물이 아직 모자란 상태 ⇒ 정반응(오른쪽)으로 진행 Q = K ⇒ 평형상태 ⇒ 겉보기 변화 없음 Q > K ⇒ 생성물이 넘치는 상태 ⇒ 역반응(왼쪽)으로 진행 4) 돌턴의 부분압력 법칙: P(성분) = 몰분율 × 전체압력.

전체압력이 1기압이면 부분압력의 수치는 몰분율의 수치와 같아집니다.

5) K는 온도의함수입니다.

이 반응은 발열이므로 온도가 높아지면 K가 급격히 작아집니다.

반드시 문제에 지정된 온도의 K와 비교해야 합니다.

6) 평형은 "멈춤"이 아닙니다.

n(전체) = 0.1 + 0.3 + 0.01 = 0.41 mol 단계 2) 몰분율을 구합니다.

χ(N2) = 0.1 / 0.41 = 0.244 χ(H2) = 0.3 / 0.41 = 0.732 χ(NH3) = 0.01 / 0.41 = 0.0244 단계 3) 전체압력이 1기압이므로 부분압력은 몰분율과 같은 수치입니다.

P(N2) = 0.244 atm, P(H2) = 0.732 atm, P(NH3) = 0.0244 atm 단계 4) 반응 지수 Q를 계산합니다.

Q = P(NH3)2 / (P(N2) × P(H2)3) = (0.0244)2 / (0.244 × 0.7323) = (5.95×10−4) / (0.244 × 0.392) = (5.95×10−4) / (9.56×10−2) = 6.23×10−3 22 단계 5) 600 °C에서의 Kp와 비교합니다.

Q = 6.23×10−3 , Kp = 2.25×10−6 ⇒ Q > Kp (약 2800배) 단계 6) Q > K 이므로 Q가 작아지는 방향, 즉 NH3가 분해되는 역반응 쪽으로 반응이 진행됩니다.

① 정반응 ⇒ 틀림.

정반응이 일어나려면 NH3가 부족해 Q < K여야 합니다.

여기서는 Q가 Kp보다 세 자릿수나 큽니다.

300 °C의 Kp(4.34×10−3)와 착각해도 Q가 여전히 더 크므로 정반응이 될 수 없습니다.

② 역반응 ⇒ 옳음.Q(6.23×10−3)가 Kp(2.25×10−6)보다 훨씬 크므로 NH3가 과잉이며, 분해되는 쪽으로 진행됩니다.

③ 평형 ⇒ 틀림.

평형이려면 Q = Kp여야 하는데 두 값의 차이가 약 2800배입니다.

④ 정지됨 ⇒ 틀림.

화학 평형은 정반응과 역반응이 같은 속도로 계속 일어나는 동적 평형이므로 반응이 "정지"하는 상태 자체가 존재하지 않습니다.

② Q = 6.23×10−3 > Kp = 2.25×10−6 이므로 역반응 쪽으로 진행됩니다.
