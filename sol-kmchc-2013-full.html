문제 1반데르발스상수정답 ①

사고과정

b는 분자 자체 부피(배제 부피)에 해당 → 분자가 작을수록 b가 작다. 단원자 Ne이 가장 작고, 이원자(특히 Cl2)는 크다. → ①

반데르 발스 b는 입자 크기(배제 부피), a는 분자 간 인력. 작은 단원자 기체가 b도 작다.
문제 2분자의구조정답 ④

사고과정

넷 다 중심 원자 결합 3+고립쌍 1 → 삼각뿔(옳음). NH3(쌍극자가 N쪽)·NF3(F가 더 전기음성→반대쪽)는 극성 방향 반대(옳음).

∠H-N-H(~107°)>∠H-P-H(~94°)(옳음). NH3는 수소결합으로 PH3보다 물에 잘 녹음(옳음). 모두 옳아 4개. → ④

치환기 전기음성도가 중심보다 크면(NF3) 결합 쌍극자가 고립쌍과 반대로 작용해 극성 방향이 뒤집힌다.
문제 3PV=nRT정답 ①

사고과정

압력·몰수 일정 → V/T 일정(샤를). T2 = 298×(30/40) = 223.5 K = −49.5°C ≈ −50°C. → ①

정압에서 부피와 절대온도는 비례. 질량(1kg)은 몰수가 일정해 계산에 불필요한 정보.
문제 4결합에너지정답 ②

사고과정

C3H8+5O2→3CO2+4H2O. 반응물 결합 = 2(356)+8(416)+5(498) = 6530. 생성물 = 6(803)+8(467) = 8554.

차이 = 8554 − 6530 = 2024 kJ. → ②

결합 수를 정확히 셈(C3H8: C-C 2개·C-H 8개 / CO2: C=O 2개 / H2O: O-H 2개). ΔH = 반응물 − 생성물 = −2024(발열).
문제 5이온반지름정답 ③

사고과정

넷 다 Kr 과 같은 전자 수(36개)를 가진 등전자 이온이다.

전자 수가 같으면 양성자가 많을수록 전자를 세게 당겨 반지름이 작아진다.

Br(35) > Se(34) 이므로 Br⁻ < Se²⁻ 이고, Sr(38) > Rb(37) 이므로 Sr²⁺ < Rb⁺ 다.

→ ③

문제 6분자의모양정답 ①

사고과정

화학종마다 중심 원자의 전자 영역을 세어 구조를 정한다.

BrF₃ 는 결합 3 + 고립쌍 2 로 T자형, ClO₄⁻ 는 결합 4 로 정사면체, ICl₄⁻ 는 결합 4 + 고립쌍 2 로 평면사각형, SF₄ 는 결합 4 + 고립쌍 1 로 시소형, I₃⁻ 는 결합 2 + 고립쌍 3 으로 직선형, IF₄⁺ 는 결합 4 + 고립쌍 1 로 시소형이다.

같은 구조가 둘인 것은 시소형뿐이다.

→ ①

문제 7완충용액정답 ①

사고과정

1:1 혼합 = pH = pKa인 완충. pH 최고 = 가장 약한 산(pKa 최대). 하이포할로산 세기 HClO>HBrO>HIO(전기음성도), HClO2(산소↑)가 가장 강. HIO가 가장 약. → ①

중심 원자 전기음성도가 작거나 산소가 적을수록 약산 → 짝염기가 강해 완충 pH가 높다.
문제 8순물질정답 ②

사고과정

순물질은 한 종류의 분자(또는 원소)만 존재. I·II는 모든 분자가 동일(단일 화학종) → 순물질. III·IV는 서로 다른 분자가 섞임 → 혼합물. → ②

순물질=한 종류 입자, 혼합물=두 종류 이상 섞임. 같은 분자만 그려져 있으면 순물질이다.
문제 9몰과양적관계정답 ②

사고과정

2NH3 + 3CuO → N2 + 3H2O + 3Cu. NH3 1.0몰·CuO 1.0몰. CuO가 한계(1.0몰 NH3엔 1.5몰 CuO 필요).

N2 = (1/3)×1.0 = 0.333몰 → 0.333×28 = 9.3g ≈ 10g. → ②

한계 반응물(CuO) 기준으로 생성물 계산. 3CuO당 N2 1개 생성된다.
문제 10압력정답 ③

사고과정

열린쪽 수은이 더 높음 → 기체 압력 > 대기압. 19 cmHg = 190/760 = 0.25 기압. P기체 = 1.0 + 0.25 = 1.25 기압. → ③

열린관 압력계: 열린쪽이 높으면 P기체=P대기+h, 낮으면 −h. cmHg를 기압으로 환산(76 cmHg=1기압).
문제 11화학반응정답 ④

사고과정

2SO2+O2→2SO3: 기체 반응(부피비 2:1:2 정수), 배수 비례(SO2·SO3 산소비), 일정 성분비(각 화합물 고정 조성), 질량 보존(원자 균형). 모두 설명 → 4개. → ④

균형 잡힌 기체 반응식 하나로 여러 화학 법칙을 동시에 예시할 수 있다.
문제 12결정수정답 ③

사고과정

CuSO4·5H2O 몰질량 ≈ 250 g/mol. 5g = 0.02몰 → 결정수 = 5×0.02 = 0.1몰.

V = nRT/P = 0.1×0.082×573/1 ≈ 4.7 L ≈ 5 L. → ③

수화물 몰수에 결정수 계수(5)를 곱해 물 몰수를 구한 뒤 이상 기체 식으로 부피 환산(T=573 K).
문제 13완충용액정답 ④

사고과정

④ 완충용량은 pH=pKa서 최대인 건 맞으나 산·짝염기의 농도(양)가 클수록 커진다(무관 아님). 틀림. → ④

①·②(NH3/NH4+ 완충)·③(아세트산/아세테이트 완충)은 옳음.

완충용량은 두 인자에 의존: pH가 pKa에 가까울수록·전체 농도가 클수록 크다.
문제 14분자오비탈정답 ①

사고과정

결합 길이는 결합 차수가 클수록 짧다.

분자 오비탈로 결합 차수를 세면 O₂⁺ 2.5, O₂ 2.0, O₂⁻ 1.5, O₂²⁻ 1.0 이다.

전자를 더할수록 반결합성 오비탈이 채워져 차수가 준다.

→ ①

문제 15쌍극자간인력정답 ②

사고과정

쌍극자-쌍극자는 극성 분자에 작용. AsH3는 삼각뿔(극성). XeF4(평면 사각)·BCl3(평면 삼각)·CO2(직선)는 대칭 무극성. → ②

대칭 구조는 결합 쌍극자가 상쇄돼 무극성. 고립쌍으로 비대칭인 분자(AsH3)만 영구 쌍극자를 가진다.
문제 16에너지준위정답 ②

사고과정

He⁺는 전자 1개(수소 유사) → 에너지가 주양자수 n에만 의존(같은 n 축퇴). 1s<(2s=2p)<(3s=3p=3d)<(4s=4p=4d=4f)<5s. → ②

다전자 원자는 차폐로 같은 n에서 s<p<d로 갈라지나, 1전자계는 갈라짐 없이 n만으로 결정된다.
문제 17반응의자발성정답 ④

사고과정

ΔH = −314.4−(−46.19−92.30) = −175.9 kJ. ΔS = 94.6−(192.5+186.69) = −284.6 J/K(둘 다 음수).

비자발(ΔG>0): T > ΔH/ΔS = 175900/284.6 = 618 K = 345°C. 400°C(673K)서 비자발. → ④

ΔH<0·ΔS<0이면 저온 자발·고온 비자발. 전환 온도 T=ΔH/ΔS(단위 일치)를 기준으로 판단한다.
문제 18전자배치정답 ③

사고과정

바닥 산소는 1s²2s²2p⁴(2p가 ↑↓ ↑ ↑, 훈트). 가장 안정한 들뜬 상태는 3s 승위 없이 n=2에 머물며 2p⁴를 (↑↓ ↑↓ _)로 짝지은 상태(③). → ③

상위 껍질(3s) 승위는 에너지가 크게 든다. 같은 부껍질 내 훈트 규칙 위반(짝지음)이 가장 낮은 들뜬 상태.
문제 19산과염기정답 ③

사고과정

양성자 이동: K = Ka(HA)/Ka(HB). pKa(HA)<pKa(HB) → HA가 더 강한 산(Ka(HA)>Ka(HB)) → K>1(정반응 우세). → ③

강한 산이 양성자를 더 약한 산의 짝염기에 넘긴다. K=Ka(주는 산)/Ka(받는 산의 짝산).
문제 20어는점내림정답 ③

사고과정

ΔTf ∝ i·m. ① 0. ② 1×0.60 = 0.60. ③ 2×0.50 = 1.0. ④ 4×0.245 = 0.98. 최대 i·m은 KF(1.0) → 어는점 최저. → ③

총괄성은 입자 수에 비례. 전해질은 반트호프 인자 i(KF는 2, FeI3는 4)를 곱해 유효 농도를 비교한다.
문제 21산화수정답 ④

사고과정

④ 산화수 변화: 1단계 N −3→+2(Δ5), 2단계 +2→+4(Δ2), 3단계 +4→+5·+2. 최대는 1단계(2단계 아님). 틀림. → ④

①(HNO3 N=+5 최대)·②(3단계는 불균등화 포함 모두 산화환원)·③(NO 11e⁻·NO2 17e⁻ 홀전자)은 옳음.

각 단계 N 산화수 변화를 추적: 암모니아 산화(1단계)가 −3→+2로 가장 크다.
문제 22평형상수정답 ③

사고과정

K = [트랜스]/[시스] = x/(2.0−x) = 1.5 → x = 3.0−1.5x → 2.5x = 3.0 → x = 1.2 mmol/L. → ③

이성질화는 1:1이라 총 농도 보존(시스+트랜스=2.0). K식에 대입해 평형 농도를 푼다.
문제 23이온결합정답 ③

③ 산성서 F⁻+H⁺→HF로 F⁻가 제거돼 용해도가 증가(르샤틀리에) → pH 의존. 틀림. → ③

①(등전자라 양성자 많은 Na⁺가 작음)·②(F⁻ 가수분해로 약염기성)·④(암염 구조라 둘 다 배위수 6)은 옳음.

약산의 짝염기를 가진 염은 산성 용액에서 용해도가 커진다(짝염기가 H⁺와 반응해 빠져나감).
문제 24몰랄농도정답 ③

사고과정

용액 100g 기준: NaCl 13.0g, 물 87.0g. 몰 = 13.0/58.5 = 0.222. 몰랄 = 0.222/0.087 = 2.55 m. → ③

몰랄농도 = 용질 몰수/용매 kg. 질량 분율만 있으면 밀도는 불필요(용액 100g 가정).
문제 25크로마토그래피정답 ①

사고과정

종이(셀룰로스)는 극성 고정상. 전개용매가 더 극성이 되면 이동성↑ → 모든 점이 위로 이동하되 상대 순서(A>B>C)는 유지. → ①

극성 용매는 Rf를 전반적으로 높인다. 순서가 바뀌려면 성분별 친화도 역전이 필요한데 여기선 전체적 상승만 일어난다.
문제 26비공유전자쌍정답 ④

사고과정

Xe 고립쌍: XeOF2(2)·XeO3(1)·XeF4(2)·XeF2(3). XeF2(직선, AX2E3)가 고립쌍 3개로 최다. → ④

중심 원자 전자쌍 = (원자가 전자 − 결합 사용)/2. 결합이 적을수록(XeF2) 남는 고립쌍이 많다.
문제 27지시약정답 ④

사고과정

pH = pKa + log([In⁻]/[HIn]) → 7.9 = 8.9 + log비 → log([In⁻]/[HIn]) = −1 → [In⁻]/[HIn] = 1/10 → [HIn]:[In⁻] = 10:1. → ④

pH가 pKa보다 1 낮으면 산형(HIn)이 염기형(In⁻)의 10배. 1 단위마다 비가 10배씩 바뀐다.
문제 28열량정답 ②

사고과정

열량 ∝ Fe2O3 생성량. ① 1.0몰. ② Fe 10g(0.179몰) 한계 → 0.089몰. ③ Fe 20g(0.357몰) 한계 → 0.179몰. ④ Fe 2몰 → 1.0몰. 최소는 ②. → ②

한계 반응물로 생성물 양을 정하고, 반응열은 생성물 몰수에 비례. Fe가 적은 ②가 가장 적게 생성한다.
