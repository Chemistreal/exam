헤스 법칙

067 · 열화학읽는 데 약 9분
‹ 파이널로
이번 진단에서 헤스 법칙이 보강으로 잡혔어. 이 1강을 끝까지 읽고 직접 해보기까지. "반응 엔탈피는 경로와 무관, 처음과 끝으로만 정해진다"가 핵심이고, 아는 반응들을 조합해 ΔH를 구하는 게 쓸모야.

자, 어떤 반응은 ΔH를 직접 측정하기 어려워. 예를 들어 탄소가 일산화탄소로만 타는 반응은, 실제로는 이산화탄소까지 가버려서 따로 재기 힘들거든. 이럴 때 구원투수가 헤스 법칙이야. 반응 엔탈피가 "어떤 경로로 갔느냐"와 무관하게, 오직 처음(반응물)과 끝(생성물) 상태로만 정해진다는 거지. 그래서 측정하기 쉬운 반응들을 레고처럼 조합해서, 원하는 반응의 ΔH를 계산할 수 있어. 오늘은 이 법칙과 반응식 조합 규칙을 잡을 거야.

01헤스 법칙 · 경로와 무관하다

헤스 법칙은 이거야. 반응 엔탈피는 반응 경로와 무관하게, 처음과 끝 상태로만 정해진다. 한 단계로 곧장 가든, 여러 단계를 거쳐 빙 둘러 가든, 시작과 끝이 같으면 총 ΔH가 같아.

이게 가능한 건 엔탈피가 상태 함수이기 때문이야. 산을 오를 때 어느 길로 가든 정상의 높이가 같듯, 처음과 끝의 엔탈피 차이는 경로와 상관없이 일정해. 중간에 어떤 길을 거쳤는지는 ΔH에 영향을 주지 않아.

직접 경로의 ΔH = 거쳐 가는 경로의 ΔH 합
02반응식 조합 규칙 · 두 가지

헤스 법칙을 쓰려면 아는 반응식들을 조합해 목표 반응식을 만들어. 이때 두 가지 규칙을 기억해.

규칙 ① 뒤집으면 부호 반대. 반응식을 역방향으로 뒤집으면 ΔH의 부호가 반대가 돼(065). 발열이 흡열이 되는 거지. 규칙 ② 배수를 곱하면 ΔH도 같은 배수. 반응식 전체에 2를 곱하면 ΔH도 2배가 돼(ΔH는 양에 비례).

조합 규칙: ① 반응식 뒤집기 → ΔH 부호 반대 ② 반응식 × n → ΔH × n. 아는 반응식들을 이 규칙으로 조작해 목표 반응식이 되도록 더하면, ΔH들도 똑같이 조작해 더한 게 답이야. 반응식을 다루는 대로 ΔH도 똑같이 다루는 거지.
03계산 예제 · CO의 생성 엔탈피

직접 재기 어려운 C + ½O₂ → CO의 ΔH를, 측정하기 쉬운 두 반응으로 구해보자.

(가) C(s) + O₂(g) → CO₂(g)   ΔH₁ = −394 kJ
(나) CO(g) + ½O₂(g) → CO₂(g)   ΔH₂ = −283 kJ
구할 것: C(s) + ½O₂(g) → CO(g)   ΔH = ?

목표 반응식을 만들려면, (가)는 그대로 두고 (나)는 뒤집어(부호 반대) 더해. (나)를 뒤집으면 CO₂ → CO + ½O₂, ΔH = +283 kJ. 이제 (가) + 뒤집은 (나)를 하면, 양변의 CO₂가 소거되고 목표 반응식이 남아.

ΔH = ΔH₁ − ΔH₂ = (−394) − (−283) = −111 kJ

그래서 C + ½O₂ → CO의 ΔH는 −111 kJ(발열)이야. 직접 못 재는 반응을, 아는 두 반응을 조합(하나는 뒤집어서)해 구한 거지. 반응식을 조작한 그대로 ΔH도 조작(빼기)한 게 핵심이야.

04함정 정리
함정 · 반응식만 조작하고 ΔH는 그대로?
반응식을 뒤집거나 배수를 곱하면, ΔH도 똑같이 조작해야 해. 뒤집었으면 ΔH 부호도 바꾸고, 2배 했으면 ΔH도 2배 해. 반응식만 맞추고 ΔH 값을 그대로 쓰면 틀려. "반응식에 한 일을 ΔH에도 똑같이"가 철칙이야. 그리고 중간 물질(예제의 CO₂)이 양변에서 깔끔히 소거되는지 확인하면, 조합이 맞았는지 검산할 수 있어.
예제 · 두 식을 더해 세 번째를 만들기 구하고 싶은 것: C(s) + ½O₂ → CO 의 ΔH. 직접 재기 어려운 반응이야(CO 에서 멈추질 않으니까). 아는 것 둘: (가) C + O₂ → CO₂ ΔH = −394 kJ, (나) CO + ½O₂ → CO₂ ΔH = −283 kJ. ① (나)를 뒤집는다 → CO₂ → CO + ½O₂, ΔH = +283(뒤집으면 부호도 뒤집힌다). ② (가) + 뒤집은 (나) 를 더하면 CO₂ 가 양쪽에서 지워지고 C + ½O₂ → CO 가 남아. ③ ΔH = −394 + 283 = −111 kJ. 엔탈피는 길이 아니라 처음과 끝만 본다 — 그래서 못 재는 반응도 아는 반응 둘로 만들 수 있어.
05한 장 정리와 다음 연결

오늘 들고 갈 한 문장.

"ΔH는 경로와 무관(처음·끝으로만) · 반응식을 조작한 그대로 ΔH도 조작해 더한다."

헤스 법칙은 반응 엔탈피가 경로와 무관하게 처음·끝 상태로만 정해진다는 거야(상태 함수). 직접 못 재는 ΔH는, 아는 반응식들을 뒤집고(부호 반대) 배수 곱해(같은 배수) 조합해 구해. CO 생성은 −111 kJ처럼.

다음 강(068 표준 생성 엔탈피)에서는 헤스 법칙을 가장 깔끔하게 쓰는 방법을 배워. 모든 물질을 "원소에서 만드는 에너지(생성 엔탈피)"로 정리해 두면, 어떤 반응이든 ΔH = 생성물 − 반응물 한 줄로 계산되거든. 오늘의 헤스 법칙이 그 바탕이야. 반응식 조합 규칙을 들고, 생성 엔탈피로 넘어가자.

✓확인 문제

방금 배운 것으로 풀 수 있는 3문항입니다. 답을 고르면 해설이 열립니다 — 먼저 스스로 고르고 나서 보세요.

1. 25 °C에서 다음 세 반응의 엔탈피 변화가 주어졌다.
(가) C(흑연) + O₂(g) → CO₂(g), ΔH = −393.5 kJ
(나) H₂(g) + ½O₂(g) → H₂O(l), ΔH = −285.8 kJ
(다) C₂H₆(g) + 7/2 O₂(g) → 2CO₂(g) + 3H₂O(l), ΔH = −1560.7 kJ
헤스 법칙을 이용하여 구한 C₂H₆(g)의 표준 생성 엔탈피는?
정답 ①

구하려는 반응은 2C(흑연) + 3H₂(g) → C₂H₆(g)이다. (가)×2 + (나)×3 − (다)를 하면 좌변·우변의 O₂와 CO₂, H₂O가 모두 상쇄되고 목표 반응이 남는다. ΔH = 2(−393.5) + 3(−285.8) − (−1560.7) = −787.0 − 857.4 + 1560.7 = −83.7 kJ/mol. 문헌값 −84 kJ/mol과 일치한다.

자주 걸리는 자리 역방향으로 쓰는 반응 (다)의 부호를 바꾸지 않거나, 계수 2와 3을 ΔH에 곱하지 않는 것.
2. 25 °C, 1 bar에서 다음 두 반응의 엔탈피 변화가 주어져 있다.

(가) N₂(g) + O₂(g) → 2NO(g) ΔH = +180.6 kJ
(나) 2NO(g) + O₂(g) → 2NO₂(g) ΔH = −114.0 kJ

같은 조건에서 NO₂(g)의 표준 생성 엔탈피 ΔH_f는? (표준 생성 엔탈피는 가장 안정한 홑원소 물질로부터 그 물질 1 mol이 생성될 때의 엔탈피 변화이다.)
정답 ②

생성 반응은 ½N₂(g) + O₂(g) → NO₂(g)이다. (가)와 (나)를 그대로 더하면 NO(g)가 소거된다. N₂(g) + 2O₂(g) → 2NO₂(g), ΔH = (+180.6) + (−114.0) = +66.6 kJ. 이 값은 NO₂ 2 mol이 생성될 때의 값이므로, 전체 식을 2로 나누면 ½N₂(g) + O₂(g) → NO₂(g), ΔH_f = +66.6 ÷ 2 = +33.3 kJ/mol.

자주 걸리는 자리 헤스 법칙으로 얻은 ΔH는 조합한 반응식 그대로의 값이므로, 생성 엔탈피를 구하려면 반드시 목표 물질 1 mol 기준으로 계수를 나눈 뒤 ΔH도 같은 배수로 나누어야 한다.
3. 두 반응 ΔH₁ = −100, ΔH₂ = −250 kJ 을 써서 (반응2 − 반응1) 의 ΔH 를 구하면?
정답 ②

−250 − (−100) = −150 kJ 이다. → ②

자주 걸리는 자리 빼야 할 자리에서 더한다. 방향을 뒤집으면 부호도 뒤집힌다.
