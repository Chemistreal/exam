N₂⁺와 N₂⁻ 모두 상자성이다.

나.

B₂는 상자성이고, B₂²⁻는 반자성이다.

다.

결합 차수는 O₂⁻가 O₂보다 크다.

라.

질소 원자 사이의 결합 길이는 N₂⁺보다 N₂가 더 길다.

① 가, 나 ② 가, 다 ③ 나, 라 ④ 다, 라 ■ 무엇을 묻는 문제인가 동핵 이원자 분자의 분자 오비탈(MO) 도표를 세워 전자를 채우고, 그로부터 결합 차수·자기적 성질·결합 길이를 모두 읽어낼 수 있는지 묻는 종합형 문제입니다.

특히 O₂ 전후에서 MO 순서가 달라진다는 점이 핵심입니다.

2주기 동핵 이원자 분자의 원자가 MO 순서는 두 가지입니다.

(i) B₂, C₂, N₂ (Z ≤ 7): σ2s < σ*2s < π2p(2개, 축퇴) < σ2p < π*2p < σ*2p.

s-p 혼합이 커서 π2p가 σ2p보다 낮습니다.

(ii) O₂, F₂, Ne₂ (Z ≥ 8): σ2s < σ*2s < σ2p < π2p < π*2p < σ*2p.

s-p 혼합이 작아져 σ2p가 π2p보다 낮습니다.

결합 차수 = (결합성 전자 수 - 반결합성 전자 수) / 2 이고, 결합 차수가 클수록 결합이 짧고 강합니다.

자기적 성질은 홀전자 유무로 판단합니다.

홀전자가 하나라도 있으면 상자성, 모든 전자가 짝지어져 있으면 반자성입니다.

원자가 전자 수: B 3개, N 5개, O 6개이므로 B₂ 6개, N₂ 10개, O₂ 12개입니다.

단계 1) 가 판정.

N₂(10개)는 σ2s² σ*2s² π2p⁴ σ2p² 로 홀전자가 없어 반자성이고 결합 차수는 3입니다.

N₂⁺(9개)는 가장 높은 σ2p에서 전자 하나가 빠져 σ2p¹ ⇒ 홀전자 1개, 상자성.

N₂⁻(11개)는 다음 빈 오비탈인 π*2p에 전자가 하나 들어가 π*2p¹ ⇒ 홀전자 1개, 상자성.

둘 다 상자성이므로 옳음.

단계 2) 나 판정.

B₂(6개)는 (i) 순서로 σ2s² σ*2s² π2p² 이고, 훈트 규칙에 따라 축퇴된 π2p 두 칸에 전자가 하나씩 들어가 홀전자 2개 ⇒ 상자성.

B₂²⁻(8개)는 π2p⁴ 로 완전히 채워져 홀전자가 없으므로 ⇒ 반자성.

1) 총괄성은 용질의 종류가 아니라 "용질 입자의 수"에만 의존하는 성질입니다.

끓는점 오름, 어는점 내림, 증기압 내림, 삼투압이 여기에 속합니다.

2) 끓는점 오름 공식은 ΔTb = Kb × m × i 입니다.

ΔTb = (용액의 끓는점) - (순수한 용매의 끓는점) Kb = 몰랄 오름 상수 (용매마다 정해진 값, 물은 0.52 °C/m) m = 몰랄농도 = 용질의 몰수 / 용매의 질량(kg) i = 반트호프 인자 = 실제 용액 속 용질 입자 수 / 녹인 화학식 단위 수 3) 비전해질(설탕, 요소 등)은 물에 녹아도 분자 그대로 있으므로 i = 1 입니다.

4) 전해질이 완전히 해리하면 i는 생성되는 이온의 총 개수와 같습니다.

MXn → M^n+ + nX⁻ 이므로 완전 해리 시 i = 1 + n 입니다.

5) 해리도가 α인 경우(0 ≤ α ≤ 1) 반트호프 인자는 i = 1 + (ν - 1)α (ν = 완전 해리 시 생기는 이온의 총 개수) 로 계산합니다.

유도는 간단합니다.

처음 1 mol 중 α mol이 해리하면 남은 것은 (1 - α) mol이고 생긴 이온은 να mol이므로 총 입자 수는 (1 - α) + να = 1 + (ν - 1)α 입니다.

6) 몰질량: 설탕 C₁₂H₂₂O₁₁ = 12×12 + 1×22 + 16×11 = 144 + 22 + 176 = 342 g/mol 입니다.

단계 1) 설탕 용액으로 Kb를 구합니다.

설탕의 몰수 = 171 g ÷ 342 g/mol = 0.5 mol 용매 질량 = 500 g = 0.5 kg 몰랄농도 m = 0.5 mol ÷ 0.5 kg = 1.0 m 설탕은 비전해질이므로 i = 1 ΔTb = 100.52 - 100 = 0.52 °C 0.52 = Kb × 1.0 × 1 ⇒ Kb = 0.52 °C/m (물의 실제 Kb 값과 정확히 일치하므로 계산이 맞습니다.) 단계 2) MXn 용액의 몰랄농도를 구합니다.

MXn의 몰수 = 90 g ÷ 90 g/mol = 1.0 mol 몰랄농도 m = 1.0 mol ÷ 0.5 kg = 2.0 m 단계 3) MXn 용액의 i를 역산합니다.

ΔTb = 102.08 - 100 = 2.08 °C 2.08 = 0.52 × 2.0 × i 2.08 = 1.04 × i ⇒ i = 2 단계 4) 해리도 50 %를 반영해 n을 구합니다.

MXn 1 mol 중 0.5 mol이 해리하고 0.5 mol은 그대로 남습니다.

남은 MXn: 0.5 mol 생긴 M^n+: 0.5 mol 생긴 X⁻: 0.5 × n mol 총 입자 수 = 0.5 + 0.5 + 0.5n = 1 + 0.5n 따라서 i = 1 + 0.5n 입니다.

단계 5) i = 2를 대입합니다.

1 + 0.5n = 2 ⇒ 0.5n = 1 ⇒ n = 2 단계 6) 공식으로 검산합니다.

ν = 1 + n = 3, α = 0.5 이므로 i = 1 + (3 - 1) × 0.5 = 1 + 1 = 2 ⇒ 실제 i = 2와 일치합니다.

① 1 ⇒ 틀림.

n = 1이면 MX → M⁺ + X⁻ 이고 해리도 50 %일 때 i = 1 + 0.5×1 = 1.5 입니다.

ΔTb = 0.52 × 2.0 × 1.5 = 1.56 °C가 되어 끓는점이 101.56 °C가 되므로 조건과 다릅니다.

② 2 ⇒ 옳음.

i = 1 + 0.5×3 = 2.5 이므로 ΔTb = 0.52 × 2.0 × 2.5 = 2.6 °C, 끓는점 102.6 °C가 되어 맞지 않습니다.

② i = 2이고 해리도가 50 %이므로 1 + 0.5n = 2에서 n = 2 입니다.

아세틸렌이 연소할 때 엄청난 열을 내는 이유도 처음부터 에너지가 높기 때문입니다.

단계 3) ㄷ.

C(s, 흑연) + O₂(g) → CO₂(g) ΔH = -393.5 kJ → 발열 탄소의 완전 연소로, 대표적인 강한 발열 반응입니다.

단계 4) 흡열 반응은 ㄱ과 ㄴ 두 개입니다.

① ㄱ ⇒ 틀림.

ㄱ이 흡열인 것은 맞지만 ㄴ도 흡열이므로 답이 될 수 없습니다.

② ㄴ ⇒ 틀림.

ㄴ이 흡열인 것은 맞지만 ㄱ을 빠뜨렸습니다.

I₂가 고체 상태라는 점을 놓치고 ㄱ을 발열로 판단하면 이 선지를 고르게 됩니다.

③ ㄱ, ㄴ, ㄷ ⇒ 틀림.

ㄷ은 탄소의 연소로 ΔHf°(CO₂) = -393.5 kJ/mol인 강한 발열 반응입니다.

④ ㄱ, ㄴ ⇒ 옳음(정답).

HI(+26.5)와 C₂H₂(+227.4) 모두 ΔHf°가 양수이므로 두 생성 반응 다 흡열입니다.

④ ㄱ(ΔH = +53.0 kJ)과 ㄴ(ΔH = +227.4 kJ)이 흡열 반응입니다.

문제 20열역학과 전기화학 · 표준 연소 엔탈피정답 ②

다음 화합물 중 표준연소엔탈피(ΔHcomb)의 절댓값이 가장 큰 것은 무엇인가? ① C₂H₅OH ② C₂H₆ ③ CH₃COOH ④ CH₃CHO ■ 무엇을 묻는 문제인가 숫자를 외우지 않고도 연소열의 대소를 비교할 수 있는가를 묻습니다.

네 물질 모두 탄소 2개짜리 화합물이므로 연소 생성물(CO₂ 2몰 + H₂O)이 거의 같습니다.

그렇다면 차이는 오직 출발 물질이 얼마나 이미 산화되어 있는가에서 나온다는 논리를 세울 수 있어야 합니다.

1) 표준 연소 엔탈피 ΔHcomb°는 물질 1몰이 산소와 완전 연소할 때의 엔탈피 변화이며 항상 음수(발열)입니다.

"절댓값이 크다" = "열을 많이 낸다" 입니다.

2) ΔH = Σ(생성물 ΔHf°) - Σ(반응물 ΔHf°) 입니다.

생성물이 같다면 반응물의 ΔHf°가 높을수록(즉 불안정할수록) 방출 열량이 커집니다.

3) 연소는 산화 반응입니다.

이미 많이 산화된 물질은 더 산화될 여지가 적으므로 낼 수 있는 열이 적습니다.

반대로 전혀 산화되지 않은 물질은 산화될 여지가 최대라 열을 가장 많이 냅니다.

4) 탄소의 산화수로 산화 정도를 정량화할 수 있습니다.

탄소의 산화수가 클수록 이미 많이 산화된 상태입니다.

5) 네 물질 모두 탄소 2개이므로 CO₂ 2몰씩 생성됩니다.

물의 몰수만 조금 다를 뿐이라 비교의 축은 탄소의 산화 정도입니다.

단계 1) 각 물질에서 탄소의 평균 산화수를 구합니다(H는 +1, O는 -2 기준).

② C₂H₆ : 2x + 6(+1) = 0 → x = -3 (가장 환원된 상태) ① C₂H₅OH (C₂H₆O) : 2x + 6(+1) + (-2) = 0 → x = -2 ④ CH₃CHO (C₂H₄O) : 2x + 4(+1) + (-2) = 0 → x = -1 ③ CH₃COOH (C₂H₄O₂) : 2x + 4(+1) + 2(-2) = 0 → x = 0 (가장 산화된 상태) 단계 2) 산화 정도 순서는 C₂H₆(-3) < C₂H₅OH(-2) < CH₃CHO(-1) < CH₃COOH(0) 입니다.

완전 연소의 종착점인 CO₂에서 탄소의 산화수는 +4 이므로, 출발점의 산화수가 낮을수록 +4까지 갈 길이 멀고 그만큼 많은 열을 냅니다.

단계 3) 따라서 열을 가장 많이 내는 것은 가장 덜 산화된 C₂H₆, 가장 적게 내는 것은 가장 많이 산화된 CH₃COOH 입니다.

단계 4) 실제 표준 연소 엔탈피 값으로 확인합니다.

① C₂H₅OH : -1367 kJ/mol ② C₂H₆ : -1560 kJ/mol ③ CH₃COOH : -874 kJ/mol ④ CH₃CHO : -1167 kJ/mol 절댓값 순서가 1560 > 1367 > 1167 > 874 로 예측과 정확히 일치합니다.

단계 5) 연소 반응식으로도 확인할 수 있습니다.

소비되는 산소의 몰수를 보면 C₂H₆ + 3.5O₂ → 2CO₂ + 3H₂O C₂H₅OH + 3O₂ → 2CO₂ + 3H₂O CH₃CHO + 2.5O₂ → 2CO₂ + 2H₂O CH₃COOH + 2O₂ → 2CO₂ + 2H₂O 산소를 많이 먹는 물질일수록 열을 많이 냅니다.

① C₂H₅OH ⇒ 틀림.

산소 원자가 하나 붙어 이미 부분 산화되었으므로 약 1367 kJ/mol로 C₂H₆보다 작습니다.

② C₂H₆ ⇒ 옳음(정답).

탄소 평균 산화수 -3으로 가장 환원된 상태이고, 산소를 3.5몰이나 소비하며 약 1560 kJ/mol을 방출합니다.

③ CH₃COOH ⇒ 틀림.

탄소 평균 산화수 0으로 CO₂(+4)에 가장 가까운 상태라 약 874 kJ/mol로 가장 적게 방출합니다.

④ CH₃CHO ⇒ 틀림.

탄소 평균 산화수 -1로 중간이며 약 1167 kJ/mol입니다.

② C₂H₆이 가장 덜 산화된 상태여서 완전 연소 시 방출 열량, 즉 표준 연소 엔탈피의 절댓값이 가장 큽니다.

문제 21화학 평형과 산·염기 · 약산의 이온화 상수정답 ③

CH₃COOH 용액 0.5 M 의 [H⁺]가 3.0 × 10⁻³이다.

이 때, CH₃COOH의 Ka는 얼마인가? ① 1.0 × 10⁴ ② 1.0 × 10⁻⁵ ③ 1.8 × 10⁻⁵ ④ 1.8 × 10⁻¹⁰ ■ 무엇을 묻는 문제인가 약산의 초기 농도와 평형 상태의 [H⁺]만 주어졌을 때 이온화 상수 Ka를 구하는 가장 기본적인 문제입니다.

평형 표(ICE 표)를 세우거나 이온화도 α를 이용하는 두 가지 길이 있는데, 어느 쪽으로 가도 같은 답이 나옵니다.

약산에서 쓸 수 있는 근사(C - x ≈ C)의 타당성을 스스로 확인하는 습관도 함께 점검합니다.

1) 약산의 이온화 평형 CH₃COOH(aq) ⇌ H⁺(aq) + CH₃COO⁻(aq) Ka = [H⁺][CH₃COO⁻] / [CH₃COOH] 2) 초기 농도 C, 이온화된 농도를 x라 하면 평형에서 [H⁺] = x, [CH₃COO⁻] = x, [CH₃COOH] = C - x Ka = x²/(C - x) 약산은 x가 C에 비해 매우 작으므로 C - x ≈ C 로 근사할 수 있고, 이때 Ka ≈ x²/C 입니다.

(근사가 타당한지는 x/C가 5 % 미만인지로 판정합니다.) 3) 이온화도 α = 이온화된 몰수 / 처음 몰수 = x/C 이므로 x = Cα 이고, Ka = (Cα)²/(C - Cα) ≈ Cα² (α가 작을 때) 이를 오스트발트 희석 법칙이라고 합니다.

4) 약산의 Ka는 1보다 훨씬 작습니다.

1보다 크면 강산이므로, 계산 결과가 1을 넘으면 어딘가 틀린 것입니다.

[방법 1] 평형 농도를 직접 대입 단계 1) 평형 농도를 정리합니다.

C = 0.5 M, x = [H⁺] = 3.0×10⁻³ M [H⁺] = 3.0×10⁻³ M [CH₃COO⁻] = 3.0×10⁻³ M (물의 이온화는 무시) [CH₃COOH] = 0.5 - 0.003 = 0.497 ≈ 0.5 M 단계 2) Ka에 대입합니다.

Ka = (3.0×10⁻³)(3.0×10⁻³) / 0.5 = 9.0×10⁻⁶ / 0.5 = 1.8×10⁻⁵ [방법 2] 이온화도 이용 단계 1) α = [H⁺]/C = (3.0×10⁻³)/0.5 = 6.0×10⁻³ (즉 0.6 %) 단계 2) Ka = Cα² = 0.5 × (6.0×10⁻³)² = 0.5 × 3.6×10⁻⁵ = 1.8×10⁻⁵ 단계 3) 근사의 타당성 확인: α = 0.6 %로 5 %보다 훨씬 작으므로 C - x ≈ C 근사가 안전합니다.

근사 없이 Ka = 9.0×10⁻⁶/0.497 = 1.81×10⁻⁵ 로 계산해도 결과가 사실상 같습니다.

① 1.0 × 10⁴ ⇒ 틀림.

Ka가 1보다 크다는 것은 완전히 이온화되는 강산이라는 뜻인데, 문제에서 아세트산은 0.5 M에서 [H⁺]가 겨우 3.0×10⁻³ M밖에 되지 않는 약산입니다.

지수의 부호를 빠뜨렸을 때 나오는 값입니다.

② 1.0 × 10⁻⁵ ⇒ 틀림.

자릿수는 비슷하지만 계수가 맞지 않습니다.

[H⁺]²을 9.0×10⁻⁶이 아니라 5.0×10⁻⁶ 부근으로 어림했거나, [H⁺]를 제곱하지 않고 대략 계산했을 때 나오는 값입니다.

③ 1.8 × 10⁻⁵ ⇒ 옳음.

Ka = (3.0×10⁻³)²/0.5 = 1.8×10⁻⁵ 이며, 실제 아세트산의 Ka 문헌값과도 일치합니다.

④ 1.8 × 10⁻¹⁰ ⇒ 틀림.

지수를 5제곱만큼 잘못 옮긴 값입니다.

참고로 아세트산 이온의 Kb는 Kw/Ka = 1.0×10⁻¹⁴/1.8×10⁻⁵ = 5.6×10⁻¹⁰ 로, 이 값과도 다릅니다.

③ Ka = [H⁺]²/C = (3.0×10⁻³)²/0.5 = 1.8 × 10⁻⁵ 입니다.

문제 22화학 평형과 산·염기 · 이온화도와 Ka정답 ③

0.1 M 미지의 산 HA의 이온화도가 0.99라고 할 때, [H⁺]×Ka와 가장 가까운 값은 어느 것인가? ① 10⁻⁴ ② 10⁻² ③ 1 ④ 10² ■ 무엇을 묻는 문제인가 이온화도 α의 정의에서 출발해 평형 농도를 모두 채우고, 거기서 산 해리상수 Ka를 직접 계산할 수 있는지 묻는 문제입니다.

"이온화도가 0.99"라는 말이 곧 "거의 완전히 이온화되는 강산"이라는 뜻이고, 그런 산의 Ka는 1보다 훨씬 큰 값이 된다는 감각을 갖추었는지가 관건입니다.

약산의 근사식(Ka = Cα²)을 무비판적으로 쓰면 틀리도록 설계되어 있습니다.

1) 이온화도 α = (이온화된 산의 몰수)/(처음 넣은 산의 몰수) 입니다.

0 ≤ α ≤ 1 이며, α가 1에 가까울수록 강한 산입니다.

2) HA ⇌ H⁺ + A⁻ 에서 처음 농도가 C일 때 평형 농도는 [HA] = C(1 - α), [H⁺] = [A⁻] = Cα 입니다.

3) 이것을 평형식에 넣으면 Ka = [H⁺][A⁻]/[HA] = (Cα)²/(C(1-α)) = Cα²/(1-α) 입니다.

이 식이 이 문제의 뼈대입니다.

4) α가 매우 작을 때만 1 - α ≈ 1 이 성립해 흔히 쓰는 Ka ≈ Cα² 가 됩니다.

여기서는 α = 0.99 라 1 - α = 0.01 로 아주 작아지고, 이 값이 분모에 들어가 Ka를 100배 규모로 키웁니다.

근사를 쓰면 안 되는 대표적인 상황입니다.

5) 강산의 Ka는 1보다 훨씬 큽니다.

예를 들어 HCl은 약 10⁶, HNO₃는 약 20 수준입니다.

Ka가 1보다 크면 pKa는 음수가 됩니다.

단계 1) ICE를 세웁니다.

C = 0.1 M, α = 0.99 이므로 이온화된 양은 0.1 × 0.99 = 0.099 M 입니다.

처음: [HA] = 0.1, [H⁺] = 0, [A⁻] = 0 변화: [HA] -0.099, [H⁺] +0.099, [A⁻] +0.099 평형: [HA] = 0.001, [H⁺] = 0.099, [A⁻] = 0.099 단계 2) Ka를 계산합니다.

Ka = [H⁺][A⁻]/[HA] = (9.9×10⁻² × 9.9×10⁻²)/(1.0×10⁻³) = (9.801×10⁻³)/(1.0×10⁻³) = 9.80 단계 3) 공식으로 검산해도 같습니다.

Ka = Cα²/(1 - α) = 0.1 × (0.99)²/(1 - 0.99) = 0.1 × 0.9801/0.01 = 9.80 단계 4) 구하는 값을 계산합니다.

[H⁺] × Ka = 0.099 × 9.80 = 0.970 단계 5) 0.970은 1에 매우 가깝고, 선지의 다른 값(10⁻⁴, 10⁻², 10²)과는 자릿수 자체가 다릅니다.

따라서 답은 ③ 1 입니다.

① 10⁻⁴ ⇒ 틀림.

[H⁺]와 Ka를 곱한 것이 아니라 [H⁺]² 정도를 구하거나(0.099² ≈ 10⁻²), 약산으로 착각해 Ka를 10⁻³ 정도로 잡았을 때 나오는 값입니다.

② 10⁻² ⇒ 틀림.

Ka ≈ Cα² = 0.098 로 근사해 버리면 [H⁺]×Ka = 0.099 × 0.098 ≈ 10⁻² 가 나옵니다.

이것이 이 문제의 가장 대표적인 함정으로, 1 - α = 0.01 을 분모에 넣지 않은 결과입니다.

③ 1 ⇒ 옳음.

Ka = 9.80, [H⁺] = 0.099 이므로 곱은 0.970 ≈ 1 입니다.

④ 10² ⇒ 틀림.

Ka만 계산하고 [H⁺]를 곱하지 않았거나, Ka를 Cα²/(1-α)² 처럼 분모를 한 번 더 제곱해 980 정도로 부풀렸을 때 나오는 값입니다.

③ Ka = 0.1 × 0.99²/0.01 = 9.80 이고 [H⁺] = 0.099 이므로 곱은 0.970, 즉 약 1입니다.

문제 23화학량론 · 한계 반응물과 수득률정답 ②

타이타늄 금속은 염화 타이타늄(IV)과 용융 마그네슘과의 반응을 통해서 아래와 같이 얻을 수 있다.

TiCl₄(g) + 2Mg(l) → Ti(s) + 2MgCl₂(l) TiCl₄(몰질량=189.7 g/mol) 18.97 g과 Mg(원자량=24.3 g/mol) 2.43 g을 반응시켜 Ti(원자량=47.9 g/mol) 2.156 g을 얻었다.

이 반응의 한계 반응물과 수득률[(실제수득량/이론수득량)×100]은 얼마인가? ① TiCl₄, 90% ② Mg, 90% ③ TiCl₄, 45% ④ Mg, 45% ■ 무엇을 묻는 문제인가 한계 반응물을 찾고 이론 수득량을 구한 뒤 실제 수득량과 비교해 수득률을 계산하는, 화학량론의 종합 문제입니다.

"몰수가 적은 쪽이 한계 반응물"이라는 잘못된 직관을 계수로 걸러 낼 수 있는지가 핵심입니다.

1) 몰수 = 질량 ÷ 몰질량.

2) 한계 반응물은 단순히 몰수가 적은 물질이 아니라, "각 반응물의 몰수를 반응식 계수로 나눈 값"이 가장 작은 물질입니다.

이 값이 실제로 진행할 수 있는 반응의 횟수(반응 진행도)를 결정합니다.

3) 이론 수득량은 한계 반응물이 100% 소모되었을 때 얻어지는 생성물의 양이고, 실제로는 부반응·손실 때문에 그보다 적게 얻어집니다.

4) 수득률 = (실제 수득량 / 이론 수득량) × 100(%).

단계 1) 각 반응물의 몰수를 구합니다.

TiCl₄: 18.97 g ÷ 189.7 g/mol = 0.100 mol Mg: 2.43 g ÷ 24.3 g/mol = 0.100 mol 단계 2) 계수로 나눠 비교합니다.

반응식 TiCl₄ + 2Mg → Ti + 2MgCl₂에서 TiCl₄: 0.100 ÷ 1 = 0.100 Mg: 0.100 ÷ 2 = 0.050 값이 더 작은 Mg가 한계 반응물입니다.

몰수는 똑같이 0.100 mol이지만 Mg는 두 배가 필요하기 때문입니다.

단계 3) 이론 수득량을 구합니다.

Mg 0.100 mol이 모두 반응하면 Ti는 0.100 × (1/2) = 0.050 mol 생성되고, 질량 = 0.050 mol × 47.9 g/mol = 2.395 g입니다.

1 mol의 이상 단원자 기체가 300 K에서 부피를 2배로 가역 단열 팽창하면 T₂ = T₁(V₁/V₂)^γ-1 = 300 K × (1/2)^2/3 = 300 × 0.630 = 189 K ΔH = nC_pΔT = 1 mol × 20.79 J mol⁻¹ K⁻¹ × (189 - 300) K = -2.31 kJ ≠ 0 온도가 111 K나 떨어지므로 ΔH는 결코 0이 아니다.

Ⅰ은 거짓이다.

STEP 3.

(STEP 1의 결과를 계산으로 재확인) ― 같은 과정의 ΔS를 상태함수 공식으로 직접 계산해 본다.

ΔS = nC_V ln(T₂/T₁) + nR ln(V₂/V₁) = 1 × 12.47 × ln(189/300) + 1 × 8.314 × ln 2 = 12.47 × (-0.462) + 8.314 × 0.693 = -5.76 + 5.76 = 0 J K⁻¹ 온도 하강에 따른 엔트로피 감소와 부피 팽창에 따른 엔트로피 증가가 정확히 상쇄된다.

Ⅱ만 참이므로 정답은 ②다.

① ✕ Ⅰ만.

ΔH = 0 은 성립하지 않는다.

가역 단열 팽창은 계가 외부에 일을 하고 그만큼 내부 에너지를 잃으므로 온도가 내려가고, 따라서 ΔH = nC_pΔT < 0 이다.

압축이면 반대로 ΔH > 0 이다.

② ◎ 정답 Ⅱ만.

q_rev = 0 이므로 ΔS = 0 이고(참), ΔH는 온도 변화 때문에 0이 아니다(거짓).

가역 단열 = 등엔트로피라는 등식을 알고 있으면 즉시 고를 수 있다.

③ ✕ Ⅰ과 Ⅱ 모두.

Ⅱ는 옳지만 Ⅰ이 틀렸다.

"열 출입이 없으니 엔탈피도 변하지 않는다"는 잘못된 연결이며, ΔH = q_p의 아래첨자 p를 지워 버린 실수다.

④ ✕ 모두 아니다.

Ⅱ는 엔트로피 정의에서 곧바로 따라 나오는 참인 명제다.

이 선택지를 고르는 학생은 대개 "비가역 단열 과정에서는 ΔS > 0"이라는 사실을 가역 과정에까지 잘못 확장한 것이다.

가역이라는 단서가 붙는 순간 등호가 성립한다.

■ 오개념 클리닉 [함정 1] q = 0 → ΔH = 0 으로 넘어가는 실수.

ΔH = q 는 정압·비팽창일 없음이라는 조건에서만 성립한다.

조건절을 잘라 먹고 결론만 외운 대표적 사례다.

[함정 2] 단열(adiabatic)과 등온(isothermal)을 혼동하는 실수.

단열은 열을 주고받지 않는 것이지 온도가 일정한 것이 아니다.

오히려 단열 팽창에서는 온도가 반드시 내려간다.

[함정 3] 가역과 비가역을 구분하지 않는 실수.

단열이라도 비가역이면 ΔS > 0 이다.

진공으로의 단열 자유 팽창이 그 예이며, q = 0 인데도 ΔS = nR ln(V₂/V₁) > 0 이다.

ΔS는 상태함수라 실제 경로가 아니라 같은 처음·끝 상태를 잇는 가역 경로로 계산해야 한다.

[함정 4] dS = dq/T 로 아래첨자 rev를 빠뜨리고 외우는 실수.

이 아래첨자 하나가 [함정 3]의 전부를 만든다.

일반적으로는 클라우지우스 부등식 dS ≥ dq/T 이며, 등호는 가역일 때만 성립한다.
