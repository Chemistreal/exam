오비탈의 마디

126 · 원자모형읽는 데 약 11분
‹ 파이널로
이번 진단에서 오비탈 마디 · 양자수가 보강으로 잡혔어. 이 1강을 끝까지 읽고 직접 해보기까지. "p의 각마디는 몇 개?", "3p의 방사 마디는 몇 개?" 같은 O/X 문장은 공식 세 줄만 정확하면 다 맞아.

자, 오비탈은 궤도가 아니라 전자를 발견할 확률의 구름이라고 했지(005강). 그 구름을 들여다보면 확률이 딱 0인 면이 있어. 이게 마디야. 오늘은 양자수 이름표를 다시 붙이고, 마디 두 종류를 그림으로 본 다음, 세는 공식 세 줄과 자주 틀리는 자리, 마디와 확률·에너지의 관계까지 갈 거야.

01먼저 이름표부터 · 양자수 네 개가 정하는 것

마디를 세려면 n과 l을 정확히 읽어야 해. 시험 문장은 이 이름표를 슬쩍 바꿔치기해서 틀린 문장을 만들어.

양자수정하는 것허용 값
주양자수 n전자 껍질1, 2, 3, …
부양자수 l오비탈의 종류(모양)0 ~ n−1
자기양자수 mₗ오비탈의 방향−l ~ +l
스핀양자수 mₛ전자의 스핀 방향+½, −½

l은 방위양자수라고도 불러. 값과 문자는 짝으로 외워. s 0 · p 1 · d 2 · f 3. 한 종류의 오비탈 수(방의 수)는 mₗ 값의 개수인 2l+1이라 s 1개, p 3개, d 5개, f 7개야.

함정 · 이름표 바꿔치기
"p의 부양자수는 2", "d의 부양자수는 3"은 한 칸 밀린 틀린 문장이야. 껍질은 n이 정하니 "자기양자수는 전자껍질을 나타낸다"도 틀려. 스핀양자수는 오비탈이 아니라 전자 자신의 스핀 방향이라 "스핀양자수는 오비탈의 방향"도 틀리고, 값은 +½와 −½뿐이라 "0 또는 +1"도 틀려.
02마디란 무엇인가 · 전자가 절대 없는 자리

기타 줄 가운데를 살짝 짚고 튕기면 그 점은 안 움직이고 양쪽만 떨려. 파동이 늘 0인 그 자리가 마디야. 전자도 파동이라 오비탈 안에 이런 자리가 생기고, 마디 위에서는 전자를 발견할 확률이 정확히 0이야. 3차원이라 마디는 면이고, 두 종류가 있어.

방사 마디(방사상 마디)는 핵을 둘러싼 공 껍질 모양, 각마디(마디면)는 핵을 지나는 평면이야.

점선이 마디고, 마디를 사이에 두고 파동의 부호(+, −, 색)가 바뀌어. d 중 dz² 하나는 평면 대신 원뿔 두 개지만 개수는 똑같이 2야.

함정 · 전자는 마디를 어떻게 건너가?
2s 전자는 마디 안쪽에서도 바깥쪽에서도 발견되는데 마디 위에서는 안 발견돼. 궤도를 도는 알갱이로 그리면 말이 안 되지? 오비탈은 길이 아니라 한 덩어리 파동이고, 마디는 그 모양일 뿐이야.
03세는 공식 세 줄 · l, n−l−1, n−1
① 각마디 수 = l  (s 0 · p 1 · d 2 · f 3)
② 방사 마디 수 = n − l − 1
③ 전체 마디 수 = n − 1  (= ① + ②)

각마디는 문자만 보면 돼. s는 공이라 자를 평면이 없고(0), p는 한 장, d는 두 장, f는 세 장. 2p든 5p든 각마디는 1이야. 전체 마디는 껍질이 높을수록 늘어서 n−1이고, 거기서 각마디를 뺀 나머지가 방사 마디야.

오비탈 (n, l)각마디 l방사 n−l−1전체 n−1

2s (2, 0)011
2p (2, 1)101
3s (3, 0)022
3p (3, 1)112
3d (3, 2)202
4s (4, 0)033

4d (4, 2)213
4f (4, 3)303
예제 · 거꾸로 찾기 각마디 1개, 방사 마디 3개면? 각마디 1이니 l=1(p). n = 방사 + l + 1 = 5라서 5p야. 4p는 방사 마디가 4−1−1 = 2개라 아니야.
04가장 많이 틀리는 네 자리
함정 네 개
① "각마디 수는 주양자수(n)와 같다" ✗ 각마디는 l이야. n이 정하는 건 전체(n−1).
② "2p의 방사 마디는 1", "3p의 방사 마디는 2" ✗ n−1은 전체 수야. l=0인 s만 방사 = 전체라서 2s 1개, 3s 2개가 맞고, p부터는 l을 빼. 2p 0개, 3p 1개.
③ "s의 각마디 수는 1" ✗ 공 모양이라 자를 평면이 없어. 0개.
④ "f의 각마디 수는 1" ✗ f는 l=3이라 3개.
지름길 · 모양이 처음 나오는 1s·2p·3d·4f는 l = n−1이라 방사 마디가 0이야. 3d의 마디 2개는 둘 다 각마디.
05마디와 확률 · 봉우리, 그리고 에너지

핵에서 거리 r인 얇은 공 껍질에서 전자를 발견할 확률을 거리마다 그리면(방사 분포), 수소의 3s는 이래.

0으로 떨어지는 곳이 방사 마디(3s는 2곳)고, 봉우리는 마디보다 하나 많아. 봉우리 수 = n − l. 3s 3개, 3p 2개, 3d 1개. 가장 높은 봉우리는 제일 바깥이야.

함정 · 핵 자리가 최대?
이 그래프는 핵(r=0)에서 0이야. 핵 자리 껍질은 부피가 0이거든. 한 점의 확률 밀도로 보면 s는 핵에서 가장 크지만, p·d·f는 각마디가 핵을 지나서 핵 위치의 밀도가 0이야.

에너지도 마디와 이어져. 전자가 하나인 수소와 He⁺에서는 마디가 많을수록 파동이 잘게 출렁이고 에너지가 높아(기타 줄도 마디가 많을수록 높은 음). 에너지가 n만으로 정해져서 전체 마디 수와 나란히 가. 1s < 2s = 2p < 3s = 3p = 3d.

함정 · 다전자 원자의 s < p < d
전자가 여럿이면 같은 n에서도 s < p < d로 갈라져. 3s는 방사 마디 안쪽의 작은 봉우리 덕분에 핵 가까이 파고들어(침투, 007강) 더 세게 붙잡히거든. 그래서 다전자 원자에서는 «마디 많음 = 에너지 높음»이 그대로 안 맞아(K·Ca에서는 4s가 3d보다 먼저 채워져). He⁺에는 이 갈라짐이 없어서 2s = 2p이고, 3d가 4s보다 낮아. 마디 수는 n과 l로만 정해지니 4s의 전체 마디(3개)는 3d(2개)보다 늘 1개 많아.
06한 장 정리와 다음 연결

오늘 들고 갈 한 문장.

"각마디는 l, 방사 마디는 n−l−1, 합치면 n−1 · 마디 위에서는 전자를 발견할 확률이 0."

O/X 문장을 만나면 이름에서 n과 l부터 적고, 묻는 게 각마디·방사·전체 중 무엇인지 보고 맞는 줄에 넣어. 이 마디 그림은 분자 오비탈에서 다시 써. 두 핵 사이에 마디가 생기면 거기 전자가 없어서 결합이 약해지거든.

✓확인 문제

방금 배운 것으로 풀 수 있는 3문항입니다. 답을 고르면 해설이 열립니다 — 먼저 스스로 고르고 나서 보세요.

1. 오비탈의 마디(node)에 대한 설명으로 옳지 않은 것은? (전체 마디 수 = n − 1, 각마디(마디면) 수 = l, 방사 마디(구형 마디) 수 = n − l − 1이다.)
정답 ③

주어진 관계식에 각 오비탈을 대입한다. · 3s: n = 3, l = 0 → 전체 2, 각마디 0, 방사 마디 3 − 0 − 1 = 2. ①은 옳다. · 3p: n = 3, l = 1 → 전체 2, 각마디 1, 방사 마디 3 − 1 − 1 = 1. ②는 옳다. · 3d: n = 3, l = 2 → 전체 2, 각마디 2, 방사 마디 3 − 2 − 1 = 0. 즉 3d의 방사 마디는 1개가 아니라 0개이므로 ③이 틀리다. 3d는 전체 마디 2개가 모두 각마디(마디면)이다. · 2p: n = 2, l = 1 → 전체 1, 각마디 1, 방사 마디 2 − 1 − 1 = 0. ④는 옳다. 각 부껍질에서 가장 낮은 n을 갖는 오비탈(2p, 3d, 4f)은 방사 마디가 항상 0이다.

자주 걸리는 자리 전체 마디 수 n − 1만 기억하고 각마디와 방사 마디의 배분을 l로 나눈다는 점을 잊는다. 특히 3d는 마디 2개가 전부 각마디여서 방사 마디가 0이다.
2. 수소 원자의 오비탈에서 파동 함수의 값이 0 이 되는 면을 마디(node)라 하고, 핵을 중심으로 한 구면 형태의 마디를 방사 마디, 핵을 지나는 평면(또는 원뿔) 형태의 마디를 각 마디라 한다. 주 양자수 n, 각운동량 양자수 l 인 오비탈에서 각 마디 수는 l, 방사 마디 수는 n − l − 1, 전체 마디 수는 n − 1 이다.

수소 원자의 4d 오비탈에 대한 설명으로 옳은 것은?
정답 ①

4d 오비탈은 n = 4, l = 2 이다. · 각 마디 수 = l = 2 · 방사 마디 수 = n − l − 1 = 4 − 2 − 1 = 1 · 전체 마디 수 = n − 1 = 4 − 1 = 3 검산: 각 마디 2 + 방사 마디 1 = 3 = 전체 마디 수로 일치한다. d 오비탈은 이름(l = 2)에서 곧바로 각 마디가 2개임을 알 수 있고, 방사 마디는 그 나머지로 정해진다.

자주 걸리는 자리 각 마디 수와 방사 마디 수의 공식을 서로 바꿔 쓰거나, 방사 마디 수를 n − 1 로 두어 전체 마디 수와 혼동한다.
3. 전자가 1개뿐인 수소꼴 이온 He⁺의 오비탈을 생각한다. 이 이온에서 오비탈의 에너지는 E = −Z²(2.18×10⁻¹⁸ J)/n²으로 주양자수 n에만 의존한다. 또 오비탈의 전체 마디 수는 (방사 마디 수) + (각 마디 수) = n − 1이고, 각 마디 수는 방위양자수 l과 같다. 옳은 설명은?
정답 ①

3d는 n = 3이므로 전체 마디 수는 n − 1 = 2다(각 마디 l = 2, 방사 마디 n − l − 1 = 0). He⁺는 전자가 1개인 수소꼴 이온이라 에너지가 n에만 의존하므로 2s와 2p의 에너지는 같고, n = 3인 3d가 n = 4인 4s보다 에너지가 낮다. 3s의 방사 마디 수는 n − l − 1 = 3 − 0 − 1 = 2다.

자주 걸리는 자리 다전자 원자에서 가려막기 때문에 나타나는 s < p < d 갈라짐과 4s < 3d 순서를 전자가 1개인 수소꼴 이온에도 그대로 적용한다.

검수된 동형문제에서 골랐습니다 (사람이 확인한 2,490문항).

직접 해보기 (숙제)
① 표를 가리고 1s~4f의 각마디·방사·전체 마디를 써 봐. ② 오답 난 O/X 문장마다 n과 l을 적고, 세 줄 중 어느 줄을 썼어야 했는지 표시해. ③ 각마디 2개·방사 마디 1개인 오비탈을 찾아봐(답 4d). 그리고 입으로 말해. "각마디는 l, 방사 마디는 n−l−1, 합치면 n−1." 한 바퀴 돌리면 이 개념은 네 거다.
