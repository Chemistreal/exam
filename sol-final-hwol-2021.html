문제 1밀도·유효숫자정답 ③
눈금 실린더에 물을 25.0mL로 맞추고 9.00g 고체 X를 넣으니 수면이 28.0mL로 상승. 유효숫자를 고려한 X의 밀도(g/mL)는?
① 0.33
② 0.333
③ 3.0
④ 3.00

사고과정

X 부피 = 28.0−25.0 = 3.0mL(뺄셈이라 소수 첫째 자리, 2유효숫자). 밀도 = 9.00/3.0 = 3.0 g/mL(2유효숫자). → ③

뺄셈은 소수 자릿수 기준. 3.0(2자리)이 제한해 밀도도 2유효숫자로 3.0으로 적는다.
문제 2배수 비례·벤젠정답 ①
탄화수소 X·Y 중 하나가 벤젠(C6H6). 6.5g 시료의 C·H 질량: X(C 6.0g·H 0.5g), Y(C 5.6g·H 0.9g). 일정 C당 H 질량비의 비율 N과 벤젠에 해당하는 것은?
① N=2, X
② N=2, Y
③ N=3, X
④ N=3, Y

사고과정

H/C: X = 0.5/6.0 = 0.083, Y = 0.9/5.6 = 0.161. 비율 N = 0.161/0.083 ≈ 2(배수 비례). 벤젠 C6H6의 H/C = 6/72 = 0.083 → X가 벤젠. → ①

같은 C 질량당 H 질량의 정수비가 배수 비례. 벤젠(CH 실험식, H/C=0.083)과 일치하는 X가 답.
문제 3수소 생산(개질)정답 ①
CH4+H2O→CO+3H2(반응식 1), CO+H2O→㉡+H2(반응식 2). ㉠(CO·H2의 ㉠)과 ㉡에 해당하는 것은?
① 혼합물·CO2
② 혼합물·HCO2H
③ 화합물·CO2
④ 화합물·HCO2H

사고과정

㉠ 합성가스는 CO와 H2의 혼합물(화합물 아님). ㉡ 수성가스 전환: CO+H2O→CO2+H2. → ①

합성가스(syngas)는 두 기체가 섞인 혼합물. 수성가스 전환은 CO를 CO2로 바꾸며 수소를 추가 생산한다.
문제 4농도·투여량정답 ②
백신 유효성분 농도 10mg/dL. 0.5mL씩 접종할 때 개인별 투여량(μg)은?
① 20
② 50
③ 200
④ 500

사고과정

10mg/dL = 10mg/100mL = 0.1mg/mL. 0.1mg/mL×0.5mL = 0.05mg = 50 μg. → ②

1 dL = 100 mL 환산이 핵심. 농도×부피로 질량을 구한 뒤 mg→μg(×1000) 변환.
문제 5칼슘카바이드(CaC2)정답 ②
CaC2 격자구조에 대해 옳은 것은? (가. 이온 결합이라 전성 큼 / 나. 암염 구조 / 다. C2²⁻ 고립쌍이 sp 혼성 / 라. C-C는 π 1개+σ 2개)
① 가, 나
② 나, 다
③ 다, 라
④ 나, 다, 라

사고과정

가 이온 결정은 부서지기 쉬움(전성 작음). 라 C≡C는 σ 1개+π 2개(반대). 나 암염(NaCl)형 구조. 다 C2²⁻([:C≡C:]²⁻)은 sp 혼성, 고립쌍이 sp 궤도에. → ②

아세틸리드 이온 C2²⁻는 N2와 등전자(삼중결합+양 끝 고립쌍). 이온 결합은 충격에 층이 어긋나 깨진다.
문제 62s 방사 확률 분포정답 ③
2s 오비탈 방사 방향 확률 분포(봉우리 2개, 사이에 마디). 옳은 것은? (가. 봉우리 수 = n / 나. 한 전자는 0.5Å, 다른 전자는 3Å에 / 다. 1Å서 발견 확률 0)
① 가, 나
② 나, 다
③ 가, 다
④ 가, 나, 다

사고과정

가 2s는 봉우리 2개 = 주양자수 n(=2). 다 두 봉우리 사이 마디(1Å)서 확률 0. 나 이건 한 전자의 확률 분포이지 두 전자의 고정 위치가 아님. → ③

방사 확률 분포는 한 전자를 거리별로 발견할 확률. ns 오비탈의 봉우리 수는 n개, 마디(확률 0)는 (n−1)개.
문제 7쌍극자 모멘트 최대정답 ④
기체 상태에서 분자 쌍극자 모멘트가 가장 큰 것은?
① BF3
② SO3
③ PH3
④ NH3

사고과정

BF3·SO3는 평면 삼각(대칭) → 쌍극자 0. PH3·NH3는 삼각뿔(극성)인데 NH3가 N-H 결합 극성이 커 쌍극자 최대(~1.47D). → ④

대칭 평면 분자는 무극성. 같은 삼각뿔이라도 결합 극성이 큰 NH3가 PH3(P·H 전기음성도 비슷)보다 쌍극자가 크다.
문제 8양자수·전자 배치정답 ③
a+b+c는? (a: 4f 부껍질 최대 전자수 / b: n=3, ml=−1인 모든 오비탈 최대 전자수 / c: 바닥상태 ₂₅Mn의 홀 전자수)
① 19
② 21
③ 23
④ 25

사고과정

a = 4f 최대 = 14. b: n=3·ml=−1은 3p·3d 2개 궤도 → 2×2 = 4. c: Mn [Ar]3d⁵4s²의 3d⁵ → 홀전자 5. 합 = 14+4+5 = 23. → ③

f 부껍질 14개. 특정 ml 값은 해당 l 이상의 부껍질마다 한 궤도씩(n=3서 p·d). Mn은 3d 반채움이라 홀전자 5개.
문제 9유효 핵전하(관련 적은 것)정답 ②
주기적 성질 중 '유효 핵전하'와 관련이 가장 적은 것은? (② 같은 족서 원자번호↑면 원자반지름↑)
① 같은 주기서 원자번호↑면 원자반지름↓.
② 같은 족서 원자번호↑면 원자반지름↑.
③ 등전자 이온서 원자번호↑면 이온반지름↓.
④ 전자를 떼어낼수록 순차 이온화에너지↑.

사고과정

② 같은 족 반지름 증가는 전자 껍질(n) 추가가 주원인이지 유효 핵전하 변화가 아님. → ②

①(주기 내 Zeff↑→반지름↓)·③(등전자서 핵전하↑→이온↓)·④(전자 잃을수록 남은 전자의 Zeff↑)는 모두 유효 핵전하 관련.

같은 족을 내려가면 주양자수가 커져 반지름이 증가. 유효 핵전하는 같은 주기·등전자 비교에서 핵심 인자다.
문제 102주기 원소(F)정답 ④
2주기 원소 설명 중 옳은 것은? (가. 제1 IE 최대는 F / 나. 전자 받을 때 최대 에너지 방출은 F / 다. 전기음성도 최대는 F(Ne 제외) / 라. 홀 전자수 최대는 F)
① 가, 나
② 다, 라
③ 가, 다
④ 나, 다

사고과정

가 제1 IE 최대는 Ne(F 아님). 라 홀전자 최대는 N(2p³ 3개, F는 2p⁵ 1개). 나 2주기서 전자친화도 최대(F). 다 전기음성도 최대(F). → ④

F는 전기음성도·전자친화도 1위지만, 1차 이온화 E는 Ne(비활성)이 더 크고 홀전자는 반채움 N이 가장 많다.
문제 11원자 구성 입자정답 ①
원자를 구성하는 입자에 대해 옳은 것은? (가. 중성자 없는 원자 존재 / 나. 양성자보다 중성자 많은 원자 존재 / 다. 양성자·중성자 질량 동일 / 라. 전자는 질량 없음)
① 가, 나
② 다, 라
③ 가, 다
④ 나, 다

사고과정

가 ¹H(수소-1)은 중성자 0. 나 ¹⁴C 등 중성자가 더 많은 핵 존재. 다 양성자·중성자 질량은 거의 같으나 동일하지 않음(중성자가 약간 무거움). 라 전자도 질량 있음(양성자의 약 1/1836). → ①

수소-1만 중성자가 없다. 양성자와 중성자는 비슷하지만 미세하게 다르고, 전자 질량은 작지만 0이 아니다.
문제 12전이 금속 이온 홀전자정답 ②
Cr(₂₄, 4s¹3d⁵)·Cu(₂₉, 4s¹3d¹⁰)를 참고해 Cr³⁺와 Cu⁺의 홀전자수의 합은?
① 2
② 3
③ 4
④ 5

사고과정

Cr³⁺: [Ar]3d³(4s 먼저·이어 3d 2개 제거) → 홀전자 3. Cu⁺: [Ar]3d¹⁰(4s 제거) → 홀전자 0. 합 = 3. → ②

전이 금속 양이온은 4s 전자를 먼저 잃는다. Cr³⁺는 3d³(홀전자 3), Cu⁺는 3d¹⁰(채워져 홀전자 0).
문제 13수소 원자 에너지 준위정답 ②
수소 원자에서 M 전자 껍질 에너지 준위를 −E로 가정. 옳은 것은? (가. L껍질서 2s<2p / 나. K껍질 준위는 −9E / 다. 라이먼계열 최단 파장 빛의 에너지는 5E)
① 가
② 나
③ 가, 나
④ 나, 다

사고과정

M껍질(n=3) = −E → En = −RH/n²서 RH = 9E. 나 K껍질(n=1) = −9E. 가 수소는 2s·2p가 축퇴(에너지 같음). 다 라이먼 한계(∞→1) = RH = 9E(5E 아님). → ②

단일 전자 수소는 에너지가 n에만 의존(2s=2p). En=−9E/n²이라 K(n=1)=−9E, 라이먼 한계는 9E.
문제 14이온 결합 미포함정답 ④
이온 결합 화합물을 하나도 포함하지 않는 것은? (① HCN·NO2·Ca(NO3)2 / ② KOH·CCl4·SF4 / ③ NaH·CaF2·NaNH2 / ④ CH2O·H2S·NH3)
① HCN·NO2·Ca(NO3)2
② KOH·CCl4·SF4
③ NaH·CaF2·NaNH2
④ CH2O·H2S·NH3

사고과정

④ CH2O·H2S·NH3 모두 공유 결합 분자. ① Ca(NO3)2·② KOH·③ NaH·CaF2·NaNH2는 이온 결합 포함. → ④

금속 양이온+음이온(또는 다원자 이온)이면 이온 결합. NaH(Na⁺H⁻)·NaNH2(Na⁺NH2⁻)도 이온 화합물이다.
문제 15전자 배치(W·X·Y·Z)정답 ③
W: 1s²3s¹ / X: 1s²2s²2p³ / Y: 1s²2s²2p⁶3s¹ / Z: 1s²2s²2p⁶3s²3p⁴(렌더 "3s4"). 옳은 것은?
① W는 바닥상태 전자배치이다.
② X의 원자가 전자수는 4개이다.
③ Y의 가장 안정한 이온은 Y⁺이다.
④ Y는 Z보다 홀전자수가 많다.

사고과정

③ Y = Na(1s²2s²2p⁶3s¹) → 전자 1개 잃은 Y⁺(Na⁺)이 가장 안정. → ③

① W는 2s 건너뛴 들뜬상태. ② X(N)의 원자가 전자 5개. ④ Z(S, 3p⁴)는 홀전자 2개로 Y(Na, 1개)보다 많음.

Z는 렌더가 3s²3p⁴를 "3s4"로 누락. 황(S)은 3p⁴라 홀전자 2개, 나트륨(Na)은 3s¹이라 1개다.
문제 16최소 결합각(VSEPR)정답 ③
VSEPR 모형에서 가장 작은 결합각을 가지는 것은?
① NH4⁺
② BeCl2
③ PH3
④ NO3⁻

사고과정

NH4⁺ 109.5°·BeCl2 180°·NO3⁻ 120°. PH3는 고립쌍+큰 P 원자로 ~93.5°로 가장 작음. → ③

PH3는 NH3(107°)보다도 작다. 중심 원자가 클수록 s 성질이 줄어 결합각이 90°에 가까워진다.
문제 17쌍극자 모멘트 보유정답 ②
쌍극자 모멘트를 가지는 분자 또는 이온은?
① XeF4
② SO2
③ I3⁻
④ CO2

사고과정

SO2는 굽은형(고립쌍)이라 극성. XeF4(평면 사각)·I3⁻(직선)·CO2(직선)는 대칭이라 무극성. → ②

대칭 구조는 결합 쌍극자가 상쇄돼 무극성. 굽은형(SO2)은 상쇄되지 않아 쌍극자가 남는다.
문제 18C-O 결합 길이 순서정답 ②
탄소-산소 결합 길이가 짧은 것에서 긴 순으로 나열한 것은? (가. CO / 나. HCO2⁻ / 다. CH3CHO / 라. CH3OH)
① 가<나<다<라
② 가<다<나<라
③ 나<가<다<라
④ 다<가<라<나

사고과정

결합 차수↑면 길이↓: CO(≡, 3) > CH3CHO(=, 2) > HCO2⁻(공명, ~1.5) > CH3OH(−, 1). 짧은→긴: 가<다<나<라. → ②

결합 차수가 클수록 짧다. 폼산 이온(HCO2⁻)은 공명으로 차수 1.5라 이중결합(CH3CHO)보다 길고 단일결합보다 짧다.
문제 19사이안산 이온(NCO⁻)정답 ③
NCO⁻ 이온에 대해 옳은 것은? (① 결합각 120° / ② 동등한 공명 3개 / ③ C-N이 CN⁻보다 길다 / ④ NO2와 같은 기하)
① 세 원자가 이루는 결합각은 120°이다.
② 세 개의 동등한 루이스 구조를 갖는다.
③ C-N 결합 길이는 CN⁻보다 길다.
④ NO2와 같은 형태의 기하구조이다.

사고과정

③ NCO⁻는 직선형. C-N이 공명으로 차수 ~2.5라 CN⁻(삼중결합)보다 길다. → ③

① 직선형이라 180°. ② 공명 구조가 동등하지 않음. ④ NCO⁻ 직선 vs NO2 굽은형.

NCO⁻는 CO2와 등전자라 직선. C-N이 완전한 삼중결합(CN⁻)이 아니므로 더 길다.
문제 20분자간 힘 종합정답 ③
옳은 것은? (가. CO2·P4·S8의 분자간 힘은 쌍극자-쌍극자 / 나. OCS>CO2 분자간 힘 / 다. H2O가 HF·NH3보다 끓는점↑ / 라. N2·CO·CO2 중 CO2 어는점 최저)

② 가, 다
③ 나, 다
④ 다, 라

가 무극성 분자라 분산력(쌍극자 아님). 라 CO2가 가장 무거워 어는점 최고(N2가 최저). 나 OCS는 극성+더 무거움. 다 H2O 끓는점(100°C)>HF>NH3. → ③

문제 21공명·고립쌍·단위세포 합정답 ③
㉠+㉡+㉢은? (가. NO3⁻의 동등 공명 ㉠개 / 나. SF3⁺의 황은 ㉡쌍의 비공유전자 / 다. NaCl 단위세포 속 소듐이온 ㉢개)
① 6
② 7
③ 8
④ 9

시간 ∝ 흡수열. 얼음(−50→0) 50×37.9 = 1895, 융해(0°C) 6010(가장 김), 물(0→50) 50×75.3 = 3765 J/mol. 얼음이 물보다 가파르게(빨리) 오르고 0°C 정체가 가장 긴 ①. → ①

비열이 작을수록(얼음 37.9<물 75.3) 같은 열로 온도가 빨리 올라 기울기가 가파르다. 융해 구간은 온도 일정(정체).
문제 44속력 분포(틀린 것)정답 ④
기체 분자 속력 분포 곡선 A·B·C(A가 저속·고봉, C가 고속·저봉). 옳지 않은 것은? (④ 같은 온도면 C의 평균 운동E 최대)
① 같은 분자면 A의 온도가 가장 낮다.
② 같은 온도의 다른 분자면 C의 분자량이 가장 작다.
③ 같은 분자면 A 상태의 반응속도가 가장 느리다(1차 반응).
④ 같은 온도의 다른 분자면 C의 평균 운동E가 가장 크다.

사고과정

④ 같은 온도면 평균 운동에너지는 모두 같음((3/2)kT, 종류 무관). C가 최대 아님. 틀림. → ④

①(A 저속=저온)·②(같은 온도서 빠른 C=가벼움)·③(A 저온이라 반응 최저)는 옳음.

평균 운동에너지는 온도만의 함수. 가벼운 분자(C)는 더 빠르지만 평균 운동에너지는 무거운 분자와 같다.
문제 45상평형 그림정답 ③
어떤 분자의 상평형 그림(고체-액체 경계 음의 기울기). 옳은 것은? (① P1서 승화 불가 / ② P3서 융해 시 부피 증가 / ③ 압력↑ 시 기체→고체→액체 가능 / ④ P2서 끓는점 T2)
① 외부 압력 P1에서 승화가 일어날 수 없다.
② 외부 압력 P3에서 융해 시 부피가 증가한다.
③ 특정 온도서 압력↑면 기체→고체→액체 순 상변화 가능.
④ 외부압력 P2일 때 끓는점은 T2이다.

사고과정

고체-액체 경계가 음의 기울기(액체가 더 조밀, 물형). ③ 압력↑면 더 조밀한 액체로 가므로 기체→고체→액체 가능. → ③

① P1(삼중점 아래)서 승화 가능. ② 융해 시 부피 감소(액체 조밀). ④ P2(≈삼중점)서 끓는점은 T2가 아님.

고체-액체 경계의 음의 기울기는 물의 특징(얼음이 물에 뜸). 압력을 가하면 고체가 액체로 녹는다.
문제 46토리첼리 기압계정답 ④
토리첼리 실험서 수은 기둥 76cm. 옳은 것은? (① 지름 2배면 38cm / ② 물도 76cm / ③ 달서 6배 / ④ 진공부에 질소면 76cm보다 작아짐)
① 지름 2배 유리관이면 수은 기둥 38cm.
② 물로 해도 76cm로 동일.
③ 중력 1/6인 달에서 6배가 된다.
④ 진공부(A-C)가 질소로 채워지면 76cm보다 작아진다.

사고과정

④ 진공이어야 할 윗공간에 N2가 있으면 그 압력이 수은을 눌러 기둥이 76cm보다 낮아짐. → ④

① 기둥 높이는 관 지름과 무관(76cm). ② 물은 밀도 1/13.6이라 ~10m. ③ 기압도 g에 비례해 상쇄(76cm 유지).

기압계 높이는 압력 균형(P=ρgh)으로 결정. 단면적·관 모양과 무관하고, 윗공간 기체 압력이 있으면 기둥이 낮아진다.
문제 47라울 법칙·분자량정답 ②
액체 A·B 증기압 a·2a. A 0.8몰+B 1몰+용질 C 20g 용액서 평형 B 증기압이 a. C의 분자량(g/mol)은? (C 비전해질·비휘발성)
① 20
② 100
③ 200
④ 500

사고과정

PB = xB×2a = a → xB = 0.5. xB = 1/(0.8+1+nC) = 0.5 → 1.8+nC = 2 → nC = 0.2몰. 분자량 = 20/0.2 = 100. → ②

비휘발성 용질 C는 증기압엔 기여 안 하지만 몰분율을 낮춘다. 라울 법칙으로 xB를 구해 C 몰수를 역산.
문제 48반응 속도(틀린 것) (복수정답)복수정답 ③④
NH4⁺+NO2⁻→N2 초기 속도 [실험1 (0.12,0.10)→3.6×10⁻⁶ / 실험2 (0.24,0.10)→7.2×10⁻⁶ / 실험3 (0.12,0.20)→7.2×10⁻⁶]. 옳지 않은 것은?
① NH4⁺+NO2⁻→N2+2H2O.
② NH4⁺ 반응차수는 1이다.
③ NO2⁻ 반응차수는 2이다.
④ 반응속도상수 k는 3.0×10⁻⁴ M⁻¹·(단위) 이다.

사고과정

이 문항은 원본 시험에서 복수정답 ③④로 처리되었다(옳지 않은 것이 둘).

실험 1→2: NH4⁺ 2배에 속도 2배(차수 1). 실험 1→3: NO2⁻ 2배에 속도 2배(차수 1). ③ NO2⁻ 차수는 1(2 아님) → 틀림. ④ k = 3.6×10⁻⁶/(0.12×0.10) = 3.0×10⁻⁴로 값은 맞으나 단위 표기 오류(2차라 M⁻¹·s⁻¹여야 함) → 틀림.

①(균형식 N·H·O·전하 일치)·②(NH4⁺ 차수 1)는 옳음. 전체 2차 반응이라 k 단위는 M⁻¹·s⁻¹. ③·④ 둘 다 옳지 않아 복수정답.
문제 49반감기(1차 붕괴)정답 ②
라돈-222의 방사성 붕괴 속도 상수 k=0.181 일⁻¹. 반감기에 가장 가까운 값은? (ln2=0.693)
① 2일
② 4일
③ 8일
④ 16일

사고과정

1차 반응 반감기 t½ = ln2/k = 0.693/0.181 = 3.83일 ≈ 4일. → ②

문제 50반응 메커니즘(2단계)정답 ④
2단계 반응(k1≪k2). 옳은 것은? (가. NO3는 중간체 / 나. NO3는 1단계서 빠르게 생성·2단계서 느리게 소모 / 다. 1단계가 속도결정 / 라. 전체 속도=k1[NO2]²)
① 가, 나
② 가, 다
③ 나, 다, 라
④ 가, 다, 라

사고과정

k1≪k2라 1단계가 느림(속도결정). 가 NO3는 중간체. 다 1단계 속도결정. 라 속도=k1[NO2]². 나 NO3는 1단계서 느리게 생성·2단계서 빠르게 소모(반대). → ④

k가 작은 단계가 느린 속도결정 단계. 그 단계의 반응물 농도로 전체 속도식이 결정된다.
문제 51단위세포·화학식(Ti·O)정답 ④
Ti·O 단위세포: O 4개는 면·2개는 내부, Ti는 꼭짓점과 내부에 존재. 이 고체의 화학식은?
① TiO
② Ti2O3
③ Ti3O4
④ TiO2

사고과정

O = 면 4×(1/2) + 내부 2×1 = 4. Ti = 꼭짓점 8×(1/8) + 내부 1×1 = 2. Ti:O = 2:4 = 1:2 → TiO2. → ④

면 중심 원자는 1/2, 꼭짓점 원자는 1/8, 내부 원자는 1로 센다. 단위세포 내 비율이 화학식.
문제 52속도 상수 비교(Ea)정답 ①
3가지 반응 에너지 단면도(정반응 Ea: (a)30·(b)50·(c)40 kJ/mol). 정반응 속도 상수가 큰 것부터 작은 순은? (아레니우스 상수 동일)
① (a)>(c)>(b)
② (a)>(b)>(c)
③ (c)>(b)>(a)
④ (b)>(c)>(a)

사고과정

k = A·e−Ea/RT이라 Ea가 작을수록 k가 큼. 정반응 Ea: (a)30 < (c)40 < (b)50 → k는 (a)>(c)>(b). → ①

속도 상수는 정반응 활성화에너지(봉우리까지의 높이)로 결정. ΔH(반응열)는 속도와 무관하다.
문제 53적정 지시약정답 ①
0.1M 아세트산(Ka=1.8×10⁻⁵) 50mL를 0.1M NaOH로 적정할 때 가장 적절한 지시약은?

약산+강염기 적정의 당량점은 염기성(아세테이트 가수분해, pH ~8.7). 변색 범위가 염기성인 페놀프탈레인(pH 8.2~10)이 적절. → ①

문제 54평형·속도 개념정답 ②
옳은 것은? ((가) K가 클수록 평형 도달 시간 오래 / (나) 반응 속도는 활성화에너지에 의존 / (다) 온도↑면 발열 반응 K 증가)
① (가)
② (나)
③ (가),(다)
④ (나),(다)

사고과정

(나) 반응 속도는 활성화에너지에 의존(옳음). (가) K(평형 위치)는 도달 시간(속도론)과 무관. (다) 발열 반응은 온도↑면 K 감소. → ②

K는 열역학(평형 위치), 속도는 속도론으로 별개. 발열 반응은 열을 생성물로 보면 온도↑서 역방향(K↓).
문제 55용해도·공통 이온정답 ②
Ba(IO3)2 Ksp=4×10⁻⁹, AgIO3 Ksp=9×10⁻⁸. 몰용해도는 Ba(IO3)2가 AgIO3보다: 순수 물서 (가), 0.1M NaIO3서 (나)?
① (가)크다 (나)크다
② (가)크다 (나)작다
③ (가)작다 (나)크다
④ (가)작다 (나)작다

사고과정

순수 물: Ba(IO3)2 s=(Ksp/4)1/3=10⁻³ > AgIO3 s=√(9×10⁻⁸)=3×10⁻⁴ → (가) 크다.

0.1M NaIO3([IO3⁻]=0.1): Ba(IO3)2 s=4×10⁻⁹/0.01=4×10⁻⁷ < AgIO3 s=9×10⁻⁸/0.1=9×10⁻⁷ → (나) 작다. → ②

Ba(IO3)2는 IO3⁻를 2개 내놓아 [IO3⁻]² 항으로 공통 이온 효과를 더 크게 받아 용해도가 역전된다.
문제 56평형 이동(틀린 것)정답 ④
CH4+I2⇌CH3I+HI (630K Kp=2.3×10⁻⁴, 730K 9.7×10⁻⁴). 옳지 않은 것은? (④ 전체 압력 일정 유지하며 비활성기체 첨가 시 오른쪽 이동)
① 630K서 Kc=2.3×10⁻⁴이다.
② HI를 가하면 평형은 왼쪽으로 이동.
③ 온도를 높이면 평형은 오른쪽으로 이동.
④ 전체 압력 일정 유지하며 비활성기체 첨가 시 오른쪽 이동.

사고과정

기체 몰수 변화 Δn=0(양변 2몰). ④ Δn=0이라 비활성기체 첨가(부피 변화)에도 평형 불변(이동 없음). 틀림. → ④

①(Δn=0이라 Kp=Kc)·②(HI 생성물 추가→왼쪽)·③(온도↑서 K↑이라 흡열·오른쪽)는 옳음.

Δn=0인 반응은 압력·부피·비활성기체 변화에 평형이 영향받지 않는다.

② 가>다>나
③ 다>가>나
④ 다>나>가

모두 완충용액. pH = pKa+log([A⁻]/[HA]). (다) 산1:염2 → pKa+log2 = 5.04. (가) 산1:염1 → pKa = 4.74. (나) 산2:염1 → pKa+log(1/2) = 4.44. → ③

문제 58이온 농도 순서정답 ①
0.1M 아세트산 50mL에 0.1M NaOH 55mL를 가했을 때 이온 농도가 높은 것부터 나타낸 것은?
① [Na⁺]>[CH3COO⁻]>[OH⁻]>[H3O⁺]
② [Na⁺]>[OH⁻]>[CH3COO⁻]>[H3O⁺]
③ [Na⁺]>[OH⁻]>[H3O⁺]>[CH3COO⁻]
④ [CH3COO⁻]>[Na⁺]>[OH⁻]>[H3O⁺]

사고과정

아세트산 5mmol + NaOH 5.5mmol → 아세테이트 5mmol 생성 + NaOH 0.5mmol 과량. Na⁺ 5.5 > CH3COO⁻ ~5 > OH⁻ 0.5(과량) > H3O⁺(미량, 염기성). → ①

강염기가 과량이라 OH⁻가 H3O⁺보다 많다. Na⁺(구경꾼)가 가장 많고, 전하 균형 [Na⁺]=[CH3COO⁻]+[OH⁻]−[H3O⁺]도 성립.
문제 59압력 평형 상수 Kp정답 ④
2XY(g)+Z2(g)⇌2XYZ(g), 298K Kp=1.0×10³. 평형서 PXY=5.0×10⁻²·PZ2=4.0×10⁻¹ atm일 때 PXYZ는?
① 0.001
② 0.01
③ 0.1
④ 1.0 atm

사고과정

Kp = PXYZ²/(PXY²·PZ2). PXYZ² = 10³×(5×10⁻²)²×(4×10⁻¹) = 10³×2.5×10⁻³×4×10⁻¹ = 1.0 → PXYZ = 1.0 atm. → ④

Kp 식에 평형 분압을 대입해 미지 분압을 푼다. 계수(2·1·2)가 지수로 들어가는 데 주의.
문제 60침전·이온 농도 (결함 문항)정답 ①
AgCl(Ksp=1.6×10⁻¹⁰). 0.10M AgNO3 100mL + 0.30M CaCl2 100mL 혼합. 침전된 AgCl 질량과 용액 속 [Cl⁻]는? (AgCl 몰질량 143)
① AgCl 1.43g, [Cl⁻]=0.1M
② AgCl 1.43g, [Cl⁻]=0.2M
③ AgCl 14.3g, [Cl⁻]=0.1M
④ AgCl 14.3g, [Cl⁻]=0.2M

사고과정

Ag⁺ = 0.10×100 = 10mmol(한계), Cl⁻ = 2×(0.30×100) = 60mmol. AgCl 침전 = 10mmol → 질량 = 10×143 = 1.43g(확정).

잔여 Cl⁻ = 60−10 = 50mmol, 전체 부피 200mL → [Cl⁻] = 50/200 = 0.25M(원본 공식 풀이도 0.25M로 동일 계산).

⚠️ 결함 문항: 정확한 [Cl⁻]=0.25M이 선택지에 없다(①②는 0.1·0.2M). 원본 채점표는 ①로 처리했으나(질량 1.43g 일치) [Cl⁻] 값은 어느 선택지와도 맞지 않는다. 채점 기준(정답표)을 따라 ①로 표기한다.

AgCl 질량(1.43g)은 명확해 ①·② 중 하나. CaCl2는 Cl⁻를 2개 내놓아 잔여 Cl⁻ 50mmol·0.25M이 옳으나 선택지에 없어 결함이다.
