문제 1유효숫자정답 ③

사고과정

X 부피 = 28.0−25.0 = 3.0mL(뺄셈이라 소수 첫째 자리, 2유효숫자).

밀도 = 9.00/3.0 = 3.0 g/mL(2유효숫자).

→ ③

뺄셈은 소수 자릿수 기준. 3.0(2자리)이 제한해 밀도도 2유효숫자로 3.0으로 적는다.
문제 2질량비정답 ①

사고과정

H/C: X = 0.5/6.0 = 0.083, Y = 0.9/5.6 = 0.161.

비율 N = 0.161/0.083 ≈ 2(배수 비례).

벤젠 C6H6의 H/C = 6/72 = 0.083 → X가 벤젠.

→ ①

같은 C 질량당 H 질량의 정수비가 배수 비례. 벤젠(CH 실험식, H/C=0.083)과 일치하는 X가 답.
문제 3물질의분류정답 ①

사고과정

㉠ 합성가스는 CO와 H2의 혼합물(화합물 아님).

㉡ 수성가스 전환: CO+H2O→CO2+H2.

→ ①

합성가스(syngas)는 두 기체가 섞인 혼합물. 수성가스 전환은 CO를 CO2로 바꾸며 수소를 추가 생산한다.
문제 4농도정답 ②

사고과정

10mg/dL = 10mg/100mL = 0.1mg/mL.

0.1mg/mL×0.5mL = 0.05mg = 50 μg.

→ ②

1 dL = 100 mL 환산이 핵심. 농도×부피로 질량을 구한 뒤 mg→μg(×1000) 변환.
문제 5고체의구조정답 ②

사고과정

가 이온 결정은 부서지기 쉬움(전성 작음). 라 C≡C는 σ 1개+π 2개(반대). 나 암염(NaCl)형 구조. 다 C2²⁻([:C≡C:]²⁻)은 sp 혼성, 고립쌍이 sp 궤도에. → ②

아세틸리드 이온 C2²⁻는 N2와 등전자(삼중결합+양 끝 고립쌍). 이온 결합은 충격에 층이 어긋나 깨진다.
문제 6오비탈정답 ③

사고과정

가 2s는 봉우리 2개 = 주양자수 n(=2). 다 두 봉우리 사이 마디(1Å)서 확률 0. 나 이건 한 전자의 확률 분포이지 두 전자의 고정 위치가 아님. → ③

방사 확률 분포는 한 전자를 거리별로 발견할 확률. ns 오비탈의 봉우리 수는 n개, 마디(확률 0)는 (n−1)개.
문제 7쌍극자모멘트정답 ④

사고과정

BF3·SO3는 평면 삼각(대칭) → 쌍극자 0.

PH3·NH3는 삼각뿔(극성)인데 NH3가 N-H 결합 극성이 커 쌍극자 최대(~1.47D).

→ ④

대칭 평면 분자는 무극성. 같은 삼각뿔이라도 결합 극성이 큰 NH3가 PH3(P·H 전기음성도 비슷)보다 쌍극자가 크다.
문제 8전자배치정답 ③

사고과정

a = 4f 최대 = 14.

b: n=3·ml=−1은 3p·3d 2개 궤도 → 2×2 = 4.

c: Mn [Ar]3d54s2의 3d5 → 홀전자 5.

합 = 14+4+5 = 23.

→ ③

f 부껍질 14개. 특정 ml 값은 해당 l 이상의 부껍질마다 한 궤도씩(n=3서 p·d). Mn은 3d 반채움이라 홀전자 5개.
문제 9유효핵전하정답 ②

사고과정

② 같은 족 반지름 증가는 전자 껍질(n) 추가가 주원인이지 유효 핵전하 변화가 아님. → ②

①(주기 내 Zeff↑→반지름↓)·③(등전자서 핵전하↑→이온↓)·④(전자 잃을수록 남은 전자의 Zeff↑)는 모두 유효 핵전하 관련.

같은 족을 내려가면 주양자수가 커져 반지름이 증가. 유효 핵전하는 같은 주기·등전자 비교에서 핵심 인자다.
문제 10주기율정답 ④

사고과정

가 제1 IE 최대는 Ne(F 아님). 라 홀전자 최대는 N(2p³ 3개, F는 2p⁵ 1개). 나 2주기서 전자친화도 최대(F). 다 전기음성도 최대(F). → ④

F는 전기음성도·전자친화도 1위지만, 1차 이온화 E는 Ne(비활성)이 더 크고 홀전자는 반채움 N이 가장 많다.
문제 11원자의구성정답 ①

사고과정

가 ¹H(수소-1)은 중성자 0. 나 ¹⁴C 등 중성자가 더 많은 핵 존재. 다 양성자·중성자 질량은 거의 같으나 동일하지 않음(중성자가 약간 무거움). 라 전자도 질량 있음(양성자의 약 1/1836). → ①

수소-1만 중성자가 없다. 양성자와 중성자는 비슷하지만 미세하게 다르고, 전자 질량은 작지만 0이 아니다.
문제 12전자배치정답 ②

사고과정

Cr3+: [Ar]3d3(4s 먼저·이어 3d 2개 제거) → 홀전자 3.

Cu+: [Ar]3d10(4s 제거) → 홀전자 0.

합 = 3.

→ ②

전이 금속 양이온은 4s 전자를 먼저 잃는다. Cr3+는 3d3(홀전자 3), Cu+는 3d10(채워져 홀전자 0).
문제 13수소원자정답 ②

사고과정

M껍질(n=3) = −E → En = −RH/n²서 RH = 9E. 나 K껍질(n=1) = −9E. 가 수소는 2s·2p가 축퇴(에너지 같음). 다 라이먼 한계(∞→1) = RH = 9E(5E 아님). → ②

단일 전자 수소는 에너지가 n에만 의존(2s=2p). En=−9E/n²이라 K(n=1)=−9E, 라이먼 한계는 9E.
문제 14이온결합정답 ④

사고과정

④ CH2O·H2S·NH3 모두 공유 결합 분자. ① Ca(NO3)2·② KOH·③ NaH·CaF2·NaNH2는 이온 결합 포함. → ④

금속 양이온+음이온(또는 다원자 이온)이면 이온 결합. NaH(Na⁺H⁻)·NaNH2(Na⁺NH2⁻)도 이온 화합물이다.
문제 15전자배치정답 ③

사고과정

③ Y = Na(1s²2s²2p⁶3s¹) → 전자 1개 잃은 Y⁺(Na⁺)이 가장 안정. → ③

① W는 2s 건너뛴 들뜬상태. ② X(N)의 원자가 전자 5개. ④ Z(S, 3p⁴)는 홀전자 2개로 Y(Na, 1개)보다 많음.

Z는 렌더가 3s²3p⁴를 "3s4"로 누락. 황(S)은 3p⁴라 홀전자 2개, 나트륨(Na)은 3s¹이라 1개다.
문제 16분자의모양정답 ③

사고과정

NH4+ 109.5°·BeCl2 180°·NO3- 120°.

PH3는 고립쌍+큰 P 원자로 ~93.5°로 가장 작음.

→ ③

PH3는 NH3(107°)보다도 작다. 중심 원자가 클수록 s 성질이 줄어 결합각이 90°에 가까워진다.
문제 17쌍극자모멘트정답 ②

사고과정

SO2는 굽은형(고립쌍)이라 극성. XeF4(평면 사각)·I3⁻(직선)·CO2(직선)는 대칭이라 무극성. → ②

대칭 구조는 결합 쌍극자가 상쇄돼 무극성. 굽은형(SO2)은 상쇄되지 않아 쌍극자가 남는다.
문제 18결합길이정답 ②

사고과정

결합 차수↑면 길이↓: CO(≡, 3) > CH3CHO(=, 2) > HCO2-(공명, ~1.5) > CH3OH(−, 1).

짧은→긴: 가<다<나<라.

→ ②

결합 차수가 클수록 짧다. 폼산 이온(HCO2-)은 공명으로 차수 1.5라 이중결합(CH3CHO)보다 길고 단일결합보다 짧다.
문제 19형식전하정답 ③

사고과정

③ NCO⁻는 직선형. C-N이 공명으로 차수 ~2.5라 CN⁻(삼중결합)보다 길다. → ③

① 직선형이라 180°. ② 공명 구조가 동등하지 않음. ④ NCO⁻ 직선 vs NO2 굽은형.

NCO⁻는 CO2와 등전자라 직선. C-N이 완전한 삼중결합(CN⁻)이 아니므로 더 길다.
문제 20극성정답 ③

사고과정

가 무극성 분자라 분산력(쌍극자 아님). 라 CO2가 가장 무거워 어는점 최고(N2가 최저). 나 OCS는 극성+더 무거움. 다 H2O 끓는점(100°C)>HF>NH3. → ③

무극성 분자(CO2·P4·S8)는 분산력만. 분산력은 분자량이 클수록 강해 CO2의 어는점이 N2·CO보다 높다.
문제 21고체의구조정답 ③

㉠ NO3- 동등 공명 3개.

㉡ SF3+(S: 결합 3+고립쌍 1) → 1쌍.

㉢ NaCl 단위세포 Na+ 4개.

문제 22격자에너지정답 ②

사고과정

격자 에너지 ∝ (전하 곱)/(이온 거리).

MgCl2(Mg2+, 전하 최대)이 최고.

+1 염은 이온이 작을수록↑: KBr<KCl<LiCl.

→ ②

전하가 가장 큰 영향(Mg2+). 같은 +1 중에선 작은 이온일수록 격자 에너지가 크다(Li+<K+ 크기, Cl-<Br- 크기).
문제 23형식전하정답 ①

→ ①

S2O32-는 SO42-의 O 하나를 S로 바꾼 구조. 중심 S가 이중결합을 가져야 형식 전하 합이 가장 작아진다.
문제 24흡광도정답 ④

사고과정

④ (나)는 ~600nm(주황) 흡수 → 보색인 파란색으로 보임. → ④

① (가)는 녹색 흡수 → 보색(자홍)으로 보임. ②·③ (가)가 단파장(고에너지) 흡수 → 띠간격 큼 = 더 작은 입자. (나)가 더 크고 띠간격 작다.

관찰 색 = 흡수 색의 보색. 양자점은 작을수록 띠간격이 커져 짧은 파장(고에너지)을 흡수한다.
문제 25계수맞추기정답 ③

사고과정

P 균형: 3+a = 5×2 = 10 → a = 7.

H 균형: 1+3(7)+2b = 5×6 = 30 → 22+2b = 30 → b = 4.

a+b = 11.

→ ③

먼저 한 원소(P)로 a를 구하고, 그다음 H로 b를 구한다. O까지 맞으면(45=45) 검산 완료.
문제 26반트호프인자정답 ②

사고과정

ΔTf ∝ i×m. ① 0.10×4 = 0.40. ② 0.20×3 = 0.60. ③ 0.30×1 = 0.30. ④ 0.40×1 = 0.40. 최대(0.60)인 MgCl2가 어는점 최저. → ②

어는점 내림은 입자 수(i×몰랄농도)에 비례. 비전해질(글루코오스·수크로스)은 i=1, MgCl2는 i=3.
문제 27산화수정답 ④

사고과정

가 Li(+1)·나 H(−1, 금속수소화물)·다 O(−1, 과산화물)·라 H(0, 홑원소). 나·다가 모두 −1. → ④

금속수소화물(NaH)의 H는 −1, 과산화물(H2O2)의 O는 −1로 예외적 산화수다.
문제 28농도전환정답 ①

사고과정

1L 질량 = 1000×1.133 = 1133g.

H2O2 = 0.30×1133 = 340g → 340/34 = 10몰.

몰농도 = 10M.

→ ①

1L 기준 용액 질량(부피×밀도)→용질 질량(×질량%)→몰수(÷몰질량) 순으로 몰농도를 구한다.
문제 29수득률정답 ②

사고과정

TiCl4 0.10몰·Mg 0.10몰.

0.10몰 TiCl4엔 Mg 0.20몰 필요한데 0.10몰뿐 → Mg 한계.

이론 Ti = 0.10×(1/2)×47.9 = 2.395g.

수득률 = 2.156/2.395 = 90%.

→ ②
