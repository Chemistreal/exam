문제 1중합체 단위체정답 ②
다음 중 세 가지 이상의 다른 종류의 단위체로 이루어진 중합체는?
① 천연고무
② 핵산
③ 테플론
④ 셀룰로오스

사고과정

천연고무(아이소프렌 1종)·테플론(테트라플루오로에틸렌 1종)·셀룰로오스(글루코스 1종)는 단일 단위체.

핵산은 4종류 뉴클레오타이드(A·T/U·G·C)로 구성 → 3종 이상. → ②

대부분의 합성·천연 고분자는 한 종류 단위체. 핵산·단백질만 여러 종류 단위체(염기·아미노산)로 정보를 담는다.
문제 2분자간 힘 세기 순서정답 ②
다음 점선으로 표시한 상호작용 중 두 번째로 강한 것은? (① CH4⋯CH4 / ② H2O⋯H2O / ③ Li+⋯H2O / ④ CHCl3⋯CHCl3)
① CH4⋯CH4
② H2O⋯H2O
③ Li+⋯H2O
④ CHCl3⋯CHCl3

사고과정

세기: 이온-쌍극자(Li+-H2O) > 수소결합(H2O-H2O) > 쌍극자-쌍극자(CHCl3) > 분산력(CH4).

두 번째로 강함 = H2O⋯H2O(수소결합). → ②

분자간 힘 위계: 이온-쌍극자 > 수소결합 > 쌍극자-쌍극자 > 분산력. 1위는 Li+(이온)이 낀 ③.
문제 3끓는점 최고정답 ②
다음 중 끓는점이 가장 높은 화합물은? (① 에탄올 CH3CH2OH / ② 아세트산 CH3COOH / ③ 아세트알데하이드 CH3CHO / ④ 다이메틸에터 CH3OCH3)
① 에탄올
② 아세트산
③ 아세트알데하이드
④ 다이메틸에터

사고과정

아세트산(−COOH)은 이합체(dimer)로 수소결합 2개를 형성 → 끓는점 최고(118°C).

에탄올(78°C, −OH 1개) > 아세트알데하이드(20°C, 케톤형) > 다이메틸에터(−24°C, 에터). → ②

카복실산은 −COOH끼리 두 줄의 수소결합으로 이합체를 만들어, 같은 크기 알코올보다도 끓는점이 훨씬 높다.
문제 4끓는점 경향 · 수소결합 이상정답 ③
다음 중 끓는점의 순서가 옳은 것은?
① H2O < H2S < H2Se < H2Te
② NH3 < PH3 < AsH3 < SbH3
③ He < Ne < Ar < Kr < Xe
④ HF < HCl < HBr < HI

사고과정

①②④ H2O·NH3·HF는 수소결합으로 끓는점이 이상하게 높아 최저가 아니다(순서가 깨짐).

③ 비활성기체는 수소결합이 없어 분자량↑(분산력↑)에 따라 단조 증가: He < Ne < Ar < Kr < Xe. → ③

2주기 H 화합물(H2O·NH3·HF)은 수소결합으로 끓는점이 튄다. 분산력만 작용하는 비활성기체만 깔끔히 단조 증가.
문제 5끓는점 증가 순서정답 ②
KBr, C2H5OH, C2H6, He를 끓는점이 증가하는 순서로 나열하면?
① He < C2H5OH < C2H6 < KBr
② He < C2H6 < C2H5OH < KBr
③ KBr < C2H6 < C2H5OH < He
④ KBr < C2H6 < He < C2H5OH

사고과정

He(분산력, 최저) < C2H6(분산력) < C2H5OH(수소결합) < KBr(이온결합, 최고). → ②

결합 세기: 이온(KBr) ≫ 수소결합(에탄올) > 분산력(He·에테인). 분산력은 분자량이 큰 에테인이 He보다 강하다.
문제 6끓는점 증가 순서정답 ②
메탄올·에탄올·에틸에테르·아세톤의 끓는점이 증가하는 순서로 맞는 것은?
① 메탄올 < 에탄올 < 에틸에테르 < 아세톤
② 에틸에테르 < 아세톤 < 메탄올 < 에탄올
③ 아세톤 < 에틸에테르 < 메탄올 < 에탄올
④ 아세톤 < 에틸에테르 < 에탄올 < 메탄올

사고과정

에틸에테르(35°C)·아세톤(56°C)은 수소결합 없음(에터·케톤). 메탄올(65°C)·에탄올(78°C)은 −OH 수소결합.

에틸에테르 < 아세톤 < 메탄올 < 에탄올. → ②

수소결합 유무로 먼저 두 그룹을 나누고, 그 안에서 분자량·극성으로 세분한다. 알코올끼리는 메탄올 < 에탄올.
문제 7끓는점 순서정답 ③
C6H6, C6H5OH, C6H5Cl, C6H5Br를 끓는점이 낮은 것부터 높은 순서로 나열한 것은?
① C6H6 < C6H5Br < C6H5Cl < C6H5OH
② C6H5Cl < C6H5Br < C6H5OH < C6H6
③ C6H6 < C6H5Cl < C6H5Br < C6H5OH
④ C6H6 < C6H5OH < C6H5Br < C6H5Cl

사고과정

C6H6(무극성, 80°C) < C6H5Cl(극성, 132°C) < C6H5Br(더 무거움, 156°C) < C6H5OH(−OH 수소결합, 182°C). → ③

벤젠 고리에 −OH가 붙은 페놀만 수소결합으로 끓는점이 가장 높다. 할로젠은 Cl < Br 순(분산력↑).
문제 8HF의 성질정답 ④
플루오린화 수소(HF)에 해당하는 설명을 모두 고른 것은? (가. 할로젠화 수소 중 가장 높은 끓는점 / 나. 수소결합 가능 / 다. 할로젠화 수소 중 가장 약한 산 / 라. 규소 산화물 유리를 녹임)
① 가, 나
② 가, 다
③ 나, 다, 라
④ 가, 나, 다, 라

사고과정

가(수소결합으로 끓는점 최고)·나(F−H⋯F 수소결합)·다(약산, HCl·HBr·HI는 강산)·라(SiO2 + 4HF → SiF4, 유리 부식) 모두 참. → ④

HF는 할로젠화수소 중 유일하게 약산이면서 끓는점은 가장 높다(수소결합 때문). 유리를 녹이는 특이 성질도 있다.
문제 9수소결합 에너지 크기정답 ④
HF 분자 간에 존재하는 가장 큰 분자간 힘의 크기(kJ/mol)로 가장 가까운 값은?
① 0.01
② 0.1
③ 1
④ 10

사고과정

HF의 수소결합 에너지는 약 10~40 kJ/mol(수소결합 중 가장 강함). 보기 중 10에 가장 가깝다. → ④

수소결합은 보통 10~40 kJ/mol로, 공유결합(수백 kJ/mol)보다 약하지만 분산력(수 kJ/mol)보다 강하다.
문제 10이성질체 끓는점정답 ①
A(네오펜테인 C(CH3)4), B(n-펜테인 CH3(CH2)3CH3)에 대한 옳은 것을 모두 고른 것은? (가. A의 끓는점이 B보다 높다 / 나. A와 B는 이성질체이다 / 다. 두 화합물 모두 수소결합 가능)
① 나
② 가, 나
③ 나, 다
④ 가, 다

사고과정

나 둘 다 C5H12 → 구조 이성질체. 가 가지 달린 네오펜테인(A, 9°C)은 표면 접촉이 적어 끓는점이 낮다(B n-펜테인 36°C). 다 둘 다 알케인이라 −OH 없음 → 수소결합 불가. → ①

같은 분자식이라도 가지가 많을수록(구형) 분자간 접촉면이 줄어 분산력↓ → 끓는점이 낮아진다. 알케인은 수소결합 불가.
문제 11수소 화합물 끓는점 그래프정답 ①
수소 화합물(H2O, HF, NH3, CH4, SiH4, GeH4)의 분자량-끓는점 관계에 대한 설명으로 옳은 것은?
① SiH4보다 GeH4 분자 사이의 분산력이 크다.
② 선형 분자 HF 사이에는 수소 결합력이 작용하지 않는다.
③ 전기음성도 차이가 클수록 수소 화합물의 끓는점이 높아진다.
④ 물의 끓는점이 높은 것은 분자 내 결합 에너지가 크기 때문이다.

사고과정

① GeH4는 SiH4보다 크고 무거워 분산력이 크다. → ①

② HF는 수소결합 함. ③ 끓는점은 분산력·분자량 등 복합 요인. ④ 물 끓는점은 분자 간 수소결합 때문(분자 내 결합 아님).

끓는점은 분자를 떼어내는 데 드는 에너지 = 분자 간 힘의 문제. 분자 내(공유)결합 세기와 혼동하면 안 된다.
문제 12기체 분자 운동론정답 ②
같은 몰 수의 N2, O2, H2, He 혼합물에 대해 옳지 않은 설명을 모두 고른 것은? (a. 운동에너지 크기 H2>He>N2>O2 순 / b. 탈출속도 11,000 m/s, 모든 기체가 종류 무관 이 속도의 분자 존재 가능 / c. 온도가 2배면 모든 기체 평균속도 2배)
① a, b
② a, c
③ b, c
④ a, b, c

사고과정

a 같은 온도면 평균 운동에너지 동일(3/2 kT, 질량 무관). H2>He>N2>O2는 속도 순서. c 평균속도 ∝ √T이라 T 2배면 √2배(2배 아님).

b 옳음: 분포의 꼬리 때문에 온도가 낮아도 매우 빠른 분자가 일부 존재 → 어떤 기체든 탈출속도 분자가 있을 수 있음. 따라서 틀린 것은 a·c → ②

같은 온도 = 같은 평균 KE. 맥스웰 분포는 꼬리가 있어 어떤 기체든 극히 빠른 분자가 일부 존재한다(b가 옳은 이유).
문제 13동일 T·P·V 비교정답 ②
온도·압력·부피가 동일한 질소(N2)와 암모니아(NH3) 기체에서 두 기체가 동일한 값을 가지는 것을 모두 고른 것은? (이상기체) (a. 분자수 / b. 질량 / c. 공유결합수 / d. 평균속력)
① a, b
② a, c
③ a, d
④ a, c, d

사고과정

PV=nRT라 같은 T·P·V면 몰수(분자수) 동일(a ✓). b 몰질량 다름(N2 28 vs NH3 17) → 질량 다름. d 평균속력 ∝ 1/√M → 다름.

c 분자당 공유 전자쌍: N2(삼중결합 3쌍) = NH3(N−H 3개) → 분자수 같으니 총 공유결합 수 동일. → ②

N≡N의 삼중결합은 공유 전자쌍 3개, NH3의 N−H 3개도 3쌍. 우연히 분자당 공유결합 수가 같아진다.
문제 14평균속도 · 분자량정답 ③
25°C에서 He의 평균분자속도가 1300 m/s일 경우, H2의 평균분자속도는?
① 650 m/s
② 919 m/s
③ 1838 m/s
④ 2600 m/s

사고과정

같은 온도에서 v ∝ 1/√M. v(H2) = v(He) × √(MHe/MH₂) = 1300 × √(4/2) = 1300√2 ≈ 1838 m/s. → ③

속도비 = √(몰질량 역비). H2(2)가 He(4)보다 √2배 빠르다.
문제 15그레이엄 확산 법칙정답 ②
동일 조건에서 기체 A가 질소보다 1.3배 빨리 확산할 때 기체 A는 무엇인가?
① 헬륨
② 메테인
③ 아르곤
④ 이산화탄소

사고과정

확산속도 ∝ 1/√M: √(28/MA) = 1.3 → MA = 28/1.69 ≈ 16.6.

M ≈ 16.6 → 메테인(CH4, 16). → ②

그레이엄 법칙: 가벼울수록 빨리 확산. 1.3배 빠르려면 몰질량이 28/1.3² ≈ 16.6 → CH4.
문제 16평균속력 · T·M정답 ②
100K에서 2L 용기의 산소 기체의 평균속력이 v이다. 400K에서 1L 용기의 수소 기체의 평균속력은? (이상기체)
① 4v
② 8v
③ 16v
④ 32v

사고과정

평균속력 ∝ √(T/M), 부피 무관. v'/v = √[(400/2)/(100/32)] = √(200×32/100) = √64 = 8. → ②

속력은 부피·압력과 무관하고 오직 T/M에 의존. 용기 크기(2L·1L)는 함정이다.
문제 17같은 질량 기체 비교정답 ④
일정 온도, 같은 크기 용기에 같은 질량의 질소와 산소를 각각 주입했다(이상기체). 옳은 것은?
① 두 용기에는 같은 수의 분자가 들어 있다.
② 산소 분자의 평균 속도는 질소 분자보다 크다.
③ 산소 분자의 평균 운동에너지는 질소 분자보다 더 크다.
④ 질소가 든 용기의 압력은 산소가 든 용기의 압력보다 더 높다.

사고과정

같은 질량이면 가벼운 N2(28)가 O2(32)보다 몰수가 많다. ① 분자수 다름. ② 무거운 O2가 더 느림. ③ 같은 온도라 운동에너지 동일.

④ PV=nRT, 같은 V·T → P ∝ n. N2 몰수↑ → 압력↑. → ④

같은 "질량"이면 가벼운 기체가 몰수가 많다. 몰수↑ → (같은 V·T에서) 압력↑. 운동에너지는 온도만의 함수.
문제 18속도 분포 그래프정답 ③
같은 온도에서 세 기체 (가)(좁고 느림)·(나)·(다)(넓고 빠름)의 속도 분포에 대해 옳지 않은 것은?
① (가)→(나)→(다)로 갈수록 기체의 분자량은 작다.
② (가)→(나)→(다)로 갈수록 기체는 더 빠르게 확산한다.
③ (가)→(나)→(다)로 갈수록 기체 분자의 운동 에너지는 커진다.
④ 온도가 높아지면 (가) 기체의 분포는 (나), (다)의 분포처럼 넓어진다.

사고과정

①(빠를수록 가벼움)·②(가벼울수록 빨리 확산)·④(가열하면 분포가 넓어짐)는 옳다.

③ 같은 온도면 평균 운동에너지 동일(3/2 kT). 분자량만 다를 뿐 에너지는 같다. → ③

같은 온도 = 같은 평균 KE. 분포가 다른 건 분자량 차이(가벼우면 빠르고 넓게 퍼짐)이지 에너지 차이가 아니다.

문제 47농도 단위 비교정답 ④

문제 48몰농도·몰랄농도 식정답 ①
분자량 M인 고체 m g을 부피 V mL 액체에 녹여 부피 V' mL가 되었다. 몰농도와 몰랄농도 식은? (순수 액체 밀도 d g/mL)
몰농도몰랄농도
①(1000m)/(MV')(1000m)/(MdV)
②(1000m)/(MdV)(1000m)/(MV')

몰수 = m/M. 몰농도 = 몰수/용액 부피(L) = (m/M)/(V'/1000) = 1000m/(MV').

몰랄농도 = 몰수/용매 질량(kg). 용매 질량 = dV g = dV/1000 kg → 1000m/(MdV). → ①

몰농도는 용액 전체 부피(V'), 몰랄농도는 용매 질량(dV) 기준. 분모가 다르다는 게 핵심.
문제 49ppb → 몰농도정답 ④

② a, c

문제 52몰랄농도 환산정답 ③
NaCl 수용액의 질량 분율이 13.0%이고 밀도가 1.10 g/mL일 때 이 용액의 몰랄농도는? (NaCl 58.5)
① 2.23
② 2.44
③ 2.55
④ 2.03

사고과정

몰랄농도 = 용질 몰수 / 용매 kg. 용액 100g 기준: NaCl 13g·물 87g. NaCl 몰수 = 13/58.5 = 0.2222몰, 물 = 0.087kg.

몰랄농도 = 0.2222 / 0.087 = 2.55 mol/kg → ③. (밀도 1.10은 미끼·몰랄농도엔 불필요)

문제 53온도 의존 농도정답 ④
다음 농도 중 온도에 따라 그 값이 변하는 것은?

③ 몰랄 농도
④ 몰 농도

문제 54침전 · 몰농도정답 ①
공장 폐수에 과량 Na2S를 가해 CuS(95.5)를 형성했다. 폐수 2.0L에서 0.019g CuS를 얻었다면 Cu(II) 이온의 몰농도는?
① 0.10 mM
② 0.15 mM
③ 0.20 mM
④ 0.25 mM

사고과정

CuS 몰수 = 0.019/95.5 ≈ 2.0×10⁻⁴ mol = Cu²⁺ 몰수. 농도 = 2.0×10⁻⁴/2.0L = 1.0×10⁻⁴ M = 0.10 mM. → ①

난용성 CuS로 Cu²⁺를 정량하는 침전 분석. CuS 1몰 = Cu²⁺ 1몰이므로 질량/몰질량/부피로 농도를 구한다.
문제 55침전 질량 · 한계반응물정답 ②
0.1M CoCl2 30mL와 0.2M NaOH 20mL를 혼합했더니 붉은색 침전 Co(OH)2(93)가 생겼다. 침전 질량과 가장 가까운 값은?
① 100mg
② 200mg
③ 300mg
④ 400mg

사고과정

CoCl2 + 2NaOH → Co(OH)2 + 2NaCl. CoCl2 3mmol, NaOH 4mmol → NaOH 한계(3몰 필요는 6mmol).

문제 56아이오딘 적정 · 역추적정답 ②
구리 광석 0.50g을 녹여 2Cu²⁺ + 5I⁻ → I3− + 2CuI, 이어 I3− + 2S2O32− → 3I− + S4O62−로 적정했다. 0.020M Na2S2O3 30.0mL가 필요. 광석 중 CuCO3(125)의 질량 백분율은?

문제 57증기압 내림 · 물 이동정답 ①

① (A)의 수면이 (B)의 수면보다 높아진다.
② (B)의 수면이 (A)의 수면보다 높아진다.
③ (A),(B) 두 용액의 수면 높이는 변화가 없다.

문제 60어는점 내림 · 총괄성정답 ③
