문제 2원자의크기정답 ②

주어진 것: CO2 13.5 cm3(0 °C·1기압 기준이 아니라 25 °C·1기압), 이것을 한 층으로 깔았을 때의 넓이를 묻는다.

1단계 — 분자 수를 센다.

n = PV/RT = 0.0135 ÷ (0.082 × 298) ≈ 5.5×10−4 mol N = 5.5×10−4 × 6.02×1023 ≈ **3.3×1020 개** 2단계 — 분자 하나가 차지하는 넓이를 잡는다.

CO2 의 지름은 약 0.3 nm = 3×10−10 m 이므로 한 분자의 단면적은 π(1.5×10−10)2 ≈ **7×10−20 m2** 3단계 — 곱한다.

3.3×1020 × 7×10−20 ≈ **23 m2** 보기는 1 · 10 · 100 · 1000 m2 라 자릿수로 고르는 문항이다.

23 m2 에 가장 가까운 것은 **10 m2**

→ ②

확인 필요 2026-09-05 정정: 옛 해설이 「한 분자의 넓이를 약 3×10⁻¹⁹ m² 로 보면 넓이 ≈ 100 m² 남짓이지만, 어림 자릿수로는 10 m² 쪽에 가깝다」고 적고 있었다. 100 을 어림해서 10 이 되지는 않는다. 어긋난 것은 단면적 쪽이다 — 3×10⁻¹⁹ m² 는 지름 0.6 nm 에 해당하고, CO₂ 의 지름은 그 절반인 약 0.3 nm 라 단면적은 약 7×10⁻²⁰ m² 다. 그것으로 다시 곱하면 약 23 m² 이고, 보기 1·10·100·1000 가운데 10 이 가장 가깝다. 정답 ②는 그대로다.
문제 3쌍극자모멘트정답 ①

주어진 것 CO2, O3, H2O, 아세톤(CH3COCH3) 네 분자의 쌍극자모멘트 크기를 견주는 문제다.

쓰는 법칙 분자의 쌍극자모멘트는 결합 쌍극자를 벡터로 더한 값이다.

결합 하나하나가 극성이어도 모양이 대칭이면 벡터 합이 0 이 되고, 결합이 약한 극성이어도 모양이 비대칭이면 값이 남는다.

1단계 CO2 는 중심 탄소에 비공유 전자쌍이 없어 O=C=O 직선형이다.

크기가 같고 방향이 정반대인 두 C=O 쌍극자가 완전히 상쇄되므로 μ = 0 이다.

2단계 O3 는 중심 산소에 비공유 전자쌍이 하나 있어 약 117° 로 굽어 있다.

세 원자가 모두 산소여도 형식전하가 중심 +1, 양 끝 0 과 −1 로 갈려 있고 모양이 굽어서 상쇄되지 않으므로 작은 값이 남는다.

μ = 0.53 D

다. 3단계 H2O 는 비공유 전자쌍 두 개 때문에 104.5° 로 굽었고 O−H 의 전기음성도 차(3.5 − 2.1 = 1.4)가 크다.

두 결합 쌍극자의 합이 그대로 남아 μ = 1.85 D

다. 4단계 아세톤은 C=O 하나가 매우 극성이고, 그 반대편에는 이를 상쇄해 줄 극성 결합이 없다(양옆의 메틸기는 탄소·수소라 거의 무극성이다).

μ = 2.9 D

다. 결론 0 < 0.53 < 1.85 < 2.9 이므로 CO2 < O3 < H2O < CH3COCH3 다.

→ ①

문제 7모양정답 ③

주어진 것 PH3, B2H6, NO2+, MnO4− 가운데 입체(모든 원자가 한 평면에 놓이지 않는 것)를 모두 고른다.

쓰는 법칙 중심 원자 둘레의 전자 영역(결합 + 비공유 전자쌍) 수로 모양을 정한다.

전자 영역이 2 개면 직선, 3 개면 평면삼각형, 4 개면 사면체 뼈대다.

사면체 뼈대에서 비공유 전자쌍이 하나면 삼각뿔, 둘이면 굽은 모양이 된다.

직선·평면삼각형·굽은 모양은 한 평면에 놓이므로 입체가 아니다.

1단계

가. PH3 — P 는 5 족이라 결합 3 개 + 비공유 전자쌍 1 개로 전자 영역이 4 개다.

삼각뿔이므로 입체다.

2단계

나. B2H6 — 붕소가 모자라는 전자를 수소 다리(3중심 2전자 결합)로 메운다.

각 붕소 둘레에 말단 H 2 개와 다리 H 2 개로 전자 영역이 4 개라 사면체꼴이고, 말단 H 4 개가 놓인 평면과 다리 H 2 개가 놓인 평면이 서로 수직이다.

입체다.

3단계

다. NO2+ — 전자 수가 CO2 와 같은 등전자 이온이다.

N 에 비공유 전자쌍이 없고 전자 영역이 2 개뿐이라 O=N=O 직선형이다.

직선은 평면 안에 들어가므로 입체가 아니다.

4단계

라. MnO4− — Mn 둘레에 산소 4 개, 비공유 전자쌍 없음으로 전자 영역이 4 개다.

정사면체이므로 입체다.

결론 가, 나, 라 다.

→ ③

문제 8발열반응정답 ③

주어진 것 네 가지 변화 가운데 계의 온도가 높아지는 것을 모두 고른다.

쓰는 법칙 계의 온도가 높아지려면 계 스스로 열을 내놓아야 한다.

곧 ΔH < 0 인 발열 변화를 찾는 문제다.

결합이 새로 생기면 에너지가 나오고(발열), 결합을 끊으려면 에너지를 넣어야 한다(흡열).

1단계

가. 기체의 용해 — 기체 분자가 용매 분자에게 붙들리며 새로 인력이 생기므로 에너지가 나온다.

발열이다.

탄산음료를 데우면 기포가 빠져나가는 것도 용해가 발열이라 온도를 올리면 역방향으로 밀리기 때문이다.

2단계

나. 광합성 — 6CO2 + 6H2O → C6H12O6 + 6O2 로, 빛 에너지를 받아 그 에너지를 포도당의 결합 속에 저장한다.

ΔH > 0 인 흡열이다.

3단계

다. 결합의 분해 — 결합 해리 에너지는 언제나 양수다.

어떤 결합이든 끊는 데는 에너지를 넣어야 하므로 흡열이다.

4단계

라. 에탄올의 산화반응 — C2H5OH + 3O2 → 2CO2 + 3H2O, ΔH = −1367 kJ/mol 인 발열이다.

알코올램프가 뜨거운 것이 그 증거다.

결론 발열은 가와 라다.

→ ③

문제 14배위수정답 ①

주어진 것 한 변이 a 인 정육면체에서 A 는 여덟 꼭짓점(단순입방), B 는 여섯 면의 중심, C 는 정육면체의 중심에 있다.

쓰는 법칙 배위수는 그 입자에서 가장 가까운 이웃 입자의 수다.

입자의 종류를 가리지 않고 세며, 단위세포의 경계도 가리지 않는다(결정은 이 세포가 사방으로 이어 붙은 것이므로 옆 세포의 입자도 이웃이다).

1단계 거리를 먼저 모두 구한다.

꼭짓점을 원점에 두면 A−B 는 (a/2, a/2, 0) 만큼 떨어져 있어 a/√2 = 0.707a

다. A−C 는 (a/2, a/2, a/2) 이므로 (√3/2)a = 0.866a, A−A 는 a, B−C 는 (0, 0, a/2) 이므로 a/2 = 0.500a, B−B 는 a/√2 = 0.707a

다. 가장 짧은 거리는 B−C 의 0.500a

다. 2단계 A 의 배위수.

A 에서 가장 가까운 것은 0.707a 인 B

다. 원점 둘레에서 그 거리에 있는 B 는 (±a/2, ±a/2, 0), (±a/2, 0, ±a/2), (0, ±a/2, ±a/2) 의 세 묶음이고 묶음마다 부호 조합이 4 가지이므로 3 × 4 = 12 개다.

C(0.866a)와 A(a)는 그보다 멀어 세지 않는다.

3단계 B 의 배위수.

B 에서 가장 가까운 것은 0.500a 인 C

다. 한 면의 중심은 그 면을 함께 쓰는 두 정육면체의 중심 사이에 끼여 있으므로 C 는 2 개다.

같은 면의 꼭짓점 A 는 0.707a 로 더 멀다.

4단계 C 의 배위수.

정육면체 중심에서 여섯 면의 중심까지가 모두 0.500a 로 같으므로 B 가 6 개다.

결론 A = 12, B = 2, C = 6 이다.

→ ①

문제 16몰농도정답 ②

주어진 것 A2(aq) + 2B2(aq) ⇌ 2AB2(aq), K = 10−5.

1.0 L 에 세 물질을 1.0 몰씩 넣었으므로 처음 농도는 모두 1.0 M 이다.

1단계 반응이 갈 방향을 먼저 정한다.

Q = [AB2]2/([A2][B2]2) = 12/(1 × 12) = 1 이고 K = 10−5 이므로 Q ≫ K

다. 분자를 줄이는 쪽, 곧 AB2 가 분해되는 역방향으로 간다.

2단계 K 가 10−5 로 아주 작으니 AB2 가 거의 다 분해된다고 두고 출발한다.

계수를 보면 AB2 2 몰이 분해될 때 A2 1 몰과 B2 2 몰이 생긴다.

AB2 1.0 M 이 모두 분해되면 [A2] = 1.0 + 0.5 = 1.5 M, [B2] = 1.0 + 1.0 = 2.0 M 이다.

3단계 남은 AB2 의 농도를 x 라 두고 평형식에 넣는다.

문제 40평형상수정답 ①

주어진 것 25 °C 에서 H2A ⇌ H+ + HA− (Ka1 = 10−3), HA− ⇌ H+ + A2− (Ka2 = 10−6), 그리고 Kw = 10−14

다. 구하는 것 A2− + 2H2O ⇌ H2A + 2OH− 의 평형상수다.

쓰는 법칙 반응을 더하면 평형상수는 곱하고, 반응을 뒤집으면 평형상수는 역수가 된다.

짝산·짝염기 쌍에서는 Ka × Kb = Kw

다. 이 반응은 OH− 를 만드는 가수분해이므로 Ka 만으로는 끝나지 않고 Kw 가 들어온다.

1단계 목표 반응을 두 단계로 쪼갠다.

(1) A2− + H2O ⇌ HA− + OH− — A2− 의 짝산은 HA− 이므로 Kb1 = Kw/Ka2 = 10−14/10−6 = 10−8 이다.

(2) HA− + H2O ⇌ H2A + OH− — HA− 의 짝산은 H2A 이므로 Kb2 = Kw/Ka1 = 10−14/10−3 = 10−11 이다.

2단계 (1) 과 (2) 를 더하면 A2− + 2H2O ⇌ H2A + 2OH− 로 목표 반응이 된다.

더했으므로 상수는 곱한다.

K = 10−8 × 10−11 = 10−19 이다.

3단계 한 줄로 검산한다.

K = Kw2/(Ka1 × Ka2) = (10−14)2/(10−3 × 10−6) = 10−28/10−9 = 10−19 이다.

물 분자가 2 개 쓰였으므로 Kw 가 두 번 들어간다.

→ ①

문제 41완충용액정답 ③

주어진 것 25 °C 에서 0.1 M HA 수용액의 pH = 3 이다.

여기에 소량의 NaOH 를 넣어 pH = 4 가 되었을 때 [HA]/[A−] 를 구한다.

1단계 처음 용액에서 Ka 를 구한다.

pH = 3 이므로 [H+] = 10−3 M 이고, 이온화로 생긴 H+ 와 A− 의 수가 같으므로 [A−] = 10−3 M, 남은 [HA] = 0.1 − 0.001 = 0.099 M 이다.

Ka = [H+][A−]/[HA] = (10−3 × 10−3)/0.099 = 10−6/0.099 = 1.01 × 10−5 ≒ 10−5 이므로 pKa = 5

다. 2단계 Ka 는 물질의 성질이라 NaOH 를 넣어도 변하지 않는다.

Ka = [H+][A−]/[HA] 를 묻는 비에 대해 풀면 [HA]/[A−] = [H+]/Ka

다. 3단계 값을 넣는다.

pH = 4 이므로 [H+] = 10−4 M 이고, [HA]/[A−] = 10−4/10−5 = 10 이다.

검산 헨더슨-하셀바흐 식으로도 같다.

pH = pKa + log([A−]/[HA]) 에서 4 = 5 + log([A−]/[HA]) 이므로 log([A−]/[HA]) = −1, 곧 [A−]/[HA] = 0.1 이고 뒤집으면 [HA]/[A−] = 10 이다.

크기 감각 처음 용액에서는 [HA]/[A−] = 0.099/0.001 ≒ 100 이었다.

문제 49완전연소식정답 ④

문제 51아레니우스식정답 ①

주어진 것 단일 단계 반응 A ⇌ B, ΔH°(정반응) = 24 kJ/mol, 25 °C 에서 35 °C 로 올렸을 때 정반응 속도가 2배, ln2 = 0.7, ln3 = 1.10 이다.

x 는 25 °C 의 역반응 속도, y 는 35 °C 의 역반응 속도다.

1단계 아레니우스 식을 두 온도에 적용한다.

ln(k2/k1) = (Eₐ/R)(1/T1 − 1/T2) 이고 T1 = 298 K, T2 = 308 K 이므로 1/298 − 1/308 = 1.089 × 10−4 K−1 이다.

2단계 정반응의 활성화 에너지를 구한다.

ln 2 = 0.7 = (Eₐ,정 ÷ 8.314) × 1.089 × 10−4 에서 Eₐ,정 = 0.7 × 8.314 ÷ (1.089 × 10−4) = 53.4 kJ/mol 이다.

3단계 역반응의 활성화 에너지를 구한다.

단일 단계 반응에서 ΔH = Eₐ,정 − Eₐ,역 이므로 Eₐ,역 = 53.4 − 24 = 29.4 kJ/mol 이다.

흡열 반응이라 역반응 쪽 언덕이 24 kJ 만큼 낮다.

4단계 역반응의 속도비를 구한다.

온도 조건이 같으므로 (1/T1 − 1/T2) 는 그대로이고 ln(y/x) = (Eₐ,역 ÷ Eₐ,정) × ln 2 = (29.4 ÷ 53.4) × 0.7 = 0.385

다. 5단계 주어진 로그값과 견준다.

ln(3/2) = ln3 − ln2 = 1.10 − 0.7 = 0.40 으로 0.385 에 가장 가깝다.

따라서 y/x ≈ 3/2

다. 결론 x : y = 2 : 3 이다.

역반응도 빨라지되 활성화 에너지가 작은 만큼 정반응의 2배보다는 덜 빨라진다.

→ ①

(J/(g·°C)) × g × °C = J

그래프에 없는 C 를 넣어야 봉우리가 안 생긴다(②).

평형 Ⅰ 은 8 몰, Ⅱ 는 6 몰이라 몰수비는 4:3 이지만 **온도가 달라졌으므로** 압력비는 4:3 이 아니다 — ③ 이 틀렸다.
