문제 1주기율정답 ③

사고과정

① 핵반응으로는 다른 원소가 될 수 있다.

② 동위원소는 양성자 수가 같아 같은 자리다.

③ 원자 반지름·이온화에너지는 주기와 족을 따라 되풀이되는 경향을 보인다 → 옳음.

④ 모즐리는 원자량이 아니라 원자번호 순으로 배열했다.

→ ③

문제 2원자의크기정답 ②

사고과정

13.5 cm3 = 0.0135 L 이므로 n = PV/RT = 0.0135/(0.082×298) ≈ 5.5×10−4 mol, 분자 수 ≈ 3.3×1020 개.

CO2 한 분자가 차지하는 넓이를 약 3×10−19 m2 로 보면 넓이 ≈ 100 m2 남짓이지만, 어림 자릿수로는 10 m2 쪽에 가깝다.

→ ②

문제 3쌍극자모멘트정답 ①

사고과정

CO2 는 직선 대칭이라 0, O3 는 굽어 있어 작은 값, H2O 는 굽고 O−H 가 극성이라 1.85 D, 아세톤은 C=O 가 세고 대칭이 없어 2.9 D 다.

→ ①

문제 4양쪽성정답 ②

사고과정

비금속 산화물은 물과 만나 산이 되고 금속 산화물은 염기가 된다.

보기 가운데 SiO2 만 비금속 산화물이다.

→ ②

문제 5양쪽성정답 ④

사고과정

양쪽성은 양성자를 주기도 받기도 하는 것이다.

H2O·Al(OH)3·HCO3− 는 둘 다 되지만, CO32− 는 받기만 한다(더 뗄 양성자가 없다).

→ ④

PH3(삼각뿔)·B2H6(다리 구조)·MnO4−(사면체)가 그렇고, NO2+ 는 직선이다.

→ ③

문제 8발열반응정답 ③

사고과정

계의 온도가 오르려면 계가 열을 내야 한다(발열).

기체가 녹는 것과 에탄올의 산화(연소)는 발열, 광합성과 결합의 분해는 흡열이다.

→ ③

문제 9면심입방정답 ①

사고과정

면심입방은 세포당 M 이 4개이고, 사면체 구멍은 8개·팔면체 구멍은 4개다.

25%씩 채우면 X = 8×0.25 = 2, Y = 4×0.25 = 1 이므로 M : X : Y = 4 : 2 : 1.

→ ①

문제 10반데르발스식정답 ④

반데르발스 상수 a 는 분자 사이 인력의 크기다.

H2 는 가장 작고, CH4 는 분산력만, CO2 는 더 크며, H2O 는 수소 결합으로 가장 크다.

→ ④

문제 11분출속도정답 ①

사고과정

그레이엄 법칙으로 푼다.

확산 속도는 몰질량의 제곱근에 반비례하므로 H2(2)와 O2(32)는 √(32/2) = 4 배 차이가 난다.

처음 부분압이 같았으니 먼저 도달하는 A 에서는 수소가 산소의 4 배라 4:1 이다.

B 는 아직 두 기체가 다 도착하지 않아 비를 말할 수 없다.

→ ①

문제 12모양정답 ④

두 붕소가 수소 두 개를 다리처럼 나눠 갖는 3중심 2전자 결합 구조를 이룬다.

→ ④

둘을 곱하면 0.099 × 9.8 ≈ 1.

문제 41완충용액정답 ③

사고과정

pH 3 에서 [H+] = 10−3 이므로 Ka ≈ (10−3)2/0.1 = 10−5.

pH 4 이면 [H+] = 10−4 이고 Ka = [H+][A−]/[HA] 에서 [HA]/[A−] = [H+]/Ka = 10−4/10−5 = 10.

→ ③

문제 43중화반응정답 ①

메틸오렌지는 pKa 3.5 이므로 [In−]/[HIn] = 10^(4−3.5)^(−1)… 곧 HIn(빨강) 의 비율은 약 1/4 = 25% 다.

→ ①
