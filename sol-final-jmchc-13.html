문항별 사고과정

문제 1환원제정답 ①

사고과정

환원제는 잘 산화되는 종 = E°가 가장 음인 짝의 환원형.

Al3+/Al(−1.66V)이 최저 → 환원형 Al이 가장 강한 환원제.

→ ①

표준환원전위가 낮을수록 그 환원형이 전자를 잘 내놓는다(강한 환원제). 반대로 E° 높은 짝의 산화형이 강한 산화제.
문제 2반응식정답 ③

사고과정

E° 높은 쪽이 환원전극(음극).

Cu2+/Cu(0.34V)가 환원, Zn(−0.76V)이 산화.

→ ③

갈바니전지: 환원전극(cathode)=E° 큰 쪽서 환원, 산화전극(anode)=E° 작은 쪽서 산화. 전자는 산화→환원 전극으로.
문제 3표준환원전위정답 ④

사고과정

④ 아연은 산화되므로 환원제, Cu²⁺는 환원되므로 산화제(반대로 서술해 틀림).

①(Zn이 더 잘 산화)·②(0.34−(−0.76)=1.10V)·③(Cu 환원전극, Zn 산화전극)은 옳다. → ④

산화되는 물질이 환원제(상대를 환원시킴). Zn은 환원제, 구리이온은 산화제. 헷갈리기 쉬운 명명.
문제 4갈바니전지정답 ④

사고과정

E°cell = E°(환원전극) − E°(산화전극) = 0.80 − (−0.76) = 1.56V. → ④

기전력은 두 표준환원전위의 차. 전위는 세기 성질이라 계수(2e⁻)를 곱하지 않는다.
문제 5네른스트식정답 ③

사고과정

ΔE = −0.289−(−0.230) = −0.059V. E가 0.059 낮아지면 log[CN⁻]이 +1 → [CN⁻] 10배. 10⁻³ → 10⁻² M. → ③

상수를 구해도 되지만, 0.059V 변화당 농도 10배 관계를 쓰면 빠르다. E 감소 = [CN⁻] 증가(식의 음의 부호).
문제 6건전지연료전지정답 ②

사고과정

② 건전지 Zn은 산화전극(환원제), 연료전지 O2는 환원전극(산화제) → 반대 역할(같지 않음). → ②

①(H2쪽 음극·O2쪽 양극)·③·④는 옳은 반응식.

Zn은 전자를 내놓는 쪽(−극), O2는 전자를 받는 쪽(+극)이라 역할이 정반대다.
문제 7기전력정답 ②

사고과정

가 Zn 산화로 Zn²⁺↑. 다 전자는 산화전극(Zn)→환원전극(Sn). 나 전압은 양(0.63V)에서 0으로 감소(음에서가 아님). → ②

방전될수록 전압은 양수에서 0(평형)으로 줄어든다. Zn(낮은 E°)이 산화전극이라 전자를 Sn으로 보낸다.
문제 8전하량정답 ③

사고과정

Zn 65.4g = 1몰. Zn → Zn²⁺ + 2e⁻(2전자). 전하 = 2×96500 = 1.93×10⁵ C. → ③

전하 = (이동 전자 몰수)×F. Zn 1몰이 2몰의 전자를 내놓는다.
문제 9선표시법정답 ①

사고과정

농도전지(E°=0): 전체 2H⁺(1.0) → 2H⁺(x), Q=x². E = −(0.0592/2)log x² = −0.0592 log x = a → −log x = a/0.0592.

산화 전극은 x M 쪽. pH = −log x = a/0.0592. → ①

농도전지는 묽은 쪽(x M, 산화전극)에서 전자가 나온다. pH=−log[H⁺]가 바로 a/0.0592로 정리된다.
문제 10아보가드로수정답 ④

사고과정

c R = 볼츠만 상수 × NA(나눈 게 아니라 곱한 값). d N2 22.4L는 NA개의 분자(원자는 2NA개, 이원자라). → ④

a(6.022×10²³)·b(1몰 전자=1F)는 옳다.

R=kBNA(곱). 이원자 기체 1몰은 분자 NA개지만 원자는 2NA개라는 함정.
문제 11물의전기분해정답 ④

사고과정

④ 전체 반응(2H2O→2H2+O2)은 양·음극 전위가 pH에 같은 양만큼 변해 상쇄 → pH 무관(참).

① H2·O2지 N2 아님. ② O2 E°(1.23)가 Cl2(1.36)보다 낮음(과전압 때문에 Cl2 발생). ③ 1.0V<1.23V라 부족. → ④

전체 물 분해 전위는 pH 독립. 실제 NaCl 전기분해서 Cl2가 나오는 건 과전압(속도론) 때문이지 열역학(전위)이 아니다.
문제 12소금물의전기분해정답 ①

사고과정

음극: 2H2O+2e−→H2+2OH−(물이 환원, Na+ 아님).

양극: 2Cl−→Cl2+2e−.

생성물 H2·Cl2·NaOH.

Na 금속은 안 생김.

→ ①

수용액에서는 Na+의 환원전위가 너무 낮아 물이 먼저 환원된다. 그래서 Na 금속은 용융 전기분해로만 얻는다.
문제 13도금정답 ④

사고과정

셋 다 옳다. 가 AgNO3가 Ag⁺ 공급. 나 Ag 막대(양극)가 산화돼 Ag⁺를 계속 공급. 다 도금 대상(숟가락)은 환원전극이라 (−)극 연결. → ④

전기도금: 도금할 물체=환원전극(−), 도금 금속=산화전극(+)으로 녹아 이온 공급, 전해질=금속염 용액.
문제 14반응차수정답 ①

사고과정

① 0차 반감기 t½ = [A]0/(2k)라 초기 농도에 비례(무관 아님). → ①

②(1차는 [A]↓로 속도 변화)·③(분수 차수 가능)·④(정촉매 가속)은 옳다.

0차는 반감기가 초기 농도에 비례, 1차는 일정, 2차는 반비례. 차수별 반감기 의존성이 다르다.
문제 15반응차수정답 ①

사고과정

A: 직선 감소 → 0차(속도 일정).

B: 일정 반감기 → 1차.

C: 2배→4배 = 22 → 2차.

→ ①

0차는 [A]가 직선으로 감소, 1차는 반감기 일정, 2차는 속도가 농도 제곱에 비례하는 게 특징.
문제 16초기속도법정답 ③

사고과정

속도 = k[BrO3−][Br−][H+]2(총 4차).

k = 8.0×10−4/(0.10·0.10·0.102) = 8.0.

단위 = (M/s)/M4 = M−3s−1 = L3·mol−3·s−1.

→ ③

전체 차수 n이면 k 단위는 M1−ns−1. 4차라 M−3s−1 = L3mol−3s−1.
문제 17초기속도법정답 ④

사고과정

실1→2: [NO] 2배 → 속도 4배(2차).

실2→3: [Cl2] 2배 → 속도 2배(1차).

속도 = k[NO]2[Cl2].

→ ④

한 농도만 변하는 실험 쌍을 골라 속도 변화로 각 차수를 읽는다. 화학량론 계수(1/2)와 차수는 별개.
문제 18초기속도법정답 ④

사고과정

ClO2 2배→4배(2차), OH⁻ 2배→2배(1차), 총 3차. ④ k = 2.07×10⁻⁴/(0.012²·0.012) = 120 = 1.2×10² M⁻²·s⁻¹(참).

① ClO2 2차. ② OH⁻ 1차. ③ 차수(3)≠분자수라 다단계. → ④

총 3차라 k 단위는 M⁻²s⁻¹. 속도식 차수가 화학량론과 다르면 단일 단계가 아니다.
문제 19초기속도법정답 ③

사고과정

실2→3: [B] 2배 → 속도 2배(B 1차).

실1→2: 둘 다 2배 → 속도 4배 = 2a·21 → a=1(A 1차).

전체 = 2차.

→ ③

한 농도만 변한 쌍(실2→3)으로 B 차수를, 둘 다 변한 쌍으로 A 차수를 역산. 합이 전체 차수.
문제 20반응속도상수정답 ②

사고과정

k는 온도(다)·촉매(나)로만 변한다. 가 농도는 속도를 바꾸지만 k는 불변. 라 생성물 제거도 k 무관. → ②

속도상수 k는 농도와 무관하고 온도·촉매(활성화에너지)에만 의존. 농도는 반응 속도를 바꿀 뿐이다.
문제 21메커니즘정답 ④

사고과정

④ NOBr2는 1단계 생성·2단계 소모 → 중간체(참).

① 느린 2단계가 속도결정. ② 2단계는 이분자. ③ 속도 = k₂K₁[NO]²[Br2](평형 대입). → ④

빠른 평형 단계의 중간체 농도를 K로 대입하면 전체 속도식이 나온다. 여기선 [NO]²[Br2]가 된다.
문제 22속도론정답 ④

사고과정

2차: 1/[A] = 1/[A]0 + k1t = 100 + 0.25×180 = 145 → [A] = 6.9×10−3.

소모된 A = 10−2 − 6.9×10−3 = 3.1×10−3.

[A2] = 소모/2 = 1.55×10−3 ≈ 1.6×10−3.

→ ④

2차 적분식 1/[A]−1/[A]0=kt로 [A]를 구한 뒤, 2A→A2라 소모량의 절반이 A2. ③(소모량 자체)·②([A] 자체)가 함정.
문제 23반감기정답 ②

사고과정

반감기 횟수 = 19/3.8 = 5회. 남은 양 = 1.0×(1/2)⁵ = 1/32 = 3.13×10⁻² g. → ②

경과 시간을 반감기로 나눈 횟수만큼 1/2씩 곱한다. 5번이면 1/32.
문제 24속도론정답 ①

사고과정

−(1/a)Δ[A] = −(1/b)Δ[B] = (1/c)Δ[C].

Δ[A]=Δ[B]이라 a=b, Δ[C]=2Δ[A]이라 c=2a.

a:b:c = 1:1:2, 합 = 4.

→ ①

속도는 (변화율)/(계수)로 모두 같다. 변화율 비가 곧 계수 비. 가장 작은 정수로.
문제 25산소정답 ②

사고과정

기체 A = O2. ② O2는 연소를 돕는 기체일 뿐 자신이 타서 물을 만들지 않음(물은 H2 연소 산물). → ②

①(MnO2 촉매)·③(O2는 물에 잘 안 녹어 수상 치환)·④(KClO3 분해도 O2)는 옳다.

산소는 조연성(연소 지원)이지 가연성이 아니다. 불씨를 키울 뿐 스스로 타지 않는다.
문제 26촉매정답 ④

사고과정

촉매는 활성화 에너지가 낮은 새 경로를 제공해 속도를 높인다. → ④

③ 활성화 에너지를 낮춘다(높이는 게 아님). 온도·분자 수를 바꾸지 않는다.

촉매는 반응 자체나 평형, ΔH를 바꾸지 않고 더 낮은 장벽의 경로만 새로 열어준다.
문제 27에너지정답 ④

사고과정

온도↑ → 충돌 에너지(b)↑(분자 운동에너지)·속도상수(c)↑(아레니우스). 활성화 에너지(a)는 반응 고유값이라 불변. → ④

활성화 에너지는 온도와 무관(촉매로만 변함). 온도는 분자의 에너지와 k를 키운다.
문제 28활성화에너지정답 ④

사고과정

b(생성물이 낮아 정반응 발열)·c(촉매가 A 낮춤)·d(발열이라 온도↑면 역반응→생성물↓) 옳음.

a 반응열은 열역학량이라 속도와 무관(클수록 빠른 게 아님). → ④

반응 속도는 활성화 에너지(A)가 결정, 생성물 안정성·열(B)은 열역학. 발열 반응은 고온서 수율이 떨어진다.
문제 29평형상수정답 ③

사고과정

ΔH = Ea,정 − Ea,역 = 330 − 30 = +300 kJ/mol(흡열).

K ≈ exp(−ΔH/RT), ΔH 큰 양수라 K ≪ 1.

→ ③

정반응 활성화 에너지가 역반응보다 크면 흡열. 흡열이 강하면 평형이 반응물 쪽으로 치우쳐 K<1.
문제 30반응도표정답 ④

사고과정

넷 다 틀림. 가 Y→X 활성화 에너지는 U가 아니라 U+T(반응물 Y에서 봉우리까지). 나 X→Y(발열)서 흡수가 아니라 방출, 엔탈피 변화는 ΔH=T(U+T 아님).
