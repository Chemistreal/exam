문제 1단위변환정답 ③

사고과정

스케일바 500nm = 0.5μm.

화살표 간격이 스케일바와 비슷한 길이 → 약 0.5μm.

→ ③

1μm = 1000nm. 스케일바 길이를 기준 자로 삼아 대상의 길이를 비례로 읽는다. 미토콘드리아 폭은 보통 0.5~1μm.
문제 2유효숫자정답 ③

주어진 것: 눈금실린더의 일부와 액면.

4 와 5 사이에 보조눈금이 아홉 개 있으므로 **최소 눈금은 0.1 mL** 이다.

규칙 — 측정값은 최소 눈금의 **한 자리 아래까지** 어림해서 적는다.

최소 눈금이 0.1 이므로 0.01 자리를 어림한다.

액면은 4 와 5 사이 여섯째 보조눈금 근처에 있어 4.6 까지는 눈금으로 확실하고, 그 아래 한 자리를 어림해 **4.60** 으로 적는다.

유효숫자는 세 개다.

① 5 는 어림 자리를 아예 안 적은 것이고, ② 4.6 은 어림 자리가 빠져 유효숫자가 둘뿐이며, ④ 4.600 은 최소 눈금이 0.01 일 때라야 쓸 수 있는 네 자리다.

→ ③

확인 필요 2026-09-05 정정: 옛 해설이 「보조눈금이 0.2 간격」이라 적고 있었다. 그림의 4~5 사이 보조눈금은 아홉 개라 최소 눈금은 **0.1** 이다. 0.2 라면 십분위부터 어림이 되어 4.60 이라는 표기 자체가 설 수 없다 — 결론 ③을 떠받치는 것이 0.1 이다. 정답은 그대로다.

문제 7오비탈정답 ③

주어진 것: 수소 원자의 n = 2 인 오비탈 X · Y 의 방사 방향 확률 분포 함수.

1단계 — 그림에서 둘을 가른다.

**X** 는 봉우리가 **하나**뿐이고 마디가 없다 → 방사 마디 0 → **2p** **Y** 는 핵 가까이 작은 봉우리 → 마디 → 바깥에 큰 봉우리로, 봉우리가 **둘**이고 그 사이에 마디가 하나 있다 → 방사 마디 1 → **2s** 2단계 — 보기를 하나씩 본다.

ⓐ 각운동량 양자수는 2s 가 0, 2p 가 1 이다.

Y(2s)=0, X(2p)=1 이라 Y > X 가 아니다.

거짓.

ⓑ 전체 마디 수는 둘 다 n − 1 = 1 로 같다(2p 는 각마디 1·방사마디 0, 2s 는 각마디 0·방사마디 1).

거짓.

ⓒ **수소 원자는 전자가 하나뿐이라 에너지가 오직 n 에만 달려 있다.** 둘 다 n = 2 이므로 에너지 준위가 같다(축퇴).

**참.** ⓓ Y 는 2s

다. 거짓.

→ ③

(다전자 원자라야 같은 n 안에서 s < p < d 로 갈라진다.)
확인 필요 2026-09-05 정정: 옛 해설이 X 와 Y 를 **바꿔** 적고 있었다 — 「X(작은 봉우리+주봉)=2s, Y(단일 봉우리)=2p」. 그림에서는 봉우리가 하나인 쪽이 X, 작은 봉우리·마디·큰 봉우리를 가진 쪽이 Y 다. 그 뒤바뀐 배정을 그대로 따르면 ⓐ(l 은 Y > X)와 ⓓ(Y 는 p 오비탈)가 **둘 다 참**이 되어 정답이 셋이 된다. 게다가 옛 해설은 「④ Y 는 2s」라 적어 자기 배정과도 어긋났다. 정답 ③은 그대로다.

문제 9이온화에너지정답 ①

사고과정

가 전자를 떼려면 항상 에너지 흡수 → 일차 IE>0(옳음). 나 H⁻→H+e⁻(IE)와 H+e⁻→H⁻(EA)는 역과정이라 크기 같음(옳음).

다 이차 IE>일차 IE(양이온서 떼기 더 어려움) → E=hc/λ로 더 짧은 파장 필요(긴 파장 아님). → ①

IE는 항상 흡열(+). 양이온화가 진행될수록 IE↑이고, 에너지↑는 파장↓에 해당한다. IE(H⁻)와 EA(H)는 부호 반대·크기 동일.
문제 10혼성오비탈정답 ③

사고과정

③ NO2+(직선 180°)>NO2(굽음 ~134°)>NO2−(굽음 ~115°).

결합각 최대는 NO2+.

옳음.

① NO2+는 sp(고립쌍 없음).

② 무극성은 직선형 NO2+.

문제 14양자수정답 ②

사고과정

나 l은 0~n−1(옳음). 라 오비탈은 n·l·ml 3개로 지정(옳음, ms는 전자 구별용).

문제 19형식전하정답 ①

사고과정

문제 21분자간인력비교정답 ③

무엇을 묻는가: 온도가 올라갈 때 전기 전도도가 커지는 물질끼리 짝지어진 보기를 고르는 문제다.

1단계 — 전도도의 두 가지 요인.

전도도는 (전하 운반자의 수) × (운반자의 이동도)로 결정된다.

온도가 오르면 이 두 요인이 물질마다 반대 방향으로 움직인다.

2단계 — 물질별 판정.

· 반도체: 온도가 오르면 열에너지를 받아 띠간격(band gap)을 넘어 전도띠로 올라가는 전자가 급격히 늘고 그만큼 양공도 생긴다.

운반자 수가 지수적으로 늘어나므로 전도도는 증가한다.

· 전해질 용액: 온도가 오르면 용매의 점성이 낮아져 이온이 같은 전기력을 받아도 더 빨리 끌려가므로 이온의 이동도가 커진다.

이 한 가지만으로 전도도는 증가한다.

이온화가 흡열인 약전해질이라면 이온화도도 커져 증가를 더 돕지만, 이 효과는 이온화 엔탈피의 부호에 달려 있어 항상 성립하지는 않으므로 판정의 근거로 삼지 않는다.

· 금속 도체: 운반자인 자유전자의 수는 온도에 거의 변하지 않는다.

반면 온도가 오르면 금속 이온의 격자 진동이 커져 전자가 산란되는 횟수가 늘어난다.

이동도가 떨어지므로 저항이 커지고 전도도는 감소한다.

· 수은: 상온에서 액체이지만 자유전자가 전도를 담당하는 금속이므로, 온도가 오르면 격자(이온) 진동에 의한 산란이 늘어 저항이 커지고 전도도는 감소한다.

실제로 수은의 비저항은 온도가 오르면 커진다(저항 온도계수가 양수다).

3단계 — 보기 대조.

① 반도체는 증가, 수은은 감소이므로 조합이 성립하지 않는다.

② 수은과 금속 도체는 둘 다 감소이므로 성립하지 않는다.

③ 전해질 용액은 증가지만 금속 도체는 감소이므로 성립하지 않는다.

④ 전해질 용액과 반도체는 둘 다 증가한다.

결론: 정답은 ④이다.

문제 32엔탈피정의정답 ②

무엇을 묻는가: 반응계에 출입한 열량 q 와 엔탈피 변화량 ΔH 가 같아지려면 어떤 조건에서 반응을 해야 하는지를 묻는 문제다.

1단계 — 열역학 제1법칙에서 출발한다.

ΔE = q + w 이고, 계가 하는 일이 팽창 일뿐이라면 w = −P_ext ΔV 이다.

따라서 q = ΔE + P_ext ΔV 이다.

2단계 — 엔탈피의 정의를 쓴다.

엔탈피는 H ≡ E + PV 로 정의된 상태함수다.

변화량을 쓰면 ΔH = ΔE + Δ(PV) 이다.

3단계 — 두 식을 비교한다.

q = ΔH 가 되려면 ΔE + P_ext ΔV = ΔE + Δ(PV), 즉 P_ext ΔV = Δ(PV) 여야 한다.

압력이 일정하면 Δ(PV) = PΔV 이므로 이 조건이 그대로 성립한다.

곧 일정 압력에서는 q_p = ΔH 이다.

4단계 — 보기 대조.

① 온도만 일정하게 유지해도 부피가 변하면 계가 팽창 일을 하므로 q 와 ΔH 는 일반적으로 같지 않다.

온도 일정은 조건이 되지 못한다.

② 압력을 일정하게 유지하면 3단계에 따라 q_p = ΔH 가 되므로 이것이 답이다.

③ 부피를 일정하게 유지하면 ΔV = 0 이어서 w = 0 이 되고 q_v = ΔE 가 된다.

이때 같아지는 것은 엔탈피가 아니라 내부에너지다.

④ 닫힌계에서 질량이 일정하므로 밀도를 일정하게 유지한다는 것은 부피를 일정하게 유지한다는 말과 같다.

결과는 ③과 마찬가지로 q_v = ΔE 이지 ΔH 가 아니다.

결론: 정답은 ②이다.

엔탈피는 애초에 '일정 압력에서 주고받은 열'을 상태함수로 다루기 위해 정의된 양이다.

문제 55평형상수계산정답 ①

주어진 것: Cu(OH)2의 용해도곱 Ksp = 1.6×10−19, Cu(NH3)42+의 형성상수 Kf = 1.0×1013, 그리고 구하려는 반응 Cu(OH)2(s) + 4NH3(aq) ⇌ Cu(NH3)42+(aq) + 2OH−(aq) 이다.

1단계 — 목표 반응을 아는 두 반응의 합으로 쪼갠다.

(1) 용해: Cu(OH)2(s) ⇌ Cu2+(aq) + 2OH−(aq), K1 = Ksp = 1.6×10−19 (2) 착물 형성: Cu2+(aq) + 4NH3(aq) ⇌ Cu(NH3)42+(aq), K2 = Kf = 1.0×1013 두 식을 더하면 양변의 Cu2+가 소거되어 목표 반응이 그대로 나온다.

2단계 — 어떤 법칙을 쓰는가.

반응식을 더하면 표준 자유에너지는 더해지고(ΔG°_전체 = ΔG°1 + ΔG°2), K = e^(−ΔG°/RT) 이므로 평형상수는 곱해진다.

즉 K = K1 × K2 이다(헤스 법칙의 평형상수 버전).

3단계 — 계산한다.

K = (1.6×10−19) × (1.0×1013) = (1.6 × 1.0) × 10^(−19+13) = 1.6 × 10−6 4단계 — 결과를 점검한다.

지수는 −19 와 +13 을 더해 −6 이고, 유효숫자는 1.6×1.0 = 1.6 이다.

Ksp 만 놓고 보면 10−19 로 거의 녹지 않던 Cu(OH)2가 암모니아가 있으면 K = 1.6×10−6 까지 올라간다는 뜻이며, 착물 형성이 용해를 크게 밀어 준다는 사실과도 맞는다.

결론: 정답은 ①이다.
