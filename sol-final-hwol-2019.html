문제 1동위원소·질량결손정답 ②
안정한 동위원소가 하나인 원소들로만 짝지은 것은? (① C, N, O / ② Na, Al, P / ③ Mn, Fe, Co / ④ Pt, Au, Hg)
① C, N, O
② Na, Al, P
③ Mn, Fe, Co
④ Pt, Au, Hg

사고과정

② Na·Al·P는 모두 단일 안정 동위원소(원자량 22.99·26.98·30.97로 정수에 근접). 단일 동위원소라도 질량결손으로 정수보다 약간 작다. → ②

① C·N·O 모두 동위원소 2개 이상. ③ Fe는 4종. ④ Pt·Hg는 여러 종.

단일 동위원소 원소(Na·Al·P·F·Co·Au 등)는 원자량이 정수에 가깝되, 핵 결합에너지 질량결손으로 약간 작다.
문제 2몰농도·질량정답 ②
빗물 속 C29H60(화학식량 409)의 몰농도가 10 nM이다. 빗물 1톤(1000 kg, 밀도 1 g/mL)에 든 C29H60의 질량은?
① 0.409 mg
② 4.09 mg
③ 40.9 mg
④ 409 mg

사고과정

1톤 = 10⁶ g·밀도 1 → 부피 10⁶ mL = 1000L. 몰수 = 10⁻⁸ mol/L × 1000L = 10⁻⁵몰. 질량 = 10⁻⁵×409 = 4.09×10⁻³ g = 4.09 mg. → ②

10 nM = 10⁻⁸ M. 몰농도×부피(L)로 몰수를, 몰수×화학식량으로 질량을 구한다.
문제 3배수 비례 법칙정답 ③
N·O로 된 기체 X·Y·Z. 일정량 N과 결합하는 O 질량비 X:Y:Z = 1:2:3. Y가 NO일 때 Z의 분자식은?
① NO2
② N2O
③ N2O3
④ N2O4

사고과정

Y=NO는 N당 O 1개(비율 2). Z는 비율 3 = Y의 1.5배 → N당 O 1.5개 → N2O3(2N:3O). → ③

참고: X(비율 1)는 N당 O 0.5개 → N2O.

같은 N 양 기준으로 O 원자수를 비교한다. NO(N당 O 1)를 기준 2로 잡으면 비율이 곧 N당 O 개수의 2배다.
문제 4정확도·정밀도정답 ④
참값 41.000 g인 초콜릿을 저울 A~D로 3회 측정. 높은 정확도·낮은 정밀도를 보이는 저울은? (A 평균42·B 40.0·C 41.0·D 41)
① 저울 A
② 저울 B
③ 저울 C
④ 저울 D

사고과정

정확도 = 평균이 참값(41)에 가까움, 정밀도 = 측정값 흩어짐 작음. D는 평균 41(정확) but 39·41·43으로 편차 큼(부정밀). → ④

A 평균42(부정확). B 평균40.0(부정확). C 정확하고 정밀(둘 다 높음).

정확도와 정밀도는 별개. 평균은 맞아도(정확) 값들이 들쭉날쭉(부정밀)할 수 있다.
문제 5피펫 사용법정답 ③
옮김 피펫(transfer pipette)의 올바른 사용법은? (마우스 피펫팅·마지막 방울 처리 관련)
① 입으로 빨아 흡입·손가락 조절
② 입으로 빨고 남은 액 입으로 불어냄
③ 피펫벌브로 흡입·표시선 맞춰 옮김
④ 피펫벌브 사용하나 짜서 남은 액 배출

사고과정

③ 피펫벌브로 안전하게 흡입하고, 옮김 피펫은 마지막 한 방울을 남기도록 보정돼 있어 불거나 짜내지 않음. → ③

①② 입으로 빨기(위험). ④ 벌브를 짜서 남은 액 배출(보정 위배).

실험실서 입으로 빠는 마우스 피펫팅은 금지. 용량 피펫(TD)은 잔류 방울을 남기도록 설계돼 강제 배출하면 안 된다.
문제 6주기적 성질(3주기)정답 ②
3주기 Na·Mg·S·Cl에 대해 옳은 것은? (가. 반지름 최대 Cl / 나. 금속성 최대 Na / 다. 1차 IE 최소 Na / 라. 전기음성도 최소 Cl)
① 가, 나
② 나, 다
③ 다, 라
④ 가, 라

사고과정

주기 →로 반지름↓·금속성↓·IE↑·전기음성도↑. 나 금속성 최대 = Na. 다 1차 IE 최소 = Na. 가 반지름 최대는 Na(Cl 아님). 라 전기음성도 최소도 Na(Cl은 최대). → ②

같은 주기서 왼쪽 원소(Na)가 반지름·금속성 최대, IE·전기음성도 최소다.
문제 7이온 크기 비교정답 ③
이온의 크기가 큰 순으로 나열한 것은? (S²⁻·K⁺·Ca²⁺·Ga³⁺)
① Ga³⁺>Ca²⁺>S²⁻>K⁺
② Ga³⁺>Ca²⁺>K⁺>S²⁻
③ S²⁻>K⁺>Ca²⁺>Ga³⁺
④ S²⁻>Ga³⁺>Ca²⁺>K⁺

사고과정

S²⁻·K⁺·Ca²⁺는 등전자(18e⁻) → 핵전하 클수록 작음: S²⁻(16)>K⁺(19)>Ca²⁺(20). Ga³⁺(28e⁻·Z=31)은 유효핵전하 커 최소. → ③

등전자 이온은 양성자 수가 많을수록 전자를 강하게 당겨 작아진다. Ga³⁺는 d전자까지 있어 가장 작다.
문제 8주기적 경향성정답 ②
원자번호 7~13(N·O·F·Na·Mg·Al, Ne 제외)에서 원자가 전자 수의 변화와 가장 비슷한 경향성을 갖는 성질은?
① 원자 반지름
② 전기음성도
③ 제1 이온화 에너지
④ Ne 배치 이온의 반지름

사고과정

원자가 전자 수: 5·6·7(N→F)→1·2·3(Na→Al), 증가 후 리셋·재증가. 전기음성도가 같은 패턴(N→F 증가·Na서 급락·Na→Al 증가). → ②

①④ 반지름은 단조 감소(반대). ③ IE는 N>O 예외로 불일치.

전기음성도는 원자가 전자 수처럼 주기 내 증가하다 새 주기서 리셋된다. 반지름류는 정반대로 단조 감소.
문제 9산소산의 세기(틀린 것)정답 ①
산소산의 세기 비교 중 옳지 않은 것은? (① H2SO3>HClO4 / ② HNO3>HNO2 / ③ HOCl>HOBr / ④ HClO3>HClO2)
① H2SO3>HClO4
② HNO3>HNO2
③ HOCl>HOBr
④ HClO3>HClO2

사고과정

① HClO4는 가장 강한 산(Cl +7·비수산기 O 3개)이고 H2SO3는 약산 → "H2SO3>HClO4"는 틀림. → ①

②(HNO3 O 더 많음)·③(Cl이 Br보다 전기음성)·④(Cl +5>+3)는 옳음.

산소산 세기는 비수산기 산소가 많을수록(중심 산화수 높을수록)·중심 원자 전기음성도가 클수록 강하다.
문제 10순차 이온화 에너지정답 ④
원소 A~D의 순차 IE(E₁~E₄). 옳은 것은? (가. A·D 같은 족 / 나. 원자가 전자 최소는 B / 다. C가 안정 이온 되려면 2189 kJ/mol 필요)
① 가
② 다
③ 가, 나
④ 나, 다

사고과정

IE 도약 위치로 족 판별: A(E₂후 도약)=Be(2족), B(E₁후)=Na(1족), C(E₂후)=Mg(2족), D(E₃후)=Al(13족). 나 B(Na) 원자가 전자 1로 최소. 다 Mg→Mg²⁺ = E₁+E₂ = 738+1451 = 2189. 가 Be·Al은 다른 족. → ④

순차 IE가 급증하는 지점이 원자가 전자 수를 알려준다. 안정 이온 형성에 필요한 에너지는 떼어낼 전자들의 IE 합이다.
문제 11평균 운동 속력정답 ①
같은 온도서 기체 분자의 평균 운동 속력이 증가하는 순서는? (Cl2·F2·O2·N2)
① Cl2<F2<O2<N2
② Cl2<O2<F2<N2
③ N2<F2<Cl2<O2
④ Cl2<F2<N2<O2

사고과정

같은 온도서 속력 ∝ 1/√M. 몰질량 Cl271>F238>O232>N228 → 속력은 Cl2<F2<O2<N2. → ①

평균 운동에너지는 같아도(온도 동일) 무거운 분자가 느리다. 속력은 분자량의 제곱근에 반비례.
문제 12기체 법칙(틀린 것)정답 ②
기체 법칙 중 틀린 것은? (① 보일: V∝1/P / ② 샤를: V는 절대온도에 반비례 / ③ 아보가드로: V∝n / ④ 부분압: P전체=ΣPi)
① 보일: 몰수·온도 일정 시 V는 압력에 반비례.
② 샤를: 몰수·압력 일정 시 V는 절대온도에 반비례.
③ 아보가드로: 온도·압력 일정 시 V는 몰수에 비례.
④ 부분압: 전체 압력은 부분 압력의 합.

사고과정

② 샤를의 법칙은 V가 절대온도에 비례(반비례 아님). 틀림. → ②

①(보일 V∝1/P)·③(아보가드로 V∝n)·④(돌턴 부분압 합)는 옳음.

샤를: 압력 일정서 온도↑면 부피↑(비례). 보일만 반비례(압력-부피) 관계다.
문제 13기체 밀도·질량정답 ③
같은 온도·압력서 Cl2를 두 용기에 보관. 용기 A(1.30 m³, 6.70 g), 용기 B(2.33 m³, X). X는?
① 3.8 g
② 8.7 g
③ 12.0 g
④ 22.4 g

사고과정

같은 기체·같은 T·P → 밀도 동일이라 질량 ∝ 부피. X = 6.70×(2.33/1.30) = 12.0 g. → ③

같은 온도·압력의 같은 기체는 단위 부피당 질량(밀도)이 같으므로 질량과 부피가 비례한다.
문제 14총괄성정답 ③
용액의 총괄성(colligative property)과 관계가 가장 깊은 것은?
① 산 정상서 물 끓는점이 낮아 밥이 설익음.
② 채소를 볶으면 물이 나와 부피가 줆.
③ 콜라를 얼리려면 0℃보다 낮은 온도가 필요.
④ 호수는 표면부터 얼기 시작함.

사고과정

③ 콜라(설탕 용액)는 용질 때문에 어는점 내림(총괄성)이 일어나 0℃ 아래서 언다. → ③

① 기압 영향. ② 가열에 의한 수분 방출. ④ 물의 밀도 이상(얼음이 더 가벼움).

총괄성(어는점 내림·끓는점 오름·삼투압)은 용질 입자 수에만 의존한다. 기압·밀도 효과는 총괄성이 아니다.
문제 15라울 법칙(증기압 내림)정답 ②
순수 물 증기압 250 torr. 물 1800g에 포도당(180 g/몰)을 녹였더니 증기압 245 torr. 첨가한 포도당 질량은?
① 180 g
② 360 g
③ 400 g
④ 540 g

사고과정

245 = χ물×250 → χ물 = 0.98, χ포도당 = 0.02. 물 = 1800/18 = 100몰. χ포도당 ≈ n/물 = 0.02 → n = 2몰. 질량 = 2×180 = 360 g. → ②

라울 법칙: 용액 증기압 = 용매 몰분율×순수 증기압. 증기압 내림으로 용질 몰분율을 구한다.
문제 16증기압 편차(분자간 힘)정답 ③
휘발성 액체 A·B 용액의 증기압 그림(점선=라울 이상, 실선=실측). 실측이 이상보다 높을 때 가장 약한 힘은?
① A-A 분자 사이 인력
② B-B 분자 사이 인력
③ A-B 분자 사이 인력
④ 알 수 없다.

사고과정

실측 증기압 > 이상(양의 편차) → 분자가 더 쉽게 증발 → A-B 인력이 A-A·B-B보다 약함. → ③

양의 편차는 이종 분자(A-B) 인력이 동종보다 약할 때. 음의 편차면 A-B 인력이 더 강하다.
문제 17라울 법칙(증기 몰비)정답 ①
25℃서 A·B 증기압 40·90 torr. A 0.2몰+B 0.8몰을 닫힌 용기서 평형(둘 다 액체 잔존) 시 기체 A:B 몰비는?
① 0.1:0.9
② 0.15:0.85
③ 0.2:0.8
④ 0.25:0.75

사고과정

증기 몰비 = 분압비. PA = 0.2×40 = 8, PB = 0.8×90 = 72 torr. 비 = 8:72 = 0.1:0.9. → ①

분압 = 액체 몰분율×순수 증기압(라울). 기체 상태의 몰비는 곧 분압의 비와 같다.
문제 18띠 이론(도체·반도체)정답 ③
고체의 온도-저항 그래프. ⓐ(온도↑ 저항↓)·ⓑ(온도↑ 저항↑)를 바르게 짝지은 것은?
① ⓐ 도체 / ⓑ 부도체
② ⓐ 도체 / ⓑ 반도체
③ ⓐ 반도체 / ⓑ 도체
④ ⓐ 반도체 / ⓑ 부도체

사고과정

ⓐ 온도↑서 저항↓ = 반도체(열로 전자가 띠틈 넘어 증가). ⓑ 온도↑서 저항↑ = 도체(격자 진동↑로 전자 산란↑). → ③

금속(도체)은 가열 시 저항 증가, 반도체는 가열 시 전도 전자가 늘어 저항 감소한다.
문제 19전기 전도도(이온 농도)정답 ①
전기 전도도가 감소하는 순서는? (가. 1M NaCl / 나. 0.1M Na2CO3 100mL+0.2M HCl 100mL / 다. 1M 아세트산(α=0.01))
① 가>나>다
② 가>다>나
③ 나>다>가
④ 다>가>나

사고과정

전도도 ∝ 이온 농도. 가 1M NaCl → 이온 2M. 나 Na2CO3 0.01몰+HCl 0.02몰 완전반응 → NaCl 0.02몰/200mL = 0.1M → 이온 0.2M. 다 아세트산 α=0.01 → 이온 0.02M. 가>나>다. → ①

강전해질은 완전 해리, 약산은 일부만 해리. 중화 후 남은 강전해질(NaCl)과 미해리 약산의 이온 수를 비교한다.
문제 20분자간 힘의 효과(아닌 것)정답 ③
액체의 분자 간 인력이 클수록 큰 값을 가지지 않는 것은?
① 점성
② 표면장력
③ 증기압
④ 끓는점

사고과정

분자간 인력↑ → 점성·표면장력·끓는점 모두 증가. 그러나 증기압은 분자가 탈출하기 어려워 감소. → ③

강한 인력은 분자를 붙잡아 증발을 억제하므로 증기압을 낮춘다(휘발성 감소).
문제 21끓는점 비교정답 ①
끓는점이 감소하는 순서는? (벤젠 C6H6·뷰테인·헥산올 C6H13OH·헥세인 C6H14)

이 문항은 원본 시험에서 문제삭제되었다.

표준생성엔탈피는 원소의 표준 상태(N2·O2)에서 화합물 1몰을 만드는 엔탈피. 원자 상태가 남으면 정의가 성립하지 않는다.
문제 43결합 에너지·연소열정답 ②
기체 에탄올(C2H5OH) 완전 연소열을 결합 에너지로 계산하면? (C-C 350·C-H 410·C-O 350·O-H 460·O=O 498·C=O 804)
① −500
② −1,200
③ −2,200
④ −3,300

사고과정

C2H5OH+3O2→2CO2+3H2O. 깨짐 = (C-C+5C-H+C-O+O-H)+3(O=O) = 3210+1494 = 4704. 형성 = 4(C=O)+6(O-H) = 3216+2760 = 5976. ΔH = 4704−5976 = −1272 ≈ −1200. → ②

ΔH = (깨진 결합 에너지 합) − (형성된 결합 에너지 합). 분자 구조를 정확히 세어 결합 종류·개수를 파악한다.
문제 44평형 이동(암모니아 합성)정답 ①
N2+3H2⇌2NH3(ΔH<0). 옳은 것은? (가. 정반응 발열 / 나. 부피↑면 평형 왼쪽 / 다. NH3 평면삼각 / 라. N2 2몰+H2 2몰 → NH3 2몰)
① 가, 나
② 가, 다
③ 나, 라
④ 다, 라

사고과정

가 ΔH<0 발열. 나 부피↑(압력↓) → 기체 몰수 많은 쪽(반응물 4몰)으로 = 왼쪽. 다 NH3는 삼각뿔. 라 H2 한계(2몰)라 NH3 4/3몰만. → ①

압력 변화 시 평형은 기체 몰수가 많은 쪽/적은 쪽으로 이동. 평형 반응은 완결되지 않는다.
문제 45용해도 증가(CaCO3)정답 ①
CaCO3(Ksp=3.3×10⁻⁹)의 몰용해도를 높이는 방법은?
① 용액에 이산화 탄소를 불어 넣는다.
② 용액을 잘 저어준다.
③ CaCO3를 곱게 갈아 가루로 만든다.
④ 더 많은 물을 넣어준다.

사고과정

① CO2+H2O → H2CO3의 H⁺가 CO3²⁻를 소모(CaCO3+CO2+H2O → Ca²⁺+2HCO3⁻) → 용해 촉진. → ①

②③ 용해 속도만 바꿀 뿐 평형 용해도 불변. ④ 물 추가는 몰용해도(포화 농도) 불변.

몰용해도(포화 농도)는 젓기·입자 크기·물 양과 무관. 공통 이온 제거(CO3²⁻ 소모)가 용해도를 높인다.
문제 46속도 상수 결정정답 ①
2NO+2H2→N2+2H2O. 실험(0.10/0.20→0.030, 0.10/0.30→0.045, 0.20/0.20→0.120)서 속도 상수(M⁻²s⁻¹)는?
① 15
② 1.5
③ 8.5
④ 0.85

사고과정

[H2]×1.5→속도×1.5(1차), [NO]×2→속도×4(2차) → 속도 = k[NO]²[H2]. 실험1: 0.030 = k(0.10)²(0.20) = k(0.002) → k = 15. → ①

한 농도만 바꾼 실험을 비교해 각 차수를 정한 뒤, 한 실험 값을 대입해 k를 구한다.
문제 47메커니즘·속도법칙정답 ②
NOBr 생성 메커니즘: NO+Br2⇌NOBr2(빠른 평형, k1/k−1), NOBr2+NO→2NOBr(느림, k2). 속도법칙은?
① k1[NO]1/2
② (k1k2/k−1)[NO]²[Br2]
③ (k2/k−1)²[NO]²
④ (k1k2/k−1)[NO]²[Br2]²

사고과정

느린 단계: 속도 = k2[NOBr2][NO]. 빠른 평형서 [NOBr2] = (k1/k−1)[NO][Br2] 대입 → (k1k2/k−1)[NO]²[Br2]. → ②

속도결정단계(느린 단계)의 중간체 농도를, 앞선 빠른 평형식으로 치환해 반응물 농도로 표현한다.
문제 48반감기(방사성 붕괴)정답 ③
²²²Rn → ²¹⁸Po + α. 50%로 줄어드는 데 3.8일(반감기). 10%로 줄어드는 데 걸리는 시간은?
① 5.7일
② 7.6일
③ 12.6일
④ 19일

사고과정

0.10 = (1/2)t/3.8 → t/3.8 = log0.1/log0.5 = 1/0.301 = 3.32회. t = 3.8×3.32 = 12.6일. → ③

10%는 3회(12.5%)와 4회(6.25%) 사이라 약 3.3 반감기. 반감기에 회수를 곱해 시간을 구한다.
문제 49약산 이온화도·희석정답 ③
0.9 M 약산의 이온화도가 3%. 0.1 M로 묽히면 이온화도는?
① 0.3%
② 0.9%
③ 9%
④ 30%

사고과정

Ka ≈ Cα²로 일정. 이온화도 α ∝ 1/√C. 농도 9배 묽힘 → α는 √9 = 3배 → 3%×3 = 9%. → ③

약산은 묽힐수록 이온화도가 커진다(르샤틀리에). α는 농도의 제곱근에 반비례한다.
문제 50루이스 산-염기(아닌 것)정답 ④
루이스 산-염기 반응이 아닌 것은? (① H⁺+OH⁻ / ② Cu²⁺+NH3 / ③ HCl+NH3 / ④ 2Al+3Cl2)
① H⁺+OH⁻⇌H2O
② Cu²⁺+4NH3⇌[Cu(NH3)4]²⁺
③ HCl+NH3→NH4Cl
④ 2Al+3Cl2→2AlCl3

사고과정

④ 2Al+3Cl2→2AlCl3은 전자 이동(산화환원)이지 전자쌍 주개-받개 반응이 아님. → ④

①②③은 전자쌍 공여·수용(루이스 산-염기).

루이스 산-염기는 전자쌍을 주고받는 반응(착물 생성·중화). 산화환원은 전자가 완전히 이동한다.
문제 51지시약 변색(이양성자)정답 ②
티몰 블루(H2B 붉음·HB⁻ 노랑·B²⁻ 파랑, pK1=1.7·pK2=8.9). pH 8.9에서 색은?
① 노란색
② 초록색
③ 주황색
④ 파란색

사고과정

pH = pK2 = 8.9서 [HB⁻] = [B²⁻](2단계 평형 중간점). 노랑(HB⁻)+파랑(B²⁻) = 초록. → ②

pH = pKa면 두 화학종이 1:1. 노랑과 파랑이 섞이면 초록으로 보인다.
문제 52산화된 화학종(수소 제조)정답 ③
단계1 H2O+CH4→CO+3H2, 단계2 CO+H2O→CO2+H2. 각 단계서 산화된 화학종은?
① H2O·CO
② H2O·H2O
③ CH4·CO
④ CH4·H2O

사고과정

단계1: C가 CH4(−4)→CO(+2) 산화 → CH4. 단계2: C가 CO(+2)→CO2(+4) 산화 → CO. → ③

산화수가 증가한 원소를 포함한 반응물이 산화된 화학종. 두 단계 모두 탄소가 산화된다.
문제 53산화-환원(아닌 것)정답 ③
산화-환원 반응이 아닌 것은? (① CuSO4+H2 / ② Fe2(SO4)3+Cu / ③ Al2O3+H2SO4 / ④ Fe2O3+CO)
① CuSO4+H2→Cu+H2SO4
② Fe2(SO4)3+Cu→2FeSO4+CuSO4
③ Al2O3+3H2SO4→Al2(SO4)3+3H2O
④ Fe2O3+3CO→2Fe+3CO2

사고과정

③ Al(+3)·S(+6)·O(−2)·H(+1) 모두 산화수 불변 → 산-염기(복분해), 산화환원 아님. → ③

①(Cu²⁺ 환원·H 산화)·②(Fe³⁺ 환원·Cu 산화)·④(Fe³⁺ 환원·C 산화)는 산화환원.

산화수 변화가 없으면 산화환원이 아니다. 금속 산화물+산 → 염+물은 전형적 산-염기 반응.
문제 54산화-환원 균형정답 ③
aH2O2+Cr2O7²⁻+bH⁺→cO2+dCr³⁺+eH2O의 계수 (a,b,c,d,e)는?
① 3,6,2,2,7
② 2,7,3,1,8
③ 3,8,3,2,7
④ 2,9,2,1,8

사고과정

H2O2→O2(O −1→0, 2e⁻ 방출)·Cr2O7²⁻→2Cr³⁺(Cr +6→+3, 6e⁻ 흡수). 전자 맞춤: 3H2O2:1Cr2O7²⁻. O 균형서 e=7, H 균형서 b=8. (a,b,c,d,e) = (3,8,3,2,7). → ③

반쪽 반응의 전자 수를 맞춘 뒤 O는 H2O로, H는 H⁺로 균형. 마지막에 전하 균형으로 검산한다.
문제 55배위 화합물·침전정답 ②
AgNO3 첨가 시 침전이 일어나는 배위 화합물은? (① [Cr(NH3)3Cl3] / ② [Cr(NH3)6]Cl3 / ③ [Cr(NH3)5Cl]NO3 / ④ Na3[Cr(CN)6])
① [Cr(NH3)3Cl3]
② [Cr(NH3)6]Cl3
③ [Cr(NH3)5Cl]NO3
④ Na3[Cr(CN)6]

사고과정

Ag⁺는 자유(짝이온) Cl⁻만 AgCl로 침전. ② [Cr(NH3)6]Cl3는 Cl⁻ 3개가 착이온 밖 짝이온 → 침전. → ②

①(Cl 모두 배위)·③(Cl 배위·짝이온 NO3⁻)·④(Cl 없음)는 침전 안 됨.

배위(착이온 안쪽) Cl은 침전하지 않는다. 대괄호 밖 짝이온 Cl⁻만 Ag⁺와 반응한다.
문제 56거울상 이성질체정답 ①
거울상 이성질체가 존재하는 것은? (en=이좌배위) (① cis-[Co(en)2(H2O)2]³⁺ / ② cis-[Co(NH3)4Br2]⁺ / ③ trans-[Co(en)2(NH3)Cl]²⁺ / ④ Co(NH3)3Cl3)
① cis-[Co(en)2(H2O)2]³⁺
② cis-[Co(NH3)4Br2]⁺
③ trans-[Co(en)2(NH3)Cl]²⁺
④ Co(NH3)3Cl3

사고과정

① cis-[Co(en)2X2]는 두 en이 프로펠러처럼 배치돼 거울상이 겹쳐지지 않음(키랄). → ①

②(대칭면 존재)·③(trans, 대칭)·④(fac/mer 모두 대칭)는 비키랄.

거울상 이성질체는 내부 대칭면이 없어야 한다. cis-bis(이좌배위) 착물이 대표적 키랄 구조다.
문제 57착물 기하·자기성(Ni²⁺)정답 ①
[NiCl4]²⁻(상자성)·[Ni(CN)4]²⁻(반자성). 각 기하구조와 홀전자 수는?
① NiCl4²⁻ 사면체·홀전자 2 / Ni(CN)4²⁻ 사각평면·홀전자 0
② NiCl4²⁻ 사각평면·1 / Ni(CN)4²⁻ 사면체·1
③ NiCl4²⁻ 사면체·1 / Ni(CN)4²⁻ 사각평면·2
④ NiCl4²⁻ 사각평면·2 / Ni(CN)4²⁻ 사면체·0

사고과정

Ni²⁺ = d⁸. [NiCl4]²⁻: Cl⁻ 약한장 → 사면체, 홀전자 2(상자성). [Ni(CN)4]²⁻: CN⁻ 강한장 → 사각평면, 홀전자 0(반자성). → ①

배위수 4 d⁸: 약한장이면 사면체(홀전자 2), 강한장이면 사각평면(홀전자 0·반자성)을 이룬다.
문제 58결정장·흡수 파장(Fe³⁺)정답 ②
[Fe(CN)6]³⁻(400nm 흡수)·[Fe(NCS)6]³⁻(700nm 흡수)의 d-전자 배치로 옳은 것은?
① 둘 다 저스핀
② CN⁻ 저스핀(t2g⁵)·NCS⁻ 고스핀(t2g³eg²)
③ CN⁻ 고스핀·NCS⁻ 저스핀
④ 둘 다 고스핀

사고과정

Fe³⁺ = d⁵. [Fe(CN)6]³⁻ 400nm(큰 Δ·강한장) → 저스핀 t2g⁵(홀전자 1). [Fe(NCS)6]³⁻ 700nm(작은 Δ·약한장) → 고스핀 t2g³eg²(홀전자 5). → ②

문제 59전기분해·산화수정답 ③

Crn++ne⁻→Cr. 흘린 전자 몰수를 석출된 금속 몰수로 나누면 이온의 전하수(n)가 나온다.
문제 60농도 전지정답 ②
Cu 농도 전지. 전위차 절댓값이 더 크고 전자 이동 방향이 모두 옳은 것은? (① 0.1/0.2·→ / ② 0.3/0.1·← / ③ 0.3/0.1·→ / ④ 0.1/0.2·←)
① 0.1M↔0.2M, 전자 →
② 0.3M↔0.1M, 전자 ←
③ 0.3M↔0.1M, 전자 →
④ 0.1M↔0.2M, 전자 ←

사고과정

전자는 묽은 쪽(산화, Cu→Cu²⁺)→진한 쪽(환원)으로 흐르고, |ΔE|는 농도비 클수록 큼. ①(비2·방향 옳음)·②(비3·방향 옳음) 중 ②(비 3)가 전위차 더 큼. → ②

③④는 전자 이동 방향이 반대(틀림).

농도 전지는 농도를 같게 하려 묽은 쪽이 산화(음극). 농도비 [진한]/[묽은]이 클수록 기전력이 크다.
