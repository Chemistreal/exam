문제 1동위원소정답 ②

사고과정

② Na·Al·P는 모두 단일 안정 동위원소(원자량 22.99·26.98·30.97로 정수에 근접). 단일 동위원소라도 질량결손으로 정수보다 약간 작다. → ②

① C·N·O 모두 동위원소 2개 이상. ③ Fe는 4종. ④ Pt·Hg는 여러 종.

단일 동위원소 원소(Na·Al·P·F·Co·Au 등)는 원자량이 정수에 가깝되, 핵 결합에너지 질량결손으로 약간 작다.
문제 2질량정답 ②

사고과정

1톤 = 106 g·밀도 1 → 부피 106 mL = 1000L.

몰수 = 10−8 mol/L × 1000L = 10−5몰.

질량 = 10−5×409 = 4.09×10−3 g = 4.09 mg.

→ ②

10 nM = 10−8 M. 몰농도×부피(L)로 몰수를, 몰수×화학식량으로 질량을 구한다.
문제 3분자식구하기정답 ③

사고과정

Y=NO는 N당 O 1개(비율 2).

Z는 비율 3 = Y의 1.5배 → N당 O 1.5개 → N2O3(2N:3O).

→ ③

참고: X(비율 1)는 N당 O 0.5개 → N2O. 같은 N 양 기준으로 O 원자수를 비교한다. NO(N당 O 1)를 기준 2로 잡으면 비율이 곧 N당 O 개수의 2배다.
문제 4정밀도정확도정답 ④

사고과정

정확도 = 평균이 참값(41)에 가까움, 정밀도 = 측정값 흩어짐 작음. D는 평균 41(정확) but 39·41·43으로 편차 큼(부정밀). → ④

A 평균42(부정확). B 평균40.0(부정확). C 정확하고 정밀(둘 다 높음).

정확도와 정밀도는 별개. 평균은 맞아도(정확) 값들이 들쭉날쭉(부정밀)할 수 있다.
문제 5피펫사용법정답 ③

사고과정

③ 피펫벌브로 안전하게 흡입하고, 옮김 피펫은 마지막 한 방울을 남기도록 보정돼 있어 불거나 짜내지 않음. → ③

①② 입으로 빨기(위험). ④ 벌브를 짜서 남은 액 배출(보정 위배).

실험실서 입으로 빠는 마우스 피펫팅은 금지. 용량 피펫(TD)은 잔류 방울을 남기도록 설계돼 강제 배출하면 안 된다.
문제 6원자반지름정답 ②

사고과정

주기 →로 반지름↓·금속성↓·IE↑·전기음성도↑. 나 금속성 최대 = Na. 다 1차 IE 최소 = Na. 가 반지름 최대는 Na(Cl 아님). 라 전기음성도 최소도 Na(Cl은 최대). → ②

같은 주기서 왼쪽 원소(Na)가 반지름·금속성 최대, IE·전기음성도 최소다.
문제 7이온반지름정답 ③

사고과정

S2−·K+·Ca2+는 등전자(18e−) → 핵전하 클수록 작음: S2−(16)>K+(19)>Ca2+(20).

Ga3+(28e−·Z=31)은 유효핵전하 커 최소.

→ ③

등전자 이온은 양성자 수가 많을수록 전자를 강하게 당겨 작아진다. Ga3+는 d전자까지 있어 가장 작다.
문제 8원자가전자정답 ②

사고과정

원자가 전자 수: 5·6·7(N→F)→1·2·3(Na→Al), 증가 후 리셋·재증가. 전기음성도가 같은 패턴(N→F 증가·Na서 급락·Na→Al 증가). → ②

①④ 반지름은 단조 감소(반대). ③ IE는 N>O 예외로 불일치.

전기음성도는 원자가 전자 수처럼 주기 내 증가하다 새 주기서 리셋된다. 반지름류는 정반대로 단조 감소.
문제 9산소산의세기정답 ①

사고과정

① HClO4는 가장 강한 산(Cl +7·비수산기 O 3개)이고 H2SO3는 약산 → "H2SO3>HClO4"는 틀림. → ①

②(HNO3 O 더 많음)·③(Cl이 Br보다 전기음성)·④(Cl +5>+3)는 옳음.

산소산 세기는 비수산기 산소가 많을수록(중심 산화수 높을수록)·중심 원자 전기음성도가 클수록 강하다.
문제 10이온화에너지정답 ④

사고과정

IE 도약 위치로 족 판별: A(E₂후 도약)=Be(2족), B(E₁후)=Na(1족), C(E₂후)=Mg(2족), D(E₃후)=Al(13족). 나 B(Na) 원자가 전자 1로 최소. 다 Mg→Mg²⁺ = E₁+E₂ = 738+1451 = 2189. 가 Be·Al은 다른 족. → ④

순차 IE가 급증하는 지점이 원자가 전자 수를 알려준다. 안정 이온 형성에 필요한 에너지는 떼어낼 전자들의 IE 합이다.
문제 11평균운동속력정답 ①

사고과정

같은 온도서 속력 ∝ 1/√M.

몰질량 Cl271>F238>O232>N228 → 속력은 Cl2<F2<O2<N2.

→ ①

평균 운동에너지는 같아도(온도 동일) 무거운 분자가 느리다. 속력은 분자량의 제곱근에 반비례.
문제 12기체법칙정답 ②

사고과정

② 샤를의 법칙은 V가 절대온도에 비례(반비례 아님). 틀림. → ②

①(보일 V∝1/P)·③(아보가드로 V∝n)·④(돌턴 부분압 합)는 옳음.

샤를: 압력 일정서 온도↑면 부피↑(비례). 보일만 반비례(압력-부피) 관계다.
문제 13PV=nRT정답 ③

사고과정

같은 기체·같은 T·P → 밀도 동일이라 질량 ∝ 부피.

X = 6.70×(2.33/1.30) = 12.0 g.

→ ③

문제 14용액의총괄성정답 ③

사고과정

③ 콜라(설탕 용액)는 용질 때문에 어는점 내림(총괄성)이 일어나 0°C 아래서 언다. → ③

① 기압 영향. ② 가열에 의한 수분 방출. ④ 물의 밀도 이상(얼음이 더 가벼움).

총괄성(어는점 내림·끓는점 오름·삼투압)은 용질 입자 수에만 의존한다. 기압·밀도 효과는 총괄성이 아니다.
문제 15증기압정답 ②

사고과정

245 = χ물×250 → χ물 = 0.98, χ포도당 = 0.02.

물 = 1800/18 = 100몰.

χ포도당 ≈ n/물 = 0.02 → n = 2몰.

질량 = 2×180 = 360 g.

→ ②

라울 법칙: 용액 증기압 = 용매 몰분율×순수 증기압. 증기압 내림으로 용질 몰분율을 구한다.
문제 16실제용액정답 ③

사고과정

실측 증기압 > 이상(양의 편차) → 분자가 더 쉽게 증발 → A-B 인력이 A-A·B-B보다 약함.

→ ③

양의 편차는 이종 분자(A-B) 인력이 동종보다 약할 때. 음의 편차면 A-B 인력이 더 강하다.
문제 17이상용액정답 ①

사고과정

증기 몰비 = 분압비.

PA = 0.2×40 = 8, PB = 0.8×90 = 72 torr.

비 = 8:72 = 0.1:0.9.

→ ①

분압 = 액체 몰분율×순수 증기압(라울). 기체 상태의 몰비는 곧 분압의 비와 같다.
문제 18반도체도체정답 ③

사고과정

ⓐ 온도↑서 저항↓ = 반도체(열로 전자가 띠틈 넘어 증가). ⓑ 온도↑서 저항↑ = 도체(격자 진동↑로 전자 산란↑). → ③

금속(도체)은 가열 시 저항 증가, 반도체는 가열 시 전도 전자가 늘어 저항 감소한다.
문제 19전기전도도정답 ①

사고과정

전도도 ∝ 이온 농도. 가 1M NaCl → 이온 2M. 나 Na2CO3 0.01몰+HCl 0.02몰 완전반응 → NaCl 0.02몰/200mL = 0.1M → 이온 0.2M. 다 아세트산 α=0.01 → 이온 0.02M. 가>나>다. → ①

강전해질은 완전 해리, 약산은 일부만 해리. 중화 후 남은 강전해질(NaCl)과 미해리 약산의 이온 수를 비교한다.
문제 20분자간인력정답 ③

사고과정

분자간 인력↑ → 점성·표면장력·끓는점 모두 증가. 그러나 증기압은 분자가 탈출하기 어려워 감소. → ③

강한 인력은 분자를 붙잡아 증발을 억제하므로 증기압을 낮춘다(휘발성 감소).
문제 21끓는점정답 ①

사고과정

헥산올(–OH 수소결합·큰 분자, ~157°C) > 벤젠(~80°C) > 헥세인(~69°C) > 뷰테인(가장 작음, ~0°C).

→ ①

수소결합(헥산올)이 가장 강하고, 같은 탄소 수면 분자량·구조로 비교. 작은 뷰테인이 끓는점 최저.
문제 22반응의자발성정답 ③

사고과정

③ 불포화 용액은 더 녹을 수 있어 소금이 저절로 석출되지 않음(비자발). → ③

문제 23고체의구조전원정답

사고과정

이 문항은 원본 시험에서 문제삭제되었다.

HCP의 "단위 세포"는 정의가 둘이다 — 기본 단위 세포(원자 2개)와 큰 육방 기둥 세포(원자 6개).

보기(3·4·5·6)에 2가 없고 세포 정의가 모호해 전원정답 처리되었다.

육방 기둥 세포 기준: 꼭짓점 12×(1/6)+면심 2×(1/2)+내부 3 = 6개.

기본 세포 기준은 2개로, 어떤 세포를 묻는지 불명확했다.

문제 24고체의구조정답 ②

사고과정

O(BCC): 꼭짓점 8×(1/8)+체심 1 = 2개.

Cu: 세포 내부에 완전히 든 4개.

Cu:O = 4:2 = 2:1 → Cu2O.

→ ②

체심 입방은 단위세포당 2개. 내부에 온전히 든 원자는 1개로 센다. 이 구조가 적동석(Cu2O)이다.
문제 25화학식구하기정답 ④

사고과정

2차원 반복 단위에서 꼭짓점·모서리 공유를 고려해 V(흰)·Os(검정) 원자 수를 세면 V:Os = 7:9 → V7Os9.

→ ④

2차원 격자도 단위 세포 경계의 원자를 분수로 센다. 반복되는 최소 단위의 두 원자 비가 화학식이다.

이를 옳게 그린 것은 ④.

문제 27수소원자정답 ①
