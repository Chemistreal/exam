# 오답노트 · 동형문제 슬롯

성적표 PDF의 **오답 정리 노트**에서, 틀린 문항마다 그 개념을 다시 확인할 수 있는
**동형문제(스스로 확인용)**를 자동으로 붙이기 위한 폴더입니다.
문제·해설 내용은 **관리자가 직접** 작성해 채웁니다(한 회차/문항당 1개만 만들어 두면 모든 학생에게 재사용).

## 파일 규칙

```
donghyung/<시험id>.json
```

- `<시험id>` : `final.html` 의 시험 id (예: `jmchc-1`, `hwol-2015`, `sanyeom-60` …)
- 키는 **문항 번호**(문자열), 값은 그 문항의 동형문제 객체.

## 형식

```json
{
  "11": {
    "stem": "문제 지문을 여기에 적습니다.",
    "choices": ["보기1", "보기2", "보기3", "보기4"],
    "answer": 3,
    "sol": "해설을 여기에 적습니다.",
    "mis": "오개념 분석을 여기에 적습니다."
  },
  "13": {
    "stem": "...",
    "choices": ["...", "...", "...", "..."],
    "answer": 1,
    "sol": "...",
    "mis": "..."
  }
}
```

| 필드 | 설명 | 필수 |
|---|---|---|
| `stem` | 문제 지문 | 권장 |
| `choices` | 보기 배열(①②③④ 순서로 자동 번호) | 권장 |
| `answer` | 정답 번호(1~4) | 선택 |
| `sol` | 해설 | 선택 |
| `mis` | 오개념 분석 | 선택 |

## 동작

- 학생이 그 문항을 틀렸고, 해당 번호의 동형문제가 파일에 있으면 → 오답노트에
  **동형문제 + 풀기 칸(①②③④) + 정답·해설·오개념 분석**이 함께 출력됩니다.
- 없으면 → 조용히 생략(오류 없음).
- 한 번 작성해 두면 그 시험을 응시한 **모든 학생 리포트에 자동 재사용**됩니다.

`_template.json` 을 복사해 시작하세요.
