문제 1염의액성정답 ③

사고과정

각 염이 물에서 가수분해하는지 이온마다 본다.

강산·강염기에서 온 이온은 가수분해하지 않는다.

NH4+ 만 약염기의 짝산이라 가수분해해 산성을 낸다.

→ ③

문제 2산의세기정답 ①

사고과정

'가장 약한 염기' 를 만드는 것을 찾는다.

HNO3 는 강산이라 수용액이 아예 산성이다.

염기성 쪽으로 늘어놓으면 HNO3 < HNO2 < NaHCO3 < Na2CO3 다.

→ ①

문제 3루이스산정답 ④

사고과정

루이스 산은 비공유 전자쌍을 받는 쪽이다.

CCl3+ 의 C 와 BF3 의 B 는 옥텟이 비어 받을 자리가 있다.

H2O 는 양쪽성이라 산으로도 쓰이니 셋 다 된다.

→ ④

문제 4산화환원의정의정답 ④

사고과정

각 반응에서 산화수가 바뀌는지 본다.

①②③ 은 홑원소가 드나들어 산화수가 바뀐다.

중화 반응만 어느 원소의 산화수도 그대로다.

→ ④

문제 5산화수정답 ②

사고과정

중심 원자의 산화수를 하나씩 매긴다.

CaO 는 +2, XeF6 는 +6, PO43− 는 +5, [PdCl4]2− 는 +2, [Cr(H2O)6]3+ 는 +3 이다.

+2 끼리 묶인 것을 고른다.

→ ②

문제 6전도도적정정답 ①

사고과정

적정 중에 이온이 어떻게 되는지 따라간다.

Ba(OH)2 와 (NH4)2SO4 가 만나면 BaSO4 앙금과 약염기 NH3·H2O 가 되어 이온이 사라진다.

중화점에서 전도도가 바닥을 찍고, 그 뒤 넣는 (NH4)2SO4 가 그대로 남아 다시 오른다.

→ ①

문제 7산화수정답 ④

사고과정

각 화합물에서 할로젠의 산화수를 매긴다.

F 는 어느 화합물에서나 −1 이라 HOF 에서도 −1 이고, HOCl 의 Cl 은 +1 이다.

합하면 0 이다.

→ ④

문제 8농도환산정답 ③

사고과정

진한 황산의 몰농도를 먼저 구한다.

100 g 속 96 g 은 0.98 mol 이고 부피는 100/1.84 = 54.3 mL 이니 18 M 이다.

18 M × x = 1.0 mol 에서 x = 55.5 mL 다.

→ ③

문제 9라울법칙정답 ④

사고과정

몰분율 0 과 1 의 끝값에서 순물질의 증기압을 읽는다.

톨루엔 300, 벤젠 750 mmHg 쯤이니 벤젠이 더 잘 증발하고 끓는점이 낮다.

벤젠 몰분율이 클수록 전체 증기압이 오르고, 톨루엔을 넣으면 벤젠의 증기압은 내려간다.

→ ④

문제 10결합에너지정답 ①

사고과정

결합에너지로 ΔH = (끊는 결합) − (만드는 결합) 을 셈한다.

(4×411 + 240) − (3×411 + 327 + 428) = 1884 − 1988 이다.

−104 kJ/mol 이다.

→ ①

문제 11등전자이온정답 ④

사고과정

넷 다 [Ne] 등전자임을 알아챈다.

같은 전자 배치에서는 양성자가 많을수록 당김이 세 반지름이 작다.

양성자가 가장 많은 Na+ 가 가장 작다.

→ ④

문제 12러더퍼드정답 ②

사고과정

실험 결과가 어느 모형을 무너뜨렸는지 본다.

톰슨 모형이라면 알파 입자가 모두 통과해야 하는데 일부가 크게 튕겼다.

원자 질량 대부분이 작고 무거운 양전하 덩어리에 몰려 있다는 뜻이다.

→ ②

문제 13부분압력정답 ②

사고과정

포집된 기체는 수소와 수증기가 섞여 있다.

수소의 부분압은 1.032 − 0.042 = 0.99 atm 이다.

n = PV/RT = 0.99×0.24/(0.082×303) = 9.56×10−3 mol 이다.

→ ②

문제 14혼성오비탈정답 ①

사고과정

각 원자의 입체수를 센다.

+CH2 는 결합 셋이라 sp2, C≡N 의 탄소와 질소는 sp

다. 질소의 비공유 전자쌍은 sp 궤도에 있다.

→ ①

문제 15비열정답 ③

사고과정

Q = cmΔt 로 올린 온도를 구한다.

Δt = 2280/(0.70×36) ≈ 90.5°C

다. 25 + 90.5 ≈ 115°C 가 녹는점이다.

→ ③

문제 16분출속도정답 ②

사고과정

같은 온도면 v ∝ √(1/M) 이다.

238UF6 는 352, 235UF6 는 349 이니 비는 √(352/349)

다. 약 1 : 1.004 다.

→ ②

문제 17활성화에너지정답 ④

사고과정

에너지 도표에서 활성화 에너지와 ΔH 를 갈라 읽는다.

Y→X 의 활성화 에너지는 U + T 이고, X→Y 에서 오간 에너지는 ΔH = T

다. 평형에 이르면 X 도 남고, 속도는 활성화 에너지가 정하니 늘 빠르지도 않다 — 옳은 것이 없다.

→ ④

문제 18압력평형상수정답 ④

사고과정

Kp 식에 주어진 분압을 넣는다.

Kp = P(CO)·P(H2)3 / (P(CH4)·P(H2O)) = x×0.008/(0.2×0.2) = 2.0 이다.

x = 10 atm 이다.

→ ④

문제 19기체의밀도정답 ④

사고과정

표준 상태에서 기체 1 몰의 부피를 구한다.

V = nRT/P = 0.082×298 ≈ 24.4 L

다. 44 g / 24.4 L ≈ 1.8 g/L 이니 가장 가까운 값은 2 g/L 다.

→ ④

문제 20반응엔탈피정답 ②

사고과정

Al 1 kg 이 몇 몰인지가 아니라 반응식 한 번에 Al 이 몇 g 나오는지를 본다.

Al2O3 한 번에 Al 이 두 개, 곧 53.8 g 이 나오고 그때 1676 kJ 이 든다.

1000/53.8 × 1676 ≈ 3.1×104 kJ 이다.

→ ②

문제 21엔트로피정답 ④

사고과정

기체 분자 수가 늘어나는 쪽을 찾는다.

①②③ 은 기체가 줄거나 고체가 되어 엔트로피가 준다.

H2 + I2(s) → 2HI 만 고체가 기체가 되고 기체 몰수도 는다.

→ ④

문제 22상평형도정답 ②

사고과정

탄소의 상평형도에서 다이아몬드 영역이 어디인지 본다.

다이아몬드는 높은 압력 쪽이라 1 기압 선에 닿지 않는다.

곧 다이아몬드는 승화할 수 없다.

→ ②

문제 23반응지수정답 ②

사고과정

Q 와 K 를 견줘 어느 쪽으로 가는지 본다.

Q < K 면 정반응, Q > K 면 역반응이 우세하다.

②가 뒤집혀 있다.

→ ②

문제 24상변화의 자발성정답 ①

사고과정

얼음이 녹는 과정을 본다.

녹으려면 열을 빨아들이니 ΔH > 0 이다.

고체가 액체가 되어 흐트러지니 ΔS > 0 이다.

→ ①

문제 25산화환원반응정답 ②

KO2 의 산화수부터 매긴다.

K 가 +1 이니 O 는 −1/2 인 초과산화물이다.

두 반응 모두 홑원소 O2 가 나오므로 산화·환원이다.

→ ②

문제 26용해도곱정답 ③

사고과정

AB 꼴이므로 Ksp = x2

다. x = √(7.7×10−13) = 8.8×10−7 mol/L

문제 27유기반응의생성물정답 ②

사고과정

BCl3 의 붕소는 옥텟이 비어 있고 (CH3)2S 의 황에는 비공유 전자쌍이 있다.

황이 전자쌍을 내주어 붕소에 배위 결합한다.

황이 +, 붕소가 − 형식전하를 갖는 부가물이 된다.

→ ②

문제 28평형상수정답 ④

사고과정

평형 상수가 무엇에 매이는지 짚는다.

K 는 온도에만 매이므로 농도를 넣거나 부피를 바꿔도 그대로다.

부피를 두 배로 늘리면 모든 분압이 반이 되고, 그 뒤 평형이 옮겨 가도 COCl2 분압은 늘어난 직후보다 더 줄어든다.

→ ④

문제 29순차이온화에너지정답 ④

사고과정

이온화 에너지는 오비탈의 에너지 준위가 낮을수록 크다.

2s 가 2p 보다, 1s 가 2p 보다 낮으니 그 전자를 떼기가 더 어렵다.

수소의 1s 는 He 보다 핵전하가 작아 이온화 에너지가 작다 — ④가 뒤집혔다.

→ ④

문제 30분자의극성정답 ④

사고과정

각 분자의 모양을 그려 쌍극자가 상쇄되는지 본다.

CHCl3 는 사면체이지만 한 자리가 H 라 안 지워지고, NCl3 는 삼각뿔, H2S 는 굽은형이다.

BF3 만 평면삼각형으로 대칭이라 상쇄된다.

→ ④

문제 31모세관현상②·③ 복수정답

사고과정

모세관 상승과 표면장력이 무엇으로 정해지는지 짚는다.

응집력과 부착력이 셀수록 높이 오르니 ②는 뒤집혔다.

표면장력은 액체 분자 사이의 힘이라 중력과 무관해 달에서도 같다 — ③도 틀렸다.

→ ②

문제 34방사성붕괴정답 ③

14055Cs → 0−1β + 14056Ba 로 질량수는 그대로, 원자번호는 1 는다.

x + y + z = 0 + (−1) + 140 = 139 다.

→ ③

문제 35배위화합물정답 ②

사고과정

착이온 전체 전하에서 리간드 전하를 뺀다.

Cl− 여섯이 −6 이고 전체가 −3 이니 Mn 은 +3 이다.

Mn 은 [Ar]4s23d5 이라 Mn3+ 는 [Ar]3d4 다.

→ ②

문제 36분자의구조정답 ③

사고과정

SO32− 는 결합 3 + 고립쌍 1 로 삼각뿔, NH3 도 삼각뿔이다.

BF3·CO32− 는 평면삼각형, ClF3 는 T자형이다.

→ ③

문제 37면심입방정답 ③

사고과정

면심입방에서는 면 대각선을 따라 원자가 맞닿는다.

4r = √2 a 이므로 r = √2 × 362 / 4

다. 약 128 pm 이니 가장 가까운 값은 130 pm 다.

→ ③

문제 38르샤틀리에원리정답 ②

사고과정

르샤틀리에로 하나씩 본다.

고체를 더하는 것과 생성물을 빼는 것은 정반응을 돕지 않는다.

4NH3 + 5O2 ⇌ 4NO + 6H2O 는 기체가 9 → 10 으로 늘어 압력을 낮추면 정반응이다.

→ ②

문제 39삼투압정답 ②

사고과정
