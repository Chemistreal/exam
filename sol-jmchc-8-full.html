문항별 사고과정

문제 1수소결합정답 ①

사고과정

−OH 개수가 3개(글리세롤) > 2개 > 1개로 갈수록 점도가 급증.

−OH가 많을수록 수소결합 망이 촘촘해 흐름이 느려진다.

→ ①

점도는 분자끼리 얼마나 강하게 얽히는가의 문제. −OH가 많으면 수소결합이 많아져 점도가 커진다(글리세롤이 끈적한 이유).
문제 2분산력정답 ①

사고과정

HF·NH3는 수소결합, SiH4는 CH4보다 무겁다.

CH4가 가장 작고 무극성·분산력만 → 끓는점 최저.

→ ①

같은 14족이라도 SiH4가 CH4보다 무거워 끓는점이 높다. 수소결합 없는 가장 작은 분자가 CH4.
문제 3수소결합정답 ①

사고과정

H−X 결합 세기는 원자가 작을수록 강하다: H−O > H−S > H−Se > H−Te.

H2O의 H−O 결합이 가장 강하다.

→ ①

이건 끓는점(분자 간)이 아니라 분자 내 결합 세기 문제. 작은 원자일수록 결합 길이가 짧고 강하다.
문제 4분산력정답 ①

사고과정

모두 무극성이라 분산력(∝분자량)이 결정: CH4(16) < Cl2(71) < Br2(160) < CBr4(332).

→ c < d < b < a.

→ ①

무극성 분자끼리는 무거울수록(분극성 클수록) 분산력↑ → 끓는점↑. 분자량 순서대로 끓는점이 오른다.
문제 5쌍극자간인력정답 ③

사고과정

에탄올(78°C, −OH 수소결합) > 아세톤(56°C, 케톤 쌍극자) > 다이에틸에테르(35°C, 약한 에터).

내림차순 = (다) > (가) > (나).

→ ③

수소결합(에탄올) > 쌍극자(아세톤) > 약한 쌍극자(에터). "낮아지는 순서"는 높은 것부터 적는다.
문제 6분자사이의힘정답 ②

사고과정

①(O2 더 무거움)·③(HF 수소결합)·④(H2Se 더 무거움)는 옳다.

② NO는 극성(쌍극자-쌍극자)이라 무극성 O2보다 끓는점이 높다 → "O2 > NO"는 거짓. → ②

분자량이 비슷하면(O2 32, NO 30) 극성 여부가 끓는점을 가른다. 극성 NO > 무극성 O2.
문제 7분산력정답 ②

사고과정

가장 높음 = H2O(100°C, 강한 수소결합).

가장 낮음 = N2(−196°C, 무극성·최경량).

→ ②

물이 수소결합으로 단연 최고, 무극성이고 가벼운 N2가 최저. SO2·NH3는 중간.
문제 8얼음정답 ④

사고과정

물은 극성 분자라 쌍극자 힘·분산력·수소결합(가·나·다)이 모두 작용. 라 이온-쌍극자는 이온이 없어 순수한 얼음엔 없다. → ④

모든 분자엔 분산력이 있고, 극성이면 쌍극자 힘, O−H가 있으면 수소결합까지. 이온-쌍극자는 이온(전해질)이 있어야 한다.
문제 9비활성기체정답 ②

주어진 것 보기는 O3, He2, S8, P4 네 가지이고, 이 중 상온에서 존재하지 않는 것을 고르는 문제다.

판단 기준 원자들이 모여 하나의 분자로 존재하려면 그 원자들 사이에 실제 결합이 만들어져야 하고, 분자 궤도 관점에서는 결합 차수가 0보다 커야 한다.

① O3 오존은 산소 원자 3개가 굽은 구조로 이어진 분자이며, 성층권의 오존층과 지표 부근 대기에 실제로 존재하는 산소의 동소체다.

상온에서 존재한다.

② He2 헬륨은 18족이고 전자 배치가 1s2 인 닫힌 껍질이다.

두 He 원자가 접근하면 결합성 σ1s 궤도에 전자 2개, 반결합성 σ*1s 궤도에 전자 2개가 들어간다.

결합 차수 = (2 − 2)/2 = 0 이므로 결합이 만들어지지 않는다.

상온에서 He2 분자는 존재하지 않는다.

③ S8 상온에서 가장 안정한 황인 사방황은 황 원자 8개가 왕관 모양 고리를 이룬 S8 분자가 쌓인 결정이다.

상온에서 존재한다.

④ P4 흰인은 인 원자 4개가 정사면체의 네 꼭짓점에 놓인 P4 분자다.

상온에서 존재한다.

결론 존재하지 않는 것은 He2 이므로 답은 ②

다. 참고 극저온에서 헬륨 원자 두 개가 반데르발스 힘으로 아주 약하게 묶인 이합체가 관측된 적은 있으나, 이는 화학 결합이 아니고 상온에서는 유지되지 않는다.

문제 10분산력정답 ③

사고과정

CH4는 무극성·O−H 없음.

분자를 모으는 유일한 힘은 분산력(순간 쌍극자).

→ ③

무극성 분자는 분산력만으로 액화·고화된다. 표면장력은 힘의 종류가 아니라 결과(현상)다.
문제 11분자의구조정답 ④

사고과정

①(O·C·N 모두 옥텟 충족)·②(VSEPR로 구조 결정)·③(H2O·NH3 끓는점은 수소결합 관련)는 옳다.

④ CH4는 고립쌍이 없다(4개 결합 모두 사용). "모두 비공유 전자쌍"은 거짓. → ④

H2O(고립쌍 2)·NH3(고립쌍 1)는 비공유쌍이 있지만 CH4는 0개. 정사면체 CH4만 예외다.
문제 12탈출속도정답 ③

사고과정

목성-지구 차이의 핵심은 중력에 의한 기체 붙잡기: ①(작은 분자량→빠른 속도→탈출)·②(무극성→약한 인력→기체로 남아 탈출)·④(태양에 가까워 따뜻→더 빠른 탈출)는 모두 탈출과 관련.

③ 산소와의 반응(화학적 소모)은 지구만의 화학이지, 목성과의 H2 보유 차이를 설명하는 요인이 아니다. → ③

행성의 H2 보유 여부는 중력(질량)·온도로 결정되는 물리적(탈출) 문제. 거대한 목성은 중력으로 H2를 붙잡고, 지구는 놓친다. 산소 반응은 이 비교와 무관.
문제 13속도정답 ③

사고과정

속도 ∝ 1/√M, 가벼울수록 빠르다.

몰질량: H2(2) < Ne(20) < N2(28) < O2(32) < Ar(40).

→ 수소 > 네온 > 질소 > 산소 > 아르곤.

→ ③

함정은 Ne(20)이 N2(28)보다 가벼워 더 빠르다는 점. 단원자 Ne을 무겁다고 착각하지 말 것.
문제 14분자량정답 ②

사고과정

몰질량: 238UF6 = 352, 235UF6 = 349. 분출속도 ∝ 1/√M.

속도(238)/속도(235) = √(349/352) ≈ 0.996 → 238 : 235 = 1 : 1.004(가벼운 235가 약간 빠름). → ②

우라늄 농축의 원리. 질량 차이가 작아(352 vs 349) 속도 차이도 극히 미세(0.4%)해 수천 번 반복해야 분리된다.
문제 15분출속도정답 ①

사고과정

분출 속도 ∝ P/√M(압력×속도, 같은 온도): (가) 2/√2 = 1.41, (나) 2/√4 = 1.0, (다) 4/√32 = 0.71.

→ (가) > (나) > (다).

→ ①

구멍으로 나오는 분자 수 = (밀도)×(속도) ∝ P/√M. 압력이 높을수록·가벼울수록 많이 새어 나간다.
문제 16충돌수정답 ②

사고과정

같은 P·V인데 T(A)=4T(B)라 몰수 n(A) = n(B)/4.

속도 v(A) = 2v(B)(√4).

충돌빈도 ∝ n×v: A/B = (1/4)×2 = 1/2 → 1:2.

→ ②

압력이 같아도 충돌빈도는 다르다. 충돌빈도 ∝ P/√T라 뜨거운 A(분자 적고 빠름)가 오히려 충돌이 적다.
문제 17분자운동속도정답 ②

사고과정

같은 온도 → 평균 운동에너지 동일(3/2 kT).

속도 ∝ 1/√M라 가벼운 H2가 더 빠름.

→ ②

온도가 같으면 운동에너지는 무조건 같다. 속도만 질량에 따라 갈린다(가벼우면 빠름).
문제 18이상기체정답 ②

사고과정

①(둘 다 1몰)·③④(속도비는 온도·압력 무관, 몰질량만)는 옳다.

② 속력비 = √(M역비) = √(2/32) = 1/4(O2:H2 = 1:4)지 1:16이 아니다. → ②

속력은 1/√M에 비례. 몰질량비 16:1이라도 속력비는 √16 = 4 → 1:4. 제곱근 빼먹는 함정.
문제 19반응식정답 ①

사고과정

균형: SO2 + 2Cl2 → SOCl2 + OCl2(a=1,b=2,c=1,d=1).

① 몰질량 SO2(64)<OCl2(87)<Cl2(71)... 최경량 SO2이 최고속. ② SOCl2는 고립쌍 있어 삼각뿔. ③ d=1 ≠ a+c=2. ④ 최소 이온화는 S(O보다 작음). → ①

혼합 기체에서 가장 빠른 건 가장 가벼운 분자. SOCl2은 S에 고립쌍이 있어 평면이 아닌 삼각뿔이다.
문제 20밀도정답 ②

사고과정

가 밀도 = 질량/부피, 둘 다 일정 → 불변. 다 평균자유행로는 수밀도에만 의존 → 불변.

나 평균 운동에너지 ∝ T → 가열하면 증가. → ②

정적 가열에서 변하는 건 온도 의존량(운동에너지·압력·속도)뿐. 밀도·평균자유행로는 부피·분자수에만 의존해 불변.
문제 21이상기체정답 ④

사고과정

이상기체에 가까워지려면 낮은 압력(분자 멀어짐)·높은 온도(운동에너지가 인력 압도)·작은 n(낮은 밀도).

→ ④

분자 부피와 분자간 힘을 무시할 수 있을 때 이상적. 저압·고온·저밀도일수록 실제 기체가 이상기체에 가까워진다.
문제 22부분압력정답 ①

사고과정

P = 570/760 = 0.75기압. n = PV/RT = (0.75×1)/(0.0821×300) ≈ 0.0305몰.

질량 = 0.0305 × 16 ≈ 0.49 ≈ 0.50g. → ①

부분압력만으로 그 기체의 몰수를 구한다(혼합기체의 다른 성분은 무관). torr→atm 변환(÷760) 주의.
문제 23분자사이의힘정답 ④

사고과정

a는 분자간 인력 크기.

물(수소결합) > CO2(크고 분극성) > Ar(단원자) > H2(최소).

→ ④

a 값 비교 = 분자간 힘 비교. 수소결합 > 큰 분자 분산력 > 작은 분자 순. 실제 a: H2O 5.5 > CO2 3.6 > Ar 1.3 > H2 0.24.
문제 24반데르발스식정답 ④

사고과정

①(극성↑→인력↑→a↑)·②③(큰 분자→부피↑→b↑)는 옳다.

④ Ar이 Ne보다 크고 분극성이 커 인력이 강함 → a(Ar) > a(Ne). "Ne > Ar"은 거짓. → ④

a = 인력(극성·분극성에 비례), b = 분자 부피(크기에 비례). Ar이 Ne보다 크니 a·b 모두 Ar이 크다.
문제 25증기압력정답 ③

사고과정

두 면이므로 2 × 1/2 = 1 개다.

5단계 O 를 합한다.

주어진 것 진한 황산은 질량 백분율 96 %, 밀도 1.84 g/mL 이고, 만들려는 것은 1.0 M H2SO4 수용액 1 L

다. 1단계 필요한 H2SO4 의 몰수를 구한다.

1.0 mol/L × 1.0 L = 1.0 mol 이다.

2단계 몰수를 질량으로 바꾼다.

표준 원자량(H 1.0, S 32.1, O 16.0)으로 M(H2SO4) = 2×1.0 + 32.1 + 4×16.0 = 98.1 g/mol 이므로 필요한 순수 H2SO4 는 약 98 g 이다.

3단계 진한 황산 용액의 질량을 구한다.

96 질량% 는 용액 100 g 안에 H2SO4 가 96 g 들어 있다는 뜻이므로, H2SO4 98 g 을 얻으려면 용액이 98 ÷ 0.96 = 102.1 g 필요하다.

4단계 질량을 부피로 바꾼다.

밀도가 1.84 g/mL 이므로 102.1 ÷ 1.84 = 55.5 mL

다. 결론 필요한 진한 황산은 55.5 mL 이므로 답은 ③

다. 다른 풀이 진한 황산의 몰농도를 먼저 구해도 같다.

1000 mL × 1.84 g/mL × 0.96 ÷ 98 g/mol = 18.0 mol/L 이고, M1V1 = M2V2 에서 V1 = 1.0 × 1000 ÷ 18.0 = 55.5 mL 다.
