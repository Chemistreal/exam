문제 1원자의구조정답 ③

난이도 중 수소 원자살은 홀전자 1개(1s1)를 가지고 있어서 자기장을 통과하면 위쪽과 아래쪽 두 가지 방향으로 나누어진다.다음 중 원자살이 자기장을 통과하였을 때 두 가지 방향으로 나누어지는 것을 모두 고르면? <보 기> Na, Ca, Cd, Ag ① 없음 ② Ca, Cd ③ Na, Ag ④ Na, Ca, Cd, Ag ■ 무엇을 묻는 문제인가 슈테른-게를라흐 실험을 소재로 삼아 전자 배치를 묻는 문제입니다.

원자살이 자기장에서 갈라지려면 홀전자(짝짓지 않은 전자)가 있어야 하므로, 결국 네 원소의 바닥상태 전자 배치를 정확히 쓸 수 있는지, 특히 Ag 같은 예외 배치를 아는지가 관건입니다.

1) 전자는 스핀 자기 양자수 ms = ±1/2 를 가집니다.

서로 짝지은 두 전자는 스핀이 +1/2과 -1/2로 반대라 자기 모멘트가 상쇄됩니다.

2) 모든 전자가 짝지어져 있으면 알짜 스핀 자기 모멘트가 0이 되어(반자성) 자기장 속에서 갈라지지 않고 그대로 직진합니다.

홀전자가 있으면(상자성) 스핀 방향에 따라 위/아래로 갈라져 두 줄기로 나뉩니다.3) 수소는 1s1로 홀전자가 1개이므로 두 갈래로 갈라집니다.

발문에서 말한 상황이 바로 그것입니다.

4) 전자 배치의기본 순서는 1s 2s 2p 3s 3p 4s 3d 4p 5s 4d 5p 6s 4f 5d 6p 이며, d5·d10 근처에서는 안정성 때문에 예외가 생깁니다(Cr, Cu, Mo, Ag, Au 등).

5) 채워진 부껍질(ns2, np6, nd10, nf14)은 전자가 모두 짝지어져 홀전자가 없습니다.단계 1) Na (원자번호 11) ― 1s22s22p63s1 입니다.

Cu, Au와 마찬가지로 d 부껍질을 꽉 채우는 것이 더 안정하기 때문에 5s가 하나만 채워지는 예외 배치입니다.

전자 수는 36 + 10 + 1 = 47 로 맞습니다.

5s에 홀전자 1개가 있으므로 갈라집니다.

문제 2에너지정답 ①

결국 핵심은 "엔탈피는 상태 함수이므로 경로를 어떻게 잡아도 총합은 같다"는 헤스 법칙입니다.

· 격자 에너지(여기서의 정의): 기체 상태의 이온이 모여 고체 이온 결정을 만들 때의 엔탈피 변화, 즉 Na+(g) +Cl−(g) → NaCl(s)의 ΔH입니다.

이온이 서로 강하게 끌려 안정해지므로 값은 항상 큰 음수입니다.

· 헤스 법칙: 반응을 여러 단계로 쪼개도 각 단계 ΔH의 합은 전체 ΔH와 같습니다.

· Born-Haber 순환: Na(s) + 1/2 Cl2(g)에서NaCl(s)로 가는 길을 두 가지로 놓습니다.

직접 경로 = (1) 생성 엔탈피 우회 경로 = 승화(2) + 결합 해리의 절반(1/2)×(3) + 이온화(4) + 전자 친화(5) + 격자 에너지 U · Cl2 결합 해리는 Cl 원자 2개를 만드는 값이므로, Cl 원자1개만 필요할 때는 반드시 1/2배 해야 합니다.

여기서 실수가 가장 많이 납니다.

단계 1) 순환식을 세웁니다.

ΔH(1) = ΔH(2) + (1/2)ΔH(3) + ΔH(4) + ΔH(5) + U 단계 2) 숫자를 대입합니다.

-411 = 108 + (1/2)(242) + 496 + (-349) + U -411 = 108 + 121 + 496 - 349 + U 단계 3) 오른쪽 상수부를 정리합니다.

108 + 121 = 229, 229 + 496 = 725, 725 - 349 = 376 -411 = 376 + U 단계 4) U를 구합니다.

U = -411 - 376 = -787 kJ/mol 단계 5) 타당성 검산 ― 실험적으로 알려진 NaCl의 격자 에너지는 약 -787 kJ/mol이며, KF의 -821 kJ/mol보다 크기가 조금 작습니다.

Na+와 Cl−의 거리(약 283 pm)가 K+와 F−의 거리(약 271 pm)보다 멀기 때문으로, 계산 결과가 화학적 감각과 어긋나지 않습니다.

위 계산과 정확히 일치하며 실험값과도 맞습니다.

② -291 ⇒ 틀림.

④ -908 ⇒ 틀림.

Cl2 해리 에너지 242를 절반으로 나누지 않고 그대로 쓰면 -908이 나옵니다.

가장 흔한 함정입니다.

문제 3에너지정답 ②

난이도 중 이온결합 화합물 RbI, NaF, BaTe 및 MgO를 격자 에너지가 감소하는 순서대로 바르게 나열한 것은? ① MgO > BaTe > RbI > NaF ② MgO > BaTe > NaF > RbI ③ BaTe > MgO > NaF > RbI ④ BaTe > MgO > RbI > NaF ■ 무엇을 묻는 문제인가 격자 에너지가 이온의 전하와 이온 간 거리로 어떻게 결정되는지를 알고, 그 두 요소 중 어느 쪽이 우선인지 판단할수 있는지 묻습니다.

격자 에너지는 기체 상태의 이온들이 모여 1몰의 이온 결정을 만들 때 방출되는 에너지의 크기입니다.

쿨롱 법칙에서 출발하면 |U| ∝ |z+ × z−| / (r+ + r−) 로 근사됩니다.

여기서 z는 이온 전하, r는 이온 반지름입니다.

분자에 있는 전하는 곱으로 들어가고 분모의 거리는1제곱으로만 들어가므로, 전하가 미치는 영향이 훨씬 큽니다.

그래서 격자 에너지 비교는 언제나 "전하 먼저, 반지름 나중"입니다.

이온 반지름 경향도 필요합니다.

거리가 짧은 MgO가 더 큽니다.

단계 3) 1가 그룹 내부 비교.

Na+(102 pm) + F−(133 pm) = 235 pm, Rb+(152 pm) + I−(220 pm) = 372 pm.

거리가 짧은 NaF가 더 큽니다.

실제 값은 NaF 약 923 kJ/mol, RbI 약 617 kJ/mol.

BaTe는 거리가 356 pm로 길지만 전하 곱이 4라서 4/356 = 0.0112이고, NaF는 거리가 235 pm로 짧아도 전하 곱이 1이라 1/235 = 0.0043입니다.

전하가 이겨서 BaTe > NaF입니다.

문제 4원자의구조정답 ②

난이도 중 다음 알칼리 금속에 대한 화학 반응식 중 타당하지 않은 것은? ① 2Rb(s) + 2H2O(l) → 2RbOH(aq) + H2(g) ② Na(s) + H2(g) → NaH2(s) ③ 4Li(s) + O2(g) → 2Li2O(s) ④ 2K(s) + Cl2(g) → 2KCl(s) ■ 무엇을 묻는 문제인가 1족 알칼리 금속의 화학적 성질, 특히 "이들은 오직 +1가 양이온만 만든다"는 원칙을 알고 있는지 묻습니다.

반응식이 그럴듯해 보여도 생성물의 화학식이 원소의 산화수 규칙과 어긋나면 성립할 수 없습니다.

알칼리 금속(Li, Na, K, Rb, Cs)은 최외각에 s 전자 1개를 가집니다.

이 전자 하나를 잃으면 바로 앞 비활성 기체와같은 안정한 전자 배치가 되므로 1차 이온화 에너지는 매우 작지만, 2차 이온화 에너지는 안쪽 닫힌 껍질을 깨야 하므로 폭발적으로 커집니다.

Na의 경우 1차가 496 kJ/mol인데 2차는 4562 kJ/mol로 아홉 배가 넘습니다.

그래서화합물에서 산화수는 항상 +1입니다.

알칼리 금속의 대표 반응은 다음과 같습니다.

- 수소와 반응: 2M + H2 → 2MH (이때 H는 드물게 -1가인 수소화 이온) - 산소와 반응: Li만 산화물 Li2O를 잘 만들고, Na는 과산화물 Na2O2, K·Rb·Cs는 초과산화물 KO2 형태를 선호합니다.

- 물과 반응: 2M + 2H2O → 2MOH + H2 (아래로 갈수록 격렬) - 할로젠과 반응: 2M + X2 → 2MX 단계 1) ①은 Rb의 물과의 반응입니다.

Rb는 0 → +1로 산화되고 물의 H는 +1 → 0으로 환원되어 수소 기체가 발생합니다.

계수도 양변 Rb 2, H 4, O 2로 맞습니다.

타당합니다.

단계 2) ②의 NaH2를 검사합니다.

금속 수소화물에서 H는 -1이므로 H 2개의 총 전하는 -2이고, 전기적으로 중성이되려면 Na가 +2여야 합니다.

그런데 Na의 2차 이온화 에너지는 4562 kJ/mol로 격자 에너지로 감당할 수 없을만큼 큽니다.

따라서 Na는 +1만 가능하고 옳은 식은 2Na(s) + H2(g) → 2NaH(s)입니다.

타당하지 않습니다.

단계 3) ③은 Li 4개가 전자를 1개씩 총 4개 내놓고, O2가 4개의 전자를 받아 O2− 2개가 됩니다.

Li2O에서 (+1)×2 +(-2) = 0으로 타당합니다.

단계 4) ④는 K 2개가 전자를 1개씩 내놓고 Cl2가 2개의 전자를 받아 Cl− 2개가 됩니다.

KCl에서 (+1) + (-1) = 0이고계수도 K 2, Cl 2로 맞습니다.

타당합니다.

① 2Rb + 2H2O → 2RbOH + H2 ⇒ 타당함.

수소 기체가 발생하는 알칼리 금속의 대표 반응.

② Na + H2 → NaH2⇒ 타당하지 않음.

H가 -1인 수소화물에서 Na가 +2가 되어야 하는데 알칼리 금속은 +2가 이온이 될 수 없습니다.2Na + H2 → 2NaH이어야 합니다.

③ 4Li + O2 → 2Li2O ⇒ 타당함.

앞부분은 "약산 수용액의 pH로부터 Ka를 역산"하는 계산이고, 뒷부분은 "Ka를 알고 pH가 주어졌을 때 짝산과 짝염기의 농도비를 구하는" 헨더슨-하셀바흐 계산입니다.

마지막에 구한 비의 방향(분자와 분모가 무엇인지)을 정확히 읽어야 함정을 피할 수 있습니다.

1) 약산의 해리: HA ⇌ H+ + A−, Ka = [H+][A−]/[HA] 2) 해리도 α를 써서 표현하면, 초기 농도가 C일 때 해리 후 [H+] = [A−] = Cα, [HA] = C(1-α)입니다.

α가 충분히 작아 1-α ≈ 1로 볼 수 있으면 [H+] = Cα, Ka = (Cα)2/C = Cα2 이 근사는 보통 α < 0.05일 때 안전합니다.

pKa = -log(10−6) = 6 단계 5) 헨더슨-하셀바흐 식에 pH = 4를 넣습니다.

4 = 6 + log([A−]/[HA]) log([A−]/[HA]) = 4 - 6 = -2 단계 6) 로그를 풉니다.

[A−]/[HA] = 10−2 = 0.01 단계 7) 문제가 묻는 것은 [HA]/[A−]이므로 역수를 취합니다.

[HA]/[A−] = 1/0.01 = 100 단계 8) 타당성 확인: pH 4는 pKa 6보다 2만큼 작으므로 용액은 pKa 기준보다 산성 쪽에 있고, 따라서 산 형태인HA가 짝염기 A−보다 훨씬 많아야 합니다.

단계 3) 엔탈피 변화를 판정합니다.

물-CCl4 혼합은 새로 만드는 인력이 약해 흡열이므로 ΔH > 0 입니다.

단계 4) ΔG = ΔH - TΔS 에 부호를 넣습니다.

ΔH > 0 이므로 첫 항은 자발성에 불리합니다.

ΔS > 0 이므로 -TΔS = -(T)(양수) = 음수가 되어 자발성에 유리하고,그 크기는 T에 비례합니다.

단계 5) 따라서 T가 클 때는 |TΔS| > |ΔH| 가 되어 ΔG < 0 (자발적), T가 작을 때는 |ΔH| > |TΔS| 가 되어 ΔG > 0(비자발적)입니다.

두 항이 같아지는 T = ΔH/ΔS 가 경계 온도이고, 상온은 그 경계보다 낮기 때문에 실제로 물과 사염화탄소는 섞이지 않고 두 층으로 남습니다.

① 높은 온도에서 자발적이다 ⇒ 옳음(정답).

ΔH > 0, ΔS > 0 조합이므로 고온에서 엔트로피 항이 승리해 ΔG < 0이 됩니다.

② 낮은 온도에서 자발적이다 ⇒ 틀림.

ΔH < 0, ΔS < 0 인 경우의 결론이며, 이는 혼합이 아니라 그 역과정인 층분리에 해당하는 설명입니다.

변화의 방향을 거꾸로 읽으면 걸립니다.

③ 항상 자발적이다 ⇒ 틀림.

ΔH < 0,ΔS > 0 일 때만 가능한 결론인데 여기서는 ΔH > 0 이므로 성립하지 않습니다.

실제로 상온에서 물과 사염화탄소는섞이지 않습니다.

④ 항상 비자발적이다 ⇒ 틀림.

ΔH > 0, ΔS < 0 일 때의 결론입니다.

여기서는 ΔS > 0 이므로 온도를 충분히 올리면 -TΔS 항이 ΔH를 넘어서 자발적이 될 수 있습니다.

문제 29에너지정답 ②

난이도 중 다음 자료를 활용하여 다이에틸 에터의 정상 끓는점을 계산한 값과 가장 유사한 것은? 물질 ΔHf°(kJ/mol) ΔS°(J/mol·K) C4H10O(l) -280 254 C4H10O(g) -253 343 ① 250 K ② 300 K ③ 350 K ④ 400 K ■ 무엇을 묻는 문제인가 "끓는점이란 무엇인가"를 열역학의 언어로 다시 정의할 수 있는지 묻는 문제입니다.

끓는점은 액체와 기체가 평형을 이루는 온도이고, 평형이란 곧 ΔG = 0 인 상태입니다.

이 한 문장을 T = ΔH/ΔS 로 옮길 수 있으면 나머지는 표에서 뺄셈 두 번을 하는 일뿐입니다.

단위 환산(kJ ↔ J)이 유일한 함정입니다.

1) 깁스 자유에너지 ΔG = ΔH - TΔS 입니다.

ΔG < 0 이면 자발적, ΔG = 0 이면 평형, ΔG > 0 이면 비자발적입니다.2) 정상 끓는점은 1기압에서 액체와 기체가 공존하며 평형을 이루는 온도입니다.

기화 과정 C4H10O(l) →C4H10O(g) 에 대해 ΔG = 0 이 되는 온도가 바로 정상 끓는점이므로 0 = ΔH - TΔS → T = ΔH / ΔS 3) 헤스 법칙과 표준 생성엔탈피: ΔH° = (생성물의 ΔHf° 합) - (반응물의 ΔHf° 합) 입니다.

엔트로피는 절대값이 존재하므로(열역학 제3법칙) 절대 엔트로피를 그대로 빼면 ΔS° 가 됩니다.

4) 기화는 언제나 ΔH > 0(분자간 힘을 끊어야 하므로 흡열)이고 ΔS > 0(기체가 훨씬 무질서)이므로 T = ΔH/ΔS 는 항상 양수입니다.

이 온도보다 높으면 -TΔS 항이 이겨 기화가 자발적, 낮으면 응축이 자발적입니다.

5) 단위 통일이 필수입니다.

ΔH는 kJ/mol, ΔS는J/mol·K 로 주어지므로 1000배 차이를 반드시 맞춰 주어야 합니다.

단계 1) 대상 반응을 씁니다.

C4H10O(l) → C4H10O(g) 단계 2) 기화 엔탈피를 구합니다.

ΔH = ΔHf°(기체) - ΔHf°(액체) = (-253) - (-280) = +27 kJ/mol 흡열이라는 예상과 부호가 맞습니다.

단계 3) 기화 엔트로피를 구합니다.

ΔS = S°(기체) - S°(액체) = 343 - 254 = +89 J/mol·K 기체가 되면서 엔트로피가 늘어난다는 예상과 맞습니다.

단계 4) 평형 조건 ΔG = 0 을 적용합니다.

0 = ΔH - TΔS → T = ΔH / ΔS 단계 5) 단위를 맞추어 대입합니다.

T = 27 kJ/mol ÷ 0.089 kJ/mol·K = 27000 J/mol ÷ 89 J/mol·K = 303.4 K 단계 6) 보기와 대조하면 303.4 K에 가장 가까운 값은 300 K이므로 ②입니다.

참고로 다이에틸 에터의 실제 정상끓는점은 307.6 K(34.5 °C)여서 계산치와 4 K 정도밖에 차이가 나지 않습니다.

ΔH를 22 kJ/mol 정도로 작게 잡거나 ΔS를 110 J/mol·K 정도로 크게 잡았을 때 나오는 값입니다(27000/110 = 245 K).

303.4 K와 50 K 넘게 차이 납니다.

② 300 K ⇒ 옳음.

T = 27000/89 = 303.4 K 이므로 보기 중 가장 가깝습니다(차이 3.4 K).

③ 350 K ⇒ 틀림.

ΔS를 68 J/mol·K 정도로 지나치게 작게 잡거나 ΔHf° 두 값을 더하는 식으로 ΔH를 잘못 처리했을 때 나옵니다.
