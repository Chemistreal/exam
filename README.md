# CHEMISTREAL · 화학 성적표와 오답 카드

대치동 다원교육 영재관 조준모 화학. 시험을 채점해 성적표를 내주고, 틀린
문항마다 문제 그림 · 해설 · 오개념 한 줄 · 같은 개념의 새 문제를 붙여 주는
정적 웹앱이다. 서버가 없고 브라우저에서 바로 돈다.

> 이 파일은 **저장소의 지금 모습**을 적는다. 2026-07-07 판은 그때 한 번
> 묶어 보낸 꾸러미(`deploy/`)를 설명하고 있었는데, 그 폴더는 이 저장소에
> 없고 적혀 있던 크기(index.html 876KB)도 오래전 값이었다.

## 돌리는 법

화면을 열려면 그냥 파일을 열면 된다. 검사를 돌리려면 저장소 뿌리에서 정적
서버를 띄운 뒤 한 줄이다.

```bash
python3 -m http.server 8931 &
node tests/run.js                       # 브라우저 검사는 playwright 없으면 건너뛴다
```

`tests/run.js` 는 `tests/*.js` 를 스스로 찾아 돌고, **CI 목록에 없는 검사가
있으면 짚어 준다.** 만들어 놓고 CI 에 안 걸면 아무도 안 돌리기 때문이다.
건너뛴 것은 초록으로 세지 않는다.

## 자물쇠

한 번 걸린 결함은 규칙으로 바꿔 둔다. 지키는 자들이 무엇을 막는지만 적는다.

| 자 | 막는 것 |
|---|---|
| `tools/crop_align.py` | 문제지에 섞인 딱지 때문에 크롭이 한 칸씩 밀리는 것 |
| `tools/om_cover.py` | 오개념 한 줄이 없는 유형 |
| `tools/gen_omlib.py` | 오개념표가 두 화면에서 갈라지는 것 |
| `tools/gen_expl_html.py` | 해설이 비거나, 글과 해설지 꼴이 다른 말을 하는 것 |
| `tools/dh_validate.py` · `dh_lint.py` · `dh_number.py` | 동형문항의 구조·정답 쏠림·셈이 답에 안 닿는 것 |
| `tools/void_check.py` · `rate_check.py` | 폐기 문항·공식 정답률이 조용히 사라지는 것 |
| `tools/page_exams.py` · `concept_table.py` | 화면마다 품은 회차 목록·개념표가 갈라지는 것 |
| `tools/audit_pages.py` · `theme.py` | 글자 대비 4.5:1 미달, 옷이 갈라지는 것 |
| `tests/page-health.js` | 화면이 열리다가 터지는 것 (258장 전수) |
| `tools/font_block.py` | 바깥 글꼴이 첫 그림을 인질로 잡는 것 |

**바깥 CSS·JS 파일로 빼지 않는다.** 바깥 stylesheet 를 만나면 브라우저는
그리기를 멈추고 기다린다 — 글꼴 한 줄 때문에 첫 화면이 13초였던 일이 있다.
같은 조각을 화면마다 안에 박아 넣고, 갈라지지 않게 자로 잰다.

## 아직 못 채운 자리

**KMChC 2020.** 실제로 열렸고(온라인 시험, 60문항) 문제지 PDF 도 있는데
**정답표가 없어** 넣지 못하고 있다. 대회 정답표가 들어오면 다른 회차와 같은
방식으로 넣을 수 있다.
(2026-08-08 에 `sol-final-hwol-2020.html` 을 지웠다. 제목만 2020 이고 담긴
것은 2019 회차의 정답이었다.)

**화올 2003~2008.** 문제지 PDF 가 없다. 크롭을 뜰 수 없어 오답 카드에 문제
그림을 붙일 수 없다. HWP 본문만으로는 안 된다.

**응시 기록이 없는 23회차.** 석차·수상 확률은 응시 기록 위에 선다. 기록이
없는 회차는 "비슷한 난이도의 실전이라면" 이라는 가정 위에 서 있다
(`tools/cut_link.py` 가 회차마다 그 사정을 적어 준다). 시험지 난이도만은
공식 정답률로 메워 두었다. 기록은 앞으로 쌓인다.
