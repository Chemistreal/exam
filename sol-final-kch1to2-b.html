문제 5평균원자량정답 ③

문제 36수소원자정답 ③

자외선은 라이먼 계열, 가시광선은 발머 계열, 적외선은 파셴 계열이다.

옳은문장: ① n=5 → 3 전이의 에너지는 n=3 → 1 전이의 에너지보다 작다.

계산 ΔE5→3 = 13.6×(1/32 − 1/52) = 13.6×(1/9 − 1/25) = 13.6×(16/225) = 217.6/225 ≈ 0.966 eV ΔE3→1 = 13.6×(1 − 1/9) = 13.6×(8/9) ≈ 12.089 eV 비교: 0.966 eV < 12.089 eV 이므로 참.

해석: 바닥상태(n=1)로 갈수록 에너지 간격이 커지므로 3→1 전이가 훨씬 에너지가 크다.

옳은문장: ② 바닥상태는 전자의 가장 안정한 에너지 상태를 나타낸다.

근거: 바닥상태(n=1)는 가장 낮은 에너지 수준으로, 전자가 자발적으로 도달하려는 안정 상태이다.

따라서 설명이 정확하다.

틀린문장: ③ n=3 → 2 전이는 n=4 → 1 전이보다 파장이 작다.

계산 ΔE3→2 = 13.6×(1/22 − 1/32) = 13.6×(1/4 − 1/9) = 13.6×(5/36) = 68/36 ≈ 1.889 eV 이에 대응하는 파장 λ3→2 ≈ 1240 eV·nm / 1.889 eV ≈ 656 nm (Balmer α, 가시광 적색) ΔE4→1 = 13.6×(1 − 1/16) = 13.6×(15/16) = 204/16 = 12.75 eV λ4→1 ≈ 1240 / 12.75 ≈ 97.3 nm (Lyman 계열, 자외선) 비교: 1.889 eV < 12.75 eV 이므로 λ3→2 > λ4→1 이다.

즉 3→2가 더 긴 파장이다.

결론: “더 작은 파장”이라고 한 진술은 반대이므로 거짓.

옳은문장: ④ 전자가 높은 에너지 준위로 전이될 때 빛을 흡수한다.

원리: 상향 전이(ni < nf)는 ΔE > 0의 에너지가 필요하며, 그 에너지를 광자 흡수로 보통 충당한다.

따라서 참.

nf=1: Lyman(자외선, 매우 짧은 λ) 예: 4→1 ≈ 97 nm nf=2: Balmer(가시영역) 예: 3→2 ≈ 656 nm nf=3: Paschen(적외선) 예: 5→3 ≈ 1.28 μm 정도 큰 에너지 전이는 항상 더 짧은 파장(자외선 쪽)이고, 작은 에너지 전이는 더 긴 파장(적외선/가시 장파장)이다.

문제 38수소원자정답 ④

높은 에너지준위에서 낮은 에너지준위로 전자전이가 일어날 경우 빛을 방출한다.

반대로 낮은 에너지준위에서 높은 에너지준위로 전자전이가 일어나기위해서는 빛을 흡수해야 한다.

이므로 에너지는 진동수(υ)에 비례하고, 파장(λ)에는 반비례한다.

전이 방향 규칙: 주양자수 n이 커지는 전이(아래→위)는 흡수, n이 작아지는 전이(위→아래)는 방출.

두 전이의 에너지 차 ΔE를 비교하면 ΔE가 더 작은 전이가 더 긴 파장 λ를 갖는다(λ = hc/ΔE).

(a) 4→5, (b) 2→4 모두 흡수이며, ΔE(a) < ΔE(b)이므로 (a)가 더 긴 파장.

전이의 흡수·방출 판정 (a) n=4 → n=5: 에너지가 높은 궤도로 올라감 → 흡수.

(b) n=2 → n=4: 역시 더 높은 궤도로 올라감 → 흡수.

따라서 (A)=흡수.

파장 비교를 위한 에너지 차 계산 수소의 에너지 준위: E_n = −13.6 eV / n^2 전이 에너지 크기: ΔE = 13.6 eV × (1/n_i^2 − 1/n_f^2) (n_f>n_i인 흡수 전이) (a) 4→5 ΔE(a) = 13.6 × (1/4^2 − 1/5^2) = 13.6 × (1/16 − 1/25) = 13.6 × (9/400) = 0.306 eV λ(a) ≈ 1240 eV·nm / 0.306 eV ≈ 4050 nm (중적외선) (b) 2→4 ΔE(b) = 13.6 × (1/2^2 − 1/4^2) = 13.6 × (1/4 − 1/16) = 13.6 × (3/16) = 2.55 eV λ(b) ≈ 1240 / 2.55 ≈ 486 nm (가시광, 파란색 영역) 비교: ΔE(a) < ΔE(b) ⇒ λ(a) > λ(b).

즉 더 긴 파장은 (a)에서 흡수될 때 나온다.

따라서 (B)=(a), (A)=흡수.

선택지 판정 ① 방출, (b): 틀림 — (b)는 흡수 전이이며, 더 긴 파장은 (a)이다.

② 흡수, (b): 틀림 — 흡수는 맞지만 더 긴 파장은 (a)이다.

③ 방출, (a): 틀림 — (a)는 흡수 전이이다.

④ 흡수, (a): 옳음 — 두 전이 모두 흡수이며, 더 긴 파장은 (a)에서 해당.

핵심 정리 n 증가 전이: 흡수, n 감소 전이: 방출.

수소에서 높은 n 구간의 간격이 더 촘촘하여 ΔE가 작음 → 파장은 더 김.

여기서는 4→5가 2→4보다 ΔE가 작아 더 긴 파장.

문제 42파동성정답 ①

빛의 입자성을 보여주는 실험은 광전효과이고, 전자의 파동성을 보여주는 실험은 금속 결정을 이용한 회절실험이다.

전자의 파동성은 간섭·회절처럼 ‘위상’을 갖는 파동만 보이는 현상에서 직접 드러난다.

문제 57주기적성질정답 ①

O2−, F−, Ne, Na+, Mg2+는 모두 전자 수가 10개인 등전자종이다.

등전자열에서는 핵전하수 Z가 클수록 유효핵전하가 커지고 반지름은 작아지며(전자들이 더 세게 끌려들어감), 전자를 하나 떼어내는 데 필요한 에너지는 커진다.

옳은문장: 가 반지름의 크기는 O2− > F− > Ne > Na+ > Mg2+ 순이다.

설명: 전자 수가 같을 때 Z가 커질수록 전자를 더 강하게 끌어 반지름이 작아진다.

Z는 8,9,10,11,12로 오른쪽으로 갈수록 커진다.

틀린문장: 나 “전자를 1개 떼어내는 데 필요한 에너지”의 순서를 O2− > F− > Ne > Na+ > Mg2+라고 했는데, 옳은 순서는 O2− < F− < Ne < Na+ < Mg2+이다.

설명: 등전자종에서 Z가 클수록 전자 결합이 더 단단해 전자 제거 에너지가 증가한다.

실제로 개념상 O2−→O−(가장 쉽다) < F−→F < Ne→Ne+(1차 이온화) < Na+→Na2+(2차 이온화) < Mg2+→Mg3+(3차 이온화, 가장 어렵다).

틀린문장: 다 전자 수는 O2−, F−, Ne, Na+, Mg2+ 모두 10개로 같다.

제시된 부등식 순서는 성립하지 않는다.

정정: O2− = F− = Ne = Na+ = Mg2+.

틀린문장: 라 양성자수(원자번호)는 O(8) < F(9) < Ne(10) < Na(11) < Mg(12)로 오른쪽으로 갈수록 커진다.

제시된 순서는 반대다.

문제 58전자친화도정답 ②

① 음이온의 반지름은 해당 원자 반지름보다 작다.

→ 틀린문장 전자 1개 이상을 얻어 음이온이 되면 전자 간 반발이 커지고, 전자 하나가 느끼는 유효핵전하(Zeff)가 감소해 전자구름이 팽창한다.

따라서 음이온의 반지름은 같은 원자의 중성 원자 반지름보다 커진다.

예: Cl < Cl−.

② 이온 반지름의 크기는 F− < Cl− < S2− 순서이다.

→ 옳은문장 첫째, 같은 족에서는 아래로 갈수록 주양자수(n)가 커져 반지름이 커진다.

F−(2주기) < Cl−(3주기).

둘째, Cl−과 S2−는 등전자종(둘 다 18전자)이다.

등전자종에서는 양성자 수가 적을수록(핵전하가 작을수록) 전자들을 덜 세게 끌어당겨 반지름이 더 크다.

S2−(Z=16) > Cl−(Z=17).

이를 합치면 F− < Cl− < S2−가 성립한다.

③ 모든 원자 가운데 염소의 전기음성도가 가장 크다.

→ 틀린문장 가장 큰 전기음성도를 가지는 원소는 플루오린이다.

염소는 그 다음 수준으로 작다.

따라서 진술이 사실과 다르다.

④ 수소 원자의 전자배치에서 4s 오비탈이 3d 오비탈보다 에너지 준위가 낮다.

→ 틀린문장 수소처럼 1전자 원자에서는 오비탈 에너지가 주양자수 n에만 의존한다.

E ∝ −1/n^2 이므로 n=3(3d)이 n=4(4s)보다 항상 더 낮은 에너지다.

다전자 원자에서야 4s가 3d보다 낮게 나오는 경향이 있으나, 문제는 “수소 원자”를 특정했으므로 해당하지 않는다.

문제 60전기음성도정답 ②

전기음성도: 공유 전자쌍을 끌어당기는 능력(주로 주기 내 오른쪽↑, 족 아래로↓).

① 틀린문장: 2주기에서 오른쪽으로 갈수록 전기음성도는 감소가 아니라 증가한다.

④ 틀린문장: 전자친화도 EA(X)는 “바로 다음 원소의 이온화 에너지”와 동일하지 않다.

또한 Be, N 등은 전자친화도가 거의 0 또는 음수인 반면, 바로 다음 원소들의 IE는 큰 양의 값이다.
