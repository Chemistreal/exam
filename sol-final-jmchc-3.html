문제 4진동수 · 빛의 영역정답 ②
스트론튬 염을 연소시키면 빨강색의 불빛을 내며 탄다. 이 빛의 진동수보다 낮은 진동수를 갖는 것은?
① 노란빛
② 적외선
③ 자외선
④ x-선

사고과정

가시광선 진동수 순서: 빨강 < 노랑 < 초록 < 파랑 < 보라. 빨강이 가시광 중 진동수가 가장 낮다.

빨강보다 더 낮은 진동수(긴 파장)는 적외선. (노란빛·자외선·X선은 모두 더 높음) → ②

"빨강 바깥(적외선) = 진동수 더 낮음, 보라 바깥(자외선) = 진동수 더 높음". 빨강은 가시광의 저진동수 끝이다.
문제 5결합에너지 · 파장정답 ③
광화학 반응을 통해 질소의 삼중 결합(결합 에너지 = 941 kJ/mol)을 끊을 때 필요한 빛의 최대 파장은 어느 영역인가?
① 마이크로파
② 적외선
③ 자외선
④ 감마선

사고과정

① 분자 1개당 에너지 = 941000/(6.0×1023) = 1.56×10−18 J.

② λ = hc/E = (6.63×10−34 × 3×108)/(1.56×10−18) ≈ 1.27×10−7 m = 127 nm → 자외선 영역. → ③

"최대 파장" = 결합을 겨우 끊는 최소 에너지에 대응. 결합에너지가 클수록 파장이 짧아(고에너지 자외선) 진다.
문제 6수소 원자 · 에너지 준위정답 ③
수소원자에 대한 다음 서술 중 옳은 것은?
① n=5에서 n=3으로의 전이 에너지는 n=3에서 n=1로의 전이 에너지보다 크다.
② 바닥상태는 전자의 가장 불안정한 에너지 상태를 나타낸다.
③ n=3에서 n=2로의 전이는 n=4에서 n=1로의 전이에 해당하는 전자기파보다 큰 파장값을 가진다.
④ 전자가 높은 에너지 준위로 전이될 때 빛을 방출한다.

사고과정

① n=3→n=1(바닥 근처 큰 낙차)이 n=5→n=3보다 에너지가 크다. 거짓. ② 바닥상태는 가장 안정(최저 에너지). 거짓. ④ 높은 준위로 가는 것은 흡수. 거짓.

③ n=3→n=2(작은 에너지=발머)는 n=4→n=1(큰 에너지=라이먼)보다 파장이 길다(에너지∝1/λ). 참. → ③

에너지와 파장은 반비례. 준위 차가 작으면 에너지가 작고 파장이 길다. 바닥 근처 전이일수록 에너지가 크다.

수소원자에서 일어나는 다음 전자전이 중에서 가장 긴 파장의 복사선을 방출하는 전이는?
① n=3 → n=4
② n=2 → n=1
③ n=4 → n=3
④ n=1 → n=4

① 방출은 낮은 준위로 내려갈 때. ①·④는 위로 올라가는 흡수라 제외.

② n=2→n=1(큰 에너지=짧은 파장), ③ n=4→n=3(인접 고준위, 가장 작은 에너지=가장 긴 파장). → ③

긴 파장 = 작은 에너지 = 준위 간격이 가장 좁은 전이. 고준위에서 인접 준위로 내려갈 때가 간격이 가장 좁다.
문제 8수소 선스펙트럼 · 발머정답 ②
수소 기체 방전관에서 관찰되는 자외선·가시광선 영역의 선스펙트럼(122 / 410, 434, 486 / 656 nm)에서 434nm에 해당하는 전자 전이를 옳게 나타낸 것은? (K=n1, L=n2, M=n3, N=n4, O=n5)
① N → K
② O → L
③ O → M
④ N → L

사고과정

가시광선 영역(410~656 nm)은 발머 계열(n → 2 = L)이다. 656(3→2), 486(4→2), 434(5→2), 410(6→2).

434 nm = n=5 → n=2 = O → L. → ②

L(n=2)로 떨어지면 가시광선(발머), K(n=1)로 떨어지면 자외선(라이먼, 122 nm 등). 434는 발머의 세 번째 선이다.
문제 9이온화 에너지 · 파장정답 ③
수소 원자의 에너지 준위는 En = −RH/n²로 쓸 수 있다(RH = 2.2×10−18 J). 바닥상태의 수소 원자를 이온화시키는 데 필요한 빛의 최대 파장 값과 가장 가까운 것은?
① 10 nm
② 50 nm
③ 90 nm
④ 130 nm

사고과정

① 이온화 = n=1 → n=∞, 에너지 = 0 − (−RH/1²) = 2.2×10−18 J.

② 최대 파장 = 최소 에너지(=이온화 에너지). λ = hc/E = (6.63×10−34×3×108)/(2.2×10−18) ≈ 90 nm. → ③

바닥상태 이온화 에너지가 곧 "겨우 떼어낼" 최소 에너지 = 최대 파장에 대응. 90 nm은 자외선 영역.
문제 10전자의 파동성정답 ①
다음 중 전자의 파동성을 가장 잘 보여주는 실험은?
① 금속 결정을 이용한 회절 실험
② 도체를 통한 전자의 이동
③ 전기장에 의한 음극선 굴절 실험
④ 광전 효과

사고과정

회절(diffraction)·간섭은 파동의 고유 현상이다. 전자가 결정 격자에서 회절무늬를 만드는 것(데이비슨-거머 실험)이 전자의 파동성의 직접 증거. → ①

②·③은 전자의 입자성(전하·이동), ④ 광전효과는 오히려 빛의 입자성(광자)을 보인다.

파동성 = 회절·간섭. 입자성 = 충돌·광전효과. ④를 고르지 않도록 "무엇의 무슨 성질인가"를 구분하라.

문제 13수소꼴 이온 · 에너지 순위정답 ②
헬륨 +1가 양이온(He+)에 있는 오비탈들의 에너지 준위를 순서대로 바르게 나열한 것은?
① 1s < 2s < 2p < 3s < 3p < 3d < 4s < 4p < 4d < 4f < 5s
② 1s < 2s = 2p < 3s = 3p = 3d < 4s = 4p = 4d = 4f < 5s
③ 1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d
④ 1s < 2s = 2p < 3s = 3p = 3d = 4s < 4p = 4d = 4f < 5s

사고과정

He+는 전자가 1개인 수소꼴 이온. 전자 간 반발이 없어 에너지가 주양자수 n에만 의존한다(E ∝ −Z²/n²).

따라서 같은 n은 모두 같은 에너지(축퇴): 1s < 2s=2p < 3s=3p=3d < 4s=4p=4d=4f < 5s. → ②

다전자 원자(4s<3d 등)와 달리 수소꼴은 l 의존성이 없다. "전자 1개 → n만 중요"가 결정적 차이.
문제 14양자수 · 전자 수정답 ③
어떤 원자에서 주양자수 = 3, 자기양자수 = 0, 스핀양자수 = 1/2을 가지는 전자는 최대 몇 개인가?
① 1
② 2
③ 3
④ 4

사고과정

① n=3이면 l = 0, 1, 2(3s, 3p, 3d).

② 각 부껍질에서 자기양자수 m=0인 궤도는 1개씩 → 3s(m=0), 3p(m=0), 3d(m=0) = 궤도 3개.

③ 스핀까지 +1/2로 고정하면 각 궤도에 1개씩 → 3개. → ③

m=0은 각 l마다 정확히 하나의 궤도. n=3엔 l이 3종(0·1·2)이라 m=0 궤도도 3개다.

문제 16전자배치 · 산화정답 ②

① 4
② 5
③ 6
④ 7

문제 56평면 삼각형 구조정답 ③
다음 분자 중 평면 삼각형 구조인 것은?
① PCl3
② NH3
③ SO3
④ ClF3

사고과정

PCl3·NH3은 고립쌍 1개 → 삼각뿔. ClF3은 고립쌍 2개 → T자형.

SO3은 결합 3개 + 고립쌍 0 → 평면 삼각형(120°). → ③

평면 삼각형 = 결합 3 + 고립쌍 0(SO3, BF3, CO32−). 고립쌍이 하나라도 있으면 평면이 깨진다.
문제 57같은 구조 짝짓기정답 ③
다음 중 동일한 형태의 구조를 가진 화학종으로 짝지은 것은?
① SO32−, BF3
② CO32−, ClF3
③ NH3, SO32−
④ ClF3, BF3

사고과정

구조: SO32−(고립쌍 1, 삼각뿔), BF3·CO32−(평면삼각형), ClF3(T자형), NH3(삼각뿔).

NH3와 SO32−이 모두 삼각뿔로 같다. → ③

SO3(평면)와 SO32−(삼각뿔)를 혼동하지 말 것 — 전자 2개가 더해져 고립쌍이 생기면 모양이 바뀐다.
문제 58구조 빈도정답 ①
다음 화학종들의 구조 중에서 가장 많은 것은? (BrF3, ClO4−, ICl4−, SF4, I3−, IF4+)
① 시소형
② 평면사각형
③ 삼각뿔형
④ 구부러진 T형

사고과정

구조: BrF3(T자형), ClO4−(정사면체), ICl4−(평면사각형), SF4(시소형), I3−(직선), IF4+(시소형).

시소형이 2개(SF4, IF4+)로 가장 많다. → ①

시소형 = 결합 4 + 고립쌍 1. SF4와 IF4+(I가 +1로 전자 6개) 둘 다 이 조건을 만족.
문제 59혼성 · 아스피린정답 ③
아스피린 구조(벤젠 고리에 −COOH와 −OCOCH3가 결합)에서 sp² 탄소의 개수는?
① 6
② 7
③ 8
④ 9

사고과정

sp² 탄소: 벤젠 고리 6개(방향족) + COOH의 카르보닐 C 1개 + 에스터(−OCOCH3)의 카르보닐 C 1개 = 8개.

−OCOCH3의 CH3 탄소만 sp³(유일). → ③

혼성 판별: 이중결합 참여 탄소(C=O, 방향족) = sp², 단일결합만(CH3) = sp³. 카르보닐 C 두 개를 빠뜨리기 쉽다.
문제 60혼성·결합 종합정답 ③
화합물 H3C−O−CH2−C≡C−CH=N−H(탄소 번호 1: CH2, 2·3: 삼중결합, 4: =N)에 대한 설명으로 옳지 않은 것은?
① 13개의 시그마 결합과 3개의 파이 결합이 있다.
② 4번의 탄소 원자는 결합각이 약 120°인 sp² 혼성 오비탈을 가진다.
③ 산소 원자는 sp 혼성 오비탈을 가진다.
④ 결합 길이는 1번과 2번 탄소 사이가 2번과 3번 탄소 사이보다 길다.

사고과정

① 시그마 13개(모든 단일결합 + 다중결합의 σ), 파이 3개(삼중결합 2 + 이중결합 1). 참. ② C4는 결합 영역 3개(=N, –C, –H) → sp²(120°). 참.

③ 에터 산소는 결합 2 + 고립쌍 2 = 전자쌍 4 → sp³ 혼성(굽은형). "sp"는 거짓. → ③

④ C1–C2(단일) > C2≡C3(삼중) 길이. 참.

에터·물의 산소는 고립쌍 2개를 포함해 sp³. sp 산소는 거의 없다(고립쌍 영역까지 세는 게 함정).
