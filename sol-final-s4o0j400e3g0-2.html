바닥상태 홀전자 수 : Sc 1, Ti 2, V 3, Cr 6(4s13d5), Mn 5, Fe 4, Co 3, Ni 2, Cu 1, Zn 0.

문제 2분자의구조정답 ①

정답 ① CO2 풀이 비공유 전자쌍 수 : CO2 4개(O마다 2개), HF 3개, NH3 1개, C2H4 0개.

→ 정답 ① 요령 : 총 원자가전자 수에서 결합에 쓰인 전자 수를 빼고 2로 나눈다.

CO2 = 16 e− - 8 e−(4결합) = 8 e− → 4쌍.

문제 3몰과질량정답 ②

정답 ② 5×103 풀이 혈액 1 L 기준 : 포도당 180 mg/100 mL = 1.8 g/L → 1.8/180 = 0.010 mol.

물 1 L ≈ 1000 g → 1000/18 = 55.5 mol.

55.5 / 0.010 = 5550 ≈ 5×103.

→ 정답 ② 핵심 : 물의 몰수(55.5 mol/L)는 외워 두면 이 유형이 전부 30초 컷이다.

문제 4열화학정답 ③

Born-Haber : (1) = (2) + ½(3) + (4) + (5) + U -411 = 108 + 121 + 496 + (-349) + U -411 = 376 + U → U = -787 kJ/mol.

→ 정답 ③ 주의 : (3)은 Cl2 1몰 기준이므로 반드시 ½을 곱한다.

문제 5고체정답 ②

정답 ② MgO > CaTe > NaF > RbI 풀이 격자 에너지 ∝ (Z+Z−)/(r++r−).

전하가 1순위, 이온 크기가 2순위다.

2가-2가 : MgO, CaTe → 이온이 작은 MgO가 더 크다.

1가-1가 : NaF, RbI → 이온이 작은 NaF가 더 크다.

따라서 MgO > CaTe > NaF > RbI.

→ 정답 ②

문제 6분자간인력정답 ②

정답 ② -0.83 풀이 꼭짓점 A(+)에서 나머지 8개 이온까지의 거리와 부호를 모두 센다.

(거리는 r 단위) · 거리 1 : 음이온 2개 → 2×(-1)/1 = -2 · 거리 √2 : 양이온 1개 → +1/1.414 = +0.71 · 거리 2 : 양이온 2개 → 2×(+1)/2 = +1.00 · 거리 √5 : 음이온 2개 → 2×(-1)/2.236 = -0.89 · 거리 2√2 : 양이온 1개 → +1/2.828 = +0.35 합 = -2 + 0.71 + 1.00 - 0.89 + 0.35 = -0.83.

→ 정답 ② 부호가 음수여야 안정한 결정이라는 점으로 ③④는 바로 지운다.

문제 7전기음성도정답 ④

정답 ④ O에 두 번째 전자를 붙이는 과정이 발열이므로 O2−가 쉽게 만들어진다.

풀이 ①②③ 모두 2가-2가 결정을 지지하는 타당한 근거다.

④ 2차 전자친화도는 흡열(O− + e− → O2−, ΔH ≈ +744 kJ/mol)이다.

O2− 자체는 만들기 '불리한' 이온이고, 그 손해를 2가-2가의 큰 격자 에너지가 갚아 주는 구조다.

따라서 ④는 사실 자체가 틀렸다.

→ 정답 ④

문제 11주기율정답 ②

정답 ② N > C > Be > B > Mg 풀이 같은 주기(2주기)에서는 원자번호가 커질수록 대체로 증가 : Be < B < C <

N. 그런데 2족(Be)과 13족(B) 사이에는 예외가 있다.

B는 2p1 전자를 떼는데, 2p는 2s보다 에너지가 높고 가려막기를 받아 오히려 Be보다 이온화 에너지가 작다.

→ N(1402) > C(1086) > Be(899) > B(801).

Mg는 3주기라 가장 작다(738).

따라서 N > C > Be > B > Mg.
