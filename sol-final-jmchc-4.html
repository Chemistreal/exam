문제 1톰슨정답 ①

사고과정

음극선이 음극 물질과 무관하게 동일 = 모든 원자에 공통으로 들어있는 입자(전자)가 존재한다는 뜻.

즉 원자가 더 작은 입자(전자)로 나뉠 수 있음을 의미. → ①

② 러더포드, ③ 채드윅, ④ 모즐리의 발견으로 톰슨 실험과 무관하다.

"물질 종류와 무관하게 같다" = 보편적 구성 입자 = 전자. 톰슨의 전자 발견이 원자 가분성의 첫 증거다.
문제 2마이크로파정답 ③

사고과정

마이크로파는 분자의 회전 운동 에너지 간격에 해당한다. 물 분자가 마이크로파를 흡수해 회전이 빨라지며 열로 전환된다. → ③

에너지 순서: 회전(마이크로파) < 진동(적외선) < 전자(가시·자외선). 전자레인지가 물을 데우는 원리.
문제 3에너지간격정답 ①

사고과정

에너지 간격: 전자 전이 > 진동 > 회전 > 병진. 전자 전이가 가장 크다. → ①

각 운동에 대응하는 빛: 전자(가시·자외선), 진동(적외선), 회전(마이크로파). 파장이 짧을수록 에너지 간격이 크다.
문제 4파장정답 ②

사고과정

파장 긴 순: 라디오 전파 > 마이크로파 > 빨간 빛 > 자외선. 가장 긴 것은 라디오, 두 번째는 마이크로파. → ②

전자기파 파장(긴 순): 라디오 > 마이크로파 > 적외선 > 가시광(빨강~보라) > 자외선 > X선 > 감마선.
문제 5에너지크기정답 ④

사고과정

다(이온화, 전자 제거) ≫ 가(결합 끊기) ≫ 나(회전). 이온화 에너지가 결합에너지보다 크고, 회전은 매우 작다.

큰 순서: 다 > 가 > 나. → ④

전자를 완전히 떼는 이온화가 가장 큰 에너지. 결합 끊기는 그다음, 회전 빠르게 하기는 가장 작다.
문제 6계열정답 ②

사고과정

n → 2 전이가 가시광선(발머 계열). → ②

계열별 도달 준위: 라이먼(→1, 자외선), 발머(→2, 가시광선), 파셴(→3, 적외선).
문제 7전자전이정답 ④

사고과정

(a)·(b) 모두 낮은 준위로 내려가는 방출. 더 긴 파장 = 작은 에너지 = 준위 간격이 좁은 (b)(n=3→2).

(A) = 방출, (B) = (b). → ④

바닥 근처 전이(n=2→1)는 에너지가 크고 파장이 짧다. 위쪽 인접 전이(n=3→2)가 파장이 길다.
문제 8에너지비정답 ④

사고과정

선들은 발머(n→2=d): z(656)=c→d, y(486)=b→d, x(434)=n5→d, w(410)=n6→d.

① w는 n6→d(a→e 아님). ② z는 c→d(d→e 아님). ③ E∝1/λ → 비는 486:434이지 4:9 아님.

④ 이온화(n=1→∞) 파장 = 1/RH ≈ 91 nm < w(410 nm) → 더 짧다. 참. → ④

이온화 에너지(RH 전체)는 가장 큰 에너지 = 가장 짧은 파장(≈91 nm). 가시광선 선들보다 훨씬 짧다.
문제 9양자화학정답 ②

사고과정

플랑크(양자 가설), 아인슈타인(광전효과), 드브로이(물질파)는 양자론의 기초를 놓았다.

볼츠만은 19세기 고전 통계역학·열역학의 인물로 양자역학 창시와는 거리가 있다. → ②

볼츠만의 업적(엔트로피·분자운동론)은 위대하지만 고전물리. 양자 창시 3인방은 플랑크·아인슈타인·드브로이(+보어).
문제 10광전효과정답 ②

사고과정

광전효과에서 빛의 세기(밝기)는 광자의 개수를 결정 → 방출 전자 수 n → 2n.

전자의 운동에너지는 빛의 진동수에만 의존(세기 무관) → E 불변. → ②

광전효과의 핵심: 세기 = 전자 수, 진동수 = 전자 에너지. 두 변수가 독립적이라는 점이 고전이론을 무너뜨렸다.
문제 11광전효과정답 ②

사고과정

출력(W) = (광자 수) × (광자 1개 에너지 hc/λ). 같은 100W에서 광자 수 ∝ λ.

280 nm은 560 nm의 절반 파장 → 광자 1개 에너지 2배 → 광자 수는 절반. (1/2)X. → ②

짧은 파장 = 에너지 큰 광자 = 같은 출력에 더 적은 개수. 출력이 같으니 개수와 파장이 비례한다.
문제 12양자수정답 ①

사고과정

규칙: l ≤ n−1, −l ≤ ml ≤ +l, ms = ±½.

① n=1이면 l은 0만 가능(l ≤ 0). l=1은 불가. → ①. (②③④는 모두 규칙 만족)

n=1 껍질엔 s 오비탈(l=0)만 존재. l 값이 n보다 작아야 한다는 게 첫 점검 사항.
문제 13양자수정답 ③

사고과정

P([Ne]3s²3p³): 홀전자 3개가 모두 3p → (n, l) = (3, 1).

Cr+: Cr([Ar]3d⁵4s¹)에서 4s 전자가 빠져 [Ar]3d⁵ → 홀전자 5개가 모두 3d → (3, 2). → ③

l 값: s=0, p=1, d=2. Cr은 3d⁵4s¹의 예외 배치라 Cr+는 3d⁵(홀전자 5개)이 된다.
문제 14에너지정답 ③

사고과정

홀전자 수: As(4p³)=3, Br(4p⁵)=1, Te(5p⁴)=2, Y(4d¹)=1.

p⁴ 배치(↑↓,↑,↑)는 홀전자 2개. → ③

p⁴는 산소와 같은 패턴(홀전자 2개). 16족(O, S, Se, Te)이 모두 홀전자 2개를 가진다.
문제 15들뜬상태정답 ①

사고과정

오비탈: 가=3d, 나=5s, 다=4d, 라=4p. 다전자 원자의 쌓음 순서는 3d < 4p < 5s < 4d.

따라서 가(3d) < 라(4p) < 나(5s) < 다(4d). → ①

쌓음 순서: ...4s 3d 4p 5s 4d 5p... (n+l 규칙). 5s가 4d보다 먼저 채워진다는 게 핵심.
문제 16전자배치정답 ③

사고과정

①은 바닥상태(훈트 만족)라 "들뜬 상태"가 아니다. 들뜬 상태 ②④는 전자를 더 높은 오비탈(3s, 2p)로 승위시켜 에너지가 크다.

③은 같은 바닥 배치(1s²2s²2p⁴)에서 훈트 규칙만 위반(짝지음) — 승위가 없어 가장 작은 에너지의 들뜬 상태. → ③

들뜬 상태의 에너지: "오비탈 승위" ≫ "훈트 위반(짝지음 에너지)". 같은 배치 내 스핀 재배열이 가장 낮은 들뜬 상태다.
문제 17금속정답 ②

사고과정

SnCO3 = Sn2+ + CO32−. Sn([Kr]4d¹⁰5s²5p²)에서 5p² 두 개가 빠져 Sn2+ = [Kr]4d¹⁰5s². → ②

주족 금속은 이온화 시 최외각 p 전자가 먼저 빠진다. Sn2+은 5s²가 남아 [Kr]5s²4d¹⁰.
문제 18반지름정답 ④

사고과정

① 전자를 잘 내주는 강한 환원제. ② 이들은 알칼리 금속(1족)이지 토금속(2족)이 아님. ③ 물과 격렬히 반응하므로 기름 속에 보관.

④ 각 주기의 맨 왼쪽이라 그 주기에서 원자 반경이 가장 크다. 참. → ④

알칼리 금속(1족)은 주기 맨 왼쪽 = 최대 반경, 최저 이온화에너지, 강한 환원제. 보관은 기름 속.
문제 19원소기호정답 ④

베르셀리우스가 알파벳 기반의 현대적 원소 기호(H, O, Na 등)와 화학식 표기법을 도입했다. → ④

문제 20반지름정답 ②

Mg(3주기·2족)는 같은 3주기 Si보다 왼쪽이라 크고, 2주기 O·C보다 아래라 크다. → ②

문제 21이온반지름정답 ④

사고과정

Na+이 양성자가 가장 많아 가장 작다. → ④

등전자에서는 양성자 수가 크기를 결정. 양성자 많을수록 전자를 강하게 끌어 작아진다.
문제 22이온반지름정답 ③

사고과정

Br−(35개 양성자)와 Se2−(34개)는 등전자(36개 전자). 양성자 적은 Se2−이 더 크다 → Br− < Se2−.

Rb+(37)와 Sr2+(38)도 등전자. 양성자 적은 Rb+이 더 크다 → Rb+ > Sr2+. → ③

두 쌍 모두 등전자 비교. 같은 전자 수면 양성자가 적은 쪽이 크다(전하 −가 클수록, +가 작을수록 큼).
문제 23이온반지름정답 ③

사고과정

K → K+: 양이온은 전자를 잃어 원자보다 작아진다. 따라서 K 원자는 138보다 훨씬 큰 ~230 pm.

F → F−: 음이온은 전자를 얻어 원자보다 커진다. 따라서 F 원자는 133보다 작은 ~65 pm. → ③

양이온 < 중성 원자 < 음이온. K+(138)과 F−(133)이 비슷해도 중성 원자는 K(큼)·F(작음)으로 크게 갈린다.
문제 24등전자이온정답 ③

사고과정

"등전자(isoelectronic)" = 전자 수가 같음. 양성자·중성자·산화수는 제각각 다르다.

→ ④

문제 26이온화에너지정답 ④

사고과정

①②③은 옳다(핵전하↑로 2s IE↑, 같은 원자 안에서 2s>2p, 1s(내부)>2p(원자가)).

④ He(Z=2)는 H(Z=1)보다 핵전하가 커서 1s 전자를 더 세게 잡는다 → He의 1s IE > H. "H > He"는 거짓. → ④

같은 1s라도 핵전하가 크면(He) 더 강하게 묶인다. H의 이온화에너지(1312)보다 He(2372)가 훨씬 크다.
문제 27순차적이온화에너지정답 ②
