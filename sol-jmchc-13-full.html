문제 1환원제정답 ①

사고과정

환원제는 잘 산화되는 종 = E°가 가장 음인 짝의 환원형.

Al3+/Al(−1.66V)이 최저 → 환원형 Al이 가장 강한 환원제.

→ ①

표준환원전위가 낮을수록 그 환원형이 전자를 잘 내놓는다(강한 환원제). 반대로 E° 높은 짝의 산화형이 강한 산화제.
문제 2반응식정답 ③

주어진 것: Zn(s)|ZnSO4(1.0 M) ‖ CuSO4(1.0 M)|Cu(s) 갈바니전지와 표준환원전위 E°(Cu2+/Cu) = 0.34 V, E°(Zn2+/Zn) = −0.76 V 이다.

1단계 — 어느 전극에서 환원이 일어나는지 정한다.

표준환원전위는 그 반쪽반응이 환원 방향으로 일어나려는 세기를 나타내는 값이다.

0.34 V > −0.76 V 이므로 Cu2+가 Zn2+보다 전자를 훨씬 잘 받는다.

따라서 Cu 전극에서 환원이 일어나고, 남은 Zn 전극에서 산화가 일어난다.

2단계 — 두 반쪽반응을 쓴다.

환원전극(cathode): Cu2+(aq) + 2e− → Cu(s).

산화전극(anode): Zn(s) → Zn2+(aq) + 2e−.

3단계 — 검산한다.

E°전지 = E°(환원전극) − E°(산화전극) = 0.34 − (−0.76) = 1.10 V 이다.

값이 양수이므로 이 방향이 자발적이고 배정이 옳다.

반대로 배정하면 −1.10 V 가 되어 저절로 일어나지 않는다.

4단계 — 그림과 맞춰 본다.

Zn 전극이 녹아 전자를 내놓고 그 전자가 도선을 따라 Cu 전극으로 흘러 Cu2+를 환원시키므로, Zn 쪽이 (−)극, Cu 쪽이 (+)극이다.

결론: 환원전극은 Cu2+ + 2e− → Cu, 산화전극은 Zn → Zn2+ + 2e− 이므로 답은 ③이다.

문제 3표준환원전위정답 ④

④ 아연은 산화되므로 환원제, Cu²⁺는 환원되므로 산화제(반대로 서술해 틀림).

①(Zn이 더 잘 산화)·②(0.34−(−0.76)=1.10V)·③(Cu 환원전극, Zn 산화전극)은 옳다. → ④

산화되는 물질이 환원제(상대를 환원시킴). Zn은 환원제, 구리이온은 산화제. 헷갈리기 쉬운 명명.

문제 6건전지연료전지정답 ②

주어진 것: 건전지(르클랑셰 전지)와 수소–산소 연료전지의 개략도이다.

잘못된 설명을 고르는 문제이므로 네 보기를 하나씩 판정한다.

① 옳다.

연료전지의 (가)는 H2가 들어가는 쪽이다.

H2 → 2H+ + 2e− 로 전자를 내놓으므로 산화전극이고, 전자가 도선으로 흘러나가는 쪽이므로 (−)극이다.

(나)는 O2가 들어가 O2 + 4H+ + 4e− → 2H2O 로 전자를 받으므로 환원전극이고 (+)극이다.

그림의 전자 화살표도 (가)에서 (나)로 향한다.

② 잘못되었다.

건전지의 아연은 Zn → Zn2+ + 2e− 로 전자를 내놓는 환원제이며 (−)극이다.

연료전지의 산소는 전자를 받아 물이 되는 산화제이며 (+)극이다.

전자를 내놓는 쪽과 받는 쪽이므로 역할이 같은 것이 아니라 정반대다.

③ 옳다.

두 반쪽반응 2H2 → 4H+ + 4e− 와 O2 + 4H+ + 4e− → 2H2O 를 더하면 전자 4개와 H+ 4개가 양변에서 지워져 2H2 + O2 → 2H2O 만 남는다.

④ 옳다.

산화 반쪽반응 Zn → Zn2+ + 2e− 와 환원 반쪽반응 2MnO2 + 2NH4+ + 2e− → Mn2O3 + 2NH3 + H2O 를 더한 뒤, 생성된 Zn2+가 NH3 두 분자와 결합하는 Zn2+ + 2NH3 → [Zn(NH3)2]2+ 까지 합치면 보기의 전체 반응식이 그대로 나온다.

Mn의 산화수는 MnO2의 +4에서 Mn2O3의 +3으로 줄어 2몰의 전자를 받고 Zn은 0에서 +2로 늘어 2몰의 전자를 내놓으므로 전자 수도 맞는다.

결론: 잘못된 설명은 ②이다.

문제 8전하량정답 ③

주어진 것: Zn + Ag2O → 2Ag + ZnO, 사용된 Zn 65.4 g, 이론전압 1.59 V 이다.

계산에는 지문에 없는 값인 Zn의 원자량 65.4 와 패러데이 상수 F = 96500 C/mol 을 외워서 쓴다.

1단계 — Zn의 몰수를 구한다.

Zn의 원자량이 65.4 이므로 65.4 g ÷ 65.4 g/mol = 1.00 mol 이다.

2단계 — Zn 1몰이 내놓는 전자 몰수를 구한다.

Zn의 산화수는 홑원소물질 상태의 0에서 ZnO의 +2로 변한다.

즉 Zn → Zn2+ + 2e− 이므로 Zn 1몰당 전자 2몰이 이동한다.

이동 전자 = 1.00 mol × 2 = 2.00 mol 이다.

3단계 — 전하량을 구한다.

Q = nF = 2.00 mol × 96500 C/mol = 193000 C = 1.93 × 105 C 이다.

4단계 — 문제에 주어진 다른 값들을 점검한다.

Ag2O 쪽에서 Ag+ 2몰이 받는 전자 2몰은 Zn이 내놓은 바로 그 2몰이므로 따로 더하지 않는다.

이론전압 1.59 V 도 전하량에는 쓰이지 않고, 전지가 낼 수 있는 에너지 W = QE = 1.93 × 105 C × 1.59 V = 306870 J, 곧 약 3.07 × 105 J 를 구할 때 쓰인다.

결론: ③ 1.93 × 105 C 이다.

문제 14반응차수정답 ①

문제 15반응차수정답 ①

주어진 것: 세 반응 A, B, C 의 속도 관찰 결과이다.

차수마다 드러나는 특징이 다르므로 하나씩 대응시킨다.

반응 A — '반응물의 농도가 시간에 따라 일정하게 감소한다'.

단위 시간마다 줄어드는 양이 늘 같다는 뜻이므로 −Δ[A]/Δt = k 로 속도가 일정하다.

속도가 농도에 전혀 의존하지 않으므로 0차다.

적분 속도식은 [A] = [A]0 − kt 이고 [A]–t 그래프가 직선이 된다.

반응 B — '반감기가 반응물의 농도와 관계없이 일정하다'.

1차 반응의 반감기는 t½ = ln2/k 로 식 안에 초기 농도가 들어 있지 않다.

0차의 반감기는 [A]0/2k 로 농도에 비례하고, 2차의 반감기는 1/(k[A]0) 로 농도에 반비례한다.

반감기가 농도와 무관한 차수는 1차뿐이므로 B는 1차다.

반응 C — '농도를 2배로 하면 속도가 4배가 된다'.

속도식 v = k[C]n 에 넣으면 (2)n = 4 이므로 n = 2, 곧 2차다.

결론: A는 0차, B는 1차, C는 2차이므로 세 값을 순서대로 짝지은 ①이다.

문제 57세라믹정답 ④

주어진 것은 네 세라믹의 실험식이다.

옳지 '않은' 것을 고르는 문제다.

쓰는 법칙: 실험식의 첨자는 구성 원소의 산화수가 서로 상쇄되도록, 곧 양의 산화수 총합과 음의 산화수 총합의 절댓값이 같아지는 가장 간단한 정수비로 정해진다.

① SiC: Si 는 +4, C 는 Si 보다 전기음성도가 커서 −4

다. (+4) + (−4) = 0 이므로 1:1 이 맞다.

탄화규소로 실재하는 세라믹이다.

② SiO2: Si 는 +4, O 는 −2

다. (+4) + 2 × (−2) = 0 이므로 1:2 가 맞다.

③ Si3N4: Si 는 +4, N 은 −3 이다.

3 × (+4) = +12, 4 × (−3) = −12 로 정확히 상쇄되므로 3:4 가 맞다.

질화규소다.

④ B2N3: B 는 13족으로 +3, N 은 15족으로 −3 이라 1:1 로 상쇄된다.

실험식은 BN 이어야 한다.

B2N3 로 두면 2 × (+3) = +6, 3 × (−3) = −9 로 −3 이 남아 중성 화합물이 될 수 없다.

결론: 옳지 않은 것은 ④ 다.

문제 58유효숫자정답 ④

쓰는 법칙: 첫 0이 아닌 숫자 앞에 오는 0(선행 0)은 자릿수를 표시할 뿐 유효숫자가 아니다.

첫 0이 아닌 숫자부터 세고, 남길 자리 바로 다음 숫자가 5 이상이면 올린다.

1단계 유효숫자 세기: 0.045006700 에서 첫 0이 아닌 숫자는 4

다. 거기서부터 4, 5, 0, 0, 6, 7, 0, 0 순으로 센다.

앞의 0.0 은 세지 않는다.

2단계 네 자리 끊기: 남길 유효숫자 넷은 4, 5, 0, 0 이다.

3단계 반올림: 다섯 번째 숫자가 6 이고 6 ≥ 5 이므로 네 번째 자리의 0 을 1 로 올린다.

4, 5, 0, 0 이 4, 5, 0, 1 이 된다.

4단계 자릿수 복원: 원래 값이 0.045… 이므로 4 는 소수점 아래 둘째 자리에 그대로 두어야 한다.

결론: ④ 다.
