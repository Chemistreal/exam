문제 1GHS 그림문자정답 ②
유해·위험성 그림문자(GHS)에 대한 설명 중 자기 분류(옳은/틀린 설명)가 바른 것은? (① (ㄱ)=급성독성 / ② (ㄴ)=고압가스(틀린 설명) / ③ (ㄷ)=인화성 가스 / ④ (ㄹ)=폭발성)
① (ㄱ) 급성독성
② (ㄴ) 고압가스
③ (ㄷ) 인화성
④ (ㄹ) 폭발성

사고과정

②만 자기 분류가 정확 — "(ㄴ)은 고압가스"라는 진술을 틀린 설명으로 바르게 판정(해당 그림문자는 고압가스가 아님). → ②

GHS 그림문자는 폭발성·인화성·산화성·고압가스·부식성·급성독성·건강유해성·환경유해성·경고 9종. 모양과 의미를 정확히 연결해야 한다.
문제 2원자 구성 입자정답 ④
원소·이온의 양성자수·중성자수·전자수·전하량 표에서 미지수 A·B·C·D·E의 합(A+B+C+D+E)은? (전하량 = 양성자수 − 전자수)
① 90
② 100
③ 110
④ 120

사고과정

전하 = 양성자−전자. C = 20−2 = 18, E = 23−20 = +3, D = 15−(−3) = 18, A = 56+(−2)→양성자 54, B(Fe 동위원소 중성자) = 27. 합 = 54+27+18+18+3 = 120. → ④

이온의 전하량은 양성자수에서 전자수를 뺀 값. 전자수는 양성자수와 전하량으로 역산한다.
문제 3용액 농도정답 ②
용매 1000g에 용질 5몰(화학식량 40)이 녹은 용액에서, 용액 60g에 들어있는 용질의 질량은?
① 5g
② 10g
③ 15g
④ 20g

사고과정

용질 5몰×40 = 200g. 용액 = 1000+200 = 1200g. 60g 용액 속 용질 = 200×(60/1200) = 10g. → ②

용액 질량 = 용매+용질. 용질이 균일하게 녹아 있으므로 용액 질량비로 비례 배분한다.
문제 4산소의 산화수정답 ①
OF2·H2O2·CH3COOH에서 (밑줄 친) 산소의 산화수 합은?
① −1
② 0
③ −3
④ −5

사고과정

O 산화수: OF2서 +2(F가 더 전기음성), H2O2서 −1(과산화물), CH3COOH서 −2(일반). 합 = +2−1−2 = −1. → ①

산소는 보통 −2이지만, 플루오린화물(OF2)서는 +2, 과산화물(H2O2)서는 −1로 예외다.
문제 5중화·한계 반응물정답 ④
2HNO3+Mg(OH)2→2H2O+Mg(NO3)2 (HNO3 0.2M 0.25L, Mg(OH)2 1.16g). 옳은 것은? (ㄱ. ICE표 / ㄴ. 한계 반응물은 Mg(OH)2 / ㄷ. 잔여 HNO3+NaOH)
① ㄱ
② ㄱ, ㄴ
③ ㄴ, ㄷ
④ ㄱ, ㄴ, ㄷ

사고과정

HNO3 = 0.2×0.25 = 0.05몰, Mg(OH)2 = 1.16/58 = 0.02몰. ㄴ Mg(OH)2 0.02몰엔 HNO3 0.04몰 필요(0.05 충분) → Mg(OH)2 한계. ㄱ ICE표 일치. ㄷ 잔여 HNO3 0.01몰이 NaOH 0.01몰과 반응. 모두 옳음. → ④

계수비(2:1)로 필요량을 따져 한계 반응물을 정한다. 남은 산은 추가 염기와 다시 중화된다.
문제 6같은 조건 기체 물리량정답 ③
같은 온도·부피·몰수의 서로 다른 두 기체에서 같은 물리량끼리 옳게 짝지은 것은?
① 밀도·압력
② 평균속력·밀도
③ 압력·평균 운동에너지
④ 평균속력·압력

사고과정

P=nRT/V라 같은 n·T·V → 압력 동일. 평균 운동에너지는 온도만 의존 → 동일. 밀도(분자량 의존)·평균속력(∝1/√M)은 분자량 따라 다름. → ③

압력과 평균 운동에너지는 온도·몰수·부피로 정해져 분자 종류와 무관. 밀도·속력은 분자량에 좌우된다.
문제 7이온화 에너지정답 ③
이온화에너지 설명 중 옳은 것은? (가. Be·Mg IE 비교(틀린 설명) / 나. O의 1차 IE가 N보다 작다 / 다. Ar의 IE가 Ne보다 작다)
① 가, 나
② 가, 다
③ 나, 다
④ 가, 나, 다

사고과정

나 O(2p⁴)는 쌍 전자 반발로 1차 IE가 N(2p³ 반채움)보다 작음. 다 Ar(3p)은 Ne(2p)보다 전자가 핵서 멀어 IE 작음. 가는 틀린 설명. → ③

반채움(N의 2p³)은 안정해 IE가 크다. 같은 족은 주기↑면 전자가 멀어져 IE가 감소(Ne>Ar).
문제 8쌍극자 모멘트(이성질체)정답 ④
다이브로모벤젠 이성질체의 쌍극자 모멘트를 작은 것부터 나열한 것은? ((가) ortho 2.06D / (나) meta 1.37D / (다) para 0.00D)

② (나)<(가)<(다)
③ (가)<(다)<(나)
④ (다)<(나)<(가)

두 C-Br 쌍극자의 사잇각이 작을수록 합이 큼. para(180°, 상쇄) 0 < meta(120°) 1.37 < ortho(60°) 2.06. → ④

para는 쌍극자가 정반대라 상쇄돼 0. 두 치환기 사잇각이 작은 ortho가 합벡터가 가장 크다.
문제 9결합 종류정답 ③
다음 중 이온 결합 화합물은? (① HCl / ② NH3 / ③ BaCl2 / ④ SO2)
① HCl
② NH3
③ BaCl2
④ SO2

BaCl2는 금속(Ba)+비금속(Cl) → 이온 결합. HCl·NH3·SO2는 비금속끼리라 공유 결합. → ③

금속+비금속 = 이온 결합, 비금속+비금속 = 공유 결합이 기본 판별법이다.

문제 12온도와 반응 속도정답 ①
대부분의 화학반응에서 온도가 높을수록 증가하지 않는 것은?

② 충돌 에너지

④ 반응 속도

사고과정

온도↑면 운동·충돌 에너지·충돌 빈도·반응 속도 모두 증가. 활성화 에너지는 온도와 무관한 일정한 값(촉매만 변화시킴). → ①

활성화 에너지는 반응 경로 자체의 장벽이라 온도로 바뀌지 않는다. 촉매가 이 장벽을 낮춘다.
문제 13반응 차수·속도 상수정답 ②
Fe(CN)6³⁻+I⁻ 반응. 실험 1·2: [I⁻] 2배면 속도 2배. 실험 2·3: [Fe(CN)6³⁻] 2배면 속도 4배. 속도 상수 k는? (실험1: 속도 2.0×10⁻⁵, 각 농도 10⁻²M)
① 2 M⁻²s⁻¹
② 20 M⁻²s⁻¹
③ 200 M⁻²s⁻¹
④ 2000 M⁻²s⁻¹

사고과정

[I⁻] 1차, [Fe(CN)6³⁻] 2차 → 속도 = k[Fe(CN)6³⁻]²[I⁻]. 실험1 대입: 2.0×10⁻⁵ = k(10⁻²)²(10⁻²) = k·10⁻⁶ → k = 20 M⁻²s⁻¹. → ②

농도 변화 대비 속도 변화 배수로 각 차수 결정(2배→4배는 2차). 전체 3차라 k 단위는 M⁻²s⁻¹.

② 정촉매는 정반응·역반응 속도를 모두 빠르게 한다.
③ 반응 속도식의 전체 차수는 반응 단계 수로 결정된다.

반응 차수는 메커니즘(특히 속도결정단계)에서 나오며 실험으로 확인한다. 균형식 계수나 단계 수와 일치하지 않을 수 있다.
문제 15헨더슨-하셀바흐정답 ②
pH = 5인 완충 용액에서 약산의 pKa = 6일 때 [짝염기 A⁻]:[산 HA]의 비는?
① 1:1
② 1:10
③ 10:1
④ 1:100

사고과정

pH = pKa+log([A⁻]/[HA]) → 5 = 6+log(비) → log(비) = −1 → [A⁻]:[HA] = 1:10. → ②

pH가 pKa보다 1 작으면 짝염기가 산의 1/10. pH<pKa면 산(HA)이 더 많다.
문제 16브뢴스테드-로리 산염기정답 ①

① 가, 나
② 가, 다
③ 나, 다
④ 가, 나, 다

문제 19약산 화학종 농도정답 ①

문제 20산화환원(비타민 C)정답 ③
C6H8O6+Br2→aC6H6O6+bHBr. 옳은 것은? (가. a+b=3 / 나. Br2는 구경꾼 이온 / 다. 비타민 C는 환원제)
① 가, 나
② 나, 다
③ 가, 다
④ 가, 나, 다

① 아연은 수소보다 반응성이 커 표준 환원전위가 음의 값이다.
② 아연판은 산화제이다.
③ 아연판은 브뢴스테드 염기로 작용한다.
④ 반응 중 양이온 총 전하량이 변한다.

① Zn은 H보다 반응성이 커 표준 환원전위가 음수(쉽게 산화). → ①

α 입자 4회·β 입자 4회 방출 후 원자번호와 질량수의 순변화는?
① 원자번호 −4, 질량수 −16
② 원자번호 −8, 질량수 −16
③ 원자번호 +4, 질량수 −16
④ 원자번호 −4, 질량수 −8

사고과정

α 4회: 원자번호 −8, 질량수 −16. β 4회: 원자번호 +4, 질량수 0. 순변화: 원자번호 −8+4 = −4, 질량수 −16. → ①

α 붕괴는 (−2 원자번호·−4 질량수), β⁻ 붕괴는 (+1 원자번호·질량수 불변). 각각 곱해 더한다.
문제 44지시약 변색(pKa)정답 ②
지시약(pKa=5, HIn 붉은색·In⁻ 노란색)의 pH 3과 pH 8에서의 색은?
① pH3 노랑·pH8 빨강
② pH3 빨강·pH8 노랑
③ 둘 다 빨강
④ 둘 다 노랑

사고과정

pH3: [HIn]/[In⁻] = 105−3 = 100:1 → HIn 우세·붉은색. pH8: 105−8 = 1:1000 → In⁻ 우세·노란색. → ②

pH<pKa면 산형(HIn), pH>pKa면 염기형(In⁻)이 우세. pKa 부근서 변색이 일어난다.
문제 45구의 표면적/부피 비정답 ④
구형 입자의 SA/V에 대해 옳은 것은? (가. SA/V = 3/r / 나. 20nm가 20μm보다 SA/V 큼 / 다. 차이는 1000배)
① 가
② 가, 나
③ 나, 다
④ 가, 나, 다

사고과정

SA/V = 4πr²/(4πr³/3) = 3/r(가). 반지름 작을수록 SA/V 큼 → 20nm > 20μm(나). 크기비 20μm/20nm = 10³ → SA/V 차이 1000배(다). 모두 옳음. → ④
