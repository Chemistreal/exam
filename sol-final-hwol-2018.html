문제 1실험안전정답 ②

사고과정

②만 자기 분류가 정확 — "(ㄴ)은 고압가스"라는 진술을 틀린 설명으로 바르게 판정(해당 그림문자는 고압가스가 아님). → ②

GHS 그림문자는 폭발성·인화성·산화성·고압가스·부식성·급성독성·건강유해성·환경유해성·경고 9종. 모양과 의미를 정확히 연결해야 한다.
문제 2원자의구성입자정답 ④

사고과정

전하 = 양성자−전자.

C = 20−2 = 18, E = 23−20 = +3, D = 15−(−3) = 18, A = 56+(−2)→양성자 54, B(Fe 동위원소 중성자) = 27.

합 = 54+27+18+18+3 = 120.

→ ④

이온의 전하량은 양성자수에서 전자수를 뺀 값. 전자수는 양성자수와 전하량으로 역산한다.
문제 3몰랄농도정답 ②

사고과정

용질 5몰×40 = 200g.

용액 = 1000+200 = 1200g.

60g 용액 속 용질 = 200×(60/1200) = 10g.

→ ②

용액 질량 = 용매+용질. 용질이 균일하게 녹아 있으므로 용액 질량비로 비례 배분한다.
문제 4산화수정답 ①

사고과정

O 산화수: OF2서 +2(F가 더 전기음성), H2O2서 −1(과산화물), CH3COOH서 −2(일반).

합 = +2−1−2 = −1.

→ ①

산소는 보통 −2이지만, 플루오린화물(OF2)서는 +2, 과산화물(H2O2)서는 −1로 예외다.
문제 5중화반응정답 ④

사고과정

HNO3 = 0.2×0.25 = 0.05몰, Mg(OH)2 = 1.16/58 = 0.02몰. ㄴ Mg(OH)2 0.02몰엔 HNO3 0.04몰 필요(0.05 충분) → Mg(OH)2 한계. ㄱ ICE표 일치. ㄷ 잔여 HNO3 0.01몰이 NaOH 0.01몰과 반응. 모두 옳음. → ④

계수비(2:1)로 필요량을 따져 한계 반응물을 정한다. 남은 산은 추가 염기와 다시 중화된다.
문제 6PV=nRT정답 ③

사고과정

P=nRT/V라 같은 n·T·V → 압력 동일.

평균 운동에너지는 온도만 의존 → 동일.

밀도(분자량 의존)·평균속력(∝1/√M)은 분자량 따라 다름.

→ ③

압력과 평균 운동에너지는 온도·몰수·부피로 정해져 분자 종류와 무관. 밀도·속력은 분자량에 좌우된다.
문제 7이온화에너지정답 ③

사고과정

나 O(2p⁴)는 쌍 전자 반발로 1차 IE가 N(2p³ 반채움)보다 작음. 다 Ar(3p)은 Ne(2p)보다 전자가 핵서 멀어 IE 작음. 가는 틀린 설명. → ③

반채움(N의 2p³)은 안정해 IE가 크다. 같은 족은 주기↑면 전자가 멀어져 IE가 감소(Ne>Ar).
문제 8쌍극자모멘트정답 ④

사고과정

두 C-Br 쌍극자의 사잇각이 작을수록 합이 큼.

para(180°, 상쇄) 0 < meta(120°) 1.37 < ortho(60°) 2.06.

→ ④

para는 쌍극자가 정반대라 상쇄돼 0. 두 치환기 사잇각이 작은 ortho가 합벡터가 가장 크다.
문제 9이온결합정답 ③

사고과정

BaCl2는 금속(Ba)+비금속(Cl) → 이온 결합. HCl·NH3·SO2는 비금속끼리라 공유 결합. → ③

금속+비금속 = 이온 결합, 비금속+비금속 = 공유 결합이 기본 판별법이다.
문제 10고체의구조정답 ①

사고과정

CsCl은 Cs+·Cl− 단순입방 격자가 서로 관통한 구조.

단위세포당 Cs+ = 꼭짓점 8×(1/8) = 1, Cl− = 체심 1 = 1(1:1).

배위수 8.

→ ①

CsCl은 NaCl(면심입방)과 달리 단순입방 두 격자의 관통 구조로, 배위수가 8이다.
문제 11상태변화정답 ④

사고과정

분자가 고정된 위치에서 진동만 함 = 고체의 특징.

액체가 냉각되어 고체가 되는 응고.

→ ④

고체는 입자가 제자리에서 진동만 한다. 움직임이 점점 줄어 고정되는 건 냉각·응고 과정이다.
문제 12반응도표정답 ①

사고과정

온도↑면 운동·충돌 에너지·충돌 빈도·반응 속도 모두 증가. 활성화 에너지는 온도와 무관한 일정한 값(촉매만 변화시킴). → ①

활성화 에너지는 반응 경로 자체의 장벽이라 온도로 바뀌지 않는다. 촉매가 이 장벽을 낮춘다.
문제 13반응속도상수정답 ②

사고과정

[I−] 1차, [Fe(CN)63−] 2차 → 속도 = k[Fe(CN)63−]2[I−].

실험1 대입: 2.0×10−5 = k(10−2)2(10−2) = k·10−6 → k = 20 M−2s−1.

→ ②

농도 변화 대비 속도 변화 배수로 각 차수 결정(2배→4배는 2차). 전체 3차라 k 단위는 M−2s−1.
문제 14반응속도와에너지정답 ③

사고과정

③ 전체 반응 차수는 실험적으로 또는 속도결정단계로 정하지, 반응 단계 수로 결정되지 않음. 틀림. → ③

①(흡열 생성물 高)·②(촉매 양방향 가속)·④(k는 온도 함수)는 옳음.

반응 차수는 메커니즘(특히 속도결정단계)에서 나오며 실험으로 확인한다. 균형식 계수나 단계 수와 일치하지 않을 수 있다.
문제 15헨더슨-하셀바흐식정답 ②

사고과정

pH = pKa+log([A−]/[HA]) → 5 = 6+log(비) → log(비) = −1 → [A−]:[HA] = 1:10.

→ ②

pH가 pKa보다 1 작으면 짝염기가 산의 1/10. pH<pKa면 산(HA)이 더 많다.
문제 16브뢴스테드로리산염기정답 ①

사고과정

가 CH3COOH는 H2O에 H⁺를 줌 → 산. 나 H2O는 H⁺를 받아 H3O⁺ → 염기. 다 짝산-짝염기 관계 서술에 오류. → ①

브뢴스테드-로리: H⁺를 주면 산, 받으면 염기. CH3COOH의 짝염기는 CH3COO⁻(H⁺ 하나 차이).
문제 17불꽃색정답 ④

사고과정

가·나 A = K(보라 불꽃, K+O2→KO2 초과산화물·산소 호흡장치에 사용). 다·라 B = I(I2 승화·반지름 Se<I<Te). 모두 옳고 AB = KI. → ④

칼륨은 보라색 불꽃과 초과산화물(KO2)이 특징. 아이오딘은 고체지만 승화하며 같은 주기 Se·Te 사이 크기.
문제 18몰용해도정답 ①

사고과정

① pH↓면 [H⁺]↑ → 평형이 정반응(용해)으로 이동 → CdS 용해도 증가. (②③④는 몰 용해도에 영향 없음.) → ①

S²⁻가 약산(H2S)의 짝염기라 산을 넣으면 S²⁻가 소모돼 CdS가 더 녹는다(공통 평형 이동).
문제 19산의해리정답 ①

사고과정

[H+] = √(KaC) = 10−2·37 ≈ 0.004M로 작음(α≈0).

[HA] = C(1−α) ≈ 1.0M로 가장 많음.

→ ①

약산은 거의 해리되지 않아 분자 상태(HA)가 대부분. 해리된 H+·A−는 소량이다.
문제 20적정정답 ③

사고과정

C6H8O6+Br2→C6H6O6+2HBr. 가 a=1·b=2 → a+b=3. 다 C 산화수↑(비타민 C 산화)·Br 0→−1(환원) → 비타민 C는 환원제. 나 Br2는 반응에 참여하므로 구경꾼 아님. → ③

자신이 산화되며 상대를 환원시키는 물질이 환원제. Br2는 환원되는 산화제이자 직접 참여 물질이다.
문제 21금속의반응성정답 ①

사고과정

① Zn은 H보다 반응성이 커 표준 환원전위가 음수(쉽게 산화). → ①

② Zn은 산화되며 H⁺를 환원 → 환원제. ③ 산화환원이지 양성자 이동(염기) 아님. ④ Zn²⁺ 1개(+2)당 H⁺ 2개(+2) 소모 → 총 전하량 일정.

활동도 서열서 H보다 위(반응성 큼)인 금속은 표준 환원전위가 음수라 산에 녹으며 H2를 발생시킨다.
문제 22방사성붕괴정답 ①

사고과정

(a) 질량수↑·원자번호 일정 → 중성자 포획. (b) 질량수 일정·양성자수+1 → β 붕괴(중성자→양성자+전자). → ①

중성자 포획은 질량수만 +1(원자번호 불변). β⁻ 붕괴는 질량수 불변·원자번호 +1이다.
문제 23배위화학정답 ②

문제 24촉매정답 ④

사고과정

촉매는 가(반응경로)·나(활성화에너지)·중간체·속도상수를 바꿈. 그러나 다(반응열)·라(생성물 에너지)는 불변. → ④

촉매는 더 낮은 장벽의 새 경로를 제공할 뿐, 반응물·생성물의 에너지(따라서 반응열 ΔH)는 바꾸지 못한다.
문제 25이성질체정답 ③

사고과정

1.

이성질체 = 3(cis 광학 2 + trans 1).

2.

Co 산화수: en 중성·2Cl− = −2·전체 +1 → +3.

3.

배위수: en(친이좌배위) 2×2 + Cl 2 = 6.

합 = 3+3+6 = 12.

→ ③

en은 한 분자가 2자리 배위(이좌배위). cis 형은 거울상이 겹치지 않아 광학 이성질체 2개를 가진다.
문제 26동위원소정답 ④

사고과정

79x+81(1−x) = 79.9 → 81−2x = 79.9 → x = 0.55.

79Br 55%·81Br 45%.

→ ④

평균원자량은 (동위원소 질량×존재비)의 합. 평균이 79.9로 79에 가까워 가벼운 79Br이 더 많다.
문제 27계수맞추기①·② 복수정답

사고과정

이 문항은 원본 시험에서 복수정답 ①②로 처리되었다.

요소 1몰 → NH3 2몰.

SCR(선택적 촉매 환원)서 NH3가 NO를 환원(4NH3+4NO+O2→4N2+6H2O, 1:1).

따라서 NO 최대 2몰 처리.

인용된 반응식 표현에 따라 두 답이 모두 인정됨.

요소가 가수분해로 암모니아 2몰을 내고, 그 암모니아가 질소산화물을 환원한다.

NO/NO2 반응식 표기차로 복수정답 처리.

문제 28실험식정답 ④
