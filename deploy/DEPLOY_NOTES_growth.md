성장 10단계 개선 플랜 중 1단계(진단 무결화, 선행 완료)를 제외한 2~10단계 전부를 index.html 단일 파일에 구현.

## 단계별 요지

### 2단계 · 개인별 성장 기준선 - "성장 추이 · 기준선 대비"
첫 진단을 기준선으로 고정, 총점 궤적·영역 Δ·비교 상대(같은/동형/다른 시험)·첫 응시 콜아웃.

### 3단계 · 약점 -> 처방 자동 연결 - "다음 학습 처방" 증강
각 처방 항목에 "해설 바로가기" 링크(오답/약점 영역 실제 오답/개념 교정/심화).

### 4단계 · 선지별 오개념 지도 - "오답 개념 분석" 증강
오답 카드마다 확장형 지도: 오답 선지별 오개념+교정, 내 선택 강조, 정답 명시.

### 5단계 · 개념 숙달 추적 - "개념 숙달 · 정착 추적"
영역별 미습득/습득/정착 3분류(이전+이번 종합), 흔들림 배지, 간격 재출제 추천+해설 링크.

### 6단계 · 학부모 서사 리포트 - "이번 학습 리포트 · 학부모용"
성장·숙달·현재 위치를 문장으로 자동 서술 + 담당 강사 코멘트(교사 입력, 인쇄·공유에 유지).

### 7단계 · 학생 동기 설계 - "성장 배지 · 나의 목표"
목표 진척 바(추천/커스텀) + 정착 배지 + 마일스톤(실제 달성분만).

### 8단계 · 경쟁 좌표 · 목표 정렬 - "경쟁 좌표 · 목표 정렬"
코호트 백분위 좌표·사다리 SVG·목표 tier(과학고/영재고/올림피아드/메달권)·목표까지 올릴 영역.
내부 시험은 실제 수상 컷이 없어 실측 백분위 사용, 허위 컷 미생성 + 고지문 명시.

### 9단계 · 개념 깊이 · 사고력 - "개념 깊이 · 사고력"
영역별 문항을 난이도(정답률)로 기본/심화 분리, 깊이 3분류(깊은 이해/표면 이해/기초 미흡).
표면 이해 영역엔 심화 미해결 해설 링크. "답을 아는 것과 구조로 이해하는 것은 다르다" 코칭.

### 10단계 · 폐쇄 루프 + 장기 추적 - "성장의 증거 · 폐쇄 루프"
영역별 처음 등장 대비 최근 정답률을 비교, 약점(60% 미만) -> 정착(80% 이상)으로 올라선 영역을 "닫힌 루프(해결)"로 증명.
진행 중(개선)·아직 열린 루프(우선 처방)·강점 유지로 분류. 종단 지표(진단 횟수, 기간, 기준선 대비, 정착·해결 영역).
진단 -> 처방 -> 재학습 -> 재진단 -> 성장의 루프가 실제로 닫혔다는 증거를 정리. 같은/동형 시험 재응시가 쌓일수록 촘촘.

- 아홉 기능 모두 기존 로컬 명단·문항은행·오개념·코호트(SEED) 데이터에서 파생. 저장 포맷·구글 시트·공유링크 해시 무변경(하위호환 100%).
