문제 4이온화에너지정답 ②

난이도 중 중성 Na, P, S, Cl, K 원자의 1차 이온화 에너지를 큰 순서대로 나열한 것은? ① Cl > S > P > Na > K ② Cl > P > S > Na > K ③ Na > Cl > S > P > K ④ K > Na > P > S > Cl ■ 무엇을 묻는 문제인가 이온화 에너지의 주기적 경향을 알고 있는지, 그리고 그 경향을 벗어나는 예외(2족-13족, 15족-16족 사이의 역전)를함께 적용할 수 있는지를 묻습니다.

단순 암기만으로는 P와 S의 순서에서 반드시 걸립니다.

1차 이온화 에너지(IE₁)는 기체 상태 중성 원자 1몰에서 전자 1몰을 떼어내는 데 필요한 에너지입니다.

값이 클수록전자를 꽉 붙잡고 있다는 뜻이죠.

일반 경향은 두 가지입니다.

첫째, 같은 주기에서 오른쪽으로 갈수록 유효 핵전하가 커지고 원자 반지름은 작아지므로 IE₁이 증가합니다.

둘째, 같은 족에서 아래로 갈수록 껍질이 늘어 최외각 전자가 핵에서 멀어지고 가려막기가 커지므로 IE₁이 감소합니다.

예외도 두 가지가 유명합니다.

(i) 2족 → 13족: 13족은떼어낼 전자가 np에 있어 ns보다 에너지가 높아 오히려 떼기 쉽습니다.

(ii) 15족 → 16족: 15족은 p 오비탈 3칸에전자가 하나씩 들어간 반만 채워진(half-filled) 안정한 배치라 전자를 떼기 어렵고, 16족은 한 오비탈에 전자 2개가짝지어져 반발이 생기므로 오히려 떼기 쉽습니다.

그래서 IE₁(P) > IE₁(S)가 됩니다.

문제 21이온화상수정답 ①

난이도 하 HCOOH 용액 0.2 M 의 [H⁺]가 6.0 × 10⁻³이다.

이 때, HCOOH의 Ka는 얼마인가? ① 1.8 × 10⁻⁴ ② 1.0 × 10⁻⁴ ④ 1.8 × 10⁻⁸ ③ 1.8 × 10⁴ ■ 무엇을 묻는 문제인가 약산의 초기 농도와 평형 상태의 [H⁺]만 주어졌을 때 이온화 상수 Ka를 구하는 가장 기본적인 문제입니다.

평형 표(ICE 표)를 세우거나 이온화도 α를 이용하는 두 가지 길이 있는데, 어느 쪽으로 가도 같은 답이 나옵니다.

약산에서쓸 수 있는 근사(C - x ≈ C)의 타당성을 스스로 확인하는 습관도 함께 점검합니다.

1) 약산의 이온화 평형 HCOOH(aq) ⇌ H⁺(aq) + HCOO⁻(aq) Ka = [H⁺][HCOO⁻] / [HCOOH] 2) 초기 농도 C, 이온화된 농도를 x라 하면 평형에서 [H⁺] = x, [HCOO⁻] = x, [HCOOH] = C - x Ka = x²/(C - x) 약산은 x가 C에 비해 작으므로 C - x ≈ C 로 근사할 수 있고, 이때 Ka ≈ x²/C 입니다.

(근사가 타당한지는 x/C가 5% 미만인지로 판정합니다.) 3) 이온화도 α = 이온화된 몰수 / 처음 몰수 = x/C 이므로 x = Cα 이고, Ka = (Cα)²/(C - Cα) ≈ Cα² (α가 작을 때) 이를 오스트발트 희석 법칙이라고 합니다.

C = 0.2 M, x = [H⁺] = 6.0×10⁻³ M [H⁺] = 6.0×10⁻³ M [HCOO⁻] = 6.0×10⁻³ M (물의 이온화는 무시) [HCOOH] = 0.2 - 0.006 = 0.194 ≈ 0.2 M 단계 2) Ka에 대입합니다.

Ka = (6.0×10⁻³)(6.0×10⁻³) / 0.2 = 3.6×10⁻⁵ / 0.2 37 = 1.8×10⁻⁴ [방법 2] 이온화도 이용 단계 1) α = [H⁺]/C = (6.0×10⁻³)/0.2 = 3.0×10⁻² (즉 3.0 %) 단계 2) Ka = Cα² = 0.2 × (3.0×10⁻²)² = 0.2 × 9.0×10⁻⁴ = 1.8×10⁻⁴ 단계 3) 근사의 타당성 확인: α = 3.0 %로 5 %보다 작으므로 C - x ≈ C 근사를 써도 됩니다.

근사 없이 Ka =3.6×10⁻⁵/0.194 = 1.86×10⁻⁴ 로 계산해도 선지 중 가장 가까운 값은 여전히 1.8×10⁻⁴ 입니다.

① 1.8 × 10⁻⁴ ⇒ 옳음.

Ka = (6.0×10⁻³)²/0.2 = 1.8×10⁻⁴ 이며, 실제 폼산(개미산)의 Ka 문헌값과도 일치합니다.

② 1.0 × 10⁻⁴ ⇒ 틀림.

자릿수는 비슷하지만 계수가 맞지 않습니다.

[H⁺]²을 3.6×10⁻⁵이 아니라 2×10⁻⁵ 부근으로 어림했을 때 나오는 값입니다.

③ 1.8 × 10⁴ ⇒ 틀림.

Ka가 1보다 크다는 것은 완전히 이온화되는 강산이라는뜻인데, 문제에서 폼산은 0.2 M에서 [H⁺]가 겨우 6.0×10⁻³ M밖에 되지 않는 약산입니다.

지수의 부호를 빠뜨렸을 때 나오는 값입니다.

④ 1.8 × 10⁻⁸ ⇒ 틀림.

문제 22이온화도정답 ④

난이도 중 1.0 M 미지의 산 HA의 이온화도가 0.99라고 할 때, [H⁺]×Ka와 가장 가까운 값은 어느 것인가? ① 10⁻⁴ ② 10⁻² ③ 1 ④ 10² ■ 무엇을 묻는 문제인가 이온화도 α의 정의에서 출발해 평형 농도를 모두 채우고, 거기서 산 해리상수 Ka를 직접 계산할 수 있는지 묻는 문제입니다.

"이온화도가 0.99"라는 말이 곧 "거의 완전히 이온화되는 강산"이라는 뜻이고, 그런 산의 Ka는 1보다 훨씬 큰 값이 된다는 감각을 갖추었는지가 관건입니다.

약산의 근사식(Ka = Cα²)을 무비판적으로 쓰면 틀리도록 설계되어 있습니다.

1) 이온화도 α = (이온화된 산의 몰수)/(처음 넣은 산의 몰수) 입니다.

0 ≤ α ≤ 1 이며, α가 1에 가까울수록 강한 산입니다.

2) HA ⇌ H⁺ + A⁻ 에서 처음 농도가 C일 때 평형 농도는 [HA] = C(1 - α), [H⁺] = [A⁻] = Cα 입니다.

3) 이것을 평형식에 넣으면 Ka = [H⁺][A⁻]/[HA] = (Cα)²/(C(1-α)) = Cα²/(1-α) 입니다.

이 식이 이 문제의 뼈대입니다.4) α가 매우 작을 때만 1 - α ≈ 1 이 성립해 흔히 쓰는 Ka ≈ Cα² 가 됩니다.

여기서는 α = 0.99 라 1 - α = 0.01 로 아주 작아지고, 이 값이 분모에 들어가 Ka를 100배 규모로 키웁니다.

근사를 쓰면 안 되는 대표적인 상황입니다.

5) 강산의 Ka는 1보다 훨씬 큽니다.

예를 들어 HCl은 약 10⁶, HNO₃는 약 20 수준입니다.

Ka가 1보다 크면 pKa는 음수가 됩니다.

6) 구하는 값이 [H⁺]×Ka이므로 농도와 상수를 곱한 합성량입니다.

C가 커지면 [H⁺]도 커지고 Ka도 C에 비례해 커지므로, 이 곱은 C의 제곱에 비례해 급격히 커집니다.

단계 1) ICE를 세웁니다.

C = 1.0 M, α = 0.99 이므로 이온화된 양은 1.0 × 0.99 = 0.99 M 입니다.

38 처음: [HA] = 1.00, [H⁺] = 0, [A⁻] = 0 변화: [HA] -0.99, [H⁺] +0.99, [A⁻] +0.99 평형: [HA] = 0.01, [H⁺] = 0.99, [A⁻] = 0.99 단계 2) Ka를 계산합니다.

Ka = [H⁺][A⁻]/[HA] = (9.9×10⁻¹ × 9.9×10⁻¹)/(1.0×10⁻²) = (9.801×10⁻¹)/(1.0×10⁻²) = 98.0 단계 3) 공식으로 검산해도 같습니다.

Ka = Cα²/(1 - α) = 1.0 × (0.99)²/(1 - 0.99) = 1.0 × 0.9801/0.01 = 98.0 단계 4) 구하는 값을 계산합니다.

[H⁺] × Ka = 0.99 × 98.0 = 97.0 단계 5) 97.0은 100 = 10²에 매우 가깝고, 선지의 다른 값(10⁻⁴, 10⁻², 1)과는 자릿수 자체가 다릅니다.

따라서 답은④ 10² 입니다.

① 10⁻⁴ ⇒ 틀림.

약산으로 착각해 Ka를 10⁻⁴ 정도로 잡고 [H⁺]를 곱하는 것을 잊었을 때 나오는 값입니다.

α =0.99인 산은 강산이므로 Ka가 10⁻⁴일 수 없습니다.

② 10⁻² ⇒ 틀림.

1 - α = 0.01 을 분모가 아니라 분자에 곱해 Ka≈ Cα²(1-α) ≈ 0.0098 로 계산했을 때 나오는 값입니다.

③ 1 ⇒ 틀림.

Ka ≈ Cα² = 1.0 × 0.9801 = 0.98 로 근사해 버리면 [H⁺]×Ka = 0.99 × 0.98 ≈ 0.97 ≈ 1 이 나옵니다.

이것이 이 문제의 가장 대표적인 함정으로, 1 - α =0.01 을 분모에 넣지 않은 결과입니다.

④ 10² ⇒ 옳음.

Ka = 98.0, [H⁺] = 0.99 이므로 곱은 97.0 ≈ 10² 입니다.

④ Ka = 1.0 × 0.99²/0.01 = 98.0 이고 [H⁺] = 0.99 이므로 곱은 97.0, 즉 약 10²입니다.

문제 23수득률정답 ①

5) 과량 반응물의 남는 양 = 처음 몰수 - (한계반응물 몰수 × 계수비)로 구합니다.

단계 5) 검산합니다.

③ TiCl₄, 53.3% ⇒ 틀림.

문제 29열역학정답 ②

난이도 하 어떤 기체가 압축되면서 외부로부터 2.0 kJ 만큼의 일을 받고, 이 과정 중에서 3.5 kJ 만큼의 열이 기체로부터 방출되었다.

이 과정에서 기체의 총 내부에너지 변화는? ① -5.5 kJ ② -1.5 kJ ③ +1.5 kJ ④ +5.5 kJ 46 ■ 무엇을 묻는 문제인가 열역학 제1법칙을 직접 적용하는 기본 계산 문제입니다.

숫자 자체는 아주 간단하지만, "외부로부터 일을 받았다"와"열이 방출되었다"라는 표현의 부호를 정확히 붙일 수 있는지가 승부처입니다.

1) 열역학 제1법칙(에너지 보존): ΔU = q + w 여기서 ΔU는 계(기체)의 내부 에너지 변화, q는 계가 흡수한 열, w는계가 받은 일입니다.

2) 부호 규약(계를 기준으로 생각합니다) - 계가 열을 흡수하면 q > 0, 계가 열을 방출하면 q < 0 - 계가 외부로부터 일을 받으면(압축) w > 0, 계가 외부에 일을 하면(팽창) w < 0 3) 즉 "기체가 압축되면서 외부로부터 일을 받았다"는 것은 계가 에너지를 받아들였다는 뜻이므로 w는 양수입니다.물리적으로도 압축하려면 외부가 기체를 밀어 주어야 하므로 에너지가 안으로 들어옵니다.

② -1.5 kJ ⇒ 옳음.

이것이 정답입니다.

③ +1.5 kJ ⇒ 틀림.

문제 30열화학정답 ①

난이도 중 등온 과정(isothermal process)에서는 계의 온도가 일정하게 유지된다.

이상 기체가 겪는 가역 등온 팽창(reversible isothermal expansion)에서 반드시 참인 것은 어느 것인가? Ⅰ.

ΔU = 0 Ⅱ.

ΔS = 0 ① Ⅰ만 ② Ⅱ만 ③ Ⅰ과 Ⅱ 모두 ④ Ⅰ과 Ⅱ 모두 아니다 47 ■ 무엇을 묻는 문제인가 이상 기체의 내부 에너지가 오직 온도만의 함수라는 사실과, 엔트로피의 정의식 dS = (가역 경로의 열)/T 를 조건에정확히 적용할 수 있는지 묻는 문항입니다.

단열 과정과 등온 과정을 구별하는 것이 관건입니다.

1) 이상 기체의 내부 에너지는 부피나 압력에 의존하지 않고 온도만의 함수입니다.

ΔU = n × CV × ΔT 이므로 온도가 일정하면(ΔT = 0) ΔU = 0 입니다.

이것이 등온 과정의 정의에서 곧바로 따라 나오는 결론입니다.

2) 엔트로피의 열역학적 정의는 dS = (가역 경로에서 주고받은 열)/T 입니다.

S는 상태함수이므로 실제 경로가 비가역이어도계산은 가역 경로로 합니다.

3) 가역 등온 팽창에서 제1법칙을 쓰면 ΔU = q + w = 0 이므로 q = -w 입니다.

팽창하며 계가 일을 했으니 w < 0 이고, 따라서 q > 0 입니다.

즉 계는 열을 흡수합니다.

4) 이상 기체의 엔트로피 변화는ΔS = n × CV × ln(T2/T1) + nR ln(V2/V1) 입니다.

등온이면 첫 항이 0이므로 ΔS = nR ln(V2/V1) 이 되고, 팽창이면 V2 > V1 이므로 ΔS > 0 입니다.

5) ΔS = 0(등엔트로피)이 되는 것은 "단열 + 가역"이 동시에 성립할 때입니다.등온은 단열이 아니므로 이 조건에 해당하지 않습니다.

6) 정리하면 등온이면 ΔU = 0, ΔH = 0(이상 기체), 단열이면 q = 0, 정압이면 ΔH = q, 정적이면 ΔU = q 입니다.

어떤 조건에서 무엇이 0이 되는지를 표로 외워 두면 이런 문항은 즉답할 수 있습니다.

단계 1) Ⅰ을 판정합니다.

이상 기체이고 등온이므로 ΔT = 0 입니다.

ΔU = n × CV × ΔT = n × CV × 0 = 0 따라서 Ⅰ은 참입니다.

가역이든 비가역이든, 팽창이든 압축이든 등온이기만 하면 성립합니다.

단계 2) Ⅱ를 판정합니다.

제1법칙에서 0 = q + w 이므로 q = -w 입니다.

단계 4) ΔS = 5.76 J/K ≠ 0 이므로 Ⅱ는 거짓입니다.

계가 열을 흡수했으므로 엔트로피가 늘어나는 것이 당연합니다.

단계 5) 따라서 Ⅰ만 참이고 정답은 ①입니다.

① Ⅰ만 ⇒ 옳음.

② Ⅱ만 ⇒ 틀림.

ΔS = 0 은 "단열 + 가역"일 때 성립하는 결론인데, 이 과정은 단열이 아니라 등온입니다.

두 조건을 맞바꿔 외운 대표적인 오답입니다.

③ Ⅰ과 Ⅱ 모두 ⇒ 틀림.

Ⅰ은 옳지만 Ⅱ가 틀렸습니다.

"ΔU = 0이니 q도 0이겠지"라고 생각하면 이 선지를 고르게 되는데, ΔU = 0 은 q와 w가 서로 상쇄된다는 뜻이지 둘 다 0이라는 뜻이 아닙니다.

④ Ⅰ과 Ⅱ 모두 아니다 ⇒ 틀림.
