문제 1물분자수정답 ③

사고과정

물 질량 = 50×0.70 = 35 kg = 35000

g. 몰수 = 35000/18 ≈ 1944몰.

분자수 = 1944×6.0×1023 ≈ 1.2×1027 ≈ 1027.

→ ③

질량 → 몰수(÷몰질량) → 아보가드로 수 곱. 차수 비교라 자릿수만 맞으면 된다.
문제 2PV=nRT정답 ④

사고과정

n = PV/RT = (10-10 × 10-6 m3)/(8.3×300) ≈ 4×10-20몰.

분자수 = 4×10-20×6.0×1023 ≈ 2.4×104 ≈ 3×104.

→ ④

이상기체식 n=PV/RT에 SI 단위 대입(Pa·m3·J). 초고진공이라도 1 mL에 수만 개의 분자가 존재한다.
문제 3원자의표시정답 ④

사고과정

원자 표기는 왼쪽 위가 질량수, 왼쪽 아래가 원자번호(양성자 수)다.

원자번호가 원소 기호와 맞는지 본다.

Li 은 3, C 는 6, P 는 15 로 맞는데 Cu 는 29 다 — 30 은 Zn 이다.

→ ④

문제 4리비히원소분석장치정답 ①

사고과정

물은 건조제(실리카겔)에, CO2는 염기(수산화나트륨)에 흡수.

→ ①

연소 분석은 물을 먼저(건조제) 잡고 그 뒤 CO2를 염기로 잡아 각각의 질량 증가로 H·C 양을 정량한다.
문제 5산화환원반응정답 ②

사고과정

선택적 촉매 환원(SCR): NOx + NH3 → N2 + H2O.

질소(환원 생성물) 외 부산물은 물.

→ ②

NH3의 H가 산소와 결합해 물이 되고, N은 N2로 환원된다. 대기오염 저감 장치의 핵심 반응.
문제 6계수맞추기정답 ④

사고과정

Cl: +5→−1(6e- 환원), S: +4→+6(2e- 산화).

전자 맞추면 ClO3- + 3SO2 + 3H2O → 3SO42- + Cl- + 6H+.

a=3, d=6.

→ ④

반쪽 반응의 전자 수(6과 2)를 최소공배수(6)로 맞춘 뒤 합산. 원자·전하 모두 검산.
문제 7표준생성엔탈피정답 ③

사고과정

½I2(s)+½Cl2(g)→ICl(g): ½(65) + ½(150) + ½(243) − 211 = 32.5+75+121.5−211 = 18 kJ/mol.

→ ③

생성 엔탈피 = (원소를 기체 원자로 분해하는 에너지의 합) − (생성물 결합 에너지). I2는 고체라 승화 단계가 추가된다.
문제 8수소스펙트럼정답 ④

사고과정

둘 다 n 감소 → 방출(A).

더 긴 파장 = 낮은 에너지 = (b) n=3→2(발머, 라이먼보다 저에너지).

→ ④

전자가 낮은 준위로 떨어지면 방출. n=2→1(라이먼·자외선)이 n=3→2(발머·가시광선)보다 에너지가 커 파장이 짧다.
문제 9연소열정답 ①

사고과정

CO2/열량 = 탄소수/연소열: C(s) 1/396 = 0.00253(최대), CH4 1/896, C8H18 8/5472, C7H8 7/3864.

→ ①

단위 열량당 CO2는 (탄소수/연소열). 수소가 없는 흑연이 같은 열을 내는 데 CO2를 가장 많이 배출한다.
문제 10헤모글로빈정답 ②

사고과정

Fe2+ = [Ar]3d6, Fe3+ = [Ar]3d5.

빠지는 전자는 3d(n=3, l=2).

n+l = 5.

→ ②

전이금속 양이온은 4s를 먼저 잃은 상태. Fe2+→Fe3+는 3d 전자 1개를 더 잃는다(l=2는 d오비탈).
문제 11시그마파이결합정답 ②

사고과정

σ = C−C 6 + C−H 10 = 16(ㄱ 15 틀림). ㄴ π = 이중1+삼중2 = 3(옳음). ㄷ sp²는 C3·C4뿐이라 그 사이 σ 1개(옳음).

ㄹ sp 탄소는 C6·C7로 2개(1 아님). → ②

모든 결합은 σ 1개 포함, 다중결합의 추가분이 π. 이중결합 탄소는 sp², 삼중결합 탄소는 sp.
문제 12혼성오비탈정답 ③

사고과정

③ 표시된 아민 질소(−NH2)는 결합 3개+고립쌍 1개라 sp³로 본다 → "sp²"는 틀림. → ③

①(인산 P sp³)·②(에터 O sp³)·④(방향족 고리 C sp²)는 옳음.

단일결합 3개+고립쌍 1개인 질소는 sp³(피라미드형). 고리의 방향족 탄소·질소는 sp²로 평면을 이룬다.
문제 13분자구조정답 ③

사고과정

XeOF2: 중심 Xe에 결합 3개(O·F·F) + 고립쌍 2개 = 5 전자 영역(삼각쌍뿔).

고립쌍이 적도면을 차지 → T-자형(ClF3와 유사).

→ ③

전자 영역 5개에 고립쌍 2개면 T자형. 고립쌍은 반발이 커 적도 위치를 선호한다.
문제 14극성정답 ④

사고과정

④ SF4는 고립쌍 1개로 시소형(비대칭) → 극성(쌍극자 모멘트 있음). XeF4·BrF4⁻(평면사각)·ClF2⁻(직선)은 대칭이라 무극성. → ④

고립쌍이 대칭을 깨면 극성. 평면사각형·직선형처럼 대칭이 높으면 결합 쌍극자가 상쇄돼 무극성이다.
문제 15몰농도정답 ③

사고과정

M = (d×0.98×1000)/98 = 10d.

18.0 = 10d → d = 1.8 g/mL.

→ ③

몰농도 = (밀도×질량분율×1000)/몰질량. H2SO4는 몰질량 98이라 계수가 깔끔하게 10d가 된다.
문제 16이온결합정답 ④

사고과정

이온성 ∝ 전기음성도 차.

KCl(금속 K + 비금속 Cl, ΔEN ≈ 2.2)이 최대.

나머지는 극성 공유결합.

→ ④

금속-비금속 결합이 전기음성도 차가 커 이온성이 크다. 비금속끼리는 공유결합 성격이 우세.
문제 17결합세기정답 ②

사고과정

② 극성(ΔEN): F–Cl(1.0)<F–Br(1.2)<F–H(1.9) 옳음.

① C≡O가 최대(중간 아님). ③ N>O(반채움 안정). ④ O²⁻가 최대(전자 얻어 커짐). → ②

결합 에너지 C≡O>C≡C>C=C, 이온화는 N>O(2p³ 안정), 등전자 이온은 양성자 적을수록 큼(O²⁻>F⁻).
문제 18용해도정답 ①

사고과정

A=B=1.5

g. 25°C·0.5 L 용해: A 2.4×0.5=1.2 g·B 1.2×0.5=0.6

g. 석출: A 0.3·B 0.9(총 1.2).

A% = 0.3/1.2 = 25%, B% = 75%.

→ ①

석출량 = (가진 양) − (25°C 최대 용해량). 용해도×부피로 각 물질의 용해 한계를 구한다.
문제 19분출속도정답 ①

사고과정

분출률 ∝ P/√M(구멍 면적 동일).

(가) 2/√2=1.41 > (나) 2/√4=1.0 > (다) 4/√32=0.71.

→ ①

분출 분자 수는 압력에 비례, √(분자량)에 반비례. 압력이 높아도 무거우면 느릴 수 있다.
문제 20상평형정답 ①

사고과정

① 25°C는 임계온도(31°C)보다 낮아 가압하면 액화 가능 → "만들 수 없다"는 틀림. → ①

②(1 atm<삼중점 5.1 atm이라 승화)·③(35°C>임계 31°C라 액체 없음)·④(액체 증기압>고체)은 옳음.

임계온도 아래면 가압으로 액화 가능. 삼중점 압력보다 낮으면 고체는 녹지 않고 곧장 승화한다.
문제 21약산의희석정답 ③

사고과정

가 묽히면 산성 약화 → pH 증가. 나 오스트발트 희석 법칙으로 해리도 증가. 다 Kw·pKw는 온도만 의존(불변). → ③

문제 23촉매정답 ④

사고과정

④ 촉매는 활성화 에너지가 낮은 새 경로를 제공. 온도·분자 에너지 분포는 바꾸지 않으며 Ea를 낮춤(③ 반대). → ④

촉매는 반응 전후 변하지 않고 경로(메커니즘)만 바꿔 Ea를 낮춘다. ΔH·평형은 바꾸지 않는다.
문제 24반응의자발성정답 ①

사고과정

이상용액: ΔmixH = 0(양수 아님), ΔmixS > 0(양수), ΔmixG = −TΔmixS < 0(음수).

양수는 1개.

→ ①

이상 혼합은 발열·흡열이 없어 ΔH=0, 무질서 증가로 ΔS>0, 자발적이라 ΔG<0이다.
문제 25계수맞추기정답 ①

사고과정

속도 = (1/a)(−ΔA/Δt) = (1/b)(−ΔB/Δt) = (1/c)(ΔC/Δt).

A·B 속도 같으니 a=b, C가 2배라 c=2a → 1:1:2.

a+b+c = 1+1+2 = 4.

→ ①

각 물질의 농도 변화 속도를 계수로 나누면 모두 같은 반응 속도. 속도 비가 곧 계수 비다.
문제 26용융엔탈피정답 ②

사고과정

융해는 녹는점(0°C = 273 K)서 평형(ΔG=0) → ΔS = ΔH/T = 6030/273 = 22.1 J/K·mol.

→ ②

상전이는 전이 온도에서 ΔG=0이라 ΔS=ΔH/T. 융해는 무질서가 늘어 ΔS>0이다.
문제 27삼투압정답 ③

사고과정

삼투압 ∝ i×몰랄농도: NaCl(i=2) 2 m > 글루코스(i=1) 1

m. 물이 NaCl 쪽으로 이동 → NaCl 쪽 수위 상승.

→ ③

물은 유효 입자 농도가 낮은 쪽에서 높은 쪽으로 이동. 전해질은 해리되어 입자 수(i)가 늘어 삼투압이 크다.
문제 28중화적정정답 ④

사고과정

당량점이 10·30 mL(2단계가 1단계의 2배).

Na2CO3 단독이면 두 단계가 같음(10·20).

1:3 패턴은 CO32- 1단계(a) + 전체 HCO3- 2단계(a+b=2a)인 혼합물.

→ ④

Na2CO3는 2단계 당량점 간격이 동일(V, 2V). HCO3-가 섞이면 2단계가 길어져 간격 비가 달라진다.
문제 29형식전하정답 ③

사고과정

형식전하 최소·음전하가 전기음성도 큰 O에 있는 것이 안정. ③ [N≡C−O]⁻: N(0)·C(0)·O(−1). ①은 N(−2)·O(+1), ②는 N(−1)으로 덜 안정. → ③

가장 기여 큰 공명 구조는 형식전하 절댓값이 작고, 음전하가 전기음성도 큰 원자에 놓인다.
문제 30난용성염정답 ④

사고과정

④ NaHC2O4는 HC2O4⁻ → 일부 C2O4²⁻(공통 이온) → 용해도 감소(증가 아님). 틀림. → ④

①(산이 옥살산이온 제거→용해↑)·②(옥살산이온은 염기)·③(HC2O4⁻ 양쪽성)은 옳음.

공통 이온(C2O4²⁻)을 더하면 르샤틀리에로 용해도가 줄어든다. 반대로 산은 음이온을 소모해 용해를 촉진한다.
