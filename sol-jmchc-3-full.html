문제 1돌턴의원자론정답 ④

사고과정

나 원자는 핵반응으로 쪼개지고 양성자·중성자·전자로 구성 — 폐기됨.

다 같은 원소도 동위원소가 존재해 질량이 다름 — 폐기됨.

가·라·마는 현대에도 유효(물질=원자, 원소마다 다른 원자, 정수비 결합=배수비례). → ④

돌턴 이론에서 무너진 두 기둥이 "불가분성(나)"과 "동일성(다)". 20세기 핵물리·동위원소 발견의 결과다.
문제 2러더퍼드정답 ②

사고과정

대부분 통과 = 원자 내부가 대부분 빈 공간. 소수가 큰 각도로 튕김 = 작고 무겁고 양전하인 핵의 존재.

이 실험이 직접 제안한 것은 "질량·양전하가 핵에 집중". → ②

③ 중성자는 채드윅이 후에 발견, ④ 모즐리의 연구로 이 실험에서 나온 것이 아니다.

큰 각도 산란 = 가까이 가야 강하게 밀림 = 전하·질량이 한 점에 모여 있다는 증거. 핵 모형의 출발점.
문제 3빛정답 ③

사고과정

에너지 큰 쪽부터: A(X선) = 분자의 이온화(전자 떼어냄), B(자외선·가시광) = 전자의 들뜸, 적외선 = 진동운동(주어짐).

에너지 작은 쪽: C(마이크로파) = 회전운동, D(라디오파) = 원자핵스핀 들뜸(NMR). → ③

에너지 순서로 외우면 쉽다: 핵스핀(라디오) < 회전(마이크로파) < 진동(적외선) < 전자 들뜸(가시·자외선) < 이온화(X선).
문제 4진동수정답 ②

사고과정

가시광선 진동수 순서: 빨강 < 노랑 < 초록 < 파랑 < 보라. 빨강이 가시광 중 진동수가 가장 낮다.

빨강보다 더 낮은 진동수(긴 파장)는 적외선. (노란빛·자외선·X선은 모두 더 높음) → ②

"빨강 바깥(적외선) = 진동수 더 낮음, 보라 바깥(자외선) = 진동수 더 높음". 빨강은 가시광의 저진동수 끝이다.
문제 5결합에너지정답 ③

사고과정

① 분자 1개당 에너지 = 941000/(6.0×1023) = 1.56×10−18 J.

② λ = hc/E = (6.63×10−34 × 3×108)/(1.56×10−18) ≈ 1.27×10−7 m = 127 nm → 자외선 영역. → ③

"최대 파장" = 결합을 겨우 끊는 최소 에너지에 대응. 결합에너지가 클수록 파장이 짧아(고에너지 자외선) 진다.
문제 6수소정답 ③

사고과정

① n=3→n=1(바닥 근처 큰 낙차)이 n=5→n=3보다 에너지가 크다. 거짓. ② 바닥상태는 가장 안정(최저 에너지). 거짓. ④ 높은 준위로 가는 것은 흡수. 거짓.

③ n=3→n=2(작은 에너지=발머)는 n=4→n=1(큰 에너지=라이먼)보다 파장이 길다(에너지∝1/λ). 참. → ③

에너지와 파장은 반비례. 준위 차가 작으면 에너지가 작고 파장이 길다. 바닥 근처 전이일수록 에너지가 크다.
문제 7파장정답 ③

사고과정

① 방출은 낮은 준위로 내려갈 때. ①·④는 위로 올라가는 흡수라 제외.

② n=2→n=1(큰 에너지=짧은 파장), ③ n=4→n=3(인접 고준위, 가장 작은 에너지=가장 긴 파장). → ③

긴 파장 = 작은 에너지 = 준위 간격이 가장 좁은 전이. 고준위에서 인접 준위로 내려갈 때가 간격이 가장 좁다.
문제 8가시광선영역정답 ②

사고과정

가시광선 영역(410~656 nm)은 발머 계열(n → 2 = L)이다. 656(3→2), 486(4→2), 434(5→2), 410(6→2).

434 nm = n=5 → n=2 = O → L. → ②

L(n=2)로 떨어지면 가시광선(발머), K(n=1)로 떨어지면 자외선(라이먼, 122 nm 등). 434는 발머의 세 번째 선이다.
문제 9파장정답 ③

사고과정

① 이온화 = n=1 → n=∞, 에너지 = 0 − (−RH/1²) = 2.2×10−18 J.

② 최대 파장 = 최소 에너지(=이온화 에너지). λ = hc/E = (6.63×10−34×3×108)/(2.2×10−18) ≈ 90 nm. → ③

바닥상태 이온화 에너지가 곧 "겨우 떼어낼" 최소 에너지 = 최대 파장에 대응. 90 nm은 자외선 영역.
문제 10전자의파동성정답 ①

사고과정

회절(diffraction)·간섭은 파동의 고유 현상이다. 전자가 결정 격자에서 회절무늬를 만드는 것(데이비슨-거머 실험)이 전자의 파동성의 직접 증거. → ①

②·③은 전자의 입자성(전하·이동), ④ 광전효과는 오히려 빛의 입자성(광자)을 보인다.

파동성 = 회절·간섭. 입자성 = 충돌·광전효과. ④를 고르지 않도록 "무엇의 무슨 성질인가"를 구분하라.
문제 11물질파정답 ①

사고과정

㉠ 속도↑ → λ = h/(mv) ↓ → 더 짧은 파장은 더 작은 것을 분해 → 해상도↑. O.

㉡ 야구공 λ = h/(mv) ≈ 10−34 m, X선 ≈ 10−10 m → 야구공이 훨씬 짧다. O. → ①

전자현미경이 광학현미경보다 잘 보이는 이유 = 전자 물질파가 가시광보다 짧기 때문. 거시 물체의 물질파는 극도로 짧아 관측 불가.
문제 12전자스핀정답 ③

사고과정

자기장에서 원자살이 정확히 둘로 갈라짐 = 전자의 자기적 성질(스핀)이 두 가지 값만 가짐을 의미.

슈테른-게를라흐 실험은 전자 스핀의 두 상태(↑, ↓)를 보였다. → ③

"둘로 갈라짐"이 핵심 단서. 연속적으로 퍼지지 않고 딱 두 줄 = 양자화된 스핀 두 값.
문제 13일전자계의에너지준위정답 ②

사고과정

He+는 전자가 1개인 수소꼴 이온. 전자 간 반발이 없어 에너지가 주양자수 n에만 의존한다(E ∝ −Z²/n²).

따라서 같은 n은 모두 같은 에너지(축퇴): 1s < 2s=2p < 3s=3p=3d < 4s=4p=4d=4f < 5s. → ②

다전자 원자(4s<3d 등)와 달리 수소꼴은 l 의존성이 없다. "전자 1개 → n만 중요"가 결정적 차이.
문제 14양자수정답 ③

사고과정

① n=3이면 l = 0, 1, 2(3s, 3p, 3d).

② 각 부껍질에서 자기양자수 m=0인 궤도는 1개씩 → 3s(m=0), 3p(m=0), 3d(m=0) = 궤도 3개.

③ 스핀까지 +1/2로 고정하면 각 궤도에 1개씩 → 3개. → ③

m=0은 각 l마다 정확히 하나의 궤도. n=3엔 l이 3종(0·1·2)이라 m=0 궤도도 3개다.
문제 15전자배치정답 ④

사고과정

① 2s는 최대 2개(2s3 불가). ② n=2엔 d 궤도 없음. ③ n=3엔 f 궤도 없음.

④ 4p는 최대 6개라 4p5는 가능. → ④

규칙 둘: (1) n번째 껍질엔 l ≤ n−1까지만 존재(2d·3f 불가), (2) 각 부껍질 최대 전자 수 s2·p6·d10·f14.
문제 16양자수정답 ②

사고과정

① Fe2+ = [Ar]3d6, Fe3+ = [Ar]3d5. 빠져나가는 전자는 3d 전자.

② 3d → n=3, l=2(d). n + l = 3 + 2 = 5. → ②

전이금속은 이온화 시 4s가 먼저 빠지고(Fe2+=3d6), 그 다음 3d가 빠진다(Fe3+=3d5). l 값은 s=0, p=1, d=2, f=3.
문제 17전자배치정답 ③

사고과정

O: 2s²2p⁴ → □ = 2(주양자수). Mg: 3s2 → □ = 2(전자 수).

P: 3p3 → □ = 3(전자 수). Mn: 3d⁵ → □ = 3(주양자수).

합 = 2 + 2 + 3 + 3 = 10. → ③

□가 어디에 있는지(주양자수 자리냐 전자 수 자리냐)를 구분해서 채운다. Mn의 d는 4s 다음이지만 주양자수는 3(3d).
문제 18이온정답 ②

사고과정

A는 바닥상태, B는 3s 전자 하나가 3p로 올라간 들뜬상태(전자 수 12개로 동일).

② 낮은 에너지(A) → 높은 에너지(B)는 에너지 흡수. 참. → ②

①·③ 전자 수가 같으니 이온도 아니고 전하도 같다. ④ 동위원소는 중성자 차이지 전자배치 차이가 아니다.

전자 수가 같으면 같은 중성 원자. A·B는 들뜸/바닥의 차이일 뿐 — 흡수로 올라가고 방출로 내려온다.
문제 19환원제정답 ④

사고과정

기체 상태 이온화 에너지는 Li가 알칼리 금속 중 가장 크다(①은 맞지만 강한 환원제의 이유는 아님). 그런데 수용액에서는 가장 강한 환원제(가장 음의 환원 전위 −3.04 V)다.

이유: Li+은 작아 전하 밀도가 높고 → 수화 에너지가 매우 커서 산화(이온화) 전체 과정이 유리해진다. → ④

③ Li의 표준 환원 전위는 가장 큰 음의 값이다("양의 값"은 거짓).

겉보기 역설: 이온화에너지가 큰 Li가 왜 가장 센 환원제? 답은 수용액에서의 강한 수화가 보상하기 때문. 기체상과 수용액상을 구분하라.
문제 20끓는점정답 ③

사고과정

끓는점이 가장 높은 X는 공유결합 그물 구조(거대 분자) 고체여야 한다 — 끓이려면 강한 공유결합을 끊어야 하기 때문.

3주기에서 그물 구조 + 매우 높은 끓는점(약 3265°C)인 원소는 Si. 이후 P·S(분자성)에서 낮아지고, 비활성 기체(Ar)에서 최저, 다음 주기 금속(K)에서 다시 상승. → ③

끓는점 = 입자 간 인력의 세기. 그물형 공유결합(Si·C) ≫ 금속 ≫ 분자성 ≫ 비활성기체. 가장 높은 봉우리가 그물 구조 원소다.
문제 21이온반지름정답 ④

사고과정

이온 반지름(pm): Li+ ≈ 76, Na+ ≈ 102, Be2+ ≈ 45, Mg2+ ≈ 72.

Li+(76)과 Mg2+(72)이 가장 가깝다(대각선 관계). → ④

주기율표 대각선(Li-Mg, Be-Al 등) 원소는 전하/크기 비가 비슷해 성질이 닮는다. 같은 족(①②)이나 같은 주기(③)보다 대각선이 더 가까울 수 있다.
문제 22이온반지름정답 ④

사고과정

Be2+은 전자가 2개(1s²)뿐이고 +2 전하가 핵으로 강하게 끌어당겨 가장 작다(≈45 pm). → ④

이온 반경은 (전자 수 적을수록)·(유효핵전하 클수록) 작아진다. Be2+은 둘 다 충족(전자 2개, +2).

문제 56평면삼각형정답 ③

사고과정

PCl3·NH3은 고립쌍 1개 → 삼각뿔. ClF3은 고립쌍 2개 → T자형.

SO3은 결합 3개 + 고립쌍 0 → 평면 삼각형(120°). → ③

평면 삼각형 = 결합 3 + 고립쌍 0(SO3, BF3, CO32−). 고립쌍이 하나라도 있으면 평면이 깨진다.
문제 57동일구조정답 ③

사고과정

구조: SO32−(고립쌍 1, 삼각뿔), BF3·CO32−(평면삼각형), ClF3(T자형), NH3(삼각뿔).

NH3와 SO32−이 모두 삼각뿔로 같다. → ③

SO3(평면)와 SO32−(삼각뿔)를 혼동하지 말 것 — 전자 2개가 더해져 고립쌍이 생기면 모양이 바뀐다.
문제 58분자의모양정답 ①

사고과정

구조: BrF3(T자형), ClO4−(정사면체), ICl4−(평면사각형), SF4(시소형), I3−(직선), IF4+(시소형).

시소형이 2개(SF4, IF4+)로 가장 많다. → ①

시소형 = 결합 4 + 고립쌍 1. SF4와 IF4+(I가 +1로 전자 6개) 둘 다 이 조건을 만족.
문제 59아스피린정답 ③

사고과정

sp² 탄소: 벤젠 고리 6개(방향족) + COOH의 카르보닐 C 1개 + 에스터(−OCOCH3)의 카르보닐 C 1개 = 8개.

−OCOCH3의 CH3 탄소만 sp³(유일). → ③

혼성 판별: 이중결합 참여 탄소(C=O, 방향족) = sp², 단일결합만(CH3) = sp³. 카르보닐 C 두 개를 빠뜨리기 쉽다.
문제 60혼성오비탈정답 ③

사고과정

① 시그마 13개(모든 단일결합 + 다중결합의 σ), 파이 3개(삼중결합 2 + 이중결합 1). 참. ② C4는 결합 영역 3개(=N, –C, –H) → sp²(120°). 참.

③ 에터 산소는 결합 2 + 고립쌍 2 = 전자쌍 4 → sp³ 혼성(굽은형). "sp"는 거짓. → ③

④ C1–C2(단일) > C2≡C3(삼중) 길이. 참.

에터·물의 산소는 고립쌍 2개를 포함해 sp³. sp 산소는 거의 없다(고립쌍 영역까지 세는 게 함정).
