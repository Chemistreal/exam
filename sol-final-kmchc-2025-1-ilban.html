문제 2원자의구조정답 ③

사고과정

① 양성자 수 = 원자번호(옳음).

② 동위원소는 중성자만 다르다(옳음).

③ 중성자 수는 원소마다 다르고 질량수에서 양성자를 뺀 값일 뿐, 질량에 비례하는 것이 아니다 → 틀림.

④ 원자는 핵과 전자로 이루어진다(옳음).

→ ③

문제 3아보가드로수정답 ②

사고과정

① H₂O 1몰 → 분자 6.02×10²³.

② CO₂ 44 g = 1몰 → 산소 원자 2몰.

③ CH₄ 1몰 → 탄소 1몰.

④ O₂ 16 g = 0.5몰 → 산소 원자 1몰.

가장 큰 것은 ② 다.

→ ②

문제 4이온결합정답 ①

사고과정

[Ne]3s² 는 마그네슘이라 2가 양이온이 된다.

산소는 2가 음이온이므로 1:1 로 만나 XO 가 된다.

→ ①

문제 5화학결합정답 ②

사고과정

PbF₂ 와 NaCl 은 둘 다 금속과 비금속이 만난 이온 결합이다.

나머지 짝에는 공유 결합 물질(N₂O·SF₄·P₄O₆)이 섞여 있다.

→ ②

문제 6용해도곱정답 ④

사고과정

침전이 시작되는 것은 이온곱이 Ksp 를 막 넘을 때다.

[Br⁻] = Ksp/[Ag⁺] = 5.0×10⁻¹³/1.0×10⁻⁷ = 5.0×10⁻⁶ M.

→ ④

문제 7계수맞추기정답 ④

사고과정

2C₈H₁₈ + 25O₂ → 16CO₂ + 18H₂O 로 맞춰진다.

O₂ 의 계수는 25 다.

→ ④

문제 8산화제환원제정답 ④

사고과정

(가)에서 Na 은 0 → +1 로 산화되고, (나)에서 Cl₂ 는 0 → +3 으로 산화되며, (다)에서 Br⁻ 는 −1 → 0 으로 산화된다.

셋 다 전자를 내주므로 환원제다.

→ ④

문제 9전해질정답 ②

사고과정

NaCl 은 완전히 나뉘는 강전해질, HClO₄ 는 강산이라 강전해질, HCOOH 는 약산이라 약전해질, CH₃OH 는 이온화하지 않는 비전해질이다.

→ ②

문제 11생성엔탈피정답 ③

사고과정

가 흑연 → 다이아몬드는 ΔH = +1.90 kJ 로 흡열이다 → 거짓.

나 그 반대 방향은 ΔH = −1.90, ΔS = 5.74 − 2.38 = +3.36 이라 ΔG < 0 으로 자발적이다(참).

다 다이아몬드의 연소는 발열이다(참).

→ ③

문제 12용해과정정답 ②

사고과정

녹으면서 차가워지므로 흡열이다(가 참).

고체가 이온으로 흩어지므로 무질서도는 는다(나 참).

다만 ΔH>0·ΔS>0 이면 온도가 충분히 높아야 자발적이라 '온도와 관계없이'는 거짓이다.

→ ②

문제 14활성화에너지정답 ④

사고과정

① 온도를 낮추면 정·역 모두 느려진다.

② 발열이면 역반응의 활성화 에너지가 ΔH 만큼 더 크다.

③ 온도가 바뀌면 K 도 바뀐다.

④ 정촉매는 새 경로를 열어 정반응과 역반응의 활성화 에너지를 함께 낮춘다 → 옳음.

→ ④

문제 15온도와반응속도정답 ①

사고과정

온도가 높을수록 분포가 넓고 낮게 퍼지며 오른쪽으로 옮겨간다(가 참).

활성화 에너지를 넘는 분자가 늘어 반응이 빨라진다(나 참).

속도상수는 온도에 따라 커지고(다 거짓), 활성화 에너지는 온도와 무관하다(라 거짓).

→ ①

문제 16촉매정답 ②

사고과정

나 온도가 너무 높으면 단백질이 변성되어 오히려 느려진다(거짓).

다 아밀레이스는 엿당이 아니라 녹말에 작용한다(거짓).

라 효소마다 알맞은 pH 가 있다(참).

→ ②

문제 18표준환원전위정답 ③

나 환원 전위가 큰 Pb²⁺ 가 더 환원되기 쉽다(참).

→ ③

문제 19화학결합정답 ④

사고과정

(가)는 녹는점·끓는점이 매우 낮은 이원자 분자라 Cl₂, (나)는 고체에서 전기가 통하는 금속이라 Na, (다)는 승화하는 이원자 분자라 I₂ 다.

ㄱ X 는 Cl 이므로 거짓, ㄴ 나트륨은 자유 전자를 갖는다(참), ㄷ 액체에서 전기가 통하는 것은 Na 하나다(참).

→ ④

문제 22평형농도정답 ③

사고과정

N₂O 44.0 g = 1.0 mol 이다.

2N₂O ⇌ 2N₂ + O₂ 에서 2x 가 반응하면 전체 몰수는 x 만큼 는다.

(b)가 1.1 이므로 x=0.1, (c)가 1.2 이므로 x=0.2 다.

(c)에서 N₂O 0.6·N₂ 0.4·O₂ 0.2 이므로 K = (0.4)²(0.2)/(0.6)² ≈ 0.089.

→ ③

문제 25순차이온화에너지정답 ①

사고과정

도약이 일어나는 자리로 족을 읽는다.

X 는 1→2 에서 뛰므로 1족(Na), Y 는 3→4 에서 뛰므로 13족(Al), Z 는 2→3 에서 뛰므로 2족(Mg)이다.

ㄱ Na 는 금속이라 전성·연성이 크다(참).

ㄴ 전기음성도는 Na < Mg(참).

ㄷ 같은 주기에서 Mg > Al 이므로 Y 가 더 크다는 것은 거짓.

→ ①

→ ①

문제 29결합차수정답 ③

다 두 반응 모두 H₂O 와 CO₂ 를 낸다(참).

→ ②

문제 47산화제환원제정답 ③

사고과정

가 H₂O + Cl₂ → HClO + HCl 에서 산화수가 바뀌는 것은 염소뿐이라 물은 산화제도 환원제도 아니다 → 거짓.

나 3NO₂ + H₂O → 2HNO₃ + NO 에서 NO₂ 는 +5 로도 +2 로도 가므로 스스로 산화·환원한다(참).

다 N₂ 가 N₂H₄ 로 갈 때 질소는 환원되므로 산화제다(참).

→ ③

문제 48금속결정정답 ④

사고과정

면심입방은 세포당 원자 4개이고 면대각선이 4r 이므로 한 변 a = 2√2 r, 부피는 16√2 r³ 다.

밀도 = 4A/(N_A × 16√2 r³) = A/(4√2 N_A r³).

→ ④
