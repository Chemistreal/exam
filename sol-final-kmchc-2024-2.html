문제 1유효숫자정답 ②

사고과정

가 3 pm = 3×10−10 cm 로 2×10−9 cm 보다 짧다(거짓).

나 15.3 + 113.22 − 121.34 = 7.18 인데 덧뺄셈은 **소수점 자리**로 맞추므로 소수 첫째 자리까지인 7.2, 곧 유효숫자 2개다(참).

다 밀도와 온도는 양이 늘어도 변하지 않는 세기 성질이다(참).

라 물은 두 원소로 이루어진 화합물이지 원소가 아니다(거짓).

→ ②

문제 2아보가드로수정답 ①

사고과정

30.0 g 안의 수소 몰수를 센다.

NH3 30/17×3 ≈ 5.3, H2O 30/18×2 ≈ 3.3, CH3NH2 30/31×5 ≈ 4.8, CH3OH 30/32×4 ≈ 3.8 이다.

→ ①

문제 3양자수정답 ③

사고과정

수소 원자는 전자가 하나라 에너지가 주양자수 n 에만 좌우된다.

n=1 인 (가)가 가장 낮고, n=2 인 (나)와 (다)는 서로 같다.

→ ③

문제 4화합물명명정답 ③

사고과정

리튬은 산화수가 +1 하나뿐이라 로마 숫자를 붙이지 않는다.

Li2O 는 그냥 '산화 리튬'이다.

→ ③

문제 5이온화에너지정답 ④

사고과정

같은 주기에서는 오른쪽으로 갈수록 크되 15족 > 16족 예외가 있으므로 2주기는 F > N > O > Li

다. 나트륨은 3주기라 가장 작다.

→ ④

문제 6수소스펙트럼정답 ③

사고과정

He+ 는 Z=2 이므로 1/λ = Z2R(1/12 − 1/32) = 4R × 8/9 = 32R/9

다. E = hc/λ = (32/9)hcR∞.

→ ③

문제 7전자배치정답 ④

사고과정

Cr 은 24 번이라 [Ar] 뒤에 전자 여섯이 남는다.

쌓음 원리대로면 4s23d4 지만, 실제 바닥 상태는 3d 를 반만 채우는 쪽이 안정해 [Ar]4s13d5

다. 4s 에 홀전자 하나, 3d 다섯 칸에 홀전자 하나씩 들어간 그림을 고른다.

→ ④

문제 8엔트로피정답 ④

사고과정

① 냉각은 ΔH<0·ΔS<0, ② 증발은 ΔH>0·ΔS>0, ③ 해리는 ΔH>0·ΔS>0 로 부호가 같다.

④ 연소는 발열(ΔH<0)인데 기체가 늘어 ΔS>0 이라 부호가 다르다.

→ ④

문제 9전자배치정답 ④

사고과정

홀전자 수는 부껍질을 훈트 규칙대로 채워 센다.

4주기 전이금속을 차례로 보면 Sc 1, Ti 2, V 3, Cr 6, Mn 5, Fe 4, Co 3, Ni 2, Cu 1, Zn 0 이다.

넷인 것은 Fe 뿐이라 (vi) 다.

→ ④

문제 10발열흡열반응정답 ③

사고과정

가 물이 어는 것은 발열, 나 결합을 끊는 것은 흡열, 다 수소의 연소는 발열이다.

발열은 두 개다.

→ ③

문제 11평형농도정답 ②

사고과정

O2 가 1.0 → 0.60 으로 0.40 줄었으므로 NO 는 0.80 줄어 0.20 이 되고 NO2 는 0.80 생긴다.

Kp = (0.80)2/((0.20)2×0.60) = 0.64/0.024 ≈ 27.

→ ②

곧 sp3d 다.

문제 13격자에너지정답 ④

사고과정

전하 곱이 4 인 ZnS·SrSe 가 앞서고, 그 안에서 이온이 작은 ZnS 가 크다.

전하 곱 1 인 둘 중에는 작은 LiCl 이 KBr 보다 크다.

문제 16분자오비탈정답 ④

사고과정

가 O2 는 홀전자 2개로 상자성이지만 O22− 는 π* 가 다 차 반자성이다(거짓).

나 F2− 는 홀전자 1개로 상자성, F2+ 도 홀전자 1개로 상자성이다(거짓).

다 C2− 는 결합성 오비탈에 전자가 하나 더 들어가 차수가 2.5 로 C2(2)보다 크다(참).

라 O2+ 는 차수 2.5 로 O2(2)보다 짧으므로 O2 가 더 길다(참).

→ ④

문제 17형식전하정답 ②

사고과정

세 공명 구조의 형식 전하를 센다.

(a) 는 N −1, N +1, O 0 이고, (b) 는 N 0, N +1, O −1, (c) 는 N −2, N +1, O +1 이다.

형식 전하가 작을수록, 음전하가 전기음성도 큰 원자에 있을수록 중요하다.

(b) 는 음전하가 O 에 있어 가장 좋고, (c) 는 −2 와 +1 이 함께 있어 가장 나쁘다.

→ ②

문제 18공명정답 ①

사고과정

가는 옳다 — 아세트산이 약산이므로 그 짝염기인 아세트산 이온은 약한 염기이고, 강염기인 OH− 보다 약하다.

나는 틀리다 — A 의 2 번 산소는 고립쌍 셋과 결합 하나로 전자가 여덟이라 옥텟을 만족한다.

다도 틀리다 — 공명이라 두 C–O 결합은 길이가 같다.

문제 30연소엔탈피정답 ②

사고과정

2C2H6 + 7O2 → 4CO2 + 6H2O 로 맞춘다.

끊는 쪽은 2×(C−C 350 + C−H 6×410) + 7×500 = 5620 + 3500 = 9120 kJ, 만드는 쪽은 4×(C=O 2×800) + 6×(O−H 2×460) = 6400 + 5520 = 11920 kJ

다. ΔH = 9120 − 11920 = −2800 kJ.

→ ②
