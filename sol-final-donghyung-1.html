문제 1정확도정밀도정답 ①

사고과정

Na2CO3 0.106 g = 0.001 mol.

Na2CO3 + 2HCl → 2NaCl + H2O + CO2 이므로 HCl 0.002 mol, 곧 0.1 M 로 20.0 mL 가 참값이다.

A는 20.0·21.1·19.5 로 흩어졌지만 평균이 20 근처 → 타당도(정확도) 우수, 신뢰도(정밀도) 낮음.

B는 10.0·10.0·10.1 로 잘 모였지만 참값에서 멀다 → 신뢰도 우수, 타당도 낮음.

→ ①

문제 2화학반응식정답 ②

사고과정

ㄱ 계수비대로 넣지 않아도 반응은 일어난다(한쪽이 남을 뿐) → 거짓.

ㄴ 계수비와 넣은 양을 견주면 한계반응물을 찾을 수 있다 → 참.

ㄷ 계수비는 몰비이지 질량비가 아니다 → 거짓.

ㄹ 한계반응물로 이론적 수득량을 구할 수 있다 → 참.

→ ②

④ LiAlH4 의 H 는 −1 (옳음).

→ ③

문제 4계수맞추기정답 ④

사고과정

Br- → Br2 는 산화(2Br- → Br2 + 2e-), MnO4- → Mn2+ 는 환원이다.

염기성이므로 산성에서 맞춘 뒤 양쪽에 OH- 를 더해 H+ 를 없앤다.

MnO4- + 4H2O + 5e- → Mn2+ + 8OH-.

전자를 10개로 맞추면 10Br- + 2MnO4- + 8H2O → 5Br2 + 2Mn2+ + 16OH-.

→ ④

② 같은 피스톤(같은 외압)에 각각 들어 있으므로 압력은 둘 다 1기압으로 같다 → 옳음.

③ 분자 수는 8:1 로 다르다.

→ ②

문제 10쌍극자모멘트정답 ②

사고과정

크기는 μ = q × d 로 곧장 나온다 — q = μ/d = (3.0 × 3.3×10-30)/(150×10-12) = 6.6×10-20 C

다. 남는 것은 부호인데, SiO 는 CO 와 같은 자리다.

원자가 전자가 열 개인 삼중결합 분자라 덜 전기음성한 쪽(C·Si)에 고립쌍이 앉고, 그 고립쌍이 만드는 쏠림이 결합 쌍극자를 거꾸로 눌러 **음의 끝이 Si 쪽**으로 간다.

Si 가 −6.6×10-20 C, O 가 +6.6×10-20 C 다.

→ ②

문제 18PV=nRT정답 ③

사고과정

전체 1기압 = 760 torr, 뷰테인의 부분압이 190 torr 이므로 프로페인은 570 torr = 0.75 atm.

n = PV/RT = (0.75 × 25)/(0.082 × 298) ≈ 0.767 mol.

프로페인(C3H8, 44 g/mol) 질량 ≈ 34 g.

→ ③

문제 19평균자유행로정답 ③

사고과정

충돌 빈도는 Z ∝ n·v̄ 이고, 압력이 일정한 채 T를 4배로 하면 부피가 4배가 되어 수밀도 n은 1/4, 평균 속력 v̄ 는 √4 = 2배다.

따라서 Z 는 (1/4)×2 = 1/2 배.

평균자유행로는 λ ∝ 1/n 이므로 4배가 된다.

→ ③

→ ②

문제 23분자오비탈정답 ③

문제 24루이스구조식정답 ①

문제 30반트호프인자정답 ②

문제 32반응의자발성정답 ②

사고과정

섞여 있던 물과 사염화탄소가 층으로 갈리는 것은 무질서도가 줄어드는 변화라 ΔS < 0 이다.

그런데 실제로 자발적으로 일어나므로 ΔH < 0 이어야 한다.

ΔG = ΔH − TΔS 에서 두 항이 모두 음수 쪽에 유리하려면 T가 작아야 하므로 낮은 온도에서 자발적이다.

→ ②

물은 위로 올라가는 쪽(양의 h)이라 더 올라가고, 수은은 내려가는 쪽(음의 h)이라 더 내려간다.

→ ④

문제 34분자간인력정답 ④
