문제 1정확도정밀도정답 ①

사고과정

Na2CO3 0.106 g = 0.001 mol.

Na2CO3 + 2HCl → 2NaCl + H2O + CO2 이므로 HCl 0.002 mol, 곧 0.1 M 로 20.0 mL 가 참값이다.

A는 20.0·21.1·19.5 로 흩어졌지만 평균이 20 근처 → 타당도(정확도) 우수, 신뢰도(정밀도) 낮음.

B는 10.0·10.0·10.1 로 잘 모였지만 참값에서 멀다 → 신뢰도 우수, 타당도 낮음.

→ ①

문제 8발열반응정답 ①

주어진 것 세 가지 반응식이 제시되었고, 이 가운데 흡열 반응(ΔH > 0)을 모두 고르는 문제다.

쓰는 법칙 ΔH = (끊어지는 결합 에너지의 합) − (새로 생기는 결합 에너지의 합)이다.

끊는 데 드는 에너지가 더 크면 흡열, 생기는 결합이 더 세면 발열이다.

모든 반응은 결합을 끊는 과정을 포함하므로, 끊는다는 사실만으로는 흡열인지 알 수 없다.

ㄱ N2(g) + O2(g) → 2NO(g) 끊는 쪽은 N≡N 946 kJ/mol과 O=O 498 kJ/mol로 합이 1444 kJ이다.

생기는 쪽은 N=O 결합 2 mol로 약 631 × 2 = 1262 kJ이다.

ΔH = 1444 − 1262 = +182 kJ 로 흡열이다.

실측값도 +180 kJ이며, 그래서 NO는 번개나 엔진 안 같은 고온에서만 만들어진다.

ㄴ N2(g) + 3H2(g) → 2NH3(g) 끊는 쪽은 946 + 3 × 436 = 2254 kJ, 생기는 쪽은 N−H 6 mol로 6 × 391 = 2346 kJ이다.

ΔH = 2254 − 2346 = −92 kJ 로 발열이다.

ㄷ 2H2(g) + O2(g) → 2H2O(g) 끊는 쪽은 2 × 436 + 498 = 1370 kJ, 생기는 쪽은 O−H 4 mol로 4 × 463 = 1852 kJ이다.

ΔH = 1370 − 1852 = −482 kJ 로 크게 발열이다.

결론 흡열인 것은 ㄱ 하나뿐이므로 답은 ①이다.

문제 9에너지준위정답 ①

주어진 것 수소 원자의 에너지 준위는 Eₙ = −R_H/n2 이고 R_H = 2.2×10−18 J, n 은 자연수다.

그리고 Li2+ 의 이온화에너지는 H 의 이온화에너지의 9배다.

문제가 준 것은 이 세 가지뿐이다.

1단계 H의 이온화에너지를 구한다.

전자를 완전히 떼어내는 것은 n = 1 에서 n = ∞ 로 보내는 것이므로 E = E_∞ − E1 = 0 − (−R_H/12) = 2.2×10−18 J이다.

2단계 Li2+ 는 그 9배이므로 E = 9 × 2.2×10−18 = 1.98×10−17 J이다.

전자가 하나뿐인 이온의 이온화에너지는 핵전하 Z의 제곱에 비례하고, Li는 Z = 3 이므로 32 = 9 배가 된다.

3단계 '최대 파장'의 뜻을 정한다.

E = hc/λ 이므로 파장이 길수록 광자 한 개의 에너지는 작다.

전자를 떼어내려면 광자 에너지가 이온화에너지 이상이어야 하므로, 딱 이온화에너지와 같을 때가 쓸 수 있는 가장 긴 파장이다.

4단계 계산한다.

문제에 플랑크 상수와 빛의 속력은 주어져 있지 않으므로, 표준값 h = 6.63×10−34 J·s 와 c = 3.00×108 m/s 를 밖에서 가져다 쓴다.

hc = 6.63×10−34 × 3.00×108 = 1.989×10−25 J·m 이고, λ = hc/E = 1.989×10−25 / 1.98×10−17 = 1.00×10−8 m 이다.

5단계 단위를 고친다.

1.00×10−8 m = 10.0 nm 이다.

결론 가장 가까운 값은 10 nm 이므로 답은 ①이다.

문제 10쌍극자모멘트정답 ②

사고과정

크기는 μ = q × d 로 곧장 나온다 — q = μ/d = (3.0 × 3.3×10−30)/(150×10−12) = 6.6×10−20 C

다. 남는 것은 부호인데, SiO 는 CO 와 같은 자리다.

원자가 전자가 열 개인 삼중결합 분자라 덜 전기음성한 쪽(C·Si)에 고립쌍이 앉고, 그 고립쌍이 만드는 쏠림이 결합 쌍극자를 거꾸로 눌러 **음의 끝이 Si 쪽**으로 간다.

Si 가 −6.6×10−20 C, O 가 +6.6×10−20 C 다.

→ ②

확인 필요 2026-09-05: 정답 키가 ②로 되어 있는데 **①이 맞아 보인다.** 크기는 어느 쪽이든 같다 — μ/d = (3.0 × 3.3×10⁻³⁰) ÷ (150×10⁻¹²) = 6.6×10⁻²⁰ C 라 ①·② 둘 다 이 값이다. 갈리는 것은 **부호**다. Si 의 전기음성도는 1.90, O 는 3.44 이므로 전자는 O 쪽으로 끌리고 Si 가 δ+, O 가 δ− 가 된다. 그것이 ①이다. ②(Si 가 δ−)가 성립하려면 CO 같은 예외여야 하는데 — CO 는 고립쌍 때문에 부호가 뒤집히고 μ 가 0.11 D 로 유난히 작다 — SiO 의 실측 쌍극자는 약 3.1 D 로 전기음성도 차를 그대로 따르는 크기이고(GeO 3.3 · SnO 4.3 · PbO 4.6 과 같은 계열), 이 문항의 지문도 3.0 D 를 준다. 즉 CO 유추가 여기까지 오지 않는다. ⚠ **키를 여기서 뒤집지 않았다.** 이 회차는 이미 114명이 봤고 성적이 나갔다 — 점수가 이미 나간 회차의 정답을 자가 혼자 바꾸지 않는다. 선생님이 정하실 자리다.

문제 13적외선흡수정답 ④

주어진 것 태양 복사는 단파, 지구 복사는 장파(적외선)라는 설명과 네 분자가 제시되었다.

지구 복사에너지를 흡수할 수 '없는' 것을 고르는 문제다.

쓰는 법칙 적외선 흡수는 분자의 진동 준위가 올라가는 과정이고, 광자가 흡수되려면 그 진동을 하는 동안 분자의 쌍극자 모멘트가 변해야 한다.

기준은 '영구 쌍극자가 있는가'가 아니라 '진동하면서 쌍극자가 변하는가'다.

① H2O 굽은 구조라 영구 쌍극자가 있고, 대칭 신축·비대칭 신축·굽힘 진동 모두에서 쌍극자가 변한다.

흡수한다.

② CH4 정사면체라 영구 쌍극자는 0이지만, 비대칭 신축이나 굽힘 진동을 하면 순간적으로 대칭이 깨져 쌍극자가 생겼다 사라진다.

흡수한다.

③ CO 서로 다른 두 원자가 결합해 쌍극자 모멘트가 0이 아니고, 결합 길이가 늘었다 줄었다 하면 그 크기가 변한다.

흡수한다.

④ N2 같은 원자 둘로 된 등핵 이원자 분자라 결합이 아무리 늘었다 줄었다 해도 전하 분포가 늘 대칭이어서 쌍극자 모멘트가 항상 0이다.

진동해도 쌍극자 변화가 없으므로 적외선을 흡수하지 못한다.

결론 흡수하지 못하는 것은 N2 이므로 답은 ④이다.

공기의 78 %를 차지하는 N2 와 21 %인 O2 가 온실기체가 아닌 이유가 바로 이것이다.

문제 15발열반응정답 ①

주어진 것 CH4, CH3OH, HCOOH, HCHO 네 화합물이며, 표준연소엔탈피 ΔH°_comb 의 절댓값이 가장 큰 것을 고르는 문제다.

쓰는 법칙 연소는 탄소를 CO2 로, 수소를 H2O 로 완전히 산화시키는 반응이다.

출발 물질이 이미 산화되어 있을수록 더 산화될 여지가 적어 내놓는 열이 작다.

그러므로 탄소의 산화수가 낮은(환원되어 있는) 분자일수록 연소열의 절댓값이 크다.

1단계 탄소의 산화수를 센다.

CH4 는 −4, CH3OH 는 −2, HCHO 는 0, HCOOH 는 +2

다. 모두 CO2(탄소 +4)까지 올라가야 하므로, 탄소 1 mol당 옮겨야 하는 전자 수는 각각 8, 6, 4, 2 개다.

2단계 옮기는 전자가 많을수록 방출 열이 크므로 순서는 CH4 > CH3OH > HCHO > HCOOH 로 예상된다.

3단계 실제 값으로 확인한다.

CH4 890 kJ/mol, CH3OH 726 kJ/mol, HCHO 571 kJ/mol, HCOOH 255 kJ/mol 로 예상한 순서와 같다.

결론 절댓값이 가장 큰 것은 CH4 이므로 답은 ①이다.

문제 16중화열정답 ④

주어진 것 x M 인 HA 수용액 20 mL 에 0.1 M KOH 수용액을 넣어 적정했더니 KOH 가 10 mL 소모되었다.

온도는 2 °C 올랐고, 모든 용액의 밀도는 1.0 g/cm3, 비열은 4 J/g·°C

다. 1단계 중화된 몰수를 구한다.

문제 17분자간인력정답 ①

문제 19평균자유행로정답 ③

주어진 것 1 atm, 25 °C 에서 25 L 용기에 든 이상기체의 충돌빈도가 Z, 평균자유행로가 λ

다. 압력을 일정하게 두고 온도를 4배로 올렸을 때의 값을 묻는다.

1단계 부피와 수밀도의 변화를 본다.

PV = nRT 에서 P 와 n 이 일정하고 T 가 4배이므로 V 도 4배가 되어 25 L → 100 L

다. 단위부피당 분자 수 N/V 는 1/4 로 줄어든다.

2단계 평균 속력의 변화를 본다.

v̄ = √(8RT/πM) 이므로 v̄ ∝ √T 이고, T 가 4배이면 √4 = 2배가 된다.

3단계 충돌빈도를 계산한다.

분자 하나가 1초에 겪는 충돌 횟수는 z = √2 σ v̄ (N/V) 이므로 v̄ 와 수밀도의 곱에 비례한다.

2 × (1/4) = 1/2 이므로 충돌빈도는 ½Z 가 된다.

4단계 평균자유행로를 계산한다.

λ = v̄/z = 1/(√2 σ (N/V)) 이므로 속력과는 무관하고 수밀도에만 반비례한다.

수밀도가 1/4 이 되었으므로 λ 는 4배, 곧 4λ

다. λ = kT/(√2 σ P) 로 써도 P 가 일정할 때 T 에 비례하므로 4배로 같은 결과다.

결론 충돌빈도는 ½Z, 평균자유행로는 4λ 이므로 답은 ③이다.

문제 51지시약의선택정답 ④

주어진 것 2.0 M HA 수용액(Ka = 1.0×10−3)을 같은 농도인 2.0 M NaOH 수용액으로 적정한다.

보기에는 지시약 네 개의 pKa 가 함께 적혀 있다.

1단계 — 당량점에서 용액에 무엇이 남는가.

산과 염기의 농도가 같으므로 당량점까지 넣는 NaOH 부피는 처음 HA 부피와 같다.

부피가 두 배가 되므로 생성된 A− 의 농도는 2.0 M ÷ 2 = 1.0 M 이고, HA 도 NaOH 도 남지 않는다.

당량점 용액은 사실상 1.0 M NaA 용액이다.

2단계 — A− 의 가수분해 상수.

A− + H2O ⇌ HA + OH− 의 평형상수는 Kb = Kw/Ka = (1.0×10−14)/(1.0×10−3) = 1.0×10−11 이다.

3단계 — 당량점 pH 계산.

[OH−] = √(Kb × [A−]) = √(1.0×10−11 × 1.0) = 3.16×10−6 M 이다.

pOH = −log(3.16×10−6) = 5.50 이므로 pH = 14.00 − 5.50 = 8.50 이다.

당량점은 중성이 아니라 염기성이다.

4단계 — 지시약 고르기.

지시약 HIn 은 pH 가 자기 pKa ± 1 인 구간에서 색이 변하므로, 변색 범위가 당량점 pH 8.50 을 품는 것을 골라야 한다.

① 메틸 오렌지 pKa 3.8 → 2.8~4.8, ③ 브로모페놀블루 pKa 4.1 → 3.1~5.1, ② 메틸 레드 pKa 5.0 → 4.0~6.0 은 모두 산성 쪽이어서 8.50 을 담지 못하고, 당량점보다 훨씬 앞에서 색이 변해 종말점을 일찍 알린다.

④ 페놀프탈레인 pKa 9.2 → 8.2~10.2 만이 8.50 을 품는다.

결론 페놀프탈레인이 가장 적절하다.

→ ④

문제 52화학전지정답 ③

주어진 것 전지식 Pt(s)|H2(g, 1.0 atm)|H+(aq, 1.0 M) ‖ H+(aq, x M)|H2(g, 1.0 atm)|Pt(s), 25 °C, 전지 전위 a

V. 구하는 것은 환원 전극(오른쪽) 전해질의 pH

다. 1단계 — 어느 쪽이 환원 전극인가.

전지식은 왼쪽이 산화 전극(anode), 오른쪽이 환원 전극(cathode)이다.

따라서 x M 쪽이 환원 전극이고, 문제가 묻는 pH 는 x 로 정해진다.

2단계 — 반쪽 반응과 알짜 반응.

산화(왼쪽): H2(g) → 2H+(1.0 M) + 2e− 환원(오른쪽): 2H+(x M) + 2e− → H2(g) 알짜: 2H+(x M) → 2H+(1.0 M), 이동 전자 수 n = 2.

양쪽 전극이 같은 종류이므로 E° = 0 이다.

3단계 — 네른스트 식.

E = E° − (0.0592/n) log Q 이고, 알짜 반응의 Q = [H+]생성물2/[H+]반응물2 = (1.0)2/x2 이다.

E = 0 − (0.0592/2) log(1/x2) = −(0.0592/2) × (−2 log x) = 0.0592 log

x. 계수 2 는 n = 2 와 정확히 상쇄되므로 결국 E = 0.0592 log(x/1.0) 한 줄로 정리된다.

4단계 — 대입과 pH.

E = a 이므로 0.0592 log x = a, 즉 log x = a/0.0592 이다.

pH = −log x = −a/0.0592

다. 확인 a > 0 이면 log x > 0 이라 x > 1.0 M 이고, 환원 전극이 더 진한 산성이라는 뜻이므로 pH 가 음수로 나오는 것이 앞뒤가 맞는다.

→ ③

s3 = Ksp/4 이므로 s = (Ksp/4)^(1/3) 이다.

문제 55반트호프식정답 ①

주어진 것 ln K 를 세로축, 1/T (K−1) 를 가로축으로 그린 직선 그래프.

이 온도 구간에서 ΔH° 와 ΔS° 는 일정하다.

답은 kJ/mol 단위로 고른다.

1단계 — 반트호프 식을 직선 꼴로 정리한다.

ΔG° = ΔH° − TΔS° 와 ΔG° = −RT ln K 를 합치면 ln K = −(ΔH°/R)(1/T) + ΔS°/R 이다.

곧 ln K 대 1/T 그래프는 직선이고 기울기는 −ΔH°/R 이다.

2단계 — 그래프에서 기울기를 읽는다.

직선은 세로축과 (1/T = 0, ln K = 8.0) 에서 만나고 (1/T = 0.10, ln K = 0) 에서 가로축과 만난다.

기울기 = (0 − 8.0)/(0.10 − 0) = −80 K

다. 3단계 — ΔH° 로 바꾼다.

−ΔH°/R = −80 이므로 ΔH° = 80 × R = 80 × 8.314 J/(mol·K) = 665 J/mol 이다.

4단계 — 단위를 맞춘다.

665 J/mol ÷ 1000 = 0.665 kJ/mol 이다.

보기 0.60, 8.0, 60, 80 가운데 가장 가까운 값은 0.60 이다.

덧붙임 기울기가 음수이므로 ΔH° 는 양수, 곧 흡열 반응이다.

온도가 올라가면 1/T 이 작아지고 그래프를 따라 ln K 가 커지는 것과 일치한다.

문제 57아미노산정답 ③

주어진 것 아미노산의 구조 R−CH(NH2)−COOH (R 는 알킬기 또는 H) 와, 중성 수용액에서는 한 분자 안에 양전하와 음전하를 함께 가진 쯔비터이온 R−CH(NH3+)−COO− 로 있다는 설명.

묻는 것은 염기성 수용액에서의 주된 형태다.

1단계 — 두 작용기의 산 세기를 견준다.

아미노산에는 산성기 −COOH 와 염기성기 −NH2 가 함께 있다.

−COOH 가 −NH3+ 보다 훨씬 센 산이어서, 중성 부근에서는 −COOH 가 이미 양성자를 내놓아 −COO− 가 되고 −NH2 는 그 양성자를 받아 −NH3+ 가 된 쯔비터이온으로 있다.

2단계 — 염기성으로 가면 무엇이 달라지는가.

pH 를 올린다는 것은 OH− 를 넣어 분자에서 양성자를 더 떼어낸다는 뜻이다.

쯔비터이온에서 아직 양성자를 가지고 있는 자리는 −NH3+ 뿐이므로, −NH3+ + OH− → −NH2 + H2O 로 진행한다.

−COO− 는 이미 양성자를 내놓았으므로 더 잃을 것이 없고, 염기성에서 다시 −COOH 로 돌아가지도 않는다.

3단계 — 남는 형태.

양전하는 사라지고 −COO− 의 음전하만 남으므로 주된 형태는 알짜 −1 가의 음이온 R−CH(NH2)−COO−

다. 보기 판정 ① R−CH(NH2)−COOH: −NH2 는 염기성에 맞지만 −COOH 가 양성자를 그대로 쥐고 있다.

가장 센 산 자리가 염기성 용액에서 양성자를 유지할 수는 없으므로 옳지 않다.

② R−CH(NH3+)−COO−: 중성 부근의 쯔비터이온으로, 염기성에서는 −NH3+ 가 양성자를 더 잃는다.

③ R−CH(NH2)−COO−: 양성자를 둘 다 내놓은 음이온으로 염기성에서의 주된 형태다.

④ R−CH(NH3+)−COOH: 두 자리 모두 양성자를 가진 알짜 +1 가 양이온으로, 강한 산성 용액에서의 형태다.
