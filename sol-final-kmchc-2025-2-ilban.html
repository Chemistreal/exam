문제 1동위원소정답 ③

사고과정

수소의 동위원소는 양성자가 모두 1개이고 중성자만 다르다.

③ C 의 양성자 수가 B 의 두 배라는 것은 틀렸다.

→ ③

문제 2전자배치정답 ②

사고과정

ㄱ 3주기는 3s·3p 까지만 채우므로 3d 에 전자가 든 원소는 없다 → 거짓.

ㄴ Na·Mg·Al 세 개가 금속이다(참).

ㄷ 상온에서 액체인 3주기 원소는 없다 → 거짓.

→ ②

문제 3결합각정답 ②

사고과정

결합각은 비공유 전자쌍이 적을수록 크다.

BF₃ 120° > CH₄ 109.5° > NH₃ 107° > H₂O 104.5° 다.

→ ②

문제 4분자의모양정답 ④

사고과정

HCN·CO₂·BeCl₂·C₂H₂ 는 모두 직선이고 H₂O 만 굽은형이다.

네 개다.

→ ④

문제 5약산정답 ④

사고과정

아세트산은 약산이라 일부만 이온화한다.

그래서 pH 는 7 보다 작지만 1 처럼 낮지도 않다.

→ ④

문제 6pH정답 ④

사고과정

강염기라 완전히 해리하므로 [OH⁻] = 0.01 M, pOH = 2, pH = 14 − 2 = 12 다.

→ ④

문제 7삼투압정답 ②

사고과정

삼투압은 입자 수에 비례한다.

FeCl₃ 0.025×4 = 0.1, 아세트산 0.05×약간 ≈ 0.05, MgSO₄ 0.05×2 = 0.1, 글루코스 0.10×1 = 0.1 이다.

가장 작은 것은 약산인 아세트산이다.

→ ②

문제 8깁스자유에너지정답 ③

사고과정

ΔH < 0 이고 기체가 생기므로 ΔS > 0 이다.

ΔG = ΔH − TΔS 에서 두 항이 모두 음수 쪽이라 온도와 상관없이 자발적이다.

→ ③

문제 9상변화정답 ③

사고과정

승화는 고체가 기체가 되는 것이라 결합을 끊어야 하므로 흡열이고, 무질서도는 는다.

→ ③

문제 10이상기체방정식정답 ③

사고과정

같은 부피에서 압력이 2배이면 절대온도도 2배다.

10 °C = 283 K 의 두 배는 566 K, 곧 293 °C 다.

→ ③

문제 11양적관계정답 ②

사고과정

CH₄ 를 x 몰이라 하면 C₂H₂ 는 (n−x) 몰이고 CO₂ = x + 2(n−x) = 2n − x = 1.5n 이다.

x = 0.5n 이므로 몰분율은 0.5.

→ ②

문제 14르샤틀리에정답 ④

사고과정

① 산소를 더하면 정반응 쪽으로 밀린다(옳음).

② 발열이라 온도를 올리면 역반응 쪽이다(옳음).

③ 기체 3 → 2 라 압력을 높이면 오른쪽이다(옳음).

④ SO₃ 를 없애면 그것을 채우려 오른쪽으로 이동한다 → '왼쪽'은 틀림.

→ ④

문제 15평형상수정답 ③

사고과정

평형 상수는 온도만의 함수이고 단위가 없으며 촉매의 영향을 받지 않는다.

다만 평형에 이르는 **시간**과는 아무 관련이 없다 → ③ 이 틀림.

→ ③

문제 16용해도곱정답 ①

사고과정

AgI 가 침전하려면 [Ag⁺] > Ksp(AgI)/[I⁻] = 8.3×10⁻¹⁷/10⁻⁶ = 8.3×10⁻¹¹ 이어야 하고, AgCl 이 침전하지 않으려면 [Ag⁺] < 1.8×10⁻¹⁰/10⁻⁶ = 1.8×10⁻⁴ 이어야 한다.

→ ①

문제 17전기분해정답 ②

사고과정

전원의 (+) 단자에 이은 백금이 산화 전극이라 물이 산화되어 O₂ 가 나오고, (−) 단자에 이은 구리가 환원 전극이라 Cu²⁺ 가 환원되어 구리가 석출된다.

→ ②

문제 18전하량정답 ①

사고과정

전하량 = 6 A × 1200 s = 7200 C, 전자 = 7200/96500 ≈ 0.0746 mol 이다.

Na⁺ + e⁻ → Na 이므로 Na 도 0.0746 mol, 질량은 0.0746 × 23 ≈ 1.7 g.

→ ①

문제 19단위세포정답 ②

체심입방은 꼭짓점 8 × 1/8 + 몸중심 1 = 2개이고, 배위수는 몸중심 원자가 꼭짓점 여덟과 맞닿아 8 이다.

합은 10.

→ ②

문제 32실험식정답 ③

사고과정

문제 36평형농도정답 ④

문제 42반응차수정답 ③

사고과정

A → B + C 라 x 만큼 반응하면 전체 압력이 0.80 + x 가 된다.

1.20 이므로 x = 0.40, 남은 A 는 0.40 으로 정확히 절반이다.

반감기가 20분이므로 k = 0.7/20 = 0.035 min⁻¹.

→ ③

문제 43반응차수정답 ③

사고과정

[A] 2배에 속도 4배이므로 A 는 2차, [B] 2배에 속도 2배이므로 B 는 1차다.

k = 0.020/(0.1²×0.1) = 20 이고 전체 3차라 단위는 M⁻²s⁻¹, 곧 x=−2, y=−1 이다.

20 + (−2) + (−1) = 17.

→ ③
