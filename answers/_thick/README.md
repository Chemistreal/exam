# 증보 중인 해설

`tools/answer_fill.py --write` 가 여기 있는 `*.json` 을 읽어 `answers/<id>.json`
의 해설을 **갈아 끼운다**. 다른 갈래(`_wip`·`_crop`·`_mis`)는 빈 자리만 채우는데
이 갈래만 예외다 — 대상이 「정답률 50% 미만인데 해설이 150자도 안 되는」 문항이라
채울 빈 자리가 아니라 메모 한 줄이 앉아 있기 때문이다.

거절하는 두 가지가 있다.

* **새 해설이 지금 것보다 짧으면** 거절한다. 증보가 아니라 후퇴다.
* **정답 키(answer·acceptableAnswers)가 담겨 있으면** 통째로 거절한다.
  이 회차들은 채점이 끝나 성적이 이미 나갔다.

재료는 `python3 tools/gen_chunks.py --only thin` 이 만든다(38덩어리 · 240문항).
집필·검증 순서는 `tools/workflows/thicken.js` 에 있다.

⚠ 여기 있는 것은 **작업 중인 원고**다. 세 단계(집필 → 적대적 반박 → 수리)를
다 거치기 전에는 답지에 넣지 않는다.
