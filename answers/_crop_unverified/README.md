# 검수를 못 지난 초고 — **여기 있는 것은 병합하지 마라**

`answers/_crop/` 는 «집필 → 적대적 반박 → 수리» 셋을 **다 지난** 원고만 두는
자리다. `tools/answer_fill.py` 가 그 폴더를 통째로 읽어 답지에 옮겨 담는다.

여기 있는 것은 **집필만 끝나고 반박·수리가 중간에 끊긴** 원고다.
2026-09-05 에 세션 한도(11am UTC 재설정)에 걸려 반박자와 수리하는 사람이
죽었다. 글은 남았지만 아무도 읽어 보지 않았다.

왜 옮겼나 — `answer_fill.py` 는 `_crop/*.json` 을 전부 읽는다. 그대로 두면
다음에 그 문을 여는 사람이 **검수를 안 지난 글을 학생 해설에 실어 버린다.**
이 세션에서 반박자들이 잡아낸 것을 보면 그 위험이 뭔지 알 수 있다 — 핵반응식
부호 뒤집기, 지문에 없는 밀도 값 지어내기, 한 파일 안에서 서로 다른 정답을
가르치기, 없는 어림값(√2 ≈ 1.33) 만들기.

**되살리는 법**: 이 폴더의 파일을 `answers/_crop/` 로 되돌리기 **전에**
반박·수리를 다시 돌려라.

    Workflow(scriptPath: tools/workflows/misc4.js, args: {exam: 'sanyeom-60', chunks: [...]})

그 워크플로는 이미 원고가 있으면 그 위에서 반박부터 시작한다.
