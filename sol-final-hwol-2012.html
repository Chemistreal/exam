문제 1몰수비교정답 ②

사고과정

넷을 따로 본다.

가는 옳다 — 물질 안의 원자 수는 분자 수에 원자 개수를 곱한다.

나는 SO₂(64) 3.3 g ≈ 0.052 mol 과 N₂O₄(92) 4.0 g ≈ 0.043 mol 을 견주면 앞이 많아 옳다.

다는 MgCl₂ 가 이온 3몰, NaOH 가 2몰이라 옳다.

라는 0.5 M × 0.5 L = 0.25 mol 과 NaCl 29.2 g ≈ 0.5 mol 을 견주면 앞이 적어 틀리다.

→ ②

문제 2탄소동소체정답 ③

사고과정

결합의 종류로 나눈다.

흑연의 층 안 C–C 는 sp² 에 π 가 겹쳐 가장 짧고, 다이아몬드의 C–C 는 순수한 단일 결합이라 그다음이며, 층과 층 사이는 분산력으로만 붙어 훨씬 멀다.

→ ③

문제 3킬레이트효과정답 ④

사고과정

두 반응 모두 Cd–N 결합 수가 같아 엔탈피 차이는 작다.

다른 것은 풀려나는 입자 수다.

두 자리 리간드인 에틸렌다이아민을 쓰면 자리를 내준 물 분자가 더 많이 풀려나 무질서도가 커진다.

킬레이트 쪽 평형상수가 크고 그 까닭은 엔트로피다.

→ ④

문제 4결합차수정답 ②

사고과정

공명을 평균해 결합 차수를 센다.

O₃ 는 결합 둘에 이중결합 하나가 나뉘어 1.5, NO₃⁻ 는 셋에 나뉘어 약 1.33, PO₄³⁻ 는 넷에 나뉘어 약 1.25 다.

차수가 클수록 결합이 세다.

→ ②

문제 5부분압력정답 ④

사고과정

압력을 평균하지 않는다.

같은 온도에서 PV 가 몰수에 비례하므로 각 플라스크의 PV 를 더하고 전체 부피로 나눈다.

그림의 값으로 셈하면 1.4 기압이다.

→ ④

문제 6결합각정답 ②

사고과정

중심 원자의 전자 영역으로 각을 정한다.

카복실기의 sp² 탄소 둘레는 120° 근처이고 이중결합이 낀 쪽이 조금 넓다.

산소가 중심인 C–O–H 는 고립쌍 둘에 눌려 가장 좁다.

→ ②

문제 7이온의전자배치정답 ②

사고과정

SnCO₃ 에서 탄산이 2− 이므로 주석은 Sn²⁺ 다.

중성 Sn 은 [Kr]4d¹⁰5s²5p² 이고 전자는 주양자수가 큰 껍질부터 빠지므로 5p 의 둘이 먼저 나간다.

남는 것은 [Kr]5s²4d¹⁰ 다.

→ ②

문제 8비공유전자쌍정답 ②

사고과정

중심 원자만 센다.

H₂O 의 산소는 결합 둘에 고립쌍 둘, O₃ 의 가운데 산소는 결합 영역 둘에 고립쌍 하나, N₃⁻ 의 가운데 질소는 직선형이라 고립쌍이 없다.

2 + 1 + 0 = 3 이다.

→ ②

문제 9분자의구조정답 ④

사고과정

요오드의 원자가 전자에서 결합에 쓰인 것을 빼 고립쌍을 센다.

고립쌍이 둘 남아 전자 영역이 다섯이 되면 삼각쌍뿔 배열에서 고립쌍이 적도면을 차지해 원자 배열은 T–자형이 된다.

→ ④

문제 10산화수정답 ③

사고과정

규칙대로 센다.

F₂ 는 홑원소라 0, HNO₃ 의 N 은 +5, H₂O₂ 의 O 는 −1, O₂ 는 0 이다.

부호까지 넣어 가장 작은 값은 −1 이다.

→ ③

문제 11결합차수정답 ①

사고과정

H₂ 는 전자 둘이 σ1s 에 들어 결합 차수 1 이다.

H₂⁺ 는 전자 하나라 (1−0)/2 = 1/2 이고, H₂⁻ 는 셋이라 σ1s 둘·σ*1s 하나로 (2−1)/2 = 1/2 이다.

둘 다 1/2 이다.

→ ①

문제 12반데르발스상수정답 ④

사고과정

a 는 분자 사이 인력, b 는 분자가 차지하는 부피를 보정한다.

극성이 크면 a 가 크고 분자가 크면 b 가 크므로 ①②③ 은 옳다.

Ne 은 Ar 보다 작고 편극성도 작아 인력이 약하므로 a 가 더 작다 — ④ 가 틀렸다.

→ ④

문제 13전자친화도정답 ①

사고과정

이온화와 전자 붙임은 서로 역과정이다.

Mg⁺ → Mg²⁺ + e⁻ 의 이온화 에너지와 Mg²⁺ + e⁻ → Mg⁺ 의 전자친화도는 크기가 같고 부호가 반대라 ① 이 옳다.

나머지는 서로 다른 원소를 견주거나, 18족처럼 흡열이 되는 경우를 빠뜨렸다.

→ ①

문제 14패러데이법칙정답 ③

사고과정

Zn 65.4 g 은 1 mol 이고 Zn → Zn²⁺ + 2e⁻ 로 전자 두 개를 내놓는다.

전하량은 2 × 96500 = 1.93 × 10⁵ C 다.

→ ③

문제 15체심입방구조정답 ④

사고과정

체심입방에서는 몸 대각선을 따라 원자가 닿는다.

√3·a = 4a_r 에서 모서리 길이는 (4/√3)r 이고, 한 면의 넓이는 그 제곱이라 (16/3)r² 이다.

→ ④

문제 16기체분자운동론정답 ③

사고과정

벽 충돌 빈도는 밀도와 평균 속력에 함께 비례한다.

압력을 올리거나 부피를 줄이거나 기체를 더 넣으면 밀도가 올라 늘어난다.

압력을 고정한 채 온도를 올리면 부피가 그만큼 커져 밀도가 T 에 반비례로 줄고 속력은 √T 로만 늘어 오히려 준다.

→ ③

문제 17산화환원의정의정답 ④

사고과정

산화-환원의 잣대는 산화수 변화다.

산소가 없어도 되고, 늘 짝으로 일어나며, 불균등화처럼 한 원소가 오르내리기도 한다.

중화는 이온이 자리만 바꿀 뿐 산화수가 변하지 않는다.

→ ④

문제 18금속의반응성정답 ③

사고과정

산화가 잘 된다는 것은 전자를 잘 내놓는다는 뜻이다.

A 는 주기율표 맨 왼쪽 1족이라 전자를 가장 쉽게 내놓고, D 는 맨 오른쪽 18족 비활성 기체라 이미 닫힌 껍질이어서 가장 어렵다.

순서대로 A–D 다.

→ ③

문제 19엔트로피정답 ④

사고과정

셋을 따로 본다.

강산·강염기의 중화는 발열이라 ΔH < 0 이다.

100 °C 에서 물이 끓는 것은 흡열이면서 기체가 되어 무질서도가 는다.

NaNO₃ 용해는 흡열이면서 이온이 흩어져 무질서도가 는다.

둘이 함께 느는 것은 b·c 다.

→ ④

문제 20결합에너지정답 ①

사고과정

ΔH = (끊은 결합의 합) − (생긴 결합의 합) 이다.

끊는 쪽은 H–H 436 과 C≡C 812, C–H 두 개 828 로 2076 이고, 생기는 쪽은 C=C 620 과 C–H 네 개 1656 으로 2276 이다.

2076 − 2276 = −200 kJ 다.

→ ①

문제 21혼성오비탈정답 ④

사고과정

전자 영역 수가 혼성을 정한다.

NH₃ 와 H₃O⁺ 는 결합 3 + 고립쌍 1 로 sp³, CH₄ 는 결합 4 로 sp³ 다.

SO₂ 는 결합 영역 2 + 고립쌍 1 로 셋이라 sp² 다.

→ ④

문제 22분자식추론정답 ④

사고과정

밀도로 몰질량을 낸다.

0 °C·1기압에서 1몰이 22.4 L 이므로 C 의 몰질량은 11.3 × 22.4 ≈ 253 g/mol 이다.

질량 백분율로 C·H·X 의 몰비를 구하면 1 : 1 : 3 이 나와 CHX₃ 다.

→ ④

문제 23원자량정답 ③

사고과정

앞 문항에서 얻은 분자식과 몰질량을 잇는다.

CHX₃ 의 몰질량이 약 253 이므로 3X = 253 − 13 = 240, X ≈ 80 이다.

→ ③

문제 24순차이온화에너지정답 ④

사고과정

이온화 에너지가 3차에서 4차로 넘어갈 때 2.75 에서 11.60 으로 네 배 넘게 뛰므로 원자가 전자는 셋, 곧 Al³⁺ 다.

Ar 과 같은 배치를 갖는 3주기 음이온 가운데 반지름이 가장 작은 것은 양성자가 가장 많은 Cl⁻ 이다.

전하를 맞추면 AlCl₃ 다.

→ ④

문제 25한계반응물정답 ③

사고과정

[Ne]3s² 는 Mg 이고 Mg + 2HCl → MgCl₂ + H₂ 다.

Mg 19/24 ≈ 0.79 mol, HCl 은 6 × 0.1 = 0.6 mol 이다.

계수로 나누면 HCl 이 한계 반응물이라 H₂ 는 0.3 mol 이 생기고 0.3 × 22.4 = 6.7 L 다.

→ ③

문제 26분자운동속도정답 ②

사고과정

같은 조건·같은 부피이므로 분자 수는 같다.

평균 속력은 몰질량의 제곱근에 반비례하므로 O₂ : H₂ = 1/√32 : 1/√2 = 1 : 4 다 — ② 의 1 : 16 은 틀리다.

평균 속력은 온도만으로 정해져 압력·온도를 바꿔도 비는 그대로다.

→ ②

문제 27전기음성도정답 ②

사고과정

A–B 결합에는 두 동종 결합의 평균에 전기음성도 차에서 오는 이온성 기여가 얹힌다.

그래서 A–B 결합 에너지는 산술 평균보다 크다.

→ ②

문제 28열량계정답 ③

사고과정

반응한 몰수를 먼저 센다.

HCl 0.862 × 0.200 = 0.172 mol 이고 Ba(OH)₂ 는 0.431 × 0.200 = 0.0862 mol 이라 계수 2:1 로 꼭 맞는다.

방출열은 0.0862 × 112.4 ≈ 9.69 kJ 이고, 용액 400 g·비열 4.18 로 나누면 ΔT ≈ 5.8 °C 다.

25.0 + 5.8 = 30.8 °C 다.

→ ③

문제 29자발성정답 ③

사고과정

얼음이 녹는 것은 흡열이라 ΔH° > 0 이고 무질서도가 늘어 ΔS° > 0 이다.

4 °C 는 어는점보다 높아 실제로 녹으므로 자발적이고, 곧 ΔG° < 0 이라 TΔS° 가 ΔH° 를 이긴다.

→ ③

문제 30용해도곱정답 ③

사고과정

Cu(IO₃)₂ → Cu²⁺ + 2IO₃⁻ 이므로 [Cu²⁺] = s, [IO₃⁻] = 2s 다.

Ksp = s(2s)² = 4s³ 에서 s = (Ksp/4)^(1/3) 다.

→ ③

문제 31끓는점정답 ②

사고과정

하나씩 본다.

O₂ 는 N₂ 보다 분자량이 커 분산력이 세므로 끓는점이 높다.

NO 는 분자량이 30 으로 O₂(32)와 비슷한데 극성이 있어 오히려 NO 가 높다 — ② 가 틀리다.

HF 는 수소 결합으로 HCl 보다 높고, H₂Se 는 H₂S 보다 분자량이 커 높다.

→ ②

문제 32배위화합물정답 ③

사고과정

AgNO₃ 로 침전하는 것은 배위권 밖의 Br⁻, BaCl₂ 로 침전하는 것은 배위권 밖의 SO₄²⁻ 다.

A 는 BaCl₂ 에만 반응하므로 SO₄²⁻ 가 밖에 있고 Br 이 리간드다.

그러면 A 의 착이온은 [CoBr(NH₃)₅]²⁺ 로 +2 가라 ③ 이 틀리다.

→ ③

문제 33엔트로피정답 ③
