문제 1중화반응 · 중화반응정답 ①

즉시 재도전 중화반응 · 중화반응 ← KMChC 2025 제1차 · 심화 21번 중화반응 · 난이도 재도전 삼양성자산의 적정에서는 당량점과 반당량점이 번갈아 나온다.

산 2.50 mmol 이므로 당량점은 25.0, 50.0, 75.0mL 이고, 반당량점은 12.5, 37.5, 62.5 mL 이다.

· 12.5 mL(1차 반당량점): H₃A 1.25 mmol 과 H₂A⁻ 1.25mmol 이 같이 있다.

pH = pKa₁ + log(1) = 3.00 · 25.0 mL(1차 당량점): H₂A⁻ 만 남는 양쪽성 지점.

pH ≈ (3.00+ 6.00)/2 = 4.50 · 37.5 mL(2차 반당량점): NaOH 3.75 mmol 중 2.50 mmol 이 H₃A 를 H₂A⁻ 로 바꾸고, 남은1.25 mmol 이 H₂A⁻ 절반을 HA²⁻ 로 바꾼다.

따라서 [H₂A⁻] = [HA²⁻] = 1.25 mmol 이고 pH = pKa₂ + log(1) =6.00 짝산과 짝염기의 농도가 같을 때 완충 용량이 극대가 되므로 선택지 1 이 옳다.

· 50.0 mL(2차 당량점): HA²⁻만 남으므로 pH ≈ (6.00 + 10.00)/2 = 8.00 · 62.5 mL(3차 반당량점): pH = pKa₃ = 10.00 · 75.0 mL(3차 당량점): A³⁻ 만 남는다.

[A³⁻] = 2.50 mmol ÷ 100.0 mL = 0.0250 M, Kb = Kw/Ka₃ = 1.0×10⁻¹⁴/1.0×10⁻¹⁰ =1.0×10⁻⁴ 이므로 [OH⁻] ≈ √(1.0×10⁻⁴ × 0.0250) = √(2.5×10⁻⁶) = 1.6×10⁻³ M, pOH = 2.80, pH = 11.20○ 표와 맞는다.

세 번째 당량점은 pH 가 10.00 에서 11.20 으로 1.2 밖에 오르지 않는다.

Ka₃ = 1.0×10⁻¹⁰ 로 물의이온화와 경쟁할 만큼 약해, 세 번째 종말점은 사실상 눈으로 잡히지 않는다.

오개념 당량점과 반당량점을 뒤바꿔, 반당량점에 양쪽성 화학종 근사식을 쓰고 당량점에 pH = pKa 를 쓴다.

또 다양성자산이면 당량점마다 뚜렷한 pH 도약이 생긴다고 생각한다.

그때 왜 틀렸나 황산이 양성자를 둘 내놓는다는 것을 빠뜨려 중화 몰수를 절반으로 셈.

문제 2깁스자유에너지 · 자발성정답 ①

즉시 재도전 깁스자유에너지 · 자발성 ← KMChC 2025 제1차 · 일반 11번 자발성 · 난이도 재도전 ① 어떤 반응의 역반응은 엔탈피 변화의 크기가 같고 부호만 반대이다.

(가) 가 ΔH = -890 kJ 인 발열 반응이므로 역반응은 ΔH = +890 kJ 인 흡열 반응이다.

따라서 ① 이 옳다.

② ΔH = H(생성물) - H(반응물) 이고 (가) 는 ΔH < 0이므로 H(생성물) < H(반응물) 이다.

생성물 쪽 엔탈피가 더 작다.

③ (나) 는 ΔH > 0 인 흡열 변화이므로 주위(용액과 용기)에서 열을 흡수한다.

따라서 용액의 온도는 내려간다.

질산 암모늄을 물에 녹이면 차가워지는 것이 이 때문이며, 냉각 팩에 이용된다.

④ 반응의 자발성은 ΔH 만으로 정해지지 않는다.

ΔG = ΔH - TΔS 에서 (나) 는 고체이온 결정이 흩어져 수용액 이온이 되므로 ΔS > 0 이고, 상온에서 TΔS 항이 +25.7 kJ 를 넘어서기 때문에 실제로저절로 녹는다.

오개념 ΔH 의 부호는 계가 열을 내놓는지 받는지를 나타낼 뿐이며, 흡열이라고 해서 반응이 일어나지 않는 것은 아니다.

흡열 변화가 일어나면 주위의 온도는 내려간다.

그때 왜 틀렸나 표준 생성 엔탈피가 0 인 것을 '반응하지 않는다'로 읽음.

그것은 그 상태가 기준이라는 뜻이다.

문제 3이온화도 · 전해질의세기정답 ③

즉시 재도전 이온화도 · 전해질의세기 ← KMChC 2025 제1차 · 일반 9번 전해질의세기 · 난이도 재도전 ① 넣어 준 H⁺ 와 OH⁻ 의 몰수를 각각 구한다.

n(H⁺) = 0.15 mol/L × 0.100 L = 1.5×10⁻² mol Ba(OH)₂ 1 mol은 OH⁻ 2 mol 을 내놓으므로 n(Ba(OH)₂) = 0.025 mol/L × 0.100 L = 2.5×10⁻³ mol n(OH⁻) = 2.5×10⁻³ ×2 = 5.0×10⁻³ mol ② 중화되고 남는 쪽을 정한다.

1.5×10⁻² - 5.0×10⁻³ = 1.0×10⁻² mol 의 H⁺ 가 남으므로 혼합 용액은 산성이다.

③ 남은 H⁺ 를 혼합 후 전체 부피 0.200 L 로 나눈다.

[H⁺] = 1.0×10⁻² mol ÷ 0.200 L =5.0×10⁻² M ④ pH = -log(5.0×10⁻²) = 2 - log 5 = 2 - (1 - log 2) = 2 - (1 - 0.30) = 2 - 0.70 = 1.30 오개념 산과 염기를 섞을 때는 농도가 아니라 H⁺·OH⁻ 의 몰수로 중화시킨 뒤, 남은 이온의 몰수를 '혼합 후 전체 부피'로 나누어야 한다.

또 Ba(OH)₂ 처럼 OH⁻ 를 두 개 내놓는 염기는 몰 농도에 2 를 곱해야 한다.

그때 왜 틀렸나 녹으면 다 전해질이라 여김.

이온으로 나뉘어야 하고, 일부만 나뉘면 약전해질이다.

문제 4배위화학 · 분광화학계열정답 ③

즉시 재도전 배위화학 · 분광화학계열 ← KMChC 2025 제1차 · 심화 46번 분광화학계열 · 난이도 재도전 55 [평형 상수] 치환 반응은 두 생성 반응의 차이이다.

(Cu²⁺ + 2en → [Cu(en)₂]²⁺) - (Cu²⁺ + 4NH₃ → [Cu(NH₃)₄]²⁺)따라서 K = β₂ / β₄ 이고 로그로는 빼면 된다.

log K = 19.6 - 12.6 = 7.0 K = 1.0 × 10⁷ [표준 자유 에너지 변화] lnK = 7.0 × 2.303 = 16.12 ΔG° = -RT ln K = -(8.314)(298)(16.12) = -(2477.6)(16.12) = -39,940 J/mol ≈ -39.9kJ/mol [표준 엔트로피 변화] ΔG° = ΔH° - TΔS° → ΔS° = (ΔH° - ΔG°)/T ΔS° = [(-13,000) - (-39,940)] / 298 =26,940 / 298 = 90.4 J/(mol·K) ≈ +90 J/(mol·K) 검산: 되돌려 계산하면 ΔH° - TΔS° = -13,000 - 298(90.4) =-13,000 - 26,939 = -39,939 J 로 ΔG° 와 일치한다.

이것이 킬레이트 효과의 핵심이다.

ΔH° 는 -13.0 kJ/mol 로 작은데, 자유 에너지의 -39.9 kJ/mol 중 -26.9 kJ/mol, 곧 3분의 2가 엔트로피 항에서 나온다.

반응식 왼쪽은 착이온1개와 en 2개로 3개 입자이고 오른쪽은 착이온 1개와 NH₃ 4개로 5개 입자여서, 자유롭게 돌아다니는 입자 수가 늘어난 만큼 엔트로피가 커진다.

두 자리 리간드는 한 번 붙으면 두 자리를 동시에 차지하므로, 같은 수의 결합을 만들면서 더 적은 수의 리간드 분자만 쓰는 셈이다.

· 선택지 1: log K 를 12.6 - 19.6 = -7.0 으로 거꾸로 뺀 값이다.

치환반응은 en 착물이 생기는 쪽이므로 β₂ 를 β₄ 로 나눈다.

· 선택지 2: 두 생성 상수를 곱해 log K = 19.6 + 12.6 = 32.2로 본 값이다.

반응식이 두 과정의 합이 아니라 차이이므로 로그는 빼야 한다.

· 선택지 4: ΔG° 가 ΔH° 보다 더 음수라는 것은 -TΔS° 가 음수, 곧 ΔS° 가 양수라는 뜻이다.

부호를 반대로 두면 킬레이트 효과의 설명 자체가 뒤집힌다.오개념 여러 단계 생성 상수를 조합할 때 로그를 더할지 뺄지 혼동하고, 킬레이트 효과를 결합이 더 강해서(엔탈피때문) 생기는 것으로만 이해한다.

그때 왜 틀렸나 리간드의 세기와 흡수 파장을 같은 방향으로 봄.

세면 갈라짐이 커서 짧은 파장을 흡수한다.

문제 5원자모형 · 오비탈정답 ④

즉시 재도전 원자모형 · 오비탈 ← KMChC 2021 6번 오비탈 · 난이도 재도전 ns 오비탈의 방사 확률 분포는 봉우리가 n개, 방사 마디가 (n - 1)개다.

따라서 3s는 봉우리 3개, 방사 마디 2개다.

r= 0에서는 r² 인자 때문에 4πr²ψ² = 0이 되어 최대가 아니라 0이다.

3p의 방사 마디 수는 n - l - 1 = 3 - 1 - 1 = 1개이므로 봉우리는 2개이고, 3s의 3개와 다르다.

오개념 파동 함수 자체(ψ 또는 ψ²)의 값이 핵에서 가장 큰 것과, 거리별 발견 확률인 4πr²ψ²가 핵에서 0인 것을 구별하지 못한다.

마디와 봉우리 개수를 서로 바꿔 센다.

그때 왜 틀렸나 방사 확률 분포는 한 전자를 거리별로 발견할 확률.

ns 오비탈의 봉우리 수는 n개, 마디(확률 0)는(n-1)개.

문제 8원자모형 · 흡광도정답 ①

즉시 재도전 원자모형 · 흡광도 ← KMChC 2021 24번 흡광도 · 난이도 재도전 E = hc/λ = (6.63×10⁻³⁴ J·s × 3.00×10⁸ m/s) ÷ (500×10⁻⁹ m) = 3.98×10⁻¹⁹ J이다.

양자 구속 효과에 따라양자점이 작을수록 전자의 운동이 좁은 공간에 갇혀 에너지 준위 간격이 벌어지므로 띠간격이 커진다.

따라서 지름이 2배 큰 B의 띠간격은 A보다 작고, E = hc/λ에서 띠간격이 작으면 흡수 파장은 더 길어진다.

관찰되는 색은 흡수된 빛이 빠진 나머지 빛이므로 흡수 색의 보색이다.

오개념 '크기가 크면 에너지도 크다'는 일상적 직관으로 큰 양자점의 띠간격이 크다고 보고, 흡수한 빛의 색을 그대로 관찰되는 색이라고 생각한다.

그때 왜 틀렸나 어는점 내림은 입자 수(i×몰랄농도)에 비례.

비전해질(글루코오스·수크로스)은 i=1, MgCl2는 i=3.

문제 9원자모형 · 양자수정답 ④

즉시 재도전 원자모형 · 양자수 ← KMChC 2025 제1차 · 심화 2번 양자수 · 난이도 재도전 1단계 ― 계열 한계 광자의 에너지를 구한다.

E = hc/λ = 1240 eV·nm ÷ 22.8 nm = 54.39 ≈ 54.4 eV 2단계 ― 이에너지는 n = ∞ 에서 n = 2 로 떨어질 때의 값이므로 n = 2 준위의 깊이와 같다.

E∞ - E₂ = 0 - (-13.60·Z²/2²) =13.60·Z²/4 = 3.400·Z² 3.400·Z² = 54.4 → Z² = 16 → Z = 4 3단계 ― 바닥 상태(n = 1)의 이온화 에너지를 구한다.E₁ = -13.60 × 16 / 1 = -217.6 eV 이온화 에너지 = 0 - (-217.6) = 217.6 eV 검산: Z = 4 이면 E₂ = -217.6/4 = -54.4eV 이므로 n = 2 계열 한계는 54.4 eV, λ = 1240/54.4 = 22.79 nm 로 문제의 22.8 nm 와 일치한다.

○ 계열 한계에너지(54.4 eV)는 'n = 2 에서의 이온화 에너지'이지 바닥 상태의 이온화 에너지가 아니다.

두 값은 Z 가 같아도 n²만큼, 즉 4배 차이가 난다.

오개념 계열이 수렴하는 준위에서의 이온화 에너지를 바닥 상태의 이온화 에너지와 같은 것으로 보고, En ∝ Z²/n²에서 n² 를 빠뜨린다.

그때 왜 틀렸나 자기 양자수의 개수를 부껍질마다 세지 않고 어림함.

㉠ 126 > 6.00 →관측 안 됨 ㉡ 9.07 > 6.00 → 관측 안 됨 ㉢ 5.31 < 6.00 → 관측됨 ㉣ 0.738 < 6.00 → 관측됨 따라서 봉우리는 2개이다.

[가장 큰 운동 에너지] KE = hν - BE 이므로, 같은 hν 에서는 BE 가 가장 작은 전자가 가장 빠르게 튀어나온다.

관측되는 것 중 BE 가 가장 작은 것은 ㉣ 이다.

KE(최대) = 6.00 - 0.738 = 5.262 ≈ 5.26 MJ/mol [그 봉우리의상대 세기] ㉣ 의 상대 세기는 2 이다.

검산: 상대 세기 2 : 2 : 6 : 2 를 모두 더하면 전자 12개이고, 안쪽부터 2, 2, 6,2 는 1s² 2s² 2p⁶ 3s² 배치에 해당한다.
