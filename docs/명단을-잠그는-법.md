# 명단을 잠그는 법 — 5분, 선생님이 켜실 때 켜집니다 (2026-09-07)

## 왜 이 글이 있나

성적 창구(Apps Script)는 **열쇠 없이** 열려 있습니다. 그렇게 만든 것은
선생님 요청이었고, 덕분에 학부모가 링크만 눌러 성적표를 볼 수 있습니다.

그런데 그 창구 주소는 공개 저장소의 화면 파일에 그대로 적혀 있습니다.
그래서 주소 뒤에 `?action=all` 을 붙이면 **전교생의 이름·학교·학년과 모든
회차 답안**이 한 번에 나옵니다. 미성년자 명단입니다.

주소를 아는 사람은 지금 아무도 없을 수 있습니다. 다만 그것은 잠긴 것이
아니라 아직 아무도 열어 보지 않은 것입니다.

## 켜기 전에 알아 둘 것 — 무엇이 잠기고 무엇이 안 잠기나

| | 잠기나 | 왜 |
|---|---|---|
| 학부모가 받은 **성적표 링크** | **안 잠긴다** | 이미 보낸 것이 죽으면 안 된다 |
| 학생이 **답안을 내는 길** | **안 잠긴다** | 잠그면 시험 자체가 안 돈다 |
| 회차별 응시자 목록 (`list`) | 안 잠긴다 | 성적표 링크가 이것을 부른다 |
| 익명 점수 분포 (`cohort`) | 안 잠긴다 | 이름이 없다 |
| **전체 기록** (`all`) | **잠긴다** | 이름·학교·학년·답안이 다 실린다 |
| **한 학생 응시 이력** (`history`) | **잠긴다** | 이름으로 묻는다 |
| 이름 고치기·행 지우기·중복 정리·재계산 | **잠긴다** | 시트를 바꾼다 |

즉 **이미 나간 링크는 하나도 안 죽습니다.** 잠기는 것은 선생님이 쓰시는
「명단 관리」 쪽입니다.

## 켜는 법

1. 성적 시트를 열고 **확장 프로그램 → Apps Script**
2. 왼쪽 **⚙ 프로젝트 설정**
3. 맨 아래 **스크립트 속성 → 속성 추가**
4. 속성 이름에 `ADMIN_TOKEN`, 값에 **아무나 못 맞힐 긴 문자열**을 넣습니다

   추측할 수 있는 것은 열쇠가 아닙니다. 학원 이름·전화번호·연도는 피하시고,
   20자 이상 아무렇게나 섞은 것이 좋습니다. 예를 들어
   `Qv7-mza42Lk-91tRs-bdW3` 같은 모양입니다(이 값을 그대로 쓰지 마세요).
5. **저장** 을 누르고, **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**

여기까지 하면 켜집니다.

## 켠 다음 선생님 화면에서 할 일

성적 화면에서 「명단 관리」나 「시트에서 불러오기」를 처음 누르시면
**열쇠를 묻는 창**이 한 번 뜹니다. 4번에서 넣으신 값을 그대로 붙여 넣으세요.

- 이 기기에만 저장됩니다. 다음부터는 안 묻습니다.
- 학원 PC 와 노트북을 같이 쓰시면 **기기마다 한 번씩** 넣으셔야 합니다.
- 잘못 넣으셨으면 다시 눌렀을 때 또 물어봅니다.

## 끄는 법

스크립트 속성에서 `ADMIN_TOKEN` 을 지우고 다시 배포하면 예전 그대로
돌아갑니다. **속성을 안 두면 아무것도 안 잠깁니다** — 그렇게 만든 이유가
이것입니다. 켜는 시점을 선생님이 고르시고, 무슨 일이 생기면 되돌리는 데
1분이 걸립니다.

## 안 하시면 어떻게 되나

지금대로입니다. 창구는 열려 있고, 주소를 알아낸 사람은 명단을 통째로
받아 갈 수 있습니다. **이 글은 하시라는 뜻이 아니라, 하실 수 있게 다
만들어 두었다는 뜻입니다.**

# 두 번째 — 공개 백업을 막는 법 (선택, 2분)

## 무엇이 문제인가

깃허브에 매일 자동 저장되는 `backup/<날짜>.json` 에는 학생 **코드**(이름이
아닙니다)와 **답안 문자열**이 들어 있습니다. 이름은 소금 친 해시로 가려 두었고
그건 잘 되어 있습니다.

문제는 답안 쪽입니다. 성적표 링크는 이렇게 생겼습니다.

    index.html#r=<회차>.<답안을 접은 값>[.<수험번호>.<이름>]

뒤의 수험번호·이름은 **없어도 열립니다**. 그러니 링크의 비밀은 답안 문자열
하나뿐인데, **그 문자열이 공개 백업에 그대로 있습니다.** 이름을 몰라도
링크가 열리고, 열면 그 안에 다 있습니다.

## 고르실 수 있는 것 셋

### (가) 백업만 비공개 저장소로 — **이걸 권합니다. 잃는 것이 없습니다**

1. 깃허브에서 **비공개** 저장소를 하나 만듭니다(예: `exam-backup`)
2. Apps Script → ⚙ 프로젝트 설정 → 스크립트 속성에
   `BACKUP_REPO` = `Chemistreal/exam-backup`
3. 저장 → 배포 → 배포 관리 → 새 버전 → 배포

지금 쓰시는 `GITHUB_TOKEN` 이 그 저장소에도 쓸 수 있어야 합니다(토큰 권한에
그 저장소를 더해 주세요). 이후 백업은 그쪽으로만 갑니다.

⚠ 이미 올라간 `backup/*.json` 은 그대로 남습니다. 지우실 거면 공개 저장소에서
따로 지우셔야 합니다(과거 커밋에도 남아 있다는 점은 알아 두세요).

### (나) 답안을 아예 안 싣기 — 저장소를 새로 안 만들어도 됩니다

스크립트 속성에 `BACKUP_ANSWERS` = `0` 을 넣고 배포하면, 백업에 답안 문자열
대신 **틀린 문항 번호만** 실립니다. 스무 개를 틀렸다면 3의 20제곱 가지라
링크를 되지을 수 없습니다.

잃는 것: 학생별 파이널의 「예전에 ③」 한 줄입니다. 어느 문항을 틀렸는지는
그대로 남아서, 약점 시험을 짓는 데는 지장이 없습니다.

### (다) 그대로 두기

지금 상태입니다. 저장소 주소와 백업 파일을 아는 사람은 성적표 링크를 지어
낼 수 있습니다.

## 어느 쪽을 고르셔도

두 속성 다 **안 두면 지금 그대로 돕니다.** 넣는 순간 바뀌고, 지우면 되돌아
갑니다. 도구 쪽은 두 모양을 다 읽게 해 두었으니 옛 백업도 계속 읽힙니다.
