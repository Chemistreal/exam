# final.html · 화올 2021 Q60 채점 제외 패치 (2026-07-07)

## 문제
- 대상 파일: final.html (KMChC 기출 자동채점·수상권 분석 페이지, FINAL_EXAMS 41시험)
- hwol-2021(화올 2021) 레코드가 Q60을 정답키 ①(=1)로 그대로 채점하고 있었음.
- 그러나 공식 정답표(p29)에서 Q60은 취소선 + "(문제삭제)", 의도답 A(①)도 취소선 = 공식 문제삭제 문항.
- 감사 지침(FABLE_FLAG): "2021 키 편입 시 Q60 제외 필수(①로 채점 금지)".
- 결과: 라이브에서 Q60이 ①로 채점되어, ①을 고른 응시자는 부당 가점 / 그 외는 부당 감점 위험.

## 조치 (단일 최소 변경)
- hwol-2021 레코드의 `"miss": []` -> `"miss": [60]` (정확히 2글자 증가, 그 외 무변경).
- Q60 의도정답 기록(key[59]=1)은 그대로 보존 -> 참고용 의도답은 남기되, 채점에서만 제외.
- final.html의 채점 메커니즘은 모든 경로에서 `if(miss.has(q))continue`로 miss 문항을 건너뜀:
  - scoreAuto(개인 채점), qbankStats(정답률 통계), 정오표(wrong 목록), 등급 계산(W=t-c, award(W,cut)) 전부 반영.
  - 정오표에는 miss 문항에 "제외" pill이 자동 표시됨.

## 검증
- 원본 대비 변경 헝크 1개(해당 라인 1줄), FINAL_EXAMS 41시험·타 시험 miss 무오염, HTML script 태그 균형·U+FFFD 0.
- 실브라우저(chromium): 
  - 데이터: miss=[60], nQ=60 유지, Q60 key=1 보존, multi(36,48) 무변경.
  - 채점 로직: Q60을 일부러 오답(②)으로 응답해도 채점 대상 t=59·틀림 W=0 (제외 정상 반영), 정답 c=59.
  - 등급: W=0 -> 대상(cut=[0,4,9,13,18]).
  - UI: openExam('hwol-2021') 정상 진입, "제외" 표기 노출, 페이지 JS 오류 0.
