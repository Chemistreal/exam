## A. 지금 막혀 있는 것 — 넷

이번 주 작업이 여기서 멈췄다. 위에서부터 급하다.

### A1 ⚠ KMChC `report-data/` 의 학생 리포트 58개

`report.html?id=…` 이 읽는 JSON 에 **실명 · 학년 · 전체 응답**이 들어 있다.

    { "id":"r05540…", "name":"홍길동", "grade":"중2", "answers":"…", "savedAt":… }

`Chemistreal/KMChC` 는 **공개 저장소**다(GitHub Pages 를 쓰기 때문이다).
`tools/noindex.py` 는 화면(HTML)에만 `noindex` 를 붙일 수 있고 **JSON 에는 못
붙인다.** 남는 보호막이 "주소를 남이 모른다" 하나인데, 공개 저장소에서는 그
주소가 **목록으로 통째로 보인다.**

| 고를 수 있는 것 | 비용 |
|---|---|
| **그대로 둔다** | 지금 상태. 이름 56명분이 계속 열려 있다 |
| **저장소를 비공개로** | Pages 를 비공개 저장소에서 내려면 **유료 플랜**이 필요하다 |
| **이름을 코드로 바꾼다** | 이미 나간 링크는 살아 있고, 리포트에 이름만 안 뜬다. 학부모가 "누구 것인지" 를 링크로만 알게 된다 |
| **`report-data/` 를 걷어낸다** | Apps Script 로만 읽게 되돌린다. **이미 나간 링크가 느려지거나 깨진다** |

> 다른 세 앱에는 같은 것이 없다. DT 의 반 명단 백업은 이름이 아니라 가려진
> 학생 코드(`s64211e174h5`)를 담고, exam·study64 는 학생별 파일을 아예
> 저장소에 두지 않는다.

**기계가 정하면 안 되는 칸**이라 자를 아예 안 들여놓았다.

| | |
|---|---|

| 넣으면 | 회차 셋이 새로 생긴다(`hwol-2017-30` 같은 id). 문항·정답·크롭·해설을 새로 붙여야 한다 — **작은 일이 아니다** |

### A5 학생 이름을 **맞춰 보는 규칙**을 정할지 (2026-08-10 새로 나옴)

네 앱이 같은 학생을 다루는데, 이름을 어떻게 맞춰 보는지가 갈려 있다.
`tools/name_key.py` 로 처음 재어 보니 —

| 앱 | 맞춰 보는 키 | 규칙 |
|---|---|---|
| exam | 2곳 (`nameKey`) | 공백을 **모두 지운다** — 홍 길동 → 홍길동 |
| DT | 4곳 (`cleanName`) | 공백을 **모두 지운다** |
| KMChC | **없다** | 맞춰 보는 자리가 아예 없다 |
| study64-report | **없다** | 맞춰 보는 자리가 아예 없다 |

즉 `홍 길동` 과 `홍길동` 이 exam·DT 에서는 한 사람이고, KMChC·study64 에서는
**두 사람인지 한 사람인지 아무도 안 본다.**

| | |
|---|---|
| 안 하면 | 지금대로. 두 앱은 갈린 이름을 알아채지 못한다 |
| 정하면 | `name_key.py` 의 `AGREED` 에 한 줄 적으면 그때부터 어기는 자리가 빨간불이다 |

⚠ 다듬는 방식을 **바꾸는 것**은 다른 일이다. 이미 시트에 쌓인 이름과 새로
들어오는 이름이 어긋나므로 자료를 옮겨야 한다. 그래서 자는 **세기만 하고
조용하다** — 선생님이 정하기 전에는 아무것도 안 막는다.

먼저 여쭐 것: 학생이 `홍 길동` 이라고 띄어 적으면 `홍길동` 과 **같은 사람**으로
보시겠습니까?

## E. 결정이 아니라 **손**이 필요한 것 — 여섯

여기는 ⚖ 가 아니다. 기계가 못 재는 것이라 **한 번 해 보셔야** 아는 자리다.

| # | 무엇 | 왜 기계가 못 하나 |
|---|---|---|
| E1 | **낭독기로 셸을 한 번 써 보기** | 태그가 맞는지는 쟀다. 실제로 들리는 순서는 사람이 들어야 안다 |
| E2 | **한 손으로 셸을 한 번 써 보기** | 손가락 자리 크기는 쟀다. 엄지가 닿는지는 손이 안다 |
| E3 | **3초 안에 무엇이 보이나** | 첫 그림을 막는 글꼴은 쟀다. "3초에 쓸 만한가" 는 사람이 본다 |
| E4 | **색만으로 말하는 자리** | 색상 필터를 씌우고 같은 화면을 두 번 찍어야 안다 |
| E5 | **인쇄 실측** — 성적표·상담지·해설지를 A4 로 | `@page` 는 있다. 잘리는 자리는 뽑아 봐야 안다 |
| E6 | **첫 화면까지 걸리는 시간** — 390px · 느린 3G | 기준선부터 만들어야 한다 |

> 허브 문서의 "남은 여덟" 이 E1~E3 이다. 스물하나 가운데 **열셋을 이미 답해
> 주셨고 다섯이 코드를 바꿨다.**
