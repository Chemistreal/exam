## 관찰 사항 2건 (경미 · 채점 무해)

### 1) 단원 라벨 드리프트 70건 (동일 진술이 두 단원 표기)
- 같은 문장이 서로 다른 단원(u) 라벨로 재출제된 경우 70건. 과목별: 화학I 6, 화학II 1, 일반화학 0 (진술 단위 집계 시 70건).
- 성격: 대부분 '같은 주제의 두 표기 granularity'가 붙은 것.
  예) (산염기평형 / 완충) 9건, (열역학 / 자발성) 8건, (반응속도 / 반응속도론) 6건, (산화수 / 산화환원평형) 6건,
      로마숫자 단원 <-> 키워드 단원 혼용 14건 (예: Ⅱ-1 / 원자, Ⅰ-3 / 이상기체).
- 오류 아님: 누적 OX 설계상 같은 개념을 여러 단원 맥락에서 재노출하는 것은 정상. 정답·채점엔 무영향.
- 유일한 실질 영향: '단원별 진단 집계'에서 같은 문장이 다른 단원 버킷으로 잡힐 수 있어, 단원 통계가 미세하게 흔들릴 여지.
- 권장(선택): 단원 표기 체계를 하나로 통일(로마숫자 or 키워드), 또는 별칭 매핑 테이블로 집계 시 정규화.

### 2) 고아 동형(forms) 4건
- 동형 풀에는 있으나 본 문항(2,760)엔 해당 개념코드가 없는 항목 4건:
  CH2-095(이온 결정 전도성), CH2-101(공유 결정 녹는점), CH2-105(다이아몬드 전도성), CH2-107(금속 전도성).
  모두 '결합·전도성' 계열, reading(정리) 보유, 동형 7~15개씩 완비.
- 성격: 향후 회차용으로 준비됐거나, 본 회차에서 아직 미편성된 자산으로 보임. 현재 채점엔 무영향.
- 권장(선택): 의도 확인 후, 사용 예정이면 회차 편입 / 아니면 정리.
