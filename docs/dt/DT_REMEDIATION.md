# DT 옵션2 관찰 처리 (단원 표기 통일 · 고아 동형) 2026-07-07

옵션2(내부 정합성)에서 남긴 두 경미 관찰의 처리안. 둘 다 치명 문제가 아니며,
채점 결과에는 영향이 없다(정답·진술 불변). 단원별 약점 집계의 정합성만 개선한다.

## 1) 단원 표기 드리프트: 실측 결과 재분류
'같은 진술이 두 단원으로 갈린' 70건을 다시 분해하니 성격이 완전히 갈렸다.

- 과목 경계를 넘는 63건: 같은 진술이 화학I / 화학II / 일반화학에 동시 등장하는 경우.
  예) "pH는 -log[H⁺]로 정의된다"는 ch1, ch2, gc 셋 다; "ΔG<0이면 자발적"은 ch2, gc 양쪽.
  세 과목이 겹치는 내용을 각자의 단원명으로 다루는 정상 설계 -> 손대지 않는다.
  (옵션2 리포트에서 이 63건을 '통일 대상'으로 뭉뚱그린 것은 과대 표기였고, 여기서 정정한다.)
- 같은 과목 내 진짜 드리프트 7건(적용 시 7문항): 아래가 실제 통일 대상.

### 통일 계획 (진술 다수결 = 변경 최소화)
| round | code | from -> to | 비고 |
|---|---|---|---|
| ch1_02 | CH1-009 | Ⅰ-1 -> Ⅱ-1 | 중성자 전하(원자 구조) |
| ch1_02 | CH1-037 | Ⅰ-3 -> Ⅱ-1 | 동위원소 |
| ch1_03 | CH1-037 | Ⅰ-3 -> Ⅱ-1 | 동위원소 |
| ch1_06 | CH1-037 | Ⅰ-3 -> Ⅱ-1 | 동위원소 |
| ch1_01 | CH1-007 | Ⅰ-1 -> Ⅱ-1 | TIE 권고(원자핵 구성) |
| ch1_18 | CH1-059 | 부록 -> Ⅰ-4 | TIE 권고(질량비) |
| ch2_03 | CH2-113 | 분압 -> 농도 | TIE 권고(몰분율 정의) |

- 명확 4건: 원자·동위원소 개념을 원자 구조 단원(Ⅱ-1)으로 통일(각 진술이 이미 Ⅱ-1에 다수 존재).
- 동점 3건: 다수결로 못 정해 표준을 권고로 표시. 다른 단원을 원하면 스크립트 PLAN 의 to 만 바꾸면 된다.

### 적용 도구: unit_unify.py
- appdata 의 모든 round_*.json 을 훑어 (진술+현재단원+코드)가 계획과 맞는 문항의 u 만 바꾼다.
- 진술(s)/정답(a)/코드(c)/기타 필드는 불변. 파일명/round 포맷에 의존하지 않는다.
- 미리보기(기본) -> `python3 unit_unify.py --appdata ./appdata`
- 실제 적용 -> `python3 unit_unify.py --appdata ./appdata --apply` (원본 .bak 백업 생성)
- 안전장치: 적용 수가 예상(7)과 다르면 중단, 대시류 방어, 멱등(재실행 시 0건이면 안전 종료).
- 검증 완료: 테스트 appdata 에서 7건 정확 적용, u 만 변경·나머지 불변, 백업 생성, 무관 라운드 불변.
- 변경 표: unit_unify_changes.csv.

## 2) 고아 동형 4건: 처분안
라운드에서 한 번도 쓰이지 않는 동형(forms) 개념코드 4개. 모두 고체 결정 전도성/녹는점 개념이며
동형 문항의 과학적 정확성은 이미 검증 완료(무오류).

| code | 개념 | sub-form 수 |
|---|---|---|
| CH2-095 | 이온 결정 전도성 | 15 |
| CH2-101 | 공유 결정 녹는점 | 10 |
| CH2-105 | 다이아몬드 전도성 | 15 |
| CH2-107 | 금속 전도성 | 7 |

- 성격: 이들은 라운드가 fetch 하지 않는 '미사용 재고'다. 앱이 접근하지 않으므로 버그를 일으키지 않는다.
- 선택지 A(권장): 그대로 둔다. 내용이 정확한 동형 풀이라 향후 CH2 '고체' 단원 라운드에 바로 투입 가능한 대기 자산.
- 선택지 B: 지금 활성화하려면 특정 CH2 라운드의 '고체' 단원에 편입(문항 추가/교체)해야 하며,
  어느 라운드에 넣을지·기존 문항 교체 여부는 출제자 판단 사항이라 자동 편입하지 않았다.
- 결론: 삭제할 필요 없음. 방치해도 무해하고, 원하면 즉시 활성화 가능.

## 요약
- 63건은 정상(과목 공통) -> 무대응. 7건만 통일 대상 -> unit_unify.py 로 안전 적용 가능(채점 무영향).
- 고아 동형 4건은 무해한 대기 자산 -> 유지 또는 활성화(선택).
