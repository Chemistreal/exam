# DT 정답 외부 대조 (옵션 3) - 과학적 정확성 검증 (2026-07-07)

## 방법론: '외부' 기준의 정의
DT의 OX 문항은 조준모T 자작 콘텐츠로, 공식 정답표가 존재하지 않는다.
따라서 단원평가(KMChC 기출)처럼 '공식 정답표 대조'는 불가능하다.
대신 '외부 기준'을 **확립된 화학 지식(고교 화학 I·II + 일반화학 표준)**으로 삼아,
각 진술의 참/거짓이 라벨(O/X)과 과학적으로 일치하는지를 전수 검증했다.
(O 라벨 = 참인 진술이어야 하고, X 라벨 = 거짓인 진술이며 교정문이 옳아야 한다.)

## 범위
- 본 문항 2,760개 → 고유 진술 1,786개(중복 진술은 1건으로 병합; 같은 진술의 라벨은 전 회차 동일함을 옵션2에서 확인).
  * 화학I 848 · 화학II 626 · 일반화학 312.
  * O 라벨 1,136 · X 라벨 650 (동일 진술이 O와 X로 갈린 경우 0건).
- 1,786개 전수를 단원 순서로 검토.

## 결과: 과학적 오류 0건
- 검토한 1,786개 진술 전부에서 라벨(O/X)이 확립된 화학과 일치.
- O 진술은 모두 참, X 진술은 모두 실제로 거짓이며 교정문(f)도 정확.
- 계산이 필요한 문항(스펙트럼 전이 에너지비, 결정 단위세포 부피·자리수, 몰 질량/농도, pH, 결합차수 등)도 수치까지 검산해 일치.

### 검산으로 확인한 대표 고난도 항목(정확)
- 수소 스펙트럼: 2→1 : 4→1 전이 에너지비 = 4:5, 4→1 : 4→2 = 5:1 (E ∝ 1/n_f² − 1/n_i²로 검산).
- 결정구조: bcc 단위세포 질량 2M/NA·부피 64r³/3√3, hcp 부피 24√2 r³, fcc 사면체자리 8·팔면체자리 4.
- VSEPR/혼성: XeF₂ 직선·I₃⁻ 직선·ClF₃ T자·SF₄ 시소, SF₆·XeF₄ sp³d² 등 전수 일치.
- 열역학: ΔU=q+w에서 팽창 시 w<0, 열역학 3법칙(0K 완전결정 S=0), K>1 ↔ ΔG°<0.
- 전기화학: E°cell=E°(환원)−E°(산화), 평형서 E=0·Q=K, 갈바니 산화전극=(−).
- 핵화학: α(A−4,Z−2)·β⁻(A불변,Z+1)·β⁺(Z−1)·γ(불변), 핵자당 결합E는 Fe 부근 최대.
- 다양성자산 적정: H₃A 제1당량점 pH=(pKa₁+pKa₂)/2, 제2당량점 주화학종 HA²⁻.
- 배위화학: 강한장 리간드→큰 Δ→저스핀, 킬레이트가 한자리 리간드보다 안정, 흡수광의 보색이 관찰색.

## 신뢰도와 한계 (정직 고지)
- **신뢰도 상**: 위 1,786개의 절대다수는 고교/일반화학의 명백한 표준 사실이라, 판정에 이견의 여지가 거의 없다.
- **교육과정 관례 의존 항목**: 일부는 표기·관례에 의존한다. DT는 한국 교육과정 관례를 일관되게 사용하며, 그 관례 안에서 모두 정확하다. 예:
  - STP를 0°C·1기압=22.4 L로 사용(IUPAC 1982 개정판 0°C·100kPa=22.7 L이 아니라 한국 교과 관례). 대상 학습자 기준으로 옳음.
  - 기체상수 R=0.082, CsCl을 '단순입방'으로 기술 등 - 모두 표준 교과 관례와 일치.
- 이 검토는 'Claude의 화학 검토'이며 공식 인증이 아니다. 관례가 갈릴 수 있는 극소수 경계 사례의 최종 판단은 출제자(조준모T)가 하는 것이 바람직하나, **이번 검토에서 관례와 무관하게 틀린 항목은 발견되지 않았다.**
