# kch1to3-b Q11 재채점 안내 + 스크립트 (2026-07-07)

## 배경
- 감사(3중 대조 헤더=키=풀이결론 + 검산)에서 kch1to3-b(화학1 1-3단원 모의고사 동형)의
  11번 채점키가 4(4) -> 1(1)로 확정 정정됨. (index.html 라이브 반영 완료: Q_KCH13B Q11=1, sol 페이지 "정답 1")
- 남은 결정: 구글 시트에 이미 저장된 과거 응시 기록을 정정 키로 재채점할지 여부.

## 권고
- **재채점 권장.** Q11에 1(1)로 답했던 응시자는 정답인데 오답 처리되어 3점을 부당하게 잃었고,
  4(4)로 답했던 응시자는 오답인데 정답 처리되어 3점을 부당하게 얻었습니다. 성적표 공정성상 정정이 맞습니다.
- 영향은 Q11 응답이 1 또는 4인 기록에 한정(각 +3 / -3점). 2·3·미응답은 무변동.

## 스크립트: regrade_kch1to3b_q11.py
구글 시트를 CSV/TSV(또는 xlsx)로 내보낸 파일을 입력받아, kch1to3-b 행만 골라 Q11 정정을 반영합니다.

### 하는 일
- '시험' 열이 "화학1 1-3단원 모의고사 (동형)"(또는 kch1to3-b/1-3+동형)인 행만 대상.
  * 동형이 아닌 원본 "화학1 1-3단원 모의고사"는 문구로 구분해 제외.
- '답안(60)' 열의 11번째 글자(Q11)를 보고:
  - 1 -> 원점수 +3, 맞은개수 +1
  - 4 -> 원점수 -3, 맞은개수 -1
  - 그 외 -> 변동 없음
- 백점환산 = 원점수/만점*100 으로 재계산.
- 백분위·석차·전체누적인원은 '코호트 전체 재순위'가 필요하므로 건드리지 않고, 영향 인원만 표시.
  (점수가 바뀐 인원이 있으면 순위가 소폭 이동합니다. 필요 시 전체 재순위는 별도 요청.)

### 사용법
    # 1) 분석만 (아무것도 안 바꿈)
    python regrade_kch1to3b_q11.py sheet_export.csv --dry-run
    # 2) 정정본 생성 (원본 보존, *_regraded.csv 로 저장)
    python regrade_kch1to3b_q11.py sheet_export.csv

### 입력 준비
- 구글 시트 '성적기록' 탭을 파일 -> 다운로드 -> CSV(또는 TSV/xlsx)로 내보내기.
- 헤더는 백엔드와 동일해야 함:
  시험, 학생이름, 공유링크, 저장시각, 수험번호, 응시일, 학교, 학년,
  원점수, 만점, 백점환산, 백분위, 석차, 전체누적인원, 맞은개수, 영역별 득점, 답안(60)

### 반영
- 정정본에서 바뀐 열(원점수/백점환산/맞은개수)을 확인 후 시트에 붙여넣기.
- 원본은 스크립트가 건드리지 않습니다.


### 재순위까지 함께 반영 (--rerank)
백분위·석차·전체누적인원까지 정정 점수 기준으로 다시 계산하려면:

    python regrade_kch1to3b_q11.py sheet_export.csv --rerank

- 앱과 동일한 rankPct 공식으로 kch1to3-b 코호트 전체를 재순위합니다(높은 점수=높은 백분위, 석차 1=최고점, 동점 0.5 가중).
- 전체누적인원 = 이 파일에 든 kch1to3-b 응시 수. 반드시 시트 '전체'를 내보내 적용하세요(부분 export면 순위가 그 부분 기준).
- 검증: 합성 코호트(동점 포함)로 백분위·석차·누적이 앱 공식과 정확히 일치함을 확인했습니다.

## 검증(스크립트 자체)
- 합성 시트(가점/감점/무변동/비대상 각 케이스)로 라운드트립 검증 완료:
  Q11=1 -> +3(원점수·백점환산·맞은개수 정확), Q11=4 -> -3, Q11=2/미응답 -> 무변동, 비대상 시험 -> 무시.

## 참고 결정 사항
- 재순위(백분위·석차)까지 시트에 반영하려면 코호트 전체를 다시 정렬해야 합니다. 원하시면 재순위 포함 버전도 만들 수 있습니다.
- 이미 학부모에게 배포된 과거 성적표(공유 HTML/인쇄본)는 소급 수정되지 않습니다. 필요 시 해당 인원만 재발행 권장.
