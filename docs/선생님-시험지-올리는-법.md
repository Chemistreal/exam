# 선생님이 만든 시험지를 올리는 법

`tools/ingest_teacher_exam.py` 가 받아들인다. **Word 한 파일이면 된다.**
올리면 문항 크롭 60장 · 회차 항목 · 답지가 만들어지고, 그 학생 링크로 바로 열린다.

    final-submit.html?exam=<시험id>

---

## 1. Word 를 이렇게 쓴다

**문항마다 번호로 시작하는 줄이 하나 있으면 된다.** 그 줄을 찾아 그 앞에서 자른다.

```
1. 다음 중 옳은 것은?
   ① …  ② …  ③ …  ④ …

2. 그림은 …
   (그림)
   ① …  ② …  ③ …  ④ …
```

번호 꼴은 다음을 다 알아본다 — 문단 **맨 앞**에 있어야 한다.

    1.    1)    [1]    문제 1    Q1    1번

■ 지켜야 하는 것 셋

1. **번호는 1부터 빠짐없이 이어진다.** 12번이 없으면 그 자리에서 멈추고 알려 준다.
2. **한 문항이 두 쪽에 걸쳐도 된다.** 쪽을 넘어가면 넘어간 만큼 이어 붙인다.
3. **정답을 시험지에 적지 않는다.** 학생이 보는 종이다. 정답은 아래 ②로 준다.

■ 안 해도 되는 것

- 글꼴·여백·표·그림 — 아무거나 써도 된다. 보이는 그대로 잘라 쓴다.
- 문항 사이 빈 줄 — 있어도 없어도 된다.

---

## 2. 정답을 주는 법 (셋 중 하나)

**(가) 명령줄로** — 가장 간단하다.

    --key 3142313424...        (60자, ①②③④ 를 1234 로)

**(나) Word 맨 끝에 「정답」 줄로**

```
정답
1 ③   2 ①   3 ④   4 ②   …
```

또는 `③①④②…` 처럼 이어 붙여도 된다.

**(다) 딴 파일로** — `--key-file 정답.txt` (숫자만 60자, 줄바꿈 무시)

■ 복수 정답·전원정답

    --multi "7=1,3  23=2,4"     7번은 ①③ 둘 다 정답
    --void 34,41                34·41번은 전원정답 (삭제된 문항)

---

## 3. 영역·유형 (있으면 좋고 없어도 된다)

없으면 성적표의 **영역별 성취**와 **약점 진단**이 안 나온다. 채점과 등급은 그대로 나온다.

**(가) Word 안에 적기** — 문항 번호 줄 끝에 대괄호로.

```
7. 다음 중 … [산과염기 / 완충용액]
```

**(나) 딴 파일로** — `--areas 영역.tsv`

```
1	원자모형	전자배치
2	주기율	이온화에너지
```

영역 이름은 `final.html` 의 RX·RXMAP 에 있는 것을 쓴다.
없는 이름을 쓰면 `tools/area_tag.py --check` 가 잡는다 — 그때 알려 준다.

---

## 4. 해설 (나중에 줘도 된다)

시험을 먼저 올리고 해설은 뒤에 붙여도 된다. 해설이 없으면 성적표 오답노트에
문항 그림과 정답만 뜨고, 「왜 틀렸나」 한 줄이 빈다.

**해설 Word 를 따로** — `--sol 해설.docx`
문항 번호로 나뉘어 있으면 같은 규칙으로 잘라 붙인다.

---

## 5. 올리면 이렇게 돈다

```bash
# ① 먼저 재어만 본다 — 몇 문항으로 잘랐는지, 어디가 이상한지
python3 tools/ingest_teacher_exam.py 김지성_파이널.docx \
    --exam final2-s1e3u232r0e5 --for s1e3u232r0e5 --title "파이널 2차 · 김지성"

# ② 괜찮으면 심는다
python3 tools/ingest_teacher_exam.py 김지성_파이널.docx \
    --exam final2-s1e3u232r0e5 --for s1e3u232r0e5 --title "파이널 2차 · 김지성" \
    --key 314231342413... --write
```

심으면 이렇게 생긴다.

    crops/<시험id>/1.png … 60.png     문항 그림 (가로 955px, 기존 회차와 같은 규격)
    answers/<시험id>.json             정답·영역·유형 (해설을 주면 그것도)
    teacher-exams.json                회차 항목 (exams.json 이 아니다 — 아래 참조)

■ 왜 `exams.json` 이 아닌가

이 저장소의 검사들은 「exams.json 의 모든 회차는 문제지 PDF·공식 해설지·기준
기록을 다 갖춘 공개 회차」라는 계약을 수십 곳에서 강제한다. 선생님이 만든
시험지는 그 계약 밖이다(공식 정답 PDF 도 없고 또래 기준 기록도 없다).
그래서 `teacher-exams.json` 에 따로 두고, 화면 셋이 목록과 별개로 읽어
**직링크로만** 연다. 목록·예비본·계수 검사는 흔들리지 않는다.
학생별 파이널(`student-finals.json`)과 같은 자리다.

## 6. 심은 뒤 확인하는 것

```bash
python3 tools/ingest_teacher_exam.py --check      # 크롭 수·정답키 길이·답지 짝
python3 tools/area_tag.py --check                 # 영역 이름이 화면에 있는 것인가
python3 tools/js_syntax.py --check                # 화면이 안 깨졌는가
```

그리고 브라우저로 한 번 열어 본다 — 문항이 60장 다 뜨는지, 답을 넣고 제출하면
성적표가 나오는지. (이것을 자동으로 하는 자가 `tests/teacher-exam.js` 다.)

---

## 7. 자주 어긋나는 자리

| 증상 | 까닭 | 손보는 법 |
|---|---|---|
| 문항을 12개밖에 못 찾았다 | 번호가 문단 맨 앞이 아니다(들여쓰기·표 안) | 번호를 줄 맨 앞으로 빼거나 `--marker` 로 꼴을 알려 준다 |
| 크롭 아래가 잘렸다 | 다음 번호가 같은 줄에 있다 | 문항 사이에 줄바꿈을 넣는다 |
| 그림이 흐리다 | Word 안 그림이 저해상도 | 원본 그림을 다시 넣는다(크롭은 4배로 뜬다) |
| 영역이 안 붙는다 | 이름이 RX·RXMAP 에 없다 | `--areas` 로 주거나 화면의 이름을 쓴다 |

---

## 8. 한 시험지를 여러 학생에게

    --for s1e3u232r0e5,s6h5o00163f6,s2p0c114x5f2

학생마다 **따로 회차를 만든다**(`<시험id>-<코드>`). 크롭은 한 벌만 두고 srcmap
으로 함께 본다 — 같은 그림을 열세 벌 복사하지 않는다.
