## §0 이 배치가 안고 시작하는 것 셋

1. **정답 편차 1 을 되돌린다.** 은행이 ①522 ②523 ③523 ④522 이므로 ①3 ②2 ③2 ④3 으로
   짜 **①525 ②525 ③525 ④525 — 편차 0** 을 만든다.
2. **★4s·3d 소재를 쉬게 한다.★** T13 안에서 이미 여덟 자리다(P11 M02074·M02077,
   P12 M02084·M02085·M02086·M02090 …). 이번 배치에는 **한 자리도 넣지 않는다.**
3. **★C·D 분기를 늘린다.★** P10·P11·P12 가 연속으로 1문항에 그쳤다. P12 가 배운 규약 ㉮ —
   *오답이 C 의 암기 사실을 명시적으로 부정하면 방아쇠가 아니라 경보기가 된다. C 를 잡는
   오답은 C 가 아는 절차를 끝까지 정직하게 따라갔을 때 도착하는 지점이어야 한다.*
   그 꼴로 **세 자리**를 깔았다(§2).

## §2 ★C 를 떨어뜨리는 자리 셋 — 이번에는 '부정형' 을 쓰지 않는다★

P12 에서 불발한 넷은 모두 **오답이 C 의 지식을 정면으로 부정하는 문장**이었다.
이번 셋은 반대다 — **C 가 아는 규칙을 그대로 적용하면 오답에 도착한다.**

| ID | C 가 아는 것 | 그것을 그대로 적용하면 | 도착하는 오답 |
|----|--------------|------------------------|---------------|
| M02095 | 훈트 규칙 — p⁴ 는 홀전자 둘 | 발문이 준 **그림**을 보지 않고 규칙으로 센다 | ② 2개 |
| M02096 | mₛ 가 +1/2 인 전자는 전체의 절반 | 홀전자가 있으면 **절반이 깨진다** | ① 3개 · ② 4개 |
| M02099 | 들뜸은 에너지가 높은 상태 | '가깝다' 를 **에너지 크기**로 재려 한다 | ③ 2p 가 꽉 찬 배치 |

**세 자리 모두 오답이 "C 의 규칙을 지킨 결과" 다** — C 는 자기 지식과 충돌하는 것을 보지
못하므로 경보가 울리지 않는다. D 는 발문의 단서(그림 · 홀전자 · '한 전자만')를 읽고 규칙을
그 자리에서 멈춘다.

## §6 금지 축 확인

- **★4s·3d 는 한 자리도 쓰지 않는다★**(§0-2). 전이금속·예외 원소(Cr·Cu)도 없다.
- l < n 을 **정답 축**으로 쓰지 않는다(P3) — M02093·M02100 은 판정 도구로만 쓴다.
  ▸ M02093 은 'l = 2 가 있으려면 n 은 최소 얼마' 로 **역산**을 묻지 'l < n 이다' 를 묻지 않는다.
- 거리·핵전하·가려막기·침투 **없음** · 오비탈의 공간 배향 표기 **없음** · f 조합을 오답으로
  **쓰지 않음**(M02094 는 f 가 **정답**이고, M02092 는 l = 3 을 발문이 준다).
- 수소/다전자 대비 **없음**(P12 가 세 자리를 썼다) · 이온 **없음** · 축약 표기는 M02097 하나.
- 상자그림 **없음** — M02095 는 괄호 표기로 세 오비탈만 적는다.

## §7 배치 안 겹침 검사

- **l 의 값과 부껍질 기호를 오가는 자리 넷**(M02092 l=3 → 개수 · M02093 l=2 → n · M02094
  mₗ=−3 → f · M02100 (n,l) 판정) — 재는 것이 각각 다르다(개수 / 최소 n / 부껍질 이름 /
  실현 가능 여부). 다만 **★조판에서 넷을 붙이지 말 것★** 이고 순회에서 재판정받을 것.
  ▸ 특히 **M02093 과 M02100 은 같은 규칙(l ≤ n−1)을 쓴다** — 앞엣것은 역산, 뒤엣것은 판정.
    P12 에서 같은 짝(M02082·M02089)이 '누설 아님' 판정을 받았으나 이번에도 물어볼 것.
- **홀전자를 세는 자리 둘**(M02095 훈트를 어긴 배치 · M02096 mₛ 세기) — 앞은 그림을 보고
  세고 뒤는 배치를 세운 뒤 스핀으로 가른다. **M02096 은 홀전자의 스핀을 발문이 못 박는다.**
- **전자 수가 같은 배치 여럿을 늘어놓는 자리 하나**(M02099) — M02095 와 달리 그림이 없다.
- 원소가 나오는 자리 셋(M02095 황 16 · M02096 질소 7 · M02097 염소 17) — 겹치는 값 없음.
- **네 양자수를 정면으로 다루는 자리**가 P11·P12 보다 많다(M02091·M02093·M02094·M02096·
  M02098·M02100) — 테마가 '양자수·전자배치' 이므로 범위 안이나, **순회에서 난도 쏠림을
  물어볼 것.**
