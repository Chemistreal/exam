# T4 동위원소 — 정식 착수 문서 (F1, 소급)
현황: 24제 병행 등재 상태에서 소급 착수. 잔여 140제(≈28턴). 근거: lec-001 + 파이널 교재 T4 + 기출 '동위' 36히트.

## 1. 경계 조항 (theme_boundaries 반영)
- **T4 소유**: 동위 정의·성질(화학同/물리異), 평균 원자량 전 유형(계산·역산·지렛대·범위·다종),
  존재비(→개수·시료불변·역비), 동위 조합물(분자 '종류 수'·질량수 조합 — Cl₂ 3종 등 교재 단골),
  원자량 기준(¹²C)·발견 서사(²²Ne류), 동중·등중성자와의 대비 판별
- **금지(타 테마)**: 방사성 붕괴·반감기(→T11, lec-010 함정군 전부 이관), 확산 속도(→T31),
  몰·아보가드로(→T5: '평균 분자량'은 질량수 합 평균으로만 우회), 동소체(→T2), 전자배치 근거 성질(→T13)
- **허용 회색지대 판례**: 분자 종류 수 세기=조합 산수라 T4 ✓ / 질량분석 '원리'는 정성 서사까지만 ✓

## 2. 오개념 지도 (lec-001 + 제작 실적 기반)
핵심축: "세 갈래(동위·이온·평균) 혼동" — 강의가 명시한 단원 병소
① A↔n 혼동(동중을 등중성자로) ② 개별↔평균(35.5 원자 실재 착각) ③ %↔개수 미환산
④ 단순평균 vs 가중 ⑤ 존재비 짝 뒤바꿈 ⑥ 지렛대 방향(먼 쪽=다수) ⑦ 질량差→성질差
⑧ '동위=쌍둥이'(존재비까지 동일 착각) ⑨ 역비 미적용(질량↔개수) ⑩ 범위 밖 평균 허용
⑪ 조합 종류 과소/과대(중복 처리) ⑫ 원자량=질량수 용어 혼동

## 4. 신규 시나리오 풀 (32각, 파동 F2~F13 광맥)
**계산 확장(12)**: 4종 평균 / 2미지 연립(비율+A 동시) / 특정 동위 '기여분'(부분합) / 두 시료 혼합 평균 /
개수 변화→평균 이동량 / 3점 지렛대(가운데 미지) / 미량 3종(1% 포함) / 평균→비 정수해 조건 /
역·역산(평균과 한 A로 다른 A 범위) / 차등 표본(n개 중 k개 교체) / 소수 둘째자리 정밀 역산 / 검산식 오류 찾기
**분자 조합(5)**: Cl₂ 종류 수(3) / 질량수 스펙트럼(70·72·74와 비 1:?:?는 확률 경계 — '종류'까지만) /
HCl 4종 / H₂O 동위 조합 수 / 최중·최경 조합 차
**개념·판정(8)**: 용어 4진술(원자량vs질량수) / 표기 관례 오류 / 3×3 관계 매트릭스 채우기 /
6종에서 동위 쌍 전수 / 존재비 그래프 해석(막대) / 자연·인공 구분 없는 '안정' 서술 / 유비 2(역방향) / 소수부=0 원소의 의미(단일 동위!)
**서사·첨삭·역설계(7)**: 가중 계산 첨삭(부분정오) / 평균 논쟁 대화 / 발견 서사 2(중수소) /
'단일 동위원소' 원소 실례(F·Na — 원자량 정수 근접!) / 혼합 후 재분리 사고실험 / 채점형 / 모순 판정(존재비 합≠100)
