# 감사 15호 — Opus 4.8 단독 체제 전환 + 기계적 자기감사 프로토콜 확립
사용자 지침: "앞으로 Opus 4.8만 사용, Fable 5 불가. Opus로 Fable급 품질 달성."

## 문제 정의(정직한 진단)
감사 14호(Fable)가 실증: Opus 자기감사는 **계산·경계·파서층은 무결하나 '자기복제 판정층'에서 체계적 관대**
(거울 M785·M864, 보완값 M810을 스스로 승인). 편향은 같은 모델의 '더 엄격하자'는 결심으로 교정 불가.
→ 독립 모델이 사라진 상태에서 Fable급을 달성하려면 **판단을 기계적 신호로 대체**해야 함.

## 해결: selfaudit.py (기계적 자기복제 감사기)
신규 문항 각각을 '이전 전체'와 대조, 구조 충돌 시 기본값을 △로 강제(hostile-reviewer default).
- R1 동일 scenario / R2 동일 skill / R3 골격+정답값 동일(거울·교체) / R4 골격+linked(워크호스) / R5 보완값 짝(complement)
- ★검증: 감사14가 손으로 잡은 M785(R3+R5)·M810(R5)을 기계가 재현. M864는 scenario 재명명 후 R1로 포착★

## 본 감사 결과(T6 M823~M887 전수 기계 스캔)
기계 적발 3건(Opus 생산 모드가 놓친 T5↔T6 교차 중복):
- **M848↔M707**: skill·scenario·구조 완전 동일(STP 부피+질량→몰질량 역산), 숫자만 → △(유지, 기록)
- **M878↔M696**: 같은 기체·같은 정답(24), 몰수만 2배(평균 불변) near-mirror → ★교체★(불균등 몰수 O₂+CO₂, 정답 41)
- **M833↔M684**: 같은 개념(몰질량 큰 기체=밀도 큼), 프레임만 → △(유지, 기록)
판정: 교체 1 + △ 2. 계산·경계·켈빈층 무결 유지(감사13 재확인). ✗ 0.

## ★신 프로토콜 v3.0 — Opus 단독 자기감사(즉시 발효)★
1. **매 배치**: 등재 직후 `selfaudit.py <배치범위>` 실행. R1/R2/R3/R5 충돌 = 기계적 △ → 근거 제시 또는 교체(housekeeping 전 필수 단계로 편입).
2. **주기 감사**: (a) 계산 재검증(expr eval+SN 수동) (b) selfaudit 전 테마 범위 (c) 경계·켈빈·파서 점검 (d) 기계가 못 잡는 개념거울 hostile 수동 패스.
3. **scenario 명명 규율**: 표면 스토리가 아니라 '인지핵(물리/계산 구조)'으로 명명 → 거울이 R1으로 충돌하게. (M846·M864 = '일정부피 가열 압력증가'로 통일 완료)
4. **감사14 판례 3종 유지**, 이제 도구로 강제: 마감 잔여구간 표준감사 / 거울·보완값 창무관 △ / 자기복제 판정층 기계 재심.

## 정직한 한계(사용자 인지 필요)
독립 모델(Fable) 감사가 엄밀히 우월했음. Opus 단독 = 자기복제 잔여 위험을 완전히 0으로 못 만듦.
기계 도구(R1~R5)+인지핵 명명+hostile 수동 패스로 **최대한 근접**시키되, 도구가 못 잡는 '표면 완전히 다르나 인지적으로 동일' 케이스는 잔존 가능. 이를 감수하고 운용.
