## 2. 사전 배분 — 저작 전에 못 박는다

**정답 차례** `② ④ ① ③ ② ④ ③ ① ④ ②`
- 개수 ①2 ②3 ③2 ④3. 은행이 1970 제에서 ①493 ②492 ③493 ④492 이므로
  병합 뒤 **①495 ②495 ③495 ④495 — 편차 0**. 1980 제에서 가능한 최선이다.
- G3d(주기 2~5) 통과 · G3e(한 번호가 등간격 3 회) 통과.
- **G3f(경계 넘김)** — 앞 배치 꼬리 여덟 자리(③②④①③②①②)를 이어 붙여도
  등차 4 연속이 서지 않는다. 가장 긴 것이 간격 5 로 ② 세 번(문턱 미만).

**길이순위** `1·3·4·1·3·4·2·3·4·1` → 1위 3 · 2위 1 · 3위 3 · 4위 3.
최근 100 제가 18 / 34 / 31 / 17 로 2 위가 높으므로 이번 배치는 2 위를 하나만
둔다. 병합 뒤 2 위 비중이 내려간다.

## 3. 문항별 함정 설계 — (ㄱ)(ㄴ)(ㄷ)(ㄹ) 를 자리마다 적어 둔다

- **M01971** (ㄴ)의 핵심. "4s 가 3d 보다 낮다" 를 외운 B 가 **반드시 틀린다** —
  반발이 없으면 n 이 작은 3d 가 낮다. 오답 셋은 (가) 4s 그대로, (나) 같다,
  (다) 전자 수에 따라 다르다 로 도착지가 갈린다.
- **M01972** 선지 넷을 전부 `l ≥ n` 유형으로 채우지 말 것. `2s³`(정원 초과)와
  `2d¹`(오비탈 부재)를 섞어 **사유까지 물어야** 2 단이 된다.
- **M01973** mₗ = +2 는 l ≥ 2 를 강요한다. n = 4 에서 l = 2, 3 두 오비탈 → 4 개.
  l = 0, 1 도 센 학생은 8, 오비탈 하나로 본 학생은 2 에 도착한다.
- **M01974** 세 규칙이 각각 다른 선지로 간다 — (ㄱ)을 구조적으로 만족하는 자리.
  ★87쪽 파울리 삽화는 자료로 쓰지 말 것★ (본문과 모순). 파울리 위반은
  '같은 오비탈에 같은 방향 화살표 둘' 로만 제시한다.
- **M01975** ★Fe²⁺/Fe³⁺ 를 쓰지 말 것★ — 교재 본문에 답까지 실려 있어 암기
  우회로가 열린다. Mn²⁺ 로 s 우선 제거를 실제로 수행하게 한다.
- **M01976** (ㄴ)을 가장 강하게 막는 각도. 두 갈래·2 개를 그대로 답하면 오답.
  ★교재가 '수소 원자살' 로 서술했으므로 은 원자를 언급하지 말 것.★
- **M01977** "수소는 축퇴, 나머지는 갈라짐" 으로 단순화한 학생이 He⁺ 에서
  틀린다. He 는 갈라지고 He⁺ 는 축퇴다.
- **M01978** ★Cu 를 half-filled 로 설명하면 안 된다★ (89쪽 캡션 결함).
  두 원소를 같은 근거로 묶은 선지가 곧 함정이다.
- **M01979** 32 = 2n² → n = 4 → s2 + p6 + d10 + f14. 32 를 M껍질로 오인하면
  n = 3 이 나온다. 쉬움 등급 한 자리.
- **M01980** 전자 수를 그대로 원자 번호로 읽으면 전하만큼 어긋난 원소에 도착한다.
  ★선지 넷 가운데 둘은 교재 실례 밖 원소로 둘 것★ — 낯익은 이름으로 찍는 것을 막는다.

## 4. 저작 중 반드시 다시 볼 것 — T12 마감이 남긴 검사

1. **포함 관계** — 오답 넷에 '하나가 참이면 다른 하나도 참' 인 쌍이 없는가.
   있으면 내용을 몰라도 둘이 함께 지워진다. ★함의를 받는 쪽(결론)을 고칠 것.★
2. **이질항** — 정답만 혼자 낱말·형식이 다르지 않은가.
3. **관용 서술** — 오답이 엄밀히는 거짓이어도 **교과서가 흔히 쓰는 느슨한
   서술로 읽으면 참**이 되지 않는가. T12 마감에서 이 유형이 세 번 나왔다.
4. **암기 구호** — 한 줄("l = 0 이면 s", "n = 3 이면 3 개", "전이금속은 s 부터")로
   오답이 무더기로 지워지지 않는가. 정답과 **같은 대역·같은 유형의 오답**을
   최소 하나 동거시킬 것.
5. **누출** — 열 문항의 발문에 나오는 모든 수치·배치·관계식을 뽑아, 한 문항이
   다른 문항의 계산 단계나 함정을 대신해 주지 않는가.
   ★조치 뒤에도 이 검사를 다시 돌릴 것 — T12 마감에서 8차·9차·11차의 수정이
   각각 다음 회차의 지적을 만들었다.★
6. **자가진단 줄** — 본문이 단 조건을 요약 줄이 떼어 내지 않았는가.
   T12 마감에서 네 건이 이렇게 걸렸다.
7. **정답 자리를 옮겼다면** 본문에 박힌 옛 번호가 남았는지(`audit()`).
