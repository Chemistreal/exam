## 1. ★쪽수 예산★ — 착수 전에 반드시 셈할 것

T12 에서 얻은 교훈이 여기서 곧바로 걸린다.

> **테마 착수 시 (교재 쪽수 × 개념당 각도 수) 가 목표 제수를 넘는지 먼저 셈할 것.**

T13 은 **9쪽**이다. T12 의 16쪽보다 훨씬 얇다. 판독으로 뽑은 출제 가능 개념은
**24개**(에너지 준위 4 · 배치 원리 4 · 양자수 4 · 표기와 계수 4 · 상태 판별 4 · 이온과 예외 4).

    164 ÷ 24 ≈ 6.8

곧 **개념당 7~8 각도**가 필요하다. T12 는 2차 확장 뒤에도 개념당 4~6 각도였다.
처음부터 7~8 로 잡고 시작해야 하며, 그래도 모자라면 **개념 사이를 잇는 각도**
(예: '훈트를 어겼는가 파울리를 어겼는가를 가르기', '같은 배치를 양자수 넷으로
다시 쓰기')를 별도 층으로 세워야 한다. 이 층은 T12 에서 가장 좋은 문항이 나온
자리이기도 하다.

## 2. 교재가 못 박은 값 (문항 대조의 근거)

**양자수**
- n = 껍질. K L M N O = 1 2 3 4 5
- l = 오비탈 종류. s p d f g = 0 1 2 3 4
- mₗ = −l … 0 … +l. s:0 / p:−1,0,+1 / d:−2..+2 / f:−3..+3
- mₛ = +1/2 (up) · −1/2 (down)
- 허용 조건 l < n, |mₗ| ≤ l · 한 오비탈 최대 2개

**에너지 준위**
- 수소(일전자계): `1s < 2s=2p < 3s=3p=3d < 4s=4p=4d=4f`
- 다전자계: `1s < 2s < 2p < 3s < 3p < ★4s < 3d★ < 4p`
- 갈라짐의 까닭 = 전자 간 반발 (교재 명시)

**전자배치 (90쪽 정답표 — 전자수 검산 전량 통과)**

| 원소 | 배치 | 원소 | 배치 |
|---|---|---|---|
| O | [He]2s²2p⁴ | Au | [Xe]4f¹⁴5d¹⁰6s¹ |
| Mg | [Ne]3s² | Fe | [Ar]3d⁶4s² |
| P | [Ne]3s²3p³ | Fe²⁺ | [Ar]3d⁶ |
| Mn | [Ar]4s²3d⁵ | Fe³⁺ | [Ar]3d⁵ |
| Sn | [Kr]4d¹⁰5s²5p² | | |

**예외** ₂₄Cr [Ar]4s²3d⁴ ⇒ [Ar]4s¹3d⁵ (half-filled subshell rule) ·
₂₉Cu [Ar]4s²3d⁹ ⇒ [Ar]4s¹3d¹⁰

**실험** 슈테른-게를라흐 — 수소 원자살이 두 갈래로 갈라짐 → 전자에 두 스핀 상태.

**실측 앵커** 교재 기출 정답률: 139:56% / 140:59% / 141:47% / 142:40% / 143:36% /
144:64% / 145:74% / 146:삭제 / 147:47% / 148:22% / 149:81% / 150:48% / 151:81%.
난이도 배분의 실측 기준으로 쓸 것. **148(22%)이 최저, 149·151(81%)이 최고.**

## 3. ★교재 자체의 결함 — 문항화 금지 목록★

T12 에서 "교재를 충실히 따랐다는 것이 사실 검증을 대신하지 못한다" 를 비싸게
배웠다. 이번에는 착수 전에 적어 둔다.

1. **[87쪽 · 심각]** 파울리 배타원리 ① 본문은 "한 오비탈에 최대 2개" 인데 바로 아래
   삽화의 오른쪽 상자에 **화살표가 3개(↑ ↓ ↑)** 그려져 있다. 붉은 X 도 양쪽 상자의
   위 방향 화살표에만 찍혀 있어 "왼쪽=금지 / 오른쪽=허용" 대비가 성립하지 않는다.
   → 이 삽화를 근거로 한 문항을 만들지 말 것.
2. **[89쪽 · 중간]** `half-filled subshell rule` 캡션이 Cr 예시에만 붙어 있고 바로 아래
   **Cu(3d¹⁰ = fully-filled)** 예시에는 규칙 이름이 없다. 학생이 캡션을 두 예시 공통으로
   읽으면 잘못된 규칙을 적용하게 된다. → Cu 를 half-filled 로 설명하는 해설 금지.
3. **[90쪽 · 경미]** 같은 표 안에서 `Mn [Ar]4s²3d⁵`(4s 먼저)와 `Fe [Ar]3d⁶4s²`(3d 먼저),
   `Sn [Kr]4d¹⁰5s²5p²`(4d 먼저)로 **표기 순서가 뒤섞여** 있다. 값은 모두 정확하다.
   → **표기 순서를 정답의 근거로 삼지 말 것.** 순서를 묻는 문항을 낼 거라면 발문에서
   규약(에너지 순 / 껍질 순)을 명시할 것.
4. **[86쪽 그림 2 · 주의]** 마델룽 도표의 세로축이 '에너지' 인데 상자는 껍질(n)별 행으로
   놓여 있어 4f 가 6s 보다 아래, 5f 가 7s 보다 아래에 그려져 있다(실제 채움 순서는
   6s < 4f, 7s < 5f). 차이가 3~4 px 이고 대각선 화살표는 옳으므로 단정하지는 않되,
   **이 그림의 세로 위치를 에너지 순서의 근거로 쓰지 말 것.**
5. **[93쪽 · 문항 설계 결함]** 기출 148 은 "**들뜬** 산소 원자 중 가장 안정한 것" 을 묻는데
   선지 ① 이 산소의 **바닥상태**(1s²2s²2p⁴, 훈트 만족)다. 발문과 선지가 어긋난다.
   → 같은 프레임을 베끼지 말 것. 낸다면 "들뜬 상태끼리 견주라" 를 발문이 못 박아야 한다.
6. **[91쪽 · 오탈자]** 기출 139 선지 ① "원자는 전자 원자핵으로 구성" — 조사 누락.
7. **[93쪽 · 원문 유래 사실 오류]** 기출 147 지문 "동맥에서는 Fe²⁺, 정맥에서는 Fe³⁺" —
   실제 헤모글로빈의 철은 동맥·정맥 모두 Fe²⁺ 이고 Fe³⁺(메트헤모글로빈)는 산소 운반
   불능 상태다. → **이 설정을 발문에 쓰지 말 것.** Fe²⁺/Fe³⁺ 를 다루려면 맥락 없이 이온만
   쓸 것.

## 4. ★T13 부터 강제할 설계 규약★ (T12 마감 sim 순회에서 얻은 것)

T12 마감 14제의 실측이 이 규약을 낳았다. **A 0 / B 10 / C 11 / D 14** —
C=D 가 11 인 것보다 **B 와 C 가 1 점 차**라는 쪽이 나빴다. 14 중 9 문항이
B=C=D=정답, 곧 A 만 걸러 내는 1 비트짜리 문항이었다.

- **(ㄱ) 오답 경로의 도착지가 정답과 '다른' 선지인가.** 잘못 든 길이 되돌아와 정답에
  도착하면 변별이 0 이다.
- **(ㄴ) 1단계를 건너뛰는 암기 우회로가 없는가.** T12 M01968 은 문턱이 705.9 nm 라
  가시/적외 경계와 겹쳐, "가시광선은 들뜨게 하고 적외선은 진동만 시킨다" 를 외운
  학생이 **아무것도 계산하지 않고** 정답에 닿았다.
- **(ㄷ) 변별이 '지식'인가 '주의'인가.** "표를 끝까지 훑었는가", "묻는 방향을 놓쳤는가"
  로 갈리는 변별은 반복하면 씻겨 나간다. **주의형은 배치당 1~2 개로 묶고**, 나머지는
  틀린 판단이 **다른 값**을 낳는 지식형으로 짤 것.
- **(ㄹ) 저작 단계에서 B 와 C 의 예상 점수를 갈라 볼 것.** C=D 보다 **B≈C 가 먼저
  오는 경보**였다.

T12 에서 유일하게 지식형이었던 갈림은 M01960 ② — '5↔6 이 6↔∞ 보다 좁다' 는
준위 구조에 관한 **사실**이라서 주의력으로 메울 수 없었다. 이것이 본이다.

T13 에서 이 조건을 가장 잘 만족할 것으로 보이는 자리:
- **4s < 3d 인데 이온화하면 4s 부터 빠진다** — 두 사실이 서로 어긋나 보이므로 암기로는
  일관되게 적용되지 않는다. 틀린 경로가 다른 배치를 낳는다.
- **일전자계에서는 축퇴가 되살아난다(He⁺·Li²⁺)** — 다전자계 순서를 외운 B 가 반드시
  틀린다.
- **어느 규칙을 어겼는가(쌓음/훈트/파울리)를 가르기** — 세 규칙이 각각 다른 선지로
  간다. (ㄱ)을 구조적으로 만족한다.
- **양자수 넷의 허용 조건을 조합으로 묻기** — l < n 과 |mₗ| ≤ l 이 서로 다른 오답을 낳는다.
