# T2 원자의 크기 — 정식 착수 문서
근거: 교재 T2(9~12쪽) + T1 인계(반지름·주기성 유보분) + 기출 '반지름/크기' 교차. 목표 164제(≈33턴).

## 1. 경계 조항 (theme_boundaries 반영)
- **T2 소유**: 원자 반지름 정의·측정 개념 / 주기적 경향 2축(같은 주기 →감소, 같은 족 ↓증가) /
  유효 핵전하(가리움·껍질 수로 반지름 설명) / 이온 반지름(양이온<원자, 음이온>원자, 그 이유) /
  등전자 이온 '크기' 비교(양성자 많을수록 작음) / 크기 대소 순서 배열·판정
- **금지(타 테마·봉인)**:
  · 입자 수(p·n·e 계산)·동위원소·질량수 → **T1·T4 봉인**(크기 논증에 필요한 최소 전자 수만 인용)
  · 이온화 에너지·전기음성도·전자친화도 → 별도 테마(크기와 상관은 정성 언급까지만, 수치·주기표 금지)
  · 전자 배치 상세(오비탈·s p d)·양자수 → T13류(껍질 '수'까지만, 부껍질 금지)
  · 몰·아보가드로 → T5 / 결합·분자 크기 → 결합 단원 / 동소체 → 해당 없음(T2 아님, 교재 확인)
- **회색지대 판례(선제)**:
  · 등전자 이온 크기 비교 = T2 ✓ (T4는 '등전자인가?' 관계 판정 / T2는 '어느 게 큰가?' 크기) — 축 분리
  · '유효 핵전하'는 정성 개념(=실제 느끼는 당김)까지 ✓, Slater 규칙 등 정량 계산 ✗
  · 반지름 '수치'(pm) 제시는 비교용 상대값까지 ✓, 절대 암기 강요 ✗

## 2. 오개념 지도 (크기 단원 병소)
① 주기 방향 반전(→ 갈수록 커진다고 오해 — 실제 감소) ② 족 방향 반전 ③ '전자 많으면 크다'(핵전하 무시)
④ 양이온이 크다는 착각(전자 잃으면 작아짐) ⑤ 음이온이 작다는 착각(전자 얻으면 커짐)
⑥ 등전자에서 '전자 같으니 크기 같다'(양성자 수 무시 — 핵 당김 차이) ⑦ 껍질 수와 핵전하 효과 혼동
⑧ 주기·족 경향 충돌 시 판단 불가(대각선 비교) ⑨ 유효 핵전하=실제 양성자 수 혼동(가리움 무시)
⑩ 반지름 정의 오해(단일 원자 경계 불명 → 실제는 결합 기준) ⑪ 큰 원자=무거운 원자 착각(크기≠질량)
⑫ 이온 크기 변화를 '질량' 변화로 오귀속

## 3. 금지 수치·소재 (블랙리스트 계승 + T2 추가)
- **계승(T4)**: 63/65·70/72·50/52·62/64/66·100/102/104·Cl⁻ArK⁺·총수400·기약비3:1+400
- **T2 추가 주의**: 등전자 세트 O²⁻/F⁻/Na⁺/Mg²⁺/Al³⁺(교재 단골 — 초반 남용 금지, 분산 배치) /
  주기 2·3 대표 원소(Li~Ne, Na~Ar) 나열형 반복 회피 / 반지름 실측 pm값 특정 수치 반복 금지
- numpair_scan 전 테마 누적 대조 유지(T1·T4 수치와 자동 충돌 검사)

## 4. 신규 시나리오 풀 (파동 F1~ 광맥, 약 30각)
**주기 경향(8)**: 같은 주기 2개 대소 / 같은 족 2개 대소 / 주기+족 결합(대각선 판정) /
  경향의 '이유'(핵전하 vs 껍질) 판정 / 3원소 크기 순서 배열 / 유효 핵전하 대소 / 껍질 수 같을 때 판정 / 주기표 위치→크기 추론
**이온 반지름(8)**: 원자 vs 그 양이온 / 원자 vs 그 음이온 / 양이온·음이온·원자 3자 순서 /
  등전자 이온 크기 대소(양성자 기준) / 등전자 3~5종 순서 배열 / 같은 원소 여러 이온(전하별) 크기 /
  이온화 시 크기 변화 방향·이유 / 등전자에서 크기 최대/최소 색출
**개념·판정(8)**: 반지름 정의·측정 방식 / '전자 많음≠큼' 판별 / 크기≠질량 판별 /
  유효 핵전하 정의(가리움) / 경향 그래프(주기별 반지름) 해석 / 대소 진술 정오 / 크기 결정 요인 종합 / 등전자 크기 원리
**서사·역설계·첨삭(6)**: 크기 비교 논쟁 대화 / 잘못된 크기 추론 첨삭 / 순서 배열 채점형 /
  주기표 빈칸 원소 크기 추정 / 모순 판정(경향 위배 주장) / 두 축 충돌 사례 해소

## 5. 분포 목표 (164 도달 시)
