## 3. 검증 순회가 잡은 것 — ★값이 큰 여덟 자리★

순회에서 나온 지적은 모두 **판정 단계**를 지나 조치되었다(고침/오탐을 가른다).

| 문항 | 무엇이었나 | 왜 값이 컸나 |
|---|---|---|
| **M02765** | '고리가 그대로 남았으니 치환' 이라는 **판별 잣대 자체가 틀렸다** | 첨가 생성물도 고리를 지닌다(벤젠 + 3H₂ → 사이클로헥세인). 첨가로 깨지는 것은 고리의 연결이 아니라 **고리 안의 겹결합**이다. 정답은 맞는데 문항이 틀린 것을 가르치고 있었다 |
| **M02753** | **정답 선지가 방향을 거꾸로 지목**했다 | '넘치는 쪽' → '모자란 쪽'. 정답 쪽 결함은 순회 없이는 드러나지 않는다 |
| **M02754** | 오답 '생성물 개수로는 가릴 수 없다' 가 **잣대를 다투는 문면**이었다 | 개수 잣대는 교과서 줄이지만 다중 치환·1,4-부가에서 흔들려 변호가 늘 선다. **잣대를 다투는 문면은 오답으로 못 쓴다** |
| **M02762** | 은행 설명이 자기 자료와 어긋났다 | 네오펜테인 9.5 ℃ > n-뷰테인 −0.5 ℃ |
| **M02761** | 오답 ②가 실제로 참에 가까웠다 | '결합의 극성은 잴 수 없다' — 단평이 무엇이 틀렸는지 말하지 않아 층 혼동을 굳혔다 |
| **M02766** | 오답 ①에 **배타성이 없어** 참으로 읽혔다 | '산소가 모자라도 똑같은 것이 나온다' → 그 둘도 여전히 나온다. 배타 독법은 ②가 '만' 으로 이미 맡고 있었다 |
| **M02759** | '포화는 수소가 더 붙는 상태다' 가 **두 갈래로 읽혔다** | '(불포화보다) 더 많이 붙어 있는' 으로 읽으면 참. **가능은 '수 있다' 로 문면에 박는다** |
| **M02772** | 반박 '그런 물질은 없어' 가 과했다 | 하이드로늄 이온은 산·염기 단원에서 실제로 배운다 |

## 4. 다음 테마가 가져갈 것

1. **오답의 배타성·가능성은 문면에 박는다** — 배타는 '만', 가능은 '수 있다'. 없으면 변호가 선다.
2. **잣대를 다투는 문면은 오답으로 못 쓴다** — 잣대 자체가 틀린 문면으로 옮긴다.
3. **판별 근거를 한 번 더 읽는다** — 정답이 맞아도 근거가 틀리면 문항은 틀린 것을 가르친다(M02765).
4. **범위 밖 규약에 기댄 변호는 오탐이다** — 고온 기체 NaCl 단분자 · IUPAC 전자 친화도 표기 ·
   멀리컨 척도 · 라디칼 치환. 판정 단계에서 이것을 가르지 않으면 조치가 문항을 더 나쁘게 만든다.
5. **조치한 범위는 반드시 한 순회 더 돈다** — 이 테마의 조치 회차마다 새 흠이 한둘 났다.
