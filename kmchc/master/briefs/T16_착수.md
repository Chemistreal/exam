# T16 화학 결합 착수 — 개념 대장 C16-001~020 (각도 140)

## 1. 테마를 고른 까닭
교재 차례에서 T15(이온화에너지, 102~111쪽) 다음 구간이고, **주기적 성질에서 결합으로 넘어가는
자리**라 앞 테마의 개념(이온화 에너지·전자 배치·원자 반지름)을 그대로 딛는다.
★교재 PDF 가 작업트리에 없다★ — T15 와 같은 조건이므로 은행 대조와 교육과정 표준으로 세웠고,
쪽수는 T15 다음 구간(112~121)으로 잡았다. **교재를 펴 볼 수 있게 되면 대장을 먼저 맞댈 것.**

## 2. 대장의 짜임
| 묶음 | 개념 | 무엇을 담았나 |
|---|---|---|
| 왜 붙는가 | C16-001·002 | 결합의 에너지 부호 · 옥텟과 그 예외 |
| 세 결합 | C16-003~008 | 이온·공유·금속 각각의 정의와 성질, 그리고 셋을 가르는 잣대 |
| 표기와 극성 | C16-009~012 | 전자점식 · 결합의 극성 · 전기음성도 · 차와 결합의 성격 |
| 세기와 셈 | C16-013·014 | 결합 에너지와 길이 · 반응열 어림 |
| 모양과 분자 | C16-015~018 | 분자의 모양 · 분자의 극성 · 분자 사이의 힘 · 수소 결합 |
| 되돌리기 | C16-019·020 | 성질에서 결합으로 · 자주 어긋나는 세 갈래 |

## 3. ★이 테마에서 미리 못 박아 둔 함정 일곱★
T15 가 열여섯 배치를 치르며 얻은 것을 **저작 전에** 대장 note 로 올렸다.
1. **결합의 극성과 분자의 극성은 다른 층이다**(C16-010·016) — 극성 결합만으로 분자가 극성이
   되지 않는다. 이 둘을 섞은 오답이 이 단원에서 가장 흔하다.
2. **분자 안의 결합과 분자 사이의 힘**(C16-017) — 얼음이 녹을 때 끊어지는 것은 분자 사이의
   힘이지 산소·수소 결합이 아니다.
3. **옥텟은 예외가 많다**(C16-002) — 오답에 '언제나' 를 붙이면 곧바로 거짓이 되므로 전칭이
   오답 쪽에만 몰리지 않게 한다.
4. **공유 결합 물질의 낮은 녹는점은 분자 결정에만 선다**(C16-006) — 다이아몬드·석영은 그물
   구조라 매우 높다. 이 예외를 오답으로 쓰면 ★그 오답이 참이 된다★.
5. **전기음성도와 이온화 에너지는 다른 양이다**(C16-011) — T15 C15-023[1] 과 맞물린다.
6. **전기음성도 차의 경계는 뚜렷한 선이 아니다**(C16-012) — 문턱값을 문면에 쓰지 않는다.
7. **한 성질만으로는 결합을 되돌릴 수 없다**(C16-019) — 녹는점만으로는 이온 결합과 그물 구조
   공유 결합이 갈리지 않는다.

## 4. 저작 규약 — T15 에서 값을 치른 여섯 줄을 그대로 잇는다
㉠ 오답 셋이 같은 오류 유형을 나눠 갖지 않게 한다
㉡ 오답의 근거절을 참으로 두지 않는다(참이면 거짓이 결론절 하나에 걸려 F1 이 된다)
㉢ 정답이 발문의 어구를 되받지 않게 하고 단정형과 유보형을 섞는다
㉣ 뜻·길이·어미·극성을 한 묶음으로 잡는다 — ★정답만 부정형★ 을 처음부터 본다
㉤ '이 자료만으로는 알 수 없다' 형은 한 배치에 하나만
㉥ 교과가 참으로 가르치는 명제를 오답에 두지 않는다
㉦ 정답 자리는 앞 배치의 꼬리까지 이어 본다(G3e·G3f·G3h 가 겹쳐 걸린다)

  표로 주는 값은 처음부터 상댓값이나 실명으로 통일해 익명과 섞지 않는다.
- **병합과 같은 자리에서 각도를 박는다** — `link_t16_pN_concepts.py` 를 배치마다 함께 쓴다.
