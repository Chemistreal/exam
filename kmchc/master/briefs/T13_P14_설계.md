## §4 선지 격자를 먼저 그렸다 (P10 ㉮ · P11 ㉲)

- **M02102** (방향: 변화 없음 / 방출 / 흡수) × (근거: 축퇴 / 갈라짐) — 정답만 '변화 없음'
  이므로 **근거 축을 오답에도 달아** 방향 축의 다수결(방출·흡수 둘)이 답을 지목하지 않게 한다.
- **M02103** 네 도표가 **어긴 규칙 하나씩** — 위반 없음 / 훈트 / 파울리 / 쌓음.
  P12 M02087 의 규약대로 **칸 구분은 대괄호**로 하고 발문에 '대괄호 하나가 오비탈 하나'
  라고 적는다. 네 도표의 **전자 수를 모두 같게** 맞춘다.
- **M02106** (어느 표기가 불가능한가) × (근거가 무엇인가) — 반쪽만 맞은 오답이 이 복합
  구조에서만 나온다. P12 M02083 이 같은 꼴로 성공했다.
- **M02107** 네 화학종의 **전자 수를 흩고** 홀전자 수만 묻는다 — 개수로 답이 새지 않게.
- **M02109** ㉠·㉡ 조합형 — **두 축이 모두 살아 있어야 4택**(P11 ㉲). ㉠ 축은 0 대 10,
  ㉡ 축은 0 대 2 로 두어 **㉠·㉡ 합이 같은 칸을 하나 만든다**(합만 세는 우회로 차단, P13 ㉮).
- **M02101 · M02105 · M02108 · M02110** 은 수치 선지라 §5 에서 따로 본다.

## §7 배치 안 겹침 검사

- **★같은 규칙을 나눠 쓰는 자리 넷 — P13 ㉰ 가 경고한 꼴이다★**
  · 2n² → M02101 · 2(2l+1) → M02105 · Σ(2l+1) = n² → M02108 · l ≤ n−1 → M02106
  ▸ **M02105 와 M02108 이 가장 위험하다** — 둘 다 2l+1 을 거친다. **M02108 은 n = 3 으로
    두어 l = 3 이 등장하지 않게 하고**(1 + 3 + 5 = 9), M02105 는 l = 3 을 발문이 준다.
    묻는 것도 정원(×2) 대 조합 총수로 다르다. **순회에서 반드시 물을 것.**
  ▸ M02106 의 해설이 **2l+1 이나 2n² 을 끌어오지 않게** 할 것 — 근거는 l ≤ n−1 하나다.
- **홀전자를 세는 자리 둘**(M02103 훈트 판별 · M02107 역방향) — 앞은 도표를 보고 어긴
  규칙을 지목하고 뒤는 수를 주고 화학종을 찾는다. **M02107 에 도표를 주지 말 것.**
- **전자배치를 발문이 적어 주는 자리 셋**(M02104 Fe · M02110 Cr · M02103 도표) —
  M02104·M02110 은 이온·예외로 갈리고 M02103 은 도표다. 다만 **★조판에서 셋을 붙이지
  말 것★** 이고 순회에서 재판정받을 것.
- 원소가 나오는 자리 셋(M02104 철 26 · M02107 미정 · M02110 크로뮴 24) — M02107 의
  화학종은 **26·24 와 겹치지 않게** 고를 것.
- **에너지 비교가 나오는 자리는 M02102 하나**다 — P12 가 세 자리를 썼으므로 쉬게 한다.

**★설계와 달라진 것 다섯★**

1. **M02102 의 각도를 C13-001[3] → [6] 으로 옮겼다.** '에너지가 같은 오비탈 집합 고르기'
   는 수소에서 *에너지가 같다 = n 이 같다 = 앞자리 숫자가 같다* 이므로 **앞자리가 서로
   같은 선지가 곧 정답**이 되어 화학 없이 짚였다. '왜 같은가' 를 묻는 문장 선지로 다시 지었다.
2. **M02104 선지를 3d·3s·4p·4s 로 흩었다.** 처음의 3s·3p·3d·4s 는 셋이 3 이고 하나만 4 라
   **다수결 이탈이 정답을 그대로 가리켰고**, 에너지 오름차순이라 **배열을 깨는 하나가 정답**
   이기도 했다.
3. **M02109 ㉠ 을 (n=2, l=2) → (n=1, l=1) 로 옮기고 ㉡ 축을 2/10 으로 벌렸다.** 앞엣것은
   M02106 과 대입값이 겹쳐 앞 문항이 뒤 문항의 존재 판정을 끝내 버렸기 때문이고, 뒤엣것이
   **A·B 분기를 열었다.**
4. **M02110 발문에 '오비탈에 들어 있는' 을 넣었다.** sim 이 낸 한 낱말 제안으로,
   **A·B 분기 하나와 죽은 선지 하나를 함께 되살렸다.**
5. **정답 자리를 세 번 옮겼다** — §9 참조.

## §9 조치 이력과 이번 배치가 세운 규약

### 조치가 낳은 결함 — F2 둘이 모두 내 1차 조치에서 나왔다

| 문항 | 무엇을 고쳤나 | 그래서 무엇이 생겼나 |
|------|---------------|----------------------|
| M02102 ② | 공허참을 막으려 '전자끼리 밀어내는 힘이 두 오비탈에서 서로 똑같기' 로 | **수소에서 0 = 0 이라 참**이고 해설이 세운 인과까지 그대로 타서 **정답과 같은 논증**이 됐다 |
| M02103 ③ | sim 의 '[↑↑] 는 즉시 탈락' 을 받아 [↑][↓] 로 | 교과가 쓰는 훈트의 문면이 **'홀전자 수가 최대'** 라 [↑][↓] 도 훈트를 지킨 것이 되어 **정답과 동급** |

▸ 둘째 자리는 **매력도(sim)와 F2(defender)가 맞부딪힌 첫 사례**다. 규칙대로 F2 를 따랐다.

### 정답 자리를 세 번 옮겼고 그때마다 다음 패턴이 나왔다

1. 처음 배열(④ 가 4·9) → 앞 배치의 ④ 와 이어져 **간격 5 의 등차 넷**(G3f)
2. M02107↔M02109 맞바꿈 → M02101 을 ④ 로 올리자 **④ 가 1·4·7 등간격**(G3e)
3. M02107 을 ① 로 내림 → 4~7번이 **④③②① 완전 내림 계단**(solver)
4. M02107 을 원자 번호 내림차순으로 다시 깔아 ③ 으로 → 닫힘

▸ **한 자리를 옮기면 배치 전체의 자리 분포를 다시 봐야 한다. 고치는 손이 다음 신호를 만든다.**

### P13 규약 ㉮ 가 이 배치에서 세 번 걸렸다

*한 줄을 고쳤으면 그 문항의 네 문단을 다시 읽을 것* — 바로 다음 배치에서 세 번 어겼다.
1차의 F1 둘(정답 자리를 맞바꾸며 해설 본문의 번호를 안 고침), 4차의 M02107(본문만 낮추고
도입·마무리·자가진단에 옛 주장을 남김)과 M02104(자가진단에만 한정어를 붙임).
▸ **조치는 문장이 아니라 문항 단위로 한다.**

### ★내 반려 근거가 틀린 적이 한 번 있다★

### P15 로 이월

1. **정답 ①④ 를 셋씩** 두어 편차 0 을 되돌린다(지금 ①527 ②528 ③528 ④527).
2. **C·D 는 (ㄴ)을 채택 기준으로 삼는다.** (ㄱ)은 필요조건일 뿐이므로, 자리를 고를 때
   ***표면에 먼저 나오는 기호·숫자가 오답 규칙을 먼저 부르는가*** 를 묻는다. 그리고
   **오답 규칙의 결과값이 반드시 선지에 실물로 올라와** 있어야 하며, **정답 규칙의 위반
   사례를 옆 선지에 나란히 진열하지 말 것**(M02103 처럼 대조가 생기면 함정이 꺼진다).

   복합 요구)을 **발문에** 한 겹 더 얹고 **그 미교집합 값을 선지로 세운다.** 한정어는 선지
   문면이 아니라 발문에 두어야 한다.
4. **머리명사 대비('전자 수' 대 '오비탈 수')는 B 를 재지 못한다** — 그 자리는 C 만 가른다.
   B 를 노린 자리에 이 꼴을 쓰지 않는다.
