## §6 금지 축 확인

- l < n 을 **정답 축**으로 쓰지 않는다(P3) — M02082·M02089 는 l < n 을 **판정 도구**로
  쓰되 정답이 'l < n 이다' 라는 진술 자체는 아니다.
- 거리·핵전하·가려막기·침투 **쓰지 않음** — M02088 은 오직 '전자끼리 밀어냄' 으로만 적는다.
- '4s 가 3d 보다 높다' **쓰지 않음** — M02085 ③ 과 M02090 은 교재대로 4s < 3d 로 적는다.
- 오비탈의 공간 배향(2p_x 등) **없음** · f 조합을 오답으로 **쓰지 않음** · 포함 관계 **없음**.
- 훈트에 ↑↑ 대 ↑↓ 비교 **없음** — M02087 의 ↑↑ 는 **한 오비탈 안**의 파울리 위반이다.
- 전이금속은 한 자리뿐이고 **심화** 로 표시했다(최종은 구리 29 · Z ≤ 30 안).

## §9 조치 이력과 이번 배치가 세운 규약

### §9.1 설계 목표의 성적 — C 함정 다섯 중 하나

§2 에서 C 를 떨어뜨리는 자리를 다섯 깔았다. **작동한 것은 M02086 하나다.**

| 자리 | 결과 | 까닭 |
|------|------|------|
| M02084 축퇴의 범위 | 불발 | 축퇴는 C 에게 훈트와 한 몸이라 전제로 박혀 있다 — **함정이 C 의 강점 위에 놓였다** |
| M02086 홀전자 자리 | **발동** | 스칸듐 → 구리로 바꾼 뒤. 아래 참조 |
| M02088 인과와 수소 반례 | 불발 | 정답지가 인과를 또렷이 서술해 C 가 소거만으로 통과 |
| M02089 정원 초과 대 부재 | 불발 | 네 표기가 쓰인 그대로는 모두 불가능해 조건을 다시 읽게 된다 |
| M02090 정원과 차례의 어긋남 | 불발 | 오답 셋이 모두 C 보다 아래 수준의 오개념 |

**student-sim 이 실패의 공통 양식을 정식화했다** —
> 오답이 C 의 암기 사실을 **명시적으로 부정하는 문장을 포함하면 방아쇠가 아니라 경보기가
> 된다.** C 를 잡는 오답은 **C 가 아는 절차를 끝까지 정직하게 따라갔을 때 도착하는
> 지점**이어야 한다.

M02086 이 정확히 그 자리다. 쌓음원리대로 채우면 4s²3d⁹ 이라 홀전자가 3d 에 있고,
실제 바닥상태는 4s¹3d¹⁰ 이라 4s 에 있다 — **C 가 규칙을 정확히 굴릴수록 오답에 닿는다.**
처음 두었던 스칸듐(21)은 예외 원소가 아니라 방아쇠가 아예 없었다.

### §9.3 마감 때 반려한 것 셋

- **M02086 을 갈륨·칼륨으로**(solver·defender · defender 는 F2) — 갈륨은 Z ≤ 30 을 넘고
  칼륨은 예외가 아니라 방아쇠가 사라진다. Cr·Cu 예외는 교재 89쪽이 명시하고 대장 C13-020
  으로 등재돼 있으며 트랙도 심화다. **무엇보다 실측이 확인한 유일한 C 변별점이다.**
- **M02090 ④ 를 C 함정으로 다시**(sim) — sim 스스로 낸 대안도 '까닭이 아니라 C 가
  멈춘다' 고 평가했고, ④ 는 죽은 선지도 아니다.
- **M02089 오답 셋의 동일 유형** — 위첨자로 살릴 수 있는 경우가 '정원 초과' 뿐이다.

**이월** — sim 이 M02085·M02087·M02088 을 경합 구조로 갈아 끼우라고 권했다. D 가 전항
정답이고 F2 도 0 인 자리에서 세 문항을 다시 짜는 것은 멈춤 규칙에 걸리므로, 제안한 구조
(Cr 의 4s¹3d⁵ 를 훈트와 충돌시키기 · 채움 순서 대 에너지 순서의 역전)를 **P13 의 자리
선정 원칙**으로 옮긴다.

### §9.5 이 배치가 고친 도구 — 정답 길이순위의 분모

- **동률을 순위로 세고 있었다.** 정답과 길이가 같은 보기가 있으면 '몇 번째로 긴 것' 을
  짚을 수 없어 순위가 성립하지 않는데, 목록 차례로 순위를 매겨 **길이가 넷 다 같은
  문항까지** 특정 순위로 집계했다. 은행 2,080제 중 순위가 실제로 정의되는 것은 325제뿐.
- **그 325제에서 1위·4위가 정확히 0% 였다.** G3 가 정답의 유일 최장·유일 최단을 막으므로
  남는 자리는 2위와 3위 두 갈래뿐이고 **기대값은 1/4 이 아니라 1/2** 이다. 종전 임계
  (0.35 ⚠ / 0.50 🔴)는 4분할 가정 위의 눈금이라 균등조차 편중으로 잡았고, 동시에 동률이
  1·4위로 흩어져 실제 쏠림을 희석했다 — **두 오차가 서로를 가려 왔다.**
- master_gate.py · batch_template.py · build 의 저작 점검을 2분할 기준으로 고쳤고,
  게이트 창을 '순위가 정의되는 최근 100제' 로, 배치 검사에는 표본 하한 4 를 넣었다.
  현재 실측 2위 63% : 3위 37% — 2분할 기준 균등 범위.
