## §2 ★이번 배치의 첫째 목표 — C 를 떨어뜨리는 자리를 다섯 만든다★

P10 · P11 모두 **C·D 분기가 1문항**에 그쳤다(RESUME 남은 약점). C 프로필은
'채움 순서와 정원은 알되 **예외·수소/다전자의 차이·규칙 경합**에서 흔들린다'.
그 세 갈래를 정면으로 쓰는 자리를 다섯 깔았다.

| ID | C 가 흔들리는 지점 | C 가 고를 만한 오답 |
|----|--------------------|---------------------|
| M02084 | 축퇴가 **어디까지** 인가 — 껍질까지인가 부껍질까지인가 | ① 2s 와 2p(껍질만 같음) |
| M02086 | 4s²3d¹ 에서 **어느 자리가 홀전자인가** | ③ (4, 0) — 마지막에 적은 4s 를 홀로 봄 |
| M02088 | 갈라짐의 **인과 방향** 과 수소 반례 | ④ 수소에도 아주 작게 갈라져 있다 |
| M02089 | 정원 초과와 **오비탈 부재** 를 가르기 | ① 2s³ — 눈에 띄는 정원 초과를 고름 |
| M02090 | 2n² 과 **주기 끝 원소** 가 어긋나는 까닭 | ③ 식이 맞지 않는다 |

**세는 것이 아니라 가르는 것을 묻는 자리** 다섯이다. B 는 여기서 전멸하고, C 는
'안다고 생각하는 것' 이 어디까지인지 시험받는다.

## §4 선지 격자를 먼저 그렸다 (P10 ㉮ · P11 ㉲)

- **M02082** (㉠ 부껍질 종류 수 3/4) × (㉡ l 의 최댓값 2·3/3·4) — 완전격자.
  ㉠3㉡2 / ㉠3㉡3 / **㉠4㉡3** / ㉠4㉡4. 두 축이 모두 살아 있다.
- **M02083** (오비탈 이름 3d / 3p / 없다) × (같은 부껍질의 오비탈 수 5 / 3).
- **M02084** (무엇이 같은가: n 만 / l 만 / 채움 순서 / **n 과 l 둘 다**) — 한 축 네 칸.
- **M02087** (규칙: 위반 없음 / 쌓음 / 훈트 / **파울리**) — 한 축 네 칸.
- **M02088** (인과: 정방향 / 역방향 / 부정 / 정도) — 한 축 네 칸.

## §6 금지 축 확인

- l < n 을 **정답 축**으로 쓰지 않는다(P3) — M02082·M02089 는 l < n 을 **판정 도구**로
  쓰되 정답이 'l < n 이다' 라는 진술 자체는 아니다.
- 거리·핵전하·가려막기·침투 **쓰지 않음** — M02088 은 오직 '전자끼리 밀어냄' 으로만 적는다.
- '4s 가 3d 보다 높다' **쓰지 않음** — M02085 ③ 과 M02090 은 교재대로 4s < 3d 로 적는다.
- 오비탈의 공간 배향(2p_x 등) **없음** · f 조합을 오답으로 **쓰지 않음** · 포함 관계 **없음**.
- 훈트에 ↑↑ 대 ↑↓ 비교 **없음** — M02087 의 ↑↑ 는 **한 오비탈 안**의 파울리 위반이다.
- 전이금속은 스칸듐(21) 하나뿐이고 **심화** 로 표시했다.

## §7 배치 안 겹침 검사

- **인(15)이 나오는 자리 하나**(M02081) — M02086 은 스칸듐(21)으로 갈랐다.
- **4s 와 3d 의 선후가 나오는 자리 셋**(M02085 정렬 · M02086 홀전자 자리 · M02090 누적합) —
  M02085 는 **대소를 진술로** 묻고, M02086 은 **배치에서 자리를** 묻고, M02090 은 **주기 끝
  원소와의 어긋남** 을 묻는다. 재는 것이 다르다. 다만 ★조판에서 셋을 붙이지 말 것.★
  ▸ P11 M02077(채움 순번)·M02074(K 의 4s)와도 소재가 겹친다 — **T13 안에서 4s·3d 는
    이미 다섯 자리다. P13 부터는 이 소재를 쉬게 할 것.**
- **상자그림은 M02087 하나뿐** — P10 M02065 와 같은 꼴이므로 ★조판에서 칸 구분이
  뭉개지지 않게 할 것★(P10 이 남긴 주의).
- **부껍질 종류 수를 세는 자리 둘**(M02082 n=4 의 l 값 · M02083 같은 부껍질의 오비탈 수) —
  세는 대상이 다르다(부껍질 종류 대 한 부껍질 안의 오비탈). 순회에서 재판정받을 것.
- 수소는 M02088 에 반례로만 나온다 · 축약 표기 없음 · 이온 없음.
