# T9 양적관계 — 착수 문서 (아홉째 테마)
## 메타: unit="III", theme="양적관계", tt=9. 교재 51~56쪽 (T8 계수 맞추기 다음, T10 원소 기원 57쪽 직전)

## ★범위 (교재 51~56쪽 실물 근거)★
계수 맞추기(T8)를 '이용한 실제 계산'으로 확장:
- **계수비 = 몰수비 이용**: 한 물질의 몰수 → 다른 물질의 몰수 (반응물↔생성물, 반응물↔반응물)
- **몰수 → 질량**: 몰수 × 몰질량 (T6 몰질량을 반응식 맥락에서 적용)
- **질량 → 몰수 → 질량**: 주어진 반응물 질량 → 몰수 → 계수비 → 생성물 몰수 → 질량 (3단계 연쇄)
- **기체 부피 관계**: 같은 T·P에서 부피비 = 몰수비 = 계수비 (아보가드로 법칙 적용, 실제 L 계산)
- **몰부피**: 표준상태(STP) 기체 1몰 = 22.4 L → 몰수↔부피 환산
- **질량 보존 (라부아지에)**: 반응물 총질량 = 생성물 총질량 — ★역사·검증 실험 T9에서 정식 도입★ (T8은 명명·합차까지만)
- **반응물 부족(한계 반응물)**: 두 반응물 중 먼저 소진되는 쪽이 생성물 양 결정 (심화)

## mk() 도구 (T9)
- 계수비 = 몰수비 (무조건 성립) → 비례식으로 미지 몰수 계산
- 몰수 × 몰질량 = 질량 (g) | 질량 ÷ 몰질량 = 몰수
- 같은 T·P 기체: 부피비 = 몰수비 = 계수비 | STP: 1몰 = 22.4 L
- 질량 보존: Σ반응물 질량 = Σ생성물 질량 (라부아지에, 원자 보존이 근거)
- 3단계 연쇄: 질량→(÷몰질량)→몰수→(×계수비)→상대 몰수→(×몰질량)→질량
- 한계 반응물: 각 반응물 몰수 ÷ 계수 → 최소값 쪽이 한계 → 그 쪽 기준 생성물 계산
- 단위 주의: 몰(mol)·질량(g)·부피(L) 구별 | 계수비는 몰·부피에 직접, 질량엔 몰질량 경유
