## 6. 핵심 대비축 (T12 이후에도 유지할 것)

- 투과력 **α < β < γ** ↔ 전리 작용 **α > β > γ** — 두 서열이 반대인 뿌리는 **'얼마나 자주 부딪히나'** 하나(M01802에서 총괄)
- 전기장: α → (−)극 / β → (+)극 / γ 직진. **전하 부호 = 휘는 방향, 질량 = 휘는 정도**(별개 축)
- 질량 α ≫ β > γ = 0
- **β⁻(Z+1) ↔ β⁺(Z−1) = 전자포획(Z−1)**
- 질량수를 바꾸는 붕괴 = **α만** / 중성자가 느는 붕괴 = β⁺·전자포획
- **N/Z**: 가벼운 핵 N≈Z, 무거운 핵 N>Z → 중성자 과잉이면 β⁻
- 붕괴 속도는 **온도·압력·화학 결합·양 어느 것에도 무관** — 붕괴 수 ∝ 남은 수라서 반감기가 일정
- **투과력이 약하다 ≠ 안전하다** (α선 내부 피폭, M01765)
- 이용: 감마 = 투과(치료) / 알파 = 전리(연기 감지기) / **베타 = 중간 투과(두께 측정)**
- 반감기 요구는 용도에 따라 **정반대** — 진단용은 짧게, 연기 감지기는 길게
