# 자동 실행 계획 — 정해 두고 아직 등록하지 않음 (2026-10-28)

사용자 결정: **자동 실행 방식은 지금 정해 두고, 등록은 나중에 한다.**
이 문서는 등록할 때 그대로 따를 설계다. 등록 전까지는 사용자가 요청할 때마다 한 단위씩 진행한다.

---

## 1. 무엇을 등록하나

| 항목 | 정한 값 |
|---|---|
| 방식 | Claude Code Routine(예약 트리거) — **실행할 때마다 새 세션**(`create_new_session_on_fire`) |
| 주기 | 1시간마다(등록할 때 사용자가 바꿀 수 있다) |
| 작업 위치 | `Chemistreal/exam` · 브랜치 `claude/handoff-file-usage-bsdh9w` |
| 한 번 실행에서 할 일 | **작업 단위 하나**를 끝내고 커밋·푸시한 뒤 끝낸다 |

새 세션을 쓰는 까닭: 한 세션을 길게 이어 가면 대화가 요약되면서 맥락이 깎이고, 컨테이너가 바뀌면
스크래치패드가 사라진다. **매번 저장소만 보고 시작하면** 어느 실행이 끊겨도 다음 실행이 이어 받는다.

## 2. 매 실행의 순서(Routine 프롬프트에 그대로 넣는다)

1. **브랜치 맞추기** — `git fetch origin claude/handoff-file-usage-bsdh9w` 후 로컬이 그 커밋이 아니면
   `git checkout -B claude/handoff-file-usage-bsdh9w origin/claude/handoff-file-usage-bsdh9w`.
   새 세션이 `main` 복사본으로 시작하는 일이 실제로 있었다. **강제 푸시는 절대 하지 않는다.**
2. **대기열 읽기** — `kmchc/master/RESUME.md` 의 「다음 할 일 대기열」에서 맨 위 항목 하나를 집는다.
3. **한 단위 실행**(아래 3절).
4. **게이트** — `master_gate.py` · 해당 테마 감사 · `claimcheck.py` 가 모두 통과할 때만 커밋한다.
5. **기록** — 대기열에서 끝낸 항목을 지우고 새로 생긴 일을 넣은 뒤, 커밋 메시지에 바뀐 문항 id 를 적어 푸시한다.
6. 끝. 남은 시간이 있어도 다음 단위를 시작하지 않는다(한도에 걸려 반쯤 끝난 상태로 남지 않게).

## 3. 작업 단위(우선순위 차례)

| 차례 | 단위 | 끝의 기준 |
|---|---|---|
| ① | **판정 반영** — 판정 결과가 있으면 조치하고 `reprep` | 빗나감 0 · 게이트 통과 |
| ② | **순회** — 조치 뒤 아직 순회하지 않은 범위 최대 3개 | 결과를 `mkjudge` 로 판정 일감까지 만든다 |
| ③ | **판정** — ②가 만든 일감 | 고침/오탐 판정이 끝남 |
| ④ | **저작** — 진행 중 테마의 다음 배치(지시서 → 초안 → `draftcheck` → 병합 → 각도 링크) | 병합 · 감사 0건 |
| ⑤ | **새 테마 착수** — 개념 대장(`make_ledger`) · 지시서 | 대장 저장 |
| ⑥ | **옛 부채** — objective 채우기(일감 70개, 문항 1,742제) 등 | 한 묶음 반영 |

검증이 저작보다 앞선다 — 검증 부채를 쌓으면 조치 경로가 막힌다(patch_batch 의 교훈).

## 4. 지킬 것(이번 마디에서 값을 치르고 얻은 것)

- **동시 실행은 워크플로 3~4개까지.** 열 개를 띄웠다가 세션 한도에 걸려 판정 두 판·저작 세 판이
  한꺼번에 죽었다.
- **워크플로가 죽어도 초안은 저널에 남는다** — `subagents/workflows/<run>/journal.jsonl` 에서
  draft 결과를 건진다(P11·P14·P16 을 이렇게 살렸다).
- **마감 기준은 세 게이팅 동시 0건이 두 순회 연속.** 조치가 있었던 순회 뒤의 0건만 센다.
- **조치 뒤에는 반드시 `reprep`** — 낡은 검증 파일은 이미 고친 자리를 다시 지적한다.
- **판정 일감은 은행에서 새로 뽑는다**(`mkjudge`) — 판정자가 지금 문면을 본다.
- **초안이 흔히 안고 오는 흠**: 해설 번호를 아라비아 숫자로 · 되받이 열쇠를 줄여서 · 오답을 줄여
  인용(`fixquote`) · 빈 오답 · 정답을 자리표와 다른 칸에. 병합 전에 `draftcheck` 가 모두 잡는다.
- **검증자 프롬프트에는 늘** `/home/user/exam/kmchc/` 아래를 열지 말라는 금지를 넣는다(정답이 있다).
- 커밋 메시지·코드에 모델 식별자를 넣지 않는다. PR 은 만들지 않는다.
