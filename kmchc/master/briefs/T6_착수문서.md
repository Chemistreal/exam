# T6 기체 법칙(Gas Laws) 착수문서 — 여섯 번째 테마 [진행 중]
## unit="VII"(VII. 기체), theme="기체 법칙", tt=6. theme_order 6번. 교재 28~30쪽(이미지 30~32)
## 스코프: 보일 법칙·샤를 법칙·보일-샤를(결합)·기체 상태 방정식(PV=nRT)·돌턴 부분 압력·기체 밀도-몰질량

## ★경계(T5에서 봉인해 넘긴 영역 = T6 핵심):★
- 압력-부피 관계(보일): 일정 T·n에서 P₁V₁=P₂V₂
- 온도-부피 관계(샤를): 일정 P·n에서 V₁/T₁=V₂/T₂ (온도는 반드시 켈빈 K)
- 결합·상태방정식: P₁V₁/T₁=P₂V₂/T₂, PV=nRT
- 부분 압력(돌턴): 전체 압력 = 각 성분 압력의 합
- 비STP 조건 계산 (T5는 0 ℃·1기압 22.4 L 고정만)

## ★T5(몰)와의 경계:★
- 22.4 L/STP·몰↔부피 기본 환산은 T5 소관 → '값'으로 재사용 가능(예: STP 부피 계산)
- PV=nRT 변수 조작·비STP·법칙 간 관계는 T6 신영역
- 반응 부피비(계수)는 T9 소관 (T6는 물리적 기체 법칙만)

## mk() 상수(T6):
- 켈빈 변환: K = ℃ + 273 (계산 시 온도는 항상 켈빈)
- 보일: P₁V₁ = P₂V₂ | 샤를: V₁/T₁ = V₂/T₂ | 결합: P₁V₁/T₁ = P₂V₂/T₂
- 상태방정식: PV = nRT (R = 0.0821 L·atm/mol·K, 필요 시)
- 표준 상태: 0 ℃(273 K)·1기압에서 1몰 = 22.4 L (T5 승계 값)
