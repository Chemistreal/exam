## 4. 품질 게이트 규칙 (전부 자동 검사됨)

| 코드 | 규칙 | 조치 |

| **G3** | 정답이 **유일 최장 / 유일 최단** 선지가 되면 안 됨 | 오답 하나를 정답보다 **더 길게**(동률로는 부족) 확장 |
| **G6** | 수치 보기는 **오름차순** 배열, 지수 표기 금지 | 수치 보기 문항은 위치 **swap 금지**(순서 깨짐) |
| **R5** | 동일 계산 골격(`#//#` 등) + 두 정답값의 합이 10·100 → 보완값 의심 | 새 계산의 수치를 조정해 회피 |

| — | 오답 정확히 3개, 각각 `error`·`type`(proc/sign/surface) 태깅 | |

## 5. 판례 (지식 중복 차단 기준) — 작업의 핵심

새 문항이 기존 문항과 **정답 지식이 같으면** 프레임이 달라도 중복입니다.

| 판례 | 내용 | 예 |
|---|---|---|
| **①** | 테마 마감 시 전수 감사 의무 | 164제 전 문항 4층 감사 |
| **②** | **보완값 짝 금지** — 30%와 70%처럼 서로 보완인 답 | "남은 양" vs "붕괴한 양"을 같은 설정으로 |
| **③** | 소정수(1~6) 정답 동결 — 같은 작은 수가 반복되지 않게 | |
| **④** | 물질·단위·맥락·시점만 치환한 것은 **거울**(중복) | 단, **정답 지식이 상반**이면 정당 (β⁻ Z+1 ↔ β⁺ Z−1) |
| **⑤** | **단일 지식의 프레임 변주 금지** | 단, 복수 지식 동시 점검(종합 판별)·자료 표상 해석은 **조합 판단**이라 대상 외 |
| **⑥** | **비자명 산술 복제 금지** — 숫자만 바꾼 계산 | 반감기 계산은 반드시 **다른 sub-skill**로 |

**⑥의 실전 운용(T11에서 확립)**: 반감기·붕괴식 계산 15건을 전부 다른 sub-skill로 분리했습니다 —
`1회 잔량 / 비율→시간 / 시간→횟수 / 붕괴량 / 처음량 역산 / 여러 회 잔량 / 두 시점 비 / 질량수 균형 / 원자번호 균형 / 연속붕괴 순변화 / 계열 α횟수 / 계열 β횟수`.
새 계산을 넣기 전에 **이 목록에 없는 sub-skill인지** 먼저 확인하세요.

## 6. T11 방사성붕괴 현황 (100/164)

### 채굴 완료된 인지핵 골격 ①~⑩
기본·α붕괴·β붕괴·γ붕괴·3종 종합·반감기 개념·반감기 계산·양전자/전자포획/붕괴식/연대측정·62쪽 표 완성 + 붕괴식 심화·방사선 이용

### 핵심 대비축 (일관성 유지 필수)
- 투과력 **α < β < γ** ↔ 전리 작용 **α > β > γ** (반대)
- 전기장: α → (−)극 / β → (+)극 / γ → 직진
- 질량: α ≫ β > γ = 0
- **β⁻(Z+1) ↔ β⁺(Z−1) = 전자포획(Z−1)**
- 질량수를 바꾸는 붕괴 = **α만** / 중성자가 느는 붕괴 = β⁺·전자포획
- 이용: 감마 = **투과력**(암 치료) / 알파 = **전리**(연기 감지기)

### 테마 경계
- **T10 원소의 기원**: 붕괴도 핵반응이나 T10은 *생성*(융합), T11은 *붕괴*
- **T1 동위원소**: T1은 *안정* 동위원소, T11은 *불안정 핵의 붕괴*
- **T12 원자모형**(다음 테마): β선 전자는 **핵에서 나온 전자**이지 궤도 전자가 아님(M01661에서 확립)
- 화학 반응식(분자+분자) 금지. 단 **핵붕괴식은 정당**(²³⁸U → ²³⁴Th + ⁴He), 핵종 표기 `ᴬZX` 또는 `원소명-질량수(원자번호)` 허용

### 잔여 64제 소재 후보
① 새 자료 표상(붕괴 곡선 서술·방사선량 자료·핵종 안정성 자료) ② 계산 새 sub-skill(붕괴한 원자 비율·계열 총 붕괴 횟수·세기 자료→반감기) ③ 종합 판별 확장(정체·전하·투과·전리·변화량 교차) ④ T1/T10/T12 다리 추가 ⑤ 총괄 메타(마감 6제)

## 11. 알려진 이상 (결함 아님 — 집계 시 유의)

테마별로 세면 두 곳에서 숫자가 어긋나 보입니다. **초기 시드 단계에서 만들어진 잔재 문항 2건** 때문이며, 게이트는 통과하는 정상 문항입니다.

| 문항 | 태그 | 정체 |
|---|---|---|
| **M00001** | `textbook_theme=33` (기체의 압력, 235쪽) | 프로젝트 극초기 시드 |
| **M00004** | `textbook_theme=9` | 같은 시기 시드. T9 실제 생산분은 **M01315~M01478 = 164제**이므로, 이 1건이 더해져 T9가 165로 집계됨 |

따라서:
- 총 등재 **1,742제** = 테마 생산분 **1,740제** + 초기 잔재 **2제**
- 완성 테마 판정은 **ID 범위**로 하세요(`theme_order_final.json`의 `range` 필드). 단순 카운트로는 T9가 165로 보입니다.

처리 방침은 Eric 판단 사항입니다 — ① 그대로 둔다(현행) ② 해당 테마 진행 시 정식 편입한다 ③ 별도 보관으로 뺀다. 어느 쪽이든 **10,000제 목표 집계 기준을 먼저 정하고** 진행하는 편이 좋습니다.
